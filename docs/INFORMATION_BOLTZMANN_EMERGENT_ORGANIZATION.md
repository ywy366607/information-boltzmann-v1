# 后续假设：个体内的层次组织与传播

2026-09-10，用户提出，尚未验证。当前OWT单个体训练保持原方程和配置；本记录不触发新增训练或架构改动。

## 三类竞争解释

1. 非线性数据驱动和可学习gamma使个体形成持久多模态组织、不同时间尺度及传播模式，并对预测有不同作用。
2. 主要是单势阱的受迫随机振动；阈值分组、投影、低样本量制造了团簇外观。
3. 存在结构和波动，但来自输入统计、显式sin/cos时钟、优化器更新周期或数值离散，不具有所推测的语义分工。

## 不能预先当作事实的部分

粒子数增加不保证相分离。无数据驱动、固定正阻尼和匹配热浴的调和系统具有单峰Gibbs平衡分布，可作为理论反例；无热浴的阻尼系统还可收缩。因此不得写“绝不散开或聚拢、必定分裂为多个团”。

单一调和势阱没有预设多个深/浅局部势阱；无阻尼线性振子的频率由kappa决定，不因轨道更大自动变快。局部gamma改变阻尼，但不会自动建立主题/句法/拼写分工。当前粒子是同一概率分布的等权采样点，不是预先分配角色的神经元。

## 个体纵向研究

- 在多个年龄窗口检查完整x/v组织；区分嵌套结构、瞬时靠近、单云整体收缩。检验阈值变化及跨时间成员交换，不预设固定团数量。
- 提取集体快慢模式及其寿命；允许同一粒子参与多个模式。先问结构是否出现，再问时间尺度是否分化。
- 使用真实文本中可追踪的主题/语法/局部统计关联提出功能候选；后续受控干预检验预测影响，不从轨道半径直接命名语义。
- 传播须先定义在信息位置空间或相空间中的局部可观测场，检测有方向的时延/相位梯度和传播速度；整体同时振荡不算传播。
- 排除输入的共同驱动、固定时钟、更新周期、显示混叠。物理时间单位未标定，模型频谱不能直接命名为人脑alpha/beta。
- 增加粒子数用于后续系统族/分辨率研究，不改当前个体的粒子数或生命史。32粒子限制空间结构分辨率；保存原始记录供后续分析。
