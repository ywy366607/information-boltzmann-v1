# 统一 64px / 256px：七条竞争解决方案

日期：2026-09-05。北极星为 `NORTH_STAR.md`；本文件是选型，不是已实现能力。
七条按唯一改动位置区分，第一轮不组合。故障原因可能共存，不能声称物理上互斥。

## 当前证据与问题重构

- 观测：第一轮 3200 步同权重重载后，两种尺寸真实完整描述均 2/2；自然图生成
  边缘相关仅 0.179/0.059。证明更长训练曾解决文本串台，但未解决图像细节。
- 观测：完整银行 800 步 1px RGB IoU 全为 0；36 个笔画像素在 256px 只占
  0.055%。两个样本的背景/笔画 RGB 头梯度范数比为 217/437，方向部分相反。
  来源 `mixed_full_sparse_gradient_800.json`。这是末端局部测量，不是全网根因证明。
- 观测：冻结最终 X 后，目标拟合线性 logit 读出未恢复自然图边缘；该拟合不是
  最优 RGB 上界，不能据此断言状态已经丢光信息。
- 观测：未来 τ=0/1 的目标不同，但时距消融尚未可靠正向。当前先验只在 τ>0。
- 三种独立重构：①目标函数让哪些误差获得学习机会；②全分辨率地址与有限
  Slice 写入能表达哪些结构；③共享参数如何同时保留不同条件任务。
- 约束：同一持久 X、瞬态 Slice、共同 H、Slice/Deslice 写入；冻结 Pythia；
  不增加私有骨干、外部生成器或推理真值。循环在非循环能力闭合之后再议。

## 七条方案（每条只改变一个机制族）

### S1 观测似然的空间测度：让细节获得有效监督

假设：均匀像素平均使小区域误差被背景稀释。仅改变训练时 RGB 似然的
空间积分权重：显式掩码存在时，对前景和背景分别归一再加权；自然图没有
掩码时，以预先定义的目标梯度分层，保留平坦区监督。不改变推理输入或网络。
这是重新定义加权观测目标，不是原均匀 NLL 的无偏估计，不能把二者混说。
实现核查后首试只改 RGB Gaussian NLL：分割 CE 已经前景/背景各半，保持不动。
笔画邻近背景要单独监控，避免前景重权导致整块涂红；不能用阈值伪造自然图分割。

预测：笔画对 RGB 头的有效梯度占比提高；同预算 1px IoU/自然图边缘提高且
背景误差不爆炸。若只改善稀疏字形、不改善自然图，则仅支持稀疏监督修复。
首试：同一稳定检查点、同样本顺序/优化器/预算，均匀似然对照与分层似然各
800 次联合更新，400/800 步两个原生尺寸全部复测；不同时增加边缘头、MoE
或 Slice。此预算只能筛选方向，不能以短程失败永久否证训练机制。

### S2 共享优化器的冲突处理：避免任务更新互相抵消

假设：单项任务存在有效下降方向，但轮换训练在共享参数中彼此抵消。
只改变更新规则：每个任务族获取梯度，采用冲突感知的梯度组合，再更新原参数；
不改损失、样本权重、坐标、attention。4GB 下顺序累积，不能并驻多个大图。
此前全局 PCGrad 在动作微世界失败，因此不是全新、已保证有效的解。

预测：先测当前真实任务的梯度余弦与一步相互损失变化。若负冲突很少，或消除
冲突后仍没有内容改善，放弃。对照必须匹配梯度计算次数，不只匹配优化器步数。

### S3 输入空间坐标的频率基：提供可学习的细位置差异

假设：空画布只有平滑坐标，写入前很难形成高频地址差异。仅将现有 xy 编码
扩为连续、分辨率无关的正弦/余弦坐标，再投到同一个 X；内容仍只经 Slice 写入。
不增加固定像素表，不增加 Slice 数，不动局部算子与损失。

预测：高频地址响应可辨识，生成细节改善且同权重支持两种尺寸；用相同参数量
的非周期坐标 MLP 作对照。若只有像素纹理/混叠、真实形状不改善，拒绝。
这是候选归纳偏置，不是对“Transolver 必须频率编码”的理论主张。

### S4 瞬态 Slice 空间基扩容：提高单层写入带宽

假设：16 个 Slice 在四层中的写入基不足。仅将 M=16 改为 M=64，仍每层重读
X、同一 Deslice，固定数量与分辨率无关；不引入额外循环、坐标频率或新路由。
记录参数量、显存、耗时；不能把更大计算预算的收益说成同成本优势。

预测：内容误差随 M 增加下降，而不是只多出重复 Slice。比较有效写入谱与
输出细节；若有效基仍重复，继续堆 M 无依据。旧 64-Slice 生成也曾失败，
但布局/训练方案不同，不能直接当作当前修复图的决定性否证。

### S5 任务 TToken 条件的隐式专家化：学习每个头何时参与

假设：相同头在不同模式下反复承担不兼容功能。仅让观测任务 token 给现有
attention 头的更新输出产生连续增益；原 QKV、FFN 和写入路径共享，不新增
专家骨干、不按输出 need 标志路由、不由任务 ID 硬选私有头。
它是隐式功能分工候选，不自动等于真正 MoE，也不等于零值 attention sink。

预测：任务间头增益形成可重复差异，打乱任务条件会破坏对应能力且整图性能
提升；若所有任务同一增益或只是整体缩放，就没有专家化证据。以等参数、
无任务条件的头增益作对照。旧 sink 失败只约束旧方案，不替此方案判死刑。

### S6 同图观察后验教生成先验：把重建能力传给空画布生成

假设：源图存在时 X 能承载细节，但空画布语义先验没学到同一表征。只增加
训练期同图静态后验—先验对齐：目标图的 τ=0 感知产生 q，空画布+文本产生 p，
在同坐标下使用停止梯度的 q 与 p 的 KL，并用原观察似然锚住 q。
不得把 q 的 X、Slice 地址或目标像素送入预测 p；推理仍一次图前向。

预测：p/q 场差距和真实生成误差一起下降；KL 降但图像不改善或 q 坍塌则拒绝。
同额外前向预算对照必需。它与 S1 的区别是增加表征层训练约束，而非重分配
RGB 误差；与既有语义 F2 prior loss 的重叠必须先审查，避免重复约束。

### S7 时间监督的可辨识性：同历史配多个真实未来目标

假设：只有相邻一步、变化微小的两组三元组，使当前重建足以解释大部分监督，
无法强迫模型有效使用时距。只改时间数据配对，不改模型/损失：同一历史 0/1
分别配 τ=0 当前帧1、τ=1 帧2、τ=2 帧3，以及历史1/2配下一帧3。
使用已缓存真实帧和官方掩码，不伪造动作，不修改静态任务回放。
新增帧3由此前未训练变成训练目标，必须显式登记，不能继续把它报为留出集。

预测：同输入不同 τ 的输出差异应对准真实变化，错时距目标能量更高；不是仅仅
让输出变得不同。同样未来样本曝光预算对比原配对与多时距配对，静态预算保持。
若只是按视频身份记忆或多 τ 仍无正效应，不支持该解释。它只解决时间条件学习，
不承诺修好静态生成。

源码核对修订：最初考虑的“τ 门控内容残差”已存在于
`NativeMoTStack._active_memory_prior`（prior_residual + 固定 atlas + τ 门控），
不能算新方案，故在选型前替换为上述独立的时间数据方案。

## 必要性与独立选型

没有证据证明七条中任何一条是统一冠军的充分必要条件。S1 的局部依据最直接，
但它可能只修复 1px；S3/S4 针对空间表示；S2/S5 针对共享使用；S6 针对知识
传递；S7 针对时间数据可辨识性。首选应最大化信息增益、降低改动耦合，而非宣称
一步解决所有能力。所有最终门仍要求同一权重、两个原生尺寸和全部任务。

## 独立子智能体选择（已完成）

`select_seven_solutions` 独立核查候选、源码及证据后选择：**首选 S1，后备 S3**。
完整顺序：S1 > S3 > S6 > S7 > S4 > S2 > S5。七条分别改变观测测度、优化规则、
坐标编码、工作空间容量、头条件化、表征监督、时间数据，修订后无机制重复。

选择 S1 的理由是当前 RGB 均匀平均与实测背景梯度优势直接吻合；S3 是不同的
空间表示解释。不能用同一任务内前景/背景冲突，冒充 S2 所需的跨任务冲突证据；
也没有证据证明 S5 的任务特异头冲突是主因，因此隐式专家化排后而非永久排除。

核验 S6 有别于 clean stem Slice 均值对齐；S3 有别于旧路径的 xy_features，
当前原生 stem 本身仍为 RGB+xy 线性投影。主要风险为 S1 放大误差却无法定位，
产生 flood，故必须保留邻近背景；只修好 1px 不算自然图生成成功。

建议首试的稳定起点：`mixed_native_full_64_256.pt` 的 800 步状态，SHA256
`5718aee71281bccb93203c84e0c7ac9fbfeff275772f9537b625df42418f974a`。
两臂复制相同优化器、样本序列和退火位置，种子一致；旧文件无 RNG 状态，因此
只能两臂统一重设 RNG，不声称重现旧训练的全部随机轨迹。顺序跑两臂，不与
当前训练并驻重型进程。只改 RGB NLL 测度，KL、分割平衡、所有门不变。

400/800 步逐例评估全部任务：若只梯度改善而图像不变，不算能力改善；若背景
涂满、数值失效，或已通过文字案例退化且无图像收益，拒绝该分支。800步没有
方向收益则停止本次筛选、考虑 S3，不把它说成 S1 永久无效。当前只是经独立
选型的实施建议，尚未进行该 A/B，不宣称它能一次解决全部未通过能力。

## S1 已获用户授权：实现与对照排程

`fine_grain/spatial_likelihood.py` 已实现训练专用权重。明确掩码存在时，使用
前景/其两像素邻域背景/远背景三个互斥层；没有掩码的自然图，以 RGB 一阶
绝对差的逐点通道平均取横纵最大值，选 ≥80% 分位且 >0.01 的边缘，再建
邻域和远背景。固定 5×5 膨胀，不按观察到的结果调阈值。空层排除，其余各
分得相同总质量；返回每图均值为 1 的权重。常量目标精确退化为均匀权重。

仅 `omni_loss` 的 Gaussian RGB NLL 接受可选 `rgb_likelihood_weight`，默认
仍调用原来的全像素平均；训练权重不传 `forward_real_capacity`。模型图、
异方差、KL、分割 CE、Pythia 和推理代码不变。所有有 RGB 监督的任务按同一
规则处理，不通过 output-needed 标志改变动力学。此方案有意改变空间测度，
不声称其仍是均匀 NLL 的无偏估计。

对照入口 `scripts/run_spatial_measure_ab.py`，只在当前完整银行训练正常结束
并完成独立重载后运行，已经排入顺序等待。分别输出 `spatial_measure_uniform`
和 `spatial_measure_stratified`；起点、Adam 状态、样本轮换完全一致，总退火
仍为 6400 步，仅执行 800→1600。400/800 次新增更新后评估全部 42 例×两尺寸。
已有报告保护，不自动覆盖；源检查点哈希不符或前一训练失败即拒绝启动。

完整测试 398 项通过，随后补充的同图集成测试也通过，验证只有 RGB 损失变化、
分割项和前向 RGB 不变、梯度可达；Deslice 独立检查全过。尚未取得 A/B 结果，
不能把实现与测试通过称为生成能力改善。结果汇总保留逐样本原始指标、背景
与邻近背景 flood、实际回答及各项变化量，不用加权训练损失比较能力。
