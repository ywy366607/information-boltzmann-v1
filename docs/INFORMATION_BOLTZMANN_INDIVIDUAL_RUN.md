# OWT 单个持续学习个体：首轮 5000 更新

用户于 2026-09-10 授权执行。研究中心是同一个体的生命史；不进行 toy 能力门槛，不启动多种子或种群比较。

## 数据与训练定义

使用 data/ib_owt_10000：固定 OWT revision 433fe0f44ed7894fea29c08b3202aa348ccc6369，10000 文档，约4815万训练字节 token。训练/验证/测试按正文哈希划分，精确去重，未完成近重复清理。byte tokenizer，260 词表；不称完整 OWT 或标准 BPE 基准。

一次初始化，跨文档不重置；先预测后观察；每16个真实 token 更新一次，反传窗口16。首轮5000次参数更新等于80000 token。窗口边界仅截断计算图，状态和时钟继续存在。5000更新是观察预算，不预先视为收敛。结束保存同一个体，续训不得回绕数据或重生。

模型：4维 x 和4维 v，32粒子，hidden=2048，4层初始联合 flow，4个动力学子步，FP32。总参数52255054；初始密度网络只在启动可达的首个反传窗口学习，后续长期更新作用于数据力、碰撞与分布读出等路径。总参数不等于每次更新都活跃的参数量。

采用可学习局部 gamma(x)，初始化0.3，范围(0.01,2)，temperature=0.1，kappa=1。它是任务梯度学习的耗散场，不是已验证的临界反馈控制器；旧 adaptive_gamma 禁用。

## GPU校准与实际限制

在同一真实OWT前缀上测128 token的运行成本，未用这些短测的CE选择模型。hidden=128/256/512/1024/2048的吞吐约6.07/6.00/6.02/5.94/5.79 token/s。2048的PyTorch峰值约1168 MiB，nvidia-smi总占用约1537 MiB。选择已测的最大宽度，保持比最小宽度少于10%的吞吐损失；不是宣称这是最佳模型容量。

GPU为GTX1650 4GB。设置PyTorch allocator上限为总显存75%，保留外部程序/驱动余量；这不是所有外部程序同时运行都不会OOM的保证。每5秒记录GPU利用率、显存、温度、功率。单个体时间递推、随机碰撞及细粒度算子使GPU利用率仍约30–40%，没有达到满载。未并行多个个体，也未截断碰撞数量改变随机法则来抬高读数。

碰撞预先批量生成独立候选随机数，候选碰撞仍按顺序作用于速度。法则不变，但相同seed的轨迹与旧代码版本不再逐位相同；本次源码与配置保存到运行目录，后续严格续训拒绝源码/配置/数据版本不一致。

## 生命史记录

每个事件落盘：CE、真实token id、相时间、位置/速度矩、各坐标均值、gamma分布摘要、动力学能量、驱动做功、阻尼损失、OU端点随机能量、碰撞能量误差和账目残差。预算张量在GPU累计、每更新窗口批量拷回CPU；RAM只保留4096事件的年龄局部窗口，完整轨迹保存在磁盘。

每次更新记录：实际update/event计数、窗口/累计CE、学习率、裁剪前梯度范数、吞吐、显存峰值。每100次更新原子保存last.pt；第一次更新也保存以供恢复。birth.pt仅为出生快照，不能恢复初始flow计算图，因此不作为严格续训入口。

每500次更新保存年龄checkpoint，并在独立冻结流上对固定1024验证字节计分（另128字节预热）。测试集不参与调参。复制当前个体做256事件的完整相空间共同噪声响应，epsilon=1e-3；这是有限扰动响应，尚未经epsilon收敛检验，不称严格Lyapunov或历史记忆能力。无法解析扰动时记录测量失败，主个体继续。

年龄局部窗口输出自相关与加窗功率谱，不强拟合标度指数。真实输入统计、显式sin/cos时钟、每16事件的参数更新周期以及成长非平稳性均可产生谱结构，不能直接称临界性。真实历史贡献的干预实验和无限时稳定条件仍待后续研究，不由这些记录代替。

## 运行与恢复

入口：scripts/train_information_boltzmann_lifetime.py；配置：configs/information_boltzmann/owt_individual.json。

运行目录：results/ib_owt_individual_20260910。progress.json记录最新进展；events.jsonl、updates.jsonl和gpu.jsonl记录完整过程。checkpoint含相状态、时钟、优化器、模型、当前token与RNG。中断后使用相同配置和数据，加 --resume 指向last.pt，--updates指定累计更新终点；不改变模型尺寸或重置状态来掩盖故障。

验证：438项全套测试通过；另通过Deslice独立测试。新增在线能量仪表不改变参数更新、验证不改变主个体/RNG的测试。真实OWT完整流水线短检查通过，仅用于运行正确性，不作学习结论。
