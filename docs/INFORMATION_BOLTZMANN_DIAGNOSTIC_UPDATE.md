# 数值核对更新：保持训练暂停

2026-09-10。本轮只做固定参数诊断，没有更新模型参数、启动CE训练或使用test流选型。

## 能量账目

force.kick可选记录冻结位置/驱动下的解析速度积分，分开记录数据力做功、回复力做功、确定性阻尼损失及OU随机端点能量增量；drift记录势能变化，碰撞记录动能误差。相加与实际总能量变化对照。记录开关不改变轨迹或随机数。

CUDA FP64、128事件：最大绝对记账残差2.22e-16；平均回复力/势能分裂残差−4.72e-5。前者只验证实现账目闭合，后者仍需步长收敛。OU端点随机能量不是连续热注入gamma*d*T*dt，不能互换标签。

加入热浴后的连续模型是

`∂t f + v·∇x f + div_v(Ff) = C[f] + gamma*T*Δ_v f`。

在正则/衰减边界条件下，`dH/dt = gamma*d − D_C − gamma*T*∫f|∇v log f|²`。原来无扩散的熵账本不再适用。轨迹速度是随机过程，仍有x(t)=x(0)+∫vdt，但不能把完整dv写成仅确定性Fdt。非零方差可能仅是热浴维持的，不能自动视为信息容量。

## 修正的相空间响应

同时保留所有粒子的x和v扰动，以固定能量坐标范数重归一化；共用随机数、冻结模型和物理参数，扰动不可分辨时抛错而非填lambda=0。无阻尼谐振子解析对照通过。

第一轮128事件、4子步，gamma=1/.3/.1/.03的响应率约−.47988/−.14838/−.04927/−.01510。epsilon=1e−4与1e−5相符。

复核256事件、8子步：

| gamma | 完整相空间有限响应率 |
|---|---:|
| 0.1 | −0.0487603 |
| 0.03 | −0.0146356 |
| 0 | +0.0007538 |

gamma=0的微小正值不能据此称混沌，更不能称临界；需更长窗口、多seed及多方向收敛。目前结果近似普通阻尼振子的−gamma/2，而非已识别的临界转变。禁止将减小阻尼让响应率靠近零本身当作自组织临界证据。随机碰撞接受事件也可能分叉，当前是有限扰动响应，不是未经限定的严格切向Lyapunov指数。

## 两条流与余代数契约

训练流和部署流各自持有phase、时钟、当前输入、独立RNG及（在线学习时）独立优化器；共享是显式版本化参数复制，不能共享可变model对象后让训练无声改变部署预测。

固定输入与随机序列下，检查切块与连续执行等价、checkpoint续流等价、另一条流的训练不影响本流。在余代数`S→(O×S)^I`中，这是可观察行为一致性；在线学习的完整执行状态S也需包含参数/优化器/计数器。有限测试不是所有无限输入上的形式化双模拟证明。

新增双流隔离测试已验证：训练源模型改变参数时，复制后的部署流与独立控制流逐步输出一致。现有独立weights入口与严格resume分别用于新流启动和旧流续跑。
