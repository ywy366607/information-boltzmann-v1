## 优先修正的解释与实现问题

1. **Lyapunov测量不是完整相空间测量。** model.py及exp3只量一个粒子位置差，并在重归一化时清除速度扰动。即使无阻尼谐振子也可能被这种每步投影测成收缩。应联合所有x/v采用固定无量纲范数、共同随机数、全扰动向量重归一化、除以真实时间；先在解析振子上验收。随机跳变还需区分固定事件切向响应和整个随机核的有限扰动响应。当前gamma控制器使用这个代理，不能称已实现临界控制。
2. **gamma=0改变了噪声定义。** force.kick在gamma>0时方差是T(1-exp(-2gamma h))，gamma=0时却设2Th。这不连续；同一涨落耗散模型在gamma→0时噪声应趋零。要研究独立扩散D，必须显式分开参数，否则gamma=0的“相变/发散”被换模型混淆。
3. **能量平衡不能推出NESS。** power_budget报告平均dE/dt=-0.000077，预测净流=-0.023789，残差约0.023712；`is_true_NESS`只用宽松0.05阈值。输入功率取步首、耗散取步末，未按子步积分。应先核对离散功/阻尼/热浴及能量增量，再检查平稳性、持续非零驱动、时间反演/概率流等。热平衡也可以有零能量漂移。
4. **所谓entropy_H是Gaussian协方差熵代理。** exp3等使用0.5 log det(2πeΣ)，对非Gaussian f不是实际熵，更不是H=∫f log f（符号相反）。可保留为体积指标但应改名；不能用于宣称H定理或熵产生测量通过。
5. **自适应反馈改变了被测系统。** analyze_criticality对原轨迹advance后gamma已改变，再advance影子轨迹，可能不再是同参数对照；且两次都会更新控制器。应冻结控制参数进行诊断。权重加载及部分诊断仅load_state_dict，没有恢复另外保存的force_gamma/kappa；严格resume已恢复，但权重评估需明确采用哪组物理参数。

自适应1000事件结果的终点E|x|²约176、动能约119，远高于固定gamma样例。它不是已经稳定在合适临界区的证据；需先修测量而非继续按该代理调参。

## 粒子数实验的建议

先同一checkpoint、同一输入、冻结参数比较N=16/32/64/128下读出误差、输出波动和计算量，分离Monte Carlo积分精度与学习效果。然后各N独立训练相同事件数、相同优化器节奏、相同数据顺序，多个seed，同时报告同时间预算结果。

粒子数增加首先增加数值分辨率，不增加网络参数数目。固定归一化概率质量的N→∞是粒子/平均场近似极限，不能不加定义就叫热力学扩展。当前候选事件数约O(N)，每事件attention读取N个粒子，碰撞部分可能约O(N²)；先profile，勿仅从固定参数数目推断成本不变。

## 余代数能带来的实际价值

用S→(O×S)^I描述接收输入、给出输出并继续运行。固定参数时S包含f、时钟与必要运行状态；在线学习时闭合的执行状态还包含参数、优化器、更新计数与随机数状态。这些是实现状态，不代表另加一个神经memory模块。

最直接的应用是把“行为等价”变成验收：相同事件/随机流下，完整运行、切块运行、断点恢复、训练与部署应给出一致输出；随机模型也可比较输出分布。它不证明稳定、不证明无遗忘、不证明无限容量。参考：[Jacobs余代数教材](https://www.cs.ru.nl/B.Jacobs/CLG/JacobsCoalgebraIntro-1.0.pdf)。

## 临界耗散的启发

线性临界阻尼gamma²=4kappa与非平衡临界点、输入驱动系统的条件Lyapunov零点是不同对象。当前最相关的问题是：相同未来输入下，过去信息是过快消失、可控持续，还是扰动失控放大。先修正确的扰动实验，再联测延迟回忆、输入打乱、关闭碰撞、冻结/在线学习和噪声强度。lambda接近零只能作为候选工作区，不能代替语言任务收益。

参考：[输入驱动网络的edge-of-chaos研究](https://papers.nips.cc/paper_files/paper/2004/hash/f8da71e562ff44a2bc7edf3578c593da-Abstract.html)。该研究不是本模型的保证。下一步优先级：测量正确性 → 同预算粒子对照 → 数据依赖与记忆任务 → 再讨论临界反馈机制。
