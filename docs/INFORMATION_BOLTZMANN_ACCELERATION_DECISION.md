# 加速与临界调节：实施及决策（2026-09-10）

## 已实现、原基线保持独立

`scripts/ib_shared_projections.py`：共享同一token的首层大投影；冻结碰撞子步上下文的key/value投影复用；公共key平移在softmax抵消，value显式减平移。缓存保留autograd，仅限有效子步，在finally清空；deepcopy通过self调用类原实现，已补隔离测试。数学函数不变，浮点顺序改变。

`scripts/ib_fused_ou.py`：已在GTX1650/Windows/Triton3.2编译执行OU前后向融合内核，采用expm1降低小gamma抵消误差；PyTorch继续提供相同外部噪声，诊断账目no_grad。仅支持当前CUDA FP32、(N,D)速度/外力和(N,1)正gamma的一阶训练路径，不称通用可高阶求导求解器。训练主程序/原包源文件未更改，未用加速版本伪装严格续训。通过独立脚本安装模型实例选项。

复现：`scripts/profile_information_boltzmann_checkpoint.py`，传原checkpoint/config/data、新output；`--tokens 64 --save-comparison`，候选增加`--shared-projections`及/或`--fused-ou`。原16事件预热后测64真实事件/4次更新，保留能量记账。

## 端到端结果

原版9.80397秒/64字节；仅共享10.29782秒；共享+融合9.15362秒；仅融合9.45915秒。组合本窗口节省6.6%耗时，模型张量峰值1041.84→875.44MiB，约16%下降。单窗口不是稳定速度排名；共享单独更慢，不能只从减少FLOPs推断提速。编译冷启动未计入已预热吞吐，源码与checkpoint仍分开保存。

从相同检查点执行预热+测量共80事件/5次更新：组合相对原版x最大误差1.31e-6，v9.54e-7，参数1.04e-6，累计NLL差-9.24e-6，RNG相同，累计接受数均6252。这不是长时轨迹等价保证。共享测试覆盖非饱和梯度、在线更新、RNG与deepcopy隔离；OU测试覆盖gamma=.01/.3/2及T=0/.1的输出与非零梯度，连同原信息Boltzmann测试共41通过。未改公共包API。

## 临界性与gamma代价

冻结500权重、同保存相状态/同后续128个OWT字节/同随机数，乘以原局部gamma场的倍率，噪声同时按原OU定义变化；响应去前32事件。相同权重、输入、观测口径：

|约gamma|有限响应率|平均能量|最大能量|续流NLL|
|---|---|---|---|---|
|.03|-.015019|12.3206|29.2965|3.89456|
|.10|-.050311|4.0422|14.3133|3.12702|
|.30|-.149513|1.6675|3.8479|2.93548|
|.60|-.299690|1.0986|1.7739|2.90656|

这是短暂参数干预，不是重新训练的gamma优劣排名或泛化验证。响应随gamma近似-gamma/2；降低gamma让响应趋近零，但在此片段中能量增大、原读出预测变差。gamma=.03平均能量约7.39倍于原值。有限128事件不说明发散或渐近平衡。候选融合gamma=原值的128窗口响应与原版同窗口接近，未显示数值融合把系统推到临界。

因此当前观察支持稳定耗散驱动系统，不支持已经自组织到边际临界。自调节gamma不是现有证据推出的必需结构。不要将线性临界阻尼gamma=2sqrt(kappa)和响应趋零混为一谈，也不要将“控制器达到设定值”称自组织临界。

决定：不启用原有未验证adaptive_gamma控制器。若以后做控制器，目标必须同时约束能量/漂移、局部响应测量可信度与真实数据预测；同时训练固定、可学习、自调节gamma时分别计入控制器测量成本，统一数据与墙钟预算。先解决吞吐以及驱动饱和的覆盖诊断，不能以控制gamma掩盖驱动梯度退化。当前32粒子/短年龄不支持关联长度、尺寸标度或完整学习系统无限存续结论。

## 结构性加速现在进入候选研究

共享+融合版本在形状预热后，对同checkpoint经验测度重复粒子支持（不是训练出的更大个体），冻结单个真实事件重复3次，中位时间N=32/128/512/1024分别.04153/.10085/.39842/.77744秒，候选数17/60/242/484，接受数0/3/6/10。无反向、优化器、记账；仅用于定位规模成本，不能外推完整训练显存或语言能力。可见逐候选顺序仍是扩展障碍，矩阵投影去重不足以消除它。

下一结构候选优先“连续粒子+有限通道碰撞算子”：Slice聚合相空间上下文，在M个通道中并行求碰撞/弛豫，再保守回写到N个粒子。首先分别定义质量、动量、能量约束和非负分布/熵条件；不能用普通attention平均速度冒充弹性碰撞。复杂度目标O(NM+M²)，显式记录M随精度/N增长的需求。关键是减少串行事件链，仅将上下文压成Slice而保留每候选Python循环可能仍无足够收益。

与显式LBM离散速度网格分开：后者是独立结构候选，会改变连续速度要求且高维空间网格可能膨胀。两条均需在原真实数据上重新充分训练，并比较多时刻响应、能量、相关与预测代价；不能直接套用旧权重宣布等价加速。工程优化空间尚未穷尽，但已有小幅收益与规模成本足以让结构研究与后续工程优化并行推进，不必等待声称“极致优化”。
