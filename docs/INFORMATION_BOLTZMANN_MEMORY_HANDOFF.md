## 0. 任务与执行原则

目标：让文本历史通过可学习写入进入持存分布，经持续演化保留，并对真实文本预测产生可测收益。先定位当前系统的信息与梯度瓶颈，再只修改一个核心机制。不是证明 IB 优于 Transformer，也不是让消融指标看起来漂亮。

本文是待执行计划；没有声称建议结构已经有效，也没有独立审核或无限持存证明。用户将本文交给执行者时，按阶段完成代码、数值检查与测量；不要每做完一个文件就询问是否继续。遇到结果矛盾应诊断，不得自行增加模型家族或无限延长训练。本文作者本次没有启动新训练。

优先级：可复现诊断 → 有效梯度 → 每 token 分布写入候选 → 真实文本训练与机制测量。禁止同时换碰撞、读出、分词、控制器和积分器。

开始前读工作区 `AGENTS.md`、本文、`docs/INFORMATION_BOLTZMANN_LOCAL_OPERATOR_SPEC.md`、`docs/INFORMATION_BOLTZMANN_LOCAL_3000_BASELINE.md`。本文不是改变主仓库多模态图的授权；保持改动在独立 IB 实验范围内。

## 2. 数学对象与需要回答的问题

状态 `Z_t=(x_t,v_t)`，形状 `[N,4]` 各一份；经验分布 `f_t=(1/N) Σ δ_(x_i,v_i)`。

现有：`Z_(t+1)=Phi_theta(Z_t, e(y_(t-1)), xi_t)`，`p(y_t)=D_phi(Z_(t+1))`。

待验证三环：

1. 写入：不同真实历史是否产生可辨的分布？
2. 保持：在相同后续文本下，该差别多久衰减？
3. 读取：这种差别是否改善真实目标预测？

同时分清参数学习与状态记忆。冻结参数后的状态变化不是参数学习；非零状态差异不是有用记忆；低 NLL 不是长程记忆证明。

至少保留四个竞争解释：热噪声掩盖信号；阻尼/动力学快速遗忘；写入或读出使用不足；随机梯度噪声和全局裁剪阻碍动态模块学习。当前没有排除训练预算不足。

解析参照（不能冒充完整系统定理）：无驱动、均匀 γ 的谐振子热平衡有 `tr Cov(v)=dT=0.4`、`tr Cov(x)=dT/kappa=0.4`；线性欠阻尼振幅包络 `exp(-gamma*t/2)`，γ≈0.306 对应约6.5 token的 e-fold 时间。非线性驱动、局部 γ、碰撞、离散积分和学习会改变实际行为。

## 3. M01：信号、噪声与保持的冻结权重测量

新增 `scripts/ib_local/measure_signal_retention.py`，禁止修改原训练权重。首先保持现有温度与 γ。

### 3.1 配对设计

默认 8 个文本位置，历史 512 token，后续 256 token，2 组独立噪声。全部来自验证集，避开前4224个用于原 checkpoint 选择的 token，并为此次诊断预先保存固定 offsets。历史和后续不能越过数组末尾；记录涉及的文档边界，不能伪称所有切片都是单篇文章。

每个位置建立：

- A1、A2：相同真实历史 A，不同随机数；测随机变化。
- B1、B2：另一段不重叠真实历史 B，分别配对 A1、A2 的随机数；测历史变化。
- 接相同后续真实文本 S，绝对时钟对齐；A1/B1 共用后续随机数，A2/B2 共用另一组。

碰撞 Poisson 候选、pair、法向、uniform 和 OU noise 必须都配对。实际接受事件可以不同，这是状态干预的结果，不要强制相同接受列表。保留 token 对齐：输入 y_(t−1)，评分 y_t。

### 3.2 观测

分别记录质心 x/v、中心化协方差及谱、读出前平均特征、预测分布 JS 距离、逐 token CE。位置/速度粒子标签距离可作为轨迹指标，但不能单独代表分布记忆；报告粒子置换不变的矩指标。JS 的计算使用稳定 log_softmax，检查非负、有限和同分布为零。

对每种观测 q，分别画/记录 `D_history(k)=mean ||q(A_r,k)-q(B_r,k)||²` 与 `D_noise(k)=mean ||q(A1,k)-q(A2,k)||²`。不要把两者相减后直接称互信息或无偏信号强度。分母接近零时比值标为不可用。

历史收益：`G(k)=CE(B→S,k)-CE(A→S,k)`。A必须是S实际前文。统计区间预定为1–4、5–16、17–64、65–256；报告每位置结果、均值与位置级重采样区间，不能把相邻 token 当独立样本。

### 3.3 温度与阻尼诊断

先完成原配置，再以相同 offsets/RNG 比较 T=0.03、0，γ与其他参数保持。温度从出生后的全部预热和计分演化一致设置；出生基分布不偷偷改动。T=0 时只删除 OU 随机项，不删除碰撞抽样，不清零速度。

若降温增加历史可辨性但没有预测收益，优先定位读出/训练；若连写入后的差别也很小，优先定位输入算子。不要因为降温无效就增加更多温度网格。

γ 调节另列单因素实验，默认不与温度交叉扫描。首先记录实际 γ 分布，只有保持时间被确认是主要瓶颈时再设计 γ 测量。

验收：正常分支复现同协议参考；模型权重哈希前后一致；随机流独立；不拟合目标；输出可复现 JSON、简明结论和限制。

## 4. M02：真实窗口的梯度归因与裁剪审计

新增 `scripts/ib_local/audit_gradient_components.py`，选 age_001950、age_002000、age_003000 等已存在 checkpoint（不存在时明确报告，不造路径）。优先从1950完整恢复，重放到1996尖峰所在更新；使用其保存的数据 cursor、优化器、所有 RNG 与状态，重放副本不得覆盖原产物。

当前估计器：`L_sur = mean(CE) + score - stopgrad(score)`，`score=mean[(stopgrad(CE)-log(V))*prefix_logprob]`。

对同一随机事件表分别求 CE 路径梯度和 score 梯度，记录每模块范数、两者内积/夹角、合计范数、全局裁剪系数、AdamW实际参数增量。参数按对象身份去重；不能重复计共享 embedding。

记录最小被接受 pair 三角核边距、接受率、候选/接受数，以及碰撞上下文核边界。`∂log(1-|r|/h)` 在支持边界敏感是候选原因，不是事先认定的根因。

验收：两个分量相加与原实现梯度在规定误差内一致；相同 checkpoint 重放的正常损失复现；同样采样比较梯度，不在各分量间重新抽样。窗口仍完整128 token，不能为省内存偷偷缩短链。

若 score 方差主导，可单独实现仅依赖过去数据的滞后 EMA baseline 候选：当前窗口开始前固定 baseline，detach，窗口完成后更新，并保存到 checkpoint。不得用包含当前动作结果的 baseline 宣称无偏。任何估计器修正必须通过已有精确路径梯度审计；若修正仅改变共享背景项，要明确 baseline 独立条件。

诊断出问题后才决定是否修复。不要同时改变裁剪阈值、学习率、碰撞核和结构。对严格局部核的替换须重新论证及审计，本文未授权把它改成全局 Attention。

## 5. 决策点：先修学习障碍还是先改写入

| 观测 | 下一动作 |
|---|---|
| 历史差异从一开始就弱 | 优先实施M03写入候选 |
| 初始差异明显，迅速落入噪声；降温改善 | 先单因素验证温度/时间尺度，勿同时改写入 |
| 状态差异保留，读出收益弱 | 检查特征敏感度和学习信号，不先延长记忆 |
| score噪声压制有效梯度 | 先做独立梯度修正基线，再评估写入 |

以上可同时发生。需要给出证据表，选最少改变；不得自动把所有候选串在一起。

## 6. M03：每 token 的分布写入候选（规格，不是已证有效机制）

只在前两阶段定位后实施。保持当前出生、驱动、局部碰撞、T、γ、读出和128-token BPTT不变，唯一新增为每token一次的状态条件分布映射：

`f_t^+ = (W_psi[ e(y_(t−1)), f_t ])_# f_t`

`f_(t+1) = Phi_theta(f_t^+, e(y_(t−1)), xi_t)`。

此处#表示推送分布。它在数学上仍是一种受控状态更新，不能仅因称为“写入”就认为不同于广义外力，也不能预先宣称获得慢变量。

### 6.1 最小可编码实现

新增 `scripts/ib_local/write_operator.py`，接口 `forward(x:[N,d], v:[N,d], token_embedding:[H]) -> (x_new,v_new,diagnostics)`。

- 拼成 `z:[N,2d]`，两层交替仿射耦合。每层分 `z_a,z_b`。
- 由只依赖 z_a 的粒子特征构造 K/V；由 `[z_a_i, token_embedding]` 构造 Q，4头、宽64的 Attention＋MLP输出 s/t。输入只有一个已观察 token，没有外部历史缓存。
- `z_b'=exp(s)*z_b+t`，z_a保持不变；下一层交换分组。
- 初始候选 `s=0.05*r/sqrt(1+r²)`，`t=0.05*u/sqrt(1+||u||²)`，每粒子分别计算范数；系数属于待校准设计值，不是理论常数。最后输出投影初始化为零，初始映射为恒等。
- 分支依赖必须仅来自本层保持不变的 z_a 和token，因此可按层反序求逆。不能用完整 z 作为背景后仍声称这一逆公式成立。
- 所有粒子共享网络，不加粒子序号 embedding，保证置换等变。保留粒子数和质量；不要求写入守恒动量/能量。碰撞算子继续三守恒。
- 这是全局输入写入映射，必须与严格局部碰撞区分；不得把它标成局部碰撞或归因于碰撞。

有界单步scale/shift不保证长期有界；exp(s)连续放大仍可能累积。不得在文档声称它保证无限持存。需要记录写入的能量增量，并分析组合一步的漂移条件；未推导前只报告有限轨迹。

### 6.2 接入与验收

每 token 在原4个子步之前调用一次；计分目标不得传入写入网络。出生仍只一次；跨窗口状态不清空。候选保持现有外力是为了单因素对比，可能存在冗余，必须在文档承认。

测试：恒等初始化；逐层逆映射；置换等变；shape/dtype/device；写入参数有有限非零梯度；改变未来目标不改变过去状态；128-token普通路径与8-token图复用值/梯度一致；连续checkpoint恢复匹配。初次恒等时内部部分梯度可能为零，检查末端投影及一次更新后梯度，不强行要求所有参数首步非零。

不得为达到速度目标改成静态写入、截断跨块梯度、减少真实候选。若图模式未接入，就明确报告普通路径速度，先完成正确性。

## 7. M04：训练与测量

第一检查预算建议3000更新×128token；这是起始预算，非能力判决。执行者收到训练授权后按此执行；更长预算应基于验证曲线与用户预算安排，不擅自无限续训。

如果M02改变训练估计器，必须同时保留“仅修估计器、不加写入”的同预算基线；不能把两种改动的收益全归写入。若未改变估计器，则原基线是参考，新run需要匹配seed/data/config，并记录新增参数成本。

固定指标：验证 NLL；固定特征 NLL；`G_context=NLL_constant−NLL_normal`；持续每token重置损失；正确/错误真实历史差异；移除写入、移除碰撞的分支；各模块梯度；写入能量增量；质心、中心化方差、状态谱、γ分布；速度和专用/共享显存。

固定特征从不重叠校准文本产生，选择规则在看计分目标前冻结；不能在测试位置挑最差常量夸大收益。保留每位置结果，按文档/文本片段统计不确定性；不把512个相关token当512个独立样本。后续正式验证扩大文本覆盖，避免一直反复调同四处位置。

出现以下情况时只报告观察，不改写成成功：总NLL下降但G_context不增长；状态差异延长但预测无改善；写入有用但碰撞仍无作用；训练仍持续改善但预算用完。

阶段成功需同时看到：不同历史可写入；保持轨迹可复现；真实历史改善预测；干预对应机制削弱该改善。无需要求所有模块都有收益。达不到时按环节定位，不宣布动力学普遍失败。
