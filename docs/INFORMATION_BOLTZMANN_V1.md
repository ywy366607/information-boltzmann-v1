# Information Boltzmann v1 项目设计

日期：2026-09-10。交付状态：设计、实验协议与独立环境；模型和训练器待实现，尚无训练结果。本文是本分支新实验的规格，不替代原项目 `NORTH_STAR.md`，不将文本实验表述为已完成多模态统一。原工作区未提交实验不在本分支基线内。

## 1. 唯一目标与边界

最终需求：训练和部署都是单个实时、无预设终点的信息流；f是持久状态；真实到达的token提供驱动与在线监督；研究长期有界的非平衡运行。原先“每前缀重置”的有限闭环已被此规格替代。无限流指接口与状态连续运行，不代表无限存储、无遗忘、永不故障或已证明非平衡稳态存在。

验证 `X → Fθ[X] → f₀(x,v) → Information Boltzmann → fτ → Dφ(fτ) → Y` 能否从数据学习有效预测。x,v 均属于 R^d；v 是 x 的速度。禁止 Gaussian 后验假设、固定 velocity bins、独立 x/v embedding、额外 uncertainty/memory/energy 模块。第一阶段不加入外部检索、预训练语言主干、辅助重建、KL 正则、熵目标或循环置信度控制。

必须区分三个问题：联合密度是否表达输入；动力学是否改变可读预测信息；语言收益是否超过同预算普通流式模型。它们不能由一条下降的训练 CE 同时证明。

## 2. 数学契约与持续驱动扩展

对每条运行流：f≥0，∫∫f dx dv=1，初始x/v二阶矩有限，无穷远通量消失。持久状态只有f，token到达后不重建f₀、不重置x/v。

```
∂t f + v·∇x f + div_v(FI f) = C[f]
FI(x,v,t;y_j) = −κx −γv + bθ(x,y_j,t)
bθ = Amax / sqrt(d) * tanh(aθ(x,y_j,t))
κ>0, γ>0, ||bθ||≤Amax
```

y_j是最近已经观察到的token，在下一段动力学中提供外力。aθ不读取v、未知目标或另一个历史缓存。原始输入经Fθ建立f₀；后续流输入经已有FI进入同一分布。新token不会被赋值成x或v，也没有新增Bayes更新、memory、energy或uncertainty模块。

回复项−κx与阻尼−γv是为长期有界目标提出的明确建模假设，属于FI内部解析项，不是从H定理自动推出的结构，也不是所有可行方案中唯一必要的形式。κ=γ=1是v1起点，固定不学习；Amax=1。后续扫描其单位一致的比值。

由于div_v FI=−γd，原式FI·∇v f必须替换为div_v(FI f)，否则质量不守恒。展开时多出的−γd f不能漏掉。连续输运特征仍是dx/dt=v、dv/dt=FI；碰撞时仅v跳变、x连续，因此dx/dt=v几乎处处且x(t)=x(0)+∫v ds。

C对子步局部保持质量、动量、动能，完整受驱动系统不承诺动能守恒。q=∫f dv，μ=E[x]，Σ=E[(x−μ)(x−μ)ᵀ]；它们由f直接计算。质量矩给出∂t q+div_x∫vf dv=0。协方差不是经过校准的预测置信度。

新输入是有界加速度条件，不是粒子权重重分配。其条件信号可在到达时刻改变，但粒子不瞬移。动力学时间与参数更新时间分开；token事件只决定驱动何时更新，不把v当token embedding。

## 3. 初始神经算子：推荐联合条件可逆流

Fθ 的输入是运行开始时的启动信息 X_boot（最小为BOS），输出是可查询、可采样的联合密度对象，不是某个粒子或两条向量。条件编码器 h=Eθ(X_boot) 只在Fθ内使用；decoder不能读取原始token或h。后续已经到达的token只允许通过FI的bθ进入。一次运行只初始化一次，后续历史由f携带。

令 u∈(0,1)^(2d)，z=logit(u)，z 的基密度是标准 logistic；令 `(x,v)=Tθ(z;h)`：

```
f₀(x,v|X)=p_base(Tθ⁻¹(x,v;h)) |det ∂Tθ⁻¹/∂(x,v)|
```

T 是交替掩码 coupling 层，掩码跨 x/v 切换，使两部分联合依赖；首版可用有界 log-scale 的 affine coupling，后续同接口比较 rational-quadratic spline coupling。独立的是参考噪声坐标，不是最终 x 与 v。logistic 只是计算参考测度，不预设 f₀ 是 logistic/Gaussian；受限流族仍有表达局限，应以非对称、多峰、相关联合密度任务验证。有限层连续可逆流不承诺精确表示断裂支撑或任意密度。

使用可计算 Jacobian 的 coupling 与有界参数保证有限步计算；不能用只输出样本但无密度接口的生成器冒充已实现 f₀(x,v)。接口：`condition(tokens, mask) -> PhaseDensity`，`sample(n, generator)`，`log_prob(x,v)`。同一个 X 必须支持多个连续样本与任意坐标查询。

| 方案 | 优点 | v1 决策 |
|---|---|---|
| DeepONet branch/trunk | 输入到坐标函数直接，便于 f(x,v,t) 查询 | 合理对照；softplus 仅保证正值，归一化常数与连续采样仍需高维积分 |
| 条件联合可逆流 | 显式归一化、连续采样、log_prob、重参数化梯度 | 主路线；优先解决概率对象的硬约束，不声称普遍优于 DeepONet |
| 普通隐式密度网络 | 坐标查询灵活 | 同样需要归一化与采样，不优先 |
| FNO/网格神经算子 | 对已有规则场求解有用 | 2d 维相空间网格成本高，且固定速度网格违背本阶段要求 |

Fθ[X](x,v,t) 可作为整个解算子的记号，但 v1 必须实现 `S_t(Fθ[X])`，不能让任意时间 trunk 绕过动力学自行给答案。是否比 DeepONet 更好只能在同参数/计算预算下实验判定。

## 4. Attention 参数化守恒且满足 H 定理的成对碰撞

根据追加需求，主方案升级为局部二体弹性碰撞，替代只保证质量守恒的单粒子 gain-loss。对每个 x,t 要求：

```
∫ C dv = 0,   ∫ v C dv = 0,   ∫ |v|²/2 C dv = 0
∫ C log(f) dv ≤ 0
```

质量是概率质量，动量是速度一阶矩，能量明确指动能二阶矩；不新增 energy network。它们是 C 子步的不变量，外力作用下完整系统的动量和动能可以变化。

对同一位置的两速度 v,w，抽连续单位方向 n，定义反射型碰撞：

```
a=(v−w)·n
v'=v−a n
w'=w+a n
```

该映射是对合、Jacobian绝对值为1，逐事件精确保持 v+w 与 |v|²+|w|²。速度与 n 都连续，没有 velocity bins。d≥2 才有非平凡单物种弹性混合；d=1 等质量碰撞仅交换速度，不能用来验证非平凡耗散。

```
C[f](x,v)=∫dw ∫dn B_f(x,v,w,n)
                 [f(x,v')f(x,w')−f(x,v)f(x,w)]
```

dn 采用球面归一化测度。要求 B≥0、有限有界、交换两粒子不变、碰撞前后不变，并对 n 与 −n 对称。attention 输出原始 score s_f(v,w,n)，对粒子交换、正反碰撞、n变号生成的有限对称轨道求平均，再做 B=Bmax sigmoid(mean(score))。这些对称项全部用同一个当前局部 f 上下文计算；不能在反向项重新改变背景分布。attention 参数化的是碰撞率，不任意改写碰撞后的速度。

普通逐行 softmax 一般破坏正反对称，不能直接把其结果当 B。局部 f 的积分 attention 可以在 score 内部使用；最终 B 的对称化必须显式保留。B 允许依赖当前 f，只要每个固定 f 下具有上述对称性，瞬时 H 不等式仍成立。

记 A=f(v)f(w)，A'=f(v')f(w')，则碰撞熵产生为

```
D_C = 1/4 ∫dx dv dw dn B_f (A'−A) log(A'/A) ≥ 0
(dH/dt)_C=−D_C,  H=∫f log f dx dv
```

由 (a−b)log(a/b)≥0 得到符号，而不是训练一个熵惩罚使其“尽量”成立。需要 f 的正性/熵可积性及通常边界、交换积分条件；零点按极限处理。

这是熵增加、H耗散，不是动能损失。正常非退化碰撞下，局部碰撞平衡是 Maxwellian 速度分布；这不是预设 f₀ 为 Gaussian，但意味着长时间强碰撞可能抹去高阶速度信息。若连渐近平衡趋向 Gaussian 也禁止，则经典三守恒加 Boltzmann H 定理不能原样照搬。

粒子求解有关键限制：连续样本很少共享同一 x。采用 x 空间近邻/核匹配只是在近似局部算子。每次保持两个粒子的 x 不变，确保碰撞经验 q 完全不变；成对更新速度确保全局经验动量/动能不变，但不同 x 的配对不保证逐 x 精确动量/动能守恒。报告核宽度趋零、N增加的局部残差，不能把全局守恒当局部守恒。先通过空间均匀 d=2 的机制测试，再接受非均匀近似。配对概率也必须保持对应对称性，不能在抽样阶段破坏 B 的设计。

## 5. 数值求解与训练梯度

数值顺序固定为每步输运Δt/2 → 碰撞Δt → 输运Δt/2，各子步使用同一动力学时钟。随机事件及非线性冻结会限制整体阶数，不能仅因对称分裂就声称二阶收敛。

初始从联合流采样 N 个等权连续粒子；它们是数值积分节点，不是 velocity bins。f₀ 有精确 log_prob；f_t 首版只有弱形式粒子近似，不能把 Dirac 经验测度称为任意坐标处的平滑密度求值器。不添加 KDE decoder 来掩盖这个边界。

每个token事件间隔默认ΔT=1个模型时间单位，参数跨子步共享。数值最大步长默认0.25。动力学t是连续变量；OWT没有实时到达时间戳，默认采用事件时钟。若部署使用真实间隔，需记录单位换算并在训练中覆盖这些间隔，不能声称只在等间隔训练就自动完成真实时间泛化。没有新token时不凭空生成外部监督。

FI子步需正确处理阻尼：冻结x与该子步时间，令c=−κx+bθ，则v(h)=exp(−γh)v(0)+(1−exp(−γh))c/γ；drift子步x←x+hv。交替力、drift与碰撞是方程的分裂近似，不宣称有限步精确解全部连续动力学。需要步长收敛与长时Lyapunov诊断，不能直接沿用仅适用于v无关力的实现。

碰撞采用成对候选事件和有界率拒绝采样：候选方向 n 在连续球面抽样，按 B/Bmax 接受，再执行守恒反射。总事件率必须包含局部密度与伙伴采样测度，不能只用一个与密度无关的 Bernoulli 概率冒充二次 Boltzmann 算子。以均匀 toy 的解析弱生成元检验时间标度和双计数系数。每步冻结 f 的局部上下文，减小 Δt 检查冻结误差。

训练：f₀ 与连续方向采样可用 pathwise 梯度；依赖参数的接受/拒绝及伙伴选择必须带 score-function 梯度，方差基线采用常数或 batch leave-one-out，不新增 learned critic。必须比较数值期望有限差分；只对最终速度普通反传而漏掉离散事件概率导数是错误实现。先用微型期望积分验证梯度，再训练 OWT。

不选 `C=-div_v(f A_attention)` 为主线：它是可守恒的速度漂移闭合，但完整轨迹会变成 dv/dt=FI+A，容易把碰撞伪装成额外力；仅允许作为明确标记的替代研究对照。

## 6. Belief 与输出

等权样本估计 μ=N⁻¹Σx_i，Σ=N⁻¹Σ(x_i−μ)(x_i−μ)ᵀ。这里是经验分布协方差，用 N 而非 N−1；不是无偏总体协方差估计器。测试对称、半正定、平移不变性。N≤d 时低秩是采样事实，不增加方差预测头“修复”。

decoder：`logits=ρφ(N⁻¹Σψφ(x_i,v_i))`，再 softmax 输出词表概率。积分读出对粒子顺序不敏感，利用整个分布的非线性特征；仅 μ,Σ 读出作为消融。decoder 不能看到 X、h、f₀ 或额外 token skip。评估固定随机种子并增加 N 检查采样误差。

## 7. 单信息流的训练、部署与 OpenWebText

唯一运行循环如下，训练和部署共用同一个step函数：

```
state = Fθ[X_boot].sample(N)          # 仅启动一次
current = BOS
循环，无预设结束位置:
    state = evolve(state, current, ΔT)
    prediction = Dφ(state)            # 下一token尚不可见
    y = receive_real_token()
    score_and_record(prediction, y)   # 必须先评分
    accumulate_CE_and_update_if_due() # 监督来自已经到达的y
    preserve_and_detach_state_if_update_boundary()
    current = y
```

保存预测时参数版本或保留其计算图；不得使用学习过y的参数重新计算并替换刚才的预测分数。参数更新后保留state的数值，不调用Fθ重新编码历史，不声称它是新参数下所有历史的精确后验。生成出的自采样token不自动当外部真实监督；没有环境反馈时不据此自训练。纯文本生成与真实流学习必须区分来源。

更新节奏默认每16个真实token一次，训练部署一致；截断反传边界只detach图，不重置f。每个预测CE为−log p(y|history)，先预测后学习的累计NLL称prequential NLL。有限反传不等于无限历史精确梯度；初始Fθ只在启动后的可达图中获得梯度，不能偷偷周期重置来训练它。其输入到分布能力在专业真实数据集上经充分训练后评估，长流主实验诚实记录这个优化限制。

禁止随机独立前缀batch。主实验batch=1，单条有序流；chunk_length=16仅作反传/输出缓存边界，不是记忆长度。跨文档用EOS/BOS标示，不清空f。每个seed是一条独立运行，运行内部不重置。复现保存流游标、最近token、f粒子、参数、优化器、随机数、t与待结算预测；任意切块方式在关闭学习时应产生相同预测。

数据使用Skylion007/openwebtext（当前数据卡约8.01M行、只有train split）。准备阶段固定revision和文件SHA256，优先parquet，不执行远端数据脚本。文档标准化后按SHA256划分98/1/1，再按固定文档顺序形成各自的信息流；完全重复文档不跨split，近重复另外审计。不得先切窗口后随机划分。

tokenizer只用train文档训练byte-level BPE，词表8192，保存BOS/EOS/PAD/UNK约定及哈希。词表预处理与主模型在线学习分开披露，主模型不能通过词表预处理获得validation/test。OWT是静态有限语料，不能当作已验证无限实时环境；重复循环必须计次数，不能当新增独立数据。

验证有两个互不混报的协议：冻结参数评估通用预测；复制检查点到隔离验证会话，按与部署相同节奏进行先评分后在线更新。验证更新不得写回训练检查点。流式test从冻结的选定起点只跑一次，允许预先声明的在线更新，但当前token的分数必须来自更新前。记录总NLL/真实target总数及exp(NLL/数)，不平均batch PPL。跨数据域评估需报告输入顺序，不能掩盖顺序敏感性。

本机配置：d=4、N=32、hidden=128、batch=1、在线更新窗口16、每事件4子步、20k真实target；FP32。小规模配置：d=8、N=64、hidden=256、8子步、1M真实target。AdamW lr=3e−4、weight_decay=0.01、grad_clip=1、warmup=5%；seeds11/23/47。都是待实测起点，不是已调优参数。

本机GTX1650 4GB；本次安装的是CPU PyTorch，反传预检通过，CUDA尚未配置。先跑数值门与100步吞吐，再决定GPU环境及1M预算。无CUDA训练完成声明。配置位于configs/information_boltzmann，revision=null表示未锁定数据，未来训练器必须拒绝该值。粒子空间核宽度待M2收敛测试锁定；现有JSON是设计配置，不是已可执行训练任务。

## 8. 可证伪假设与验收

| 假设 | 控制/测量 | 判定 |
|---|---|---|
| H1 联合密度能承载输入 | 真实数据集输入条件化；充分训练后比较原始/打乱输入；密度积分另作数值单元检查 | 密度负值/不归一化/不依赖 X：实现门未过 |
| H2 运动确实满足速度语义 | FI=C=0 时 x(t)=x₀+tv₀；常力解析解；逐段路径积分 | FP64误差<1e−8；随机跳变中 x 连续 |
| H3 碰撞算子合法且被使用 | 固定 x 事件前后经验质量、非负权重；禁用 C、随机化 attention | 质量误差<1e−6；无统计差异则不能宣称碰撞有效 |
| H4 动力学贡献语言收益 | 相同流/在线更新节奏重训：禁用C；完整模型；同参数同预算普通流式网络对照 | 3 seeds 配对验证 NLL差，文档级bootstrap CI；包含0则不宣称收益 |
| H5 收益不是积分伪影 | N=32/64/128、步数4/8/16，同一检查点和随机数耦合 | 误差不随分辨率降低则先审求解器 |

补充门：一次初始化后跨chunk持续；预测前不能看到目标；训练与部署逐事件相同；恢复游标/RNG/状态后的后续预测一致；固定平稳输入下长时矩与熵收支；概念漂移适应与旧分布回访遗忘。其余门：可逆流逆变换/Jacobian一致、x/v耦合梯度、任意查询有限log_prob；粒子置换不变；未来 token 改动不能影响当前 logits；改变跨样本数据不能影响本样本；保存/加载含 RNG 后逐步重现；离散碰撞梯度与数值期望差分一致。

连续归一化的理论保证与 Monte Carlo 积分误差分开报告；在 d=1 toy 上数值积分检查，不能要求高维随机积分精确到1e−6。当前规格要求 C 的动量和动能守恒及 H 耗散；均匀 toy 逐事件验证前者，用可查询连续密度积分验证后者。经验 Dirac 粒子的微分熵未定义，不能直接对粒子算 f log f；熵测量的网格/核只用于离线低维诊断，不变成速度状态 bins。只有 H1–H3 通过才进入 OWT；H4 仅在专业数据集上充分训练、核对学习曲线及预算后判定；短跑无提升不能定位架构根因。

CE降低只说明优化；打乱输入仍可预测说明可能只学习词频。Σ 非零不证明不确定性有用。高容量 Fθ/decoder 能让动力学被绕过，因此同信息可达性、同在线更新节奏的流式对照是必要对照；消融推理与重训对照分别记录。

## 9. 长期有界驱动与非平衡稳态

用户已明确目标为长期持续驱动、状态有界的非平衡稳态；本文不再把“临界”解释为相变临界或临界阻尼。需要分别验证有界性、非退化性和稳态，不能合并成一个标签。

令E=E_f[(|v|²+κ|x|²)/2]，则连续模型满足：

```
dE/dt = −γ E_f|v|² + E_f[v·bθ]
dH/dt = γd − D_C,   H=∫f log f
```

C守恒动能而产生熵；阻尼排出动能并压缩相空间；已观测数据提供有界驱动。这是明确的开放系统闭合，非完整系统能量守恒。无阻尼时外力做功不能自动抵消H耗散；无回复项时即使速度有界位置仍可漂移。

在质量归一化、有限初始二阶矩、κγ>0、驱动一致有界、严格局部碰撞及适定性条件下，取

```
V=E+ε E_f[x·v]
0<ε<min(sqrt(κ), κγ/(κ+γ²/4))
```

V是正定二次型，无驱动导数中的耗散二次型正定；用Young不等式吸收有界驱动得到dV/dt≤−cV+C，故二阶矩随时间一致有界。bθ按范数封顶，因此即使在线参数改变，这项充分条件仍可保留；训练参数本身和优化器并不因此自动有界。该推导不保证每个样本坐标都处于固定紧集。

特别注意：跨不同x的近似粒子碰撞会改变E[x·v]，不能直接继承此证明。离散方案必须报告该残差、子步稳定性与长期矩漂移，并在N/邻域/步长变化下验证收敛。

有限熵定常态若存在，才有D_C=γd及平均输入功率=平均阻尼损失；统计稳态只要求对应平均收支。不能从这两个等式反推稳态存在。零驱动或常量驱动可能使粒子集中到点，H不再有有限稳态；因此“有界”不等于“不塌缩”。不偷偷加入噪声浴或其他防塌缩模块，先记录协方差谱、近邻距离、速度分布、驱动功率、碰撞熵产生以及任务预测。

任意变化的信息流与不断更新参数一般没有单一时间不变f_ss。第一组稳态探针应冻结参数，给定可复现的平稳输入过程，检查包含输入状态的扩展系统统计规律；第二组恢复在线更新，测长时有界性、概念漂移适应与回访遗忘。即使稳态探针通过，也不能证明整个开放知识流永远不遗忘。有限粒子与有限参数承载有限可用信息。

停止条件：守恒/因果性/散度项错误立即停；长时矩随数值精度改善仍漂移则审查连续假设；塌缩或流式预测不优于对照则登记失败，不把继续运行等同于持续学习成功。只有稳定、非退化和任务有效性分别通过，才能称该设定支持所需长期运行。
