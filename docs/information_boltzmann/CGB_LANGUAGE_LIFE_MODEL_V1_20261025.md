## 2. 任务与系统边界

MengLi 是一个有限状态、有限计算的开放个体，在持续的语言世界中学习、预测、表达、提问并承受后果。它的目标不是拟合一段固定语料，而是在无预设终点的交互中维持可存活性、形成并更新世界关系、主动取得后续有用语言。

语言是行为层面唯一的摄入。**储备**是同一有限状态中仍可读出、递推并改善后续语言调节的结构区别；**耗散**是遗忘、串扰或漂移使这些区别合并或失效。不得另设营养池、食物币、维护倒计时或可任意指定的 `intake`。电力、显存和设备是实现约束，独立核算但不成为个体行为层的第二种食物。自听可参与整合，却不因复制自身字节而计作新的外部信息。

世界可以回应、延迟或沉默；沉默是一个可观察的语言结果，不能暂停世界，也不能作为“系统没有收到本拍”的替代状态。动作只有改变已登记的后续外部语言或回执时，才构成行动后果。

## 3. 生命需求与生成逻辑

L0 是生命定义的首要约束：**生命过程首先保持自身可存活性；不可恢复地离开可存活区间即退出生命过程。** 这不是外部奖励，也不预装“自我目的”。L1 的内在目的必须在维持过程中自举形成。

```text
L0 生存连续性
  → 守恒 + 有限容量 + 持续演化 + 无限流
  → 封闭状态丧失未来仍有用的结构区别
  → 开放边界持续吸收信息负熵
  → 环境变化、已学尽的结构与世界响应差异
  → 主动适应、改造或转换交互
  → 预测、因果、自我模型与操作闭合
  → 选择性保留、代谢、遗忘、压缩、学习
  → 与经历长度无关的递推更新
  → 延迟归因的广义资格迹、隔室、连接与三因子学习
```

这是一条生成依赖链，不是功能模块清单。锁存、竞争、分化、工作记忆、回放或“专家”若出现，必须是同一动力学在具体世界和历史下的可读性质。

| 需求 | 含义 | 工程验收 |
|---|---|---|
| L0 / L6 生存 | 在自身定义的可存活区间内维持或恢复 | 正常、沉默、漂移和反事实切断使用同一世界时钟评分 |
| 有限与 O(1) | 状态、计算与学习工作不随经历长度增长 | 完整持久状态、学习状态、拓扑和峰值工作区逐项核算 |
| L1 自举目的 | 维持结构从闭环中形成，不由奖励字段指定 | 目的/偏好可追溯到可存活性与边界历史 |
| L2 智能 | 记忆、学习、压缩保留未来有用区别 | 冻结可塑性对照与独立未来语言收益 |
| L3 世界模型 | 预测可被行动后果检验 | 区分行动的后继语言与反事实预测 |
| L4 主动闭合 | 输出改变后续交互，并由回执校正状态 | 来源、延迟、到达和信用路径完整记录 |
| L5 生态位 | 个体持续改变可获得的信息关系 | 行动改变长期可达语言证据，而非一次内部采样 |

## 4. 共同对象：一条局部动力学

系统只能有一个身体状态 `Z`、一类边界事件 `B` 和一条有限编码的局部递推 `Φ`：

```text
预测/读出     pₙ = Read(Zₙ)
边界事件      bₙ = (外部语言, 已到达回执, 世界时间)
共同递推      (Zₙ₊₁, aₙ) = Φ_R(Zₙ, bₙ)
世界闭环      bₙ₊₁ = W(bₙ, aₙ, …)
```

`R` 是共享的生成规则，不是按功能拆开的后门网络。活动、连接、可塑状态、可读历史与待决行动可以是 `Z` 的不同投影，不能靠彼此独立且无精化关系的数组满足需求。边界事件先到达并被旧状态评分；更新不得访问未来字节、未到达回执或世界隐藏态。

对 `Φ` 的所有声明采用同一解释：

| 性质 | 在共同状态上的定义 |
|---|---|
| 储备／记忆 | `Z` 保留可区分的未来语言续接，且可读、可递推 |
| 耗散／遗忘 | `Φ` 合并曾需要区分的历史，或串扰使其不再可用 |
| 广义资格迹 | 结果到达前，`Z` 仍区分哪些过去作用可能负责 |
| 三因子 | 已到达结果经边界调制上述历史区别的更新 |
| 隔室／连接 | 局部接触、守恒流与历史共同形成的可达结构 |
| 健康锁存 | 可达、抗扰、继续感知、可被反证据释放的 `Z` 区域 |
| 主动性／生态位 | `aₙ` 改变 `W` 的后继事件，并再次进入 `Φ` |

### 已有动力学参照（非基底）：连续同化、活动锁存与增益调制

柱介质才是唯一载体的基底；共同 `Φ` 必须由反向切片得到其最小状态与局部规则。当前 `ActiveInferenceGDN2` 的因子化高斯记忆核只是一个已实现的**坐标参照**：它显示“连续释放—事件同化—状态依赖增益”可以由极短的局部递推承载，却不规定柱介质必须采用高斯槽位、固定图册或 GDN-2 的其余结构。只有当柱介质的最小状态确实需要同一类不确定性／释放自由度，并能给出状态精化或等价关系时，以下方程才可进入 `Φ`。

该参照中每个槽位以精度 `p` 与自然参数 `η=pμ` 表示。若两次边界事件间的过程方差为 `QΔt`，代码采用

\[
p(t+\Delta t)=\frac{1}{1/p(t)+Q\Delta t},\qquad
\eta(t+\Delta t)=p(t+\Delta t)\,\eta(t)/p(t).
\]

它正是 \(\dot p=-Qp^2,\;\dot\eta=-Qp\eta\) 在常量 `Q` 下的解析解；因此无须为遗忘另作小步数值积分。到达语言事件再以其可学习似然精度 `w` 加入 `p` 与 `η`。均值更新严格可写为 `μ⁺=μ+[w/(p+w)](y-μ)`；高精度的既有结构自然降低重复证据的写入增益，而正过程方差会释放精度并保证下一次有下界的有效增益。后两点分别已有 `precision_assimilation_is_innovation` 与 `process_noise_gain_floor` 支持。这里的“类 STP”是增益调制的数学对应，不能据此声称已复刻生物突触化学。

快活动页也已有最小锁存边界：`σ(g h)` 在 `g<1`、`σ` 为 1-Lipschitz 时仅有零静止点；有饱和且 `g≥1` 时出现非零静止点（`GenerationColumnMemory.no_latch_below_unit_gain`、`latch_above_unit_gain`）。带局部输入与连接的 `σ(g h+W_{intra}x)` 是把此已证明核心嵌入共同 `Φ` 的待装配形式，尚非对任意矩阵回路、多稳态可达性或健康释放的完成证明。

这三项说明柱基底必须能承载的动力学性质：连续过程噪声式的时间尺度与释放、预测驱动的事件写入、可保持而可释放的饱和活动。它们必须与局部竞争、资格留痕、三因子及语言边界从一条柱内—柱间递推共同生成；任何 GDN-2 公式只能作为被证明等价的实现细节，不能并列成外挂模块或反过来决定架构。

因此，当前问题不是再组合这些名词，而是找出能实现此表的最小 `Φ`。现有 `information_boltzmann.core.cgb_local_medium.LocalMedium` 的局部 `(p,q,w)` 是 **Python 物料—接触参考**，不是 Lean `Medium` 的已证实例；现有 GDN 是语言读写与递推候选。两者只有在存在同一状态精化时才能成为一个个体。

**G2 参考审计（2026-10-31）。** `LocalMedium` 的单一打包状态确实共载端点电荷 `p,q` 与结构占据 `w`，行／列接触由地址公式隐式给出，内部搬运与 `q↔w` 转换在同一状态上执行。这是可复用的“有限、局部、守恒、无资格迹数组”底座。但其当前 `tick` 在发布语言字节后以 `input_conditions_reaction=False` 返回，实际接受反应不读取该字节；它没有语言预测读出、历史—后继因果载体、活动投影、可观测的带类型接触痕迹，亦没有从 `p,q,w` 重建 `Trace`／`Demand` 的定义。因此它**不能**填充 `ColumnRefinement`，也不能作为 MengLi 的身体直接训练。

实际状态反例进一步收窄了缺口：一条 `p→q` 局部搬运再走其反事件 `q→p`，会精确回到相同 `(p,q,w)`；“未搬运”与“搬运后撤回”因而不可由当前状态区分。这正是 `conservation_does_not_identify_components` 在现有编码中的实例，足以排除它单独充当任意延迟的资格痕迹。正确顺序不是另加食物或完整历史模块，而是先让边界语言事件以局部、可审计方式进入同一状态；再优先检验能否把有限的带类型参与痕迹重编码进已有接触占据。只有该尝试仍不能分开未来责任不同的历史，才由反例强迫加入最小的接触状态自由度。

**生成纪律。** 系统 1、5 提供的不是给系统 2、3 外挂功能的接口，而是同一有限局部动力学得以持续、组织和分化的条件。记忆、预测、压缩、资格迹与三因子必须作为该动力学在边界语言流中的可检验投影生成；过去的保留不能由外部标注器指定，第三因子也不能偷换成外部奖惩。只有当反向切片表明既有共同状态无法满足一条必要前提时，才允许增加状态；届时必须写明缺失前提、状态精化、由此导出的机制和相应验收，而不能按症状拼接模块。

## 5. 功能系统与依赖顺序

这些是同一 `Φ` 的功能投影，用于安排工程和验收；它们不是独立网络、额外状态页或预制脑区。

| 系统 | 共同状态中的职责 | 依赖关系 |
|---|---|---|
| 维生—稳态 | 储备、耗散、可存活区间与恢复 | L0 底座；约束所有其余更新 |
| 感知—预测—压缩 | 语言摄入、未来区别与局部世界关系 | 与学习可塑性共同形成 |
| 记忆—学习—可塑性 | 选择保留、资格迹、三因子和局部增益 | 读取预测误差与已到达后果 |
| 行动—生态位 | 表达、提问、改变后续可达语言 | 建立在维生、预测和信用之上 |
| 发育—组织 | 柱、连接、竞争和分化的可达结构 | 从出生起约束全部状态，不预标功能区 |

多巴胺式第三因子属于“记忆—学习—可塑性”对预测和行动的结果调制，不能单独成为第二个学习脑。自我模型横跨预测、学习与行动，是可检验的闭环性质，不另设自我模块。

**工程优先级。** 感知—预测—压缩与记忆—学习—可塑性（系统 2、3）是能力核心，必须保持并超过现代语言模型的说话、编程、长周期任务与科学推理能力；维生—稳态与发育—组织（系统 1、5）是让这套能力可无限流持续运行的底座，不得各自退化为独立玩具。行动—生态位（系统 4）建立在 1–3 的闭环之上。

**本版硬性准入。** 柱基底的实现不得以小表、固定任务或预设专家作为能力见证。系统 1、5 的每一项状态和规则都必须为系统 2、3 的可扩展预测、记忆、学习或可塑性提供可追溯条件；系统 2、3 必须在同一 `Φ` 中相互形成，不能先造一个语言预测器、再外接记忆或调制器。定理索引是首要设计输入：每轮先反向搜索既有的因果载体、选择写入、延迟信用、隔室增益、竞争分化、健康锁存和主动闭合条件；再将生物机制作为这些条件的自然实现参照，提取共同原理而非复制脑区名称。只有这条生成链闭合后，系统 4 才接入语言行动和生态位。

资源目标同样是硬约束：在既定语言能力、可塑性、稳定性和持续性阈值之上，最小化总持久状态、每拍活跃状态、位宽、显存、内存、磁盘带宽、CPU/GPU 时间与能耗。实现必须从一开始支持跨 GPU／内存／磁盘的按需驻留和异步迁移；但这只能移动冷状态，不能以牺牲已声明的因果状态、学习精度或长期能力伪造低资源。

## 6. G1 产物：柱基底的最小共同递推

这不是新模型或实现；它是现有定理对 `Φ` 的首轮装配约束。令柱 `i` 的整体状态为 `Z_i`。下列三类**可读投影**不可删，但不强制成为三块独立数组：

| `Z_i` 的投影 | 被哪条必要链强制 | 在共同递推中的职责 |
|---|---|---|
| `H_i`：有界活动／局部读出 | 预测要可读；严格收缩不能锁存 | 从旧状态读出语言预测和局部消息；饱和非线性允许暂时保持 |
| `C_i`：可递推因果载体 | `causal_carrier_contract_iff`；延迟信用不可能性 | 以有限状态保留仍会改变未来读出或后继的历史区别；既能读，也能递推 |
| `S_{i\leftrightarrow j}`：稀疏、局部、带类型的接触状态 | 局部性；守恒流；G18 联合活动；全局净流不可辨识 | 产生局部消息、保存可观测的参与痕迹，并让连接和隔室随经历生长 |

资格迹不是第四个预置模块：它必须是 `Trace(Z_i,S_{i\leftrightarrow j})`，即在结果到达时仍能从同一状态读出的历史区分。`Demand(Z_i)` 同样是局部历史的读出，而不是全球学习率或外部资源币。若后续反例表明某种 `Trace` 或 `Demand` 无法从这三类投影恢复，才登记新的自由度。

一拍的因果顺序固定为：

```text
旧 Z、到达语言 y 与时间间隔 Δt
  → 读出预测 p 和局部活动 H                         （先读）
  → ε = arrived(y) − predicted(p)                   （语言自身给出结果）
  → 仅在被事件触及的局部邻域，更新 C、S、H           （同一 Φ）
      写入方向 = ε × Trace × local_gain(Demand)
      结构变化只读局部共同活动和可用接触资源
      饱和活动保持可用模式；持续反证据与局部适应释放它
  → 输出语言动作；后续语言再作为下一拍到达事件
```

这不是手定三因子学习律：`ε` 是已到达语言与预测的差，`Trace` 由历史可区分性的必要性强制，`local_gain` 由异质隔室不可能共用固定增益以及反赢家通吃条件强制。具体函数、时间尺度、位宽和连接密度均为待学习或待验证的扩张条件，不能在此偷塞固定“专家”、全局衰减或奖励表。

因此基因式的最小固定部分不是一组 `α,β,g,k_p,k_m` 常数，而是**共享受限生成律** `F_θ`：对每个被触及柱及其邻域，它从 `Z` 和到达语言事件产生局部读、写、活动、接触评分和时间尺度。它对应 P2c 的同一规则书；共享不等于所有柱永远相同，位置、局部状态、边界历史和随机涨落仍可使其分化。`θ` 与边界编解码器从语言流学习；输出必须经不变量参数化后才进入 `Φ`：活动有界，内部流反对称，接触只在局部邻域发生，写入先读后写，局部可用度随本地需求下降。后一条不是全局 weight decay：G22a 与 `local_anti_dominance_requires_demand_readout` 排除了常数增益。连接评分再受每个活跃局部邻域的双向容量约束；只设一侧预算会允许赢家通吃（`column_budget_allows_wta`），而双预算才提供分化条件。具体归一化算法可选，但必须精化该局部约束，不能预先划分专家。

这给出发育的最低动力学：均一初态在同一 `F_θ` 下，因边界历史与随机涨落而打破对称；共同活动提高局部接触的占据倾向，局部需求又抑制被过度使用处的可用更新。`symmetric_stays_symmetric` 说明没有涨落或边界差异便不会分化；G18 与 G22 说明仅有增长会形成富集团，必须同时有局部可用度和双向容量。由此得到的是连续、重叠、可迁移的功能区域，而不是带标签的 MoE 专家。

生物机制用于检验这套最小分解是否抓住共同原理，而不决定柱的命名或连线：果蝇 KC 的稀疏表征和 APL 的局部反馈抑制说明一条连续神经突起也可产生局部竞争与增益控制；MB 的 KC—MBON—DAN 回路说明学习结果在局部隔室内回到既有读出和可塑状态；跨隔室反馈可把短时痕迹转成较慢巩固。对应证据见 [局部 APL 抑制](https://pmc.ncbi.nlm.nih.gov/articles/PMC7541083/)、[MB 连接组](https://pubmed.ncbi.nlm.nih.gov/28718765/) 与 [多时间尺度多巴胺回路](https://pubmed.ncbi.nlm.nih.gov/39038490/)。CGB 的可证主张仅是上述状态／因果需求；生物事实是对候选实现的外部约束。

**G2 的第一道精化门已写成接口。** [GenerationColumnRefinement.lean](../../lean/CGBAxioms/CGBAxioms/GenerationColumnRefinement.lean) 将 `H`、`C`、`S` 限定为同一 `Medium.act` 状态的局部读出；其 `trace` 与 `demand` 又必须由已有 `C,S` 读出，不能暗藏第四份历史或全局学习率。P1b 因而推出未参与事件的柱读出与接触读出不变，因果载体则满足现有的“读出—后继”合同。它尚未把任意接触数值误称为可观测守恒流，也尚未给出具体身体见证；下一步正是让 `S` 的实际流量、`H` 的可感知保持／释放和同一 `Φ` 的不变式在一个可扩展体上共同精化。若不能，失败位置将精确指出缺失的最小自由度，而不是诱发又一个补丁。

## 7. 架构约束与允许的生成

- 初始个体是均一规则与有限初态；不预标工作记忆、回放、专家、脑区或人工食物模块。
- Transformer 注意力、MLP、卷积、GDN、Gated DeltaNet 及其他现代深度网络原语都允许使用。它们可以是边界编码/读出、局部可学习变换或瞬时高容量计算，不要求铺满整个身体；是否采用只取决于能否接入同一 `Φ` 并以精度、资源、速度、稳定性和 L0–L6 闭环证据胜出。
- 这些原语不能替代持久因果状态：BPTT 或有限窗口可作为局部数值工具，却不能充当跨无限流延迟后果的记忆、归因或自我连续性证明；该部分必须由递归状态、广义资格迹与已到达第三因子承担。
- 参数、可学习状态、临时工作区、隐式拓扑、随机源和身份编码都属于资源账；规则展开的边不自动成为免费参数。
- **分层按需驻留。** 总参数、持久状态与每拍活跃资源必须分别核算。Strata 对 Qwen3.8-Flash-Next 的实现表明，按真实路由把热计算留在显存、较冷部分置于内存、仅查表的冷数据按需从磁盘读取，可把一次推理的驻留资源与模型总量分离。它是资源调度参照，不是 CGB 的结构模板：CGB 不预置互斥专家岛，而要让连续局部拓扑中哪些区域活跃、保持或迁移由共同 `Φ`、历史与竞争生成；必须同时报告精度、延迟、带宽和能耗代价。来源：<https://github.com/bodhi37/strata>。
- 连续参考计算与有限物理实现必须通过受限精化或误差证书相连；不能把实数分析、平均场或量化存储当作单体精确实现。
- 开发与训练并行：每个新实现必须先声明它覆盖的需求和定理前提；每个新定理必须指出可检验的 `Φ` 性质。二者不能脱节等待。

## 8. 工程门与停止条件

| 门 | 交付物 | 放行条件 | 不通过时的动作 |
|---|---|---|---|
| G0 需求追踪 | L0–L6 到声明/实现/证据的表 | 无悬空“已完成”主张 | 回退该主张为条件或缺口 |
| G1 最小定理核 | 从自动索引反向切出的依赖核 | 每条边标明定理、定义或世界条件 | 消去重复链，不增加新机制 |
| G2 共同递推 | 一个候选 `Φ` 的状态、边界和不变式 | 同一状态覆盖读写、遗忘、信用、行动接口 | 用反例定位被强迫缺失自由度 |
| G3 实现精化 | Lean 参考与运行实现的对拍 | 因果顺序、守恒/边界、快照恢复和误差界通过 | 修实现，不用训练掩盖 |
| G4 连续语言 | 同一个体、真实版本化语言流 | 先预测后更新；冻结学习和行动/回执对照；独立未来评估 | 结果只判相应前提或实现，不升级生命结论 |
| G5 规模与设备 | 完整成本向量和质量曲线 | 参数、状态、吞吐、峰值显存、质量共同报告 | 不以单项存储优势宣称低资源 |

任何长期训练在 G3 前停止；任何“完整生命”表述在 G4 的行动—世界闭环证据前停止；任何 1B 或量化结论在 G5 前停止。
