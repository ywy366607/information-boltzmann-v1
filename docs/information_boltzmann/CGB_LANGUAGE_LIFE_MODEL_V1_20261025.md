# CGB 连续语言生命体：目标、共同对象与准入规格

状态：架构推导与接口验收阶段。目标约1B独立可学习参数，从随机初始化开始；当前尚无通过训练验收的1B CGB主体。本文件是唯一活规格，重复推导和历史检查按下方来源查阅，不追加逐轮日志。

## 1. 固定目标与验收范围

目标是在连续语言世界中，长期维持自身、主动获取有用信息、持续学习并行动的低资源个体。大脑的生成规律须从共同约束与真实现象中寻找，复杂功能应由同一过程在不同条件下出现。

| 目标 | 必须看到的证据 |
|---|---|
| 长期维持 | 世界持续前进；实际供给、维护、结构保持与失效相互作用；全时域报告生存与损失 |
| 主动吸收信息 | 个体动作改变后续可见信息；配对保留成本与延迟、移除返回信息后收益减弱 |
| 学习 | 实际局部更新作用于未来预测／动作；与保持活动而冻结可塑性的对照比较 |
| 行动 | 请求／输出进入真实外部过程，带身份的后果在后续拍到达；内部采样不代替后果 |
| 低资源 | 完整持久状态、学习状态、拓扑、端口和峰值工作区可核算；同时报告质量与吞吐 |
| 约 1B 规模 | 统计约十亿独立可学习标量，包含词表／读出；展开边数、节点数及固定规则另列 |

一般公理约束生命体，真实世界任务规定要完成的因果响应；精度、截止拍和完整成本共同约束可执行结构。自维持、智能或性能最优不写成新公理。生物与工程证据帮助识别推导中的关系；结构推导出后，若与MLP、attention或卷积等同构，再沿用其名称。

## 2. 一个共同数学对象

采用现有`Interaction.Machine`的开放交互：身体S有限，输入类型I不必有限，交互长度不预设上限。`trace_prefix_consistent`已证全部有限前缀的概率相容，尚未构造无限路径测度。完整个体状态Z_n包含活动、结构、可学习系数、可用历史、储备及待决请求；分栏仅为读写和资源审计。

    p_n = Predict_R(Z_n)
    (Z_{n+1}, a_n) ~ K_R(· | Z_n, x_n, receipts_n)
    后续观察、请求后果及真实供给由登记的外部世界 W 返回。

`R` 是有限编码的共享局部规则；`x_n` 是本拍外部到达信息。语言主边界为原生UTF‑8字节0..255，字节的组合意义由内部状态学习；GPT2词表保留为旧接口适配。先用过去状态给 `x_n` 评分，目标到达后才允许更新。动作可以使用已到达信息，不能访问未来目标或未交付的查询结果。

所有变化使用统一离散因果拍n；到达、延迟和保持范围共用此拍，不引入K/T/H/D。n是外部过程下标，不给身体免费无限计数。有限内态可重复，受不同未来输入驱动的开放轨迹仍可不周期；内部计算不能暂停世界或延长实际可用时间。

学习主路径采用前向递归的广义历史状态，不保留跨拍反向计算图或逐拍激活；BPTT、Adam、FP32 master 和全参数梯度均不是默认组成。历史载体的粒度与位宽由任务充分性、递归闭合及范围界决定，不默认每参数一条 FP16 迹。

短规则须共同约束状态转移：同一局部变化应对未来活动、结构保持和资源交换产生可检验后果。把独立机制函数放在同一个求和式里只是统一记法。具体转移图、函数形式和参数来源仍要登记。

完整编码包括规则、参数、身份、几何和初态。规则展开出 1B 条边不等于 1B 参数；从历史经验得到的任意逐边残差也不因有生成器就免于存储。

详细对照见 [原路线审查](CGB_CLAUDE_LINEAGE_REVIEW_20261025.md)。旧物理材料核链保持归档；不恢复逐层加状态的推进方式。

代数层不要求实数坐标或显式端点表：`AlgebraicCore` 保留有限输运代数，`AlgebraicHomology` 验证给定相邻边界的复合为零。边界与端点可由公式计算；同调合同不自动指定学习参数精度或认知能力。

`history_readout_exists_iff`、`history_transition_exists_iff` 给出历史读出与递归闭合条件；`SensoryRecord.fold_refines` 已有固定4 bit、任意长前向运行的具体见证。这里的空间 O(1) 相对经历长度而言，指历史状态不随经历长度追加；固定模型需要的参数和充分状态另计。共享载体须保留任务所需区别，不能把因子数少当作任意历史的无损压缩。

`CausalState` 进一步从给定的确定性任务合同 `f : List U → O` 构造规范状态。令历史h的未来响应为 `q(h)(w)=f(h++w)`，规范状态集合Q是所有这类响应的像；两段历史合并，当且仅当它们对每个有限续接w都给出相同读出。U/O可表示登记的输入和预测／动作响应，但f的来源及价值仍须独立识别。

    规范读出：Read(q(h)) = f(h)
    规范递推：Next(q(h), u) = q(h ++ [u])
    任意精确递归实现：Out(fold(next, initial, h)) = f(h)
    必有投影：project(fold(next, initial, h)) = q(h)，且project满射到Q。

`realizes`、`fold_refines`、`minimal` 证明上述读出、任意长追加及通用最小性；投影与递推的对应限于可达实现状态。`finite_bound` 先从有限精确实现S推出Q有限，再给出 `|Q|≤|S|`；完整状态若确能编码为b位，便有 `|Q|≤2^b`。这是二进制表示的组合下界，不是每bit的热力学费用定理。现有P1a给定性有限性，硬件字节关系仍按实际表示核算。

`finite_alphabets_unbounded` 给出容量反例：输入与输出均为Bool，只读出历史中true/false数量是否相等，Q仍为无限。重复n次true的历史可用n次false区分于其他长度。有限身体因此须识别适合有限实现的任务类，或给出可验收的误差；“存在有限充分状态”不升格为新公理。

`CausalState.separated_histories_capacity`：若历史族中每对都有共同合法续接使所需读出距离>2ε，续接前固定的code且逐点误差≤ε，则code在族上单射，M≤|S|。M≥1且完整固定B位编码时，B≥⌈log₂M⌉。M数任务必须保留的历史区别，不数一生的刺激；组合码已计入码空间。窗口时空响应也可作读出O，但仅由同一内态和同一未来输入生成的确定性码字仍受初态容量限制；近似关系无需可传递。

通信须固定同一查询及公共侧信息，再给截止拍前可达transcript的完整容量。若接收侧至多2^a种状态、该固定查询的transcript至多2^C种，则M_query≤2^(a+C)；这是同一定理的纸面应用合同。逐对可选不同续接的M不能代入：存n位历史、每次按查询只返回其中1位即构成反例。地址、静默、路由、长度与时序等可见信息也要计入C；无允许因果路径且侧信息固定时不能交付新区别。

上述code计入全部可利用的历史相关参数、隐态、结构、缓存和随机状态；外部记录按侧信息或通信计费。时间窗内持续新输入可增加可读信息，时间经过本身不能恢复已被全部载体合并的过去区别。下界针对合法域及最坏情形误差，平均NLL／随机编码平均风险不直接适用；微观不重复与任务可读区别分开。实际M、B及带宽未识别，容量界不等于显存或速度最优。

有限实现允许近似时，采用参考完整状态x与实现状态z之间的误差证书，不把“距离≤ε”当作可传递的等价关系。误差E必须实际测量或有已证上界控制登记读出；参考与实现处理同一已到达输入，完整更新包括参数／结构学习、储备及随机状态。`Approximation.fold_error`、`invariant_error`给出：

    若 E(x',z') ≤ L·E(x,z)+δ 且 L≥0，则 e_n ≤ L^n e_0 + δ Σ_{k<n}L^k。
    若另有 e_0≤ε、Lε+δ≤ε，则任意长续接均有 e_n≤ε。

一步证书及常数须从具体规律／实现证明，不作为新公理；状态域可取已证明闭合的区域，证书与本拍计算／存储预算共同验收。L=1且δ>0通常只得到随拍数增长的界；L<1是可用充分条件之一，L=1、δ=0或其他前向不变容差合同也可保持精度。无需强求所有任务状态都收缩；被保留的任务区别与实现误差须分别审查。这里只合成同一输入下的误差，动作使世界输入分叉时另需世界耦合合同。

语言读出合同固定为已到达历史上的256字节概率分布，在下一字节到达前给出。参考生成律与约化实现的逐字节分布差异可用总变差登记；转为稀有字节NLL界须另有概率下界或KL合同。当前语言参考律、ε、L／δ仍未识别；fixture自洽评分和精确小整数算术仅验已登记接线与算子。真实语言失配由充分训练、独立未来NLL／bits-per-byte检验，单列于实现误差。

## 4. 从任务合同到可执行结构

| 合同 | 须从约束确定的对象 | 怎样验收 |
|---|---|---|
| H_R | 世界响应、局部收支和因果时限共同约束的完整转移 | 每个状态／相互作用的推导来源及跨读出的共同预测 |
| H_C | 登记精度下必须保留的合法历史区别 | 分离族容量下界；完整递推误差闭合及可达信息／延迟合同 |
| H_W | 连续真实语料及可付费的外部信息端口 | 固定划分、无未来泄漏、动作改变后续观测、端口等待期间输入持续 |
| H_Q | 满足精度和时限的表示、布局与执行过程 | 实际成本与已证下界的差距；量化误差、完整恢复和吞吐分别核验 |

先登记输入、行动后果、合法历史／续接、读出、容差／可靠性、截止拍及资源预算，再推导必须保留和及时交付的信息；计算结构从这些义务中构造。既有算子只在推导需要其已证性质时复用，不先选模块再倒推任务。

`CGB.finite_reweighting_improves_iff` 已形式化一个有限修改的准确判据。对严格正权重 `w(s)`、正修改倍率 `r(s)` 和非空观测事件 E，令 `p=w/Σw`，`p'=wr/Σwr`，则：

    p'(E) > p(E)  当且仅当  E_p[r | E] > E_p[r]。

这给出指定结构修改的学习方向：它对已观测事件相容状态的平均支持，须超过对所有状态的平均支持。概率判据本身不涉及梯度或跨拍计算图；现有有限块实现直接枚举同一规则的旧／新权重，取得该判据所需的精确和。世界允许的拍数内计算、充分递归历史及独立未来预测仍须验收。

若修改只依赖有限局部特征 `φ`，按特征分组得到 `Σ_u ρ(u)[p(φ=u|E)−p(φ=u)]>0`；此分组已用精确分数核对。`local_masses` 从同一旧模型、固定context和纯规则流式取得 `Z,A,Z',A'`；`LocalEdit.accepts_iff` 已证 `A'Z>AZ'` 等价于同一事件概率提高。双分布采样及跨拍统计另需误差／充分性合同，不默认两套缓存。

`local_sample` 用同一权重规则按整数票取样；调用者须提供 `[0,Z)` 的均匀票。`local_edit` 仅提交一个INT4码的合法±1修改，固定共享scale并保留邻码；多个单独有利修改不能据此并行提交。规则配置数≤256、context≤64个INT32、四和≤2³¹−1，交叉乘积<2⁶²；规则回调的纯性、依赖封闭与隐藏分配由调用者承担，当前算子为串行参考。

对内部二值变量与输出位的正联合质量，令旧块为 `(a,b,u·c,u·d)`，只修改内部因子u→v。`LocalEdit.binary_factor_balance` 在任意交换环上已证：

    A'Z − AZ' = (v−u)(ad−bc)。

正质量下，此式与既有判据接合：提高因子的方向由联合对比 `ad−bc` 决定。`(3,1,1,3)` 与 `(1,3,3,1)` 的两个边缘都相同，但u=1→v=2使输出位1概率分别从1/2变成7/12与5/12。已用既有历史读出定理核验：只保留这两个边缘不能精确实现两种相反修改判定。6144组INT4字节／方向／耦合／目标及608张采样票核对实际算法；这不是语言能力检验。

因此，选定学习合同下的历史压缩须同时保留所需读出／修改判定，并对全部合法后继闭合；复用 `history_readout_exists_iff`、`history_transition_exists_iff` 与 `CausalState`。这不强制存四格表、协方差变量或逐参数迹，也不从模型相关性识别世界因果。联合统计如何在学习中有界递推、完整R及资源耦合仍待推导；不把当前事件改善冒充独立未来收益。

现有数值fixture `PackedTreePort` 将有限块接成完整离散字母表概率，3／2常数与修改提议不预选脑规律。原生V=256、D=8，独立INT4码4 bytes／隐藏mask逻辑8 bit；GPT2适配V=50257、D=16、码8 bytes，宿主对象／RNG另计。一般 `D=ceil(log₂V)`，深度d子前缀c合法当且仅当 `c·2^(D−d−1)<V`；单分支概率1，双分支同核归一化。树深归纳给出合法叶和1，纸面推导与558个精确叶概率核对，不作为完整脑或能力证据。

给定旧context s和D个depth码，将每个合法前缀上的正权重归一为联合因子q_d(h_d,b_d|s,b_<d)。共同核是：

    W(b,h'|s) = Π_d q_d(h'_d,b_d | s,b_<d)。
    p(b|s) = Σ_h' W(b,h'|s)，观察b后 K(h'|s,b) = W(b,h'|s)/p(b|s)。

`Interaction.Machine.conditioned_next` 已证明给定联合核及正观测质量时，条件状态分布非负、归一且唯一。任意独立p/K仍可写成W=pK，所以统一来源还须靠共享因素与可否证的共同约束识别；这里各depth的相同码同时影响字节边缘与下一隐藏态条件分布。这里q的函数族与参数仅定义算子测试输入，完整个体的规律仍须按任务、收支与时限推导。

`predict` 冻结D个depth码、context及tick，整条字节／token路径先按同一旧帧评分。原生joint模式随后从旧帧的观测位条件分布逐depth采隐藏位，拼成下一context；条件独立来自此fixture的因子分解，运行无需展开全部联合状态。这是实际内部随机状态，世界后验若要成立须另给观察模型与信念合同。

隐藏态取完后才提议修改一个depth的独立码，最后提交context并推进一次外部拍。此码仅影响目标路径一个因子，故在同一旧context重评时接受提高该当前符号概率；修改提议与顺序仍是算法选择，跨depth共享参数时须重验联合判据。显式advance只保留为legacy兼容路径。

生成沿相同合法树取样，独立生成RNG保证诊断采样不改变观察后的状态递推。恢复以joint v2／legacy v1区分语义，包含packed码、context、规则身份、调度计数与两套RNG；旧无模式v1快照仅允许legacy加载。来源、tokenizer及游标由外层绑定，规则须纯且封闭。有限mask的任务充分性须对具体合同证明；现有1824张条件票及多拍独立CDF核验只覆盖此fixture的精确采样。

真实OWT字节接线沿用已登记的NFC、换行归一及strip后的文档、来源revision和文档级划分。旧数据存储把字节加4并附EOS/BOS；原生适配核对文件与逐文档SHA，仅输出原始0..255，不把标记伪装成字节。文档边界留作来源元数据，不额外喂给当前头。数据文件的INT64布局留在宿主，不成为神经状态或显存要求。来源拥有者绑定字节游标、原数组位置和下一文档身份，恢复跨多字节字符也无需Unicode重解码。

新主协议每字节一外部拍，旧GPT2协议每token一拍，二者分别登记，损失不能直接按不同单位比较。原生流不保证每拍更快；同一文本改用字节通常增加到达拍数，比较须报告总文本字节、bits/byte、总耗时及完整成本。输出保留采样字节；UTF‑8合法性由生成分布学习，显示替换字符不能改写原始输出或评分。

可选感知只增加一种边界关系：冻结编码器把已到达的有限输入映射为附加观察，原生字节仍持续输入。`cgb_sensory_port.py` 留出统一特征receipt，记录来源区间、请求拍、声明送达拍、模型revision、维数及实际向量字节数；强制source_end≤requested_at<arrival，预测前只能读取已送达特征。来源数据与声明区间的对应由输入提供者保证。当前提供有界同步编码与交付门槛，真实异步调度仍由世界接口承担。

[EmbeddingGemma‑2官方卡](https://huggingface.co/google/embeddinggemma-2)确认文本／图像／视频／音频输入及原生768维；768是传感器输出维数，不限制内部脑状态。可选MRL维数512／256／128须重新归一并验证任务损失。它是有损预训练感知，不能替代精确语言字节读出；核心仍从随机初始化，启用传感器后整体须注明使用预训练感知先验。其内部tokenizer不成为核心词表。

全模态感知约740M固定参数，纯文本约270M，另计权重、激活和运行延迟；一条768维FP32向量3072 bytes不代表整个感知成本。官方要求BF16或FP32，禁FP16；GTX1650无原生BF16，默认CPU／FP32。接口延迟加载固定revision，默认仅本地权重。vox尚缺ST≥6.1，现有transformers未识别该模型类型，实际权重前向留待隔离环境验证；本轮注入编码器合同测试通过，不下载权重。

下一准入是固定有世界来源的未来读出、合法续接及精度／时限合同，取得必要区别与可达信息的证书，再构造满足预算的共享递推。规范状态与现有端口复用已证性质，具体状态充分性由该合同验收。公共前缀回读原位接入既有世界接口；充分训练后以独立未来收益判断学习。修改超出本拍预算时延期或跳过，世界照常推进。

## 5. 语言世界合同与外部历史回读

先登记输入、干预、合法历史、精度／可靠性、截止拍与预算，再构造语言闭环。“无限”取无固定终止长度的开放交互；实际持续输入、有效新信息及可取得供给分别由世界合同提供，不要求每拍刺激不同。旧有限World的静态丰富度不足以保证这些条件。H_W保留以下真实数据验收协议：

1. 固定真实 OWT 的来源、字节编码和文档级划分；公共字节流持续推进，先评分再更新，GPT2比较另列时钟与单位。
2. 当前世界允许付费回读本次运行已经公开的字节前缀。请求时冻结区间，非零起点以前的内容无权读取；验证集过去的回读明确标为public-prefix replay。未来若接train-only检索，则另验库划分及近重复排除。
3. 一个待决槽保留冻结区间、请求与到期拍；正延迟后付费交付一次。单槽可隐式配对身份，拒绝／等待／失效均不暂停fresh字节。接纳数减送达／取消数等于占槽数，逐前缀不超过1。
4. 到期回读作为本拍临时附加观察进入同一旧帧的预测与条件递推，不另调用observe冒充fresh拍；下一目标到达后才更新。公开视图只有已到达内容，源SHA／全文件长度及未来文档身份留在审计侧。
5. 维护、查询、写入和更新分别列出成本来源。供给序列与初始储备预先固定，预测 NLL／useful bits 不铸造成资源。
6. 维护不足进入登记失效态；世界继续。全时域评分按固定 fallback 纳入缺失输出，同时单列存活时长，避免只报告幸存片段。

`PrefixReplayWorld`原位替换旧同步后果脚手架：begin交付并收费→冻结预测→publish新字节→评分／递推→可发请求。世界快照保存阶段、已公开边界、待决区间、当前receipt及全部收支；联合模型恢复后重供同一临时观察，模型快照版本不变。有限文件EOF明确结束，不循环冒充fresh；宿主绝对下标和计数不是免费有限身体状态。

真实OWT接口验收使用固定请求时刻与数值fixture，先核验连续性、因果隔离、完整恢复及费用保真信息切断；它不验收已学会主动获取或语言能力。当前延迟是离散外部拍，OS独立生产者与秒／拍截止尚未实现。供给独立于动作时只验收给定供给下的维持；主动取得补给仍需真实任务—供给合同。

| 配对对照 | 保持什么 | 区分什么 |
|---|---|---|
| 冻结学习 | 输入、世界、活动状态与预算口径 | 实际可塑性是否改善未来表现 |
| 历史破坏 | 合法状态、相同当前输入与外部条件 | 收益是否需要保留的过去区别；不注入非法状态 |
| 断行动信息 | 请求、成本、延迟、时钟 | 动作获取的信息是否实际有用 |
| 切资源 | 原个体及持续世界 | 维护耦合与耗尽失效；此对照不单独证明适应价值 |

真实训练从头开始，先校准同一规则的小规模运行，再检验可扩展性。充分训练、曲线、实际更新／数据预算、独立未来验证、A→B→A 回访及停止准则齐备后才判断能力。接口单测允许；不新增 toy 能力研究，不按一次短跑决定架构。

## 6. 1B 的资源合同

独立参数P、展开边E、节点N分开计数；约1B是给定部署目标，尚非推导出的最低参数量。已验隐式块用行列／公式生成端点、零逐边索引；生产布局由推导出的信息依赖和时空预算确定。外部存储、搬运、重算及任意经验重连偏离量按实际过程计费。

预算包含参数、scale、块路由、经推导需要的节点／通道／块／边历史、局部学习状态、读出额外状态、待决请求，以及复用工作区、更新和恢复临时副本。广义历史的所有权未定时不填造一个逐参数迹作为默认。

    常驻字节 = 所有持久项之和
    峰值字节 = 常驻 + 工作区 + 更新临时量 + 恢复临时量

语言头权重已计入 P 时不重复计数；其激活／缓存仍须列出。任何零项表示明确声明没有该项，不表示尚未核算。仅供声明测试使用的 `ResourceSpec` 类已移除，现有bench直接核对实际tensor storage及CUDA峰值；完整预算继续按真实算法审查。

| 已验收布局示例的存储项 | 核算方式 |
|---|---:|
| packed INT4 参数 | 1B 个独立标量为 500,000,000 bytes |
| 每 64 参数一个 FP16 scale | 1B 时为 31,250,000 bytes |
| 规则隐式拓扑 | 零逐边索引；仅尺寸、种子或块级路由，宿主对象开销另计 |
| 广义历史与局部学习状态 | 按已证任务充分状态计，不默认按 P 个 FP16 分配 |
| 临时累加／局部更新 | 按 tile 上界计，禁止默认全矩阵 flow、delta、grad |

布局示例：64 个4096×4096块含1,073,741,824个独立系数槽位，INT4＋上述scale共544 MiB，逐边索引为零。GTX1650实测加入INT32节点后张量常驻546 MiB，PyTorch allocated峰值558.07 MiB，reserved峰值568 MiB；单次遍历约0.677秒。这里只验收存储与输运，scale尚不参与算术；历史、语言端口、学习与恢复仍须按实际算法核算。块数不预设层数；旧16.53GB是拒绝的显式索引方案。

现有隐式块入口已按固定大小tile调用流生产器，分开旧／新节点状态，同一流同时扣源、加目标；3种非整除tile与显式小图逐值一致。每块检查累积溢出，超界拒绝；通用回调的隐藏分配仍是调用者合同，显存实测使用固定受审生产器。INT32临时归约与INT8流可共存；局部修改已有参考，完整1B学习个体尚待实现。

三值关联符号由源／目标确定，可以不存；log₂3 不是整个学习个体的位宽。量化存储和累加器分开核算；原生有限状态的精确打包与改变动力学的量化分别报告。旧手写整数 CUDA 核只证明了特定存储优势，未证明模型吞吐优势。

## 7. 维护纪律与验收顺序

复用现有文件和一个规则核。新机制必须说明它填补哪个已识别缺口、哪条联合预测会区分它；已有对象能承担时合并。定理按可复用科学结论组织，编译辅助声明不作机制计数。

- Lean 总量上限：72 模块、4000 声明、800 源码定理；模块数不再增加。
- Lean 源码行数上限：15600，单文件 900；本活规格上限 220 行。
- `check_lean_complexity_budget.py` 检查库存与当前源码哈希一致，并约束活入口行数；不得用旧库存掩盖新增代码。
- 超预算先合并、缩减或移除冗余；不自动提高上限，不用另开目录绕过核算。

顺序为：生命体定义与世界任务合同 → 精度所需区别 → 状态／可达信息／通信及时限约束 → 预算内构造共享转移 → 递归闭合、误差和收支证明 → 真实语言充分训练、因果对照与完整成本实测。优越性需同合同、同单位比较；报告成本向量与下界差距，未约束的时空权衡保留，不加任意权重打分。结构名称在推导后识别。
