## 2. 任务与系统边界

MengLi 是一个有限状态、有限计算的开放个体，在持续的语言世界中学习、预测、表达、提问并承受后果。它的目标不是拟合一段固定语料，而是在无预设终点的交互中维持可存活性、形成并更新世界关系、主动取得后续有用语言。

语言是行为层面唯一的摄入。**储备**是同一有限状态中仍可读出、递推并改善后续语言调节的结构区别；**耗散**是遗忘、串扰或漂移使这些区别合并或失效。不得另设营养池、食物币、维护倒计时或可任意指定的 `intake`。电力、显存和设备是实现约束，独立核算但不成为个体行为层的第二种食物。自听可参与整合，却不因复制自身字节而计作新的外部信息。

世界可以回应、延迟或沉默；沉默是一个可观察的语言结果，不能暂停世界，也不能作为“系统没有收到本拍”的替代状态。动作只有改变已登记的后续外部语言或回执时，才构成行动后果。

## 3. 生命需求与生成逻辑

### 3.1 无限流生命体（用户定义 v2，2026-10-12，原文）

> 无限流生命体：一个具有有限状态空间和有限计算资源的开放系统，持续暴露于近乎无限的信息流中。它通过自举，自发形成并维持以自身存在为核心的内在目的，利用自身有限的内部自由度，通过记忆、学习、信息压缩等过程形成一定程度的智能，并利用这些智能形成关于周围世界的局部世界模型，据此预测未来、选择行动，主动改变自身与环境之间的相互作用关系，形成操作闭合，进而维护自身生存状态，构建并维持自身生态位，使自身状态保持在由自身定义的可存活区间之内。

### 3.2 实现主链（用户确认，2026-10-31）

生存是生命体的第一需要：失去可存活性即退出生命过程；这不是外部奖励或预先写入的“自我目的”。在守恒、有限容量、持续演化与近乎无限信息流共同成立时，封闭状态会丧失对未来仍有用的可区分结构，因此生命必须作为开放系统从边界持续吸收信息负熵以维持自身。这里的负熵是同一有限状态中可用于后续语言/世界交互的有效预测、记忆与压缩结构，不另设食物、能量币或储备账户。

但可摄入的新结构会被学尽，环境也会变化；被动接收不足以持续维持可存活性。因此系统必须主动适应、改造或转换与环境的相互作用，以获得新的可用信息。主动推理由此要求预测、因果关系与自我模型；自举形成的特异性记忆、遗忘、压缩和学习结构，随后反过来维护生存。有限容量又迫使选择性保留、代谢、遗忘与压缩；无限流要求这些更新的工作量不随既往经历长度增长。延迟后果下的归因由此要求广义资格迹，并进一步约束隔室、连接与三因子学习机制。

```text
L0 生存连续性
  → 守恒 + 有限容量 + 持续演化 + 无限流
  → 封闭状态丧失未来仍有用的结构区别
  → 开放边界持续吸收信息负熵
  → 环境变化、已学尽的结构与世界响应差异
  → 主动适应、改造或转换交互
  → 预测、因果、自我模型与操作闭合
  → 选择性保留、代谢、遗忘、压缩、学习
  → 与经历长度无关的递推更新
  → 延迟归因的广义资格迹、隔室、连接与三因子学习
```

这是一条生成依赖链，不是功能模块清单。锁存、竞争、分化、工作记忆、回放或“专家”若出现，必须是同一动力学在具体世界和历史下的可读性质。

| 需求 | 含义 | 工程验收 |
|---|---|---|
| L0 / L6 生存 | 在自身定义的可存活区间内维持或恢复 | 正常、沉默、漂移和反事实切断使用同一世界时钟评分 |
| 有限与 O(1) | 状态、计算与学习工作不随经历长度增长 | 完整持久状态、学习状态、拓扑和峰值工作区逐项核算 |
| L1 自举目的 | 维持结构从闭环中形成，不由奖励字段指定 | 目的/偏好可追溯到可存活性与边界历史 |
| L2 智能 | 记忆、学习、压缩保留未来有用区别 | 冻结可塑性对照与独立未来语言收益 |
| L3 世界模型 | 预测可被行动后果检验 | 区分行动的后继语言与反事实预测 |
| L4 主动闭合 | 输出改变后续交互，并由回执校正状态 | 来源、延迟、到达和信用路径完整记录 |
| L5 生态位 | 个体持续改变可获得的信息关系 | 行动改变长期可达语言证据，而非一次内部采样 |

### 3.3 整体约束表（生命闭环验收纪律）

LLM 的模块通常通过张量接口拼接；生命体的模块通过“能否共同维持自身”拼接。感知没有记忆就只是输入，记忆没有学习就会陈旧，学习没有耗散与选择就会饱和，行动没有世界回流就没有主动性。拆开时每块都合理，合起来才可能活。

因此这里的模块不该被当作可独立完成的功能件，而应是同一闭环的不同投影。以后每项实现先过一张“整体约束表”：

| 约束项 | 核心准入条件 | 缺失时的状态标注 |
|---|---|---|
| 1. 有限状态 | 持久状态 $Z$ 与每拍工作区有严格上界，不随时间累积历史缓冲 | 若依赖历史全长缓冲，标为“未有限化” |
| 2. 持续信息流 | 适应无限流世界时钟，沉默与延迟均为可观测边界事件 | 若依赖批次重置或静态截断，标为“非无限流” |
| 3. 选择性保留 | 新信息进入必须伴随局部耗散/竞争，禁止无损全局堆叠 | 若缺乏遗忘/容量饱和释放，标为“无代谢” |
| 4. 长期信用 | 延迟后果必须由有限递推资格迹或局部载体承载，非离线反向回溯 | 若需跨无限时间反向求导，标为“非因果闭合” |
| 5. 开放交互 | 外部语言为因果输入与校验来源，禁止预设外部奖励/食物字段 | 若设人造奖惩或虚拟能量币，标为“伪外生” |
| 6. 主动维持 | 行动改变后续语言摄入，操作闭合反哺自身存活性 | 若行动不改变外部后续证据，标为“无生态位” |
| 7. 资源受限 | 位宽、显存、通信与算力必须满足局部可达性 | 若依赖超标全局密集算子，标为“未物理精化” |

缺哪一环就明确标为未闭合，不能把局部通过当作生命体完成。
工程上仍要分层，但分的是运行尺度：底层状态与耗散、记忆学习与调控、预测压缩、行动世界回流。每层都必须有同一状态链的接口和联合验收，而不是各自造一个 toy。这样 A 没做时，B 不会被误判为失败；它会明确显示自己缺少哪条闭环。

## 4. 共同对象：一条局部动力学

系统只能有一个身体状态 `Z`、一类边界事件 `B` 和一条有限编码的局部递推 `Φ`：

```text
预测/读出     pₙ = Read(Zₙ)
边界事件      bₙ = (外部语言, 已到达回执, 世界时间)
共同递推      (Zₙ₊₁, aₙ) = Φ_R(Zₙ, bₙ)
世界闭环      bₙ₊₁ = W(bₙ, aₙ, …)
```

`R` 是共享的生成规则，不是按功能拆开的后门网络。活动、连接、可塑状态、可读历史与待决行动可以是 `Z` 的不同投影，不能靠彼此独立且无精化关系的数组满足需求。边界事件先到达并被旧状态评分；更新不得访问未来字节、未到达回执或世界隐藏态。

对 `Φ` 的所有声明采用同一解释：

| 性质 | 在共同状态上的定义 |
|---|---|
| 储备／记忆 | `Z` 保留可区分的未来语言续接，且可读、可递推 |
| 耗散／遗忘 | `Φ` 合并曾需要区分的历史，或串扰使其不再可用 |
| 广义资格迹 | 结果到达前，`Z` 仍区分哪些过去作用可能负责 |
| 三因子 | 已到达结果经边界调制上述历史区别的更新 |
| 隔室／连接 | 局部接触、守恒流与历史共同形成的可达结构 |
| 健康锁存 | 可达、抗扰、继续感知、可被反证据释放的 `Z` 区域 |
| 主动性／生态位 | `aₙ` 改变 `W` 的后继事件，并再次进入 `Φ` |

### 已有动力学参照（非基底）：连续同化、活动锁存与增益调制

柱介质才是唯一载体的基底；共同 `Φ` 必须由反向切片得到其最小状态与局部规则。当前 `ActiveInferenceGDN2` 的因子化高斯记忆核只是一个已实现的**坐标参照**：它显示“连续释放—事件同化—状态依赖增益”可以由极短的局部递推承载，却不规定柱介质必须采用高斯槽位、固定图册或 GDN-2 的其余结构。只有当柱介质的最小状态确实需要同一类不确定性／释放自由度，并能给出状态精化或等价关系时，以下方程才可进入 `Φ`。

该参照中每个槽位以精度 `p` 与自然参数 `η=pμ` 表示。若两次边界事件间的过程方差为 `QΔt`，代码采用

\[
p(t+\Delta t)=\frac{1}{1/p(t)+Q\Delta t},\qquad
\eta(t+\Delta t)=p(t+\Delta t)\,\eta(t)/p(t).
\]

它正是 \(\dot p=-Qp^2,\;\dot\eta=-Qp\eta\) 在常量 `Q` 下的解析解；因此无须为遗忘另作小步数值积分。到达语言事件再以其可学习似然精度 `w` 加入 `p` 与 `η`。均值更新严格可写为 `μ⁺=μ+[w/(p+w)](y-μ)`；高精度的既有结构自然降低重复证据的写入增益，而正过程方差会释放精度并保证下一次有下界的有效增益。后两点分别已有 `precision_assimilation_is_innovation` 与 `process_noise_gain_floor` 支持。这里的“类 STP”是增益调制的数学对应，不能据此声称已复刻生物突触化学。

快活动页也已有最小锁存边界：`σ(g h)` 在 `g<1`、`σ` 为 1-Lipschitz 时仅有零静止点；有饱和且 `g≥1` 时出现非零静止点（`GenerationColumnMemory.no_latch_below_unit_gain`、`latch_above_unit_gain`）。带局部输入与连接的 `σ(g h+W_{intra}x)` 是把此已证明核心嵌入共同 `Φ` 的待装配形式，尚非对任意矩阵回路、多稳态可达性或健康释放的完成证明。

这三项说明柱基底必须能承载的动力学性质：连续过程噪声式的时间尺度与释放、预测驱动的事件写入、可保持而可释放的饱和活动。它们必须与局部竞争、资格留痕、三因子及语言边界从一条柱内—柱间递推共同生成；任何 GDN-2 公式只能作为被证明等价的实现细节，不能并列成外挂模块或反过来决定架构。

因此，当前问题不是再组合这些名词，而是找出能实现此表的最小 `Φ`。现有 `information_boltzmann.core.cgb_local_medium.LocalMedium` 的局部 `(p,q,w)` 是 **Python 物料—接触参考**，不是 Lean `Medium` 的已证实例；现有 GDN 是语言读写与递推候选。两者只有在存在同一状态精化时才能成为一个个体。

**G2 参考审计（2026-10-31）。** `LocalMedium` 的单一打包状态确实共载端点电荷 `p,q` 与结构占据 `w`，行／列接触由地址公式隐式给出，内部搬运与 `q↔w` 转换在同一状态上执行。这是可复用的“有限、局部、守恒、无资格迹数组”底座。但其当前 `tick` 在发布语言字节后以 `input_conditions_reaction=False` 返回，实际接受反应不读取该字节；它没有语言预测读出、历史—后继因果载体、活动投影、可观测的带类型接触痕迹，亦没有从 `p,q,w` 重建 `Trace`／`Demand` 的定义。因此它**不能**填充 `ColumnRefinement`，也不能作为 MengLi 的身体直接训练。

实际状态反例进一步收窄了缺口：一条 `p→q` 局部搬运再走其反事件 `q→p`，会精确回到相同 `(p,q,w)`；“未搬运”与“搬运后撤回”因而不可由当前状态区分。这正是 `conservation_does_not_identify_components` 在现有编码中的实例，足以排除它单独充当任意延迟的资格痕迹。正确顺序不是另加食物或完整历史模块，而是先让边界语言事件以局部、可审计方式进入同一状态；再优先检验能否把有限的带类型参与痕迹重编码进已有接触占据。只有该尝试仍不能分开未来责任不同的历史，才由反例强迫加入最小的接触状态自由度。

**生成纪律。** 系统 1、5 提供的不是给系统 2、3 外挂功能的接口，而是同一有限局部动力学得以持续、组织和分化的条件。记忆、预测、压缩、资格迹与三因子必须作为该动力学在边界语言流中的可检验投影生成；过去的保留不能由外部标注器指定，第三因子也不能偷换成外部奖惩。只有当反向切片表明既有共同状态无法满足一条必要前提时，才允许增加状态；届时必须写明缺失前提、状态精化、由此导出的机制和相应验收，而不能按症状拼接模块。

## 5. 功能系统与依赖顺序

这些是同一 `Φ` 的功能投影，用于安排工程和验收；它们不是独立网络、额外状态页或预制脑区。

| 系统 | 共同状态中的职责 | 依赖关系 |
|---|---|---|
| 维生—稳态 | 储备、耗散、可存活区间与恢复 | L0 底座；约束所有其余更新 |
| 感知—预测—压缩 | 语言摄入、未来区别与局部世界关系 | 与学习可塑性共同形成 |
| 记忆—学习—可塑性 | 选择保留、资格迹、三因子和局部增益 | 读取预测误差与已到达后果 |
| 行动—生态位 | 表达、提问、改变后续可达语言 | 建立在维生、预测和信用之上 |
| 发育—组织 | 柱、连接、竞争和分化的可达结构 | 从出生起约束全部状态，不预标功能区 |

多巴胺式第三因子属于“记忆—学习—可塑性”对预测和行动的结果调制，不能单独成为第二个学习脑。自我模型横跨预测、学习与行动，是可检验的闭环性质，不另设自我模块。

**工程优先级。** 感知—预测—压缩与记忆—学习—可塑性（系统 2、3）是能力核心，必须保持并超过现代语言模型的说话、编程、长周期任务与科学推理能力；维生—稳态与发育—组织（系统 1、5）是让这套能力可无限流持续运行的底座，不得各自退化为独立玩具。行动—生态位（系统 4）建立在 1–3 的闭环之上。

**本版硬性准入。** 柱基底的实现不得以小表、固定任务或预设专家作为能力见证。系统 1、5 的每一项状态和规则都必须为系统 2、3 的可扩展预测、记忆、学习或可塑性提供可追溯条件；系统 2、3 必须在同一 `Φ` 中相互形成，不能先造一个语言预测器、再外接记忆或调制器。定理索引是首要设计输入：每轮先反向搜索既有的因果载体、选择写入、延迟信用、隔室增益、竞争分化、健康锁存和主动闭合条件；再将生物机制作为这些条件的自然实现参照，提取共同原理而非复制脑区名称。只有这条生成链闭合后，系统 4 才接入语言行动和生态位。

资源目标同样是硬约束：在既定语言能力、可塑性、稳定性和持续性阈值之上，最小化总持久状态、每拍活跃状态、位宽、显存、内存、磁盘带宽、CPU/GPU 时间与能耗。实现必须从一开始支持跨 GPU／内存／磁盘的按需驻留和异步迁移；但这只能移动冷状态，不能以牺牲已声明的因果状态、学习精度或长期能力伪造低资源。

## 6. G1 产物：柱基底的最小共同递推

这不是新模型或实现；它是现有定理对 `Φ` 的首轮装配约束。令柱 `i` 的整体状态为 `Z_i`。下列三类**可读投影**不可删，但不强制成为三块独立数组：

| `Z_i` 的投影 | 被哪条必要链强制 | 在共同递推中的职责 |
|---|---|---|
| `H_i`：有界活动／局部读出 | 预测要可读；严格收缩不能锁存 | 从旧状态读出语言预测和局部消息；饱和非线性允许暂时保持 |
| `C_i`：可递推因果载体 | `causal_carrier_contract_iff`；延迟信用不可能性 | 以有限状态保留仍会改变未来读出或后继的历史区别；既能读，也能递推 |
| `S_{i\leftrightarrow j}`：稀疏、局部、带类型的接触状态 | 局部性；守恒流；G18 联合活动；全局净流不可辨识 | 产生局部消息、保存可观测的参与痕迹，并让连接和隔室随经历生长 |

资格迹不是第四个预置模块：它必须是 `Trace(Z_i,S_{i\leftrightarrow j})`，即在结果到达时仍能从同一状态读出的历史区分。`Demand(Z_i)` 同样是局部历史的读出，而不是全球学习率或外部资源币。若后续反例表明某种 `Trace` 或 `Demand` 无法从这三类投影恢复，才登记新的自由度。

一拍的因果顺序固定为：

```text
旧 Z、到达语言 y 与时间间隔 Δt
  → 读出预测 p 和局部活动 H                         （先读）
  → ε = arrived(y) − predicted(p)                   （语言自身给出结果）
  → 仅在被事件触及的局部邻域，更新 C、S、H           （同一 Φ）
      写入方向 = ε × Trace × local_gain(Demand)
      结构变化只读局部共同活动和可用接触资源
      饱和活动保持可用模式；持续反证据与局部适应释放它
  → 输出语言动作；后续语言再作为下一拍到达事件
```

这不是手定三因子学习律：`ε` 是已到达语言与预测的差，`Trace` 由历史可区分性的必要性强制，`local_gain` 由异质隔室不可能共用固定增益以及反赢家通吃条件强制。具体函数、时间尺度、位宽和连接密度均为待学习或待验证的扩张条件，不能在此偷塞固定“专家”、全局衰减或奖励表。

因此基因式的最小固定部分不是一组 `α,β,g,k_p,k_m` 常数，而是**共享受限生成律** `F_θ`：对每个被触及柱及其邻域，它从 `Z` 和到达语言事件产生局部读、写、活动、接触评分和时间尺度。它对应 P2c 的同一规则书；共享不等于所有柱永远相同，位置、局部状态、边界历史和随机涨落仍可使其分化。`θ` 与边界编解码器从语言流学习；输出必须经不变量参数化后才进入 `Φ`：活动有界，内部流反对称，接触只在局部邻域发生，写入先读后写，局部可用度随本地需求下降。后一条不是全局 weight decay：G22a 与 `local_anti_dominance_requires_demand_readout` 排除了常数增益。连接评分再受每个活跃局部邻域的双向容量约束；只设一侧预算会允许赢家通吃（`column_budget_allows_wta`），而双预算才提供分化条件。具体归一化算法可选，但必须精化该局部约束，不能预先划分专家。

这给出发育的最低动力学：均一初态在同一 `F_θ` 下，因边界历史与随机涨落而打破对称；共同活动提高局部接触的占据倾向，局部需求又抑制被过度使用处的可用更新。`symmetric_stays_symmetric` 说明没有涨落或边界差异便不会分化；G18 与 G22 说明仅有增长会形成富集团，必须同时有局部可用度和双向容量。由此得到的是连续、重叠、可迁移的功能区域，而不是带标签的 MoE 专家。

生物机制用于检验这套最小分解是否抓住共同原理，而不决定柱的命名或连线：果蝇 KC 的稀疏表征和 APL 的局部反馈抑制说明一条连续神经突起也可产生局部竞争与增益控制；MB 的 KC—MBON—DAN 回路说明学习结果在局部隔室内回到既有读出和可塑状态；跨隔室反馈可把短时痕迹转成较慢巩固。对应证据见 [局部 APL 抑制](https://pmc.ncbi.nlm.nih.gov/articles/PMC7541083/)、[MB 连接组](https://pubmed.ncbi.nlm.nih.gov/28718765/) 与 [多时间尺度多巴胺回路](https://pubmed.ncbi.nlm.nih.gov/39038490/)。CGB 的可证主张仅是上述状态／因果需求；生物事实是对候选实现的外部约束。

**G2 的第一道精化门已写成接口。** [GenerationColumnRefinement.lean](../../lean/CGBAxioms/CGBAxioms/GenerationColumnRefinement.lean) 将 `H`、`C`、`S` 限定为同一 `Medium.act` 状态的局部读出；其 `trace` 与 `demand` 又必须由已有 `C,S` 读出，不能暗藏第四份历史或全局学习率。P1b 因而推出未参与事件的柱读出与接触读出不变，因果载体则满足现有的“读出—后继”合同。它尚未把任意接触数值误称为可观测守恒流，也尚未给出具体身体见证；下一步正是让 `S` 的实际流量、`H` 的可感知保持／释放和同一 `Φ` 的不变式在一个可扩展体上共同精化。若不能，失败位置将精确指出缺失的最小自由度，而不是诱发又一个补丁。

### 6.1 现有运行物的归位：一个身体，不是四个候选脑

下表是总装约束，不是新的机制目录。每个现有对象只能承担其已经证明或实际实现的职责；任何一行都不能单独被叫作 MengLi。

| 现有对象 | 可复用职责 | 不能替代的职责 | 在共同 `Z=(H,C,S)` 中的归位 |
|---|---|---|---|
| `LocalMedium` 的 `(p,q,w)` | 有限、局部、守恒、隐式接触地址和付费局部更新的参考 | 语言条件反应、可读的历史—后继因果载体、活动锁存、带类型接触痕迹 | 系统 1、5 的物理/资源精化参照；在它能使语言事件实际条件化局部转移前，不是运行身体 |
| `ActiveInferenceGDN2` 的 `natural, precision, velocity, last_*` | 连续时间的精度释放、到达事件的似然写入、可学习地址/精度和持久关联读出 | 局部守恒接触、竞争分化、可由同一状态读出的延迟痕迹、健康锁存与行动闭环 | 可作为 `C` 的候选数值实现与 `H` 的预测读出；只有连同局部 `S` 和同一 `Φ` 的合同精化后才可进入身体 |
| `GDNByteReadoutPort` | 先预测后到达、真实经过时间、字节读出和当前字节的两相头更新 | 已学习的查询/编码器、长延迟信用、主动行动或完整持续学习 | 系统 2 的边界验收端口；不是新的记忆页，也不是系统 3 的完成实现 |
| `ColumnRefinement` | 规定 `H,C,S,Trace,Demand` 必须从同一身体读出，并给出局部未参与不变式与因果载体合同 | 一个具体可训练的 `Φ`、语言能力或物理流量见证 | 总装的 Lean 门：运行实现必须精化它，不能只引用它 |
| `ResourceCycle` / 旧优化器支线 | 守恒预算、竞争、分化、健康保持/释放的数值学习参照 | 语言个体的持久状态、世界接口或发育组织 | 仅为系统 3 的机制检验；不得成为 MengLi 的第二套身体状态 |

由此固定一个排他决定：**目标载体是柱式共同递归体，而非“LocalMedium + GDN + 优化器”三套并行状态。** GDN 的自然参数更新可以在证明精化后成为其中 `C` 的一个局部数值规律；LocalMedium 的局部守恒与接触限制可以成为其中 `S` 的不变量来源；两者在精化前只能相互约束，不能用拼接掩盖缺口。

这个缺口已有当前 GDN 状态上的精确反例：既有的 `step_source_irrelevant` 证明，同一字节、时间和观测精度的 `.external` 与 `.self` 到达会得到严格相同的完整 `GDNLife.State`，因为现行更新不写入 `Arrival.source`。如果后续世界结果要求区分“自己的表达”与“外界的回应”，任何只读该状态的信用规则都不可能正确。它强迫的不是完整历史缓存，而是能从 `C,S` 读出的**带来源/参与类型的局部痕迹**；这正是 `S` 的最小精化理由，也与 `delayed_action_credit_requires_state_separation` 一致。

第一份运行时 `Z` 只准有下列语义字段：有界局部活动 `H`、可读且可递推的因果载体 `C`、稀疏带类型接触 `S`。`Trace` 必须由 `C,S` 读出，`Demand` 必须由 `C` 读出；语言到达、经过时间和输出行动是一次事件的边界参数，不得另存成“食物”“奖励”或完整历史。任何拟新增张量都必须先写出它是 `H/C/S` 的精化，或给出当前三者无法区分未来责任的 Lean 反例。

这确定了唯一允许的下一步：为一个可扩展的柱式语言状态给出实际 `Z` 的字段、局部事件顺序和不变量映射，并同时证明/测试它满足 `ColumnRefinement` 的读出—后继、局部不变和 `Trace/Demand` 可重建条件。随后才接 GDN 的可学习似然、预测头和语言训练；在此之前扩张 GDN、接入另一个优化器或增加独立记忆页都会重新把整体拆开。

**首个运行时精化候选。** `CGBColumnLanguageBody` 以周期网格实现一份可扩展 `Z`：`H=[B,R,C,D]` 是硬饱和活动；`C=(η,λ)` 是每柱自然参数与正精度；`S=[B,R,C,4,2]` 是四个局部方向上 external/self 两类参与量；每条被触及的几何边从两端共同局部统计得到同一驱动，并同时改写互易端点读数，因此 `S` 的拼接差可收缩而不另加反馈页。网格地址隐式给出，故没有边索引表；每拍只路由有限个柱，且边流以“入流减出流”构造，内部总和为零。读出路由只读旧 `H,C`，到达字节不能选择自身的预测路径；评分后才写 `C,S` 并更新被路由柱及其四邻域的 `H`。经过时间造成的精度释放是另一个全体时间演化：空白间隔严格保持 `H,S` 与 `C` 的均值，只释放 `C` 的精度，不能被偷当作局部输入。`Trace` 是 `(C,S)` 的函数，`Demand` 是 `C` 的函数，均不分配独立数组。相同字节的 self/external 到达只在 `S` 的来源通道不同，正好补足 `step_source_irrelevant` 指出的状态合并；这不是行动日志或完整历史。现已接上 G14 的到达字节头更新：瞬时回执保存旧读出特征，`(到达−预测)×特征` 只在评分后改读出参数，既不写入 `Z` 也不保留反向图。它是语言监督的即时路径，不能替代尚未接入的延迟行动三因子。运行层已做张量合同检查，尚未声称已精化完整 Lean `Medium`、完成在线三因子学习或获得语言能力。在同一真实 OWT 流上，保持互易 `S` 写入而静音唯一的 `S→H` 读边，会使局部 H/C/S 相对 bias-only 的验证贡献从 −0.086 回落到 −0.064 BPB；这把接触读回的作用从叙述变为一项有限范围的因果证据，但其参数尚未自组织学习。

### 6.2 自组装学习回路：下一道精化门

Liao 等人的 Self-Assembling Learning 给出一个外部可检验目标：在匹配学习率与局部衰减下，成对异突触更新会使两个流之间的**拼接误差**指数收缩，而无需预置互为转置的反向权重；完整前行—教学通路误差仍是其主定理的显式条件，必须实际测量，不能由前一结论偷推出来。其模型也仍先假定两条流和输出误差信号。[论文](https://www.pnas.org/doi/10.1073/pnas.2606245123) 因而不是可直接搬入的“四矩阵脑”，而是对 `F_θ` 的一条更强准入条件。

对 CGB，已有两端已经明确：`value_future_log_likelihood_deriv` 将有限前向资格与到达语言误差精确连成 G14 方向；`diagonal_cannot_whiten` 表明有非零耦合时，仅按坐标缩放不能得到充分的关系预条件。缺的是由共同局部规律**生成**这条关系方向的中间环。现有 `CGBColumnLanguageBody` 已让互易 `S` 接触读数因果地进入下一拍 `H`，但仍只有即时的仿射头 G14；它尚未把语言误差带回局部资格，也没有可学习教学通路。

这一中间环现有一个最小、已证的构件：`reciprocal_shared_update_mismatch` 与 `reciprocal_iter_mismatch` 表明，一对互易局部通路若读取同一个异突触统计并具有同一释放率，其拼接误差会几何收缩，即使二者仍持续接收新统计。它没有预置转置，也不证明多跳通路已对齐；后者恰好由下面的实测门承担。`value_future_teaching_direction_deriv` 与 `positive_teaching_alignment_is_local_ascent` 则把“对齐”锚定为精确未来语言分数的正一阶方向，而不是某个看似合理的反馈相关性。

因此后续只允许如下精化，而不新开记忆页或硬编码反向矩阵：同一共享规则 `F_θ(H,C,S,事件)` 必须从已有局部读出产生前行消息与教学消息；教学消息的参数是同一规则的可学习参数，不是第二个持久个体状态。对每个局部资格方向 `e`，其教学读出 `b_θ(e)` 必须与已证 G14 的 `valueFutureScore(e)` 建立可测对齐，并在真实连续语言流上同时满足：

1. **因果性：** 消息只读旧 `Z` 和已经到达的语言结果；不读未来字节、不保存反向图。
2. **共同状态：** 延迟痕迹仍由 `C,S` 重建；学习回路不得新增独立 eligibility、反馈历史或全局学习率页。
3. **非预置对称：** 不把教学参数初始化为或每步强制为前行参数的转置。匹配的局部异突触项可使其拼接误差收缩，但完整通路对齐仍须作为独立量报告，不能从拼接误差为小便直接宣称。
4. **方向与能力双验收：** 先在同一状态上测 `b_θ(e)` 对 `valueFutureScore(e)` 的符号/余弦对齐，再以冻结教学通路、随机教学通路和精确短程 G14 为对照，在连续版本化语言流上报告独立未来 BPB、持久状态与每拍成本。

这四项是一个生成门，不是新的公理或已完成机制。若当前 `H,C,S` 的读出无法表达所需的局部教学方向，必须先给出两段未来责任不同却在所有既有读出上合并的反例；只有该反例成立，才允许把最小的带类型接触自由度精化进 `S`。这使论文真正服务于本项目：检验学习回路能否从均一局部动力学长出，而不是用生物名词替换反向传播。

## 7. 架构约束与允许的生成

- 初始个体是均一规则与有限初态；不预标工作记忆、回放、专家、脑区或人工食物模块。
- Transformer 注意力、MLP、卷积、GDN、Gated DeltaNet 及其他现代深度网络原语都允许使用。它们可以是边界编码/读出、局部可学习变换或瞬时高容量计算，不要求铺满整个身体；是否采用只取决于能否接入同一 `Φ` 并以精度、资源、速度、稳定性和 L0–L6 闭环证据胜出。
- 这些原语不能替代持久因果状态：BPTT 或有限窗口可作为局部数值工具，却不能充当跨无限流延迟后果的记忆、归因或自我连续性证明；该部分必须由递归状态、广义资格迹与已到达第三因子承担。
- 参数、可学习状态、临时工作区、隐式拓扑、随机源和身份编码都属于资源账；规则展开的边不自动成为免费参数。
- **分层按需驻留。** 总参数、持久状态与每拍活跃资源必须分别核算。Strata 对 Qwen3.8-Flash-Next 的实现表明，按真实路由把热计算留在显存、较冷部分置于内存、仅查表的冷数据按需从磁盘读取，可把一次推理的驻留资源与模型总量分离。它是资源调度参照，不是 CGB 的结构模板：CGB 不预置互斥专家岛，而要让连续局部拓扑中哪些区域活跃、保持或迁移由共同 `Φ`、历史与竞争生成；必须同时报告精度、延迟、带宽和能耗代价。来源：<https://github.com/bodhi37/strata>。
- 连续参考计算与有限物理实现必须通过受限精化或误差证书相连；不能把实数分析、平均场或量化存储当作单体精确实现。
- 开发与训练并行：每个新实现必须先声明它覆盖的需求和定理前提；每个新定理必须指出可检验的 `Φ` 性质。二者不能脱节等待。

旧的八字节审计确认 `readout`、`event_value`、`causal_address`、`column_keys` 与 `reciprocal_contact` 可变化。当前分相回执又使 `event_likelihood` 成为同一 C 写入的第二个可学习坐标：它由**下一字节语言误差 × 同一 C 中重建的后验均值敏感度**更新，和 value 共用既有 C 写入步长，不引入新优化器或状态页。`dynamics_value` 现在也已完成一拍方向对拍：当前语言误差经上拍的接触门、守恒流和 C 中的前一字节，精确回到事件驱动输入；它与 value、likelihood 及共享 `byte_embedding` 在同一原子 C 事件步中共同更新。唯一新增的运行时暂存是一拍流量回执，不属于 H/C/S，也不随经历增长。只有 `process_variance_raw` 仍冻结，因此当前体仍不是完整可学习的 `F_θ`。后续先对每个冻结路径反向切片：若其所需一拍资格能由现有 C/S 重建，就接入同一回执；若两段未来责任不同的历史已在 C/S 中合并，才以该反例精化最小带类型接触状态。禁止逐参数另造优化器、历史页或手工训练规则。

这给出实际的下一道 G2 门：共享局部规则先在**旧 Z 与 Δt**上进行无边界泄漏的预测性内部相，再产生语言预测；到达字节随后只触发局部同化与三拍接触回执。这样规则中影响预测相的参数可由当前 G14 直接学习，事件同化的参数则必须由 C/S 中可重建的一拍资格学习。该分相不是增加模块：它把已经需要的“内部持续演化”和“先预测后到达”写成同一 `Φ` 的顺序，避免把所有可学习性压到尚未到达的输入分支。是否能用现有 H/C/S 重构事件相的全部资格，必须先由逐路径反例或证明决定。

**反向切片的最小结论（2026-11-01）。** 已将已知的 `Δt` 调整为先经 C 的解析先验、再读出语言预测；这与 `GDNLife.prepare` 一致，零间隔路径保持原样。它同时暴露了全参学习真正只差的一次共同精化，而不是四个独立优化器：

|---|---|---|
| `event_value` | C 的自然参数、精度、前一字节和固定路由；`value_future_score_factor` 已给精确因子化 | 现有一拍更新保留 |
| `event_likelihood` | 同一 C 中的后验均值、精度、前一字节；`assimilate_likelihoodLogitPerturb_*` 给实际写入切线，`likelihood_posterior_mean_deriv` 合并分子／分母为后验敏感度 | 已接入下一字节语言误差的局部因子化；不得另存历史 |

因此代码改造的单位是一个共享的 `F_θ` 事件顺序，而不是参数名单：`Z_{t-1},Δt → Z^-_t → \hat y_t →` 消费先前回执 `→` 同化 `y_t` 并发行新回执。运行器与独立 CPU 参考现已按此执行，且逐状态／参数对拍通过；它仍只有 H/C/S，回执只跨一个已定义边界，长时因果仍须进入 S 的秩／隔室载体。该顺序让可学习路径可审计，并避免为了保存过期参数而复制一整份参数或反向图。先前 OWT 的 S 结果属于旧融合顺序，保留为历史诊断，不能作为此顺序的能力或作用证据；新顺序须重新接受真实流验收。

**新顺序的真实流验收（2026-11-01）。** 在同一初始体、同一 OWT UTF-8 连续训练 100,000 字节、随后不重置地继续 100,000 独立 validation 字节的单种子比较中，`local_g14_event_credit` 的 validation 为 **4.008 BPB**，相同 H/C/S-feature G14 readout 为 **4.107 BPB**，差值 **−0.099 BPB**；训练段差值为 **−0.046 BPB**。记录在 `results/published/cgb_column_event_credit_owt100k_20261101.json`。这表明这条已对拍的一拍事件链在真实语言流上有正向信号，足以保留为当前共同 `Φ` 的学习路径；它仍不是多种子估计、长延迟资格验证或语言能力结论。该 32 宽、8×8 实例的 H/C/S 持久状态为 18,696 bytes；一拍回执为 24,073 bytes，其中新增流量回执仅 512 bytes。事件臂约 790 bytes/s，head-only 约 1,554 bytes/s，因此下一次工程工作应在不改变回执语义的条件下融合三个局部返回的矩阵算子，而不是削掉因果项换速度。
