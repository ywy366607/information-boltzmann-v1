# 同一物理生成元的整核时间推进

2026-10-22；本推导写于实现前，现已按此接入schema3整核模式并完成真实连续副本，见[实现与结果](CGB_FULL_STEP_RESULTS_20261022.md)。承接实际源驱动对照，不新增生物方程、存活目标或结构选择分数。

## 1. 当前顺序的物理与数值含义

当前step(dt)依次推进运动M(dt)、局部反应R(dt)、快场F(dt)，再令全局时间增加dt。各子过程属于同一连续时间生成元的分裂执行，不能把总物理时间加成3dt。快场内部已经采用对称OU组合，但整核M→R→F仍然是一阶顺序。

在外源无非零亲和、同一热浴/零参考电极下，局部反应的正反比、运动Metropolis与OU涨落均对应既有联合G。若各算子保持同一平衡测度π，它们的组合也保持π；所以当前顺序本身不意味着产生了免费能量。但它的伴随为F*R*M*，通常不等于MRF：有限步长可带来由执行顺序造成的时间非互易，不能拿这一项当内生时间方向。

这是对理想物理状态算子的条件结论，不能直接当作当前数组实现整体无偏的证明；§3的边存储顺序会影响有限步F，若它与历史状态相关，还需先消除这项隐藏依赖再讨论实际全核测度。能量账闭合也不能替代这一核对。

这一点与断源后仍可出现库存/混合相变不同。前者是数值路径的互易性，后者是允许的物理瞬态；不能用其中一个抹掉另一个，也不能仅凭宏观增长就归因数值错误。

## 2. 同时守住实际时钟与互易性

候选整核组合：

    M(dt/2) R(dt/2) F(dt) R(dt/2) M(dt/2)

M、R、F各自累计推进dt，全局t只增加dt，外部字节仍4ms、原步长仍2ms。R的两半实际事件记录使用各自反应累计时钟[0,dt/2]和[dt/2,dt]，而不是把第二半也写成从0开始；这不是把三个分裂子过程硬排成总时长3dt。

对无源平衡条件，若每个子核自伴随，则此回文组合自伴随。M按均匀随机节点排列依次作对称空间提议/Metropolis，每个排列与其逆序等权，给出条件互易的运动核。R是已有局部详细平衡的带标记SSA（包括付费域出生/回收），其目标测度及变维提议不改。F必须同时处理下面的执行标签问题。

## 3. 内部桥顺序不能成为隐藏物理状态

内部桥在数组中按创建先后排列；删除后再建通常追加到末尾。物理对象是带方向/r/C/身份的桥集合，数组先后不是新增材料自由度。R在物理图上的概率不依赖数组顺序，但当前有限步F使用该顺序安排不对易OU边更新，因而会在高阶误差中携带创建顺序。

候选做法是在每次F中均匀随机安排内部边顺序，后半使用同一顺序的逆序。每种条件排列仍是同温回文OU核，排列的均匀混合仍互易，且其物理分布不依赖存储排列。端口顺序是已声明的世界端口角色，不以新轴向/目标方向控制材料。随机排列只改变求解器执行，不改变每个通道的总dt、G、噪声温度或物料。

逐个排列的条件通道是Gaussian，但未知随机排列的混合一般不是单一Gaussian。旧frozen_field_channel若没有显式条件排列，必须拒绝把新模式当作同一个解析Gaussian通道；可在小规模下明确枚举排列，不能默默套用旧公式。原源码/档案继续用原顺序，不回填随机数冒充逐位同轨迹。

这些互易性指在物理图/域的执行标签商空间上的核，忽略浮点舍入；不把桥数组标签当作新的记忆。驱动源非零亲和时不要求平衡详细平衡，实际功/热仍照旧核对。

## 4. 实现与验证要求

新整核/边顺序模式须有明确archive schema，旧schema恢复原执行；不新增脑状态或修改物性。只在完成整个算子步的边界保存/分叉；部分算子状态若未保存其阶段游标，不能宣称可完整恢复。

先核对各物理过程累计dt、全局时钟、反应时间标记、关闭扩展的旧未来等价。用已有物理子核的正反密度检查，及小规模OU排列的条件协方差/互易性与存储排列不变性作数值接口验证，不作为人工能力研究。再在完整自然副本上做短真实流和中点恢复，保存所有功热/来源/随机状态。

回文排列消除相应组合的顺序不对称，不自动证明整套算法二阶收敛：运动有限提议本身不是精确扩散半群，源时变和有限步反应耦合仍需实际同T步长检查。不能以一个“对称”名字代替真实时钟、均匀热浴或长期功能证据。完成后继续检验持续交换对维持/学习的作用，不把数值修正作为新生命原理。
