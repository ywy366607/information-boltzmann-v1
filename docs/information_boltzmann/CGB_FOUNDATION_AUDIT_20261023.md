# CGB 基础审计：前提、独立性、量词与证明范围

2026-10-23，Codex。审查基线 `de0268d`。继承 Claude 的六条谓词、原有证明/反例及生命目标；本轮不改物理核、个体或妈妈训练，不增加物理公理，不恢复已撤回的主动推理优势或自我模型。

## 本轮结论

六条谓词在通用 Medium 类中具有已核对的共同模型和逐条独立性反例。本次没有发现要撤销这些 Lean 证明的错误；发现的是跨层特化、量词与文字外推。它们尚非全局最小体系、全部原子条件独立或生命生成充分性的证明。

新增 `Foundation.lean` 的 14 条源码证明/反例，完整构建及全量审计通过。审计覆盖 385 个命名声明，其中 239 个 theorem、104 个为源码显式定理/引理，其余包含自动生成辅助。这些不是大脑机制完成数。工具的 10 个正/负控制通过。

## 1. 独立性必须固定模型类

| 层 | 已承担的前提 | 独立性范围 |
|---|---|---|
| 通用 Medium | 类型、接触、含量、事件、非负实数速率 | 允许无限 Λ，磁带/容量袋子反例有效 |
| 有限生命计算接口 | 身体/局部状态/事件可枚举；有限 World；Clocked 准入 | 有限 Λ 下 P1a 两个有限性分量自动成立，不能再用无限状态反例证明它们独立 |
| 目标与具体载体 | 生存、闭环维持、记忆，以及数据约束的扩张 | 需要目标见证、依赖及实测，底层独立性不自动迁移 |

马尔可夫表示、固定接触/位点/身份、实数速率等也是建模前提。结论依赖它们时必须登记。P1b 等复合条款仍需逐原子条件审核；条款行数不是公理最小性的证明。

### 有限性并未被删除

一般层 P1a 保留，有限计算层的枚举可从其推论选取。原 Medium/Life/Inference/Models 的定义和运行语义未变，没有通过删除底层条款破坏原 API，也没有把枚举实例算作新物理来源。

### 有限速率的结论需要注明刺激范围

反例没有无限身体或无限局部状态，非有限的是刺激范围。它推翻“有限身体单独保证全局界”。LifeConjecture 另有有限 I，所以该处存在某个界，但是否小于给定世界时钟仍需 Clocked 准入。只检查世界可供刺激的较弱时钟，可作为后续接口精简；本轮未替换。

### 概率归一化必须配合非负性

原 `kernel_sum`、`law_sum` 即使在 R 太小导致负权重时也可能成立。原 `kernel_nonneg` 已要求 Clocked；本轮补了后续概率语义。新参数界是从目标见证推出的必要条件，没有反过来添加物理公理。

### 当前恢复量的实际含义

`recover_ignores_world_moves` 将此前代码审阅中的疑点变成定理：当前 recover 是有利刺激菜单下的理想能力，不是当前世界实际可达恢复概率。目标定义保留，语义桥标待修，不暗中替换生命概念。

### 反例不能混用量词

生命主目标是存在性；删除约束扩大模型类，原见证不会消失。坏模型可以反驳普遍机制保证；独立性反例可反驳“其余公理推出这条”；二者均不是完整生命目标的物理必要性证明。后续每条必要性声明必须标明所证结论与量词。

## 3. 主文档已收紧的陈述

- **P1a 与物理界**：抽象自然数含量的有限性不是已形式化的 Bekenstein 界，也没有自动映射为硬件字节或真实能量。
- **P2b 与能量**：已证聚合细致平衡给出 E=−log π 的正反速率比；未证温度/能量标定、逐反应通道热功、完整第二定律。
- **P2c 与 ρ**：实际是等变性及页数/单元数；规则内部有限描述长度、计算成本、实数参数编码、程序比特预算均未由此证明。
- **T-LR**：有限速率不等于正的最短随机等待时间，待研究的是注明几何/耦合前提的概率传播界，不预称严格硬光锥。
- **T-L**：需指定擦除、热浴、侧信息与循环协议，不能从有效势单独推出任意写入的 kT ln2 代价。
- **T4**：持续有输入不保证每个结构被冲刷；还缺实际耦合、混合/周转条件。现有证明仅为部分必要条件。
- **T7/T8**：事件参与者可以多于两个，不自动推出配对 Hebb；隐藏状态不自动是慢模或有用资格。
- **目标与算法**：完整 Lives 见证、主动推理优势、自我形成，以及原 Python 核到 Lean 的算法精化均未完成。

这些是修复证明边界，不是用新机制拟合旧结果。
