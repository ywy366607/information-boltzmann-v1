# 快活动—慢结构交换：推导与预注册

2026-10-22，基线`14bcfa1`。沿主规划§4和核心方程E1的储能／有限池推进。目的：让已有结构子核得到有来源的功，并使结构反过来改变快响应；不是将旧脉冲模型或NLL重新命名成物理能量。

## 从哪里得到耦合

1. 保留固定正电容C_i、荷量q_i，V_i=q_i/C_i，E_q=Σq_i²/(2C_i)。这是文档已声明的被动物理极限。
2. 已装结构n_e若代表相同并联传输单元，则G_e=g0_e n_e。并联电流相加给出此式；“相同单元、固定C”是本轮的具体材料假设，不是所有大脑的定律。每个接触在快电荷层是互易二端元件；旧pre/post标签仍用于支持逆向运输，不将电阻解释成定向兴奋／抑制突触。
3. 有限驱动池P/D继续提供结构转化所需自由能。接入可逆换能事件：D→P同时从电容端向参考回路转移z单位荷量。正向从快场取功zV，反向可把池内能量送回快场。参考回路在零电位，转移的电荷明确记入边界回流账。
4. 当P增加dξ时，dq=−z dξ；组合自由能变化为

       dG/dξ = eP + ln(P/D) − zV

   所以亲和力A=ln(D/P)+zV−eP。选择有限尝试频率κ的两态热浴跃迁：

       j+ = κ D sigmoid(zV−eP)
       j− = κ P sigmoid(eP−zV)

   其对数比恰为A，净通量乘A非负。sigmoid在这里是成对跃迁率的一个具体热浴本构，不是行为门控；详细平衡只约束比值，不能唯一推出此函数或κ。未用目标梯度、奖励或“流量越大越长”的规则。
5. 结构继续经原有B+U+P⇌S+D转化。快场所储能量能影响P/D，P/D影响结构转化，n又影响G。若断开κ，边界功不再进入这个慢通路；若去掉边界驱动，内部可暂时相互充放，但没有无限免费供给。

能量单位沿用kBT=1；C、q、z、g0、κ均需将来识别。这是已声明材料的局部有效模型；不是把历史支持量标定为真实化学分子，也不是已校准的生成脑。

## 执行与收支

- 边界电流在一步内注入δq=hI，功W=Σ(q旧+q新)δq/(2C)，包括充电及抽取，不能以旧电压乘δq漏掉自能变化。
- 传输采用后向欧拉求解(C+hL_G)V新=q旧，矩阵自由的稀疏共轭梯度与对角预条件；实际荷量按成对边电流q新=q旧−hL_GV解更新，防止迭代残差累积成虚假边界电荷。收敛到精确解时热Q=E旧−E新分解为hΣG(ΔV新)²和非负数值耗散；记录有限求解精度下的分解余差，并逐次减半步长检查收敛。没有全局历史Jacobian，也不存BPTT图。
- 换能用中点电压V̄=(q旧−zx/2)/C，末态P+x、D−x，在可行区间[−P,D]内解

       x=hκ[(D−x)sigmoid(zV̄−eP)−(P+x)sigmoid(eP−zV̄)]。

  右边随x单调下降，故唯一；无需裁剪池。中点电压使电容能量交换精确为−zV̄x。混合自由能的隐式推进另有非负数值耗散。
- 最后执行原有有限支持／结构转化；固定C避免遗漏变电容的结构功。总账U+Q−W=U0，G0+W−G=累计不可逆损失。Q由声明状态能量差计算，是有效模型热账，不是显卡发热测量。
- 状态保存q、C、g0、所有有限池／结构、逐点输入／回流／传输电荷、功热熵账和时钟。无历史长度增长；CG工作量单独测量，不声称每步恒定计算。
