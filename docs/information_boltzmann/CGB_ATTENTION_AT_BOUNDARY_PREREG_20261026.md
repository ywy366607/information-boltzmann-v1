# 注意力在边界上：混合模型的最优配置由跳数与回忆负荷决定（预注册，2026-10-26，实验前写定）

## 1. 已有工作（查过，多为二手综述，未逐篇核对原文）

- 工业界的混合比例是经验值：Qwen3-Next、Kimi Linear 约 3:1（线性:全注意力），Ling 2.5 为 7:1；有报告称召回在每 3–6 个线性层配 1 个全注意力层时饱和。
- 位置被认为尚未研究清楚（Native Hybrid Attention, arXiv 2510.07019）；蒸馏研究发现，挑选保留全注意力的层优于固定比例的均匀插入（ICLR 2026）。
- 据二手报道，MiniMax 的混合模型在大规模多跳推理上明显吃亏，后改回全注意力；Ye 等（2026）在理论上指出，多步组合任务中，固定层数全注意力的混合网络不如全注意力网络。
- 未找到"最优配置是状态容量与跳数的函数"的闭式结论。

## 2. 推论

注意力 = 回看世界保存的记录 = 边界感知（P3）；内部 = 有限状态（P1a、G16、G17）。是否需要读取，由世界的两个条件决定，二者都是现象：

1. **回忆负荷**（读的宽度）：每个 token 需要精确取回的信息超过线性状态的容量（约为状态位数 ÷ 每项位数条关联）时，超出部分只能读记录。它决定每个注意力层的宽度（头数、KV），不决定层数。
2. **跳数 k**（读的次数）：第 i 跳的查询依赖第 i−1 跳的结果（先读，形成下一个查询，再读：主动感知）。每一跳一次读取，相邻读取之间至少隔 m 层内部处理。注意力层数 ≥ k，间距 ≥ m；第一个注意力层前至少有一层用于形成查询。

推出的配置：注意力层数 = k，按间距 m 放置，宽度由回忆负荷决定，其余为线性递推；**比例不是常数**，数据固定时模型越深，注意力层所占比例越低。进一步（未在本实验检验）：每个 token 的跳数不同时，读取应由预测误差触发，即主动推理。

## 3. 实验（锁存与优化器实验之后进行）

- 任务：k 跳指针追踪。上下文中有 N 个键值对，值也是键；查询给出一个起始键，要求输出连跳 k 次后的值。k ∈ {1, 2, 3}，N ∈ {16, 64}（回忆负荷）。
- 模型：L ∈ {6, 12} 层，宽度 64；线性层为 GDN（同 `run_latch_gdn.py`），注意力层为因果 softmax 注意力。配置包括：a ∈ {0, 1, 2, 3, 4} 个注意力层，以三种放置方式（均匀间隔、全部靠底层、全部靠顶层），再加均匀 3:1 对照。
- 每个配置 1 个种子（初步验证），训练步数相同，报告查询准确率。

## 4. 预言

| 编号 | 预言 |
|---|---|
| A1 | 在间距足够（均匀间隔）的条件下，准确率 ≥ 0.9 当且仅当 a ≥ k，两种深度 L 都如此 |
| A2 | a > k 时，相对 a = k 没有显著提升（< 0.03） |
| A3 | 相同 a 下，全部靠底层或全部靠顶层的放置，在 k ≥ 2 时不如均匀间隔（相差 > 0.1）：相邻读取之间需要用于形成查询的层 |
| A4 | 回忆负荷 N 从 16 增到 64 时，a = 0（纯线性）在 k = 1 上的准确率下降 > 0.2，而 a ≥ 1 时不下降：宽度条件由容量决定 |
| A5 | 当 k ≠ L/4 时，均匀 3:1 不是代价最低的成功配置 |
