# 二维食物世界与粗粒化耦合（设计与预注册，2026-10-26，实现前写定）

用户定下的方向：现在不做完整嵌套，用**粗粒化**；世界读不到生物的内部；嵌套与否，边界注入和耗散都是必需的；二维世界，食物随机刷新、向周围扩散（类似多人贪吃蛇）。

## 1. 为什么粗粒化是允许的（已证）

- T-N1 `blanket_of_contact`：世界只经生物的边界读它，生物只经边界读世界。所以世界里只需要表示生物的边界：位置、朝向、吃进与排出的量。
- T-N4 `cell_step`：一个装着 n 份、容量 V 的格子，对与它交换的单元就是势 μ = log(n / (V − n + 1)) 的储库，每次交换只改变势约 1/n。所以生物的感受器与进食口用本格的这个势，是联合介质的储库极限。
- T-N7 `stream_never_dry`：世界随机演化，每一拍都有不可预测的新信息，小盒子也是无限信息流。
- G26b `stay_starves`：吃掉的食物从世界扣除，停留处的长期摄入不超过流入它的量。

## 2. 世界（一个随机的、被驱动的介质）

- G × G 的环面格子，每格食物份数 n ∈ 0..V。
- **注入（世界的外边界）**：每拍以泊松数在随机格子投下一颗"食物豆"（k 份，不超过 V）。随机刷新。
- **扩散（世界内部，局部）**：每份食物每拍以概率 D 跳到四个邻格之一。
- **耗散**：每份食物每拍以概率 δ 消失（回到外部）。
- 废物与热：生物排出的份数离开世界（外部的汇）。

## 3. 生物与世界的耦合（只经边界，守恒）

生物内部是一张规则表（`tableCRN`，同前），边界页按下列方式接世界：

| 页 | 储库势 | 守恒 |
|---|---|---|
| F 感受器 | 本格食物势 μ = log(n/(V−n+1)) | 结合不消耗食物（只读势） |
| E 进食口/储备 | 本格食物势（不再是手设的 6） | 每一次进入 E 的份数从本格扣除；离开 E 的份数还回本格 |
| D 排废口 | 外部的汇（低势，常数） | 排出的份数离开世界 |
| M 马达 | — | 世界只读马达状态：游动态时每拍前进，翻滚态时随机换朝向 |

**储备、成本、死亡都在生物体内**：
- 储备 = E 页单元的含量。
- **身体会自行分解**：结构页 S 的单元以世界给定的物理速率（温度，不可选择）从完好态退化；修复要消耗储备。这一条登记为扩张公理（物质在有限温度下衰变），否则选择会把衰变速率调到 0，得到永生的石头。
- **死亡** = 结构全部退化（不可恢复）。死后身体的全部含量按位置还给世界，成为食物（贪吃蛇里蛇死变豆）。
- 游动由马达态消耗储备驱动（前进必须耗能，见体系图 7.1）。

## 4. 先检查世界（理想策略，不是个体）

在同一世界、同一成本下比较：
1. 盲游（一直直游）；
2. 绝对阈值（本格势高于 θ 就停下吃，θ 在训练世界上取最优）；
3. 比较器（势下降就翻滚换方向）；
4. 比较器 + 吃到饱再走。

**世界参数在检查前固定**（尺度论证，不为结果调）：G = 48，V = 30，每拍 0.5 颗豆、每颗 20 份，D = 0.1，δ = 0.002（食物平均寿命 500 拍），生物速度 0.5 格/拍，每拍吃本格的 30%。成本按"被动策略必须死"的原则定：**成本 = 盲游平均摄入的 1.5 倍**。

**预言（W1）**：比较器类策略的存活中位数高于盲游与最优阈值。若不成立，说明这个世界里比较不是必需的（条件定理 C-1 的反面），记录原因，不调世界去逼它。

## W1 结果（第一组参数）与修订（看到新结果前写定）

成本 = 0.8（盲游摄入 0.533 的 1.5 倍）；最优阈值 θ = −1，吃饱阈值 −1。留出 16 个世界存活 [最小 / 中位 / 均值 / 最大]，无一活满：盲游 137 / 199 / 215 / 322；阈值 137 / 211 / 220 / 322；比较器 98 / 125.5 / 136 / 219；吃饱再走 98 / 126 / 135 / 196。**W1 ✗**。

**原因（两条，都由已有定理给出）**
1. **违反了粗粒化的前提。** T-N4 的储库极限要求格子份数远大于每拍交换量。第一组参数每格平均约 2 份，生物每拍吃本格的 30%：自己吃一口造成的势变化 log 0.7 ≈ −0.36，远大于游半格看到的梯度（约 0.07）和世界的涨落。比较器看到的"变稀"几乎全是自己吃出来的，于是一直翻滚。真实细菌处在储库极限：所在的一小片水有上百万个分子，每秒只吃掉极小一部分。
2. **比较器不是最优的。** 单拍差分在噪声下很差；G10a/G13：应当与由历史滤出的预测比较（新息）。

**修订（只为满足前提，不为结果调）**
- 份数尺度乘 S = 50：V = 1500，每颗豆 1000 份；每拍吃本格的 2%（自己一口造成的势变化 ≈ −0.02，小于游动看到的梯度）。成本仍 = 盲游平均摄入的 1.5 倍。
- 比较器改为与滤出的预测比较：快均值（时间常数 2 拍）低于慢均值（时间常数 10 拍）超过 0.02 即翻滚。
- 预言 W1 不变。

## W1 结果（修订参数）与归因（2026-10-26）

成本 0.064（盲游 0.042 的 1.5 倍）；最优阈值 −2，吃饱阈值 −2。留出 16 个世界存活 [最小 / 中位 / 均值 / 最大]，无一活满：盲游 2165 / 2349.5 / 2360 / 2680；**阈值 2582 / 3126.5 / 3197 / 4186（最好）**；比较器 1827 / 2052 / 2085 / 2661（最差）；吃饱再走 1774 / 2457.5 / 2412 / 3278。**W1 ✗**。

**归因：边际值定理（Charnov 1976）。** 斑块觅食的最优规则是"此处摄入率高于环境平均就留下，低于就离开"。世界统计处处、时时相同时，环境平均是常数，**固定阈值就是最优**，不需要比较现在与过去。本世界正是如此（参数固定、豆子均匀随机刷新）。所以阈值策略获胜是正确的；先前选择长出的绝对阈值个体（ms s0）在这类世界里也是正确的解。

**比较（适应）的必要条件**：环境平均本身变化（时间上的丰歉、空间上的富贫区），且变化幅度超过 G25e 的可分辨带宽。这是 G10b、G25f 的同一结构，写成条件定理 C-1（待 Lean）：
- 平均不变 ⇒ 固定阈值最优；
- 两个不同平均 ⇒ 没有固定阈值在两者都最优，必须由记忆追踪当前平均（比较现在与过去）。

是否让世界变化，是对生态位的刻画（真实大肠杆菌的环境浓度跨数个数量级），由用户决定；不为逼出比较去调世界。

## C-1 已证（2026-10-26，`GenerationLeaveRule.lean`）与用户的决定

- `fixed_threshold_optimal`：环境平均 c 不变时，固定阈值 τ = c 处处最优（只读当下即可）。
- `no_fixed_leave_threshold`（C-1）：环境平均取两个不同值时，任何固定阈值都在其中一个世界的某个斑块上严格吃亏。阈值必须跟随当前平均，而平均不能直接感到，只能由近期历史估计（G10、G11、G13）：这就是比较现在与过去。与已有 G12 `exists_leave_threshold` 衔接（离开阈值就是 c）。

**用户的决定**：世界的丰歉**随机**变化（不排季节表）；展示页可交互，用户点哪里就在哪里放一颗食物豆，随后自然扩散。用户放的豆子属于世界外边界的注入，与随机刷新同等对待。世界与生物都要在浏览器中运行，JS 实现须与 Python、Lean 定义逐条对拍。

## W2：随机丰歉的世界（运行前写定，2026-10-26）

**世界**：同 W1 修订版（S = 50），另加
- 刷新率随机漂移：每拍刷新率 = 0.5 × e^{X_t}，X 是均值 0、标准差 1.15、相关时间 2000 拍的 Ornstein–Uhlenbeck 过程（±2 个标准差约跨两个数量级；一生 10000 拍内经历约 5 次丰歉起伏）；
- 豆子大小随机：对数正态，平均 20 单位，对数标准差 0.5。

**成本（原则先于结果）**：成本 = 盲游在训练世界（种子 1000–1015）上的平均摄入。即盲目的生命至多勉强持平，感官必须为自己付账。

**策略**：盲游；固定阈值（θ 在训练世界取最优）；**自适应阈值**（边际值规则 + 记忆）：本格的预期摄入率 ≥ 自己近期摄入率的慢均值（时间常数 300 拍）就留下吃，否则离开；游动时用比较器选方向（快均值 2 拍对慢均值 10 拍）。

**预言 W2（来自 C-1）**：留出 16 个世界上，自适应阈值的存活中位数高于最优固定阈值，两者都高于盲游。若固定阈值不输，先查丰歉幅度是否落在其可分辨带宽内（G25e），再查自适应估计是否被自己的进食偏置。

### W2 结果（第一次）与修订（重跑前写定）

成本 0.0584（盲游摄入）。最优固定阈值 θ = 0（网格边缘，几乎不停 ≈ 盲游）。留出存活 [最小 / 中位 / 均值 / 最大]：盲游 1061 / 5266 / 5823 / 10000（7 个活满）；阈值 1061 / 5119 / 5548 / 10000（4）；自适应 1002 / 1991.5 / 4136 / 10000（2）。**W2 ✗**。

**原因**：理想策略漏掉了本预注册 §3 已写明的前提——**游动由储备驱动**（体系图 7.1）。检查中游动免费，于是在 48 × 48 的环面上一直游最划算（一生扫世界约两遍，食物寿命内扫过的格子又长回来）。边际值规则本来就含路上的成本。

**修订（补前提，不为结果调）**
- 成本分两部分：基础代谢 b（每拍）与游动 b（游动的每拍再付一份，"动一倍"）。b = 盲游无成本时平均摄入的一半，使盲游（一直游，付 2b）恰好持平——原则同前：盲目的生命至多持平。
- 阈值网格向上扩到 θ ∈ {−3, …, 1.0}，避免最优落在边缘。
- 预言 W2 不变。

## 生物与世界的耦合：实现中发现的约束（2026-10-26）

`information_boltzmann/core/cgb_organism2d.py`。
- **受体结合也从本格取食物**（解离时还回）。否则含量可经受体免费进入体内再转给储备，违反守恒。
- **结构衰变是规则表中的一条可逆规则** S1 + D0 ⇌ S0 + D1，速率与能量是物理常数（不交给选择）；反向（由废物自发修复）被能量抑制。
- **食物带化学能**：本格食物的势 = μ₀ + log(n/(V−n+1))，μ₀ = 8 是世界的物理常数。没有它，生命在热力学上无法运转：结构是高能态（φ_S1 = 4），修复要求燃料能量高于结构，进食要求食物的势高于燃料；单靠浓度项（约 −2.6）付不起。**边界注入的必须是自由能，不只是物质**；食物势与汇势（−6）之差就是驱动生命的势差。旧接口中手设的 μ_E = 6 由此有了来源：它是食物的性质，不是生物端口的参数。
- 冒烟测试：生物能进食、修复、死亡，死后身体还原为本格食物。

## 生物的生成（O1–O4，运行前写定）

**结构由定理定，数值由选择定**（前提写进结构）：
- 受体 F（快，读现在）；慢页 Y 与已结合的受体交换（Y0 + F1 ⇌ Y1 + F0），记住近期平均（G13、C-1 的"平均"）；**时间尺度前提**：Y 的速率前因子至少比受体结合小 20 倍（结构约束，不交给选择）。
- 马达：过去高则开（Y1 + M0 → Y0 + M1），现在高则停（F1 + M1 → F0 + M0）——比较器见证的反号方式；另有界面规则（燃料冲程、释放）。
- 选择：种群 32、每代 8 个新的随机丰歉世界、验证集选出；只接受通过生命层的数值。

| 编号 | 预言（留出 16 个世界） |
|---|---|
| O1 | 存活中位数高于致盲对照（受体读固定势）与从不游动对照 |
| O2 | 适应：μ 阶跃后游动率回到阶跃前水平的一半以内（在 μ 的两个不同水平上） |

### W2 公平性检查：预言被推翻（2026-10-26）

最优固定阈值在第一次网格中落在下边缘（−3），向下扩展（−6 … −3）后训练最优为 θ = −4.5（训练均值 8880）。留出 16 个世界：**固定阈值 2385 / 10000 / 8232 / 10000，活满 11 个**，优于自适应（2122 / 8886 / 7235 / 10000，活满 8）。**W2 ✗**。

**归因（C-1 的条件不成立）**：θ = −4.5 即"本格还剩一点就留下，几乎吃空才走"。游动与基础代谢同价，扩散又把周围的食物送到脚下，所以"坐着吃"在丰年和歉年都最优；两种年景下最优离开点都接近"吃空"，C-1 所需的离开价值之差消失。理论无误，是这个世界不给比较存在的理由。这是第三个"最简单的活法就够"的世界。

**不再单方面改世界**。使比较必需的条件（C-1）：食物不会自己送上门（扩散慢、衰减快），或路费相对便宜（游动耗能低于基础代谢；真实细菌的运动只占其能量预算的一小部分）。由用户选择生态位。
