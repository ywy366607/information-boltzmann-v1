# The brain's generative principle: copy the generator, not the fly product

> 本文的提案部分已被 `CONSTRUCTAL_GENERATIVE_BRAIN_FRAMEWORK_20261018.md` 取代，这里只保留作历史。

Date: 2026-10-18. Status: route and predictions. E1 is in progress.

## Starting point

- **Goal.** The infinite-stream life-form needs a dynamical computing centre. The fly brain is the product of evolution for
  the fly's niche: genetically specified to a high degree, effectively pre-trained weights. Copying it system by system
  is reconstructing a product. What we want is the generator behind it, so we can grow a brain suited to our niche (a
  continuous language and interaction stream).
- **The information account (rough).**
  - Fly: genome about 1.4×10⁸ bp, about 35 MB. The connectome has 1.65×10⁵ neurons and 2.5×10⁷ edges; recording just
    "who connects to whom" takes on the order of 100 MB. So the wiring must be compressed by at least an order of magnitude.
  - Human: about 10¹⁴ synapses against a genome of about 6×10⁹ bits, a ratio of about 10⁶. Most of it can only be learned.
- **The genome is a program, not a blueprint.**
  - Identity = spatial (about 100 neuroblasts per side) × temporal (transcription-factor cascade) × Notch split
    (hemilineage A/B).
  - Wiring = surface-molecule matching + guidance gradients + physical encounter.
  - Many places specify only statistics (KC←PN is random).
  - Physics and self-organisation do most of the work; activity does the final pruning.
- **Where the genes came from.**
  - Duplication and divergence, plus co-option of mechanisms that predate neurons: synaptic scaffolds exist in sponges,
    voltage-gated channels in bacteria, and transmitters started as metabolites.
  - Evolution searches the generator's parameters, not individual synapses. Only compressible, modular, copyable schemes
    can be found, so a short genome is a consequence of evolvability.

## Laws shared by neural and non-neural sustainable learners

| Law | Examples |
|---|---|
| L1 Use it or lose it: local flux strengthens a channel, idleness decays it, O(1) | axon fasciculation, Hebbian learning, Physarum tubes, immune memory |
| L2 Integral-feedback adaptation: sensitive only to change, a built-in novelty detector | receptor desensitisation, refractoriness, perfect adaptation in bacterial chemotaxis |
| L3 Expansion → sparse → competition: arbitrary associations learnable with local rules | Kenyon cells, cerebellar granule cells, dentate gyrus, immune repertoire |
| L4 Local eligibility × global broadcast: credit across time, O(1), no BPTT | dopamine at KC→MBON, climbing fibres, hormones, bacterial methylation memory |
| L5 Separation of time scales | state / weights / structure (growth, pruning) / genome |
| L6 Variation and selection at many levels | synapse turnover, clonal selection, evolution |
| L7 Identity codes set the rules' parameters: the same chemical means different things to cells with different receptors | the basis of region differentiation and transmitter modulation |

In this language, the earlier 3D medium (Gen1–3: homogeneous, one rule) had only L1. Gen4's "gravitating mass must be
slow installed capacity" is L5. What was missing is L7.

## The minimal generative kernel (proposal)

```
cell       = fast state + slow state + identity code c (low-dimensional, generated by the lineage tree: binary split
             at division + temporal cascade)
physiology = f_θ(c): time constants, refractoriness, receptor set, what it releases, sign of its plasticity rule
wiring     = growth + matching: P(i→j) = σ(c_iᵀ A c_j) × encounter(distance, whether along an existing bundle)
chemistry  = releasing cells determined by c; diffusion + receptors
learning   = Δw = e_ij × local chemistry m(c_j); homeostasis adjusts only cell physiology
outer loop = selection / gradient only on (θ, A, lineage parameters), about 10⁴ numbers;
             judged by survival, prediction and interaction in the infinite stream
```

## Experiments and falsifiable predictions

**E1: genomic bottleneck** (`scripts/ib/generative/e1_genomic_bottleneck.py`)
- Model: a k-dimensional code per type, W_ab ~ Poisson(n_a n_b exp(o_a + i_b + c_aᵀ A c_b)).
- Score: share of Poisson deviance explained beyond the degree-only null, on held-out type pairs.
- Prediction 1: k ≈ 32 explains > 70% on held-out pairs.
- Prediction 2: with hemilineage × superclass as a fixed prior code, the k needed for the same accuracy halves.
- Falsification: if the k needed approaches the number of types, the wiring is incompressible. Then the kernel becomes
  "lineage tree first, matching second", plus exact-matching genes.

**E2: resample the connectome from the generator in the existing fly model, then run the living gates**
- Predictions:
  - resampling the mushroom body is nearly lossless;
  - resampling the CX loses the persistent state;
  - whole-brain prediction contribution keeps ≥ 80%.
- Falsification: if the whole brain collapses, find which classes of connection must be specified edge by edge, and add
  them to the kernel as exact-matching genes.

**E3: grow from scratch**
- Setup: a minimal genome develops in a 3D medium, the inner loop learns for life in the infinite stream, and the outer
  loop selects.
- Predictions:
  - a world with delayed consequences spontaneously yields a small class of broadcast cells; remove the delayed
    consequences and the class does not appear;
  - high-dimensional input yields an expansion-sparse layer; low-dimensional input does not.
