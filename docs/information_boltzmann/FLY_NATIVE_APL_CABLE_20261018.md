# APL：从整细胞单值反馈到真实形态上的局部电位与释放

本轮连续来源是32968的MB末梢候选，不是重新出生。主线32384保持暂停。
正式数值与当前存档因果证据见 `results/published/fly_native_apl_cable_20261018.json`。

## 接入什么

两侧APL使用MaleCNS v1.0原始SWC：共88,905个节点、88,900段电缆。
每个提供的节点保留一组局部膜电位、兴奋/抑制电导，以及四拍延迟释放包；
不按脑区、分支或细胞群合并物理状态。原先两个APL槽位仅保存面积加权的
观测坐标，实际突触递送读取局部释放，不再以该均值广播。

| 路径 | 实际接法 |
|---|---|
| 其他细胞/KC→APL | 实际突触的APL侧坐标映射到原形态节点，保留原连边权重、符号及延迟 |
| APL内部 | 按原分支长度、两端半径、膜面积构成有限体积轴向电流；两侧各有可学习的正传导参数 |
| APL→其他细胞/KC树突 | 实际释放位置的局部包沿原快抑制连边到达，原点模型的重复输出被移除 |
| APL→KC轴突 | 原有已测轴突接触总量分配到真实APL释放位置，再进入已接的KC末梢抑制 |
| APL→APL | 使用源和靶各自的局部位置；不绕回整细胞均值 |
| 世界/学习器 | 沿用真实感官时钟、脑状态、已有可塑性、预测/选词政策和优化器；不增加发言率或奖励先验 |

实际输入接触在本模型图内的数量为234,026个；APL输出接触在图内209,913个。
映射后的相同节点/连边只合并数值求和，不把不同节点的状态合并。
位置来自8nm坐标系，最近形态节点投影距离中位0.765微米、99%为1.783微米，
最大2.856微米；这是当前提供形态和点位的空间分辨率，不是精确到每个膜分子。

原形态各有3和2个根；大分量分别43,724和45,160节点，其他分量分别9、4及8节点。
这些小片段保留独立，不凭空间接近补造轴向连线。

## 动力学与数值方法

局部COBA膜积分继续使用原生细胞类型的时间常数、兴奋/抑制反转电位、
电导增益及分级释放函数。随后解同一真实形态上的被动轴向电流。
膜容量相对值由相邻段表面积确定，轴向几何量为 `pi*r_i*r_j/length`。
未知材料比例由 `apl_log_axial` 学习，初值为一个模型单位；不固定50微米
空间常数，不固定生物毫秒，也没有人为传播距离上限。

每拍求解 `(C + L_axial) v_new = C v_local`。这是该形态分辨率上的数值
积分，不是声称恢复了所有离子通道。稀疏直接求解与伴随梯度在CPU的FP64
中执行，残差必须通过1e-9相对尺度检查，再回到原物理状态精度。
局部COBA与轴向过程按拍分步积分；没有使用静态距离权重代替持续电位。
电位均一时保持均一；轴向交换守恒面积加权电荷；未连接的分量不交换电流。

输入/输出求和使用固定顺序的分段归约，避免局部突触原子累加的随机次序
被误当成空间机制的因果作用。接线表一次解压并载入，稀疏分解按材料参数
缓存；反传使用对应的同一算子。当前CPU直接求解不支持CUDA Graph捕获，
仍支持逐拍重算和实际BPTT，不能通过缩短世界时间来冒充提速。

## 连续性和统一验收

旧存档没有过去的局部空间模式。因此第一次接入时，将每侧原膜电位、
两种电导和四个在途包分别均匀展开到其节点，明确标为状态展开；不编造
旧经历中的空间花纹，也不清空已学权重、记忆、信用、优化器或世界队列。

零暴露迁移独立比较旧模型、物理字段、优化器、世界、RNG和游标。
真实整脑初始化检查同时核对兴奋输入总量、抑制输入总量、快输出总量、
轴突输出总量，避免几何展开顺便改变信号幅度。新经历之后的局部状态
与完整学习器共同保存，错误的非空状态形状或几何身份一律拒绝恢复。

统一因果矩阵增加两支：APL实际释放关闭、轴向传导关闭。仍使用当前存档、
真实输入间隔、相同感觉采样、sham和恢复控制，分别记录局部状态、
MBON/DAN、预测和选词影响。释放存在、急性作用与长期学习收益分别验收。

## 仍缺的层次

本轮完成32个真实保留输入、8次更新、483实际拍，完整保存至33000。
15支/63拍同状态对照及完整恢复通过，209项相关检查通过。更新前NLL
为4.44436，同批固定词频6.20404；全部为妈妈主动输入，没有新对话轮次。
两个APL关断支在4词样本上的CE更低，接入作用不等于学习收益。

资源仍需处理：首轮最后保存失败，完整32996未损坏；重试从该点完成最后4词并
保存，模型/学习器/世界/RNG重载一致。重试分段2峰值3847MiB超过3800保护线，
保存后按规则退出，主线和候选都不继续长训。全部持久张量约1966MiB，其中
模型583MiB、学习器1384MiB；APL四项局部持久状态仅2.374MiB，但反传中间量
另计。保存失败处理和等方程的有序冻结对照不改变已保存的脑状态。

- **KC仍是一颗细胞一个轴突输出。** APL已经按位置释放，但作用在KC的
  不同bouton上后如何局部传播、分别改变各下游释放，仍需要KC自己的形态、
  受体位置和末梢状态；不能拿本轮APL接线冒充KC空间机制已完成。
- APL专用受体、主动离子通道、更多亚细胞效应器尚未完整识别。这里还原的是
  真实形态约束的局部被动电位/分级释放，不是整细胞全部生物化学。
- 新轴向材料参数参与窗内BPTT及现有政策导数；其精确跨窗前向敏感度未实现。
- 选择性熟悉化、巩固、自然选词后果的持续收益、完整探索和自我，需要后续
  真实交流与持续学习证据。
