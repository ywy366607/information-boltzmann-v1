## 1. 消去的只是执行中的条件随机数

父域容量C、荷量Q；新域与父域同相、等容量。付款后的资源组成记为a=(B−2,F,H,P−1,D+1)，新域得到整数向量z、父域a−z。既有出生提议为：局部球壳均匀位置、固定总荷的条件高斯，以及各池独立Binomial(a,1/2)。物理状态里仍然保留新域的全部荷量/资源；只解析积分拒绝决策对这些提议的依赖，不能删掉它们或把两个域平均合并。

    ΔU_q = −Q²/(4C) + (q_new−Q/2)²/C
    log f_q = log(q_ref) − log(πC)/2 − (q_new−Q/2)²/C

因此−ΔU_q−log f_q中，新荷量的二次项精确抵消。对于每一种资源：

    ΔG_mix = log[(a−z)! z! / n_old!]
    log f_partition = log[a!/(z! (a−z)!)] − a log 2

两者之和同样不含z。抵消包含完整出生提议、原自由能与实际储能，没有用近似梯度或经验阈值。

## 2. 单一物理正反比

令d为父域旧度数，k为材料端容量，e=k−d为可用端，l为新桥长度，l0与κ为已有弹性本构，V_shell=4π(R³−r_core³)/3。去掉软件数组log(N!)与均匀插入位置的互相抵消后：

    L(l) = log R_birth
         = A − κ(l−l0)²/2

    A = −E_domain − E_bridge + E_P + ε_cohesion d − F_identity
        + Q²/(4C) + log(πC)/2 − log q_ref
        + log[e k V_shell/V_ref]
        + log[B(B−1)P/(D+1)]
        + (B+F+H+P+D−2) log 2

适用B≥2、P≥1、e>0。F_identity为原有向身份的完整自由能，α能量/熵分解在速率比中合并；改变α仍改变实际热账，不消去它。R、r_core、κ、l0、端容量、P能、域/桥形成能和参考测度全部继承已声明本构。

正向有界接受率min(1,exp L)，对应逆向min(1,exp(−L))；成对尝试率仍用原assembly_rate*(bulk_attempt+surface_attempt*d)。几何越界/重叠仍拒绝；此公式不把不相遇的位置连接起来。
