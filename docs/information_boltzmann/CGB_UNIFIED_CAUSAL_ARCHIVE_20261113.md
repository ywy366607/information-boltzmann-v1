# 统一磁盘因果档案：经历、原话与关系共用持存后端

## 已落地的结构

当前3510同体新增显式SSD档案选项：磁盘最多65536条经历、65536个关系；现有4096经历槽与64关系槽成为热工作集。没有增大神经网络，没有复制每条关系的权重、Adam或全层S。

统一因果档案保存：

- 经历记录：当前已有条件、行动、实际后果、信用统计、版本和结算来源；每条4012字节，包含原话附件和两列结算版本。
- 原话附件：直接进入同一经历记录，不另占身份或容量池。旧`model.retrieval`和`memory.words`保留为访问口。
- 关系目录：关系身份/代际/版本、条件及对同一经历记录的证据引用。共享编码器和原机制现场构造可执行关系，磁盘不保存另一份私有预测器。

字节n-gram仍是另一类语言统计，使用原有磁盘映射。启用因果档案后，续接入口在未指定`--table-storage`时默认将快表映射到输出目录。每字节递推的S/P、当前计算与有限热工作集留CUDA。

## 一次共同转移

1. **水→木，事件边界**：持存上一边界的真实经历和关系。用实际当前状态查询磁盘关系，条件在当前编码器下重新编码；分块256个条件，不把全库搬进显存。
2. **关系与证据共同换入**：选中的旧关系最多带8条版本化真实证据，正文、原话、取用统计和结算版本一起加载。换入旧经历不增加新经历次数、不推进世界或记忆时钟、不清空S/P。
3. **木→火**：原`RelationBank.bind`、原`mechanism/imagine`和原草稿/选择继续执行；真实读到的是换回的经历。没有新增选问句奖励或私有词表解码器。
4. **土→金**：原实际语言学习和真实后果结算继续；编码器仍在实际重激活图上获得梯度。
5. **金→水**：原关系U修订证据，连同新经历写回同一档案。热槽复用或合并前先存旧版本；物理换出不等于推翻旧因果。不同版本有不同经历ID，关系引用受SQLite外键约束。

磁盘目录容量使旧关系可以超出64个身份继续存在并被再次查到；不是把备份存在文件里却不再读。

## 收据、安全边界与恢复

- 正在等待TD、下一真实边界和保留问题结算的槽/关系受保护；没有足够可用热槽时放弃该次换入，继续原路径。
- 有尚未结算的可微读参与时禁止换页。换入经历使用新的热读版本，旧槽的参与收据不能误付给新占用者。
- 关系证据以磁盘经历ID引用，未被语义修订的关系不因热槽换出而删除证据。
- 历史问题的嵌套热槽收据仍由原读口逐项检查stamp；父记录未在正确位置时拒绝那项父引用，不把物理槽号冒充持久身份，也不因此删除锚点自身的真实问题/后果。本次长期可唤回的是关系的因果证据，尚未将所有嵌套问题收据改造成可独立分页的递归持久图。
- 每个身体检查点绑定一份不可变、带SHA256的SQLite快照。恢复到新私有工作文件，研究分支互不写入对方档案。
- 保存先生成档案快照、再原子替换身体检查点；保存失败恢复旧manifest并保留旧快照。成功后只清理本输出目录已被最新检查点替代的滚动档案。
- 旧热区快照/恢复接口在档案开启时明确拒绝，原旧loader也拒绝静默丢弃外部档案。使用实际mother continuation入口恢复。

## 有限资源

磁盘逻辑预算65536经历、65536关系；主SQLite文件上限512MiB。关系可共享经历，两个数量不是每关系都额外分配8个独占经历。释放不再使用且不被引用的冷记录；预算满且所有候选都受保护时显式失败，不隐藏无限追加。

SQLite页缓存目标2MiB；操作系统文件缓存、只读GPU条件分块、原热区及保存时CPU缓冲仍会占内存。恢复默认使用磁盘n-gram工作区，不称零RAM。

当前关系搜索是**决策边界精确分块扫描**，成本随配置的冷目录容量增长；每字节语言预测仍查有限热区。未宣称ANN、任意规模O(1)或无I/O代价。主库、事务日志及滚动快照同时存在时的磁盘峰值高于主库上限，需留余量。

## 使用与代码

新档案显式迁移参数：`--causal-storage <工作目录>`，容量可在首次创建时用`--causal-episode-capacity`、`--causal-relation-capacity`指定。已有档案恢复自动继承预算，不静默改变。已有迁移检查点恢复不再需要额外开关；通过原`python -m scripts.ib_local.run_mother_continuation --checkpoint ... --output <新目录> --cycles ...`续行。妈妈harness仍为原桥服务，不改harness实现。

- `causal_archive.py`：统一后端、版本引用、候选搜索、换入与不可变快照。
- `latent_navigation_v3.py`：覆写/合并旧槽前捕获。
- `navigation_causal_program.py`：原循环边界接档案准备和真实写回。
- `mother_checkpoint.py`、`run_mother_continuation.py`：完整存储绑定与续接。
- `audit_causal_archive_real.py`、`migrate_causal_archive_checkpoint.py`：实体验证及不改变生命史的显式迁移。

与原必要条件的连接：`GenerationContactEligibility`要求信用使用实际局部参与与响应；本改动保留原重激活图和版本化读参与，不重新定义资格。`GenerationSelfProduction.delayed_readout_capacity_with_retrieval`要求外部历史真正交付可读区别；本次补的是冷经历到原实际机制的取回和交付。Lean原前提没有被当成本次学习收益，也未另做脱离身体的证明。
