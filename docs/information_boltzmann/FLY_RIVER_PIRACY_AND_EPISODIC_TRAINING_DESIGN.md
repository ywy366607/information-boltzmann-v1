## 一、 第一部分：河流袭夺与水力侵蚀结构可塑性 (River Piracy Plasticity)

### 1.1 物理与地质学原理
在物理学与地貌学中，流动系统的结构演化遵循严格的自组织法则：
1. **下切侵蚀正反馈（Incision Positive Feedback）**：
   流体对床面的剪切应力驱动冲刷，冲刷越深则水力半径越大、流阻越低，进而吸引更多流量集中，形成自催化侵蚀循环。
2. **河流袭夺（Stream Piracy / River Capture）**：
   当一条新侵蚀河道切穿分水岭并与邻近河流相交时，由于比降与流速优势，它将截断原河流的上游来水（“截胡”）。失去水流补给的下游河段流量骤降，发生泥沙淤积、逐渐萎缩闭合，在地质上演化为“断头河（Beheaded Stream）”。
3. **结构定律（Constructal Law）与黏菌流动模型（Physarum Model）**：
   黏菌管道导电率微分方程表明：
   $$\frac{d g_{ij}}{dt} = f(|Q_{ij}|) - \gamma g_{ij}$$
   流量 $Q_{ij}$ 大的通道迅速扩张，流量低于临界值的通道自发耗散退化。

### 1.2 果蝇连接组工程化方案

在果蝇 ~1.38 万神经元和 140 万固有突触的基础上，突破固定图拓扑限制：

```text
[突触前神经元 i] --(总输出电导预算上限 C_i)--> 
       ├── 原有突触通路 (流量 Q_old 下降) --------> 自然淤塞、断流退化 (-gamma * g_old)
       └── 潜伏探测微通道 (预测增益正反馈冲刷) ---> 流量激增、河道下切 (+f(|Q_new|))
```

1. **暗流渗透（潜伏边候选空间）**：
   在 3D 几何空间中，允许空间邻近（微米级距离内）但解剖学未连接的神经元对之间存在初态微弱的潜伏电导 $g_{\text{candidate}} \to 0$。
2. **总水头约束与河流袭夺（Competition via Presynaptic Budget）**：
   对每个突触前神经元施加总外流电导（代谢与膜面积）约束：
   $$\sum_{j \in \text{Post}(i)} g_{ij}(t) \le C_i$$
   当某条潜伏通道在下游语言预测任务中展现出强力的自由能下降/梯度增益时，流量集中，反向权重提升；由于总预算 $C_i$ 守恒，这必然抢夺原本流向无用旧突触的电导分配。
3. **自然淤塞与断流（Spontaneous Pruning）**：
   被“截胡”的旧通路因流量低于耗散阈值，按 $-\gamma g_{ij}$ 缓慢沉积闭合，实现完全无人工干预的生理学自发剪枝。
4. **基岩与泥沙双层动力学（抗灾难性遗忘）**：
   - 核心语法与高阶常识通道经过大量曝光后，塑性率降低，固化为高刚性“基岩大峡谷”；
   - 瞬时特定语境通道保持高塑性“泥沙细流”，随任务流变快速开辟与淤塞。

## 二、 第二部分：生物终身学习的两阶段演化协议 (Two-Stage Episodic Protocol)

### 2.1 理论前提：离线训练 vs 生物在线认知
- **离线训练的虚妄性**：离线深度学习依赖海量数据在多 Epoch 中的随机打乱与无限次重复采样（i.i.d. 假设），这与任何生物个体终身学习的现实完全相悖。
- **生物个体的真实约束**：生物体一生经历的数据流是无界的（Infinite Stream），但在任意有限瞬间（如 10 秒钟、128 个事件），它接收的经验是极度局限的局部片段。
- **生物学习的核心诉求**：**必须在当前局部窗口内最大程度地过拟合/消化当前语境（形成工作记忆与即时表征），同时绝不损害其通用表征与未来前瞻预测能力。**

### 2.2 协议设计：情境吸收平台期 $\to$ 前瞻生成预测

设观测总窗口为 $W = 128$（例如前 64 词为 Context/Prompt，后 64 词为 Continuation/Generation）：

```text
时间流向 --->
┌───────────────────────────────────────┬───────────────────────────────────────┐
│     前半段：情境吸收阶段 (Tokens 0..63) │     后半段：前瞻生成阶段 (Tokens 64..127)│
├───────────────────────────────────────┼───────────────────────────────────────┤
│ • 局部多次迭代 / Attractor 放电平衡   │ • 保持前半段已收敛的物理工作记忆状态    │
│ • 最大化过拟合当前局部情境至平台期     │ • 以吸收后的情境为条件，进行单向生成预测│
│ • 作用于快状态 (膜电位/STP/快权重)    │ • 联合反传更新慢结构与下游生成损失     │
└───────────────────────────────────────┴───────────────────────────────────────┘
```

#### 阶段 A：前半段局部过拟合至平台期（Context Assimilation Phase）
1. 输入前 64 个 Token（提示词/当前环境情境）。
2. 个体在此 64 词的局部状态上进行生理性“回味与消化”（Local Dwell / Consolidation）：
   - 不改变全局慢权重的大骨架，而是驱动**快动力学（膜电位环、STP 短时易化、ALIF 阈值以及快可塑性）**进行快速状态迭代；
   - 持续吸收直至该 64 词上的先测后学损失进入收敛平台期（Local Saturation Plateau）。
3. 这一过程模拟了生物大脑的海马体快速情境编码（Hippocampal Rapid Encoding）与工作记忆形成：在面对全新对话或陌生环境时，生物体首先全力理解并锁定眼前的语境。

#### 阶段 B：后半段前瞻生成与预测（Forward Generation Phase）
1. 锁定（或平滑延续）前半段已经过拟合建立的内部神经场稳态。
2. 将该稳态作为物理提示（Conditioned Physical State），推进后 64 个 Token 的因果自回归预测与生成（类似于对话生成任务）。
3. 此时的预测不仅依赖长期泛化权重，更深度绑定了前半段刚刚消化的高信噪比工作记忆。

### 2.3 防御过拟合污染全局的物理隔离机制
为了防止“前半段的过度过拟合”破坏整个生命体的长期通用认知，必须采用快慢系统隔离：
1. **快慢参数解耦（Complementary Learning Systems）**：
   - 局部情境过拟合只允许耗散在**快速状态与短时突触可塑性（STP）**上；
   - 长期突触慢权重（Slow Weights）仅在生成阶段接收具备前瞻预测价值的梯度，并受热力学弹性耗散（Elastic Regularization / Bath Sink）约束。
2. **因果单向传递**：
   情境吸收是前瞻生成的因果条件，前瞻生成的误差反过来作为反馈信号，校准“什么样的主动吸收策略对未来预测最有效”（Meta-Learning 精神）。
