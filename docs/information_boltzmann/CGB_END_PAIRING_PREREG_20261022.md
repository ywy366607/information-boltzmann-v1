# 有限连接端与可区分导通域：实施前记录

基线 `48772fe`。接续空间沉积结果与连接状态必要性推导，复用 TraceExchange 的传输、写入、捕获和有限驱动。本轮先交付端的有限组成、独立导通域与接合事件；不把端口网格叫完整神经突形态生成。

## 状态、物料与自由能

一个端口是具有独立电荷/电容的局部材料域；坐标相同不意味着电势相同。候选接触没有导通，只有实际安装的桥才导通。每个端口有有限的连接端总数 L_i，空闲端 e_i=L_i−Σ_incident n_a。端总数是材料构成，不是要生成多少分支的目标。新结构仍消耗有限底物 B 和驱动 P；支持 C 占据的结构不能直接拆解，沿用已声明的反应图。

    B_b + P_b + U_ab + E_a + E_b ⇌ S_ab + D_b
    G = G_spatial + Σ_i [e_i log(e_i) − e_i]
    j+ = k(n_neighbor) B_b P_b (K_ab−n_ab) e_a e_b
    j− = k(n_neighbor) exp(e_n−J n_neighbor−e_P) (n_ab−C_ab) D_b

因此 log(j+/j−)=−∂G/∂ξ；痕迹、支持互易结合和空槽项沿用现有共同自由能。空闲端不增加另一份结合能，结构能只计一次。j+、j−共用尝试率；端不足限制可达反应量，不另设赢家或树形规则。伸长、转向、分叉若出现，应来自允许接合几何、可用端和材料，不按角度/度数事后添加事件。

执行采用端点互不重叠的反应组及每边有界隐式反应量。一个事件同时扣双方端、底物、驱动，反向归还；不以独立边更新后裁剪解决竞争。允许同位置的不同端口间接触；已有空间输运只跨正距离网格邻居，零距离接触不被当成无限扩散。该离散是有限局部端口材料的候选实现，端数、网格和候选相遇是显式材料/几何假设，尚非从身份长出连续形态。

## 先写明检验

1. 对整个 G 做独立反应方向差分，正反比与其一致；双端组成、B、P/D、支持、电荷、外界功、热量闭合。
2. 两条交叉通道共享坐标但各有电荷，未接合时无横向电流；接合后在同一边界条件下出现横向电流，连续接近真正接合的响应。不能把坐标相同直接合并电势。
3. 共享端竞争在大时间步仍不超额；独立连续 ODE 的时间细化收敛。完整状态恢复后相同输入产生逐位相同未来。
4. 在多条正交材料通道与真实书架字节端口驱动上，比较允许/禁止新接合、痕迹互易捕获开/关、有限端供给变化。报告实际新桥、空端、来源功、写入、支持与结构。关闭接合的臂保持其他活动过程。所有阈值只用于报告，不控制反应。

如果这些通过，只能说明保留连接状态后，接触形成的物理后果和痕迹通路共同工作。真实空间伸长、转向、分叉、多谱系出生和 Claude 有向身份规则在新接触上的调用仍需继续；不能用本轮端口连通检验替代那些交付。
