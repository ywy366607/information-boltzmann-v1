# 语言无限流生命体：自上而下的推导链（2026-10-27）

目标：从 CGB 公理和已证定理出发，推出一个在语言无限字节流里能活下去的生命体实例，不靠训练试错。只有一件事要靠测量：真实语言满足哪些前提（例如每字节的熵率）。实验只用于测量这些前提，以及核对代码是否忠实地实现了推导。

## 世界合同（登记，不是公理）

这一条和大肠杆菌的雨水生态位一样，是声明出来的世界，不是推出来的：

- 每个字节到来时，世界按"公平赔率"付账：身体在这个字节上留了多少容量，就得到 |B| 倍的物料。
- 收成再投回身体，变成新的容量（再投资）。

再投资使增长成为乘法式的。如果收成只是加法式累积，最优策略会变成全押在最可能的字节上（`additive_payoff_mode`）。所以"按概率分配容量"来自再投资这一条，不是光有预测就能推出的。生命把物料变成更多身体、更多容量，看起来天然是乘法式的；但这还需要在嵌套框架里推导出来，目前仍是登记项。

## T1：预测就是新陈代谢（已证，`CGBAxioms/GenerationPredictiveHarvest.lean`）

设世界的字节分布为 p，身体把容量按比例 c 分配，每次到来的期望对数增长为 `growth p c = Σ p_b log(|B| c_b)`。

| 定理 | 内容 |
|---|---|
| `growth_eq_log_card_sub_crossEntropy` | 增长率 = log\|B\| − 身体在字流上的交叉熵。压缩率就是代谢率，不需要观察方把分数兑换成补给。 |
| `gibbs_term`、`gibbs_inequality` | Gibbs 不等式：Σ p log c ≤ Σ p log p。 |
| `growth_le` | 任何分配的增长率都不超过 log\|B\| − H(p)（Kelly 上界）。 |
| `growth_at_law` | 按世界分布分配容量（c = p）时达到上界。 |
| `uniform_growth_zero` | 什么都不知道的身体（均匀分配）增长为 0。 |
| `no_allocation_persists` | 每次到来的维护费为 m 时，若 H(p) > log\|B\| − m，没有任何身体能活。 |
| `persists_of_crossEntropy` | 交叉熵低于 log\|B\| − m 的身体净增长为正。 |
| `additive_payoff_mode` | 没有再投资时，最优是全押最可能的字节。 |

和已有结果的接口：
- G13 说身体的读出就是边界上的 Gibbs 条件分布，它就是这里的 c。
- 事件驱动执行的真实字节检查（`cgb_event_driven_20261027.json`）显示，65%–76% 的字节到来时，目标 Q 团已经没有空位。用 T1 的语言说，身体还没有把容量摆到下一个字节的位置上。

## T2：需要多少记忆（已有，沿用）

要在 k 阶来源上把交叉熵压到接近熵率，身体至少需要等于因果状态数的状态。已有：`CausalState`、`history_readout_exists_iff`、`history_transition_exists_iff`、G11b `intake_memory_capacity`。

## T3：能活下去的充要条件（一半已有，一半待证）

- 必死的一半已有：`no_sustained_use_on_finite_supply`（EnergyBudget），以及 T1 的 `no_allocation_persists`。
- 待证的一半：每字节净收成 log|B| − 交叉熵，扣掉维护费和擦除的 Landauer 下限（`InformationThermodynamics`），为正时能在无限流里持续。
- 前提：收成和维护必须记在同一本账上。现在物料账和付费的信用账是分开的，要先统一。

## T4：为什么必须学习（已有，沿用）

- 来源未知或会变时，固定规则一定会被超过：O-1、O-2。
- 学习率要随波动率调制，并且按隔室分开：G10b、G10c。
- 学习规则：G14（两相学习即 delta 规则）、G15（奖励调制即策略梯度；与结果无关的调制学不到东西）。

## T5：为什么要离开、要探索（部分已有）

- 有多个来源时，需要落空计数器和离开阈值：G11、G12。这是边际值定理的一种形式：一个来源每字节带来的多出收成，降到别处的平均水平以下时就离开。
- 待推导：探索的认知价值在语言世界里的形式。也就是行动（`request`、在母亲世界里说话）怎样换来未来的收成。

## T6：构造实例（待做）

对 k 阶马尔可夫字节世界类，在同一介质里构造一个身体：
- 它的 Gibbs 读出等于经验条件分布；
- 它满足 T1–T5 和生命定义；
- 只要熵率低于 log|B| − 维护费，它就能活。

测量项：真实语言每字节的熵率。现有压缩研究的结果大约是 1 到 2 比特，而 log 256 = 8 比特，所以语言世界的食物很充足。

## 群体版本（用户 2026-10-27 提出，待证）

- 复制子动力学等价于贝叶斯更新：类型频率相当于先验，适应度相当于似然。
- 在波动环境中，群体的长期增长同样服从 Kelly 式；一条线索的适应度价值以互信息为上界（Bergstrom、Lachmann、Donaldson-Matasci）。
- 所以群体就是分布在许多身体里的记忆；T1 在个体（容量摆放）和群体（后代摆放）两个层次上是同一个式子，这正是"一个生成器、三个层次"。
- 一个群体只有在形成自己的边界（马尔可夫毯）时，才算一个更大的生命体。
- 对大肠杆菌的 E5，推出的判据是：世界内演化的群体增长率应当逼近该世界的 Kelly 上界，而不只是和 ES 比谁更好。
