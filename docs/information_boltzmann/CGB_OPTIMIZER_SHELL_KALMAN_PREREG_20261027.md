## 2. 推导

优化器的世界是一串带噪声的梯度，它的收成是损失下降。要从历史里提取有用的功，它的状态必须携带能预测下一个真梯度的信息。

| 层 | 依据 | 得到 | 局限 |
|---|---|---|---|
| 无记忆 | `memoryless_gain_excess`（由 G10a 推出）：有噪声时，增益 1 比最优多出 r²/(P+r) | SGD | 噪声原样穿过 |
| 稳态增益 | G10a：最优固定增益为 P/(P+r) | 动量（EMA） | 一个 β 管所有方向（G10b/G10c） |
| 逐坐标 | G10c：异质隔室需要局部增益；均值和方差是逐坐标高斯模型的充分统计量 | Adam | 对角形式没有关系项（GPT 的可分性定理）；除以 √v 只做尺度归一，不是信噪比增益（`unshrunk_excess`）；所有方向保留时间相同，没有壳层 |
| 竞争轴上的平衡 | G22c | Muon | 没有历史；噪声方向也给满步长，相当于一个最高增益的开关（G25e：增益乘分辨宽度为常数） |
| 特征基加 Adam | 关系载体加逐方向尺度 | SOAP | 每个方向的增益仍是稳态的，没有壳层，也没有信噪比增益 |

**壳层（导演指出）**：自然数据是长尾的，主干方向一直有稳定的信号，罕见特征只出现几次。所以各方向的"持续时间"天然不同。对每个方向跑一个随时间变化的 Kalman 滤波：
- 后验方差 P 就是壳层深度。证据让 P 下降，方向沉入内壳；漂移 q 让 P 回升。
- 一维高斯信念在 Fisher–Rao 度量下是双曲平面，Kalman 更新就是它上面的自然梯度。这是推导上的核对，不是新机制。
- 稳态版本（Adam、SOAP、动量）把这个结构抹掉了。

**KES 优化器**（Kalman-Eigen-Shell）：
1. 基：沿用 SOAP 的特征基，由左右 Kronecker 因子的 EMA 构成，β 取 0.95，每 10 步更新一次。
2. 在这个基里，对每个元素做随时间变化的 Kalman：
   - P⁻ = P + q̂，K = P⁻/(P⁻ + r̂)，m ← m + K(g − m)，P ← (1 − K)P⁻。
3. 噪声和漂移用局部水平模型的差分统计估计：
   - Var(Δg) = q + 2r，Cov(Δg_t, Δg_{t−1}) = −r；
   - 由这两个量的 EMA（β = 0.95）解出 r̂ 和 q̂，两者都截断为非负。
4. 步长：u = m / sqrt(EMA(m²) + P)。信心高的方向走接近 ±1 的步；不确定的方向走小步。这是有限增益、以预测为中心的分级响应（G25f）。
5. 把更新转回原坐标。

两个消融：
- **KES-nr**：不旋转（对角），检验关系载体。
- **KES-ss**：用同样的 q̂、r̂ 算出稳态增益，没有随时间变化的 P，检验壳层。

## 3. 任务

1. **A 长尾关联记忆**（沿用 10-26）：K = 1024 类，d = 64，Zipf 指数 1.2，200 步，batch 256。嵌入分正交和相关两种。指标：尾部准确率、头部准确率、损失。
2. **B 旋转、信噪比异质的回归**：W 为 64×64；输入 x ~ N(0, Σ)，Σ = U diag(λ) Uᵀ，λ 在 1e-2 到 1 之间按对数均匀取值，U 是随机旋转；输出噪声 ε = V diag(σ) z，σ 在 0.03 到 1 之间按对数均匀取值，V 是随机旋转。batch 32，500 步。指标：最终的总体超额损失 tr((W−W*)Σ(W−W*)ᵀ)/2。
3. **B0 各向同性对照**：Σ = I，σ 全部相同，其余同 B。
4. **C 主干加瞬变的漂移**：W 为 32×32，Σ = I，噪声 0.3。
   - 前 16 行是主干：目标固定，只有很小的随机游走；
   - 后 16 行是瞬变：目标每 40 步重新抽样。
   - 600 步。指标：最后 400 步的平均超额损失，主干和瞬变分开报告。

对比对象：SGD（动量）、Adam、AdaBelief、Muon-NS、SOAP（本仓库的重实现）、RowRes（仅任务 A）、KES、KES-nr、KES-ss。

学习率从 {1e-3, 3e-3, 0.01, 0.03, 0.1, 0.3} 中，在种子 0 上按最终损失选定，然后在种子 1–5 上评估。报告最小、中位、平均、最大。

## 4. 预言（中位数，种子 1–5）

| 编号 | 预言 | 依据 |
|---|---|---|
| P1 | 在 B 和 C 上，所有带记忆的优化器都优于 SGD | G10a |
| P2 | 在 B 上，SOAP 和 KES 都优于 Adam；KES 优于 KES-nr | 关系载体 |
| P3 | 在 B 上，KES 优于 SOAP 和 Muon | 信噪比增益（Wiener、G10c、G25e） |
| P4 | 在 C 上，KES 优于 KES-ss（壳层），而且主干行的损失更低 | 壳层 |
| P5 | 在 A 上，KES 的尾部准确率 ≥ max(Adam, Muon, SOAP) − 0.03 | 历史加竞争轴上的平衡 |
| P6 | 在 B0 上，KES 优于 SOAP 的幅度不超过种子间的区间宽度（边界） | G10c 的前提不成立时，没有优势 |

如果 P3 或 P4 不成立，说明壳层或信噪比增益在这个设定里没有带来好处，要找出原因，例如 q̂、r̂ 的估计太噪，而不是改预言。

## 5. 不声称

- 普适最优。优势只预言在方向异质（波动率或信噪比不同）的世界里成立。
- 大规模训练上的结论。这些都是小的合成任务。

## 6. 第一版结果（`results/published/optimizer_shell_kalman_20261027.json`，种子 1–5 的中位数）

| 预言 | 结果 | 数据 |
|---|---|---|
| P1 | 不成立 | B、C 上都有带记忆的优化器输给 SGD |
| P2 | 不成立 | B：SOAP 0.063 < Adam 0.130，但 KES 0.163 更差 |
| P3 | 不成立 | B：SOAP 0.063 最好；KES 0.163，Muon 0.107 |
| P4 | 成立 | C：KES 2.11 对 KES-ss 4.81；主干 0.55 对 1.64 |
| P5 | 不成立 | A 尾部：KES 0.54，Adam 0.97（正交）；SOAP 0.95（相关） |
| P6 | 成立 | B0：KES 0.459，比 SOAP 0.162 差 |

**有用的发现：**
- 在所有任务上，随时间变化的后验（KES）都远好于稳态增益（KES-ss）。
- 在主干加瞬变的任务 C 上，KES 的总损失最低：2.11，对比 SGD 2.66、Adam 3.11、SOAP 4.01。它追瞬变的能力最好：1.55，其他都在 2.1 以上。

**失败的原因（运行后的诊断）：**
1. **壳层的保护做反了。**步长 u = m/√(EMA(m²)+P) 让信心越高的方向步子越接近 ±1，所以在 C 上 KES 的主干比 SGD、Adam 抖得更厉害（0.55 对 0.13–0.20）。正确的做法是在对参数的信念上走自然梯度：步长正比于后验方差，深壳的方向难以移动（导演提出的双曲几何）。
2. **按出现次数计时这一条，设计里有，实现漏了**，预注册里也没有写明。
3. **换基时状态没有一致变换。**g_prev 换到了新基，Δg_prev 没有换，差分统计每 10 步被搅乱一次。KES-nr（不转基）在 A 上达到 0.95，KES 只有 0.54，与此一致。另外，罕见类别的事件在稠密特征基里会摊开，按出现次数计时需要在事件稀疏的坐标（行）里做，所以转基应只在输入侧。
4. **学习率网格太窄。**任务 A 上几乎所有优化器都选在了上边界 0.3。
