## 原测法需要修正的地方

`scratch/measure_iit_extended_20261105.py` 的 `compute_phi_star` 实现的是高斯条件互信息 `I(A_next;B_past|A_past)`，不是失配解码Φ*。其PID采用 `min(I(A;Y),I(B;Y))`，是最小互信息冗余设定，不能直接称Williams–Beer的I_min。`measure_phi_pci` 的残差行列式比对应高斯随机相互作用的估计式，而不是IIT3/4的Φ；64步拟合256维联合模型欠定，不能作为数值大小可靠的证据。自制阈值/字典复杂度只能称扰动复杂度代理，不能使用临床PCI阈值。旧脚本保留，不覆盖他人证据。

本轮不重新包装这些数；使用有明确出处的几何整合信息Φ_G，另列随机相互作用SI、留出预测切断损失与实际干预。

## 精确的指标定义

依据 Oizumi、Tsuchiya、Amari，PNAS 2016，式17—23：

`Y = A X + E`，对于预先声明的二分区，让 `A_cut` 的跨区块项为0，但保留创新协方差的非对角项。优化：

`Phi_G = min_Acut 0.5 * logdet(SigmaE + (A-Acut) SigmaX (A-Acut)^T) / det(SigmaE)`。

代码实际使用对数行列式差。三个确定性起点（零、原系数遮罩、分区边际回归）降低局部优化依赖；逐分区报告收敛、梯度和起点差。零起点保证互信息是可达上界。只切跨时项，避免把同拍相关创新错算成跨时整合。单独计算SI（还切断同拍项），不把它与Φ_G混用。

这是**实际整圈可观测投影的高斯Φ_G估计**，不是IIT3/4的完整因果结构、排他极大复合体或意识量。学习会使动力学漂移，12个读数也未必构成Markov充分状态。因此同报时间留出预测检验和结构干预，不能从拟合Φ_G的正值独立推出完整身体不可分解。

原论文：https://pmc.ncbi.nlm.nih.gov/articles/PMC5187746/

Φ*原定义：https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1004654

### 测实的闭环因果作用

- 同一起点的第一轮，完整/切断两者都沉默，世界输入位置相同；决策分布的总变差距离已经是 `.34657435`，本轮结算也有差异。它是同起点的直接干预，不是分岔后在不同输入上比较。
- 第2轮开始话语、动作类别和世界位置一起分岔。128轮中119轮话语不同，127轮世界位置不同。在线取用确实参与表达和世界输入选择。
- 单槽偏好只加0.1后，64轮内行为抽样及世界位置没有分岔；动作分布TV最大 `.00812363`，土/金等后续读数产生小变化。这是小扰动的数值传播，不称为行为转变或失稳。
- 切断后两条轨迹收到不同文本，不能用其回应NLL差判能力高低。切断分支的水读数恒为0，其原始最小Φ_G也为0，这是投影恒定带来的数学结果，不作为独立的“整合消失”证据。

**统计验收未通过，因此不把这个正值当作可靠的身体整合强度。** 39份8轮块打乱控制的最小Φ_G中位数为 `.13025196`，上尾比例 `(1 + 超过实测的份数)/40 = .175`。它没有清楚超出同样样本数、维数与分区搜索造成的背景。

由中段选择的最弱预测切口，在末65对样本上反而比全模型更好：固定创新协方差下“切断NLL−完整NLL”均值 `-3.05345`，8轮块bootstrap区间 `[-4.05429,-2.15835]`。这不是字节NLL，而是12维投影的高斯密度评分；负数原样保留。

读数漂移与协方差假设确实是问题：前后半段木的进展预测均值移动约1.35个前段标准差，金的误差RMS移动约1.84个，实际结算g的标准差从 `.0303` 增至 `.0666`。全模型的后段标准化点预测MSE是 `1.69449`，优于无历史均值 `2.28095` 和直接持存 `2.34435`；但其固定误差分布的密度评分泛化失败。也就是说，并非完全不能预测，而是固定高斯模型不足以给出校准的整合强度。

看到主结果后，额外用每相第一个读数及世界匹配长度组成6维投影作探索性维数检查，未追加身体运行：Φ_G为 `.03234033`，块打乱上尾比例 `.225`，留出切断评分仍为负。它不替换预登记主结果，也没有从多个投影里挑一个成功数字。
