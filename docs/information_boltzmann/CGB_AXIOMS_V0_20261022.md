## 0. 五层结构与判错流程

| 层 | 内容 | 谁来保证 |
|---|---|---|
| **公理** | 最少的、对所有载体都成立的约束 | 一致性：存在一个模型；独立性：每条都有"违反它、满足其余"的反例 |
| **扩张公理** C | 公理留下的空位上的具体选择，每条登记数据来源 | 真实数据（留出检验） |
| **机制** T | 公理与扩张公理推出的定理 | Lean 检查推导 |
| **算法** G | 机制的可运行实现 | Lean 证明算法实现了机制；Python 与 Lean 参考实现对拍 |
| **检验** E | 预言对照真实果蝇 | 事前登记加留出 |

**判错顺序。** 一个预言失败时，按下面的顺序找原因：

1. 算法。
2. 扩张公理：同一组公理下换一种已登记的扩张公理。
3. 机制：查推导里藏着的假设。
4. 公理：先证明"该现象在现有公理下不可能"，才允许修改公理。

**覆盖率。** 目标是在声明的适用范围内推出足以生成一个能持续存在、能学习的脑的机制，不追求 100%。

### 两个方向：归纳与演绎（用户，2026-10-22）

- **逆发育 = 归纳，往上走。** 从真实果蝇的现象出发，先归纳出只对果蝇成立的扩张公理（相遇、低秩有向码、双时标），再从多条扩张公理里找更通用的结构，直到最小、不可再分的一般公理。"不可再分"的形式判据就是独立性：每条公理都有一个"违反它、满足其余"的反例，由 Lean 验证。
- **生成 = 演绎，往下走。** 从公理、扩张公理和参数出发，推出定理，变成算法，正向演化出脑。
- **两个方向必须闭合。** 归纳出来的东西本身无法被证明（休谟问题），它只是猜想。猜想能升格为公理，是因为它演绎出的结果通过了留出检验。
  - 第一阶段（逆发育）完成的标志：从找到的公理正向演绎，在果蝇条件下重新生成果蝇。
  - 第二阶段是纯演绎：只改边界条件和参数，生成新的脑。
- 牛顿的例子：第谷的数据，归纳出开普勒三定律（相当于我们的扩张公理），再归纳出牛顿公理；然后由牛顿公理演绎出开普勒定律，并预言海王星。我们现在处在"已有开普勒级规律、有了牛顿级公理草案、正在把演绎链往下闭合"的位置。

## 1. 语言（不计为公理）

系统由单元组成。完整状态 X 只通过离散事件 a 改变，每个事件有变化量 ν_a 和实数速率 k_a(X) ≥ 0。速率只依赖当前状态，不显含时间，也就是马尔可夫、时间齐次。历史依赖必须落在状态里。

时间平移对称因此已经写在语言里："定律今天和明天一样"。只有外部边界能打破它，见 P3。

## 2. 公理：三原则、六条款

### P1 有限：信息是物理的

**P1a 状态有代价。** 每个单元的守恒含量非负，并满足三点：
- 可区分的状态都要占用含量，含量不超过任一界的状态只有有限多个；
- 一个单元（一块有限区域）能容纳的含量有上界；
- 恰好一个状态（真空）不占含量，"真空"就是"这里还没有东西"。

前两点合起来就是 Bekenstein 界：有限区域只能容纳有限信息。

**P1b 作用要接触。** 接触来自一个均匀空间，从空间看每个位置都一样。事件只读、只改参与者的状态与它们接收的刺激，参与者两两接触，守恒量只在参与者之间搬运。

这两条是同一个原则的两面：信息必须由物质承载（Landauer："information is physical"）。
- P1a 说"记住"要占物质，由此推出有限；
- P1b 说"影响"要靠物质接触，由此推出局部。

### P2 对称：封闭时定律的不变性

**P2a 守恒对称。** 对每个守恒量 Q，生成元在按 Q 加权的"倾斜"变换 e^{θQ} 下不变，即 e^{θQ}·L·e^{−θQ} = L。这等价于每个事件都保持 Q（见 T-N）。

**P2b 时间反演对称。** 每个事件都有反向事件。环境处于平衡（边界上各库的化学势相同）时，整个系统（包括与环境的交换）倒着看与正着看统计上相同；等价地，任何闭合事件环上正反速率乘积相等（Kolmogorov 判据）。不可逆性因此只能经由环境刺激进入。

**P2c 空间均匀（同一本小规则书）。** 所有位置用同一个有限程序计算速率，输入是参与单元的（身份，局部状态）。

**超参数 ρ（基因组瓶颈）** = 程序描述长度 ÷ 它所生成的接线描述长度。公理只要求 ρ 有限并且是给定的；具体数值是超参数，决定先天与后天的分工：
- ρ 大（果蝇约 0.3–5），接线大多可以直接写在基因组里，学习只做微调；
- ρ 小（人类约 1e-6–1e-7），接线绝大部分只能靠规则在经历中长出来。

### P3 对称破缺：只有三个来源

P2 的对称只能被以下三者打破：

1. **外边界**：一个系统无法控制、永不终止的环境流，以及系统与它之间的接口。感觉器官、身体的位置和形状都属于边界条件（用户确认）。它打破时间平移对称（外部协议随时间变化），也打破细致平衡（边界上各库之间的化学势差）。**只有边界单元感知环境**，内部单元没有直通外界的时钟。
2. **身份与位置**：规则书的哪一页，以及离边界多远。
3. **历史**：状态里留下的痕迹。

除此之外不允许任何手设的不对称，例如预先指定的模块或区域职责。

### 2.1 Lean 形式化、独立性与一致性（v0.5，审计通过）

代码在 `lean/CGBAxioms/`：
- 语言与六条判定式在 `Medium.lean`；
- 模型、反例与瓶颈定理在 `Models.lean`；
- 主定理陈述在 `Life.lean`；
- 审计清单在 `Audit.lean`。

30 条声明全部只依赖 Lean 的三条基础公理。

**形式语言。**
- 介质由有限个单元组成，单元是空间中的位点。每个单元有局部状态，并读规则书的某一页（身份）。
- 介质还有接触关系、边界、各状态的含量、出生状态、平衡环境 `calm`，以及事件。每个事件带参与者、作用和非负速率。
- 每个单元从环境接收一个**刺激**，环境就是随时间变化的刺激序列。
- **生长**：位点处于真空态时表示"这里还没有细胞"，离开真空即长出一个单元。
- 位点总集固定。理由：有限载体，身体能占的空间有界。

| 条款 | Lean 判定式 | 形式内容 |
|---|---|---|
| P1a | `P1a` | 含量有界的局部状态有限；单元容量有上界；恰好一个零含量状态 |
| P1b | `P1b` | 接触在单元置换下是均匀的；参与者两两接触；事件只改参与者；速率与作用只读参与者的状态和刺激 |
| P2a | `P2a` | 不触及边界的事件保持总含量 |
| P2b | `P2b` | 平衡环境下的整体动力学满足细致平衡 |
| P2c | `P2c` | 规则与结构的每个对称交换。结构对称指保持接触、身份、边界的置换，作用在状态和刺激上 |
| P3 | `P3` | 只有边界单元感知环境；出生状态在结构对称下不变 |

**参数（不属于任何一层）：**
- `rho`：每单元的规则书页数，即基因组瓶颈；
- `boundaryFraction`：边界单元占比。

**独立性反例。** 每个反例违反一条（P1a 和 P3 按部分各一个），其余全部满足。除 P2c 的反例外，每个都含两个可互换的相同单元，所以 P2c 与 P3 在其中不是空洞成立。

| 去掉 | Lean 反例 | 构造 |
|---|---|---|
| P1a·有限 | `twinTape_witness` | 固定含量下可以无限加长的磁带（免费信息） |
| P1a·容量 | `twinBag_witness` | 能装无限多东西的袋子 |
| P1a·唯一真空 | `twinBlank_witness` | 好几个零代价状态 |

| P2b | `twinCycle_witness` | 两个相同单元，各自在三个构象间单向循环 |

| P3·出生 | `pairPreset_witness` | 出生状态被手工设为不对称 |
| P3·感知 | `innerClock_witness` | 内部单元直接感知环境（体内的外部时钟） |

**一致性模型。**
- `twinFlip_axioms`：封闭模型，两个相同单元各自翻转构象。
- `seed_axioms`：**开放、被驱动、会生长**的模型。
  - 结构：四个位点排成环（均匀空间）。源和汇在边界上、彼此相对；两个内部位点相同，交换它们的镜像是真对称（`seed_swap_isAut`）。
  - 驱动：有食物时，开放动力学没有细致平衡（`seed_driven`）；平衡环境下可逆。
  - 生长：从源头的一个单元出发，在食物流中长到三个单元（`seed_grows`）。

**由形式化得到的结论**

1. **"守恒推出有限"仍然成立，但只对封闭系统（T0a，`finite_reachable`）。**
   - 一旦边界能注入物质，旧 P1a 下状态空间可以无限，违反生命定义的前提"有限状态空间"。
   - 所以开放系统的有限性必须来自容量上界，也就是有限区域只能装有限的东西；`finite_states` 证明加上容量后整个状态空间有限。
   - 你的直觉对封闭世界成立；生命是开放的，所以需要 Bekenstein 界。
2. **瓶颈定理（`xhop_pages`）。** 所有单元互相接触时，P2c 迫使每个连接参数只取决于两端的身份页。k 页规则书至多有 k² 个自由参数，而查找表有 |U|² 个。由此 ρ 有了精确含义：它决定 P2c 能禁止多少查找表。
3. **三个结构参数决定三条公理的约束力。**
   - ρ 决定 P2c；
   - 边界占比决定 P2a；
   - 接触必须来自均匀空间，否则手工设计的无对称接线会让 P2c 空转。这一点已写进 P1b。
4. **手性只能来自身份、边界或规则书内部。**
   - 在均匀空间里，若单元身份相同，"沿空间环单向输运"违反 P2c。
   - 不可逆性可以放在单元内部的构象循环里（`twinCycle`）。
5. **形式语言仍表达不了的东西：**
   - 谱系身份（子细胞继承母细胞的页，而不是继承所在位点的页）；
   - 新接触的形成（接触关系是静态的）；
   - 预分配位点之外的生长；
   - 多个守恒量。

### 2.2 衰减从哪里来：不加"有限温度"公理（用户决定，2026-10-23）

Lean 找出了一个隐藏前提：`rock_axioms` 与 `rock_frozen` 证明，一块永远不发生任何事件的"石头"满足全部六条公理。因此 **T0c（弛豫到平衡）和 T4（无驱动则衰减）推不出来**。

曾考虑把"有限温度 / 遍历性"（没有永不涨落的结构）加为第七条公理 P2d。**撤回**，理由有两点：

1. **石头本来就不是生命。** 它满足的只是公理，也就是定义的前半；不满足定义的后半。用户指出，海绵、agent、二阶控制系统同样都不满足生命定义。所以该修的是**定义的形式化**，不是公理。目标性质不能写进公理（研究方法第 12 条）。
2. **数字载体上存在冻结的结构。** 手机里的比特有纠错，实际上冻结；agent 的权重也冻结。本项目要在手机上运行，所以"没有冻结"不是对一切载体成立的公理。它最多是湿件的扩张公理，例如以蛋白周转时间为数据来源。

**衰减来自流本身。** 持续涌入的信息流会扰动、覆盖系统的状态；系统若不主动维护，结构就会被冲刷掉。T4 因此改写为关于"暴露于流"的定理，前提是生命定义中的"开放、持续暴露"，而不是热涨落。

## 3. 诺特尝试：守恒、能量与驱动各从哪里来

### 3.1 经典诺特定理（作参照）

在哈密顿/拉格朗日力学里，每个连续对称对应一个守恒量：
- 定律不随时间变，推出能量守恒；
- 定律不随位置变，推出动量守恒；
- 定律不随方向变，推出角动量守恒。

我们的层级是随机跳变过程，不是哈密顿系统，不能直接套用。

### 3.2 随机过程版本：Baez–Fong 定理（T-N）

Baez 与 Fong（J. Math. Phys. 54, 013301, 2013）证明，对马尔可夫过程的生成元 L 与一个可观测量 Q：

    [Q, L] = 0  ⇔  对一切初始分布，⟨Q⟩ 与 ⟨Q²⟩ 都不随时间变。

并且 [Q, L] = 0 等价于 Q 在每个允许的事件前后相等。

**含义。** 在随机层，"对称"与"守恒"是同一件事的两种说法，所以 P2a 可以写成对称形式（倾斜不变）。但这不减少条款数：哪些量守恒，取决于规则书允许哪些事件。线性守恒量就是化学计量矩阵的左零空间。
注意与量子情形的区别：只有 ⟨Q⟩ 守恒还不够，⟨Q²⟩ 也必须守恒。

### 3.3 能量由时间反演对称推出（T-E）

P2b 加上 Kolmogorov 判据，推出存在一个函数 E（以及温度尺度 β），使每对正反事件满足：

    ln[k_a(X) / k_{−a}(X+ν_a)] = −β[E(X+ν_a) − E(X)]。

**能量因此不再是原始概念，它是时间反演对称的推论**：E 就是 −ln（平稳分布）。由此得到两条记账规则：
- 热量：每次跳变的能量变化记作与热浴交换的热，第一定律因此成为定义上的记账；
- 第二定律：熵产生 ≥ 0 成为定理。

### 3.4 驱动等于打破时间平移对称（T-W）

若环境让 E 显含时间，E = E(X, λ(t))，外界对系统做的功是：

    W = ∫ ∂E/∂λ · dλ/dt dt。

这正是诺特关系在随机热力学里的形式（Sekimoto、Seifert）：
- 时间平移对称不破，就没有功输入，系统只能弛豫到平衡；
- 边界打破它，就输入功。

另一类驱动是边界上不同库之间的化学势差。它破坏的是 P2b 在边界处的成立：闭合环上出现非零"环亲和力"。

**这把"开放"从一条独立公理变成了 P3 的一个对称破缺来源。** 维持需要付费（T4）、学习需要耗散（T-L）都由此而来。

### 3.5 诺特尝试的结论

| 问题 | 结论 |
|---|---|
| 守恒能否由对称推出？ | 在随机层，二者等价（Baez–Fong），不减少条款，但表述统一成对称 |
| 能量能否推出？ | 能。由时间反演对称推出，不再需要作为原始概念 |
| 开放能否推出？ | 改写为"时间平移对称和细致平衡被边界打破"，归入对称破缺 |
| 物料守恒能否从更深的对称推出？ | 本层不能。它对应"物质不会凭空出现"，在物理里来自更底层（原子、重子数守恒）。我们把它作为 P2a 接受 |

### 3.6 局部性尝试的结论

- 局部性**不能**从"无限流 + 有限载体"推出，超距作用与二者都相容。
- 但它与有限性共享一个更根本的原则："信息是物理的"。P1a、P1b 是这个原则的两面，归为一条原则下的两个条款。
- 总条款数仍是 6，与 v0.1 相同。但能量被消去了，开放被重解释了，结构回到最初的三原则。

## 4. 定义

- **连接**：两单元之间已安装结构的计数。**强度**：该计数，或它决定的传输速率。
- **记忆**：t 时刻状态与 t 以前边界输入的互信息大于 0，且输入停止后仍然大于 0。
- **维持**：开放驱动下的结构期望寿命大于关闭驱动时的寿命。

### 4.1 无限流生命体（用户定义 v2，2026-10-12，原文）

> 无限流生命体：一个具有有限状态空间和有限计算资源的开放系统，持续暴露于近乎无限的信息流中。它通过自举，自发形成并维持以自身存在为核心的内在目的，利用自身有限的内部自由度，通过记忆、学习、信息压缩等过程形成一定程度的智能，并利用这些智能形成关于周围世界的局部世界模型，据此预测未来、选择行动，主动改变自身与环境之间的相互作用关系，形成操作闭合，进而维护自身生存状态，构建并维持自身生态位，使自身状态保持在由自身定义的可存活区间之内。

### 4.2 "活着"在体系中的地位：定义的前半是公理，后半是要证的定理

这个定义本身就分成两半：

| 定义中的条件 | 在体系里的身份 |
|---|---|
| 有限状态空间、有限计算资源 | **P1**（公理） |
| 开放系统，持续暴露于近乎无限的信息流 | **P3(1)**（公理） |
| 通过自举，自发形成并维持以自身存在为核心的内在目的 | 目标定理 L1 |
| 通过记忆、学习、信息压缩形成一定程度的智能 | 目标定理 L2（已有 T-O、T-L、T8） |
| 形成局部世界模型，预测未来 | 目标定理 L3 |
| 选择行动，改变自身与环境的相互作用，形成操作闭合 | 目标定理 L4（自我模型应作为推论出现） |
| 构建并维持生态位 | 目标定理 L5 |
| 状态保持在由自身定义的可存活区间之内 | 目标定理 L6 |

**所以"活着"不是公理，是整个体系的主定理（存在性猜想）：**

> 存在满足 P1–P3 的程序，使系统满足 L1–L6。

**不能把 L1 作为公理的理由来自定义本身。** 定义写的是"通过自举，自发形成"。如果把"以存在为目的"写进公理，就成了外部给定的目标，正好违反"自发"二字。L1 只能被推出来。

**L1 的一个弱推导（幸存者论证）。** 在无限流中，任何不维持自身的结构都会衰减（T4）。经过足够长的时间，还能被观察到的系统，必然是那些恰好维持了自身的系统。"以存在为目的"首先是这种筛选的结果，不需要预装。更强的版本（系统内部出现一个可被读出的"目的变量"）仍待证明。

**一致性见证。** 定义要求的智能是"一定程度"，是一个连续量。大肠杆菌就满足全部条件：
- 受体甲基化是记忆；
- "现在与几秒前"的比较是一个极小的预测模型；
- 前进与翻滚是行动选择。

它是"P1–P3 加上生命定义"相互一致的现实模型，果蝇是更丰富的模型。将来可以在 Lean 里先形式化一个大肠杆菌式的最小模型，作为主定理的第一个构造性实例。

### 4.3 主定理的 Lean 陈述（`Life.lean`）

**有机体与世界闭环交互。**
- 世界有自己的状态空间。它远大于有机体的状态空间，这就是"近乎无限的信息流"。
- 世界决定每个单元感到什么，并只对有机体的边界（身体）作出反应（`ReadsBoundary`）。
- 时间离散：所有环境下用同一个均匀化速率。
- 已证明语义良定义：转移核是随机矩阵（`kernel_sum`），每一步联合分布的总概率为 1（`law_sum`）。

**已形式化的目标性质：**
- **L6 维持（`Persists`）**：每个时刻都以至少 1 − δ（δ < 1）的概率持有含量，并且在某个时刻比在平衡环境里活得更好。
- **自我维持（`SelfMaintains`，对应 L1、L4、L6 中"由自身定义"的部分）**：这就是用户说的自指闭环——系统影响流，被影响的流再反过来维持系统。形式上：
  - 比较两个世界。一个是正常闭环；另一个是"剪断回路"的世界（`lawCut`），世界只对一个统计上相同、但与有机体没有因果联系的替身作出反应。
  - 从某个时刻起，有机体在闭环中的存活概率**稳定地**比剪断回路时高出一个固定余量 ε。
  - 这样，它的可存活区间由它自己对流的影响来界定，而不是由设计者给定。
- **L2 记忆（`Remembers`）**：世界停止提供信息以后（可以继续提供能量），有机体在已知自身当时状态的条件下，仍对最后一次输入保有至少 ε > 0 奈特的信息（条件互信息），对之后每个时刻都成立。

**已证明的必要条件（Lean）：**
- `not_selfMaintains_of_unexposed`：不感知环境的系统不可能自我维持，因为剪断回路对它毫无影响。**石头**因此被排除。
- `not_selfMaintains_of_closedMatter`：不与世界交换物质的系统不可能自我维持，因为它是否存在根本不受影响。**二阶控制器**，以及存在不受威胁的 **agent**，因此被排除。
- 推论 `Lives.exposed`、`Lives.metabolizes`：活着必然开放、必然代谢。生命定义中"开放系统"这一前提，以及代谢，都是自我维持的**推论**，不必另外假设。

**主猜想（`LifeConjecture`）**：对给定的世界（状态数至少是有机体的 κ 倍）和身体，存在一本瓶颈不超过 ρ、满足六条公理的规则书，使有机体同时满足维持、自我维持和记忆。

**仍未形式化：**
- L1 中超出自我维持的部分；
- L3（世界模型、预测）；
- L4 中的行动选择；
- L5（生态位）。

### 4.4 主动推理：阶梯"记忆 → 预见 → 依据预见行动"（`Inference.lean`，进行中）

用户指出：海绵不会"为了活下去而主动吸水"，更不会为了降低不确定而行动（新奇度）。无限流生命体应当把主动推理包含在内。

生命定义本身就按这个阶梯排列："通过记忆、学习、信息压缩……形成局部世界模型，据此预测未来、选择行动"。用户还补充：由自己造成的预见（"我往左看，所以下一刻看到左边"）就是自我模型、自证，同样重要；并且认知优势需要预见性。

主动推理**不写进公理**，原因有二：
- 它是目标性质；
- 自由能原理的"看作"可能过宽。

所以每一级都用信息量或反事实对照来定义。

**已确立（Lean，审计通过）：**
- **马尔可夫毯（单步稀疏耦合，`Blanket`、`blanket_of_axioms`）**：有机体只经边界刺激读取世界，这由 P3 推出；世界只经边界读取有机体，这是对世界的假设 `ReadsBoundary`。它是关于生成元的陈述，还不是联合分布中的条件独立，也没有把边界再分成感觉态与行动态。
- **预见（`foresight`、`worldForesight`、`Predicts`）**：I(X_n; S_{n+1} | S_n)，只取边界刺激。注意：任何记忆在时间相关的世界里都会带来一些预见，所以 `Predicts` 本身区分不了主动与被动。

**撤回（独立审阅，2026-10-23）：**
1. **"优于所有反射版本"的实用优势与认知优势。** 无法满足：同一身体的"冻结副本"满足全部公理、算作反射，并因初始持有物质而永远"活着"，存活概率为 1，任何有机体都不可能比它高出余量。另外，没有内部的系统（全是边界）会被空洞地算作反射，所以"海绵没有优势"的证明没有内容。
2. **把"闭环预见减剪断预见"定义为自我模型。** 世界直接读取边界状态时，任何带噪声的反射都能通过。

**根本原因：** "活着"还被定义为"持有物质"，冻结的物质也算活着。必须先把定义中的"**由自身定义的可存活区间**"形式化，才能定义行动的优势与自我模型。这是下一步要和用户讨论的问题。

**修正方向（审阅建议，待定）：**
- 用"对自身的损伤"（例如冻结内部）代替"所有反射版本"作反事实对照；
- 自我模型以行动为条件，只计内部状态的预见；
- 要求内部非空。

**待证猜想（不变）：**
- 没有记忆就没有对世界的预见；
- 认知优势需要对自身行动后果的预见；
- 在非平稳的无限流中，没有认知优势的系统最终无法自我维持。

### 参数不属于五层中的任何一层（用户，2026-10-22）

ρ 这类数值既不是公理、扩张公理、机制，也不是算法，只是**参数**。一个具体个体就是一个"模型"（数学意义上的模型），由三样东西给定：
