# 感觉轴突末梢回流：48.6万对回流进入前向运行

感觉细胞的树突在外周，脑内所有落到感觉细胞上的突触都在它的中枢轴突末梢上。这些突触调节末梢释放，不让细胞放电。`coba_r2` 建图时整片删去了这486344对（`no_sensory_input`）。本轮把它们按实际接触位置接进前向运行和完整存档。

## 机制（`information_boltzmann/core/fly_sensory_terminals.py`）

| 环节 | 实现 |
|---|---|
| 接触 → 末梢 | 1892087个实际接触各自送到目标细胞完整形态的实际节点，保留原延迟1–4拍。来源若是外部细胞，读其旧脉冲；来源若是另一感觉细胞，读它在实际释放位点的包（767899个接触），不读胞体广播。每个接触携带coba_r2的一个突触单位（兴奋0.00178178，抑制0.00653913）。 |
| 末梢电导 | 兴奋、抑制两种末梢电导，沿细胞自身的突触时钟（leak_se/leak_si）衰减，在全部6384890个节点上做守恒扩散，不跨细胞、不降维。每个细胞每种电导有一个可学习运输系数。 |
| 释放 | 每个实际释放位点（2124535个）按局部开放电导分流：`g_L/(g_L + g_E·s_E + g_I·s_I)`，与胞体同一电导代数。用的是该细胞自己的漏电和增益，末梢增益可学习，初值为1。运输无限快时，末梢看到的电导正好等于点模型给胞体的电导。 |
| 输出 | 感觉细胞919389条活边从各自实际位点发出：每条边按实际接触均分（接触数等于突触数，已核对），乘该边当前学到的权重。点细胞环中这些细胞的列不再经静态边传递，每个脉冲只送一次。 |

**机制假设：**
- 果蝇感觉末梢的突触前抑制以GABA为主（Olsen & Wilson 2008；Root et al. 2008）。
- 兴奋性（胆碱能）末梢电导同样分流入侵的动作电位、从而减少释放：这是假设，未经测量。
- 末梢易化和受体亚型没有建模。

**未接入：** 3523个来自OA/5-HT/DA细胞的接触另放。它们走代谢型受体，要等胺类受体模板，不当快电导用。

## 解读与边界

- 回流已真实接通，作用不小：对一个没带这条通路训练过的个体，感觉输出平均立刻降约30%。末梢分流的强度取决于运输系数与末梢增益；两者都是学习量，初值不是测得的生理时间常数（与KC末梢同一单位约定）。紧邻强输入的位点几乎完全被分流（最小0.0005）。
- 只是执行与递送检查，不代表学习或行为收益。是否带这条通路继续训练（`training_adoption_approved: false`）要另行决定；主线仍暂停。
- 资源：GPU常驻缓冲约427MiB（索引为int64；改int32可减约一半，尚未做），CPU几何与两份树分解缓存约511MiB，持久状态85MB；BPTT期间的反传临时空间未测。
- 仍缺：各类感觉细胞的专用受体与适应、末梢易化、胺类末梢受体、注意的功能收益（见 `FLY_NATIVE_COMPLETENESS_20261018.md`）。
