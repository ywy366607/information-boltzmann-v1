# 梦漓终端：指标定义与研究参照

界面只呈现名称、数值、状态和操作；指标来源与研究说明集中保存在本文及原测量文档。

## 数据与单位

- cycle：已提交的外界轮编号。更新次数是该轮优化器更新数。
- 累计字节：保存态的 `memory.clock`，包含自听。最老留痕是最老占用槽距末次写入的字节事件数。
- 回应预测误差：原日志的 `response_nll`，缺失时取 `mother_response_nll`，按原 NLL 单位展示。
- 联合学习进展：原日志的 `joint_progress`；该字段无记录时展示 `progress`。这些数值保留原单位。
- 分层动量：各层保存态 P 范数。星云明暗与节律读取保存态逐层动量和逐头角频率；它是动态展示映射。
- 摄入字节 / 外界字节：分别读取事件的交互回应摄入量与该轮全部外界摄入量。
- 图线按真实记录相连，在缺测和 cycle 不连续处保留断点。零值参与计算，缺失值保持缺失。

## 图表操作

每张曲线的“范围”可设置 cycle 起点、终点以及纵轴下限、上限。留空的边界随可用数据计算，“自动”恢复全部自动边界。范围筛选和纵轴裁切只影响显示。悬停或键盘选中数据点可读取数值。

当前事件含绑定拓扑快照时，界面显示水库结构数值。历史复形 β₁=62，扩充后为64；两次旧 pending 响应的调和占比分别为18.32%、17.82%。β₁ 是空间维数，调和流占比是实际信号分解结果。详细来源见 [原生身体测量总账](CGB_NATIVE_BODY_LEAN_MEASUREMENT_20261117.md)。
