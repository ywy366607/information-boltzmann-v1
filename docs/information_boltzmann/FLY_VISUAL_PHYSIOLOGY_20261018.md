# 早期视觉连续释放：复用现有动力学

本轮接入的是早期视觉的生理传递方式，不是再新增一个视觉慢状态。
感光细胞、L1–L3、Mi1、Tm1、Tm2、Tm3 的电位变化由现有 COBA 膜、延迟环和固定突触传递。
这些细胞改用已有 graded release，保留电位，不触发脉冲清零或不应期。
T4/T5 和未列入证据范围的视觉投射细胞仍走原来的脉冲动力学。

## 依据与建模边界

- Zheng et al. 2006 的果蝇感光/lamina 电生理与反馈实验：
  https://pmc.ncbi.nlm.nih.gov/articles/PMC2151524/
- Behnia et al. 2014 对 Mi1、Tm3、Tm1、Tm2 的在体膜电位记录：
  https://pmc.ncbi.nlm.nih.gov/articles/PMC4243710/

连续释放是有依据的生理约束；目前具体释放函数仍为现有模型的
`gain * relu((v - floor) / threshold)` 近似。
`floor = E_I` 是让静息附近增减都能传递的工作点假设，不是测得的果蝇绝对电位。
每个新增细胞有正值、可学习释放增益，初始化 .025。
这不是零行为变化的附件，必须在副本检查其实际影响。

## 连续性和接口

新增参数 `log_visual_graded_gain`，保留原来的 `log_graded_gain` 对象、形状和数值，
因此 APL/CT1 的优化器历史及已归档信用无需重排。视觉参数加入原生信用和独立生理学习率组。
不新增物理状态；原来的膜、电导、延迟脉冲、RNG 和世界队列照常保存。
`--visual-graded` 省略时继承，老存档默认关闭。

实现检查覆盖连续增减、无脉冲重置、旧参数保持、旧 Adam moments 保持、原生参数注册、
保存恢复及未选细胞保持原语义。真实语言短段与同时钟干预矩阵只验证实现和急性通路，
不能证明视觉理解、导航、探索、自我或持续学习收益。

ENS/内分泌仍待真实身体交换变量和递质/受体证据；不把普通低通状态改名为饥饿或生命维持。
