# 将已有有限见证收束为同一个可执行过程

本轮交付是既有 `SensoryMaintenance.process` 的统一参考实现。身体、行动、世界后果、付费学习、持续维持和物料来源使用同一个状态更新与同一世界拍；没有新增生产 Lean 模块，没有选择新的脑架构。本记录不替代语言生命体活规格。

## 一个主实例，而不是把历代状态空间相乘

| 原有工作 | 在统一模型中的位置 | 可沿用的范围 |
|---|---|---|
| ActiveMaintenance、LearningMaintenance | 早期构造与推导历史 | 它们改过身体、刺激和规则，没有整体等价证书；不直接搬用结论 |
| RenewableLearning | 最终版本的候选记忆、行动策略、改写信用、冲突重开与补给 | 复用原 `Cell`、`policy` 和 `next true true` 的实际规则 |
| GraceRecovery | 同一身体所处的后果世界 | 采用修订后的冲突反馈与三拍恢复窗口；不沿用旧世界的两拍恢复结论 |
| SensoryMaintenance | 唯一主身体：结构细胞 × 维持储备 | 同时承载付费改写、实际摄入/释放、感官失联扣费与空态吸收 |
| Recovery、Limits、Closure | 同一过程的观察与干预 | 自然存活、一拍耐受、长失联失败及自身边缘幽灵剪断分别验收 |
| SensoryMaintenanceCarrier | 同一过程的固定身份物料实现 | 定时精化保持投影、首次摄入概率与评分；再充能工作沿实际摄入计费 |
| PortSeparation、PortContracts | 对输入的扩张及其局部合同 | `legacy_rules` 对应原规则；独立感官/资源新协议的完整精化仍待建立 |
| 代数、同调、因果状态与语言核 | 可复用的表示/分析工具 | 按需要使用，不把每个工具变成新的身体状态或功能模块 |

## 同一拍怎样更新

身体是 `Cell × Fin 3`，共24种形式状态；世界有9种状态。运行时控制规则只有原来的三种行动：资源行动A、资源行动B、探测。有限候选记忆及其信用已经编码在 `Cell` 中。

给定旧状态 `(身体, 世界)`：

1. 世界给出本拍信号；失联协议只遮蔽信号，世界拍继续。
2. 身体按旧信号更新记忆与储备，同时登记摄入、释放、改写、补入信用和毁损信用。
3. 世界按旧身体行动产生后果。步骤2和3共享旧状态，不能提前把新世界信号送入身体。
4. 两组固定物料身份同步从旧库存搬运。刚释放的身份不能在同一拍再用于补源。

闭环的关键不是额外评分器，而是原规则中的因果接续：记忆选择行动；行动影响下一世界状态；失配后果触发付费重开；后续探测消耗信用写入新候选；实际食物补回维持与改写资源。世界条件、支持表及两候选族仍是该见证的明确选择，并非六公理已经强制的唯一形式。

## 已实际核对什么

- 从原 Lean 定义导出192组身体输入的转移、行动、含量和五类端口。
- 在审查文件中证明整数世界权重精确表示原 `GraceRecovery.moves`，再核对648个概率条目。同一文件还把自然全时存活、一拍耐受、剪断上界和两拍耐受否证组合为同一身体—世界对象的联合证明。
- 穷举1,728组完整身体—世界状态与输入，核对 Python 的实际一步组合；不是仅分别测试两段函数。
- 核对两组12身份载体的384组分量收支与旧库存搬运，总计24个固定身份。可执行选择采用最小旧身份，满足同一搬运合同；不声称等于 Lean `Classical.choose` 的逐身份选择。
- 剪断分支严格使用它自身联合分布的身体边缘；分段继续运行与直接运行相等。协议非法时本拍状态、核和账本均不提交。
- 同一核中有一条概率为1/8的 A→B→A 再学习路径：13拍共5次付费改写、补入6单位信用；摄入20、释放18，身体含量从4到6。来源库存保持8，再充能工作20，满足 `6 + 8 + 18 = 12 + 20`。这是一条支持路径，不是典型行为或能力统计。
- 精确复算自然过程、一拍/三拍失联及剪断评分。两拍失联从第2拍开始时，第3拍存活评分为1/2；失败分支仍有非空身体，但未来三拍摄入概率为0。这与已有两拍耐受否证相容。

所有数值核对是实现与语义验证。自然过程的全时结论等仍由已有 Lean 证书承担，有限检查没有替代无限时间量词。

## 统一以后还缺什么

该参考把多项性质放回了同一个对象，可以用于检验下一条生成规律是否保住它们。它尚未给出完整语言生命体：9状态世界不满足24状态身体的既有丰富度要求；当前粗粒介质仍为单位置全边界，空间共享尚待建立。L1–L6的完整证书、可扩展的生成规则和真实语言学习继续是待完成目标。

当前动作是保留这个统一参考作为共同检验对象，冻结各分支独立扩张。下一项机制只有在明确对应到这个共同过程、或说明为何必须改变它之后才推进；泛化到语言时须重新验收有用历史、可塑更新和行动—维持闭环，不能复制有限状态数或扩大表格代替推导。

`ReferenceRun` 保存完整概率分布、精确分数和观察历史，是验证工作区。它们不是身体免费获得的状态，也不是低资源生产训练算法。确定性数值/接口检查不作人工任务上的能力实验，本轮没有训练。
