# 统一有限过程、参数化扩展与原生字节接入

共同参考是既有 `SensoryMaintenance.process`：身体、行动、世界后果、付费学习、持续维持和物料来源使用同一个状态更新与同一世界拍。本轮将它推广为参数化有限族，并检查向原生字节流接入时必须补足的统计区别与资源接口。没有新增生产 Lean 模块。本记录不替代语言生命体活规格。

## 一个主实例，而不是把历代状态空间相乘

| 原有工作 | 在统一模型中的位置 | 可沿用的范围 |
|---|---|---|
| ActiveMaintenance、LearningMaintenance | 早期构造与推导历史 | 它们改过身体、刺激和规则，没有整体等价证书；不直接搬用结论 |
| RenewableLearning | 最终版本的候选记忆、行动策略、改写信用、冲突重开与补给 | 复用原 `Cell`、`policy` 和 `next true true` 的实际规则 |
| GraceRecovery | 同一身体所处的后果世界 | 采用修订后的冲突反馈与三拍恢复窗口；不沿用旧世界的两拍恢复结论 |
| SensoryMaintenance | 唯一主身体：结构细胞 × 维持储备 | 同时承载付费改写、实际摄入/释放、感官失联扣费与空态吸收 |
| Recovery、Limits、Closure | 同一过程的观察与干预 | 自然存活、一拍耐受、长失联失败及自身边缘幽灵剪断分别验收 |
| SensoryMaintenanceCarrier | 同一过程的固定身份物料实现 | 定时精化保持投影、首次摄入概率与评分；再充能工作沿实际摄入计费 |
| PortSeparation、PortContracts | 对输入的扩张及其局部合同 | `legacy_rules` 对应原规则；独立感官/资源新协议的完整精化仍待建立 |
| 代数、同调、因果状态与语言核 | 可复用的表示/分析工具 | 按需要使用，不把每个工具变成新的身体状态或功能模块 |

## 同一拍怎样更新

原实例的身体是 `Cell × Fin 3`，共24种形式状态，世界有9种状态。`FiniteFamily(n,R)` 将两种情境推广到 `n≥2`，将储备上限推广到 `R≥0`；身体状态数为 `(2+3n)(R+1)`，世界状态数为 `4n+1`。控制规则仍是同一规则：探测、候选行动、失配重开、付费记忆与实际补给。`n=2,R=2` 精确恢复原实例。`n=1` 不属于这个歧义搜索族：唯一候选已经足以选择行动，不能沿用“未知即探测”的语义。

给定旧状态 `(身体, 世界)`：

1. 世界给出本拍信号；失联协议只遮蔽信号，世界拍继续。
2. 身体按旧信号更新记忆与储备，同时登记摄入、释放、改写、补入信用和毁损信用。
3. 世界按旧身体行动产生后果。步骤2和3共享旧状态，不能提前把新世界信号送入身体。
4. 两组固定物料身份同步从旧库存搬运。刚释放的身份不能在同一拍再用于补源。

闭环的关键是原规则中的因果接续：记忆选择行动；行动影响下一世界状态；失配后果触发付费重开；后续探测消耗信用写入新候选；实际食物补回维持与改写资源。世界条件与支持表仍是明确选择，并非六公理已经强制的唯一形式。增大 `n` 不等于增加语言理解能力。

物料仍由两组旧库存搬运：结构缓冲宽度4，储备缓冲宽度 `max(4,R)`，固定身份数为 `12+3 max(4,R)`，来源库存为 `4+max(4,R)`。默认仍是24身份、8单位来源。`R>4` 时扩大载体的成本明确计入；既有24身份 Lean 证书只用于默认实例。

## 从有限排除到字节统计：推导与实现分开

既有 `CausalLearning.advance` 根据“不可能的观测”排除候选。若所有候选都给所有字节正概率，支持表恒为真，`agreement_no_write` 直接给出记忆不变、写费为零。审查文件将这一结论专门实例化到 `Fin 256`。这解释了为什么扩大候选数仍不足以接入一般语言流。

给定一个已登记的联合核，`Interaction.Machine.conditioned_next` 已证明正质量观测下的条件分布唯一。若旧统计编码为 `c_h/M`，候选对字节的似然为 `l_h(b)/D`，则：

`p(b)=Σ_h c_h l_h(b)/(M D)`，`post(h|b)=c_h l_h(b)/Σ_j c_j l_j(b)`。

这里推出的是**给定核的条件化形式**；核的生成、局部实现与可塑性规律仍须推导。`ByteFrame` 是数学参考，采用全局归一化，不能作为满足 P1b 的介质运行规则。[生成链](CGB_GENERATION_LAYER1_20261025.md)第三层提出的快边界条件分布及局部可塑实现，仍需时标与有限时间混合的验收。本参考可用于核对其观测语义，不以全局计算替换局部动力学。

为检查有限整数表示，参考接口登记一种投影：先向下取整，再按最大余数补足到 `M` 票，余数相同时按索引决定。它不是公理推出的唯一编码。每个候选占1字节，`1≤M≤255`；似然表为每候选256个 uint16，共 `512H` 字节，所有行严格正且总和相同 `D≤32767`。表的数据与生成计算不免费；工作区、Python对象与环境档案另计。`M²D≤255²×32767<2³¹`，只证明投影中指定乘积可用有符号 INT32，并未实现 GPU 核或证明速度优势。

最大余数投影保总票数，单步 TV 误差至多 `H/(2M)`（纸面推导：每项误差小于 `1/M`，再求半个绝对值和；数值检查及 Lean 算法向量对拍已做）。该界相对于**已量化旧状态**的精确下一步后验，不是任意长历史的误差界。反例：真实先验 `(0.004,0.996)` 在100票下可能变成 `(0,100)`；似然比10000:1时，真实首候选后验超过97%，整数状态却无法恢复它。因此不宣称无限流无损；重新开放被删除的区别需要生成动力学给出依据，不能暗加平滑补丁。

## 字节更新与维持共用一份预算

`byte_step` 冻结并验证旧预测帧，再让 `PrefixReplayWorld` 发布一个原生字节；用旧帧评分，完整构造后验候选，然后从世界的**同一份储备**支付改写费，支付成功才提交。概率票数不充当物料，也没有第二份学习信用。当前登记费率是编码变化的比特数，属于操作成本合同；推断计算、账本维护与实际焦耳成本尚未标定。

余额不足则保留旧记忆；维护失败后世界继续发布，跳过模型推断和投影，由评估方记录均匀分布回退。世界检查点升为v2；严格的v1旧字段可迁移并补记零写费，这只表示旧世界未收此费。恢复同时检查余额与首次发布前不得发生写费。

这条端口验收的是付费统计接线。它尚没有到有限身体的联合状态精化，没有把字节后验变成已证安全行动，也没有自动继承 `firstHit` 存活结论。给定似然表不是生成语言脑；下一步必须用实际局部规则填上这个位置。

## 条件分布怎样经局部跳转实现

最新生成链提出由快边界的 Gibbs 条件分布给出预测。这里必须同时固定**能量、允许的状态与读出**。若字节边界恰有一个粒子、每个标签对应一个微态，登记正权重 `w_b` 后，目标分布为 `π_b=w_b/Z`。若边界是独立二值占据，同样的权重 `(1,3)` 给出归一化平均电荷 `(2/5,3/5)`，并非单粒子的 `(1/4,3/4)`。因此 softmax 不是仅由双线性能量就强制的形式；互斥标签条件是显式选择。

`BoundaryKernel` 给出一个可执行的条件实现：每拍只提议一次标签 `j`（在全部标签中均匀选取，含当前位置），读取当前位置 `i` 与 `j` 的两个 uint16 权重；从 `0..w_i−1` 均匀取票 `u`，当 `u<min(w_i,w_j)` 时迁移，否则停留。运行时不计算 `Z`，对于登记整数权重没有舍入误差。每次合法尝试都支付同一笔 `attempt_fee`，拒绝与原地提议也付费、也占拍。权重表占 `2B` 字节，位置在 `B≤256` 时可编码为1字节；Python对象、环境账本与随机源另计。精确随机票据是登记的外部随机原语；若硬件用拒绝采样生成票据，不能把“一次逻辑提议”误说成严格固定硬件时长。

两个读取位置须属于同一个允许的团，权重在该次尝试中冻结；这验证了条件帧内的两点读取，不代表 LG-1 跨隔室的全场已局部生成。该接受率选择一种允许的对称导通，不是公理唯一迫出的速率。`tick` 驱动器每次只发布一个字节、尝试一次，返回发布前的旧样本标签，随后从世界同一份储备付费并形成下一拍样本；拒付时保持原位置。失活时继续发布，旧位置不再记为身体预测。若资金不足，不能继续套用已付费核的混合速度。

对完整付费核 `K`：

`π_i K_ij = min(w_i,w_j)/(B Z)`（非对角项），故满足详细平衡。接受率的通用加权平衡等式及下述界的标量核心已在审查文件中经 Lean 证明；完整矩阵参考与 Python 跳转还做了对拍。

令 `α=Z/(B max_b w_b)`，则包括对角项在内都有 `K_ij≥απ_j`。当 `α<1` 时，`K=α1π+(1−α)R`，`R` 仍是保持 π 的随机核；`α=1` 时 `K=1π`，一步精确混合。由随机核的 TV 非扩张，固定帧的有限次付费尝试满足：

`TV(μK^k,π) ≤ (1−α)^k TV(μ,π)`。

这是纸面收缩推导，标量不等式已由 Lean 检查，完整有限行已数值验界。无需给身体读取 `Z` 或最大权重；这些是观察方的验界量。对登记的**外源冻结帧序列**，还得到 `e_(t+1)≤(1−α_t)e_t+TV(π_t,π_(t+1))`。若权重与边界粒子相互反馈，须先建立联合状态/条件分布的证书，不能直接套用无条件边缘递推。

有限时间差异确实可能很大：256标签、权重 `(65535,1,…,1)`，从一个低权重位置出发，一次提议后的实际分布为均匀分布；它与目标的 TV 距离超过0.99。因此一个位置只代表一个样本，不能把理想平衡目标的 bits/byte 当成有限拍输出已取得的性能。世界每拍有新输入时，也不能在两个输入之间偷偷补足任意多次免费混合。

这还约束学习精度：固定历史特征与目标，用自由相样本 `Y∼μ` 替代理想分布 π，局部更新 `η p_i (onehot(byte)−onehot(Y))` 的期望与理想 delta 更新的单行 L1 差为 `2η|p_i| TV(μ,π)`。样本方差另计；此式并未证明整个可塑动力学。下一接线义务是从实际局部状态产生这份条件场，并对内生反馈给出联合误差及资源合同。

## 已实际核对什么

- 从原 Lean 定义导出192组身体输入的转移、行动、含量和五类端口。
- 在审查文件中证明整数世界权重精确表示原 `GraceRecovery.moves`，再核对648个概率条目。同一文件还把自然全时存活、一拍耐受、剪断上界和两拍耐受否证组合为同一身体—世界对象的联合证明。
- 穷举1,728组完整身体—世界状态与输入，核对 Python 的实际一步组合；不是仅分别测试两段函数。
- 核对两组12身份载体的384组分量收支与旧库存搬运，总计24个固定身份。可执行选择采用最小旧身份，满足同一搬运合同；不声称等于 Lean `Classical.choose` 的逐身份选择。
- 剪断分支严格使用它自身联合分布的身体边缘；分段继续运行与直接运行相等。协议非法时本拍状态、核和账本均不提交。
- 同一核中有一条概率为1/8的 A→B→A 再学习路径：13拍共5次付费改写、补入6单位信用；摄入20、释放18，身体含量从4到6。来源库存保持8，再充能工作20，满足 `6 + 8 + 18 = 12 + 20`。这是一条支持路径，不是典型行为或能力统计。
- 精确复算自然过程、一拍/三拍失联及剪断评分。两拍失联从第2拍开始时，第3拍存活评分为1/2；失败分支仍有非空身体，但未来三拍摄入概率为0。这与已有两拍耐受否证相容。

所有数值核对是实现与语义验证。自然过程的全时结论等仍由已有 Lean 证书承担，有限检查没有替代无限时间量词。

扩展验收覆盖 `n∈{2,3,7,16,256}`、`R∈{0,1,2,5}`：前四种情境数穷举局部状态/输入，256情境检查代表细胞的全部信号与世界行；核对物料、信用与旧库存搬运。参数族的全时存活尚未证明。整数参考还核对归一、舍入误差、拒付、失活后的持续输入、真实JSON恢复以及非法快照的原子拒绝。旧世界接口用经校验的 OWT 原生字节再次验收64拍正常/断资源路径；其中更新次数为零，不能用其预测分数论证能力。

## 统一以后还缺什么

该参考把多项性质放回了同一个对象，可以用于检验下一条生成规律是否保住它们。它尚未给出完整语言生命体：9状态世界不满足24状态身体的既有丰富度要求；当前粗粒介质仍为单位置全边界，空间共享尚待建立。L1–L6的完整证书、可扩展的生成规则和真实语言学习继续是待完成目标。

下一动作是沿生成链落实**局部边界条件化与可塑更新**，建立与资源、行动后果的联合投影，再在真实语言上验收。进入训练的条件是实际规则、局部性、代价与状态续接已明确；若联合投影失败，先定位缺少的状态或规则前提。这样共同参考才能约束语言个体，而非只给它附上几个通过的局部检查。

`ReferenceRun` 保存完整概率分布、精确分数和观察历史，是验证工作区。它们不是身体免费获得的状态，也不是低资源生产训练算法。确定性数值/接口检查不作人工任务上的能力实验，本轮没有训练。
