# DPM/APL 到 KC 轴突输出：接线与验收边界

本轮把旧的“双侧活动平均值→全局阈值/遗忘率”扩展隔离，接入实际
DPM/APL 细胞、实际 KC 靶细胞及连边延迟。完整主线32384保持暂停，
在32936候选的完整副本上继续；不重新出生，不更改妈妈教法或设置发言配额。
本轮最终数值和验收结果以 `results/published/fly_native_mb_terminal_20261018.json` 为准。

## 实际缺口

`modulatory_neurons.feather` 把 DPM 预测成 dopamine，但实际 r2 模拟图的
`edge_pre_i/post_i` 已把它作为 GABA。不能根据预测表或旧的合并边列表，
声称 DPM 原来没有快抑制或被错送到多巴胺通道。

原图保留的胞体/树突 GABA 路径继续工作。本轮补的是：被
`kc_dendritic_only` 隔在胞体计算之外的已测轴突份额，以及遗漏的 DPM
5-HT 末梢递送。没有重新打开原先被定位规则禁止的快边。

## 接入的路径

| 项目 | 本轮实现 |
|---|---|
| 实际源细胞 | DPM11734、DPM12569；APL10540、APL10977 |
| 实际靶细胞 | 原图4064个KC，各自保留身份 |
| GABA | 8714个已测非零轴突接触，逐源/逐靶保留，使用原COBA衰减核 |
| DPM5-HT | 4082个实际DPM→KC接触，逐源浓度、逐KC受体占据 |
| 延迟 | 原图1–4拍释放环，实际源释放到达后才改变输出 |
| 输出 | 抑制KC新产生的轴突释放包，只作用一次；旧在途包保持原值 |
| 下游 | 实际KC释放进入已有KC→MBON、KC→DAN及其他下游连边 |
| 可学习量 | 逐KC的GABA/5-HT增益，DPM清除时间、受体亲和力及恢复时间 |
| 连续性 | 新化学状态跨窗口保存，模型身份/优化器/世界队列/RNG完整恢复 |

增益符号遵守这里采用的抑制效应约束；时间常数可学习，没有把生物毫秒
设成信息世界的寿命上限。5-HT接触强度按实际DPM靶分布归一化，浓度单位
是模型单位，不能解释成测得的绝对生物浓度。

旧DPM/APL参数、优化器历史和物理痕迹保留为档案；旧全局规则失效。
尚未结算信用中的旧代理导数单独存档，其他信用、未完成回复和世界经历
不删除。禁用新通路的配对对照也保持旧规则隔离，以免把两种机制混在一起。

## 统一验收

1. 数值/接口检查：源与靶的身份、延迟、轴突/树突份额、原COBA核、只门控
   一次、STP未释放资源守恒、梯度和重算一致、完整状态与旧信用保存。
2. 从同一完整状态继续已有妈妈队列，使用实际感觉时钟和真实学习器，
   记录更新前预测、参数更新和实际化学状态，不把短段当能力实验。
3. 当前存档统一矩阵：完整、sham、恢复，以及全部MB末梢/GABA/DPM5-HT
   分别关闭；与其他已接系统共用实际时钟、状态、输入、感觉采样和RNG控制。
4. 再次通过真实训练器恢复完整状态。活动、急性下游影响与长期学习收益分开。

运行时遇到内存不足，未提交的窗口不算新经历。已完整保存的窗口作为续点。
普通执行和更小的拍内重算片段用于降低峰值；不缩短实际世界时间或BPTT窗口。
具体成功/失败执行、环境和保存点记录在本轮报告，不能把第一次短窗口成功
直接推广成全部长窗口可运行。

## 仍缺什么

- 当前每个KC只有一个轴突输出变量。APL单细胞内部的局部非脉冲电缆动力学、
  单个KC bouton的空间场仍未重建；逐细胞接触路由不能冒充这些空间机制。
- DPM肽类、其他靶细胞、自受体、不同受体亚型/效应器及胞外扩散尚未完整接入。
- 新慢状态会跨窗保留；新动力学参数的精确跨窗前向敏感度尚未实现。
  开启旧STP解析跨窗信用时会明确拒绝这项组合，避免悄悄使用错误导数；
  窗内STP和未释放资源守恒已检查，当前实际候选STP关闭。
- 选择性熟悉化、记忆巩固、实际选词/时机后果的持续学习收益及探索，需要
  后续真实交流证据。本轮化学送达或急性变化不等于这些能力已完成。
