## 4. 什么时候接行动，以及接什么

只需现有同一实例同时给出以下证据：真实语言学习可复现；记忆在后续预测中实际使用；转场后仍能改学而不是僵死；整套持久状态资源有界且能恢复；新增存取路径的成本与收益已记录。原组合已有前三项的部分证据，尚需独立评估和完整资源/恢复核对。必要的实现检查可以立即做，不等待全库再分类。

随后把**同一读出产生的动作→真实改变后续可达语言→结果进入同一状态并继续学习**接起来。先核对现有语言世界合同与自举/生态位联合定理的实际前提，复用当前模型；不再另造行动脑、食物币或维生余额。环境可沉默，个体仍演化；自听可用，但不自动计作新增外界信息。

锁存的后续检验对象改为**需要持续保持又能切换的当前内态**：例如当前任务承诺、工作记忆和行动参照。它是否必要、在哪些状态中形成，应由实际交互中的条件决定；不预先硬塞“自我模块”或给某个头贴身份标签。用户的自我相关解释是值得验证的机制假设，不是已经证明的普遍生物规律。已有模式任务可帮助检查保持/释放，不能代替行动闭环或升级为新的训练前置门。
