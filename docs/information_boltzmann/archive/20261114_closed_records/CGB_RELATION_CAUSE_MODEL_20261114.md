## 1. 本次增加的信息

问题定位在**新增的局部关系残差层**：它把最多8条不同情境的真实经历，重新拟合成条件/动作各64维的局部机制。条件一侧已经足以解释这8条记录，记录不能单独确定动作一侧的系数。当前岭先验选择了一个解；它选择的动作作用不能等同于经历已经辨认出的动作作用。

本轮给出了当前真实矩阵上的直接见证：存在两套关系算子，对全部8条旧证据的预测变化均小于4.1e-16，而对当前两个候选的第0维后果差分别为−1和+1。因而“历史拟合不错”与“当前该如何行动”之间，确实缺了一项结构约束。

这不是再次发现可以检索旧内容，也不是宣布整个身体没有自我模型。原共享神经预测器一直以source/action为条件、持续训练。本次查的是新增关系修正如何解释和使用已取回的证据。

此前2026-11-09地址谱文档已指出高维小样本的不可识别方向；11-10统一框架已要求跨关系共享的机制基底。本次新增的是**现行妈妈世界关系执行器的解析复现、真实算子见证及整条预演路径上的干预**，不是把上述旧认识重新命名。

## 2. 生产代码对应的最小模型

生产入口：`causal_relation_program.role_features/posterior/mechanism`。

设z为当前编码的情境、d为自听行动导致的变化：

\[
x=\frac{[z,d]}{\sqrt{\|z\|^2+\|d\|^2}},\quad
Y_i=E(o_i)-f_\theta(z_i,a_i),\quad
\hat o(q)=f_\theta(q)+qX^\top(XX^\top+\lambda I)^{-1}Y.
\]

最多8条事实，X为8×128，Y为8×64。均值解自身秩至多8；问题不是它有没有名义上的低秩，而是**它没有文档要求的、跨关系学得并共享的机制基底**。局部高维先验仍允许128个输入方向。

拆开X=[C,D]。若rank(C)=n，则对任意动作系数B_D都能找到

\[
B_C=C^+(Y-DB_D),\qquad CB_C+DB_D=Y.
\]

所以情境能独自解释全部旧记录，旧记录也能兼容完全不同的动作作用。岭惩罚提供一种偏好，但没有补进区分这些机制的新证据或已学共享约束。

数值见证采用X的零空间。若Xv=0，则B与B+vwᵀ在所有历史输入上预测一致；当前候选差δq若满足δq·v≠0，二者对当前行动差异的预测便不同。这是现行矩阵的实际算子构造，不是对任意神经网络笼统说“总有很多模型”。

## 3. 四个可直接运行的复现

复现调用生产`posterior`，不训练模型，不以合成题代替能力验收。

1. **因果欠定及正对照。** 旧观察只有c=a时，“后果=2c”和“后果=2a”完全相同；改动作到a=−1而保持c=1，两者分别预测+2与−2。换成同一条件下交叉观察两个动作，原样的生产求解器给出−.97561、+.97561，能够恢复动作方向。区别来自约束，不来自扩大网络或延长无信息重复。
2. **共同偏差被误读成动作效应。** 8条完全相同且无动作效应的证据，生产整体归一化让两个候选预测为.987654、.698377；两者差−.289277。原因是动作幅度改变了条件块的归一化尺度。仅固定查询条件块尺度，两个预测就相等。此干预是解释性拆分，不是已批准的修复算法。
3. **残差为零仍有先验噪声。** 8条残差全为0，生产公式仍得到noise=.2，两个查询的预测scale²为.22469和1.21235。该下限来自每次局部求解使用的InvGamma(1,1)，并非世界观测出的噪声。
4. **纠正上一轮评分解释。** 两个预测0、−1，真实后果1；共同加上2.5后，候选平均MSE从2.5降到1.25，实际动作的排序优势从+3变−2，但两候选的预测差始终是−1。故同一事实目标上的排序变差，不能单独证明动作表征被抹掉。上轮23组的分数仍正确，其因果解释应收窄。

## 6. 对大环的解释与下一次改造边界

水保留了真实证据，土和原共享预测器一直能学习；新增局部关系却没有从这些事实中独立确定动作作用。木用它推演时，主要得到情境偏差的修正及先验主导的不确定性；火接收的候选价值差仍小；金结算后，又把一条新事实放回同一个固定小样本局部拟合。因此单独增大表、调增益、缩噪声或延长同配方训练，都没有补上当前缺失的机制约束。
