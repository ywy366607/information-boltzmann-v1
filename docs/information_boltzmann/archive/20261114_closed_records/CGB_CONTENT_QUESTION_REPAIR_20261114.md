## 同一条件转移，整圈交付

在已有经历注入层之前：

`h' = h + RMS(h) * tanh(Aq) + Bq`。

此处RMS(h)指逐位置按通道归一化的h。A/B同属一个无偏置线性投影，随后仍是原GDN的内容相关Q/K/V、遗忘/写入门、S更新、后层与语言头。没有新增编码器、递推状态、问句类别或奖励。原Wq保留，避免删除已学参数及Adam；它只直接影响预测自己的话。

唯一作用域合同：输入0是上轮pending；输入own是最后一个自听字节，own=0时是沉默的准备边界；它们可带q进入S。其后的输入是世界实际字节，不再直接注入q。输出0..own-1预测自己的话；输出own已经预测妈妈首字节，不能再加Wq。妈妈仍可通过真实自听后的S感知本体意图，状态不重置。

整圈必须同时兑现：持存未知/关系生成q → 原多草稿在同q下演练 → 木预演选择 → 原火说出并自听 → 首段真实学习重放同一条件前缀 → 实际妈妈/环境后果与原金结算 → 同一水库U及原后到策略信用。输入作用域在objective返回后恢复，策略重放仍按完整草稿条件；留出续文无直接q。原S/P捕获的是实际经过条件和经历读出的层输入。
