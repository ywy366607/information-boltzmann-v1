# 痕迹、支持捕获与空间沉积：同一局部交换的扩展

2026-10-22，继承`e5b75bb`，回退标签`cgb-before-trace-growth-20261022`。遵循主规划§2.3、§4–§6及Claude E5/E6/E9：先把活动痕迹／支持捕获接入同一收支，再让局部沉积／拆解产生空间占据。这里声明具体材料本构，区分其从守恒推导的部分及尚须识别的参数；不用生物名称作为必要元件。

## 1. 痕迹必须有物理状态与反作用

每个接触保留有限二态载体r∈[0,A]。r是已转化态，A−r是未转化态；载体总数A固定。联合能量增加

    U_r=Σ(e_r r−χ r C)，χ≥0。

C为原有结合支持。状态自由能另有二态混合项r ln r+(A−r)ln(A−r)−A ln A。相互作用来自声明的短程结合能：痕迹降低支持结合能，结合支持也降低痕迹能量；不能只写一边的促进。

一次带痕迹的有源事件：P_pre+(A−r)→D_pre+r，同时从pre向post转移z荷量。联合亲和力为

    A_write=eP−e_r+χC+z(V_pre−V_post)
            +ln[P_pre(A−r)/(D_pre r)]。

沿已验证的有限尝试率材料，正反通量取k_w n P_pre(A−r) sigmoid(a)及k_w n D_pre r sigmoid(−a)，其中a是不含混合对数的能量部分。它是实际传输的一个带存储通道；池不足或载体满时不能继续写，不从NLL领取功。反向事件也能擦除痕迹并恢复P。

另有热交换r↔A−r，其正反比由e_r−χC决定。冻结C时总恢复率为k_r，故有精确有限时间解；这是有限寿命的物理记忆，不是把观测流量塞入EMA。痕迹寿命、结合能与载体数属于材料参数，热力学只约束相应正反比。

## 2. 捕获、通道与结构仍在同一账里

- 原F+S↔C的结合能改为eC−χr；原C+P↔H+S+D的反向率也必须随同改变。只改捕获端会破坏同一自由能。
- 原结构合成B+U+P↔S+D不改计量。支持占据减少可拆解的空闲安装态，故痕迹经支持捕获改变周转，不另加λ(r)保护规则。
- 对处于两种局部配置的通道群，平均尝试率／被动导通为各配置的数量加权和：g0 n[(1−r/A)g_low+(r/A)g_high]。共同改变正反尝试率而不改其亲和力；配置转换自身的能量已计入。此式声明快混合的有效通道群假设，不从守恒唯一推出所有电导材料。
- 新增状态、储能、混合熵和转移荷量完整保存。无输入时痕迹可松弛；有绑定支持时能改变驻留时间。功能价值仍由真实后果检验，不用“痕迹多”代替学习成功。

## 3. 空间扩展的共同物理对象

空间生长采用有限局部位置与实际邻接，在相邻空间单元间输运材料；结构由占据／空位的同一合成、拆解反应形成。界面速度来自净材料通量除以结构密度。允许多个空间位置同时增长，分叉数不作为输入。

空间离散是执行分辨率，局部结合能、表面能和可用底物决定事件偏置；不能用成年质心目标或随机分叉概率规定形状。接触机会从生成的空间共占／相邻几何导出，再调用已验证的有向身份匹配规则。完整非线性形态与尺度收敛另行报告，不把单次形成分支当作果蝇形态复现。

### 3.1 本轮空间材料的具体闭合

使用三维等体积网格；节点是材料池所在的空间单元，邻接键是可沉积材料的空间单元，均不是预先指定的神经元／成年神经突。n_e∈[0,K_e]为局部结构体积分数，原支持占据C_e≤n_e、痕迹及驱动态继续使用。网格和种子是初始／边界条件，不输入目标质心、分枝方向或分叉数。

短程同质结合能取

    U_coh=−J Σ_{相邻空间键e<f} n_e n_f。

相邻指共享一个物理网格端点，位置来自实际坐标。原结构能e_n与相邻结合共同给出体相与缺邻界面的代价；不再另加一份表面能。装入e的实际结构能为e_n^eff=e_n−JΣ_{f~e}n_f。因此同一个B+U+P↔S+D事件的正反比用e_n^eff替代e_n即可；J是指定材料的短程结合常数，不是为了分叉手编的方向力场。

邻近已有材料可提供表面催化通道，有限尝试因子选k_e=k_n[k_bulk+k_surfaceΣ_{f~e}n_f]。这是独立本底通道加上每份邻近材料提供同等催化机会的质量作用极限；共同乘正、反两率，不改变平衡偏置。k_bulk>0保留体相成核与消解，避免无邻居碎片被执行规则变成永生。仍需用具体材料识别系数，守恒不唯一决定它们。

结构变化仍实际扣B、P并回收D。F、B、P、D在相邻空间池间以有限扩散率输运，使用守恒的成对有限时间混合；同种组分两端能量相同，理想混合自由能下降，另记输运账。r、C和n锚定，不给它们伪造扩散。

空间n按体积分数决定导通截面积，故固定单元长度时并联G∝n。几何界面用多个n水平集测量，不能同时又声称n是固定截面细缆线的长度；界面运动的材料速度仍来自净沉积／密度。新的空间接触机会可从材料场实际相邻位置导出；把这些材料域分化为多个带谱系身份的细胞、再对细胞接触调用V3d，是紧随其后的独立步骤，不把网格端点冒充3000种细胞。

空间首轮预先比较同一9³网格、中心6键种子、均匀B=0.8/P=0.8/D=0.2/F=0.1的四臂：J=0/0.6，与材料扩散D_B=0.005/0.1；其余局部率相同。K=1，种子n=0.8，e_n=2，k_n=0.05，k_bulk=0.001，k_surface=2；驱动／支持扩散率各为D_B/2。步长2ms、总256参考ms；真实书架字节经8个固定边界端口进入，字节间隔4ms。记录全部四臂及0.1/0.3/0.5水平集，未形成分支就如实报告。后续分辨率细化是独立验收，不凭一个网格给连续形态结论。

本轮空间定位实验把普通有源泵与电场↔P/D换能率设0，保留带痕迹传输率0.0005、热恢复率0.001，专门检查有限初始驱动／材料如何形成空间占据；其他捕获率沿用痕迹子核。完整空间类仍支持前述全部通路，默认闭合检查覆盖它们。外部8端口接中心空间节点、6个最近邻及一个面内对角邻居，这些是输入硬件位置，不是生长目标。该实验没有持续驱动池补给，不能由此宣称长期可存活。

## 4. 本轮验收与失败出口

1. 所有新事件的正反比与独立自由能有限差分一致；材料／支持／驱动／痕迹载体／电荷收支、功热及无源自由能检查通过。
2. 痕迹写入确由有源事件和有限池支付；χ=0切断痕迹到支持的通路，通道两态速率相同时切断痕迹到通道的通路；零新增速率可恢复父模型。
3. 同状态／同输入的痕迹写入、结合能耦合和通道耦合对照，区分实现交付与结构选择性；独立ODE、步长细化及完整恢复必须通过。
4. 在保留真实图和实际书架文本的副本上运行局部改造，报告源功、状态大小、壁钟与每项效果；不把接口预算当作语言能力研究。
