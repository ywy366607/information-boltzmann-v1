# 生成第一个个体：预注册（2026-10-26，搜索开始前写定）

**用户要求**：大肠杆菌应当作为体系的推论存在，而不是人为设定。人工版本 `ecoli_v1` 的每个页、每条规则、每个常数都由 Claude 按生物学选定，只能作对照。

## 1. 什么是固定的（世界接口，不属于个体）

- **食物页 F**（边界）：世界给出食物储库的化学势。本拍有摄入时 μ = +6，否则 μ = −6。食物是高势物质，有食物时可以吸入，没有食物时储库就成了汇。
- **到达页 A**（边界）：本拍是旅行拍时 μ = +6，否则 μ = −6。这是世界提供的感觉；个体可以不用它。
- **马达页 M**（边界）：只有 **1** 个单元，世界读它的状态，1 表示换源。储库势恒为 0。
- 平衡环境下所有势为 0（M2 的 P2b 条件）。
- 世界与此前完全相同：3 个源，p 为 0.9 / 0.1，hazard 0.005，cost 0.6，储备 150。

## 2. 搜索什么（个体，全部由选择决定）

- 内部页数 0–3，各页单元数 1–16；F 与 A 的单元数 1–4。
- 每个页、每个状态的能量 φ ∈ [−4, 4]。
- 规则表：至多 12 条可逆双单元转移 (i, j, a, b, log κ)。i、j 取任意页，a ≠ b。
- 唯一的约束来自公理：两端都是内部页的规则必须守恒含量（M3）。满足它的表自动在 Lean 中证明满足全部公理，由生成器生成实例。
- 选择：适应度 = 在 4 个种子上的平均存活拍数（上限 3000）；平手时比较摄入率。种群 48，精英保留，变异包括改规则、增删规则、改能量、改单元数。
- 模拟：精确的按计数归并的 Gillespie（numba 实现，与 `cgb_table_medium.LumpedSim` 同一规则）。世界轨迹按种子预先生成，所有基因组经历同一段历史。

## 3. 预言（来自已证定理，写在搜索之前）

| 编号 | 预言 | 来源 |
|---|---|---|
| P1 | 胜出者有一个内部页，其占据量跟踪连续漏吃次数（Spearman ρ > 0.5），并在吃到时下降 | G11、G12 |
| P2 | 换源概率随漏吃次数呈阈值形：P(换 \| 0 次) < 0.05，且 P(换 \| 3 次) > 3·P(换 \| 1 次) | G12（跨阈值合并会吃亏），`merging_across_threshold_loses` |
| P3 | 吃到食物时存在持续的非平衡流：令牌从 F 进入，再经边界排出（通量 > 0） | G16、M2 修正 |
| P4 | 致盲对照（F 的势固定为 −6）存活接近随机 | P3、G9 |
| P5 | 切环对照（世界按个体自身的换源率随机换源）的存活显著下降 | SelfMaintains |

## 4. 失败的出口

- **存活良好，但 P1 或 P2 不成立**：要么世界允许别的解（例如随机换源已经足够），要么推导有误。届时检查胜出者实际用了什么，再对照定理的前提。
- **搜不出能活的个体**：先检查搜索能力（种群、代数、变异），再看接口是否给了足够的驱动。
- **胜出者用了 A 页、没用计数**：说明"到达即重置"是计数器的一部分（G12 的计数器本来就在到达时清零），不算失败。
