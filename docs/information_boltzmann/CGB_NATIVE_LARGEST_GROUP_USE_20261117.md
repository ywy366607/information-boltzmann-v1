随机对照从同一253关系群抽取1501项引用，逐端口数量完全相同，固定随机种子2401。它同样是强撤回，目的是比较两种同规模破坏，而非充当完全无作用的安慰剂。选择使用起点结构，不使用分支后果。

两条分支都允许原选择、登记、共享及学习重新形成连接；没有持续钳制删除。没有引用的关系仍沿原代码读取自身经历，因此本实验测的是**共享连接撤回**。实际事实交付、后续学习与动作另行追踪。

## 3. 变化起点：事实排列与有限预演

首轮关系213的实际8条MOTHER事实集合相同，排列由：

```
正常：203, 1133, 1616, 1919, 1977, 2216, 267, 283
撤回：203, 283, 267, 1133, 1616, 1919, 1977, 2216
```

变成原行号置换 `[0,7,6,1,2,3,4,5]`。实际X、Y在这个行置换后逐位相同，查询逐位相同。原后验公式为

\[
K=XX^T+\lambda I,\quad C=K^{-1}Y,\quad m=qX^T C.
\]

同一实际数据FP64重算的均值置换误差1.42e−14、解系数置换误差4.97e−14；实际FP32均值与noise的最大差均2.86e−6。**但原内部第一份想象回应的最大坐标差为0.104737，相对L2差4.55%。**

原因在原 `mechanism_hypotheses`：固定 `observation_directions[:, :len(x)]` 按行位置配给事实。原先验方向W、观测方向E的条件化使用

\[
L=XW+E,\qquad W'=W-X^T K^{-1}L.
\]

X→PX时，为保持同一次有限样本身份，E应一起变成PE。原代码仍使用同一个位置E，所以同一个后验分布的具体有限预演样本会改变。Lean的 `NativeLargestGroupFactOrder.lean` 核对实际8行置换，并证明均值置换和条件化噪声的相容公式；实际输入则按原日志张量独立重算。

此处还存在另一条排列入口：原提问候选由事实对应的行动变化依次构造，再受topk预算截断。故“只改事实排列”的整圈对照必须走共享事实视图，使预测、组织和提案同时消费同一视图，而不是只改预测器的矩阵行。
