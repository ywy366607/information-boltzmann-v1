# APL局部电位、钙与释放资源的连续通路

本轮在已有APL全空间被动电缆上接入局部释放链：实际突触输入→局部膜电位→电位依赖钙入口→局部钙积累/清除→可用囊泡消耗/补充→原有延迟GABA接触→KC及其释放/学习。没有添加新的解剖边、语言输出头、发言率要求或外部奖励。

## 生物依据和实现边界

APL是非脉冲型局部抑制神经元；局部钙活动与对KC的抑制具有空间局限性。[Amin等，2020](https://pmc.ncbi.nlm.nih.gov/articles/PMC7541083/)。刺激引起APL细胞内钙升高及递质释放已有实验观察，[Liu与Davis，2009](https://pmc.ncbi.nlm.nih.gov/articles/PMC2680707/)。这些支持局部电位—钙—GABA通路，不能据此声称某个通道亚型、钙泵速率或囊泡分子步骤已被确定。

保留全部88905个已有形态节点、实际接触和物理延迟。节点上的钙入口/清除使用可学习正动力学，钙和资源为归一化有效变量；不是实测molar钙、已识别VGCC通道或分子priming重建。APL不被硬改为Na/K动作电位细胞；KC/DAN的主动轴突通道仍是后续缺口。

## 生成关系

现有局部去极化记作u≥0；入口门的目标为u/(u+K)，门和钙各自按可学习衰减率持续更新。钙决定释放概率p=1−exp(−kC)，释放量q=xp，其中x为可用资源。剩余量x−q随后按可学习速率向可用池恢复，因此0≤q≤x、0≤x_next≤1；释放消耗与补充来自同一资源账目。发出的包沿原来的四拍队列推进，已经发出的历史包不被重写。

每个APL细胞有5个新增可学习量，共10个参数。门、钙、资源各有一个逐节点状态，新增1066860字节（约1.02 MiB）。入口、清除与恢复的初始时间尺度是模型tick中的初始化选择，可以继续学习；不作为果蝇生理标定值，也不改变世界输入时钟。

新参数进入原有慢生理参数组与原生选词/时机信用的参数集合；本地物理状态跨窗口保存。其长期材料学习尚没有补充全局历史Jacobian，也不把复现BPTT当作生物连通的条件。持续学习和行为收益需另验。
