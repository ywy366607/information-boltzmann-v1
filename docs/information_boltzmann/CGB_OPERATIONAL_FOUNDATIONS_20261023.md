# 有限描述与真实世界恢复：公理体系的语义接续

来源：Claude 的公理化主线与 `de0268d` 生命定义；接续基础审计 `9a14372`。
本轮只补表示、语义与证明，不新增物理公理、不改原生成核、不恢复训练。

## 1. 同一条推导链，而非新增行为机制

公理约束允许的介质；表示层说明怎样有限地给出一个具体介质；联合转移说明它实际如何同世界相遇；目标层询问这个过程能否持续存在。四层各司其职：

| 层 | 本轮对象 | 证明义务 |
|---|---|---|
| 物理约束 | 原 P1a/P1b/P2a/P2b/P2c/P3 | 原谓词保持；每个新候选仍需分别满足 |
| 有限表示 | `Description.Book` 与固定解释器 | 编码完整、可解码、数据不藏在外部回调里 |
| 过程语义 | 原身体—世界时钟与联合转移 | 非负、归一化、与原前向联合律一致 |
| 目标 | `Operational.EncodedCandidate` | 真正比特预算、实际恢复、持续存在、闭环收益的见证 |

目标是待满足的性质，写进结构字段并不等于已从公理推出它。原独立性结论与存在性/普遍保证的量词区别继续有效。本轮没有宣称公理已经全局最小。

## 2. 有限规则到底编码了什么

`RuleEncoding.lean` 给出一个保守的参考语言：有限、带局部状态/刺激条件的事件表。每个事件记录参与位置、当前状态、刺激、下一状态，以及非负有理数速率的分子和分母。一本书还包含位置数、状态/刺激字母表、接触、身份、边界、含量、初态与平衡刺激。

解释器是所有书共用的固定程序。它不接收一个任意 `Medium` 再随手附上短码，而是**由这些实际数据生成 `Medium` 的每个字段**。超界值的取模、缺项默认值、重复参与位置取首个更新，都写在解释器中；候选可再以良构条件排除它们，不能将默认值当自由参数。有限表示并不自动给出守恒、详细平衡、等变性或完整局部公理；目标仍要求完整 `Axioms` 见证。

采用锁定 Lean/mathlib 版本中派生的 `Encodable` 约定，描述长度为：

`L(book) = Nat.size(encode(book)) + 1`。

这是一个独立整数描述的固定二进制长度口径，带一位封装开销；没有声称它是自定界前缀码，串接多份独立码时还需要显式帧。字段和列表的结构已由整本书的编码计入。已证明：

- 解码编码得到原书；相同编码不能对应两本不同的书；
- 相同编码产生相同的完整介质；
- B 比特预算内不同书的数量至多为 `2^B`；
- 解释器不会改变事件参与者之外的位置；
- 有限刺激/状态/事件给出某个统一时钟界，能否符合给定世界时钟仍需准入。

它是**固定编码长度**，不是声称可计算的最短 Kolmogorov 描述。参考语言是表格式的，可以表达大表，也必须为大表付出描述成本；没有把它当已压缩的生成脑程序。下一步共享模板/生成规则语言应从既有方程编译而来，保持同样的全数据计费与精化义务。

### 2.1 1% 的分母也须固定

`WiringReference n` 注册同一批 n 个带标签位置上的有向、无权、含对角线的稠密接线编码。其实际布尔载荷长度已证明为 `n*n`，不能向新目标随意传一个极大自然数作为分母。

`GenomeBudget book graph 1 100` 精确表示：

`0 < n*n` 且 `100 * L(book) ≤ n*n`。

这是**指定比较约定下的全实例描述预算**。图本身不能参与解释器或提供免费查表。真实数据来源、位置集合、是否包含空位、图边界及编码约定必须在实验登记；本轮不以任意填大的空空间证明生物基因组压缩。若改用有权图、稀疏编码或允许公共几何，需预先登记分母和条件描述，不能事后挑有利口径。未证明存在达到1%并且满足生命目标的书。

### 2.2 有限描述与计算资源分别处理

事件评估是有界数据上的有限列表扫描、有限整数/有理数运算，不是任意实数函数。已增加带 fuel 的扫描，预算不足返回失败；证明 fuel 至少为列表长度时与原查找相同。fuel 的单位是列表节点检查，不是 CPU 周期或字节。

这提供可检查的计算接口；尚未给整本书的解释器建立硬件工作空间或总比特运算成本上界。有限代码不等于4GB可运行，某个数学时钟界也不等于硬件实时吞吐。下一步应统一从实际表达式/数据大小推导工作空间与速率准入，而非靠新阈值修补模型。

## 3. 恢复应在当前世界里实际发生

`WorldRecovery.lean` 沿用原 `law` 的更新顺序，不改时钟：

`J((x,w),(y,w')) = world.moves(w,x,w') * body.kernel(clock,sense(w),x,y)`。

世界读取当前身体 x，身体读取当前世界 w；两者在下一拍同时更新。已证明 J 非负、每行和为1，并且原前向联合律正是沿 J 推进。

设 `mark(z,z')` 表示要观察的真实转移，则第一次发生的有限时域概率为：

`R_0(z)=0`

`R_(k+1)(z)=Σ_z' J(z,z') [mark(z,z') ? 1 : R_k(z')]`。

它从**当前身体和当前世界**出发，只沿实际可能的路径累加，不选择世界状态、不替有机体规划、不发放外加奖励。事件标签是观察问题，不反馈到动力学。带“已经发生”吸收标志的观察器与这个递推等价，成功事件不会重复计数。

已证明概率位于[0,1]、固定过程下延长时域不会降低成功概率、闭合且无成功转移的区域中该概率恒为0。这里“闭合”要求在实际正概率转移下封闭，不能把未探索到当作不可达。

### 3.1 两种不可恢复继续分开

`FirstHit.Possible` 只使用同一个实际联合核的正概率边。没有路径通向成功的状态，沿该核继续演化仍无路径；并且任何有限时域的成功概率都是0。该不可逆结论没有变成新公理。

概率低于某个 p 则是风险意义的判据。它不自动变成吸收态，后续仍可能回升；不能把“低于可靠性门槛”说成绝对不可能恢复。

### 3.2 时间协议与闭环剪断

`FirstHit.during` 使用世界时间 t 的转移核，允许明确登记的中断协议以及原有依赖边际分布的 ghost 剪断。正常与剪断分支各自的恢复概率都沿各自未来核计算；没有在评分时自动把剪断世界接回正常世界。两分支分别与原 `law` / `lawCut` 的一步递推对齐。

自然、无剪断的协议已证明退化为 `actualRecover`。`Operational.alive` 同时依赖身体、世界、当前时刻和实际协议；相应存活概率有非负/[0,1]证明。由持续存在见证可推出 `δ≥0`、`H>0`、`p≤1`，无需添加新的物理公理。

## 4. 有针对性的语义对照

`RecoveryControls.lean` 构造同一有限身体和同一食物刺激菜单的两个数学世界。两者只在“当前无食物时，下一拍能否到有食物的世界状态”上不同。旧菜单恢复量对两者相同；新实际恢复量应在两拍时域内分别为0和1。它检验定义是否读到了世界可达性，不是合成能力研究，也不是完整生命见证。

## 5. 新旧接口与尚需完成的语义

原 `Life.lean` 的 `recover/aliveInd/Lives/LifeConjecture` 和原证明保留为**历史菜单语义**。`Foundation.recover_ignores_world_moves` 继续描述这个旧定义。新的操作目标采用 `Operational.EncodedCandidate`，明确没有证明它与旧目标等价，也没有把原 `Lives.exposed` 定理移名到新目标。

当前已补的两条链是：完整有限描述→可解释介质→比特预算，以及实际联合转移→真实首次摄入→实际持续存在/闭环目标。以下属于下一步有明确来源的证明义务：

1. **资源语义**：目前 mark 专门化为身体含量增加，是物料摄入。世界尚无完整资源/储能账本，因此不能称为已证负熵或有用自由能摄入。应在既有守恒与详细平衡之上补全世界端交换账本及热功对应，再用相同首次事件观察器。
2. **中断语义**：当前 `ToleratesSensoryInterruption` 只切感知。断能、断料、无信息而有能量是不同干预，需由实际世界状态/转移表示；不能都塞进 calm 刺激。
3. **主动回拉与临界点**：旧可靠性临界点条款未直接搬到新候选。应先说明中断期间实际损伤与恢复后的回升，再证明相应目标可满足及何种不可逆性；不把恢复倾向写成物理公理。
4. **学习目标**：冻结记忆漏洞、认知/实用优势、自我模型和完整生命存在性仍需证明。新候选有意不沿用旧记忆字段冒充解决。
5. **算法精化**：表式参考解释器不是旧 Python 生成核的已验证编译物；共享规则压缩、全解释器工作空间/位操作成本、真实果蝇正向验证继续沿主线推进。

这些未完成项决定下一条推导链，不用新增行为规则绕过它们。
