## 5. 从现有最小对象推导新用途

令D为当前关系的证据，a为拟采取的行动，Q为当前已绑定未知项所指向的后续条件查询，Y_a为可能取得的回应，Y_Q为Q的实际后果。取证的预期用途可定义为：

`V(a;Q,D) = E[log p(Y_Q | D,Y_a,a,Q) - log p(Y_Q | D,a,Q)] / d`

在模型给定的联合预测分布和预先固定的Q下，这等于 `I(Y_Q;Y_a | D,a,Q)/d`。d为输出潜维数，与身体现有平均对数评分对齐。先确定Q和待检验预测，真实后果到达后再评分。

这比“减少全部参数的不确定性”多出了**用途对象Q**：证据可以对某个参数很新奇，却与当前未决关系几乎无关。Q直接来自已有条件关系/共享未知身份及其复用查询，保持原系统的内容依赖。

身体已有条件高斯残差模型，设 `A = ridge*I + XᵀX`、候选角色特征为x、目标角色特征为q，则条件于同一噪声尺度：

`rho² = (q A⁻¹ x)² / [(1 + q A⁻¹ q)(1 + x A⁻¹ x)]`

`I(Y_q;Y_x | D, noise) = -d/2 * log(1-rho²)`

本次直接用实测的4维关系特征、128维输出及原ridge计算；排序时只读条件/行动特征。两个回应标签留给后续真实评分。该量沿用原信息量的条件噪声语义；Student-t真实预测评分负责检验这份模型预期。

另一侧的实际条件贡献为：

`C(e→q) = score(R_with_e,q) - score(R_without_e,q)`

两个预测都排除q自己的事实，其他上下文相同。多个e的贡献可以重叠，按用途事件保留各自比较基线。当前1344项计算是这项结算的已有实物。

## 7. 同调洞、未决关系与持续求解的对应

用户提出用同调洞理解持续未决的因果。原62维H1来自真实Dowker依赖复形：节点是关系身份/代次，一组关系共同依赖同一个有类型未知项时生成单形。715个图环方向中653个由实际共同支持面生成，余下62个独立一阶同调方向。这个维数刻画共享依赖的组织，内容相容性由具体预测与真实后果检验。

本轮288/160是448组支持事实对其他事实的用途配对的正负次数。审计保持原持存复形不变，只改变一次后验求解采用的证据子集。进一步按原查询分组，64个查询中61个同时含正、负支持贡献。例如event3、关系213/代次4、查询1133：支持267贡献+0.270159，支持1977贡献−0.124949。因此正负用途在同一实际关系、同一查询和同一持存结构中并存。

拓扑结构、结构上的实际响应、响应的功能用途分三层登记。已有Hodge输入是共享事实编码残差的响应αM_eY，具有明确的敏感度语义。将持续未决冲突与环路联系起来，需要同一条件/行动/后果端口下不同实际推理路径的预测差，以及新证据对该差和后续用途的修订。这个信号应另外绑定原实码，保留已有响应测量。

HodgeRank中循环分量可表示比较关系的不一致，来自其明确的比较信号定义：[Jiang et al.](https://arxiv.org/abs/0811.1067)。一阶同调维数决定可用调和空间的维数；具体是否存在不一致，要看信号在该空间中的投影及其语义。填面可以把某个环的性质从全局调和变成局部旋度，真实预测冲突则仍需证据解决。

持续生命体采用有界、可恢复的局部修订：每次有限预演，保存未决身份及证据，返回实际行动；后果到达再激活。当前`navigation_generative_cycle.py`已经用`joint_proposal_budget`限制一轮内部候选。后续目标是按可改变的关系分歧和实际用途安排这种预算。持续互动的调度不以全图同调清零作为结束条件。
