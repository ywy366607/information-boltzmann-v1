# 持存条件计划与多速率交接

本轮继承原分配2537完整身体，承接`CGB_BATCHED_LATENT_ACTION_PLANNING_20261120.md`末节。目标是让过去已形成的条件计算持续服务于现在，让实际内部运动能在学习过程中参与下一段输入，沿原行动—后果—结算闭环继续学习。用户2026-11-20批准完整实施及本地CDEF运行，磁盘紧张时可将退役可重建产物暂存G盘。

## 具体问题与生成规则

上一原分配16轮中，潜规划712次/588.603秒，平均每次0.827秒，每次外界交互44.5次；整圈1284.626秒。当前原生条件银行已经学习了完整后继决策端口；再次为每个后继重建问题/行动树，是可复用计算被反复展开的位置。内部活动则主要发生在完整外界调用前，其后一次长调用串住后续派发。

采用两个共同规则：

1. 保留条件程序的raw角色块、关系/未知项身份和真实证据；现在的参数重新编码这些条件，读取已学的完整决策端口。原生精算和到达的真实用途继续分开标注，在原真实结算提交，持续修订这个读出。
2. 一个实际过程在读写安全边界交出执行权，原选择器可以推进一次内部S/P；下一段真实计算读取运动后的当前状态。观察、更新、等待、保持和再学习沿同一身体连接。

这些规则作用于实际任务和端口；五行用来检查相互生成、校验和反馈的覆盖。

## 实际身体映射

|身体对象|本次实现位置及行为|
|---|---|
|条件计划|原`native_value_bank`的raw配方和带来源标签的条件预测；`persistent_rhythm.read_plans`复用该银行，替代每个后继重复展开整棵问题/行动树|
|当前编码/条件值|复用原encoder、二阶核及原continuation先验，权重/观察钟/银行版本变化后重新求值；相同条件、相同版本的执行结果有界复用|
|保留身份的计划工作集|`rhythm_state.plans`最多原evidence_budget条，含raw、关系版本、未知项身份、值和银行版本；这是执行缓存，真实世界事实仍归原归档|
|内部运动|原`continue_internal`和原S/P积分器；使用同一条件银行读出后续用途，原有限U定价当前局部后果|
|内部选择的信用|原`autonomous_cycle.poll`存储的绑定选择器score资格，后续原`take_boundary/add_boundary_credit`和真实actor因子结算|
|可续外界任务|`ExternalTask`在同一线程用greenlet保留原完整step调用栈，yield后返回同一原函数继续执行|
|安全交接|实际world.take返回时发布到达收据；原完整`_advance`返回后发布更新收据，此时backward、optimizer、S/P捕获已完成，下一objective尚未开始|
|持存修订|原有限U/v5、共享未知项、经历与关系更新、原生/世界条件银行提交均保留；计划工作集读取当前参数和当前证据|

内部选择仍由原绑定选择器及当前内容/用途共同决定。每个安全交接提供一个有界计算片机会，选择内部时真实推进S/P，选择继续时交还原任务；原外界边界前的自主续行仍可连续多次发生。各头的内在频率/耦合沿原身体的可学习动力学保留。新增调度未给五相各设一套固定Hz。

## 时间、版本和结算

`autonomous_event_clock`记录实际派发次序，`rhythm_state.clock`记录端口交接，观察字节钟只由真实学习/观察路径推进。`world_arrived`发布真实到达，外界字节在原完整事务的最终行统一记账；学习交接行记录当次实际更新，完整行另外汇总本事务更新。分析更新总量以运行总计或逐次dispatch增量为准，避免把事务汇总再累加一次。

内部运动保持参数和真实经历钟；学习后的quiet成为下一objective的实际输入。当前行动的预测、话语重放与源身份保持原收据，内部选择资格留给其后实际边界。中途内部读出恢复原行动的预演诊断，避免污染该行动的误差分解。

可续调用栈是瞬态执行器；raw计划、逻辑钟、资格、待结算、参数、优化器、S/P、归档及世界/RNG随完整身体保存。检查点提交位于完整外界事务结束，STOP先排空已开始事务；现有事件日志可从上个完整边界重放。保存时显式拒绝未完成事务，防止把半次更新伪装成完整提交。恢复后清除进程局部缓存戳，重新读出当前计划。GPU始终单线程、单学习者。
