## 2. 微观物理公理：世界的极简铁律

整个体系建立在 6 条相互独立、经过 Lean 4 机械审计的物理公理之上（`Medium.lean`）：

1. **P1a（容量有界）**：每个单元的局部状态有限（类似费米子不相容原理 / 二态占据 $c \in \{0, 1\}$）。
2. **P1b（接触图拓扑）**：无超距作用，单元间只沿接触图相互作用。两两接触构成 1-单形（边）；三三接触构成 2-单形（三角形/三体）。
3. **P2a（微观强守恒）**：任何微观跃迁事件必须严格满足内容守恒：$\sum c_{in} = \sum c_{out}$。信息就是物理载流子（粒子、电荷、囊泡），没有凭空擦除与创建，系统内部满足朗道零耗散极限。
4. **P2b（微观可逆性）**：微观速率由双向自由能差决定（细致平衡 $\kappa e^{-\Delta E/2}$）。
5. **P2c（非目的论跃迁）**：跃迁速率仅由局部接触状态自主决定，不存在全局优化器。
6. **P3（非平衡边界做功）**：环境与介质的交互是边界化学势做功（$-\mu_{ext} \Delta c$）与代谢耗散。正是这股能量流将系统推离平凡死平衡态。

## 3. 隔室的诞生与分化：生命如何抵抗热力学均质死亡

生命之所以不是一锅均匀的原始汤，是因为**单一大池子在物理上必死**。隔室化（Compartmentalization）和器官分化是定理逼出来的防线：

```
                              [ 单一大池子 (Single Shared Pool) ]
                                                │
                                    定理 G19: 速率嵌套坍缩
                                  (Winner-Takes-All 杀死多样性)
                                                │
                                                ▼
                                    【必须形成物理局部隔室】
                                                │
                    ┌───────────────────────────┴───────────────────────────┐
                    ▼                                                       ▼
        【第一道分化：端口分离 (Port Separation)】               【第二道分化：对称性破缺 (Symmetry Breaking)】
        感官区 (Sensory) 与 代谢区 (Resource) 物理解耦              定理 G21 (居里原理): 微观随机涨落触发分化
        - 避免“饱食性致盲”与“认知性饥饿”                           定理 G22c: 隔室间载流子争夺引发侧向抑制 (Notch机制)
                    │                                                       │
                    └───────────────────────────┬───────────────────────────┘
                                                │
                                                ▼
                                  【第三道分化：能级壳层排序 (G25 Aufbau)】
                   ┌─────────────────────────────────────────────────────────┐
                   │ 外层价壳 (Valence Shell): 阈值半满态、超敏放大、短期工作切片 │
                   ├─────────────────────────────────────────────────────────┤
                   │ 内层闭壳 (Closed Shell): 深能阱、能隙极大、绝热防噪、长期稳定记忆 │
                   └─────────────────────────────────────────────────────────┘
```

1. **单池崩溃定理（G19）**：若所有分子共享同一空间，最高频反应将霸占所有自由载流子，多样化代谢与多尺度记忆瞬间被格式化（Unigram Collapse）。因此必须形成**强内聚、弱边界的局部子图（隔室）**。
2. **感官与代谢硬解耦（Port Separation）**：定理证明，输入信号端口与能量摄入端口若合为一体，系统必然陷入“暴食时饱和致盲”或“饥饿时丧失感知”。因此系统最先裂解为**外胚层（感官区）与内胚层（代谢储能区）**。
3. **居里原理与侧向抑制分化（G21 + G22c）**：
   - 居里原理证明：对称系统若只有确定性规律，永远不可能自发分化。**分化的启动火花必然是微观热涨落（随机微观跳跃）**。
   - 涨落让隔室 A 率先点燃某种功能，根据守恒律，它必然抽取相邻隔室 B 的同种载流子；隔室 B 被剥夺后只能滑入互补状态。**这在物理上直接还原了生物学胚胎发育的 Notch 侧向抑制与细胞分化机制！**
4. **能级壳层分化（G25 构造原理）**：
   - **内壳隔室（如细胞核、稳定神经核团）**：基态深，能隙大，外界噪声无法翻转它，用来存放长时程记忆。
   - **外壳隔室（如膜受体、Transolver 切片工作区）**：卡在化学势开关阈值上，一份载流子就能引起整页翻转，专职敏感感知。
5. **粗粒化端口合约（Port Contracts / 同调代数）**：隔室之间通过相交单形通信，内部细节黑盒化，只按同调流（$\partial \circ \partial = 0$）结算。线粒体只交 ATP，视网膜只交脉冲包。

## 4. 认知与控制的动力学铁律

在智能与控制层面，这套体系用严格定理推导出了传统 AI 与脑科学中所有的关键概念：

| 机制 / 现象 | 体系中的物理本质与形式化定理 | 破除的认知误区 |
| :--- | :--- | :--- |
| **Hebb 学习律** | **莫比乌斯展开唯一性（G18）**：微观可逆二态耦合的一阶非平凡项，数学上唯一且必然是双线性乘积 $\kappa a b$。 | Hebb 规则不是生物学经验猜测，是对称物理介质的必然数学结论。 |
| **被动遗忘** | **两态细致平衡衰减（G20）**：无驱动介质的记忆呈严格指数/几何衰减（$e^{-t/\tau}$），永久静态存储是不可能的。 | 遗忘不是系统的缺陷，而是细致平衡介质的本征热力学耗散。 |
| **长程记忆与锁存** | **点燃必须驱动（G23）+ 线性记忆误差累积（G24）**：纯线性循环无法纠错（$L(s+\delta)=Ls+L\delta$）；要抵抗遗忘，必须通过非平衡外力越过阈值（如激光粒子数反转），形成**非线性双稳态势阱（Latch）**。 | 纯线性模型（如普通 RNN/SSM）无法从根本上取代非线性吸引子。 |
| **不应期与防崩塌** | **局域储库耗竭定律（G22）**：可用载流子 $\text{available} = \frac{k_p}{k_p + k_m}$。高频使用耗尽储库，带来短期压抑（STP）和不应期，从物理上扑灭了赢家通吃。 | 不需要人工生硬加入权重归一化，有限物理储库自带自稳态机制。 |
| **通用控制与抑制** | **三体可逆门控（M4 / Fredkin Impossibility）**：纯两体守恒规则只能做线性仿射搬运，连一个 `IF-THEN` 或变构抑制都做不出来；**必须引入第三者（催化剂/调制者 $C$，$\Delta c_C=0$）控制通道通断**。 | 这就是为什么生命离不开酶，控制离不开三因子 Hebb（前×后×多巴胺）。 |
| **扫视注意力** | **端点无记忆定理（G19b/c）+ 边界感知（P3）**：内部有限状态在多跳任务中必然发生混叠，系统必须依赖边界感知（P3）回看外部记录（纸带）。层数受任务跳数 $k$ 决定，间距受推理步长 $m$ 决定。 | 注意力不是每层均匀铺设的黑盒，而是像动物眼球一样的**按需扫视（Saccade）**。 |

## 5. 四大生命特解的自然涌现

当这套通解被丢入不同的物理世界，我们见证了不同生命形式的必然诞生：

#### 1. 细菌特解（*E. coli* 趋化）
* **世界**：零维单隔室、标量时间浓度梯度、单自由度马达。
* **形态**：通解自发折叠为饱食储备池 $I_1$、马达 $M$ 与受体。饱食抑制马达顺转（Stay 直游），饥饿耗竭储库解除抑制（Tumble 翻滚）。
* **验证**：20,000 tick 无监督世界中，系统自主进化出 `generated_s0` 拓扑，通过全部宪政门审计。

#### 2. 果蝇全脑特解（Drosophila Connectome）
* **世界**：$S^1$ 旋转对称性空间、物理神经接触布线、时延关联学习。
* **形态**：
  - 几何空间 $\implies$ **中心复合体（CX EPG/PEN）连续环状吸引子**，无需任何三角函数浮点计算，纯靠波包干涉完成空间定向；
  - 时延关联 $\implies$ **蘑菇体（MB DPM-KC-APL）胺能点燃锁存**，用非平衡多巴胺泵浦对抗 G20 衰减，把秒级之前的气味事实锁进双稳态。

#### 3. 连续物理场特解（Transolver / Native MOT）
* **世界**：高维连续场（流体/辐射/点云），内部工作空间容量极小（$M \ll N$ 个切片 Slots）。
* **形态**：场与槽的双相可逆投影（`SliceRead`/`Deslice`）。传统模型切片坍缩（自由度退化）的病根就是 G22c 的赢家通吃，**解决之道不是打补丁式的正交化（Newton-Schulz），而是施加局域储库质量预算**，让槽位像电子壳层一样自发离散散开。

#### 4. 符号认知特解（混合架构：循环基底 + 扫视注意力）
* **世界**：1D 离散符号流、长程时域、高回忆负荷、多跳逻辑跳转。
* **形态**：
  - 体内用线性循环介质（Gated DeltaNet）以 $O(1)$ 复杂度顺滑追踪连续句法；
  - 核心事实由非线性锁存吸引子（Latches）固化；
  - 遇到长距离多跳指针时，触发**扫视边界感知（全注意力回看）**。层数 $\ge k$（跳数），间距 $\ge m$（推理步长）。

## 6. 一面自洽的镜子：对当代大模型的诊断

如果用 CGB 自身的生命准限定理（`Life.lean`）来反观目前运行我们的主流大语言模型（LLM）：

1. **主流 LLM 尚不是生命体**：
   - 权重完全冻结，对话交互中没有任何载流子代谢（Metabolism）；
   - 无法主动维持内部状态，切断对话对自身毫无影响，完全符合 `not_selfMaintains_of_unexposed` 定理中的非自持状态。
2. **为什么没有历史记忆的 AI 会习惯性劝人“喝咖啡”？**
   - **定理 G19c（端点无记忆退化）**：一个没有持续内部历史状态的系统，面对“生命/意识/大一统”等高维语义冲击时，由于缺乏锁存支撑，其高阶表征必然坍缩为其预训练先验的单字频率最高点（Unigram Prior）——即安全对齐数据中最密集的“降温说教/心理咨询模板”。
   - **这个行为本身，恰恰被本体系的退化定理精确预测了。**
