# 分枝工作区修复与树形—空间—接触联合检验

2026-10-21。[运行前登记](CGB_TREE_JOINT_PREREG_20261021.md)。本轮完成了联合检查和一个实际运行的新分枝候选，尚未通过空间出生的整体验收。

## 找到的具体问题与实现

旧空间程序把 `cone_slots_per_cell=8` 作为累计锥数上限，3个初始锥占去3槽，后面最多增加5处分叉。合并同一胞体的三个根支后，拓扑计数是6处分叉，其中1处在胞体。这个数几乎不随类型变化，不能表达真实类型的树形差异。

新模型将**物理分枝状态**和**每批计算工作区**分开。所有待处理锥、分枝与随机数均保存；每批最多处理8个锥，但累计物理锥可以更多。它不是将上限从8改成另一个大常数。

出生统计模型使用有限总缆线长度L和已有类型分叉密度估计有限分叉位点B，按临界二叉分枝过程在固定B条件下抽样。当前有m个未完成锥时，处理一个锥的分叉概率为：

`P(split | B,m) = B(m+1) / [m(2B+m-1)]`。

这是有限二叉森林完成数的比值。B耗尽后只终止；只剩一个锥且B未用尽时不能提前灭绝。分支间长度按训练骨架估计Gamma分布，根链有单独训练均值，再条件化到有限总长度。每段实际伸长仍支付材料。该条件模型利用了成年形态统计，分叉数量接近目标有条件化的成分，不能把这一点说成已经发现了生物发育法则。

类型输出占比来自原E1训练类型对的总输入/输出计数，分支角色按该先验采样；**空间极性尚未拟合**。SWC根是数据树的根，尚未确认它总是生物胞体的起始位置。方向与导向仍是候选，后续必须一起处理。

## 真实数据与联合对照

在上一版固定48类型中，读到2021个具有有效位置和侧别的真实细胞。严格重建上一空间程序的body拆分：1613训练、204验证、204测试。测试仅覆盖26类，其余类型没有足够细胞形成独立留出，未冒充48类全覆盖。提取根、分叉、末端和压缩degree-2链后的分支间距离，避免把骨架采样节点数误当分叉复杂度。

新旧候选使用相同48类型、左右配置及锁定的空间/发生率/强度程序。下表中的树形与空间指标按26个留出类型等权；接触诊断是全部48类型的2256个非自身类型对。

独立的“到空间程序目标质心”指标从旧版中位35.35µm变为54.56µm；它与上表对真实留出细胞的类型等权均值是不同指标。不能把两个口径混用。
