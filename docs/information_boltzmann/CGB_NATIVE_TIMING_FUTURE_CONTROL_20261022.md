# 次序检查的未来热浴控制

2026-10-22。在原次序检查执行期间、补充检查执行前写明。原AB/BΑ各臂虽然从同一RNG开始，但不同实际事件数会消费不同数量的随机数。因此原中性制备后继续使用各自RNG的未来差异，不能全部归于保留的慢状态。

补充：读取各臂已经保存的`*_neutral.npz`完整档。身体、全部慢状态、已计入的外部制备功、时钟和历史均不改。每个噪声家族四臂的未来热浴共同取自原父档三RNG，分别advance `10000000+1000000×family`；记录旧/新RNG状态，明确这是诊断未来环境选择，不是身体自主行为或跳过物理经历。各臂随后接同一8个真实未来字节和真实32ms，原相变/学习继续。

同一未来随机数初态不能使分歧后的事件逐个配对，但可排除“仅因过去消费了不同RNG段”这一额外差别。每臂保留完整开始/末态、恢复和观察器sham；原未经制备的自然主线不变。保留的状态仍包括r、支持、驱动组成、拓扑和几何，不能将未来差异单独归因于r。write势垒对照用于定位整个原生写入通路的贡献；若要单独定位支持保护，还需另做物料匹配的允许事件检查。
