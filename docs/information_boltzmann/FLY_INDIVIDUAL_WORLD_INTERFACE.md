# 个体与世界的交互方式：果蝇脑的马尔可夫毯（2026-10-11）

从“写入、读出”两个接口出发，一路演化成一个框架：个体 = 自己运转的内部动力学 + 由它自己控制的边界（马尔可夫毯）。
本文是框架总结；实验细节见 `FLY_STREAMING_CLOCK_20261010.md`，冠军个体的因果与提速见 `FLY_CHAMPION_CAUSALITY_SPEED_20261010.md`。

## 1. 出发点：清晰的串行

冠军个体（CTM-S14 + 自适应准入）的交互是：注入一个 token 的感觉脉冲 → 等全脑膜电位通量 ‖Δh‖/√N 降到 0.048 以下或不再下降（至少 3 拍、最多 14 拍，平均 6.2）
→ 在那一拍读运动面 → 下一个 token。这是为了证明“性能受内在时间限制”而刻意设计的；它证明了果蝇连接组能学语言（脑贡献约 0.52 nats，学到的突触被真正使用）。
但毯上的两个开关（何时采样、何时说）都不归脑控制，它只有“想完、说、看下一个”一种模式。

## 3. 框架

**个体 = 内部动力学（自持、永不重置） + 马尔可夫毯（感觉状态、行动状态） + 能量池**，
毯上的通道由脑自己的输出控制，用变分自由能训练。

| 部件 | 机制 | 状态 |
|---|---|---|
| 感觉通道 | 新息 × 精度 a_t（主动推理中预测误差的精度 = 注意；a_t 由脑状态给出）→ 视而不见 | 新息已有；精度待做 |
| 行动通道 | “去”神经元：一个 LIF 神经元，积分运动面活动，过阈值放电；放电时先说出当前预测（积分读出），再把目光移到下一个 token（采样） | 待做 |
| 内在驱动 | 学到的循环自持（已存在）；起搏器、自发噪声可选 | 已测 |
| 反射 | 毯内感觉→行动直连（VNC） | 已存在 |
| 能量池 | 每拍消耗 = 突触事件（放电神经元的出边，可由连接组精确计算）+ 动作电位；B ← B + 供给 − 消耗，永不重置；供给标定为冠军个体现有节奏下收支平衡 | 待测、待做 |
| 目标 | F = E_q(τ)[−log p(y | 第 τ 拍的读出)] + KL(q(τ) ‖ p(τ | B))，思考时长先验 p(τ | B) ∝ exp(−C(τ)/B)：能量的玻尔兹曼分布，池满温度高（多想便宜），池空温度低（疲劳） | 待做 |

说在前、看在后，结构上不泄漏；k、输出滞后、通量阈值 0.048、至少 3 拍四个人为数字全部消失；
自适应读出与自适应写入统一为同一个运动动作。剩下的常数只有生理量（能量供给速率、池容量）。

**同一个毯，不同的配置就是不同的模式：**

| 模式 | 感觉通道 | 行动通道 | 内部 |
|---|---|---|---|
| 只沉思 | 关（a≈0 或无输入） | 不放电 | 自持运转（已测到） |
| 不在乎感知只思考 | 精度低 | 不放电 | 运转 |
| 边感知边思考 | 开 | 不放电 | 运转 |
| 边说边感知边思考 | 开 | 放电（先说出浅层猜测，继续深想） | 运转 |
| 多想一会儿 | 推迟采样 | 推迟放电 | 运转 |
| 反射 | — | 毯内直连 | 绕过 |

**世界的节奏是世界的属性，不是模型的参数：** 读书（自定节奏：采样由“去”神经元决定）与听人说话（外部节奏：流式时钟，脑只能决定听不听、何时说）
是同一个毯面对的两种世界。

## 4. 验收

从冠军个体分叉，与通量规则配对：四支柱（首次预测、换上下文后的恢复/AG、A→B→A 重访、健康），
加上每 token 拍数与实际速度、每拍能量、放电率、静默测试下的沉思状态是否仍在、逐位不泄漏测试。

## 5. 风险与未决

- 暗室问题：最小化惊讶/能量可能学会闭眼或整体静默；外界文本无论看不看都计分，加上沉思状态的验收可以发现。
- 能量目前几乎恒定（放电率 2.5% 与输入无关），此时能量先验退化为几何时间先验；要有意义需要脑学会难时活跃、闲时安静。
- 积分读出在短跑里有害：原因未定（读出与解码器对瞬时膜电位的共同适配；膜电位已是积分器；应积分脉冲而非膜电位）。
- 时间常数等慢参数在 lr 2e-4 下短跑内几乎不动，短跑只能比较固定初值。
- 离散的停机改变后续轨迹：期望只能在实际计算到的拍上取（截断），需要训练时采样停机拍来探索更晚的拍。
