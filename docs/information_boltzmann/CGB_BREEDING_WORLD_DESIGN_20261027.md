# 世界内部的繁殖与遗传：设计（实现前写定，2026-10-27）

目标：生态球里的生命自己繁衍、变异、被筛选，取代外部的 GA/ES（梯子第三层，见 `CGB_WORLDS_THAT_BEAR_LIFE_20261027.md`）。

## 1. 由公理推出的（强制）

1. **基因组必须是生物状态的一部分。** 现在的 `NestedWorld` 里规则表（能量、速率）属于整个世界：世界里只有一个物种。遗传要求不同个体带不同的表，所以生物的局部状态 = (基因组 g, 内部状态 y, 朝向 h)，内部规则的速率与能量由 g 决定。g 不被内部事件改变，所以导通量对称性（P2b）自动成立。
2. **分裂守恒（P2a）。** 子代的身体物质 B 与子代的内部含量都来自亲代：亲代含量 = 两个后代的含量之和。分裂是邻格事件：亲代所在格与一个空的邻格。
3. **分裂可逆（P2b）。** 逆过程是两个相邻个体融合成一个。它必须存在，但会被能量与熵压制：子代的身体物质 B 能量为 0，从高能内部态（≥ 0，物理下限）转为身体物质是顺势的。
4. **变异的核必须对称。** 分裂时子代基因组 g' 可以与 g 不同，按核 μ(g, g') 进行；P2b 要求逆过程（g 与 g' 融合回 g）的导通量相同，所以 μ 对称。在有限的基因组网格上，最近邻变异核是对称的。
5. **基因组有限（P1a 的有限性）。** 数值放在有限网格上（每个参数若干档），Γ 是有限类型。
6. **只有活的才分裂。** 导通量正比于"膜完好"（与经膜交换一致），只依赖事件索引，所以对称。

## 2. 仍需选择的（须由定理或用户决定，不调结果）

- **分裂程序**：子代以什么内部态出生，亲代从哪些单元出这份含量。按单元编号的子集为事件索引（可逆、重数即组合数）。最小方案：子代以"膜全完好、其余全空"出生，含量 B + 膜单元数从亲代的储备 E 中取出。这要求储备单元数 ≥ B + 膜单元数（当前 20 < 26），即结构须扩大储备，或降低 B。B = 16 是为压制自发生成而定的；分裂提供了另一条生成身体的正常途径，自发生成仍被熵压制即可，B 可取更小的值（需重新核算界）。
- **网格分辨率与变异率**：物理常数（变异率是复制的保真度）。

## 3. Lean 计划

1. `NestedWorld` 推广为带基因组的 `BreedingWorld`（Γ 有限）：φIn、规则前因子、交换前因子、转向与移动前因子都依赖 g；Γ = Unit 时退回现有世界。证明它仍是公理模型（P2b 的对称性由"g 不被内部事件改变"给出）。
2. 加入分裂/融合邻格事件（索引：亲代基因组、子代基因组、所取单元子集、朝向），Metropolis 对称导通量 × 对称变异核 × [膜完好]；证明守恒与可逆，仍是公理模型。
3. 定理：分裂是让"放置生物的格子集合"增大的唯一事件（与 `frees_only_by_dissolving` 对偶）；有了分裂，G26c 的"死亡不停"可以由世界内部的出生维持（无限流生命不再依赖外部投放）。

## 4. 模拟器

GPU 精确核与 JS 核心按同一张表加入分裂事件（每格至多一个生物，分裂只能进入空邻格），与 Lean 对拍；生态球不再需要外部选择器。
