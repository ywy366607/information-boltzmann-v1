# 优化器：Muon 的根本原因是防止赢家通吃吗？（预注册，2026-10-26，实验前写定）

## 1. 已有工作

- Wang 等（arXiv 2509.26030，ICLR 2026）：Muon 给梯度的每个奇异方向相等的更新幅度，平衡各方向的学习速度；在长尾关联记忆上，长尾类别学得比 Adam 好，权重谱接近各向同性。
- NorMuon（arXiv 2510.05491）：Muon 之后神经元的更新范数仍很不均匀；按神经元维护二阶矩并做行归一化，在 1.1B 规模上比 Muon 好 11%。
- Muon 等于不累积的 Shampoo，也等于谱范数下的最速下降（Bernstein 等）。

"NS / 几何 / 平衡"是同一个运算（极分解，奇异值全部置 1）的三种描述。要分辨哪一个是原因，必须有**平衡但不正交化**的方法。

## 2. 体系的推论

- **本质**（G22c）：凡是共享一个资源（势）的单元，不加约束就会长成富人俱乐部。学习中的"资源"是更新量，高频类别的梯度大，越学越强。
- **现象**：平衡必须施加在**发生竞争的那个轴**上。类别的输入嵌入互相正交时，类别不共享方向，竞争发生在类别（W 的行）上，按行归一化就够了。嵌入相关时，类别共享输入方向，竞争发生在奇异方向上，需要 Muon 式的谱平衡。
- **带历史**（G22a）：局部储库会耗竭也会恢复。带累积统计的平衡不应差于只看当前梯度的平衡。

## 3. 实验

线性关联记忆，K = 256 个类别，频率服从 Zipf 分布 p_k ∝ k^{−1.2}；输入是 d = 128 维的类别嵌入 e_k，W ∈ R^{K×d}，损失为交叉熵，W 初始为 0。每步 batch 256，共 400 步。两种嵌入：
- **正交**：e_k 取 d 维中的随机单位向量。K > d，所以只是近似正交，相关性约为 1/√d。
- **相关**：e_k = normalize(c + 0.7·g_k)，其中 c 是所有类别共享的方向（缩放到与 g_k 的期望范数 √d 相同），g_k 是各类别自己的随机向量；类别间余弦约 0.67。

优化器（每个在 lr ∈ {0.01, 0.03, 0.1, 0.3, 1} 中选总损失最低的那个；种子 0，初步验证）：

| 名称 | 更新 | 平衡什么 | 是否正交化 |
|---|---|---|---|
| SGD | 动量 SGD | 无 | 否 |
| Adam | Adam | 坐标 | 否 |
| Muon-NS | 动量 → NS 五次迭代（3.4445, −4.7750, 2.0315） | 奇异方向 | 近似 |
| Muon-SVD | 动量 → 精确极分解 UVᵀ | 奇异方向 | 精确 |
| RowNorm | 动量 → 每行除以该行范数 | 类别（行） | 否 |
| RowRes | 动量 → 每行除以其更新范数平方的 EMA 的平方根（β = 0.95；即带历史的行储库） | 类别，带历史 | 否 |

指标：尾部准确率（频率最低的一半类别）、头部准确率、权重的有效秩，按类别报告 [最小 | 中位 | 均值 | 最大]。

## 4. 预言

| 编号 | 预言 |
|---|---|
| O1 | 两种嵌入下，Muon-NS 与 Muon-SVD 的尾部准确率相差 < 0.03：NS 本身不是原因 |
| O2 | **正交嵌入下，RowNorm 的尾部准确率 ≥ Muon-NS − 0.03**：不做正交化，只在正确的轴上平衡就够了 |
| O3 | **相关嵌入下，RowNorm 的尾部准确率 < Muon-NS − 0.05**：竞争轴变成了奇异方向，按行平衡不够 |
| O4 | 两种嵌入下，Muon-NS 与 RowNorm 的尾部准确率都高于 SGD |
| O5 | RowRes 的尾部准确率 ≥ RowNorm − 0.02（历史不吃亏） |

O2 与 O3 合在一起才是对"根本原因是在竞争轴上防止赢家通吃"的检验。只有 O2 成立而 O3 不成立，说明行平衡总是够用（这个任务太简单）；只有 O3 成立而 O2 不成立，说明正交化本身有额外作用。

## 5. 追加：权重空间中的锁存（导演追问，运行前写定）

**锁存的原理**：(1) 正反馈，环路增益在阈值以上超过 1，来源是非加性的乘积耦合（G18）或驱动（G23）；线性系统不可能（`linear_hold_keeps_error`）；(2) 饱和（P1a）给出有界的"开"态，形成两个稳定态和一个不稳定阈值；(3) 驱动维持（G23）；(4) 释放靠慢负反馈（G22a）或外部信号。**赢家通吃与锁存同根**，都来自正反馈；局部、有界、可释放的是锁存，全局、共享资源、不可释放的是赢家通吃。

**优化器**：动量与二阶矩是线性指数滑动平均，属于收缩映射，没有锁存。**权重**有：多层网络中，一层的模式梯度正比于另一层在该模式上的强度（G18 乘积耦合），于是 ds/dt ≈ s(λ − s)，s = 0 不稳定，模式按强度依次点燃（Saxe 等的逐模式学习）。Muon 让每个奇异方向的步长与强度无关，切断这条正反馈，模式改为并行增长。代价（G17）：弱方向与噪声一样被放大，失去靠幅度的选择。

**实验 O6**：两层线性网络 y = W2 W1 x，d = 32，隐藏宽度 32，初始化尺度 1e−3，教师矩阵的奇异值为 {5, 4, 3, 2, 1}（其余为 0），输入白化，MSE 损失，每个优化器在 5 个学习率中选最终损失最低的，最多 3000 步。记录每个教师模式 i 的学习强度 s_i(t) = u_iᵀ W2 W1 v_i，取 t_i 为 s_i 首次达到 σ_i/2 的步数。

| 编号 | 预言 |
|---|---|
| O6 | SGD：t_1 / t_5（最弱模式与最强模式的用时之比）≥ 3，依次点燃；Muon-NS：t_1 / t_5 ≤ 1.5，并行增长 |
