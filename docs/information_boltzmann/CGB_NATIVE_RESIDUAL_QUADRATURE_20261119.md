## 从实际身体到数学

联合后继同一4096点为z_i，原生完整预演值为v_i，现有已学习便宜预测为b_i。把原索引划分成互斥、穷尽的组G_g，w_g=|G_g|/4096，在每组均匀选一个原点j_g：

`Vhat = mean_i b_i + sum_g w_g (v_jg - b_jg)`。

1. 每个后继点的概率继续由4096点经验测度承接。
2. 便宜函数在所有点读出，完整原生程序只执行至多原预算4次。
3. 对固定身体、点集和分组，按组内均匀选择取平均，E[Vhat]=mean_i v_i；便宜预测任意准确度都成立。
4. 若v_i-b_i为同一常数，一次残差校正即精确；一般误差由`sum_g w_g |sampleResidual_g-meanResidual_g|`控制。
5. 当前每组一代表。按便宜预测的组内平方离差降低量进行二叉分裂，直到原预算。其目的为聚集已有预测认为用途相近的内容；原生残差是否随之集中，由实际值核验。

固定私有积分seed提供可恢复、共同的抽样数列，CPU/CUDA/世界RNG保持。有限平均恒等式对应均匀局部抽样的数学期望；一次固定seed运行作为一个具体积分实现，效果用真实后续收益及共同旧事实验收。
