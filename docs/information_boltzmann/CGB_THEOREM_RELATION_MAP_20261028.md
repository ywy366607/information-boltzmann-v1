# CGB 定理关系图：无限流生命的最小生成追踪

状态：**工程追溯图，不是第二份架构规格。** 全部声明、源码位置与自动摘要见 [CGB_PROVEN_INDEX.md](CGB_PROVEN_INDEX.md)；当前 L0–L6 的自动反向切片见 [CGB_MENGLI_GENERATOR_SLICE.md](CGB_MENGLI_GENERATOR_SLICE.md)。本图只保留从生命定义到共同递推 `Φ` 的因果边；每条边标明它是 Lean 定理、定义，还是尚须由具体世界满足的条件。

## 1. 根、目标与证据等级

```text
P1 有限局部介质 ─┐
P2 守恒/对称     ├─→ L0 生存连续性 → 开放边界与信息负熵
P3 边界破缺     ─┘                     ↓
持续演化 + 无限语言流 → 有限状态选择/遗忘/压缩
                                      ↓
                 预测、因果、延迟信用、主动闭环
                                      ↓
                          L1–L6 的同一局部递推 Φ
```

| 等级 | 含义 | 允许的表述 |
|---|---|---|
| E0 | 原始定义、公理或世界合同 | “规定/假设” |
| E1 | Lean 已证的局部机制 | “在列明前提下推出” |
| E2 | 多条 E1 条件性组合 | “联合合同成立” |
| E3 | 同一 `Φ` 的精化与不变式 | “同一对象实现” |
| E4 | 可运行实现对拍 | “实现该合同” |
| E5 | 连续真实语言检验 | “在该世界与预算下观察到” |

E1 或 E2 不能越级称作 E3–E5。

## 2. 生命主链的可复用定理

| 主链节点 | 已有 Lean 入口 | 实际结论 | 仍由 `Φ` / 世界接通的部分 |
|---|---|---|---|
| P1 + 守恒 → 有限载体 | `Medium.finite_reachable`、`finite_states`、`NoetherBridge` | 可达状态和守恒账可受限 | 具体语言状态的完整编码与更新成本 |
| 开放边界是维持前提 | `Lives.exposed`、`Lives.metabolizes`、`actualRecover_zero_without_intake` | 封闭/无摄入不能满足相应恢复合同 | 语言边界如何维持未来可用区别 |
| 无限流 + 容量 → 选择 | `GenerationExport.export_forced`、`retention_needs_selectivity`、`InformationEconomics` | 不选择不能无限保留，写入须有信息代价 | 具体 `Z` 的遗忘、串扰与压缩率 |
| 未来区别 → 记忆储备 | `LanguageLifeKernel.CausalState.*`、`futureReservePreserved` | 可读且可递推的未来区别是记忆条件 | 从语言世界取得实际区别族 |
| 延迟结果 → 历史载体 | `delayed_credit_requires_history_carrier`、`history_readout_exists_iff` | 相同当前读出不足以处理不同延迟责任 | `Z` 是否实际保留充分历史 |
| 历史 + 结果 → 学习 | `GenerationColumnMemory.*`、G14、G15 | 指定条件下误差读写/结果调制有正确方向 | 同一局部更新的完整语言收益 |
| 异质经历 → 局部调节 | `Generation.no_fixed_gain_for_two_volatilities`、`no_global_gain_for_heterogeneous_compartments` | 固定全局增益无法同时适配指定异质条件 | 调节如何从共同状态形成且不冻结 |
| 保持与释放 | `GenerationPersistence.*`、`GenerationColumnMemory.latch_*` | 严格收缩排除多稳态；指定饱和与增益可有锁存 | 可达、感知、释放及非赢家通吃 |
| 行动与主动闭合 | `GenerationActiveInference.active_closure`、`Inference.*` | 在供给界/行动敏感世界中不能最终永久被动 | 语言行动、后果与自我模型的共同实现 |
| 语言递推桥 | `GenerationGDNLife.*`、`GenerationLanguageExistence.*` | 若干 GDN 读写、评分和同化条件可被精确表达 | GDN 与局部介质的完整精化 |

## 3. 从必然性到可生成结构

```text
有限容量
  → 选择性保留与遗忘
  → 未来可读、可递推的状态区别
  → 延迟后果前的历史区别（广义资格迹）
  → 结果经边界回到局部更新（三因子条件）
  → 经历与资源在局部接触上竞争
  → 可能形成隔室、分化、保持与释放
```

前五条有各自 E1/E2 证据；“隔室、分化、保持与释放由同一局部 `Φ` 形成”是 E3 目标。不得把条件结论倒写成“每个生命都必须是某种柱、固定维度、显式多巴胺数组或 MoE”。

健康锁存与赢家通吃是同一约束的两面：可存活的保持必须既抗小扰动，又继续感知新证据、允许释放，且不能永久剥夺其余可达状态的更新机会。现有保持、竞争与局部调节定理需在同一状态和世界中共同验收。

## 4. L0–L6 追溯矩阵

| 目标 | 必要链 | 当前最高证据 | 不能代替它的东西 |
|---|---|---|---|
| L0/L6 可存活性 | 开放边界、恢复、保持/失效、同一世界时钟 | E1–E2 分散合同 | 某次预测下降或一个满载状态 |
| L1 自举目的 | 生存筛选 → 内部维持偏好 → 闭环 | E0 定义，部分 E1 条件 | 外置奖励、“我要活”变量 |
| L2 记忆学习压缩 | 有限容量、未来区别、选择写入、延迟信用 | E1–E2 | 无限日志、BPTT 图或一次拟合 |
| L3 世界模型 | 可检验预测、因果行动差异 | E1 局部定义/条件 | 仅当前 token NLL |
| L4 操作闭合 | 输出 → 世界后果 → 边界回执 → 更新 | E1 条件主动闭合 | 内部采样或自听回声 |
| L5 生态位 | 行动改变长期可达语言机会 | E0 目标、E1 局部条件 | 一次请求或静态语料 |

这张表给出 G1 反向切片的根集合：每个目标必须落到具体 Lean 声明、定义或外部世界条件；没有正式声明的格子必须明确为空，不以相邻证明填补。

## 5. 最小生成核的工作方式

最小生成核不是“最少模块”，而是从 L0–L6 反向到 P1–P3 后不可删的声明、定义和世界条件集合。自动切片应：

1. 从上述根集合读取 `audit_inventory` 的逐声明依赖；
2. 保留依赖闭包，合并仅作语法转接的中间节点；
3. 将节点分为定理、定义、外部世界条件、实现合同；
4. 报告每项服务的 L 目标及来源位置；
5. 标记只服务历史见证、玩具或优化器支线的节点；
6. 不把“未找到连接”伪装成新增公理或机制。

切片输出才是架构约束的依据。随后用它审计候选 `Φ`：若候选不能实现某一核条件，给出反例；只有反例强迫的局部自由度才允许加入。

## 6. 当前总装判定

`LanguageLifeAdmission`、`GenerationSelfProduction` 和 `GenerationGDNLife` 已能把若干条件放在一条开放轨迹上，因此属于 E2。它们仍接收世界响应、信号、轨迹对齐或反复机会等条件，尚非从 P1–P3 唯一生成的 `Φ`。

`LocalMedium` 提供局部守恒状态候选；GDN 提供语言读写候选。二者目前只在有限的宏观同化/记忆桥上相接。[`GenerationColumnRefinement`](../../lean/CGBAxioms/CGBAxioms/GenerationColumnRefinement.lean) 已将“同一状态”变成第一份 E3 证明义务：`H,C,S,Trace,Demand` 都从 `Medium.act` 的身体状态读出，未参与事件的局部投影不变，合并历史必须保留声明的读出和后继。它不是具体身体见证；接触流的类型／可观测性、活动保持的感知与释放、以及可扩展 `Φ` 仍须共同给出。完成该精化或给出不能精化的反例，是唯一能决定下一条结构自由度的工程问题。

## 7. 使用规则

新增算法前：本图 → 自动索引 → Lean 源码 → 现有实现；写出“定理—前提—现有状态—缺口—检验”。新增文档不得复制索引；新增模型不得用孤立见证代替 `Φ`；新增实验不得把 E4/E5 结果反推为公理成立。
