# S14 与梯度累积记录审查

目标是判断已有记录能支持哪些时间与学习结论，并保留3D介质后续验证所需的边界。本次仅分析已有日志与源码；没有启动训练或修改果蝇生产实现。

## 三个应分开的时间对象

1. **前向传播时间**：每词输入拍加14静默拍，共15物理拍，真实推进COBA/ALIF/STP与延迟环。
2. **反向信用窗口**：每4词detach，最多展开60物理拍；不同词之间的远期影响能留在状态，跨边界导数在该次反向中截断。
3. **更新数据量**：提案将8块的梯度累积到32词后更新一次。它改变优化器节奏，信用窗口仍为4词。

在累积期间参数固定、块损失按32词平均、每块末detach的条件下，累积梯度等于这些截断块目标的梯度之和。完整BPTT32还包含跨块状态依赖项；两种目标通常给出不同梯度。

## 读出和监督的真实含义

源码对外返回`loss_cert`：读出时刻由预测熵最低选择，不使用答案选择评估时刻。训练使用`0.5*(loss_min+loss_cert)`，其中标签最优时刻仅构成训练辅助监督。

所有15拍先执行完，再挑读出时刻；最终持存状态仍为末拍。这个实现提供多时刻读出选择，尚未实现计算上的提前停机。选择第7至11拍也不能单独定位中央复合体或LAL的因果贡献，需另有解剖干预证据。

## 数值与测试边界

单次累积更新梯度范数204、有限值，支持该次更新可执行；不保证长期收敛或永不爆炸。时变梯度由完整增广状态Jacobian乘积决定；各单步谱半径小于1也不足保证乘积稳定。例如两个交替的非正规矩阵各自谱半径可为0，而其乘积增益大于1。

现有`test_checkpointing_equivalence`验证部分前向与梯度一致，需补齐三处才可声称生产训练完全等价：

- 反传真正的`last_train_loss`，现测试反传的是` scores.sum()`；
- 比较完整物理状态，现测试只比较`h`；
- 检查双方梯度`None`结构一致，现测试只比较双方都有梯度的参数。

激活检查点通过重新计算降低激活存储；它不改变原目标的信用窗口，也不直接消除梯度放大。

## 决策

保留S14的正向学习证据与检查点。梯度累积作为优化器节奏方案可以采用，准确命名为“TBPTT4／累积32”，不作为跨32词信用修复。目前无需新增训练来确认上述区别。S14相对S4的增量任务优势仍待匹配数据、预算与信用窗口的比较。

附件清理记录明确删除了两条`medium_v8_joint_bptt32_96k`训练目录中的权重。原3D个体的真实数据可达性与内部时间验证因此失去起点；已完成的数值检查保留原范围，后续真实数据验证需恢复备份或重新生成明确登记的起点。
