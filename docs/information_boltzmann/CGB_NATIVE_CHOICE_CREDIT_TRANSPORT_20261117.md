# 内部拓扑活动怎样成为选择与后到学习

## 1. 按实际身体确定测量映射

`navigation_generative_cycle._sample_internal_choice` 的两条路径为：

- 内容：`binding_feature` 生成388维向量 `[z, a-z, predicted_mother-z, role_tag]`，前三块各128维，标签4维；共享的无偏置线性 `binding_choice` 读它。
- 价值：两次 `compose` 的 `value` 经 `wood_choice_logits` 转成选择先验，加入同一二分类logit。

内部选择中source=action，因此第二内容块逐项为0。第一块是内部状态的编码，第三块是预期回应相对该编码的差。本轮运输旋度干预发生在预测下一身体状态的端口，实际388维内容向量保持相同，差异沿继续价值先验进入选择。

设内部选择s属于{0,1}，p为选择内部的概率，f0/f1为两条实际内容向量。现行线性选择器的资格为：

`e = (s-p) (f1-f0)`。

`autonomous_cycle.poll` 每次累加此导数；`take_boundary` 在交话时把这段参与移交给真实行动；`add_boundary_credit` 加入原行动的梯度记录。`world_learning_cycle` 保存这次行动，下一次真实外界事件由 `_settle_previous` 形成后到advantage，最后一个实际文本片段的 `_advance` 将 `-advantage * eligibility` 加入梯度，再执行原裁剪、预算与AdamW。

### Lean与原数据绑定

`reviews/NativeChoiceCreditTransport.lean`证明388维实际线性端口上的二分类资格公式、两条内容相同时内容资格归零、固定内容下先验变化只缩放原差向量，以及后到因子对累计资格的分配。

共读取7个已完成分支、119次内部选择。按原FP32两项系数重构累计资格，范数与运行时直接记录的最大差7.60e-7。证书与源码哈希随报告保存。
