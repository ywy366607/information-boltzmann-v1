# 恒定含量下的物质周转：生命目标 v0.14（2026-10-23）

海绵动物与大肠杆菌作为低复杂度生命正参照，促使我们检查“摄入”的代理量。旧 `Operational` 使用的 `Medium.materialIntake` 实际检测身体总含量增加；它适合观察净增长，却把总量恒定的替换也记为零。修复的研究问题是：如何观察持续进出，同时保持原身体—世界动力学、世界时钟与规则预算？

本轮完成通道级观察、一个恒定含量正控制，以及账本不能识别真实交换的反控制。用户的无限流生命体定义原文保留；六条物理公理、旧目标定义与旧证明均保留。

## 1. 从净变化到进出通道

令 Q 为身体总含量，给每个事件 a 登记自然数输入量与输出量。`Medium.MaterialLedger` 要求正速率事件满足：

```text
Q(act(a,s,x)) + outgoing(a,s,x) = Q(x) + incoming(a,s,x)
```

闭合事件在正速率下的两项均为0。这与已有P2a兼容，且由账本约束可推出P2a（`ledger_p2a`）。已证：

- `net_increase_implies_incoming`：正速率下净含量增加必有正输入。
- `equal_content_iff_balanced_exchange`：正速率下含量不变，等价于进出数量相等；相等可以是零，也可以是正数。

这保留了诺特桥接所约束的闭合守恒，并把开放边界的净变化与双向周转分开。物料数量与化学能、自由能、熵流分别建账；下一步需要把通道连接到世界端实际供给及热功对应。

## 2. 观察自事件，保持原过程和时钟

原 `jump` 不记录 `act(a,s,x)=x` 的事件，因而状态核本身看不到这种周转。`EventChannels` 增加事件标签：`some a` 表示该通道发生，`none` 表示空闲。标签属于观察接口；没有把外部事件历史装入身体状态。

世界时钟仍为原 R。每拍通道概率为 `rate(a,s,x)/R`，剩余概率为真正空闲。这一表示要求：

```text
EventClocked R := 0 < R ∧ ∀s x, Σ_a rate(a,s,x) ≤ R
```

原 `Clocked` 只约束有效状态退出率。已证新准入蕴含旧准入；反例 `fastBody_old_clock` / `fastBody_no_event_clock` 展示：全是自事件、总速率2的身体可通过旧R=1准入，却无法通过新通道准入。这里加强的是每拍至多一次通道事件的表示条件，不新增物理公理。超出准入时需另建保留世界时间的观察方式。

关键保持证书：

| 证书 | 保持内容 |
|---|---|
| `Medium.eventStep_forget` | 对事件标签求和，精确恢复原身体核 |
| `Medium.jointEventKernel_forget` | 正常/剪断分别恢复原联合核 |
| `EventChannels.Kernel.labelledLaw_marginal` | 任意时刻标签律的状态边际等于去标签状态律 |
| `Medium.jointEventKernel_stateLaw` | 任意时刻精确等于原 `law` / `lawCut` |
| `Medium.event_state_mark_matches_operational` | 若仍标记净增加，则精确复现旧 `Operational.recovery` |

首次通道摄入允许标记依赖当前世界时间与实际刺激协议，并证明概率位于[0,1]。正常/剪断分支继续各用自己的未来核；剪断评分没有接回正常世界。

## 3. 可区分的控制与识别边界

`TurnoverControls` 是数学语义控制，不是海绵或细菌模型，也没有训练任何能力任务。身体只有一个位点，事件保持表示状态；其全部六条公理与事件时钟准入已证。给定世界和初态后：

| 同一身体与世界 | 净增加观察 | 新通道观察 |
|---|---:|---:|
| 登记输入=输出=1 | 任意有限时域恢复为0 | 一拍恢复为1 |
| 登记输入=输出=0 | 任意有限时域恢复为0 | 任意有限时域恢复为0 |

正账本下，初始身体保持非空，所有时刻的物料存活量为1，故 `balanced_exchange_persists` 满足新物料持续性，δ=0。此见证只证明物料持续性；完整候选还要求感知中断耐受与闭环相对剪断收益。完整L1–L6、认知功能和1%编码候选继续单独构造。

`ledger_not_identified_by_state_dynamics` 同时证明了识别边界：两个账本都满足平衡与闭合约束，却对完全相同的状态动力学给出不同摄入观察。因此，平衡账本是声明的通道接口，真实交换仍需外界来源、传输和实现证据。不能通过给恒定状态任意填入相等正数，就宣布它有代谢。

旧 `LifeControls` 的“冻结排除”因此应精确理解为：所表示身体状态恒定时，旧净增长标记为零。物理零交换则由通道及来源判断。新 `Exchange.not_persists_without_incoming` 证明零输入账本不能满足新物料持续性；保持排除零输入的同时，允许观察恒定含量的替换。

```text
0 < sites² ∧ 100 × bits(完整ExchangeBook) ≤ sites²
```

`Exchange.EncodedCandidate` 要求六条公理、新事件时钟准入、扩展描述预算、边界耦合、世界丰富度、物料持续性、感知中断耐受与闭环收益。这是版本化的物料子目标，不直接等同完整生命定义。旧 `Operational.EncodedCandidate` 保留为实际过程的净增量版本；没有暗改旧接口或宣称两个目标等价。
