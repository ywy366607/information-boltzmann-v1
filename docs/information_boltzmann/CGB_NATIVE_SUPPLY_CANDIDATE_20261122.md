## 数学到实际身体的映射

原文：[SADL, arXiv:2611.21596v1](https://arxiv.org/html/2611.21596v1)，[作者实现](https://github.com/zju3dv/SADL)。现行任务损失与 live SIGReg 保留，新增系数固定为 0.01 的供给项。

| 数学对象 | 实际对象与更新资格 |
|---|---|
| H | `LiveSigregBody.objective` 返回的当前原始特征 h，与 memory 中有效的原始历史特征拼接；维数 256 |
| Z | 同组 H 经现有 `model.encoder` 编码；维数 128；供给项中停止 Z 梯度 |
| D(Z) | 原目标实际计算的 `diag['sigreg']`，停止梯度 |
| D(0) | 同一有效样本数、17 个积分点、原梯形权重的全零精确参考 |
| q | `sqrt((clip(1-D/D0,0,1)+eps)*(F_exc(Z)+eps))` |
| k | `min(F_exc(H), F_tr(H,sg Z))`，相对岭系数 0.001，gamma=9 |
| S | `relu(log(q+eps)-log(k+eps))²`，eps=1e-8 |
| 可更新对象 | 供给梯度经当前 h 回到原身体；历史 H 保留其存档值，编码器仍接受原任务及原 SIGReg 梯度 |

激发量使用非中心化总能量与中心化协方差的比值；相对岭的 H 侧尺度参与求导。数值运算使用 FP32，导数合同测试使用 FP64。历史只保留数值，当前 forward 复用原图。

代码：`scripts/ib_local/native_supply_regularizer.py`。作用域入口：`scripts/run_native_supply_life.py`。每次 objective 保存 q/k/供给损失和梯度资格；首个可求导 objective 保存实际当前 h 的供给梯度范数。

## 继承的数学结果与实码核对

`lean/CGBAxioms/reviews/SupplyDemandDynamics.lean` 已编译 7 个命题。其欧氏参数梯度流的局部主动支路满足对数缺口的漂移—阻尼分解，缺口能量功率由移动需求输入与阻尼耗散组成。这里的平方梯度取可更新参数的梯度；历史 H 作为当前目标中的固定参考。实际身体保留原优化器与动量，实码合同核对梯度方向及所有权，作用通过完整学习轨迹量取。原论文的全特征梯度流性质按其前提使用。

`tests/test_native_supply_regularizer.py` 的 6 项检查覆盖：原 SIGReg 的全零参考；H、Z 与需求的梯度归属；相对岭/能量尺度导数；已满足供给时零力；有效历史样本轴；异常退出后的原方法恢复。连同原激活存储/运行时测试，15 项通过。

**本轮决策：梦漓沿用原训练目标，供给候选作为默认关闭的显式实验入口保存。** 下一接口与已有目标闭合、弱读出和 Claude 的反事实线路衔接：需求端追踪同一实际条件下两个合法行动的后果差，供给端追踪能改变该后果差的身体/经历方向。`CounterfactualActiveInference.posterior_contrast_correction` 已把应更新的量刻画为后验行动差与事前行动差的偏离；本接口复用这一对象及现有实际成用记录。它将几何供给接到行动相关的信息需求。
