## 一个参数化尺度关系

本轮从目标函数推出，并据此在 256 维结果出现前登记了额外的 70、140 两档补测：
`C -> t C, A -> A/t²` 保持全部匹配预测不变，但会改变正则。
记 `a=mean(C²), b=mean(A²)`，最优尺度满足 `a t² = 2 b/t⁴`。
将同一相互作用补零放进更宽的 k 维码，并重新平衡尺度，最小惩罚随 `k^(-4/3)` 缩放。
因此等强度正则应满足 `lambda_k = lambda_64 (k/64)^(4/3)`；256 维对应约 6.35 倍。
这解释了原先“大码需要更大的正则”的一部分原因，也给后续细网格提供了尺度。
它是离线参数化的代数结果，不是营养或物理能量定律；最终维数选择仍由验证误差决定。

## 结果如何进入生成脑

强度生成器接受类型身份和真实几何特征，输出每个可能细胞对的对数突触强度尺度；
CPU 执行按请求的类型对分块，保留三千类身份码，不保存九百万项的逐对强度表。
“是否连接”的生成规则与“相连后强度”的规则分开，后者在本轮的相连类型对上评估。
这轮稳定的是先天匹配部分；个体经历中的局部可塑性、资源维持与动作闭环继续由介质承担。
