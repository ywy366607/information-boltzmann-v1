## 从现有方程推导，不增加捕获规则

冻结实际正标签，a_e=κ[z_e]+。记D_i=δF+Σ_post(e)=i a_e，终扣运输存活率b=ν/(ν+δT)，胞体再释放存活率c=ρ/(ρ+δH)。若所有相关退出率为正、δF>0，节点总到达通量s_i满足

    s = q + W s
    W_pre(e),post(e) += b c a_e / D_post(e)
    F_i=s_i/D_i
    T_e=a_e F_post(e)/(ν+δT)
    H_j=ν Σ_pre(e)=j T_e/(ρ+δH)

W的每列和≤bc·(D_i−δF)/D_i<1，故该冻结系统具有唯一有限非负稳态；各条路径贡献由(I−W)^−1=I+W+W²+…给出。这里是同一支持物质在清除、摄取和运输之间竞争的结果；不是新适应度或行为评分。W²q为零意味着此工作点没有两次再释放路径，但实际变化的标签可先后打开，不能用冻结结论否定动态可能性。
