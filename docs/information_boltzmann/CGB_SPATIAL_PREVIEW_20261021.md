# 空间生成与可视化：候选发育程序

在运行前登记：这次交付可执行的空间出生候选与真实状态回放，不做语言能力试验。

## 画面对应什么

192个独立细胞，取自已知48种身份，每种4个；每个细胞有输出和输入生长锥。
已拟合身份码经固定随机投影得到导向受体；高斯空间场、方向惯性与噪声驱动生长。
这是候选的“身份→形态”程序，没有用成年坐标或复制邻接表，也尚未拟合生物形态。
参数完整保留。每个细胞有有限生长锥槽位，新增缆线按长度从同一局部材料B扣款。

2µm／4µm体素里的输出缆线×输入缆线产生相遇代理。连接发生暂用
`P=1-exp(-κE)`的独立接触候选，κ明确记录为未校准参数。
初始强度使用已锁定的V3d有方向64维规则；几何按原4/2µm、正反方向和
每类型细胞对的归一化构造。报告相对拟合特征的外推量，不把生成几何当作已验证分布。

枝条占用材料进入reserved账，连接合成继续用剩余B；这两者不重新领取出生预算。
生成完成后，接入现有V2介质，短段读取书架里真实《伊索寓言》文本。
文本经固定哈希映射为少量输入细胞的电流；不训练读出、不计算虚构NLL，
不宣称理解故事、说话、自我或世界后果信用已完成。
活动颜色来自实际膜电位／放电，连接颜色来自实际结构与支持；不用随机闪烁充当活动。

## 数值／接口验收

- 同一种子和完整存档恢复后，生长、分支和账本逐位相同。
- 已长缆线长度×单位成本等于reserved账，逐供体材料误差≤1e-10。
- 不共享体素的输入／输出分支没有相遇；没有相遇的细胞对不生成连接。
- 短段共读中，介质运行时间、状态和材料账均来自实际运行；完整保存生成状态与介质。
- 浏览器支持旋转、缩放、时间拖动、暂停，切换分支／连接和选择细胞；面板标明来源与未验收项。

这些检查验收工程与规则实现。形态、发生概率、电导换算、生理类别和学习收益还需
独立校准与真实流实验；本预览不替代总体框架的出生／生命能力验收。
