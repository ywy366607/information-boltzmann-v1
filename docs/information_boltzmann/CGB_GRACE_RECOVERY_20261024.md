# 一拍感官中断恢复与配对控制（2026-10-24）

旧实例的失败定位在一个具体事件：感官中断跳过付费重开候选的机会，身体继续用旧动作进入探测窗口，世界随即将它送入不可恢复状态。本轮保留身体与学习费用，显式登记可补救的世界条件，构造任意起点的一拍中断恢复证书，并重验原剪断收益和实际物料账户。

这是有限数学见证与接口验收，没有运行训练或能力实验。结果仍归入主文 T-AM，以三组结论组织。

## 1. 可补救世界与恢复窗口

| 项目 | 旧实例 | 新实例 |
|---|---|---|
| 身体、输入与世界状态数 | 8、7、9 | 相同 |
| 身体局部规则、摄入与学习支付 | `plant true true` | 相同 |
| 事件时钟 | 1 | 1 |
| 活身体在探测窗口使用错误动作 | 进入 trap | 返回对应 miss 冲突 |
| 登记恢复窗口 | 2拍 | 3拍 |
| 正常过程逐时评分 | 1 | 1 |
| 任意起点的一拍中断逐时评分 | 第四拍起中断会失败 | 所有起点与观察时刻均为1 |
| 原边际幽灵剪断评分上界 | 第六拍起≤3/4 | 第七拍起≤3/4 |

改变的是探测失配后的世界反馈及声明的恢复时限。正确探测与正常可达区域上的世界转移完全保留；身体继续依靠原有 Ready 状态、冲突反馈与付费候选重开完成恢复。世界仍只读取身体边界，本实例的唯一位置本来就是边界。

`Medium.interrupt` 沿用原定义：任意 n₀ 开始的一拍给 calm 输入，世界持续推进；其后恢复实际感官输入。没有向身体加入中断起点、倒计时、未来输入或额外记忆。

`ScheduledRecovery` 将既有有界进展判据推广为随外部协议时间变化的区域与自然数分析量：有支持转移保持下一时刻的区域，未实际摄入的事件使分析量严格下降，分析量始终小于登记窗口。由这些局部条件推出同一实际过程的首次摄入概率为1，再以正身体含量推出原 `Exchange` 评分为1。这些对象只用于证明。

`GraceRecovery.one_tick_survival n₀ n` 对所有 n₀、n 证明评分等于1，直接接回原 `ToleratesSensoryInterruption`，参数为 δ=0、T=1；`natural_survival` 证明正常评分全时为1。

两项独立控制解释条件的作用：

- `horizon_change_alone_fails` 保留旧世界的致命探测反馈，仅将窗口改为三拍；第四拍的一拍中断仍使第六拍评分至多为1/2。
- `two_tick_lookahead_insufficient` 在新反馈世界中，从第四拍的 aReady/missB 状态出发、第五拍中断，两拍内实际首次摄入概率为0。独立复核以同一协议、时刻与状态证明三拍为1：第四拍冲突不摄入，第五拍 calm 不摄入，第六拍回答阶段才摄入。登记窗口必须计入这段延迟。

旧世界的所有正长度中断失败证书保持原样。新证书表明补救机会与恢复时限能共同支持这一身体的一拍恢复，并明确了结论成立的环境条件。

## 2. 原剪断收益继续成立

剪断继续使用原 `Medium.cutMove`，按实际边际分布执行幽灵身体干预，没有为新实例换一个更容易的对照。

在第六拍，剪断分布中 search/missB 的质量为1/4。该冲突发生在缺少 Ready 储备的身体上，下一拍身体清空。`dead_seed` 因而证明第七拍空身体质量至少为1/4，空身体的吸收性将下界传递到所有后续时刻。

`cut_survival n` 对 n≥7 证明原评分≤3/4。结合正常评分1，`maintenance` 同时提供原 `Persists`、一拍 `ToleratesSensoryInterruption` 与 `SelfMaintains`。正常与剪断比较共用新世界、身体、时钟、物料函数与恢复窗口。

补救规则没有保证所有身体状态都可恢复：它允许原有足额储备发挥作用，而剪断产生的缺储备冲突仍造成实际损失。

## 3. 学习支付与物料来源接续

`GraceRecoveryAccounting.path_budgets` 对任意输入协议、正常或剪断分支及每条有支持有限路径，证明两本原账户：

```text
期末身体含量 + 累计释放 = 初始身体含量 + 累计实际摄入
期末信用 + 累计完成改写 + 累计丢弃信用 = 初始信用 + 累计实际补入信用
```

Ready 冲突重开与 search 回答辨识仍按原规则支付；信用属于身体含量的子账户。`arbitrary_relearning k` 保留任意给定 k 的正概率再学习前缀（长度3+10k），累计改写1+4k、补入信用2+4k。该结果证实任意有限次数的可行路径；长期几乎必然频率另以路径测度检验。

固定身份物料实现沿用12个载体、身体含量上界4、源库存4。`realized cut sched` 对任意登记协议及正常/剪断分支给出精确时钟与联合律实现。实际源到身体的身份搬运对应摄入，保留所有有限恢复时限及逐时评分；`physical_one_tick_survival` 因而将全时评分1传到实际载体过程。

身体加源库存初始能量为6，所有有限前缀满足：

```text
期末平均储能 + 累计平均释放 = 6 + 累计平均外界再充能做功
```

返回旧载体的再充能由显式端口支付，内部源到身体的转移不重复计外界能量。`calm_has_no_intake` 单独核验中断拍的实际摄入为0。这里沿用已登记能量刻度，物理热力学标定继续单独建立。

## 范围与下一步

本轮沿用原生命定义、六条介质公理与评分公式，扩展的是实例条件和恢复证明工具。五个新增模块承载三组结论；辅助声明与编译器生成项目作为审计清单报告，主文没有新增主定理行。

一拍中断证明为更长与反复中断提供起点。当前 calm 会冻结身体事件，因此要研究有限储备导致的失效临界，应先明确哪些维持需求在感官中断期间继续消耗，再组合恢复与支付证书。仅延长 calm 或放宽恢复窗口不足以定义真实的饥饿临界。

单位置规则书的登记1%预算障碍仍成立，8身体状态对9世界状态仍只支持 κ≤1；下一步空间共享与世界扩展应使用实际参与的结构。身体规则归档保持原样，完整载体选择算法及接口编码继续计费；本轮没有据此宣称完整L1–L6目标。
