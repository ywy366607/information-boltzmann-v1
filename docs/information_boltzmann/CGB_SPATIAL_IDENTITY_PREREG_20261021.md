# 空间身份程序补充预注册（2026-10-21）

先前固定 V3d 强度残差码的跨类型形态预测只降低约 2.6% 留出误差。这是已经读取的结果，不是新检验的盲测。V3d 先控制几何再学习强度，因此不要求其残差码再次编码全部空间。出生程序改为共享类型身份下的两个部分：空间表型码，以及有方向的连接识别码。

本轮估计**已知类型的新细胞**形态描述分布，不声称生成未见类型或恢复真实树拓扑。每个类型最多14个实数，不能读取测试细胞的骨架。目标为 soma 3、质心相对 soma 3、log 总缆线长度 1、log 协方差 6、log 分支密度 1。左右通过训练集估计的矢状中线反射共享空间程序。

仅使用有有效 soma 的 L/R 细胞。每类型按固定随机种子20261022打乱 body ID；至少3个细胞的类型，留出约10%验证、10%测试，分别至少一个，其余训练。1–2个细胞的类型仅训练，不计入留出结论。按类型等权评价，报告验证/测试覆盖，不与前轮跨类型任务混同。

用训练细胞拟合每类型 canonical 描述均值，向训练集类型等权全局均值收缩。收缩伪计数 alpha 网格为0、0.1、0.3、1、3、10、30、100，由验证误差选取。锁定 alpha 和拆分哈希后才读测试误差。比较无类型的 canonical 全局均值。所有标准化、中线和 seed 扰动仅来自训练集。

出生时从类型空间程序生成位置与目标场；有限生长锥沿目标场局部延伸。此动力学仍是候选实现，描述分布的留出检验不等于生成树形已验证。发生率必须用总缆线重叠，与真实面板的非极化特征一致；条件强度仍单独使用方向性几何。生成形态相对目标的误差、长度完成度及外推另行报告，不用图像相似替代检验。旧空间候选和全部失败证据保留。
