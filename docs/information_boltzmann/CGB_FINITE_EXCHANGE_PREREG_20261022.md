# CGB：有限占据与驱动交换的局部物理核

2026-10-22，运行前登记。沿Claude核心文档§0的守恒、饱和、质量作用与§3b的逆向支持，补“维护不应只依赖瞬时增强”的物理过程。不是另建目标梯度，也不要求新的载体具有生物酶／囊泡。此轮是局部交换与热力学接口，不宣布完整生成脑或学习。

## 最小声明与方程

支持组成具有三种位置／结合形态：节点游离量F_i、边上结合量C_e、返回上游后的量H_i。每条边有有限接触容量S_e，空位为S_e−C_e。另有每个节点固定总量的两种驱动态P_i、D_i，P的单位能量高于D。F/C/H彼此转化时不复制支持，P/D转换不增发驱动组成。

使用参考体积与浓度单位，热能kBT=1。C、H、P相对于F／空位／D的单位能量为εC、εH、εP。这些值和接触容量、势垒速率都是声明的有效本构参数，守恒不唯一决定它们；本轮取值仅用于数值接口，尚无生理／几何校准。

对神经方向e=(j→i)，允许的支持交换为：

    F_i + 空位_e ⇌ C_e
    C_e + P_j ⇌ H_j + 空位_e + D_j
    H_j ⇌ F_j

正反通量分别为

    b+ = k_b F_i(S_e−C_e), b− = k_b exp(εC) C_e
    t+ = k_t C_e P_j, t− = k_t exp(εH−εC−εP) H_j D_j(S_e−C_e)
    r+ = k_r H_j, r− = k_r exp(−εH) F_j

支持库与驱动库分别守恒。定向运输消耗P并产生D，逆向可回收；不是只允许正向转移再另添衰减。退出运输的C释放接触位点。基本结合不读取正标签或活动频率，因此不要求结构为继续得到支持而反复增强。局部选择／慢结构转化仍沿原E5/E6作参照，尚未耦合到此物理核，不能从基本结合推出有用学习。

## 自由能与正反偏置

对x≥0记φ(x)=x(log x−1)，φ(0)=0。

    G = Σ_i [φ(F_i)+φ(H_i)+φ(P_i)+φ(D_i)]
        +Σ_e [C_e log(C_e/S_e)+(S_e−C_e)log((S_e−C_e)/S_e)]
        + εCΣC + εHΣH + εPΣP

S=0的边必须C=0，无结合通道。每一事件正反通量之比等于相应自由能下降的指数，例如

    log(b+/b−)=μF−μC
    log(t+/t−)=μC+μP−μH−μD

故每对通量的熵产生为(j+−j−)log(j+/j−)≥0；无外源的该子系统满足dG/dt≤0。改变共同的k只改变势垒／速度，不改变这一正反偏置。没有给模型传入损失梯度，没有把NLL当能量。

内部能量U=εCΣC+εHΣH+εPΣP。闭合等温过程的向外热量Qout=−ΔU，系统熵Ssys=U−G，故ΔSsys+Qout=−ΔG≥0。这是声明的有效等温物理模型；真实硬件能耗和参考单位到生物参数的映射尚未建立。

有限P/D只携带初始可用自由能，不在内部无偿补充。持续开放驱动需另给有限速率边界交换及其输入功；此轮未加一个隐形再充电源。

## 数值推进与空间资源

冻结速率，分裂为三组可逆过程。F/空位结合复用已有有限槽位隐式解；共享H/P/D的运输用每个pre单元的一维守恒隐式解；H/F交换有解析二态解。每组保持可行域；顺序是一阶数值选择，需时间收敛。

运输组令X_j为节点总正向净运输，H1=H0+X、P1=P0−X、D1=D0+X，则

    C1_e(X)=[C0_e+h k_t exp(εH−εC−εP) H1_j D1_j S_e]
             /[1+h k_t P1_j+h k_t exp(εH−εC−εP) H1_j D1_j]
    X_j+Σ_pre=j C1_e(X_j)−Σ_pre=j C0_e=0

在物理区间max(−H0,−D0,ΣC0−ΣS)≤X≤min(P0,ΣC0)内，C1随X单调不减，根唯一。没有先制造负库存再裁剪。每一步只保存F/C/H/P/D、固定容量、当前时钟及少量累计账，O(N+E)，不存BPTT历史。能量账包含所实施离散映射的数值耗散，不能把隐式步带来的全部自由能下降都当成连续模型的真实耗散；步长收敛单独检查。
