# 木的搜索、语言表达与训练成本：实码对账

2026-11-24。用户要求解释草稿、教师端点、主干前反向、四路策略梯度及剩余加速空间。本轮只读核对当前源码、已完成报告与原论文；新增训练/世界调用0。

## 当前实际流程

- `navigation_joint_cycle.JointCycleMixin._film(None)`从同一真实边界独立生成4份话语草稿，再通过原关系模型的预测用途选择其中一份。外层另比较沉默、生成和复用。画像里的5路film调用与4份采样草稿属于不同计数。
- `variable_expression.film`对未知话语逐字节采样，每字节推进完整身体、快表和交话判断；这些是行动候选，不是MTP推测解码器。已知载荷长于32字节时已分派到`known_utterance_runtime.known_film`整段前向。
- `prospective_self_execution.execute`在当前物理锚点和假设问题上下文下重执行已知旧话语，计算其身体终点，供原生教师/未来决策端口使用。已有`native_word_batch.endpoints(batch_size=8)`及严格作用域缓存；同一词串在不同问题/参数/物理锚点下可具有不同终点。
- `navigation_joint_cycle._policy_grad`重算分类选择及全部4份草稿（字节和交话）的采样梯度。实际延迟行动后果调节这些资格。当前是联合搜索过程的策略学习；GRPO使用多输出各自评分及组相对优势，目标不同。
- `world_learning_cycle`对真实字节执行语言/潜预测目标、保持测量、真实后果学习、延迟信用、完整优化器和状态推进。此前K4失败及回放修复直接继承，保持旧经验学习的频率必须随新调度一起核对。

## 已有加速直接继承

已知话语整段前向、同作用域草稿自听复用、4路策略梯度合批、8路撤回合批、教师已知话语端点合批、关系预览作用域、投影/寻址缓存、SQLite增量写等已有实现。当前新报告`cgb_alif_fast_utter_600s_20261124.json`为611.34秒/129600字节/211.99 B/s；43次完整脉冲与138片640B平静流。后续优化以此实际实现为对象。

## 原论文对应

1. DeepSeek-V3 §2.2、§5.4.3：MTP用于辅助训练，也可作为低成本提议配合目标模型验证进行推测解码。它减少生成同一输出所需的昂贵串行步骤。https://arxiv.org/html/2412.19437v2
2. LeWM §3.2、附录B：候选动作通过潜预测器展开并比较目标潜距离；视觉解码器供展示。它同样搜索多条轨迹，搜索中的图像重建成本已被移除。https://arxiv.org/html/2603.19312v3
3. H-JEPA §2.2：高层潜目标向下交接，底层返回可执行动作；可视化解码后置。https://arxiv.org/html/2610.06805v2
4. H-Net §2.4：外层仍逐字节自回归，动态边界决定何时推进内部深层网络。论文主要提供数据/FLOP配平比较；本文不采用未经本机验证的“比BPE慢10%—25%”或“本系统2.5—3.5倍”墙钟系数。https://arxiv.org/html/2507.07955v1

## 最高价值的下一对象

第一优先是把候选意图比较与具体话语生成分开，复用当前`latent_action_planner`、原条件银行、目标闭合和实际选择贡献验收。已有后继价值摊销主要加速“假设后继里的下一次决策”，当前根决策仍生成4份完整话语。

需要明确的目标是：潜行动z的估值应对应在当前完整边界B下，执行器由z生成实际话语w、世界返回真实后果后的用途期望。即Q(B,z)对该表达分布和世界后果取期望。最终选定意图后生成实际话语，用实际端点和后果校准；原生完整搜索保留作纠偏/教师对象。原代码已有名为`LatentDraftEngine`的早期版本，但其动作取自具体草稿终点，不能据名称认定已完成先潜规划后表达。

第二优先是原生教师预算分配与端点查询去重。缓存按参数/物理状态/问题/表和经历版本绑定，稀疏精算依据可能翻转行动排序的误差，继承11月20日已做的竞争行动教师与条件摊销结果。

第三优先是低成本表达提议/批量验证。MTP、小执行器或快表提议都需绑定字节分布、交话决策、快表先读后写、读路由版本及实际资格，先比较接受率和端到端时间。多个候选序列本身可在B轴并行；与单个序列未来未知字节的串行依赖分别处理。

主干学习优化继续以真实算子剖析决定：逐字节小批量前向、多次同步与核启动，不能仅凭FP32耗时推定已达到硬件算力上限。扩大1280B会同时改变优化器调用频率、回放剂量、物理步进和ALIF时钟，必须逐项映射。

## 成本量级

按用户提供的单脉冲10.37秒口径，film1.25+教师端点0.99+策略梯度1.02共3.26秒。即便把三项全部移除，高层占总时间78%时，原211.99 B/s的理想整体上限约为`211.99/(1-0.78*3.26/10.37)=280.9 B/s`，尚未计新路径成本。这为优先级定量，后续更高吞吐需要同时改善学习路径、因果规划或调度。

H-Net的4层外编码+24层深主干+4层外解码，在层成本相同且主干压缩4.5倍时，层步成本为`8+24/4.5=13.333`，相对原32层的神经部分理想比为2.4。系统墙钟还需计路由、打包、存储、关系执行及硬件效率。
