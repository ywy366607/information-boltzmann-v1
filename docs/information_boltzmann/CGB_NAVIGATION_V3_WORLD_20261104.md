# 第三版语言世界：索引修复与离线重放

本页承接 [第二版审阅与第三版交代](CGB_ACTIVE_LATCH_NAVIGATION_20261104.md#11-第二版审阅与第三版交代claude11-04-下午)。五行是共同动力学的关系与诊断，不按名称添加控制器；整体仍要把语言预测、记忆、可塑性与行动后果接在同一个持续个体中验收。

## 已实现：世界侧去掉首批位置偏置

`scripts/ib_local/language_navigation_world_v3.py` 对每个哈希桶使用真实来源位置的蓄水池抽样；同等最长匹配的候选由世界自己的 RNG 决定。哈希碰撞仍需核对真实 4 字节。无匹配或沉默时沿世界游标顺读；世界耗尽抛出异常，不循环冒充无限世界。RNG 与来源暴露记录纳入世界快照；暴露图只记录评估，不参与选择回应。

哈希桶会容纳不同 4-gram 的碰撞，等分的是桶内出现次数；响应等分的是被索引到、具有相同最高匹配分数的候选命中，重复命中可能代表相同位置。它不是在所有语义上合适的全文段里均匀采样，也不是完整自然对话。`SequentialResponseWorld` 提供“个体仍可发言自听、世界只顺读”的后续控制接口，当前尚未接入训练器。

## 固定发言的离线重放

对第二版主动臂 2500 条实际 utterance 原样重放；仅变更世界，身体不重新学习。同一预算 240 万字节，单位是来源位置，非语义新颖性。

| 世界 | 来源字节 | 位置重访率 | 后续段全部为此前未暴露位置 |
|---|---:|---:|---:|
| 旧索引 | 15993506 | 92.48% | 6.60% |
| 蓄水池、相同来源 | 15993506 | 60.13% | 39.08% |
| 蓄水池、扩大来源 | 40128875 | 50.34% | 49.00% |

原始统计、数据与日志哈希在 `results/cgb_language_navigation_v2_20261104/broad_world_offline_replay.json`。离线结果支持旧索引造成的范围限制，但不能说明重新训练后它会如何行动或语言质量会如何变化。扩大来源约为计划 240 万外界字节预算的 16.7 倍，语料仍是有限的。

## 尚须接成同一个体

1. 行动停止需要单独的可学习决策，不能把 0–255 的某个合法字节默认为结束；停止/继续的采样概率和后续结果要能进入同一策略信用。每 960 字节才允许决定一次即便能发空串，仍是固定行动机会。应在有界处理块内允许由身体状态决定何时发起，并保持训练、快表及递推的真实时序。
2. 行动经历记忆以决策时的身体状态和发言为前提，保存实际后继与后续结果，严格先用旧表预测再写新经历；它必须接入预测、取回及学习，跨窗口的内容重编码不自动等于历史写入的精确因果梯度。4096 条、最多一条每次经历只给出事件容量，不能保证一定覆盖 400 万字节或保证内容可用。
3. 第三版需在同一身体上比较主动、静默、说话但世界顺读，以及潜读开关；保持外界字节和更新预算、来源划分及随机状态可追溯。原第二版两条控制继续运行，不在其结果出来前修改运行源码。

Lean 约束依然是 `action_condition_required`、`delayed_action_credit_requires_state_separation` 与 `causal_carrier_contract_iff` 所写的条件；重新编码只接 `reactivation_exact_held` 的固定权重局部值路径。更宽的世界或新表都不自动证明这些条件在整体成立。
