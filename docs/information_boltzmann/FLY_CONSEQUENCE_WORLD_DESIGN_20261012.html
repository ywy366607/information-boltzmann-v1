果蝇的第一个后果

到目前为止，果蝇说什么都不会改变它接下来看到什么。这份设计先解释为什么一路上碰到这么多问题，再设计一个最小的世界：动作改变未来输入，后果短、清楚、经由连接组原生的味觉通路进入大脑。

2026-10-12前置提交 5510dd01 拍 = 1 ms个体：稳态出生的新生对照（b2_control）

为什么问题这么多

一路上的否定结果看起来很杂：精度门是惰性的，多巴胺没有因果，在线规则没有效果，蘑菇体不被使用，多想没有价值，内在自我模型不存在，新生大脑全静默，核心变成节拍器……但它们只来自四个根源，而且大部分来自第一个。

根源我们碰到的症状修法
A. 世界是开环的
被动读文本，输出不改变下一个输入		 调质细胞的精度门惰性；多巴胺跟踪惊奇但没有因果；在线规则在成年和新生个体都无可测效果；蘑菇体静默损失 ≤ 0.002（新生个体也一样）；成年个体多想几拍没有价值；机会成本没有可分配的东西；找不到内在自我模型 一个动作有后果的世界（本设计）
B. 连接组只给了线，没给细胞
没有离子通道、静息电位、突触位置、受体类型		 新生个体 86% 静默、多巴胺细胞 0 Hz；成年核心 140 Hz 节拍器；Kenyon 轴-轴突触被当成树突输入，Kenyon 细胞变成稠密池；多巴胺把奖赏（PAM）和惩罚（PPL1）混在一起，也不分隔室 稳态内在可塑性 + 孕育期（已做）；neuPrint 脑区修正（已做）；按隔室的多巴胺（本设计，待验证后才加）
C. BPTT 是一个太强的老师 它已经给了逐词的完整答案，标量第三因子加不进新东西；它只看 32 个词；它会找捷径（核心长成时钟、新生个体把思考拍数推到上限）；在线规则用到全部多巴胺靶点时与它形成正反馈、梯度发散 不替代它。让慢的生物学习去它够不着的地方：窗口之外、行为的后果
D. 我们自己的测量 自我模型探针泄漏了拍数；把弱自相关峰读成 8 Hz 心跳；噪声书每次换新探针造成假进展；显存碎片、磁盘写满 先设计对照再下结论；每个否定结果写原因

为什么会这样？因为这个系统不能拆开做。我们一直把器官一个个放进罐子里测：多巴胺、蘑菇体、在线规则、go 神经元、好奇心。它们的意义只在闭环里存在，罐子里的每一个都显得没用。A 类的所有否定，其实是同一个缺失前提从不同角度看到的样子。

主线也是沿着这条链走到这里的，每一步都是上一步的前提：

内外交互解耦 → 时间必须有代价 → 多想必须有用 → 大脑必须能学习和记忆 → 多巴胺要有评价的对象 → 动作必须有后果 → 需要一个会回应的世界

所以现在不是偏离主线，而是走到了主线最底下的那块地基。

动作有后果的闭环

强化学习和主动推理需要的不是“奖励不可微”，而是下面这个环。只要环成立，多巴胺、蘑菇体和在线学习才第一次有对象。

flowchart LR
  A[感知] --> B[内部状态]
  B --> C[动作：说出一个词]
  C --> D[世界变化]
  D --> E[未来的感知不同]
  E --> F[多巴胺评价]
  F --> G[学习]
  G --> B

被动阅读缺的是 C → D：说什么，下一个词都由数据集决定。

两种学习并存：BPTT 负责快的、窗口内的调整；多巴胺 + 资格迹负责慢的、窗口外的、带后果的信用分配。

书架交给大脑

世界已验证：按学习进展选能避开噪声，按惊奇选会掉进噪声陷阱（噪声占 0.73）。下一步让大脑自己选书，多巴胺预测“这本书带来多少进展”。

前提：先用可学性差异大的书把进展测量标定好（主题书信噪比只有约 0.06）。

第零层：味觉世界

它是果蝇嗅觉学习实验的文本版：气味 → 接近或回避 → 糖或苦。真实果蝇在这个任务里用的正是蘑菇体和多巴胺。

一次试验（约 6 个词的时长）

时段世界做什么果蝇做什么
提示写入一个提示词 c（每个个体 4 个常见名词，2 个“甜”、2 个“苦”，映射由个体种子随机决定）读，go 神经元决定何时作答
动作—说一个词：解码器只在 “ yes” / “ no” 两个词上取 softmax 并采样，不加任何新参数。说出的词作为它的下一个输入（它听见自己）
后果：说“是”再次写入 c，同时刺激味觉神经元：c 甜则刺激糖味投射神经元，c 苦则刺激苦味神经元，持续一个词的时长感知结果
后果：说“否”同样时长的静默什么也没发生
间隔随机 2–4 个词时长的静默—

后果出现时重新写入 c，对应真实实验里“气味在场时被电击或喂糖”。这让资格迹在后果到来时仍然指向正确的提示，不必把信用跨越很长的延迟。

为什么它满足三个条件

  • 动作改变未来输入。说“是”和说“否”之后，感知到的东西不同；它还会听见自己的回答。
  • 试验短。约 60–90 拍一次。400 次试验约 2,400 个词时长，和书架的一支差不多。
  • 奖励差异最大。结果只有糖、苦、无三种。随机策略期望为 0；最优策略每次试验期望 +0.5。

奖赏从哪里进来

不发一个标量奖励，而是走连接组里原生的味觉通路。注释里已标出味觉二级神经元（Yao & Scott 2022）：糖味投射神经元 GNG540、GNG550，糖味局部神经元 GNG056，苦味神经元 DNg28，都在图里。受体级的糖/苦味感受神经元没有直接注释，可以按连接找出投到这些二级神经元的味觉感觉神经元。

这样多巴胺细胞对后果的反应来自大脑自己的线路，而不是我们写进去的。工程对照支（GRPO）另外拿到标量奖励，但两支感知到的味觉刺激完全相同。

评价

  • 偏好指数 PI = P(是 | 甜) − P(是 | 苦)，果蝇行为实验的标准指标，范围 −1 到 1，随机为 0。每 50 次试验一个点，跨个体报告最小 / 中位 / 均值 / 最大。
  • 习得：前 200 次试验，映射固定。
  • 反转：接下来 200 次，甜苦互换。慢权重背下来的映射此时是错的，测的是在线记忆。
  • 保持：反转后固定权重读 1,000 个词的真实文本，再做 20 次不给后果的探查试验。测的是超出 BPTT 32 词窗口的记忆。
  • 健康：任务前后各测一次读文本 NLL；放电率是否守在目标附近；Kenyon 细胞稀疏性。

排除的捷径

  • 不对果蝇自己说出的词算交叉熵，否则它会模仿自己（无论结果好坏都强化原来的选择）。
  • 后果是感觉刺激，不是文本词，交叉熵够不着它。
  • 生物路线的各支冻结全部 BPTT 权重：任何学习只可能来自在线规则。

先做的零样本检查

不训练，每项几分钟到十几分钟。任何一项不通过，生物路线的零结果就有了现成的原因，先修它再跑。

检查通过标准不通过时的出路
a. 味觉 → 多巴胺细胞刺激糖味神经元时 PAM 的阶段性反应大于 PPL1；苦味反过来线路在学习中被冲淡：直接刺激 PAM / PPL1，对应光遗传学的充分性实验（Liu 2012；Aso & Rubin 2016）
b. 蘑菇体能否影响动作刺激或静默 MBON 时，“是” − “否” 的 logit 差明显改变蘑菇体够不着输出（被动阅读里静默它几乎无损失，这是真实风险）。动作应改从 MBON 投射的前运动区读出
c. 提示词的 Kenyon 编码4 个提示词两两重叠 ≤ 0.15（被动阅读时测到 0.08–0.15）换提示词
d. 提示到后果的延迟延迟 ≤ 资格迹时间常数 50 拍（预计 20–40 拍）后果时重新写入提示（已在设计里）
e. 多巴胺细胞是否也投到同隔室的 MBON已通过：97 个 MBON 都收到 PAM / PPL1 投射，51% 几乎只收 PPL1、41% 几乎只收 PAM—

对照与预言

所有支都从同一个个体出发：稳态出生、读过 16,384 个词的新生对照个体（b2_control），受体亲和常数 K = 0.000554，多巴胺细胞醒着（约 1.8 Hz）。

支内容预言
A0 对照冻结权重，无在线规则PI 在每个阶段都落在 ±0.1 内。用来排除泄漏
A1 现有规则冻结权重，现有在线规则：每个 Kenyon 细胞一份记忆，收到的全部多巴胺加成一个浓度失败或极弱：PI 在 ±0.1 内，但记忆 φ 在变（标准差 > 0.01）。它学到“发生了点什么”，学不到“好还是坏”。原因已实测：每个 Kenyon 细胞收到的多巴胺都是 PAM 与 PPL1 的混合（PAM 占比中间 80% 在 0.64–0.87，没有一个以 PPL1 为主），糖和苦在几乎每个 Kenyon 细胞上都让浓度升高；而且一个 Kenyon 细胞的所有输出被一起改变，分不出通往接近型还是回避型 MBON
A2 隔室规则冻结权重，记忆按 Kenyon→MBON 边记，多巴胺来自同一隔室的多巴胺细胞。只在 A1 如预言失败后才加检查 a、b 通过时：前 200 次试验 PI 中位数 ≥ 0.3；反转后 100 次内重新达到 0.3；读 1,000 词后的保持 ≥ 习得末期的一半。检查 b 不通过时：PI ≈ 0，原因是蘑菇体够不着输出
A2-读 被动阅读对照不进味觉世界，只读文本：冻结权重，换上隔室规则，按之前的方法测 A→B→A 重访节省（记忆照写 − 冻结）。之前的现有规则在新生在线个体上测得 +0.002（噪声内）仍在噪声内（|差| < 0.01）：之前在线规则无效，主要因为世界没有后果。若 > 0.02 且跨种子一致：缺精度是之前被掩盖的原因，要回头重看被动阅读里的那些否定结果
A3 工程参照BPTT + GRPO：同一状态复制 4 个分支，优势 = 奖励 − 组平均，损失 = −优势 × log 概率前 200 次 PI ≥ 0.8；反转比习得慢；读文本 NLL 变差 > 0.1（策略梯度改动了共享的读出）

四组比较各回答一个问题：A0 对 A1，世界本身够不够；A1 对 A2，结构精度是不是必要；A2 对 A2-读，之前的失败是缺后果还是缺精度；A2 对 A3，生物规则离工程最优多远。

A2 与 A3 的比较是关键：工程路线告诉我们这个任务能不能被这个大脑学会；生物路线告诉我们大脑能不能自己学会。我预期 A3 习得更快，A2 反转更快、对读文本无损。这是两种学习各管一段的直接证据。

多巴胺反应会不会从后果时刻迁移到提示时刻（类似奖赏预测误差），作为探索性测量记录，不预言。

隔室规则（A2，不写代码，只定原则）

  • 为什么需要。真实 Kenyon 细胞的轴突穿过十几个隔室，每个隔室由不同的多巴胺细胞管，并连着不同的 MBON。奖赏性 PAM 支配回避型 MBON 所在的隔室，惩罚性 PPL1 支配接近型 MBON 所在的隔室，效价靠这种分布实现。现在的模型里，一个 Kenyon 细胞只有一份记忆、一种多巴胺浓度，效价在结构上不可能出现。
  • 记忆放在哪里。Kenyon→MBON 一共 61,210 条边（全脑 2,556 万条），每条一份记忆，每拍固定计算，O(1)。
  • 多巴胺从哪里来（已实测）。代码保留了每条多巴胺投射，但每个神经元把它们加成一个浓度。按投射来源统计：Kenyon 细胞上 PAM 与 PPL1 是混合的（PAM 占比中位 0.77，没有一个以 PPL1 为主），效价在这里被冲掉；MBON 上则两极分化（51% 几乎只收 PPL1，41% 几乎只收 PAM）。隔室其实就藏在连接里：一条 Kenyon→MBON 边上的多巴胺取“送到这个 MBON 的多巴胺”，效价就保留下来了，不需要新的空间数据。
  • 符号固定为负。多巴胺使 Kenyon→MBON 突触减弱（Hige 2015；Cohn 2015）。这是生物事实，不是学出来的参数。
  • 资格迹只看 Kenyon 细胞。这种可塑性不需要 MBON 同时放电（Hige 2015），所以资格迹就是现有的 Kenyon 突触前迹。

第一层与 SIGReg

自生成闭环里，“结果”由什么评价决定了一切。用未来的预测误差会奖励无聊（暗室：生成“的的的的”最好预测）；用学习进展可以避开暗室，但信噪比比书架还差；用真实续文又退回半监督。

LeJEPA / LeWM 能带来什么

LeWM（Maes、Le Lidec、Scieur、LeCun、Balestriero，arXiv:2603.19312，2026 年 3 月）用两项损失端到端训练 JEPA 世界模型：下一嵌入的预测损失，加上 SIGReg。SIGReg 把嵌入投影到许多随机方向，逐个检验是否像高斯，把整个分布推向各向同性高斯，因此不需要 EMA、停止梯度或预训练编码器。它的预测器以动作为条件，规划时在潜空间里展开候选动作，朝一个目标嵌入走。

直接套用会被时钟骗过

LeJEPA 的“批”是很多张不同的图。我们只有一个个体、一条时间流，批只能沿时间取。这时有一个作弊解：内部长出一个时钟，嵌入随时间缓慢转圈，既覆盖各个方向，又完全可预测。两项损失同时满足，输入却可以是“的的的的”。成年核心曾经变成节拍器，训练日志里读出潜变量沿时间的有效秩约 8–10（32 词窗口，上限 32），所以这个风险是真实的。

换一种用法：SIGReg 跨动作分支

  • 从同一个大脑状态复制几个分支，每支说不同的话，往前走几步。
  • 要求各分支未来的嵌入彼此分得开（跨分支 SIGReg），每支的未来又能被预测（潜空间预测损失）。
  • 合起来是：我的不同动作，应该带来可区分而且可预测的不同未来，接近“赋能”（可控性）。
  • 暗室：动作不改变任何东西，分支塌在一起，被惩罚。噪声电视：分支不同但不可预测，也被惩罚。
  • LeWM 有外部目标，我们没有；可控性正好替代目标，成为没有目标时的内在价值。

和果蝇的对应

  • 预测编码写入器比较的就是预测的和实际的感觉活动，本来就是潜空间预测。
  • 稳态内在可塑性是生物版的防塌缩，但只约束每个神经元自己的平均放电率，挡不住步调一致（节拍器）。SIGReg 约束任意方向的分布。
  • 生物里对应完整去相关的是抑制，例如蘑菇体里的 APL 抑制神经元让 Kenyon 细胞稀疏而彼此不同。

它能替换掉三个嫌疑中的“奖励定义会退化”；标量奖励的信用分配方差和进展信号的信噪比仍然存在。

零成本的准备：用现有检查点，把读出潜变量沿时间的方差分成两部分，一部分与输入相关，一部分与输入无关（时钟）。它告诉我们时钟作弊在这只果蝇身上已经有多大。

代价与顺序

  1. 零样本检查 a–e，以及时钟成分的测量。每项几分钟到十几分钟。
  2. 写第零层世界的代码和测试（关闭时逐位不变、不泄漏未来），A0、A1 各跑一次。冻结权重、不做 BPTT，估计每支 10–20 分钟。
  3. A1 如预言失败，再加隔室规则跑 A2。3 个个体种子，报告最小 / 中位 / 均值 / 最大。
  4. A2-读：同一条隔室规则放回被动阅读，约十几分钟。
  5. A3 工程参照，约 1 小时。
  6. 结果写进实验记录和路线图，然后决定是否进入书架交给大脑。

最初的“高电导分流”诊断被数据否定：新生个体的电导负荷反而比成年低。真正的问题是工作点：这些细胞平时收到的输入是重尾的（偶尔有巨大的同步齐射），只调平均放电率的加性稳态，把它们放在阈值以下十几倍的位置，只让罕见的大齐射越过阈值。平均放电率达标了，但细胞从“涨落驱动”变成了“罕见事件驱动”，对普通大小的输入完全不响应。成年个体的同类细胞都贴着阈值工作（0.4–1.0 个阈值）。

补充：抵消各自的 b 后再驱动，Kenyon 细胞反应灵敏（加 1 个阈电流 46 Hz，加 5 个 122 Hz），驱动 5% 的 Kenyon 细胞使 MBON 平均 +3.6 Hz、多巴胺细胞 +1.6 Hz。蘑菇体内部的路是通的。

出路（第一性原理）：稳态要守住的不只是平均放电率，还有工作区间：膜电位的均值离阈值在 O(1) 个输入涨落之内，也就是“涨落驱动区间”，这正是当初选占空比中位数时的原则。候选做法：用突触缩放（Turrigiano 1998）把每个细胞的输入涨落缩放到与阈值同量级，加性的 b 只负责均值、限制在 O(1)。设计正与子 agent 同事讨论，之后零样本验证，再重新孕育。

工作区间稳态（新）与重新孕育的预言

稳态要守住的不是放电率，而是每个神经元的阈值在它自己“自由膜电位”（按同样方式积分、但不复位）分布中的位置。用户原则：语言果蝇已不是果蝇，不照搬生物放电率，合理即可；放电率由工作区间自然决定。设计与审查：子 agent 同事（含单细胞 COBA 数值模拟与连接组统计）。代码：attach_regime_homeostasis，测试 test_regime_homeostasis。

  • 位置。加性驱动 b（阈电流单位）使自由膜电位高于静态阈值的时间比例为 q* = P(Z > z)，z ~ N(1, 0.25) 按个体种子逐神经元抽取（q* 中位约 0.16）。b ← b + η_b (q* − [u > θ])，η_b = 1/(100 q* τ_m)。
  • 宽度。每个神经元的全部输入（兴奋与抑制电导一起，保持 E/I 与短时程可塑性；感觉神经元还包括写入电流）乘以增益 s，使自由膜电位的滑动标准差为 θ/2。log s ← log s + η_s log(θ/(2 sd))，η_s = η_b/3，滑动矩窗口 100 τ_m，log s 限于 ±log 10。
  • 为什么需要两个旋钮。连接组的有效兴奋入度中位数只有 22；按旧目标（占空比 0.05）每个膜时间常数内只有约 4 个输入事件，76% 的神经元低于 10 个，注定是散粒噪声区间。单个事件远大于阈值时，只调位置会积分饱和（模拟中 b 到 −20、距离 11 个阈值）；加上宽度后距离 1.2 个阈值、尾部比 1.4。

预言（孕育 20 万拍，固定出生权重）

  1. 工作区间：每类细胞离阈值中位距离 < 1.5 个阈值；核心、投射神经元、MBON、多巴胺细胞的尾部比 < 3。
  2. 放电率：占空比中位数 0.2–0.5（约为旧目标的 4–10 倍），跨细胞仍近似对数正态；各类 |b| 中位数 ≤ 1。
  3. Kenyon 编码：每个词 3–15% 的 Kenyon 细胞活跃；同一状态下不同词的 Jaccard < 0.3；同一个词跨上下文的重叠大于不同词在同一上下文的重叠。
  4. 蘑菇体出入口：Kenyon 细胞对词的响应 ≥ 新生旧稳态的 10 倍；以 ≥ 3 τ_m 的刺激，MBON 与多巴胺细胞对输入有响应。
  5. 否证：若 σ 已接近 θ/2 而核心尾部比仍 > 4，大事件来自群体同步而不是幅度，出路是抑制或短时程可塑性，而不是稳态。

群体爆发是正常的：让新生个体长大

用户的判断：新生个体的群体爆发是正常的发育现象（真实大脑在发育期都会如此，成熟后自然消失），不应该去修；问题出在我们让出生那一刻的大脑去完成成熟大脑才能做的联想学习。正确的做法是让它长大，再观察。
