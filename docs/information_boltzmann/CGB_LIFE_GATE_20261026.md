# 生命门：把生命的必要条件变成准入义务（2026-10-26）

导演的要求："凡是生命必须具备的，都要提到公理层检验，而不只是作为可选的条件。"

P1–P3 只说明"什么是介质"。是介质不等于活着。生成链和生命定义（`Life.lean` 中的 `Lives`）已经证明了活着必须具备的若干性质，但门以前只检查 P1–P3，这些性质都不是强制的。现在它们成为门的第四层，缺一项就拒绝。搜索也只在通过这一层的表中进行（`run_cgb_generate.py --life`）。

## 第四层的义务

| 义务 | 定理来源 | 检查方式 |
|---|---|---|
| 感知 | `Lives.exposed`（由 `not_selfMaintains_of_unexposed` 推出）；表层引理 `tableCRN.exposed_of_rule` | **Lean 证明**：个体模块必须含 `exposed`，由生成器自动给出见证规则 |
| 代谢 | `Lives.metabolizes`（由 `not_selfMaintains_of_closedMatter` 推出）；`tableCRN.metabolizes_of_rule` | **Lean 证明**：个体模块必须含 `metabolizes` |
| 排出 | G16 `export_forced`：有限容量下，持续摄入必然伴随持续排出 | 表上存在降低含量的边界事件 |
| 选择性排出 | G17 `retention_needs_selectivity`：排出若不随状态变化，任何内容都保留不住 | 各类单元在平静时的排出倾向不能全都相同 |
| 记忆 | `Lives.remembers`；G19 `memory_separates`；`hold_vanishes`（新） | 感觉页加 1 拍 ±μ 脉冲，撤掉 1 拍后从各页活跃数解码其符号，留出一半样本检验，z > 3 |
| 自我维持 | `Lives.selfMaintains` | 选择记录中，留出世界的闭环存活（均值和中位数）都不低于切环或致盲对照 |

新的 Lean 模块是 `GenerationLifeGate.lean`：
- `kernel_self_le`、`hold_vanishes`：一般介质中，只要有一个改变状态的事件速率 ≥ η，停留在某个精确微观态 n 拍的概率 ≤ (1−η/R)^n。
- `PairCRN.rate_pos`、`exposed_of_witness`、`total_pairAct`、`metabolizes_of_witness`。
- `tableCRN.witness`、`dC_witness`、`metabolizes_of_rule`、`exposed_of_rule`。

`scripts/gen_lean_organism.py` 为每个个体自动写出 `exposed` 和 `metabolizes` 的证明。

## 一个必须面对的问题：`Remembers` 要求永久记忆

`Lives.remembers` 要求在世界停止提供信息之后，对**所有** m 都保留至少 ε 奈特的信息。可是：

1. `hold_vanishes`（已证）：任何精确微观态都保持不住。
2. G17 `unselective_export_forgets`（已证）：只要每拍被改写的概率有正下界，保留概率就按几何级数趋于零。
3. M1–M3 的速率都是 κ·exp(−ΔE/2)，有限且为正。在有限状态空间上，凡是能被边界写入的部分，在平静核下也能被边界改写，因而有一个正的混合下界（Doeblin）；关于过去输入的互信息于是趋于零。与边界不连通的内部分量的含量确实永久守恒（P2a），但它也写不进去。**这一步是纸面论证，尚未写入 Lean。**

所以，若第 3 步成立，**所有成对反应介质（M1、M2、M3）都不可能满足永久记忆**。要满足它，平静核必须可约：要么某些速率恰好为零（拓扑保护），要么记忆存放在一个宏观态集合里，其逃逸率在有限系统中仍然为正。后一种就是锁存：逃逸率随单元数 N 指数下降（Kramers），记忆视界随 N 指数增长，但始终有限。

因此门目前检查的是**有限视界**的记忆。建议把 `Lives.remembers` 改为以世界自身的 `horizon` 为界的版本，与 `Persists` 的 T 同构；修订之前先在 Lean 中证明上面第 3 步（Doeblin 遗忘），作为与 P1b 删除接触齐性同类的修订依据。

这也说明锁存为什么重要。在有限的成对反应个体里，**要让记忆视界随规模无界增长，已证结论排除了精确保持和平衡态漏积分，剩下的候选是锁存**（这是猜想，不是定理）：平衡态的记忆按 G24 只有 1/T 的尺度，精确保持按 `hold_vanishes` 不可能。点燃世界（s1，生命准入搜索）正在检验选择能否生成它。

## 本质与现象（导演原则，2026-10-26）

我们做的是一个体系，它能推出许多生命体。**本质**是任何生命都必须具备的，来自公理与生命定义的无条件推论，是门的义务；搜索只在其内部进行。**现象**是"世界条件 C ⇒ 机制 Y"的条件定理，不进门，只作为在条件 C 的世界中生成的个体的预注册预言。常见的情形是：**某性质的存在是本质，它的程度或形式是现象。**

| 本质（门的义务，对所有个体） | 依据 |
|---|---|
| 是介质：有限、局部、守恒、平静细致平衡、只经边界感知 | P1–P3 |
| 感知（速率依赖刺激） | `Lives.exposed` |
| 代谢（与外界交换含量） | `Lives.metabolizes` |
| 排出 | G16 `export_forced` |
| 选择性排出 | G17 `retention_needs_selectivity` |
| 有记忆（有限视界，至少一拍） | `Lives.remembers`、G19、`hold_vanishes` |
| 经由回路自我维持 | `Lives.selfMaintains` |
| 不可恢复是吸收态，故必须保持可恢复 | `irrecoverable_absorbing` |

| 现象（条件 ⇒ 机制） | 条件定理 | 实例 / 检验 |
|---|---|---|
| 强度跨多个数量级 ⇒ 只依赖差值，即时间比较与完美适应 | G10b（平移不变性） | 趋化（E1–E2） |
| 世界状态有隐藏的持续时间 ⇒ 计数或阈值切换 | G19（记忆区分序列） | 觅食（P2） |
| 弱而短的刺激加长且可变的延迟 ⇒ 驱动的锁存 / 点燃 | G23、G24 | 点燃（I1–I6） |
| 多个隔室共享一个势 ⇒ 富人俱乐部；局部储库 ⇒ 不应期、疲劳等 | G19a、G22 | 生长结构 |
| 奖励延迟到达 ⇒ 历史载体（资格迹） | `delayed_credit_requires_history_carrier` | G15 觅食者 |
| 类别型目标 ⇒ 单符号扇区，即 softmax 读出 | R1/R2、G13 | 语言读出 |

记忆的**存在**是本质，记忆的**视界**是现象：觅食个体只需 1–2 拍，点燃世界要求 ≳80 拍。锁存是长视界这一条件下的现象，不是所有生命都必须有的。

### 一个生命体为什么同时拥有许多现象（导演追问，2026-10-26）

人类一个个体就同时有生长结构、工作记忆、觅食、趋化、学习和语言。这与"现象依赖条件"并不矛盾：**一个个体所具有的现象，是其生态位中同时成立的条件的并集。** 人的世界同时含有跨数量级的强度、隐藏的持续时间、长而可变的延迟、延迟的奖励、类别型的符号和有限的共享资源，所以上表的每一条条件定理都同时适用于同一个个体。单一世界的实验（趋化、觅食、点燃）是把条件逐条隔离出来检验，就像在生理学中一次只研究一种功能。

由此还要回答两个问题，它们决定"统一"是不是真的：

1. **相容性**：各条件推出的机制能否在同一个介质中同时成立，还是相互冲突？例如 G24 要求驱动的锁存（长时保持），G10b 要求完美适应（遗忘绝对水平），两者对同一记忆载体提出相反的要求。冲突时需要分工，这就是结构分化（分隔室、分页），即 G21 所说的分化需要涨落、边界、身份或历史。
2. **共享底物**：若统一成立，不同现象应当复用同一批本质部件。可以检验的预言：在复合世界中生成的个体，其时间比较（趋化）与计数（觅食）用的是同一个记忆载体，而不是两套各自独立的结构。

**下一步**：在单一世界的检验之后，构造**复合世界**，让多个条件同时成立，或按演化顺序依次出现、子代继承亲代的表；然后检验相容性与共享底物。
