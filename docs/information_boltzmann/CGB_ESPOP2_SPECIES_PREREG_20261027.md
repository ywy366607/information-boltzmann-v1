# espop2 物种的留出评估与 E3 检验（预注册，2026-10-27，运行前写定）

**对象**：谱系 ES 运行 espop2（`results/published/cgb_generated/nested_espop2_div_mover_20261027.json`）的最好基因组：
- 第 29 代，验证均值 3.34；
- 会分裂的语法 `grammar_v1_div`，世界 `rain_torus_w0`；
- 容量 SL = 128，每个世界 4 个创始个体。

ES 只负责启动一个能活下去的谱系（见目标文档第 5 步）；物种最终应当来自世界内的演化。

**留出世界**：种子 9000–9015。它们从未参与选择，也没有参与验证。espop2 的验证种子 500–515 被用来挑出最好的一代，所以不再算留出。

脚本 `scripts/eval_population_species.py`。所有臂共用天气和创始位置（共同随机数），结果报告 [最小, 中位, 平均, 最大]。

## A. 对照（不突变，20000 拍）

| 臂 | 做法 |
|---|---|
| organism | 原基因组 |
| blind | 感受食物的交换和跨膜规则置零（与 `Organisms(blind=True)` 的受体定义相同） |
| still | 移动置零 |
| nodiv | 分裂置零 |

基因组坐标为 0 表示该事件不存在。对照在基因组上实现，后代都会继承。谱系得分 = log(1 + 末尾存活数) + 最后有个体存活的时刻 / 拍数。

| 编号 | 预言（中位数） | 用途 |
|---|---|---|
| S1 | organism 的得分高于 blind 和 still | 准入门的自我维持义务（闭环优于致盲） |
| S2 | organism 的存活数高于 nodiv；nodiv 在至少 12/16 个世界里灭绝 | 繁殖只靠分裂，且是延续所必需的（E3 的前提） |

## B. E3 持存（突变打开，PMUT = 0.1，10⁵ 拍）

- 只放原基因组，突变按种群引擎的物理规定（一次分裂改动一个坐标，步长 0.05）；
- 不投放、不选择；
- 每 1000 拍记录各世界的存活数、灭绝数、不同基因型的数目，以及相对创始基因组的平均偏移和最大世代。

**E3 的标准**（目标文档）：16 个留出世界各延续 ≥ 10⁵ 拍，无灭绝。

**我的先验**：E3 不会通过。espop2 第 29 代验证时，16 个世界里有 5 个在 6000 拍内灭绝；容量 SL = 128 在存活的世界里是饱和的。如果确实不通过，就要分清原因：
- 灭绝发生在早期（创始个体太少、没站稳），还是在稳态之后（世界变干）；
- 灭绝是否集中在降雨率低的世界。

不通过就记为不通过，再找原因，不改标准，也不挑种子。
