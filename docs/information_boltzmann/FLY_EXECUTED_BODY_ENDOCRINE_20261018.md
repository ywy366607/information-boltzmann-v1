# 已执行行动的身体返回与 LK 受体通路

**身体部分的原生闭环验收已撤回。** 本文所述一维执行器是代理，不满足用户要求。
两种代理反馈已退出正常训练，只保留明确指定的历史冻结复现。
LK 轴和历史实验数据分别保留，不以它们证明身体闭环。
最新修正见 `FLY_NATIVE_BODY_CORRECTION_20261018.md`。

本轮把身体返回从“下行细胞平均活动直接写入上行细胞”改为一个可选的实际执行接口，
并补上有受体证据的 LK 慢信号轴。主线 32384 保持暂停；新机制在独立连续副本验收。

## 同一套生成与持续状态

实际自听事件 → 执行器状态变化 → 本体感觉输入 → 固定连接组 → 后续感知和选择。
LK 细胞活动 → 释放相关钙状态 → 配体浓度 → 受体占据 → 靶细胞兴奋性 → 固定连接组。

这些状态都按真实物理 tick 演化，不按词数重置；时间常数与效应参数可学习，
脑状态、优化器、RNG、待处理回复和信用跟随完整存档。
没有额外添加饥饿分数、发言配额或奖励标签。

## 身体接口

`--body-actuator` 需要已有 `--body-loop` 和原生 context 模式。
执行器仅在实际发声的自听区间受驱动，安静区间自然衰减。
输入是记录的执行事件，不能用 hazard、策略 logit 或下行细胞平均活动替代。
位置样状态与有符号变化量经可学习增益返回 1454 个有本体感觉类别注释的细胞。
其后使用原有突触、VNC 和上行路径；旧的直接下行→上行合成反馈在该模式下停用。

这是语言身体的一维执行器近似，尚不是果蝇肌肉、关节和运动神经元的完整物理映射。
初始 8 tick 时间常数只是可学习初值；两个返回增益为零起步。
不同词的声音仍由原来的自听路径承载，这里不会把 token 身份伪装成本体感觉。

实际世界、可微回放和内部反事实共用这条动力学。
反事实使用克隆状态并恢复 RNG，因此预演中的动作不会发生在真实个体身上。
回放使用 **输入持有期间** 的 source，不能错用区间末才到达的目标 source。

## LK 轴及生物依据

图内注释有 12 个 LK 细胞，16 个 IPC 与 7 个 ITP 候选靶细胞。
Zandawala 等的受体标记和转录组结果支持 IPC/ITP 群体表达 Lkr；
文章也区分了受体表达与直接突触连接，提出旁分泌或循环信号的可能。
[PLOS Genetics 2018](https://journals.plos.org/plosgenetics/article?id=10.1371/journal.pgen.1007767)

因此这一轴采用浓度/受体占据，不新增伪造的快速突触。
浓度是归一化模型量；钙平方释放、单一混合配体池、群体内靶细胞覆盖、
阈值作为效应器以及 32/256/64 tick 初值均是显式近似，不能称为测得的果蝇参数。
受体响应的方向和幅度可学习、零初始化；受体亲和度保持正值。
本轮没有假设 IPC/ITP 的活动已经等同于营养、水分或可存活性。

47 个未分型 ENS 细胞仍参与一般网络动力学；其受体及外周交换关系尚未专门接入。
后续应补受体/效应器与实际交换变量的证据，不能给它们统一加一个“饥饿”状态。
