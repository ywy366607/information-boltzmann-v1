# MaleCNS 连接组职责地图（2026-10-18）

> 后续接线状态以统一注册表及 `FLY_NATIVE_MOTOR_PORT_20261018.md` 为准。运动末端到语言外设已有实现和急性检查；下文初始盘点不能当作最新运行开关。真实身体反馈仍缺，不能把语言外设当作完整身体。

这份地图回答两个不同问题：连接组中有哪些功能系统，以及当前模型是否让这些系统承担了各自的职责。网络中“已经有动态”不等于“已经实现功能”；大量细胞已经经过统一的膜、突触和脉冲方程，但仍没有使用它们在果蝇中承担的特殊角色。

## 规模

当前 `fly_reservoir_coba_r2.npz` 包含 165,122 个神经元。按连接组 superclass 统计：

| ol_intrinsic | 89,390 | 视觉/嗅觉叶内局部变换 | 统一 LIF/COBA，未按局部回路职责分化 |
| cb_intrinsic | 32,160 | 中央脑局部整合、记忆和状态变换 | 统一类动力学，部分类型可独立参数化 |
| vnc_intrinsic | 13,151 | 腹神经索局部感觉—运动变换 | 统一动力学，尚无身体控制闭环 |

| vnc_sensory | 6,365 | 本体觉、触觉、内部身体感觉 | 有图中输入，未接身体后果模型 |

## 生物职责和模型对应

### 感知入口和中继

受体、视觉投射、嗅觉受体、ALPN/ALLN/ALIN/ALON、机械感受和本体觉细胞负责把外界和身体状态变成可区分的时空脉冲。它们不是记忆本身，而是记忆写入的地址和证据来源。当前模型把它们都放进同一脉冲介质，只有输入写入器和少数增益参数区分它们。

### KC：稀疏表征和记忆写入入口

4,064 个 Kenyon 细胞将感觉组合成稀疏、可分离的蘑菇体表征。KC 本身不是完整记忆；记忆需要 KC 活动、局部突触状态、DAN 调制和 MBON 读出共同形成。当前 KC 稀疏输入、KC→DAN 末梢释放和 KC→MBON 隔室记忆已经有实现，是目前最接近生物职责的一组。

### MBON：记忆读出和行为偏置

97 个 MBON 把蘑菇体突触状态转成接近、回避、持续、切换等下游偏置。它们不是普通输出层，也不应被等同为语言 decoder。当前模型已把 KC→MBON 的一部分连接移入可塑隔室，但 MBON 到行动选择、注意和身体行为的下游仍未完整闭合。

### DAN：教学和可塑性门控

340 个 DAN（包括 PAM/PPL 等）提供新奇、奖励、惩罚和时序教学信号。DAN 不应被当成单一 reward scalar，也不是记忆存储位置。当前有多巴胺浓度、KC→DAN 末梢反馈和部分局部可塑性；DAN 的不同亚型、不同 MB compartment 和不同下游目标仍被较粗地合并。

### APL、DPM 和其他蘑菇体调制细胞

APL 提供广泛抑制和稀疏化，DPM 参与蘑菇体记忆的保持、巩固和遗忘控制。当前 APL 只有在专门开关下使用部分树突接线；DPM 主要被当作内在自发活动细胞，尚未形成巩固/遗忘动力学。这是记忆系统中最明确的遗漏之一。

### OA/5-HT：状态、动机和上下文调制

连接组中有 37 个 OA 类型和 8 个 5-HT 类型。它们不是普通快速突触，也不能被硬编码成“兴奋”或“抑制”。当前已经加入可选的原生慢化学路径：解剖接触、浓度、受体占据和可学习的细胞类型响应；还没有真实语言收益和匹配关闭对照。

### CX：持续状态、航向和行动选择

中央复合体约 2,950 个神经元，承担航向、位置、导航、持续状态和行动选择。它们在当前图中会放电，也能影响整个网络，但没有航向/位置环、状态积分或选择回路，因此目前仍接近“普通细胞”。这是操作闭合中最大的脑内缺口之一。

### 上行、下行和 VNC：身体行动闭环

上行神经元把本体觉和动作结果送回脑；下行神经元把脑的行动命令送到腹神经索；VNC motor/efferent 细胞执行身体动作。当前它们被纳入全脑膜和突触动力学，也部分用于读出，但还没有真实身体执行、能量/稳态变量或动作后的感知回传。没有这条链，脑只能在语言接口里产生策略，不能完整改变自己的交换条件。

### 内分泌、ENS 和慢变量

内分泌和肠神经系统提供比单个脉冲更慢的身体状态。它们不是“情绪标签”，而是维持和改变脑—身体交换条件的慢状态。当前没有接入这些变量；下一步应从可观测的身体感觉和内分泌路径开始，而不是添加人为 hunger/reward 分数。

## NeuPrint 路径证据

使用 `male-cns:v1.0` 的 NeuPrint 查询，`gL(L) → CAN(R)` 路径约有 19,045 条连接、总权重约 143,840。聚合后可以看到 MBON、KC、DAN、CX、ALIN、ALPN、下降和上行相关类型都参与其中；CAN 也向大量 descending、ascending 和 VNC motor 相关类型输出。这说明 CAN/CX 一类结构不是图中的装饰，而是跨感觉、状态和身体行动的中继系统。

当前模型没有为 CAN/CX 形成独立的持续状态变量，也没有把它们的输出接到身体行动后果再返回上行感觉。因此它们应当列为下一阶段的原生闭环对象，而不是继续只看 KC/MBON/DAN。

## 当前优先级

1. 保持 KC—MBON—DAN 的现有记忆写入/读出，并补 DPM/APL 的巩固、稀疏和遗忘职责。
2. 把 CX/CAN 从普通 LIF 提升为有连接组依据的持续状态和行动选择回路。
3. 把 ascending → descending → VNC motor → proprioceptive sensory 接成真实动作后果闭环。
4. 让 ALPN/ALLN/ALIN/ALON 和视觉/机械感觉通路保留各自的输入时延、稀疏和局部调制，而不是只共享一个输入投射。
5. 最后接入 ENS/内分泌等慢身体状态，并用真实感觉和行动后果约束它们。

验收标准始终分开记录：解剖可达、实际放电、原生因果、持续学习收益和行为收益。某类细胞“有活动”不能证明它已经承担了生物职责。
