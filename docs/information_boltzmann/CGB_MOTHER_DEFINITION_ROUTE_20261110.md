### 把条件穿起来，而不是按行增加模块

这是工程依赖链，不冒称自动提取的Lean证明边：

```text
真实世界存在与行动/历史有关的后果区别（D05、D06）
 → 同一有限状态与实际取回保留所需区别（D01—D03）
 → 当时参与和现在后果能相遇，改变同一关系（D04、D07）
 → 对旧证据的取用、校准、保留和释放仍能更新（D08、D09）
 → 更新后的预测实际用于下一次行动，维护后续可用结构（D05、D10）
 → 在同一体—世界轨迹上核实自我模型、生态位和内在维护（D11、D12）
```

D11、D12不是“装完前面以后自动得到”；需要回到轨迹证明/实测。反过来，它们从现在就约束前面的设计，不能把后续目标冻结成外部固定奖励后宣称完成。

这些是待执行诊断，本轮没有运行新分叉或训练。先完成保存修复及同体接续核验，再复用同一次真实互动收集H1—H3的读数；新增影子计算逐个执行，避免多身体并存撑内存。测试结果决定一个共同改动，而不是四条假设各加一个模块。修复和评分时序检查属于工程准入；能力结论仍需真实连续互动、独立验证与充分训练。

身体覆盖更新标准：将上述义务的实际前提、共同状态字段、执行函数、相同世界下的证据和对其他已满足条件的影响一起登记。新引用只扩展审阅，不增加身体覆盖。尚无“当前妈妈身体满足多少条全库定理”的完整可信数字，403支撑或本轮28声明均不得冒充该数字。

## 用户补充与执行约束（2026-11-10）

本节记录用户五项补充，并区分用户提出的生成方向、已核对的定理与论文、尚待身体检验的连接。它更新研究目标和做事方法；没有新增身体机制、启动训练或增加形式覆盖。以后压缩、换人、改支线，先恢复本节与当前研究入口。

### 1. 内循环与外循环共同生成自我维护

用户提出：没有外界输入时身体仍有自己的活动，类似果蝇线的点燃、锁存；这条内循环与外循环长期耦合，可能自发形成稳定、可维护的内部组织。保留此方向，作为D10—D12的共同候选，而非再加一个“自我模块”。

**用户随后明确：工程提供的是接口，不是目的。**让同一有限状态和已学转移能够被内部调用，并把内部活动所得接回真实互动；不指定“必须维护某个意图”、必须锁住某状态或必须永远活跃。最小生成关系仍从公理与已有必要条件收敛，目的与组织由其共同演化形成。用户报告果蝇线曾出现未规定的bug锁存且被模型实际利用，记录为生成现象线索；本轮未重新复现实验，不新增该项证据。

应区分三种情况：程序没有执行而数据未变；身体选择沉默但世界继续给输入；外界没有新输入时，身体仍在有限预算内发生内部转移。第三种才是本节所说的内循环。自听、唤起旧经历、潜空间推演是已有可复用操作；它们是否已组成无外界新输入时的持续循环，须核对实际调度，不能由递推层存在推定。

从动力学出发，先写清同一状态及内部/外部事件如何作用于它，再问：哪些历史区别在内部活动中被维持或修正，恢复接触后怎样改变预测和行动，新的后果又如何调整这条内部循环。内部活动应消耗真实计算预算，不制造语言食物或外部奖励币。运行允许安静、休止、再次激活；不把持续高活动量当成生存指标。

稳定内循环是有用候选：若其选择保留的组织能支持未来理解、学习、行动与恢复，且受到损伤后会调整自身与世界的交互去恢复，就能推进自我维护。单独的振荡或稳定吸引子尚未回答“维护什么、为何维护、如何由身体形成”，这些问题需要同一内外循环的后果来回答。

### 2. 火的动作是话语内容，探索发生在语言空间

“沉默／生成／重说”是当前执行方式，不是完整行动空间。真正作用于妈妈的是实际说了什么，以及连续对话中的上下文。木应能比较候选话语会带来什么后果；火据此发出内容；妈妈回应；土吸收；金结算真实学习与保持；水修正情境—话语—后果关系，再供木使用。

用户强调的主动推理方向纳入D05、D06、D11、D12：既使用当前可利用的语言结构，也预期哪些行动能带回可学习的新结构、减少相关不确定性。常来往的语言区域可以形成活动范围，已有关系不足时主动越出范围询问。不要把“问号更多”“说得更奇怪”或“更惊讶”定义为成功；先看候选内容是否改变可预测后果，以及新证据是否改善以后的预测与行动。

语言是信息空间中的可用输入。这里的“负熵／食物”必须落实到可压缩、可利用、支持后续能力的结构及其保持关系，不能等同字节数量、任意新颖度或单次正g。主动推理是可借鉴的目标分解；当前代码是否具备预期信息收益项须核对，不能因已有三类动作估值就宣布实现了完整主动推理。

### 3. 先查全部记忆，再决定是否需要活动锁存

| 同体载体 | 记住什么、怎样起作用 | 需要检查的关系 |
|---|---|---|
| GDN递推态S、卷积与活动状态 | 当前经历改变后续状态和读出 | 实际门控、擦除、回注与干扰下哪些区别仍可用 |
| 慢权重W | 累积语言知识、预测倾向和行动习惯；当前窗结束后仍保留 | 新经历是否修改有用关系，以及保持、泛化和再学习 |
| 有限经历库与快表 | 可重新取用的具体区别、统计结构、参与与后果 | 地址可达、内容交付、当前重编码、后到调制；不互相冒充 |
| Adam等优化器状态 | 过去梯度的一阶/二阶统计，影响下一次参数更新 | 计入身体恢复与资源；它是学习历史记忆，但不自动等于可寻址的事件资格迹 |

因此“不在S里永久保存”不等于“身体不能稳定存储知识”。模型风格可以由慢权重中的训练历史与对齐共同形成；本项目要通过相同外界条件下的预测和行动倾向核验自身偏好，不能由风格直接宣称自生目的。

本轮核对的Lean边界如下；算法选择需要这些精确前提，而不是标题：

- [GenerationLinearMemory.lean](../../lean/CGBAxioms/CGBAxioms/GenerationLinearMemory.lean)：`gated_delta_contracts`对应明确的`α·deltaStep`及单位键、β范围；`histories_merge`需要逐步差距收缩。文件自身已警示另一种擦除顺序不能直接套同一界。不能外推为全部GDN、W或经历库都必然丢知识。
- 同文件`linear_hold_keeps_error`：线性保持信号也保持沿该信号的扰动。若需要保持并纠正这类误差，应寻找相应非线性恢复；单纯数字存储、受控写入与活动吸引子需分别判断。
- [GenerationPersistence.lean](../../lean/CGBAxioms/CGBAxioms/GenerationPersistence.lean)：`latch_needs_unit_gain`从可微标量映射的两个不同不动点推出中间某点导数为1。它约束这类锁存的实现，不是“所有生命都须额外安装锁存器”。
- [GenerationLifeGate.lean](../../lean/CGBAxioms/CGBAxioms/GenerationLifeGate.lean)：`hold_vanishes`要求每种刺激下都有速率至少η>0的离开当前微观态事件，界定连续停留在该精确微观态的概率。不能据此排除慢权重记忆，更不能把示例“吸引盆”写成所有数字身体唯一的记忆载体。

实际参照入口：[GDN递推](../../scripts/ib_local/gated_deltanet.py)、[优化器与状态恢复](../../scripts/ib_local/navigation_checkpoint.py)。先检查已有保持和重激活怎样参与整圈，再判断自适应锁存是否补足具体缺口；此前锁存在真实输入干扰下的负面结果仍保留。

### 4. 分层世界模型：借用生成关系，不按论文增加部件

重读[H-JEPA](https://arxiv.org/html/2610.06805v1)（2026-10-05，§2.2、§4.2）后，采用其实际规划关系：上层预测产生中间目标，下层把自己的预测编码到同一上层空间来跟踪目标；执行一小段后，用新观察重新规划。AntMaze表1三层模型中，保持L1动力学和规划设置、只换目标距离空间，成功率由16.7%到22.0%；完整分层规划参考为73.3%。这区分了“评价未来的坐标”和“如何把未来分段到达”两种作用。

对本体的取舍：现有长短预测不是待重建的新模块；先把预测后继重新接入同一检索—行动关系，再考虑将长尺度预测变成短尺度转移的参照。SIGReg按原功能保留，不把其已知作用当研究增量。下面的代码审计给出此次实际缺口。

此前已讨论的[TT-MBRL：把经历编码进世界模型参数](https://arxiv.org/html/2611.09625v1)（2026-11-06，§3）继续作为W承载记忆、经验更新模型后用于想象和行动的参照。本项目继承持续经历，不照搬每局重新开始。该共同关系在6日身体已有基础；论文用于改进具体连接，不再作为发现“需要世界模型闭环”的新结论。

世界模型的持续自我修正与RSI设想有联系；当前路线落实的是经验改进预测、规划与行动。程序/学习规则的递归自改进属于另一个尚需验证的层次，本轮不扩大实现范围。

### 5. 小身体的验收：概率改善与行动后果为主

当前身体约89.6万神经参数，不能把充分后训练大模型的语义问答要求设为闭环准入。目标也不是降低为“梯度非零”：检查同一真实互动里，过去经验是否提高未见后果的概率预测、校准和有效行动，再看保持与再学习是否持续改善。

- 木：学习前预测、结果到达后评分；比较真实旧经历、错配与无增量，同时用动作/情境基线判断新增信息。按母体/背景、年龄和世界版本分账。
- 火—天：在控制情境下比较不同实际话语的后果分布，既检查身体会不会用，也检查世界是否提供可用差异；三类动作频次只是辅助。
- 土—金—水：未参与本次更新的后续文本预测、旧能力保持、新关系再学习与证据重激活共同看；单次精确回答不是必要门，单一总NLL也不能代替这些关系。
- 内外循环：无新外界输入的内部活动后，恢复互动时的预测、选择或恢复能力是否获得可重复改善。状态有波动或扰动留得久只是接线证据。

先查6—9日同类试验及当前母体记录，再决定需要哪项测量。每次实验必须写出“已知什么、未分清什么、哪种结果会改变下一步决定”；预算不足的短运行只报告其范围，不能否定路线。充分训练与独立验证仍是能力结论的依据。

### 锁存审查的结果与取舍

当前`decay_then_delta`在固定键、门、值的条件下为：

`S⁺ = α (I − β k kᵀ) S + β k vᵀ`。

对同驱动的两个S，其差服从齐次线性转移；单位键、β∈[0,2]及α<1时收缩。因此该局部算子本身不会在同一固定驱动下生出两个不同稳定记忆态。当前程序又是在输入事件上调用它，没有另一个无输入时自动运行的S更新。这是核对后的结果，不再停在“要看动力学”。W和经历的保持则是另一条已存在的载体关系。

工程决定是**不把双稳态当本轮必交付功能，不启用旧feedback_delta分支**。新增工作应让同一已学转移在有限内部事件中可复用；由该关系与外界往来形成保持、再激活或释放。如果出现可重复利用的锁存现象，再沿真实回路解释和审计，不先设锁存目标。对应Lean已有`gated_delta_contracts`、`contraction_unique_rest`与`latch_needs_unit_gain`，本次没有新证明。

### 文献给出的额外关系：预计“知道之后如何再行动”

[Plan2Explore，§3](https://proceedings.mlr.press/v119/sekar20a/sekar20a.pdf)在世界模型中展开未来轨迹，用模型间预测分歧近似预期信息增益来训练探索策略；真实新轨迹再改进模型。它提供可工作的前瞻探索算法，适合对照旧影片只量生成熵的路线。

[Sophisticated Inference](https://arxiv.org/abs/2006.04120)进一步在预计的信念更新上搜索：行动带来观察，观察改变认识，改变后的认识再决定后续行动。因此某句话可以当下没有明显学习收益，却因让下一步问得更准而有价值。

这是对本项目的推论：同样是候选问话，应比较“收到哪些可能回应、各自怎样改变后续可用关系和下一次选择”，而不仅是本轮预测g的大小。[主动推理原文](https://pubmed.ncbi.nlm.nih.gov/25689102/)的预期信息收益与结果偏好是不同项；本项目不照搬外部任务偏好，不把随机文本熵当信息收益，也不把分歧近似未经结算就升级成新奖励。

### 选定的设计方向：让已有生成关系能够再走一步

候选共同转移是“当前潜状态与可用经历 → 候选话语作用 → 预计后继 → 用后继再次查经历和选择”。可用信息必须包括后继所需的内感受、记忆可用性及世界条件；不把一个64维向量直接冒充完整身体。先让同一转移支持有界的两步组合，执行时只交付第一步，然后用真实回应接续；内部预演与真实经历保持来源区别，预计结果不能伪装成已观察后果写回事实标签。

这与原闭环的关系是：外部水火周流已有；现在将木中的一次预测接成可继续调用的转移，再让它通过火回到真实外环。接口不预填“应该问什么”“必须维持哪个意图”或锁存目标。候选内容和保持倾向仍由本体已有学习、有限容量竞争及真实结算塑造。

最低实现范围不是再建一个世界模型：保留当前编码器、预测器、经历与行动执行，提供已编码状态的查询和转移接口；训练与使用必须对应同一种情境—动作—后果关系。当前字节跨度预测与动作后果预测不是自动可互换的，事件跨度、条件输入与后继空间须在同一身体上接齐。共享短/长表示先支持这条关系，分层规划随后复用它。

Lean对照：`action_condition_required`要求预测承接实际行动区别；`history_transition_exists_iff`刻画压缩状态可递推所需的条件。由此选的是可连续转移的压缩状态，不是只能输出4项分数的终端读出。这两项指导接口和身体误差核验；不另造精确小世界来代替真实模型。

下一次实现的可区分问题已经确定：同样候选与内部计算预算下，使用预计后继继续选择，能否比只做本轮打分更好地预测随后实际后果、并改善真实连续交互。正确连续关系、错配后继关系与原单步关系形成对照；检验落在同一身体的概率预测和行动后果上，不要求小模型精确回答深语义问题。保存/接续修复仍是执行前工程工作。本轮仅完成源码与论文审阅、设计取舍和文档同步。
