# DAN慢状态的持续材料信用

本轮把已有DAN局部受体、钙相关状态、共享释放池及四拍延迟包接入持续的条件材料信用。物理方程和材料值保留，BPTT窗口仍可为1个输入，未恢复主线训练。

## 接通的学习路径

每拍按原方程推进局部敏感度`S = d(state)/d(material)`；短窗口开头的物理状态成为叶子，后续目标给出`G = d(loss)/d(opening state)`，把缺少的历史项`G·S`加回材料梯度。范围包括六组DAN材料以及已有KC局部反馈增益。

同一收缩也接进原生行动分数的反向：选词/时机的资格迹在写入前先补上这段历史；待真实后果结算时，这段历史和窗口内分数一起参与。行动分数的辅助反向不修改NLL梯度槽，后续NLL反向也不会重复结算已归档的行动信用。

所有1404101个已接入形态节点与187404个共享释放位置保留。受体只依赖亲和度/解离两行，钙状态需要四行，资源和包需要七行；省去结构上恒为零的导数，不合并细胞、空间位置或材料。每个DAN拥有其材料，运输不跨细胞，因而无需分配稠密的全脑参数Jacobian。

运输的材料导数使用同一完整形态求解器。由`A C = V z`和`A = V + D L`得到`dC/dlogD = A^-1 V(C-z)`；把四列右端批量求解，不保留随经历增长的反向图。新增持久状态59934984字节，约57.16MiB。

## 明确边界

这是**给定实际进入KC/AP包的局部化学递推历史导数**。数值对照验证该路径的导数与完整展开自动微分一致。它没有包含更早的材料变化经全脑放电再次返回、或已在下游DA/φ中累计的全部历史导数，也不对优化器更新序列求导；因此不能称为完整全脑RTRL或已经证明长期探索收益。

参数保持可学习。没有为改善资源最小值手调恢复时间，也没有设发言率。新信用从33000输入、471577实际拍这个明确边界以零导数开始；此前未保存的导数不被冒充为已重建。旧脑、优化器、RNG、世界及未结算信用均保持原值。
