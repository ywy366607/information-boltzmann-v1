# 持续学习与内存边界

后续已落实的执行/存储压缩见`FLY_MEMORY_COMPRESSION_20261019.md`及其机器可读报告；不能沿用本页较早的失败位置或内存峰值作为当前实现测量。

用户已明确：快过程可以暂时保留局部BPTT，但它不能成为4GB机器上持续运行的前提。慢过程使用自身持续更新的资格迹和原生调质可塑性；资格迹的目标不是复现窗口梯度。后续不再把补全全部来源—材料—空间节点导数作为生物回路接通的必要条件。

必须区分物理状态、本地资格迹、用于优化材料参数的条件敏感度，以及窗口求导图。改变学习算法时明确记录来源与边界，保留已有经历及完整恢复点；不能直接清空已有学习状态来证明资源通过。

## 本轮资源检查

在33000输入候选的内存副本上，恢复完整训练状态，分别执行启用求导图和关闭求导图的第一拍前向。未调用妈妈、未提交动作、未保存修改后的权重，主线32384仍暂停。候选检查前后SHA256一致。

两支恢复时PyTorch CUDA分配均为2468.99 MiB。启用图在KC树系数构建时无法申请31.9 MiB CPU数组；关闭图在相同空间求解路径无法申请128 MiB CPU右端数组。两支都尚未执行VJP、NLL反传或优化器更新，且失败时设备总占用接近4GB。因此本轮不能把瓶颈归为BPTT独有，也不能把不同失败位置的峰值相减当作求导图成本。

关闭求导图的对照仍保留了完整优化器、持久信用和物理状态；它不是删掉所有学习存储的纯前向基线。此前冻结回放释放优化器等不参与回放的训练状态，不能代替完整训练资源验收。单拍资源检查也不代替实际每词时钟的验收。

## 优先顺序

1. 优先减少精确空间求解工作区和重复存储，不减少物理节点或切断感觉/动作通路。
2. 让慢学习依靠已有突触迹与实际到达的调质信号，按后果选择性、记忆影响选择和持续适应来验收。
3. 快过程局部BPTT限制在实测资源预算内；不能通过缩短世界时间来迁就反传。
4. 内存调整后，先验证完整恢复与物理前向，再验证真实单输入时钟和局部反传的资源边界。长期学习收益另用真实连续经历验证。
