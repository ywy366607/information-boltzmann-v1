# 出生规则校准：形态与连接发生（运行前登记）

本轮把空间预览中的随机身份投影与任意发生率，换成可检验的数据估计。
不启动旧梦漓，不使用个体内BPTT，不把短段共读作为能力实验。

## 数据与分工

male-cns:v1.0现有完整骨架缓存：165122细胞、162分片；注释与连接权重来自同一数据版本。
按已有缓存约定将坐标乘0.008换成µm。流式读分片，不构造全脑体素体积。
记录每细胞缆线长度、长度加权质心与协方差、分支密度及注释胞体位置。
记录分片成员CRC与大小、源清单及输出哈希；没有重新查询或修改原数据。

形态解码器与连接发生器分别拟合。V3d的已锁定64维身份码作为固定身份描述，
不把它当连接发生概率，也不把新拟合搬进个体终身学习。
身份码来自同一个体的连接统计，以下不是独立动物验证。

## A. 身份到空间的解码

目标：胞体位置3维、相对缆线质心3维、log缆线长度1维、对称log协方差6维、
log分支密度1维，共14维。协方差通过对称矩阵指数恢复，保持正定。
侧别与固定身份码及其侧别交互作输入。按类型固定种子划分80/10/10，
某一留出类型的形态不参与拟合和标准化；同类型细胞不跨形态划分。
以类型—侧别等权，避免大细胞类主导。基线仅含侧别。
岭强度网格1e-4至1e4，按验证误差选择；测试只在锁定后一次评分。

预期：身份解码优于侧别基线；分别报告位置、长度、协方差和分支，不以平均改善掩盖失败。
若只部分成立，只部署获支持的部分，其余保留候选标签。
实际生成几何还要对照这些描述量检查；“描述量可预测”不等于树形或接触已复原。

## B. 真实细胞对的发生概率

在不看连接标签前，从可用类型中固定种子选768类，每类2个细胞，约1536细胞。
只用骨架计算每细胞2µm/4µm总缆线密度重叠；这里不用突触标签拆轴突树突，避免
用待预测的连接构造输入。真实目标是所选细胞对是否有观测连接，权重另存。
与V3d相同的原始类型对90/5/5划分，用于这个面板的训练、验证和测试；
不让同类型对的细胞配对跨分区，排除自身细胞。

固定身份码、独立的出入身份项、独立有方向双线性匹配矩阵、几何特征，拟合
带L2的Bernoulli似然。它是细胞对概率，区别于E1的“某类型对总突触数≥5”。
几何模型与身份＋几何比较；正则按验证选择，测试在选择锁定后评分。
记录实际迭代、收敛/未收敛、样本与阳性量、log loss、Brier、AUC和几何覆盖。
固定码的解码是凸参数拟合；用训练集优化停止证据，不按测试分数追加优化。

预期：真实概率拟合的验证log loss优于只用接触量的候选；若身份没有额外收益，
部署简单的校准概率。未完成优化或阳性太少则标预算/数据受限，不声称已解决。
这仍是同动物、同已知身份的类型对留出，不证明新物种或所有细胞的泛化。

## C. 接入与状态

已有192细胞预览保持原样。校准产物另存，下一版本从规则生成新候选，
在同一观察室提供版本选择。生成几何决定接触，发生模型决定概率，
V3d负责条件强度，已有局部介质与材料账负责后续变化。
形态尚未拆输出/输入时，发生模型使用总缆线重叠；新几何不能用错特征定义。
