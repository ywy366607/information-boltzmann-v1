# R7：从痕迹保持改为付费结构存留的条件检验

写于本轮结构生成元计算与拟合之前。上一轮Control的全部结果已经看过，本轮是探索性、固定操作的逆发育约束，CG3不重新称盲测。

## 同一反应图，改变实际观察对象

上一轮在r从1变0时吸收；但原MobileExchange中这不会删除桥。付费桥只有C=r=0时能assembly−。本轮观察n（桥是否实际安装），保留原binding±、thermal±和assembly±，不把痕迹清除当结构清除。

先取一个明确受限的有限扇区：两个材料域在原rest_length，双端容量3；一个可用桥位置；未安装时post有B=P=1、D=0；安装时B=P=0、D=1。支持总数S=F+C固定。无电荷、scalar物性、同一原参数。状态是off以及(n=1,r,C)的四种组合。所有转化由原events/event_rate取得，使用原组成/端熵及能量，不手写保持率；反向事件必须回到同一有限组成扇区。保留桥存在与消失的物料付款。

这是在已给定几何、无外部补给、其它转化被冻结条件下的原生成元投影。未包括真实细丝多段几何、移动、domain±、write、transport、conversion、release和其它交换；不能泛称全核或果蝇细丝模型。将桥存留对应可见突起仍是待检验的观察假设。

## 观察由同一生成元给出

完整5态生成元Q中，off→idle为实际装配，idle→off为实际回收。取4态暂态块T，出生分布e_idle。若物理出生在相邻一分钟内平稳发生，并且存活至首次观察，首次可见分布不是自由参数：

    pi = e_idle * integral_0^1 exp(c T u) du / Z,
    Z = e_idle * integral_0^1 exp(c T u) du * 1.

其后S(d)=pi exp(cTd)1，结束与右删失同上轮。此处已允许帧间不可见的出生/消失；Z是首个观察前存活概率的积分。持续未见到的短事件不会被当作已观察轨迹。c仅是共同时间单位。因出生唯一进入idle，不再自由拟合初始支持占据。

对S=1/2/4/8/16全部报告，只用CG1/2拟合c，log c范围[log(1e-4),log(1e8)]，多区间全局一维搜索并检查边界。CG3仅在锁定训练结果后评分。原有观测单/双指数、旧痕迹首达分数分别保留，不把它们重写为同一模型。

## 同时约束数量，不能只拿寿命评分过关

由同一Q求唯一平稳分布rho、安装比例p_on与单位位置的可见出现通量c*rho_off*Q_off,idle*Z。对K个独立同质位置的明确有效极限：N边际服从Binomial(K,p_on)，计数相关由同一exp(cQt)决定。它不含共享资源竞争，不能检验竞争已实现。

仅用训练计数选择整数K：从训练最大同时数量到128，最小化两个训练锥60帧的边际复合NLL。逐帧有关联，因此复合分数不当作独立样本的完整轨迹似然，也不算显著性。报告所有K目标、边界、预测均值/Fano/出现通量/相关与原计数。相同K用于CG3，禁止按测试重新调K。

这个额外闭合假设（同质、独立、固定位置、平稳）可能失败；失败后区分观察对象、有限位置与共享供应、初始/边界及几何的缺口，不通过修改速率或加恢复状态追分。两张实际观测表的评分相近，也不能代替这一数量检查。

## 验证、保存与出口

逐事件验证原rate、组成/能量增量、逆过程、Q行和/平稳通量、首达概率、解析积分与独立数值积分；不执行新物理个体或妈妈训练。保留源哈希、完整矩阵、训练锁、全部评分和失败结果。若结构/数量映射不成立，下一步回到空间装配/回收和实际供给条件；不将条件失败等同于全部原理失败，也不把增加拟合参数当生成规律。
