## 共同边界

既有 `CGB.Description.code_roundtrip` 与 `bounded_books` 表明给定有限编码和预算时的表示性质，不证明用自然语言归纳的程序为真。`delayed_credit_requires_history_carrier` 要求所需历史区别仍存在，并不指定程序语言。`reactivation_exact_held` 是固定保持、可微条件下的重编码导数，不能保证本候选的因果关系。具体编译器语义和实际身体联合覆盖均未证明。

候选输入由 JSON 有界指令数据表达，只允许整数输入、整数常量、加法和乘法；指令长度≤16、输入数≤4、每项整数和运算中间值有固定上限。解释器不执行动态 Python/Lean 源码。`parse_candidate` 是未来模型提出候选的接口，当前候选由研究者运行线性拟合生成，未接入模型生成。预算固定时，一次执行所需工作和状态不随累计历史长度增长；未实现磁盘存储或替换策略。

## 真实收据实验

从 `results/cgb_reactivated_causal_credit_20261109/removal_checked_{0,1,2}/report.json` 读取三道题的实际有限移除收据。输入仅为该记录的当前误差调制范数和层号，输出为遮掉记录后答案 CE 的变化；取样本身来自研究者挑选的正确线索及最高教学其他记录，因此不冒称模型自行选择或无选择偏差。按题切分：0、1 为拟合，2 留出；每题4条收据。对输入/输出作微单位整数编码，拟合并取整生成9指令算术程序。

拟合集8条：MAE 0.018259 nats，对训练均值基线 0.026982。留出题4条：MAE 0.023107，对相同训练均值 0.036373；其中第13层正确线索的真实移除差为 +0.004184，而预测 −0.039283，方向错误。这个极小、已被研究者检查的试验只能验证接口，不足以证明泛化或获得因果规律；均值基线也不代表身体原预测。

程序保存为固定指令序列，自动生成只含已校验整数与固定构造器的 Lean `CandidateExecution.lean`。Lean `Std` 内核对12个已列输入运行相同栈语义并用 `decide` 检查输出，同时检查程序长≤16。它证明这些具体算术执行与输出相符，不证明实际世界中移除效果、Python与Lean对所有输入的等价、程序有益、或模型能自主产生程序。首次 `import Mathlib` 因现有 mathlib `.olean.private` 读取失败保存在 `lean_mathlib_failure.log`；仅依赖 Lean 标准库的检查成功。
