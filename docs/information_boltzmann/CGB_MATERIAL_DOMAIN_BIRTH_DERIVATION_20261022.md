# 从有限材料到新增独立储能域

2026-10-22；承接[物理核心](CGB_PHYSICAL_CORE_20261022.md)与[端口可区分性](CGB_CONNECTIVITY_STATE_DERIVATION_20261022.md)。本文件记录实现前的状态与速率推导；随后同一反应已实际生成24→28域、新域继续延伸和新接触，详见[实施结果](CGB_DOMAIN_BIRTH_RESULTS_20261022.md)。不预设目标树形或分叉概率。以下推导保留原来源与待选择本构，不把一次实现追认为唯一物理定律。

## 1. 当前真正缺少的自由度

现有移动核可以移动24个独立材料域，在接触时按既有有向身份建立桥；每域3端、8个边界槽使接触总数至多44。98单位桥前体即使全部接触填满也至少剩54。增加桥数、调B供给或改变分叉显示阈值，无法创造第25个独立储能域。

新空间端口需要新的位置、荷量和局部组成；把一段新几何简单画出来而不增加这些自由度，不能产生独立的传输与学习。应扩展同一材料的允许形态：游离前体、储能域、接合桥。域仍可沿用同一局部储能、反应和输运，既有身份程序继续在实际相遇上调用。

## 2. 物料与储能必须一起细化

先把已经存在但未计入B账的材料核质量显式化。设一个域和一条桥各占一个守恒材料单位，是待声明的材料组成选择；旧档24域、98桥/游离材料的细化总量就是122。将24核恒定质量补到账本不改变旧状态或轨迹，也不能让这24单位被当成凭空新增的游离B。

候选局部可逆事件为：

    2 B_i + P_i  ↔  一个新域j + 接合桥(i,j) + D_i

从局部B支付域和桥，P/D总量不变；新域不能免费获得B、支持或P。正向在已存在域的邻域产生新域及一条空闲桥；逆向回收同样两单位材料。该反应图是明确的材料相变假设，不由守恒唯一决定，须保留其他允许材料构成的对照可能。

总能量扩展为原U加上新域形成能。原电容能 `Σq²/(2C)` 必须包含新域，同时包含弹性、桥、身份、端和r/C/P的既有项。C、形成能与标准态体积由所选材料本构/外环物性确定；不能为让节点数增长而省去它们。迁移旧档的常数能量基准须与initial_energy一同细化，不能伪造输入功；事件中的能量变化照实记热/功。

## 3. 新荷量的产生不能是免费初始化

设旧父域荷量Q，容量C_i；新域容量C_j。在保持总荷量Q时，分配的电容能恒等为：

    q_i = Q − q_j
    U_after = Q²/[2(C_i+C_j)]
              + [q_j − Q C_j/(C_i+C_j)]²/(2 C_eff)
    C_eff = C_i C_j/(C_i+C_j)

若用热条件分配作为提议，`q_j` 可取均值 `Q C_j/(C_i+C_j)`、方差 `kBT*C_eff` 的高斯。它是采样提议，不是免费热平衡赋值：反应的接受率须含完整ΔU、提议密度及状态测度，实际发生后才把差额记入热账。将新q一律设0既不是上述热分配，也不能拥有无反向概率的详细平衡。

父域有限组成可按声明的体积分配做二项提议；每种池总数逐一守恒。逆事件必须能从两个域合并状态重构同一Q、组成和提议变量。旧世界端口、源状态与外部时钟不随内部域出生改写。

## 4. 连续位置和变维状态下的正反速率

用同一个温度的无量纲自由能 `g=U/(kBT)−S_internal/kB` 和明确参考测度定义目标状态密度 `π(x)∝exp(−g(x))`。新位置的空间体积、荷量的标准单位及同形材料的组合数属于参考测度，不能隐去。

设正向局部提议密度 `q+(y|x)`，逆向提议 `q−(x|y)`，变维映射Jacobian为J。对同一可逆事件可用有限尝试率ν乘有界接受概率：

    R = exp[−(g(y)−g(x))] q−(x|y) |J| / q+(y|x)
    A+ = min(1,R)
    A− = min(1,1/R)

因此实际事件测度满足 `π(x) k+(dy|x)=π(y) k−(dx|y)`。这是一个可逆跳变执行选择；详细平衡只约束比值，ν及物理提议核仍需来自局部接触、有限输运与过渡态本构。提议可被积分或采用拒绝/稀疏抽样执行，不应先枚举整个全脑位置/荷量空间。

逆向只允许于原反应确有前像的状态：待拆域没有外部端口、相应桥r/C已按原通路释放，荷量和所有组成可以守恒回收。不能在被支持保护时强删节点，也不能将域里尚存的资源丢掉。复杂域可先由现有桥/支持/配置反应退回可逆边界，再发生相变；所有中间步骤仍在实际时钟中付款。

这里不是将目标梯度搬入内环。能量、组合熵与提议测度决定转化偏置，已有局部活动通过q、P/D、r/C影响它；预测贡献仍在真实流中另验。

## 5. 有界执行槽不能成为新的生长力

材料守恒本身给出域数量的有限上界。执行器可预留由总物料推导的槽，或按需扩展O(活跃域+桥)数组；空槽不应参与电容、扩散、碰撞、端组合数或身份统计。

若用S个带标签执行槽表示N个无标签物理域，同一物理状态有 `(S)_N=S!/(S−N)!` 种槽标记。密度应除去该简并；正向选择空槽的概率 `1/(S−N)` 与相邻N层的简并因子配对抵消。新增一倍空槽而改变物理出生率，就是把硬件容量当成物理熵的错误。亦可用紧凑数组/重编号明确避免标签冗余，但必须证明重编号不改端口、身份、RNG与后续执行。

同样不能把“首次分配Python数组的延迟”算作材料事件等待时间。物理ν和dt独立于执行耗时，遵循现有K/T/H分离。

## 6. 伸长、转向、分支如何共用这一过程

一条桥末端附近的材料成核可延伸路径；已有域的多端在不同局部接触上付款，产生分支或环。节点坐标仍由原机械力、热运动与碰撞约束演化，不额外写“朝目标转向”。新域身份是形成材料的组成/模板属性，须按明确继承规则保存；不能从世界词语或期望成年形态挑身份。

出生后新域与其他域的真实相遇，继续调用已继承的有向发生识别和输运物性；同型延伸桥也不能悄悄跳过其声明的材料界面。若材料连续连接与异质接触需要不同能量，先证明它们是可区分的界面状态，再加入相应本构，不能因生长太慢临时加特殊通道。

这些约束没有唯一预言树形；实际树、环、团块、回收与形态尺度由物性和驱动决定。是否能生成与维持有用传输结构，要在统一执行后检验，不能通过校准分叉数代替。

## 7. 接下来的具体实现准入

先实现局部成核/逆合并的完整收据与状态往返：有限物料/荷量守恒、精确ΔU/ΔG、正反密度、无空槽偏置、世界索引稳定和完整恢复。再接入原反应/运动/OU生成元，在同一真实流上产生新域、新接触与已有身份匹配。记新增域和桥分别的物料与热功，不将几何重采样当自然生长。
