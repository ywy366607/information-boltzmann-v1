# 精简果蝇生命运行器（2026-10-19）

## 为什么要另起

原生个体（33000 词，含感觉末梢回流）在这台机器上活不起来：

- 冻结状态下纯前向，一个词就要 114 秒；改成并行和 fp32 后仍要 42 秒。
- 带学习时第一个词就内存溢出。
- 1060 万个形态节点的逐节点扩散占了 99% 的成本。
- 每个窗口要跑两遍：实时一遍，重演一遍。
- 5000 行的训练器把几十个开关叠在一起，每次修改都要绕过其他所有东西。

用户 10-19 定下的目标：生命体要轻到能在手机上跑；不要求 fp64；不是在解方程，也不是仿真。

## 原则

1. **只有一种运行方式：实时活着。** 一个词只算一遍，不重演，也没有 BPTT。学习全是局部的：
   - 读出层用到达时的局部梯度；
   - 蘑菇体用多巴胺三因子；
   - 以后突触用 e-prop 资格迹。
2. **只算发生了的事。** 突触传递只对发放的细胞展开出边（CSR，带延迟环）。神经元膜的更新本来就便宜，每拍做一次 16.5 万维的向量运算。
3. **紧凑存储。** 索引用 int32，权重用 fp16，词表矩阵用 fp16，不要求 fp64。
4. **CPU 优先。** 用 numpy 和 numba，不依赖大显卡，可移植。
5. **回路观察器内置。** 每个词记录各回路的发放率和释放水平、意外度、谁在说话、MBON 处的多巴胺。
6. **旧的完整原生个体只当离线标尺。** 每迁移一个机制，就做一次 A / A′ / B 对照：
   - A：完整版；
   - A′：完整版换随机种子；
   - B：精简版。

   B 与 A 的差距不超过 A′ 与 A 的差距才算通过。没通过就加细节，不调数字。

## 预算（每个词平均约 14 拍，发放率约 2.5%）

| 部件 | 内存 | 每拍运算 |
|---|---|---|
| 突触：1514 万兴奋 + 970 万抑制，按前细胞排成 CSR（int32 后细胞，fp16 权重，uint8 延迟） | 约 150MB | 约 4000 个脉冲 × 平均约 150 条出边 ≈ 60 万次加法 |
| 神经元状态：膜电位、电导、适应、STP、4 拍延迟环 | 约 10MB | 16.5 万维 × 约 20 次运算 |
| 感觉写入（词嵌入 fp16 加受体投影） | 约 110MB | 每个词一次 |
| 读出：读面投影、归一化、解码器（fp16，50257×768） | 约 80MB | 每个词到达时一次，约 3800 万次乘加 |
| 蘑菇体：6.1 万条 KC→MBON 隔室的 φ、迹和多巴胺 | 约 2MB | 每拍只更新有事件的部分 |
| APL：分级抑制，约化为少数舱室 | 很小 | 很小 |
| **合计** | **约 350MB** | **一个词约几毫秒到几十毫秒（CPU）** |

## 继承

- 精简个体从 33000 词个体的存档出发：连接权重、各细胞的生理参数、读出层、蘑菇体参数、STP 参数。
- 去掉的原生机制，它们的效应会丢失。所以精简个体是同一份经验的"兄弟"，不是同一个个体。和完整版的差别要测出来并写清楚。
- 主线存档不动。

## 机制迁移顺序（每一步都在妈妈世界里跑，并看观察器）

1. **核心。** 连接组、COBA LIF 加适应、STP、感觉写入、读出、实时的妈妈世界（复用 `MotherWorld` 的对话部分）。读出层在线学习。
2. **蘑菇体。** 隔室记忆 φ、多巴胺快慢浓度、三因子时序规则。
3. **APL / DPM。** 分级抑制和反馈。
4. **开口动作。** 每拍的开口 hazard 和肌肉状态、运动端口；后果信用只训练动作读出。
5. **末梢局部化学。** 先在完整版里验证约化（每个细胞保留少数慢模态，非线性化学留在位点上），再迁移过来。

## 第一阶段的验收

- 这台电脑上每个词低于 1 秒（不算妈妈的接口延迟），常驻内存低于 1GB。
- 一千个词以内，活动不爆也不死：各回路发放率稳定，读出意外度在下降。
- 观察器能给出每个回路随意外度和说话人变化的统计。
- 核心机制和完整版的 A / A′ / B 对照报告。
