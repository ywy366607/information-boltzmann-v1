# 动力学位置审计：哪些学习、哪些随内容变化、哪些保留为边界

2026-11-14。核对5356轮实际配置和对应源码；本次修界面、登记增长合同，**未改模型参数、动力学或启动训练**。32层仍是候选配置，现行完整身体4层。

## 1. 定义先看所在转移

“可学习”与“内容相关”是两条不同轴。训练得到的每层常数可以是好参数；没有梯度的在线统计也可以适应输入。逐层复制一个常数并不会自动获得适应能力。

当前主干实际关联写入可概括为

\[
S^-_{l,t}=\alpha_l(x_{l,t})S_{l,t-1},\quad
S_{l,t}=\operatorname{Admit}_{B}\!\left[S^-_{l,t}
 +\beta_l(x_{l,t})k_l(x_{l,t})(v_l(x_{l,t})-S_{l,t}^{-\top}k_l(x_{l,t}))^\top\right].
\]

这里保留/替换作用于有限关联状态，Q/K/V决定寻址和写入内容，读出与残差交给下一层，真实后果训练参数。S/P在决策边界内部续行；关系R及其证据U在另一时域支持木的预演。不能仅因它们都是矩阵，就把更新率、时间步长、资源上限归为同一种待学习参数。

## 2. 已经学习的部分

| 项 | 实际粒度及内容关系 | 在整圈中的功能 |
|---|---|---|
| GDN Q/K/V/O与输出门 | 每层有自己的矩阵；投影由当前该层输入计算 | 读写、内容变换及交给后层的区别 |
| alpha保留门 | 当前为`log_timescale`；每头`A_log/dt_bias`可学习，`alpha_proj(x)`随内容变化 | 输入如何改变该头的遗忘时标；不是全层固定衰减 |
| beta替换门 | 可学习投影＋偏置；每输入、每头一个值 | 决定当前写入替换多少旧关联 |
| SwiGLU | 每层gate/up/down可学习，gate随输入变化 | 对当前内容作非线性变换 |
| RMSNorm | 每个Norm实例有长度d的可学习增益向量；RMS由本位置d个通道计算 | 约束进入门控/投影的尺度；**不是全模型共用一个标量** |
| q内容端口 | 当前`question_to_hidden`产生通道gain/shift，和当前hidden相互作用 | 问题进入具体表达、自听及真实后果学习 |
| 关系共享基底 | condition/action/gate/mother投影可学习，gate随source变化 | 少量局部证据修改共享机制，不再独立拟合128维机制 |
| 关系噪声先验 | `SharedRelationBasis.log_noise[3, latent]`可学习，按机制类型/后果通道分开 | 木中金的后果分布尺度，不等于常数可信度 |
| 动量读出 | 每层P经对应query投影读取，拼接后交可学习`momentum_to_boundary` | 内部状态影响原后继预演；当前query共用决策特征，尚非每层自己的当时输入 |
| 选择/绑定与具体语言策略 | 原网络、共享binding选择器及字节策略均有真实结算信用 | 内外续行、未知角色和具体话语进入火 |
| 取用资格统计 | 原读logit参与经当前误差结算，按Adam式统计更新取用偏好 | 历史哪些参与对当前有用；是在线可塑状态，不是一份独立预测网络 |

依据：`gated_deltanet.py`、`question_language_port.py`、`shared_relation_basis.py`、`navigation_momentum_wood.py`、`navigation_read_credit.py`。当前alpha/beta是**每头**门；若需逐key/通道保持，是更改递推代数、状态语义及fused核，不是把一个数从float改Parameter。

## 3. 固定量逐项取舍

| 当前量 | 为什么在这里 / 实际影响 | 本次判断 |
|---|---|---|
| 输出投影初始化`0.02/sqrt(2*4)` | 写死原四层深度，影响残差初始量级；不会在训练时持续乘这个数 | **增长前必须按实际深度定义新增权重的初始化**；既有权重/Adam不重新初始化 |
| BFSS频率omega=.8 | 当前所有层共用，决定S/P内部恢复时标 | 适合作为每层可学习的正频率候选；边界条件可调节它，先保持有限/有界和真实后果学习通路 |
| 交换子耦合kappa=.01 | 所有头对、所有层同强度，忽略当前哪个头相关 | 优先考虑已有**内容相关加权势能**：每层参数＋对称非负头对权重；不是再加一个全局标量 |
| 内步dt=.01 | 数值积分分辨率，与omega/kappa共同决定离散误差 | 保留求解器量；可按误差控制细分，不直接自由最小化任务loss来“学习时间” |
| bfss_steps=1 | 外部边界的原步数；另外已有学习选择是否继续内部操作 | 固定的是单次原语；继续/返回已有选择。保留有限总上限，不硬设必须思考几次 |
| 记忆温度tau=.2 | 当前query/key归一化后控制读取的集中度 | 属于有条件可学习候选：层/查询决定正温度；由真实后果校准，保留空候选，不把更尖当更准 |
| read_gain与q/P读出尺度 | 控制记忆进入身体/预测的强度 | 原增益/投影已可学习；新增内容gate时必须同时接实际用途和信用，不重复增加永远为0的门 |
| relation ridge=.1 | 证据不足时相对共享先验的收缩强度 | 若后续误差定位到先验尺度，可按机制/支持度学习正精度；须同步预测、组织、留一与影子U，禁止只改一个读头 |
| 关系scale=.1 | 早期局部残差接入幅度；新共享程序路径不全由它控制 | 先按实际调用区分legacy修正和canonical机制，不能见config旧字段就判整圈仍固定缩小10倍 |
| critic精度、校准alpha | 已用过去真实误差更新，决定预测对选择的作用 | 已自适应，不再另装“木信任控制器”；是否进一步内容化靠条件校准证据 |
| EMA=.98等 | 统计估计的记忆时标，影响追漂移速度与噪声 | 当前是固定估计器配置；未来可从实际误差自适应时标，不能让统计和网络一起自由压低表面误差 |
| gamma=.8 | 以决策轮计的未来折扣，定义用途的时间尺度 | 不是随意学习的confidence。可变时长后必须明确按轮还是实际事件时长；若按时长，用`exp(-rho*duration)`并保持TD/木/资格一致 |
| CE×10、潜预测×.1、SIGReg=.001 | 三种学习约束在共享梯度中的比重 | 当前按用户决定保留；不要联合最小化lambda而让约束权重逃到0。若调整，沿真实梯度和留出作用制定独立方案 |
| critic×100、木×10及转换 | 同一收益的单位，不是能力参数 | **保留一致单位转换**。把转换也设可学习会重开已修复的TD尺度失配 |
| content_budget=32 | 每头关联矩阵行/列L1资源可行域 | 保留资源约束；预算内怎么分配由内容/门学习，不让学习器无上限扩大容量绕过有限性 |
| 层数/宽度、槽数、Top-k、证据8、草稿4、内算上限 | 容量和计算预算；限制活跃集合与工作量 | 固定上限，集合内容/保留/何时用可学习。不要把资源上限当无约束参数 |
| 说满32字节 | 世界交接被固定长度替代，改变了实际行动定义 | 已列入总装：128资源上限＋可学交话权＋实际前缀信用/保存；不是单改常数为128 |
| 妈妈/背景数据供给长度 | 外部环境协议，决定学什么和后果带宽 | 环境版本显式登记；不让身体看到内部世界位置或预期答案 |
| eps、合法类型、身份/版本校验 | 数值与责任边界 | 继续保持；防零除/错归因不能交由网络决定是否遵守 |

## 4. 内容相关的S/P怎样保持动力学含义

推荐沿原来已比较过的加权势能参数化，而不是直接让attention任意拼一个力：

\[
V_l(S;c)=\frac12\omega_l^2\|S\|^2+
\frac18\sum_{h<h'}\kappa_l a_{l,hh'}(S;c)
\big(\|S_hS_{h'}^\top-S_{h'}S_h^\top\|^2+
\|S_h^\top S_{h'}-S_{h'}^\top S_h\|^2\big),\quad
\dot S=P,\quad\dot P=-\nabla_S V_l.
\]

这里a对称、非负、由当前头内容计算，常数权重可恢复原势能。**求力时必须包含a随S变化的导数**；只计算“权重乘旧交换子力”会漏项。若系数依外部c，单次内部段固定c，世界到来再更新；能量变化按真实边界及参数学习分别记，不能继续套全程守恒。

此方向已有`learned_head_coupling.py`及`navigation_learned_coupling.py`：每层独立参数、内容attention、可学习总强度，真实首段objective用`create_graph=True`重算原内步来学习。**它做过分支比较，不是新发现；5356主线没有启用该分支。**增长时是否继承由明确迁移及资源准入决定，不在修网页时顺便改身体。

`omega*dt`共同影响旋转相位，P又带时间单位；同时自由调整全部时间和动量尺度会使参数解释含混。先固定数值时钟/单位，再学习不同层的动力学差异。32层不能只机械复制一组全局omega/kappa然后宣称形成了多时间尺度。

## 5. 32层的显示合同

主视觉固定三曲面，按真实`momentum_norms`连续深度三段汇总。32层时为L1—10、L11—21、L22—32；每层仍完整列在分层条形/原值表。三段是显示压缩，不预设浅层感知、中层思考、深层自我等功能。

段内平均只计真实有效数值；0是实测，缺测保留原位置。总层数不放大律动，不制造32倍“生命强度”；三段分别影响曲面幅度/变化。暂停与系统减少动态偏好均保留静态读数，后台标签页停帧。当前数据4层，不能先显示32层。

主干深度不是空间上的32层实体膜；动画的含义是有限状态读数的艺术映射，后果/用途仍由真实实验判断。

## 6. 本次遥测根因与修复

实际API当前卡片已与5356 checkpoint、branch、individual和hash相符。前端可复现的错误链是：一次不匹配令source.branch_id清空；后续恢复却要求已存在的branch_id先匹配，因此健康SSE无法清错，初始GET也仅发生一次。

修复保留服务端身份保护：错误时继续清空卡片/曲线；收到同一服务端已核过的卡片和来源后才重建来源、重新接收已保存事件，不调用身体、不自动训练。另处理较早HTTP失败晚到覆盖健康SSE的竞态。新增两项回归分别复现并检查这两条恢复路径。

浏览器控制在当前Work设置中禁用，未声称做过真实浏览器目视验收；服务API、接口回归、组件渲染和构建另行记录。配置不匹配持续存在时仍报错，不降级显示另一旧身体。

## 7. 下一次总装的具体新增义务

1. 增长前处理残差初始化深度、每层端口维度与P读出尺度；旧历史/权重不重置。
2. 当前全局决策特征作为每层P查询要明确身份；若改用各层自己的活动，须一起保存/回放对应参与，不能在旧记录上猜当时输入。
3. 内容相关头耦合属于有既有实现的候选，不与所有参数自适应同时混入迁移。
4. 可变表达后，单位、时间折扣、实际前缀与交话信用共同交付。
5. 保留已正确的学习/校准机制；只对明确阻断整圈的固定量动手，不再开一次全参数“活化”调参运动。
