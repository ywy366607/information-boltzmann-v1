# 梦漓：大小五行交接、脏腑与经脉的功能定义 v1

日期：2026-11-05。性质：当前共同动力学的功能规格与候选组织图。本次只整理定义和代码对应，不改身体、不训练，不增加定理覆盖计数。

上位规范：[关系式五行规范](CGB_FIVE_PHASE_DIAGNOSTIC_RULES.md)。历史实现与实验：[v4 交接文档](CGB_NAVIGATION_V4_HANDOVER_20261104.md)，尤其第 14 节及第 16 节。本文细化第 14 节，涉及新定义时以本文为准；历史实验保留原来的命名与上下文。

## 1. 先确定什么在流转

研究对象始终是同一个身体与世界的持续相互作用：

> 已有经历被唤起 → 形成可行动的预测与方向 → 实际表达或继续听 → 世界给出后续语言 → 同一身体吸收并改变 → 结算实际后果 → 有选择地留下可复用经历 → 再形成方向。

这次循环中，大木负责展开可能，大火负责实际出手，大土负责承接运化，大金负责据实分辨与结算，大水负责潜藏与再用。名称指作用，同一个状态、一次写入、一个梯度可以同时承担几个作用。

把完整身体状态记作 Z，世界状态记作 E，一次共同转移为 `(Z, E) → (Z', E')`。五行是对这次转移及其跨时间后果的五种观察；不是把 Z 强行切成五份互不相交的数组。有限容量、计算与来源约束贯穿所有观察。

流转的内容包括语言、预测、参与痕迹、已观察后果、可复用结构及腾出的容量。它们不共用一个守恒单位；“一气”不新增能量币或全局奖励池。

## 2. 大小五行用同一套作用定义

| 小五行 | 在任一大相内部的含义 | 要回答的问题 |
|---|---|---|
| 木 | 从已有条件展开尚未实现的可能、预测与修正方向 | 接下来可能怎样，还能怎样？ |
| 火 | 使其中一种可能实际发生，产生能够影响其他过程的作用 | 什么真正被激活、写入或发出？ |
| 土 | 承接输入，维持依据，把输入转成当前过程可用的状态 | 凭什么承接，承接后放在哪里、怎么用？ |
| 金 | 按证据分辨、校准、限定与选择，区分预想和实得 | 哪些可靠，哪些该留、该改、该止？ |
| 水 | 保存尚未显用的区别，允许腾退、再调用与重新展开 | 什么能带到以后，什么能重新打开？ |

小五行不是五个串行函数。一个局部循环可以交叠运行、由同一次更新实现；是否形成循环，要看前一次后果是否改变下一次展开、发用和保留。仅有五个标签不算自适应。

### 2.1 二十五种作用：当前最小闭环的定位

| 大相 | 内木：展开 | 内火：实际发用 | 内土：承接持据 | 内金：辨别校准 | 内水：保留再开 |
|---|---|---|---|---|---|
| **木：谋划与预测** | 对候选话语预测接话、回应可预测性和学习后果；随情境修正 | 将校准后的预测变成可供出手使用的候选倾向 | 当前身体情境、动作身份、共同漂移与动作差异的统计基本盘 | 预测先于结果，结果回来后比较基本盘与情境修正谁更准，决定采信程度 | 从经历库取回实际做过什么、后来怎样，保留尚未执行的候选 |
| **火：表达与接触** | 起草、内言，展开沉默、生成、重说等可达做法 | 真正说出所选字节，或真正继续听，使世界后续输入改变 | 承接候选倾向，托住所选内容、来源、动作概率与说后状态 | 在可达候选中承诺一个；核对草稿与实说，约束结束和执行边界 | 保留未执行的余地及待到达后果的参与信息；沉默时仍可继续承接世界 |
| **土：承托与运化** | 用当前结构预测到达语言和后继，暴露尚未吸收的区别 | 真实语言触发快状态、快表和参数的实际学习 | 同一递推状态、当前模型和可读结构，承接自听与外界输入 | 区分来源、预测与事实；确定何种误差参与何种更新，提供可比较的学前学后读数 | 保留先验与过去结构，在有限容量下允许覆盖、遗忘和换出 |
| **金：分辨与结算** | 形成关于本次变化是否有益、是否损害保持的待检判断 | 把实际结算作用到后续学习、估值和保留选择 | 保持评分单位、比较对象、参数版本与评估上下文一致 | 检查结算的校准、偏差与适用范围，分清实测收益和 TD 估计 | 保留可复核的已结算经历和比较依据，交给长期记忆而不混入未证实的想象 |
| **水：潜藏与再启** | 让相似旧经历成为当前预测的新线索，向木提供可再用的因果材料 | 某条旧经历当下真正被唤起、重编码并影响计算 | 有限地址、条目、计数、时间与来源，托住状态—动作—已观察后果 | 准入、合并、标记有效性与释放；表示正则帮助防塌缩，来源审计帮助防混账 | 未被当下读取的长期内容、仍可用的空位，以及释放后重新组织的余地 |

“实际发用”不总是对外说话。例如水中火是一次真实发生的唤起，土中火是一次真实发生的同化。

SIGReg 在水中金起表示几何约束作用；它不单独判断某段经历是否有因果价值，也不等于木中金的预测校准。三者可在同一训练过程中协作，检验对象仍各有不同。

### 2.2 每相如何自己走一圈

以下是因果依赖的展开，不规定执行器必须分五步调度：

- **木内**：记得过去 → 承接当前情境和统计依据 → 展开候选后果 → 校准哪些预测值得采信 → 形成行动倾向；实际后果回来，改写这套依据和旧经历。
- **火内**：已有余地和未决参与 → 承接候选与当前意图 → 起草具体表达 → 选择并执行 → 核对实说与后果来源；未结后果仍有载体，进入下一次接触。
- **土内**：旧结构承接新语言 → 预测与输入相遇 → 实际同化 → 区分学会、串扰和遗忘 → 选择性留下结构，成为下一次承接的底子。
- **金内**：保留比较依据 → 提出待检判断 → 在一致上下文中结算 → 复核自身误差与偏向 → 把实得后果留下，供下一轮判断与学习使用。
- **水内**：有限储存承接已结算经历 → 有选择地收藏、合并与释放 → 相似情境唤起 → 当前编码器重新加工 → 进入预测和行动；使用后的新证据又改变收藏。

这给出自适应需要补齐的关系，而不是宣称当前每个小循环都已完全自调节。当前损失权重、部分时间尺度及交互调度仍有人工设定。

## 3. 大五行究竟从哪里取用、送往哪里

本版采用一条明确的**接口约定**：上游按“正在促成下游哪种作用”定位发用处；下游的承接功能称作其小土。这里的“小土”是接纳与转化的作用，不要求另建缓冲区。

| 大相交接 | 上游发用处 → 下游承接处 | 实际交什么 | 下游怎样继续用 |
|---|---|---|---|
| **水生木** | **水中木 → 木中土** | 与当下相关的已观察状态—动作—后果、来源和支持程度 | 建立或修正基本盘，再展开当前候选后果 |
| **木生火** | **木中火 → 火中土** | 已校准的候选后果与行动倾向，以及它所针对的具体话语 | 和当前习惯、过去结算形成的价值经验共同进入选择，然后实际出手 |
| **火生土** | **火中土 → 世界 → 土中土** | 已执行的具体话语、说后状态及参与区别；世界据此给出的真实后续语言 | 同一身体承接回应，继续预测、写入与学习 |
| **土生金** | **土中金 → 金中土** | 同一比较对象上的学前学后预测、实际响应、版本和上下文 | 判断学到了多少、哪些保持受损，以及这项结算有何局限 |
| **金生水** | **金中水 → 水中土** | 带来源的真实经历、实测收益与可复核后果；估计值另有身份 | 有限收藏、合并或释放，随后被当下重新取用 |

**因此，大火从木中火取用；大木从水中木取用；大土经世界从火中土取用；大金从土中金取用；大水从金中水取用。** 每个发用处都由其所属相的其他作用共同支持，并不是只连这五个小格就能运行。

### 3.1 为什么火生土要经过世界

说后状态能帮助记住“我做了什么”，但它不等于“世界因此发生了什么”。自听可以组织记忆和思考，外界回应也可以是沉默；两者都沿实际观测进入身体。想象不能冒充新增的外界结果。世界是否提供可学的动作后果，和身体是否吸收这种后果，要作为一个功能对检查。

### 3.2 木中金、大金和火的关系

木中金问“我预测得准不准”，大金问“实际发生后，这次学到或损失了多少”。火使用木给出的预测，也使用过去大金结算后留下的价值经验与习惯。

当前 `_value` 将这些输入放进已有 critic，`_utter` 再选择动作。这是预测和历史经验共同影响出手的实现；不把它改说成“大木先去大金结算，再进入大火”。真正的大金实测结算发生在世界回应与身体学习之后。

### 3.3 主方向之内有必要的往返：先有草稿，才预测这句话的后果

当前代码的更细顺序是：

> 当前身体与旧经历 → 火中木起草具体话语、内言取得候选说后状态 → 木承接候选并预测后果 → 木中金校准 → 木中火形成倾向 → 火承接并实际选择 → 世界回应 → 土运化 → 金实测结算 → 水收藏 → 下一轮重新取用。

这里火中木的内言还不是大火已经对世界出手。它为木提供具体候选，木再回送可行动的预测；二者共同形成这次选择。大土已有的语言能力也直接参与起草，大水的召回也直接参与选择。因此，第3节五条交接是大环的主方向，不是删去其余依赖后的五级流水线。

### 3.4 相克是同一过程的条件性作用

| 关系 | 在本闭环中要追的作用 |
|---|---|
| 金克木 | 结算、边界和校准使没有结果支持的展开不再无限支配后续行为，同时保留可检验的新尝试 |
| 木克土 | 新预测与实际新证据促使旧依据重组，仍保住有用语言能力 |
| 土克水 | 可读性、来源和共同容量约束收藏，避免混账与无效占据；已有结构抵抗无根据的流失 |
| 水克火 | 过去经历使无益重复减少，仍允许有收益的复习和表达；效果应从学习中出现 |
| 火克金 | 实际出手与世界结果检验旧判断；稳定接触使判断变准，混乱接触也可能使结算失真 |

这些作用允许间接实现、时延和反向影响，不添十条固定正负反馈边。

## 4. 脏腑：相对持续的组织，与实际传化

传统依据分别来自《素问·灵兰秘典论》的官职比喻，以及《五藏别论》对藏与传化的区分。本文借它们区分职责：**脏偏向可持续的功能组织，腑偏向受纳、裁断、转化、传送和腾退。** 相对的阴阳关系可继续细分；不是“木火属阳，所以肝心也只能是阳”。

下表的工程释义是本项目的候选定义，不是古文原义、神经解剖对应或新增算法要求。某职责可以分布在身体各处，也可以由同一过程承担几个职责。

| 相与配对 | 脏：持续组织什么 | 腑：使什么实际传化 | 在当前大小五行中的落点 |
|---|---|---|---|
| **木：肝—胆** | **肝：蓄谋。** 维持可被经历修正的世界关系、情境与候选后果 | **胆：裁断。** 在可达候选中形成有依据、可承诺的方向 | 肝贯穿木中水、土、木；胆贯穿木中金、火，并接火的承诺。肝胆均可再展开内部五行 |
| **火：心—小肠** | **心：统合当下所向。** 使当前意图、参与和出手属于同一个持续身体 | **小肠：接住并分辨接触所得。** 把实做、自听、外界结果分清后交给运化 | 火中土、金与火生土交界；当前有动作记录与自听，高阶自我统合尚是目标 |
| **土：脾—胃** | **脾：运化成可用结构。** 使语言变成可读、可递推、可再学习的依据 | **胃：受纳。** 让真实到达的语言按时序进入同一身体，保留来源与承接上下文 | 胃偏土中土的入口，脾贯穿土中木、火、金、水；两者共享身体递推与学习 |
| **金：肺—大肠** | **肺：治节。** 维持可校准的分辨尺度、边界和整体运行约束 | **大肠：传化与腾退。** 处理不再可用、来源不清或重复占据的内容，归还可用余地 | 肺贯穿金中土、金；大肠连接选择、释放与水的重新开放，不能把所有遗忘都当好事 |
| **水：肾—膀胱** | **肾：持有可再生的根基。** 长期保留能支持今后预测、归因和重学的区别 | **膀胱：蓄而能出。** 使潜藏内容按需进入使用、周转或释放 | 肾偏水中水、土；膀胱跨水中火、木及腾退；共用有限记忆，不另造液体池 |

五脏为肝、心、脾、肺、肾；六腑为胆、小肠、胃、大肠、膀胱、三焦。十二经脉还包括心包这一功能组织，不能把“五脏六腑”直接计成十二个独立模块。

| 补充职责 | 本版候选定义 | 当前落地边界 |
|---|---|---|
| **心包** | 维护内在意图与对外接触的界面，使想象、实说、外界观测和真实结算各有身份 | 已有副本内言、实际自听、来源与版本检查；完整的自我保护和自我模型未由此自动得到 |
| **三焦** | 贯通当拍活动、跨回应整合、长期保留的不同时间尺度，并协调它们的有限资源与交接 | 已有不同时间尺度、固定容量和更新时序；统一的自适应资源调度仍待形成，不新增“上中下三池” |

这里肝胆的对应尤其明确：**谋虑使选择有内容，决断使谋虑能发用。** 决断仍需要记忆、承接和校准，因此不把肝胆简单等同于两个孤立的小五行格。

## 5. 十二经脉：贯穿这些职责的可追踪通路

工程上，一条“经”先定义成：**带着明确来源与时序的区别，经过哪些已有转移，被哪里使用，并怎样影响下一轮。** 它可共享参数、记忆和计算，不要求专属通道。

传统经名见《灵枢·经脉》。下面按其通行排列列名，以方便查对；这张表不是神经线路发现，也不规定模型照十二经名轮流执行。

| 经名 | 本项目的候选功能通路 | 现有承担与缺口 |
|---|---|---|
| **手太阴肺经** | 既有预测与比较尺度 → 实际误差 → 校准与运行边界 | 结算、误差统计、precision 等已有；分布变化后的整体校准继续验证 |
| **手阳明大肠经** | 发现重复、失效或来源混杂 → 选择释放/禁用 → 可用容量回到新学习 | 有合并、换出和无效标签屏蔽；不等于已学会最优淘汰 |
| **足阳明胃经** | 外界语言实际到达 → 按来源、顺序承接 → 当拍预测与学习入口 | 世界回应到 `step` 的路径已有，自听与外界字节分开记账 |
| **足太阴脾经** | 预测误差 → 同一身体写入与更新 → 后续读出、保持和重学 | 神经身体与快表共同学习；必须一起算收益，不能漏掉快表 |
| **手少阴心经** | 当前所向与候选方向 → 同一身体作出承诺 → 实际动作及参与保持 | 候选选择、实际话语与待结记录已有；不宣称已经形成成熟自我目的 |
| **手太阳小肠经** | 已执行话语及后果 → 分清实做、自听和外界返回 → 可归属的后果 | 草稿/实说核对、来源与响应时序已有；长期归因依赖所保留的区别 |
| **足太阳膀胱经** | 当前未结参与 → 有限保持 → 到达后果后使用或释放 | `prev`、待结动作与经验条目承担一部分；未证明任意长延迟均可正确归因 |
| **足少阴肾经** | 长期留下的区别 → 当前唤起与重编码 → 再学习并重新保留 | 有限经历库和当前编码器重读；不能把它说成恢复全部旧参数因果 |
| **手厥阴心包经** | 内言候选 → 实际表达 → 外界证据 → 守住三者身份 | 内言副本、自听及实测/估计分离已有；不是另加一个安全审查网络 |
| **手少阳三焦经** | 跨字节、回应和长期记忆的交接 → 有限资源下继续运行 | 多尺度时序与恢复协议已有，跨层统一调节仍是候选职责 |
| **足少阳胆经** | 候选后果与可靠性 → 可承诺的行动倾向 → 火的实际选择 | 木的 calibrated forecast 到 `_utter` 已有路径；有效收益要由整体检验 |
| **足厥阴肝经** | 当前情境与旧经历 → 行动条件预测 → 修正未来方向 | 基本盘、残差预测与回放已有；学习后果的准确性仍需随世界检验 |

十二经描述的是交织通路，五行相生描述的是功能转化关系。两张图可以在同一身体上叠加，不能仅凭名称推导出相同拓扑或相同时间顺序。

## 6. 奇经八脉：跨常规通路的统摄与再组织

《难经》将八脉与十二经区别讨论。这里仅借其跨常规通路的组织思想，提出八种统摄视角；**先给出需要保持的关系，再寻找已有共同动力学如何承担**。

| 名称 | 候选统摄关系 | 当前有什么，尚待什么 |
|---|---|---|
| **任脉** | 内向承接：边界语言 → 整合 → 可持续的内部结构 | 感知、同化和保持路径已有；不另造“阴能量” |
| **督脉** | 外向发用：内部所向 → 具体表达 → 世界变化 → 归返身体 | 动作与自听、世界响应已有；高阶自主目的待发展 |
| **冲脉** | 贯穿时间尺度：旧经历重新激活，参与当下学习与后续选择 | 有回放、重编码、快慢状态；持续共同受益尚需整体证据 |
| **带脉** | 横向约束：多种通路共享有限状态、吞吐和存储，不能无限各自扩张 | 当前有分项硬容量与工作量；联合自适应分配尚未实现 |
| **阴维脉** | 内在依据一致：跨经历保留来源、时间、目标版本和事实/估计身份 | observed 收益与 TD 写回分离、迁移有效性检查已有；长期目标变化仍需处理 |
| **阳维脉** | 外在作用一致：预演的具体动作、真说的话与观测后果保持可核对关系 | 内言/实说复现与对称探针已有；世界有无可学差异必须一起查 |
| **阴跷脉** | 内向活动的起落：潜藏如何被唤起、整理，随后重新潜藏 | 有回放；自主休息中的语言结构整理还没有得到验证，不重开已失败的影片熵或噪声重放方案 |
| **阳跷脉** | 外向活动的起落：从待发到实际接触，再退回继续听 | 当前能选沉默/生成/重说；固定交互周期与话语窗口仍有工程设定，不能称为全自主节律 |

这八种关系有交叠，当前没有证明它们必须恰好分成八条。映射成立的价值在于暴露交接与统摄缺口；无法落到共同状态或实际后果的映射保留为候选，不据此加机制。

## 7. 与当前代码、定理的具体对照

### 7.2 已读 Lean 的作用边界

入口为 [定理索引](CGB_PROVEN_INDEX.md)。本轮重读以下陈述：

- [`LanguageLifeKernel.delayed_credit_requires_history_carrier`](../../lean/CGBAxioms/CGBAxioms/LanguageLifeKernel.lean#L107)：如果当前可见状态相同，而所需信用不同，则只读当前状态的规则无法两者都正确。它要求保留必要历史区别，不指定资格迹形状，更不推出十二经或八脉数量。
- [`Generation.ActiveNavigation.reactivation_exact_held`](../../lean/CGBAxioms/CGBAxioms/GenerationActiveNavigation.lean#L137)：在写入经固定保持因子进入损失的陈述中，当前重新编码具有给出的精确导数。它支撑受限的重新激活路径，不等于完整非线性身体的全部历史信用。
- [`GDNLife.Process.observed_continuation_improvement_is_empirically_paid`](../../lean/CGBAxioms/CGBAxioms/GenerationFutureValue.lean#L126)：已观察续文逐项不变差且至少一项严格改善时，经验未来码长改善。它支持把语言变化作为结算依据，不保证某个见证池无偏或所有未来均受益。

本轮增加的是功能规格和可追踪对应，没有新增 Lean 陈述，也没有因此新增身体满足条数。候选名称的价值要由现有共同转移能否兑现其作用来判断。

## 8. 后续落实顺序与定义边界

1. 以第 3 节五个实际交接为骨架，追一条真实经历从唤起、出手、回应、结算、收藏到下一次使用。先用已有运行记录与代码确认交接。
2. 脏腑命名定位该交接里“持续组织”和“实际传化”的不同职责；经脉命名追踪贯穿职责的信息路径。不为名称齐全而新增参数、状态页或控制器。
3. 修德优先修会损害下一环的共同关系，例如实测收益被 TD 估计覆盖、评分漏掉快表、旧基本盘跟不上漂移。不是同时给每个常数配一条自调节器。
4. 跨尺度、自主节律与自我模型从这些共同关系中继续发展。新增自由度前仍查 Lean、已有机制和全环资源边界。
5. 递归细分到能够追到已有状态、更新和实际后果就停止。只有细分能区分不同的失败原因或调节关系时才继续展开；不要求每层再长出25个格子，不以命名数量作为进展。

定义分三级：大小五行的作用与交接是本版功能规格；脏腑是第一版职责组织；十二经与奇经八脉是第一版路径/统摄候选。后两级可依据实际动力学修订，不反过来要求身体长出同名部件。

## 9. 沿一条已运行经历核对组织图（只读，2026-11-05）

证据：[只读周转核对记录](../../results/published/cgb_nested_phase_trace_20261105.json)。来源是已经结束的 `cgb_observed_gain_joint_20261105`，512轮、同一个持续个体；这是用户授权的无语义机制诊断，不是新的真实语言能力实验。本轮没有训练、没有世界交互，没有修改身体文件。11份关键执行源与运行登记哈希一致，原配置、日志和摘要哈希前后不变。

### 9.1 金到水：实测收益与估计收益确实分开了

512轮日志中的 `metal_g` 均等于同轮 `joint_pre_nll - joint_post_nll`，下一轮待结记录中的旧 `g` 均等于上一轮实际结算。409轮具有完整木标签均值可核对，存储均值误差最大约 `1.14e-6`。

例如第一轮实际g为 `11.35883093`。第二轮算出的前一轮TD目标为 `16.45148523`，观察收益槽仍为约 `11.35883141`，没有被TD目标覆盖。这使“金中水→水中土”的观察身份得以保持；不是否定TD，TD仍训练估值与行动信用。

### 9.2 水到火：确有跨窗口的实际取用

| 时点 | 实际发生的事 |
|---|---|
| 第74轮 | 生成32字节话语，记录到槽456，未合并；实际g=`0.0002641188` |
| 中间 | 第75至495轮累计接收216394个外界字节；日志中没有再次写槽456 |
| 第496轮出手 | `reused_slot=456`，实际说出的32字节与第74轮逐字一致 |
| 第496轮回应后 | 新经历合回槽456，实际g=`0.0008267239` |

这是“长期潜藏→重新唤起→再次出手→获得新后果”的具体承担。它说明保留下来的旧内容被身体实际使用；该次重说是否优于其他做法，要另看同体后果，不能由取用本身推出。

### 9.3 木到火：基本预测在传递，情境修正的分量仍小

512轮内，去掉木预测输入所对应的动作分布TV变化中位数约 `0.000578`；仅去掉情境残差的TV变化中位数约 `0.00000229`。这是当前选择时点的固定输入干预读数，不是长期收益估计。

因此可以定位：已有经历、动作基本盘与选择路径确实在工作，木的情境修正所增加的直接分量仍较小。旧经历能够进入火，和木是否形成准确、可泛化的情境预测，是两个相关但不同的交接。

## 10. 本轮发现的具体交接缺口：动作身份在合并后混账

第74轮的槽456来自“生成”，第496轮又以“重说”合入。两次实际收益均值为约 `0.0005454213`。现有转移中：

1. `commit_experience` 合并收益与连续状态。
2. `v4c.py::step` 将 `memory.option[slot]` 写为最新动作类型，此例变成“重说”。
3. `v4p.py::_store_label` 发现动作类型混合，把木的回放标签置为不可用：`wood_option=-1`、`wood_target_count=0`。
4. 然而收益召回的 `reward_label_valid` 只检查目标版本和观察收益有效性，没有同样排除动作混合。`recall_outcomes` 又按最新 `memory.option` 分组。

结果是：**一个混合了“生成”和“重说”的实测均值，仍可被当作“重说”的历史收益使用。** 这里每个g本身真实，错误发生在它被归属给哪一种动作。

用真实第74/496轮的两个g，在CPU上调用现有 `commit_experience`、`_store_label`、`reward_label_valid` 与 `recall_outcomes` 做隔离接口复现：木标签已无效，但收益读口仍有效；“重说”行得到 `100 × 均值 = 0.05454213`。复现使用相同单位特征强制合并，验证这条实际helper链；没有重放原检查点、没有运行世界，也没有学习。

五行定位：金中水送来的真实后果没有错；水中土合并时丢了动作类别区别，水中金没有在另一个读口阻止错误归属，水中木遂把混合依据送进木中土，并可继续影响火。这是贯穿收藏、唤起、预测与选择的同一个问题，不能只以“木回放已排除混合标签”宣告全环正确。

### 10.1 最小修复规格（随后已实现，零训练）

- 继续使用现有槽、计数与动作标签，把“作为某类动作收益可读”要求的一致性检查用到所有相应读口。优先复用已有 `wood_option/wood_target_count/count/option`，不新建脏腑、网络或奖励池。
- 混合条目的内容可以继续用于允许混合的表示或后继学习；不再把混合收益均值伪装成最后一种动作的均值。内容可读、收益按动作可读、完整木标签可回放三种权限应明确区分。
- 覆盖真实调用顺序：异动作合并、同动作合并、默认旧模式、已保存身体的恢复及跨目标迁移。检查直接收益召回、重说候选准入、木回放各自如何使用标签。
- 先做零训练接口核对与完整恢复；是否改善整圈，后续才沿原同源配置判断。当前的512轮结果仍按原算法保留，不改写为修复后的结果。

Lean的 `delayed_action_credit_requires_state_separation` 已给出相关边界：若后果需要区分动作而载体把它们合成同一可读状态，仅靠该状态不能保证正确归因。这里已有动作标签可复用；缺的是合并与各读口对同一语义的共同遵守，不需要由此新增一套信用载体。

### 10.2 实现与真实检查点核对

用户要求先汇报后台训练、再修此问题。后台observed记忆训练已完成512轮：终点均衡NLL为 `.40916177`，同源控制为 `.40959738`；40个固定审计点均值为 `.92652930`，控制为 `1.16654855`。这是上一项“观察不被TD覆盖”的结果，不能归因于本节随后才实现的修复。

本节修复复用现有元数据：`navigation_settlement.py::complete_action_labels` 统一检查占用、计数完整性和动作一致性；迁移和 observed 模式的 `reward_label_valid` 共用该规则。直接收益召回与重说候选准入使用同一读口，因此同时过滤混合动作收益。TD旧模式保持原合同；混合经历的原内容、原观察均值和通用表示读取保留，没有新增持久数组、模型参数或检查点字段。

在完成训练的真实 `last.pt.gz` 上只读核对：730个占用槽，原有308个当前目标的观察收益可读槽，修复后272个；36个归属不完整或不一致的条目不再被当作某一动作的收益。槽456的两次g均值仍是 `.0005454213`，其生成/重说混合使条件收益读口关闭。检查点哈希及相关内存张量前后不变。

接口测试包括真实helper调用顺序下的生成→重说、重说→生成、沉默→生成合并；同动作均值召回；重说候选准入；通用内容仍可读取；已有内存state_dict恢复；旧observed模式恢复无需新迁移；以及默认TD兼容。证据见 [真实检查点读口修复核对](../../results/published/cgb_action_gain_read_fix_20261105.json)。本节尚未启动修复后的整圈训练，不把读口正确等同于收益已经改善。
