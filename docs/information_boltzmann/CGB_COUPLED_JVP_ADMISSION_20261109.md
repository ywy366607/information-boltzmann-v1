# 全层原生 GDN 单方向 JVP 只读准入

用户要求试行 8 日 Lean 耦合标记。此次仅研究副本，无训练、无主个体更新、不覆盖主源；模型为已有340M量化冻结底座，使用课程已有提示的前 4、16、128 个词元。它是从检查点原生状态分出的冻结探针，未接入原 pending 的连续生活结算，也未挂接经历表读写，故不能称完整生命体已覆盖定理或已经实现长期信用学习。

`coupled_tag_exact` 与 `delayed_loss_capture` 只在实际转移的可微/JVP前提下成立；被测参数是第2层 `A_log[0]`，当前在整个输入窗以同一共享参数方向产生源，不是只标记某一次旧事件。`bounded_causal_tags_20261108.lean` 的全耦合构造要求完整状态转移；此处只实现原生24层 S、短卷积、层间残差、MLP与语言读出，未含经历库、行动、学习器/优化器状态或环境，不能将其称为整个闭环 JVP。

## 算子与前向对齐

`attempt_01` 证明原 FLA `ChunkGatedDeltaRuleFunction` 无 forward-mode JVP 接口，不能直接对原融合实现调用前向自动微分。为只读参考，`coupled_gdn_reference.py` 实现相同次序的 GDN 递推并在进程内替换融合 norm、量化线性、SwiGLU；绝不修改模型权重、vendor或生产执行路径。标准 PyTorch 的 CPU 单元检查前向 JVP 与中心差分一致。

128词元在同一原生状态上比较原生和非融合参考：logits RMS 差 0.003646、最大绝对差 0.0234375；逐层 S 相对差见 `reference_128/report.json`。这是近似匹配而非逐位一致，因此参考 JVP 不能直接声称等于原 Triton/FP16 程序的严格导数。

这里 `max_memory_allocated` 不含驱动、其他进程、主机映射、磁盘、长训练Adam及所有运行负担。两峰值包含不完全相同的缓存/参考算子，是执行流程峰值而非严格可迁移的增量成本。峰值统计均在模型加载后重置；JVP阶段包含模型的现有CUDA分配及参考缓存。主机消耗尚未单独测量。此次是一个原生状态方向，不是整个模型所有参数的资格，24层四种cache共96个张量带有切向量；层1方向为零、后续层传播。

16词元同一参考计算图的标量 JVP 0.00364438，VJP 0.00363771，相对差约0.183%；4词元约3.14%。128词元未做反向检查。128词元参考JVP与同参考程序的参数正负微扰，ε=.05/.1 时logit方向余弦约 .929/.979、相对L2误差约 .406/.206；第24层S余弦约 .985/.995、相对误差约 .178/.098。混合精度舍入是差异候选原因，尚未单独证明；不能将此数字当成精确准入通过。4词元深层有限差分更差。

原生融合实现、非融合参考、JVP与分段传播存在数值差异；没有登记成功阈值，不能事后宣布通过。要进一步落实：实现一次事件源与共享参数源分开、跨多个真实窗口的方向持续与捕获；将经历写读及必要的更新状态纳入共同转移；测显存、主机内存、耗时与有限差分/反向对齐；不能把参考函数一键替代生产核。两个方向和1B模型都尚未实测。无需做无穷长 BPTT；有限候选数仍为O(1)状态，但使用数值导数和带损耗动力学不保证长期存活或学习有效。
