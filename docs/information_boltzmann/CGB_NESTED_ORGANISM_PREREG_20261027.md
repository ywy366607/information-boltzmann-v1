# 嵌套生物的生成（运行前写定，2026-10-27）

世界：`rain_torus_w0`（已过准入门，`CGB.NestedWorld.axioms_torus`）。生物是同一张 Lean 表（`NestedWorld`）里的内部单元、成对规则、交换、燃料规则；模拟器由表生成，速率与 Lean 逐条对拍（准入门检查）。

## 1. 由定理与公理定下的结构

| 页 | 单元数 | 态 | 作用 |
|---|---|---|---|
| F 受体 | 8 | 0, 1, 2 | 经膜与本格食物池交换（结合 0→1；卸载 2→1 还回一份） |
| Y 慢记忆 | 8 | 0, 1 | 与已结合受体交换（G13 慢均值；C-1 需要的"近期平均"） |
| M 马达 | 1 | 0 翻滚, 1 游动 | 游动态时燃料规则驱动前进；非游动态时可转向 |
| E 储备 | 20 | 0, 1 | 经膜从本格食物池进食 |
| D 废物 | 10 | 0, 1 | 经膜把废物排进本格废物池 |
| S 膜 | 10 | 0 坏, 1 完好 | 所有经膜交换的导通量 ∝ 完好膜单元数（`xgated`） |

规则（每条可逆，守恒，`hspec`）：
- Y0 + F1 ⇌ Y1 + F0（记忆跟随现在，慢）；**时间尺度前提**：其速率前因子至少比受体结合小 20 倍（结构约束，不交给选择）。
- Y1 + M0 ⇌ Y0 + M1（过去高则游走）。
- M1 + F1 ⇌ M0 + F2（现在高则停）。**修正**：原预注册（WORLD2D §O）写的 F1 + M1 → F0 + M0 不守恒含量，会被 `hspec` 拒绝；改为把马达的一份交给已结合的受体（F 第 3 态），F2 经膜卸载回本格。
- S0 + E1 ⇌ S1 + E0（修复膜，耗储备）。
- 燃料（移动时触发）：E1 + D0 ⇌ E0 + D1。
- 交换：F 0→1、F 2→1、E 0→1（食物池，经膜）；D 1→0（废物池，经膜）。
- **泄漏（物理，所有页）**：每个页的每个含量态都有一条不经膜、单单元、向本格废物池放一份的交换（F 1→0、F 2→1、Y 1→0、M 1→0、E 1→0、D 1→0、S 1→0），共用一个前因子 κ_leak。膜的磨损只是其中一条。

## 2. 物理常数（世界的，不交给选择）

- 完好膜能量 φ_S1 = −5：位于雨点处食物势（约 −3.4）与废物势（约 −8）之间。修复在雨点可行；与废物池平衡时完好比例约 10%，所以不修复必死。
- 泄漏前因子 κ_leak = 6e−4（所有页相同）：废物势 −8 时每个完好膜单元约每 500 拍坏一次；10 个单元无修复约 1500 拍全坏。
- 能量尺度 Φ = 8：所有可选能量 |φ| ≤ 8（物理，不交给选择）。
- **为什么泄漏必须是这种形式（已证，`GenerationNestedWorld.lean`，commit 9d19ef8）**。用户 2026-10-27："世界不应该允许永生，否则根据富者俱乐部，世界将塌缩"。公理（P2b）不允许严格的永久锁死，但扣留可以任意长，途径有三：出口需要伙伴，伙伴耗尽就关（`partner_exit_blocked`；例：衰变需要 D0，生物憋住不排废就成了永生的石头）；出口经膜，膜没了就关（`gated_exit_blocked`；例：尸体把储备锁死）；能阱任意深。不经膜的单单元泄漏、能量有界时，速率 ≥ κ·e^{−Φ−½ln V}，与生物的状态无关（`leak_bound`）。所以每个能装含量的页都要有这样的泄漏，能量尺度是物理。这就是漏积分（LIF 的漏项）：最长时间常数 τ_max = √V·e^Φ/κ_leak。
- **泄漏由定理推出，不是设计（2026-10-27）**。活着的个体必须排泄，由守恒推出（G16 `export_forced`、`endless_intake_endless_export`：有限容量的守恒积分器在不停的输入下必须漏，即 LIF 的漏）；排废（D→废物池，经膜）由此而来。但守恒不要求停止进食的身体（尸体、石头）交还含量。这一条由 **G26c `corpses_must_go`** 推出：世界的地方有限而死亡不停，则尸体必须被移走，否则世界被尸体填满、流停止；**`dead_output_is_physics`**：尸体自己不会交出含量（经膜的出口已关），只能靠物理泄漏或别的生物拆解（分解者）。用户 2026-10-27："这说明世界生态系统，分解者的必要性"。本世界表里没有生物取邻格尸体的事件，所以物理泄漏是唯一的分解者；把分解者作为生物之间的事件加入，是之后的扩展。
- 第一版只在膜页加了磨损，是看到漏洞后选的、没有推导，也不完整（尸体仍锁住储备）；此条取代它。
- **死亡** = 没有完好膜单元：此后一切增加生物含量的事件速率为 0，只剩物理的自发重组（`dead_only_reforms`）。存活 = 首次完好膜数为 0 的时刻。模拟照常继续（忠实于 Lean），只记录首次死亡。

## 3. 由选择定的数值

φ_F1, φ_F2, φ_Y1, φ_M1, φ_E1, φ_D1 ∈ [−8, 0]（在物理界 Φ 内）；四条内部规则、四条经膜交换、转向、移动的对数前因子 ∈ [−9, 0]；须满足时间尺度前提。单元数固定（上表）。出生：膜全完好，储备半满，其余全 0 态，随机位置与朝向，每个世界一个生物。

选择：种群 32，每代 8 个新的随机世界（种子不重复），一生上限 5000 拍，适应度 = 存活中位数（并列时看均值）；验证集种子 500–515 选出。只接受通过生命门的数值。

## 5. 物理修订（2026-10-27，第一次选择 s0 之后；结构与预言不变）

第一次选择（`nested_s0_20261027`，第 0–9 代）暴露了世界物理的两个缺陷，结果**作废**，不用于任何结论：

1. **食物没有化学能。** 嵌套世界里食物和废物是同一种含量，只差浓度；局部废物一浓，对生物就"是食物"。选出的个体把能量选到 −8 附近（与废物势相当），守着自己排出的废物云维持膜（修复与进食前因子都在下限，移动与翻滚也在下限，几乎不动；用户看页面时也发现它们"一辈子动不了多远"）。网页长跑 30000 拍：尸体 49 具、分解 0 具，有个体活满 30000 拍。早先为二维世界推出过"注入必须是自由能"（FOOD_MU0 = 8），第一版嵌套表漏了。**修正**：食物份带化学能 foodE = 8（Lean `NestedWorld.foodE`，434d0b2）；食物储库的刺激整体平移 +8（干 0、雨 16），世界本身的动力学不变。
2. **能阱可以深到废物之下，尸体溶解要求全空。** **修正**：
   - 体内每份含量的能量 ∈ [0, 8]（物理），下限 0 使任何身体态都高于半满以下废物池的势，废物不会凝结成身体；
   - 膜 φ_S1 = 2（在废物 < 0 与雨点食物 ≈ 4.6 之间；储备须在 (2, 4.6) 才能修膜又能进食），泄漏前因子 1e−5（膜单元约每千拍坏一个，不修复约 3000 拍死）；
   - 溶解：膜全坏的身体以任意内部状态连同全部含量溶进废物池（4bc190b），导通量是对称的 Metropolis 形式 κ_dis·exp(−|ΔE|/2)（434d0b2），顺势以 κ_dis = 0.005 进行（尸体约 200 拍分解），逆向（废物聚成死身体）被 e^{−|ΔE|} 压制；身体物质 B = 16，模拟器略去逆向，`formationBound` 报告上界。
3. 一生上限改为 8000 拍（饥饿死亡约 3000 拍，须能分辨进食的个体）。

第二次选择：`nested_s1_20261027`，同一结构、同一选择规则。

## 6. 物理修订二（2026-10-27，s1 与 ES es1 之后；结构与预言不变）

s1（GA）与 es1（Qiu et al. 2025 ES）都停在验证分 ~3100–3500，而生态位扫描（`nested_niche_sweep`）表明：无论雨势多少，理想局部觅食者都无法同时满足"自身 ≥ 50% 时间在 f* 以上"和"盲走 < 其一半"。原因不在生物，而在**池子的导通量**：系统地图 7.1 早已推出格子层的集总速率是 κ·√(源重数·目标重数)·e^{−ΔE/2}，但 T-E2 的实现取了常数导通量，于是整池像一个单元：每份食物的衰减与扩散随 1/√n 变慢（光晕窄），生物摄入随 √f 而不是 f 增长（感知的回报被压平）。

**修正**（按 7.1 原样，不是新机制）：Lean `poolCond`/`poolFactor`（f6bac76），交换、供给、扩散的导通量乘以重数因子；与 cellF 合起来即质量作用（`mass_action_up/down`）：池子得一份 ∝ V − n，失一份 ∝ n。证明：仍是公理模型（对称性由 `poolFactor_symm` 与可逆性给出）；泄漏界变为 κ·e^{−Φ}，不再含 log V；感知定理现在说摄入速率正比于食物份数。

常数按同样的时间尺度重新声明（世界 JSON 的 `mass_action` 条目）：干食物每份寿命 500 拍（κ_in = e^{−4}/500）、雨把空格以 ~5 份/拍充满（μ_rain = 17）、每份每拍向每个邻格跳 0.1（光晕 √(Dτ) ≈ 7 格）；生物泄漏 2.6e−7（空废物池中每份的泄漏速率与旧表相同）；交换前因子的选择范围下移到 [−16, −4]。s1、es1 的结果作废；f* 与生态位用同样三条原则重算（可行、感知有用、最省），然后从头选择。
