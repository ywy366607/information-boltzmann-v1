## 新增纠错证书

`reducedCore_iff_atomized_of_regimes` 明确：

```text
Finite Λ + HomogeneousContact + Rigid ⊢ (ReducedCore ↔ Atomized)
```

`path3Rigid` 是三个位置、两个局部状态、单射身份、空事件集的有限模型。`path3Rigid_reducedCore` 和 `finite_rigid_reducedCore_not_atomized` 共同证明它满足九字段候选与刚性，却不满足原14项。这个构造只审查逻辑蕴含，未作生物或能力实验。

有限性与刚性因此不能替代接触齐性；恢复定理额外加入A04是有内容的前提。九字段也仍需逐项独立性检验，才能进一步讨论极小性。
