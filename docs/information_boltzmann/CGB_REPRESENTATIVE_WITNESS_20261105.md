# 金中水的抽样对齐：v4s

## 问题与决定（运行前）

v4r已将快表变化纳入金的结算，波动仍很大。现有水中的见证只收听到时高于平均惊讶的窗口，金因此长期用难例集评价身体。这里决定先去掉这道筛选，使用原有32槽蓄水抽样，每个等长回应提供一个均匀抽取的128字节窗口；所有回应都有相同入池机会。不是添加新的收益账户或平滑器。

这使抽样代表该采样时期实际收到的窗口，不代表未知未来、不保证自适应训练后的泛化估计无偏。回应先发生、学习完成，再准入；一轮前后见证内容不变。网络/快表均用当前值只读评分；旧概率评分保留为诊断。

## 现有理论与准入

`GenerationFutureValue.empiricalFutureLanguageCrossEntropy`将价值连接到实际重遇语言的代码长度；`observed_continuation_improvement_is_empirically_paid`说明其条件性的改善关系，不证明采样方案。`GenerationContinualOptimizer.partition_is_unbiased`只保证事件/背景两部分合计的恒等式，不能被当作丢弃背景仍无偏的证明。`GenerationGradientFilter.fresh_decrease_unbiased`是在明确成对噪声条件下的代数抵消，不能推出惊讶筛选样本代表未来。

本地准入`reviews/witness_sampling_20261105.lean`核对有限池中旧项的边缘留存率、固定损失等边缘概率的线性均值；不添加整体生命或未来能力定理。测试检查高/低惊讶不再改变入池选择，容量有界，当前快表评分与现有peek一致且不写表。

## 运行合同

从v4q第1024轮末快照建立一个副本，网络、快表、经历库和优化器延续；原池已被惊讶筛选，因此显式开始新的空32槽采样时期。旧经历及其结果标签保留，形成测量合同迁移，不宣称全历史都是均匀抽样。旧快照缺少上一拍木的部分中间量，首拍不能称精确续跑。以后由新checkpoint辅助函数保存这些量并隔离恢复优化器缓冲。

单seed11，连续256轮真实OWT接话世界，不改世界和动作规则，不干预妈妈世界。每64轮在同一32768字节独立验证上评分并保存末快照；记录实际外界/自听字节、优化器步数、重放、g、四通道预测误差和信任、木对火TV、动作分布。每轮核对新g确实进入同一金结算和木的10g标签。结束后检验含待结算信用的下一步精确重放。

预先判据：实现准入要求容量/采样/无写入/接线/下一步恢复均通过；效用检查用末128轮中信任后收益预测是否胜过基本盘和无动作均值、独立NLL是否恶化超过.01。若不满足，记录未通过，不继续开长跑。固定预算非收敛证明，不以单条轨迹和旧v4r轨迹之差宣称因果优势。运行前不手调学习率、损失系数、池大小或平滑常数。

实现：`language_navigation_kanli_v4s.py`、`navigation_checkpoint.py`。入口：`scratch/run_representative_witness_20261105.py`。输出：`results/cgb_navigation_representative_witness_20261105/`。

## 结果（运行后）

256轮完成，独立NLL 1.473756→1.480969→1.471233→1.463925→1.474686。末128轮收益10g MSE：基本盘.00115231、信任后.00115324，无动作均值.00116320；未通过同时胜过两个基线的预登记效用要求。收益修正平均信任.01069，当前g波动标准差.003329。接话和头4字节预测仍有可测误差下降，不能把它们说成收益预测已有效。完整数值、预算与恢复见结果目录`RESULT.md`。

按约定不扩量、不调参。均匀准入实现了本轮实际回应的等机会采样，但它仍不是未来语言分布，更不是因果价值的保证。金的读数随见证池变动而变，跨轮累加也不等于固定验证集的改善。后续应检验它对实际未来重遇的预测价值，而非单独追求更平滑的g。
