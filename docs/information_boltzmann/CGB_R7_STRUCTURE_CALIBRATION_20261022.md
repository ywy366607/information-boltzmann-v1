# R7结构观察的物性反演修订

写于固定物性五态结果已知、下述物性拟合运行之前。固定结构能2时，实际结构存留评分退化至单指数约1.978；平稳安装比例0.9991至0.99994，训练最大15位置下预测均值接近15，实测7.6。没有改动这些失败结果。

当前结构能等值来自先前声明材料，并未由真实果蝇反演。主线允许从真实现象识别有限物性；因此先检验已有参数是否能闭合，不立即增加新恢复状态或规则。

本修订只开放原参数structure_energy（无量纲kBT内的形成储能）与统一时钟c。trace_energy=2、capture_coupling=2、bound_energy=-2及全部相对尝试率/组成/端容量保持原值；S=1/2/4/8/16各自报告。形成能范围[-10,30]，log c范围[log(1e-4),log(1e8)]。能量变化必须同时影响原assembly正、反率及平稳权重，不准只修改拆卸率。没有创建单独拟合的可见性权重。

仅用Control CG1/2的149个新出现轨迹拟合两参数，以原离散结束/右删失似然为唯一目标；采用跨形成能与时钟的多起点/界面检查和额外优化。各S保留全部结果，不按CG3挑选。训练锁保存后才评分CG3。CG3已在先前研究中看过，仍为探索性外推，不冒称全新验证。

随后沿用原预先声明的数量闭合：根据已拟合Q的p_on，独立地用训练计数选择整数K∈[15,128]，不让计数再调整形成能/时钟，也不将重复使用的轨迹和数量分数相加当作独立联合似然。报告数量、出现通量和时间相关的预测/残差；这是一致性约束，不是“真实共享资源竞争已确认”。

反演改变的是条件投影的材料参数，不写回实际脑/母女个体。若两参数只改善寿命而数量仍不合，则本观察闭合仍失败；转向共享供给、几何/初始条件和实际可见性，保留原物性/失败记录。支持分子名称不作为新状态清单。若参数或K触边/似然平坦，明确未识别，不把最优点当真实能量标定。
