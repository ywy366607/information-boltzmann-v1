# ActiveLoop 审查：保留合法构造，撤回自维持已闭合结论

审查日期：2026-10-24。对象：Gemini 新增的 `ActiveLoop.lean`、交接文本、技术报告与研究树节点。结论是**部分可复用，尚不能作为自维持正见证验收**。本轮保留原模型全部定义和证明，只更正说明与主张登记，并加入独立复查材料。

## 1. 已核验的成果

新增模块可构建；全量信任与导入审计通过。新增的 8 个源码定理分别证明：唯一真空、时钟界、六条介质公理、世界状态求和展开、世界转移非负、行和为一、边界读取、平均第一定律。

此前能量层的 1,473 项声明签名全部保留。`AuditAll.lean` 与当时相比只改动了说明，原有传递公理检查、签名和依赖清单仍在。当前生产库为 28 个模块、350 个源码定理；自动生成条目不等于新增理论成果。

这证明所写有限过程在当前形式语言内合法，并能接入能量账户。它为继续构造因果闭环提供了起点。

## 2. [P1] 正常过程也会失配，报告的生存值与优势式不成立

`advance` 在刺激 3 下把状态 3 一律变成动作 A（状态 1），没有记住此前动作 B。正常 B 分支的联合状态轨迹是：

```text
t=0 (动作A, 初态0)
t=1 (动作A, 线索B)
t=2 (动作B, 场景B)
t=3 (已摄食, 场景B)
t=4 (动作A, 场景B)
t=5 (已摄食, 匮乏5)
```

首个分支选择概率为 1/2，后续转移均确定。这条**正常闭环进入匮乏的路径乘积概率为 1/2**，已在 Lean 复查文件中直接证明。更新沿用旧状态同时更新语义，最后一步仍可能摄食，但落入匮乏后没有后续摄入机会。

按现有 `Operational.survival`、恢复窗口 2、阈值 1/2 和实际未来协议，精确有理数枚举得到：

| 世界时刻 n | 正常 survival | 剪断 survival |
|---|---:|---:|
| 0 | 0 | 0 |
| 1 | 1 | 1 |
| 2 | 1 | 1 |
| 3 | 1 | 1/2 |
| 4 | 1 | 1/2 |
| 5 | 1/2 | 3/8 |
| 7 | 1/2 | 21/64 |

因此报告的 `∀ n ≥ 2, survival_cut(n) + 1/4 ≤ survival_natural(n)` 在 n=2、5、7 已被反驳。“正常持续存活率 1”也被反驳。n=0 指标为 0 是因为首次摄入在第 3 次转移才发生，超过初始恢复窗口；因此按当前出生状态连 `Operational.Persists δ`（δ<1）也无法成立。

枚举在部分时刻显示较小的正常过程优势，值得继续研究；**有限枚举尚未证明任意未来时刻的统一优势，也没有证明 `Operational.SelfMaintains`**。修复应保留必要的 B 分支记忆，明确初始化/恢复窗口，再直接证明现有目标，不能另设有利生存分数替代。

## 3. [P1] 热流残差闭合第一定律，尚未建立第二定律与能量耗尽

`activeAccount.heat` 定义为：

```text
heat = U_next + load - U_now - matter
```

所以 `active_expected_first_law` 是对账身份的合法推论。账户中的 `a`、`w_act` 为任意实数，模块没有提供 `Isothermal` 见证、温度、物理熵、随料熵流、储能下界与持续维持需求，也没有调用 `work_budget` 或 `no_sustained_use_on_finite_supply`。

例如取 a=1、w_act=2，摄食态→动作态的储能由 2 降到 1，物料能输入 0、做功 2、残差热输入为 +1；该数值已由 Lean 核验。第一定律允许此种账户，热浴是否物理可实现需额外准入，不能据此宣称第二定律或可用能预算已验证。

匮乏态的刺激为 0，身体不再变化；对 `(状态3, 世界5)`，储能始终为 2a，load=matter=heat=0。对应自环和端口数值已由 Lean 核验。当前模型的“死亡”来自摄入前景阈值，不是储备枯竭；上一轮能量定理需要的持续正需求也没有在此建立。

修复方向是先声明可实现的能源和物料来源、耗散与维持机制，再验证实际过程的第一/第二定律准入和有限前缀预算。能源必须改变事件是否可发生或其速率，才能把预算约束接回生存动力学；仅增加账户字段不能做到这一点。

## 4. [P1] “正见证已证”及任意物理底座变脑的结论超出了交付内容

新增 8 个定理中没有生存率、`SelfMaintains`、第二定律或耗尽结论。原全量审计文件是真实的证明清单，但它没有验证报告里未写出的命题。该差异属于报告与证据不一致，并非 Lean 内核接受了错误定理。

模型也尚未接入上一轮 `MaterialSource.Realization` 的物料来源见证、有限编码预算、可塑性、学习或世界模型。因此构形机制、信息反馈做功、最优贝叶斯推断和“大脑起源”只能保留为另行建模与检验的方向，不能登记为本模块的推论。上述结论直接来自源码覆盖范围，本次未进行外部论文结论审查。
