## 原视觉共演化结构迁移到语言时间轴

原视觉仓库 `fine_grain/mot_coevolve.py::MoTJointLayer` 保留地址场、读出工作切片、切片与语言共同更新、再写回场；`docs/NORTH_STAR.md` 描述同一生成结构。这里复用双向更新及共享算子，不复用原实现对整段语言的非因果联合注意力。

本体原先只在一个深层边界读出经历并注入一次；这次让同一组过去事实的工作解释贯穿全部32层。L32仍承担原始深事实、世界模型和意图接口，L2仍保留字节快表接口；它们没有被替换成新的独立主干。

设已完成经历的有版本事实锚点为 A，工作槽预算 K=8，秩r=32。每层、每个时间有工作解释 M[l,t]，以及原物理S/P。单元顺序是：

1. 由当前语言 h[l,t] 与同一时刻上一层的 M[l-1,t] 生成寻址权重、候选解释及写入门。
2. `M[l,t] = (1-beta[l,t])*M[l,t-1] + beta[l,t]*candidate[l,t]`，候选经tanh约束，beta是内容相关的可学习门。
3. 当前语言读取更新后的M，经原层输出投影的共享子算子及内容门注入残差，然后经过原GDN/FFN。
4. 下一层接收当前语言及当前时刻更新后的M；下一时间继续使用各层M的递推末态。

所以一个早期字节不会读到整段后文改完的记忆。每层末态跟随S的完整状态停存；切分训练窗口不清空它。GPU上的时间递推及反向导数由Triton内核执行，Python只循环网络层。

共享算子使用本层真实Q/K/V/O及MLP在r维工作子空间上的限制；额外的记忆FFN、角色绑定及门在全部层共享。它是对本体的资源受限共演化构造，不声称逐项复现视觉论文的大宽度in-fusion。
