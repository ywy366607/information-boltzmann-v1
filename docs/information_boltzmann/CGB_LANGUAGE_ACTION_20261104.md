# 同一身体的行动—后续语言接线（2026-11-04）

本轮跳过主动再生锁存，关闭未显示净收益的取回count反馈。使用已训练GDN＋表的完整off快照，接系统4；不新增神经参数、专用自我头或食物账户。目标是让同一身体的输出改变后续真实语言，语言结果继续改变同一身体。本文件是本轮运行合同，不宣称完成生命联合定理。

## 同一转移及来源

当前状态含慢权重、Adam状态、GDN矩阵与短卷积缓存、有限快表、待处理的末字节。该末字节在既有checkpoint中已作为目标到达，但还没有作为下一拍输入处理。恢复时核对旧数据哈希后取回它，不重置个体。

1. 只读快表和GDN，处理待输入字节，从原语言读出的ASCII `0`/`1` logits归一采样动作。两个符号是声明的环境端口，不是学成的语义或必要结构。
2. 环境按动作选两路真实OWT语料之一，返回511字节；只能读选中路的接续内容。两路是train.npy原始token下标[8M,24M)、[24M,end)，超出本快照训练所取的前缀；不按难度或主题预分组。到尽头显式停止，不把循环回放当成新信息。
3. 同一身体自听自己发出的命令，并接收语言。一次窗口为“待输入末字节＋自身命令＋511外界字节”的512个预测转移。自身命令不进入外部CE；其自听仍可改变快表和GDN。文本最后一个字节成为下一窗待输入，跨窗历史不重置。
4. 用本窗口外界语言NLL同时更新预测及选择：
   `loss = L_external + stopgrad(L_external - baseline) * log π(action)`。
   baseline是采样之前已有的历史NLL EMA，系数0.95，初始化0；它仅减估计方差，不是生存账户。读取table内容由实际字节递推，未向未选路写入或预看。

| 已有Lean | 前提→实际实现→边界 |
|---|---|
| `ActiveInference.action_condition_required` | 两路后续语言可不同，模型自听动作字节，能区分动作条件。接口允许区分，不等于已学会准确世界模型。 |
| `ClosedLoopCredit.objective_deriv_advantage` | 条件于当前冻结的历史状态，环境给定动作后的转移与当前参数无关；直接CE梯度与采样score梯度同时保留。数值测试比较有限动作全枚举导数。 |
| `ClosedLoopCredit.scalar_baseline_zero` | baseline采样前固定，不能拿动作发生后才观察的、依动作而变的量冒充无偏基线。 |
| `LanguageLifeKernel.delayed_action_credit_requires_state_separation` | 本次动作保留到相应回应结算，自听进入同一递推；不恢复此前所有行动的梯度。 |
| `ActiveInference.active_closure` | 本轮未证明被动供给有界、有效摄入无界或持续可存活，不能据接口接通宣布该联合结论已经实现。 |

## 明确的目标边界

当前优化的是条件下一段语言预测损失，**不是**终身学习收益或生存概率。选择更容易的语料也可降低自身流NLL，所以必须同时报告独立文本表现、选择频率、逐路暴露/损失以及恢复后的学习。不能用选择后的流NLL直接比较成语言能力升级。这个桥验证即时行动—语言后果；多拍延迟、沉默和自发生态位不是本轮已覆盖的世界条件。

梯度只跨固定512事件，跨窗GDN状态和内容保留、计算图截断；没有声称长历史写入信用解决。政策采样先运行一次只读单步前向，完整窗口再重算同一前缀并核对概率，保证没有看到未来目标才选择动作。

## 预注册运行与成本

- 单seed11，coupled与randomized各5000更新，每窗511外界字节＋1自身字节；从同一完整off快照开始。总外界预算各2,555,000字节。
- coupled执行实际输出；randomized使用独立均匀动作选外界源，身体仍自听自己原命令。两组使用相同求导、状态和更新频率。这是切断动作与外界源连接的干预，不是保证各源暴露量相同的消融；必须报告各路频率，不能把分布差异隐去。
- 每500更新：固定独立validation前32768字节的既有sidecar协议（克隆表、冷启动侧评状态、冻结神经权重、先评分再同化）；训练个体不中断历史、不回灌validation。该验证集此前使用过，是开发集而非全新测试集。
- 首先32更新/组作GPU/连续性工程校准，不对主动性或架构能力下结论。正式5000更新也只报告预算内证据，无收敛证据则不宣称收敛。
- 两个CUDA Graph分别处理单步决策与固定窗反向，使用原Triton递推；快表仍在CPU。额外每步仅2类采样与固定窗信用。语料使用只读mmap，状态只保留2个游标；日志是外部实验记录，不读回为脑内记忆。
- 存档包含神经状态、全部表、优化器、随机数、两个源游标、末字节、baseline和预算。固定保存last.pt，原快照不动；存档失败保留旧原子快照。
- 停止条件：预算结束、语料耗尽、数值非有限、采样/重算概率不一致或配置/数据哈希不符。独立NLL下降不是提前停机/挑优的条件。

### 同暴露的直接学习对照（运行前登记）

为区分上述两项，新增且只新增一个诊断：从同一off快照开始，逐条重放主动组5000次实际动作、外部回应和自身命令，仅去掉策略梯度，保留原语言CE、表递推、优化器及验证协议。每一段回应哈希必须匹配，终点快表全部数组、世界游标与末字节必须完全相同。该外部强制重放不称为自主个体；它不估计另一策略的反事实分布，只比较同一经历上两种更新。输入日志流式读取，不把整段历史载入身体。

若重放组与主动组相当或更好，不能把当前正收益说成策略梯度改善语言学习；应转向选择形成的经历本身。若主动组更好，则只支持本轨迹上的联合策略更新收益，仍不是终身最优或全局主动生存证明。预算仍为单seed、5000更新；代码`replay_language_action.py`，输出`replay_no_policy/`，不改变已执行的行动身体或两组原始结果。

**保留已验证的同体行动接口，不把当前“最小化下一段NLL”的策略更新晋级为有益学习机制。**它能形成闭环，但持续读到容易文本不等于增加可用信息或维护未来能力。下一项工作应核对已有未来语言收益合同，把实际经历是否改善后续同体能力与动作信用连接；不继续调锁存、策略倍率或新增行动头。`GenerationGDNLife.Process.externallyUseful`是带重复目标、读出漂移等前提的特定充分证书，不能直接声称当前多层GDN已满足它；应复用其未来用途原则并明确当前实例的测量和适用条件。尚未证明自发生态位、长期生存或跨窗原始写入信用。
