## 要补的实际缺口

V2 的 Nf/T 是选择与支持的信号池。T4e 中，E6 的正标签仍直接增加 g，
没有对应的材料扣款；T 也不是结构本身的质量。调高 T_star 可以检验支持
信号的作用，却不能替代结构合成的收支。这次引入独立的抽象合成材料 B，
不把神经营养信号分子当成突触的全部物质。

每个突触后局部供体有一份 B，结构成本为 c g：

    dB = 外界有限供给 − 清除 − 实付维持 − c·正向合成 + r·c·拆解
    d(cg) = c·正向合成 − c·拆解

累计账本逐个供体满足：

    B + cΣg + 清除 + 实付维持 + 不可回收材料 = 初始材料 + 累计输入

0≤r≤1。维持欠款单独记录，不用负余额掩盖，也不擅自加入一条新的细胞死亡规则。
新结构只能用实际存在的材料；同一供体的同时请求按需求份额分享。
E5 的标签决定请求，E9 的信号决定支持和更替；两者没有被材料账替代。
有限槽位的正负转换用冻结速率的解析更新，避免 Euler 越界再裁剪。
旧模式默认不变，新模式显式启用。

## 运行前预言与出口

1. 随机数值转化、断供、回收、维持与清除的逐供体账本误差≤1e-10；
   余额非负。失败则修实现，不做活体解释。
2. 固定局部合成请求的解析收支检查：一个供体、一个结构槽，
   供给 Q、维持 μg、更替 λg、回收比例 r；请求足够大且不触及槽位上限时，
   稳态 g≈Q/[μ+c(1−r)λ]。
   本实现先维持、再解析拆解、再合成，离散固定点应为
   Q·dt/[μ·dt+c(1−r)(1−exp(−λdt))]，相对误差≤1%。
   减半供给的稳态比值应在0.49–0.51；停止供给后结构下降，恢复后回到原平台。
   dt减半应更接近连续极限。此项只是解析方程的数值验算，不是相关性学习试验。
3. 用已锁定的真实 V3d 64维强度规则，取固定种子4096个真实相连类型对，
   接到V2介质，核对有限材料支付、钙/标签池演化、完整存档与恢复。
   接口预检更正：类型暂作节点时，同类型对会变成自环，不能代表真实的同类型多细胞；
   首次运行在这一检查处退出，故抽样前明确排除同类型对，再做真实接口运行。
   这里沿用已相连的类型对，发生概率显式为1，类型暂作接口节点；
   **不声称其拓扑是独立生成的细胞级大脑**。
   身份类型与几何由原数据提供，电导换算和生理常数尚未校准。
4. 真实接口连续运行1000ms，500ms处存档并分叉，后半段输入由各自已恢复的
   RNG生成；全部动态数组、标签、材料账和随机数状态须逐位相同。
   守恒误差≤1e-10；不以是否放电或低NLL判健康。
