# 3D 介质重启方案：可兴奋组织介质（可学习的大脑）

日期：2026-10-10。状态：**设计说明，未实现**。3D 介质重启时按本文执行。
背景与教训见 [MEDIUM_ARCHIVE_20261010.md](MEDIUM_ARCHIVE_20261010.md)。

## 1. 原则

- 目标是**可学习的大脑**：空间分化出功能分区，有轴突式的快速通路，结构在信息冲刷下持续可塑。不是把信号从写口搬到读口的混响器。
- **整个模型只有两种东西**：
  - **快：信息**。可兴奋组织里的电活动（膜电位、脉冲、电导）。
  - **慢：物质**。组织在哪里、是什么性质、彼此怎样接触。学习就是物质的变化。
- **神经元被连续介质化**：不追踪一个个神经元，神经元的性质成为每个格点上的物理参数。先例有神经场理论（Wilson–Cowan、Amari）、电缆方程 / Hodgkin–Huxley、心脏电生理的三维组织模型（疤痕组织不导电）。
- **果蝇大脑是这个搜索空间中的一个点**，可以作为出生时的初始条件；学习在它之上变形、连接、修剪。

## 2. 表示

格点 R³（周期或有界均可），每个格点 C 个通道。每个通道是一个**相**，可以对应一个神经元或一类细胞。

| 量 | 每格点 × 每通道 | 快 / 慢 | 含义 |
|---|---|---|---|
| 物质密度 ρ_c ∈ [0, 1] | 是 | 慢 | 通道 c 的组织是否经过这里；Σ_c ρ_c ≤ 1，余下为空腔 |
| 膜电位 v、电导 g_E / g_I | 是 | 快 | 与果蝇线相同的 COBA 物理 |
| 适应变量 b（ALIF） | 是 | 快 | 参数：时间常数 τ_a、强度 β（慢，可学） |
| STP 资源 x、利用率 u | 是 | 快 | 参数：U₀、τ_fac、τ_rec（慢，可学） |
| 阈值、膜时间常数等生理参数 | 是 | 慢 | 细胞类型；空间上可以不同，形成功能分区 |
| 局部耦合矩阵 W(x)，C×C | 每格点 | 慢 | 突触：a → b 在两者接触的格点上；源通道的符号遵守 Dale 定律（兴奋或抑制） |

空腔（所有 ρ_c = 0）里没有这些参数，不承载、不传递信息，只是结构的一部分。

## 3. 动力学（快）

1. **沿自身组织的传导（电缆耦合）**：通道 c 在相邻格点 i、j 之间的耦合 ∝ √(ρ_c,i · ρ_c,j)。通道只在自己的物质里传导，不同神经元即使穿过同一格点也不串线；空腔天然不传导。
2. **可兴奋动力学**：局部的阈值、电导、ALIF 与 STP 方程（直接复用果蝇线已验证的 COBA/ALIF/STP 内核）。脉冲靠局部再生传播、不衰减；不应期使脉冲单向离开源头。
3. **突触**：在格点 x 上，通道 a 的发放经 W_ab(x)·ρ_a·ρ_b 驱动通道 b 的电导。延迟由路径长度和传导速度自然产生，对应果蝇的分层延迟。
4. **能量有界**：由反转电位与不应期保证。不另设与空间无关的“浴”。
5. **内在时间**：沿用果蝇线的自适应准入（到达下限 + 沉降判据 + 上限）。

## 4. 接口（身体，固定）

- **写入**：只进入感觉面上的组织，采用果蝇式的拓扑投射 + 门控 + 缓慢适应；**不在外部预测 token**。
- **读出**：只读运动面组织的活动，经线性读出和线性解码器输出；**没有读出 MLP、没有时间读出、没有任何外部记忆**。
- 感觉面与运动面在空间上分离（身体轴），写口和读口必须落在组织里。

## 5. 学习（慢）

- **生理参数与 W**：替代梯度 BPTT（复用果蝇学习器）。窗口长度按已有记录确定，不要随手截断。
- **物质 ρ_c**：守恒的梯度流（Cahn–Hilliard / Wasserstein 型），由 CE 梯度驱动，每个通道的物质总量守恒，只能搬动。
  不加界面能，除非有明确的理由；交界的宽度先由格点分辨率决定。交界有宽度，所以两个神经元靠近时的“接触”从一开始就有非零梯度，拓扑变化是连续可微的。
- **出生**：把果蝇的解剖结构和连接组映射成 ρ_c、W 与生理场。可以逐神经元映射（受 C 与 R 的限制），也可以按细胞类型或区域粗粒化成 C 个通道。之后由学习变形。

## 6. 验收（按顺序，前一关不过不做下一关）

1. **数值**：守恒与有界；脉冲传导（速度随 ρ 变化、单向、穿不过空腔）；果蝇映射后的出生个体在相同输入下复现果蝇储备池的行为。
2. **介质自己会学**：接口冻结（写入与读出不学），只有介质与线性解码器可学，在真实文本上明显胜过储备池对照（介质也冻结）。
3. **大脑功能**（由介质学到，接口冻结）：状态保持超过膜时间常数（吸引子记忆）、对输入积分、增益控制，以及不同区域承担不同功能（区域消融的因果差异）。
4. **结构学习有用**：物质变化带来的改进经得起回滚测试；接触的形成与修剪有因果效应。
5. **因果消融**：传导、突触、抑制、ALIF、STP、记忆（状态重置）逐项关闭的 ΔNLL。

送达量、到达时间、通道形状只是前提条件，**不是成功标准**。

## 7. 不做的事

- 不叠加机制：每加一项都要在第 2、3 关的标准下证明有用。
- 第 1、2 关通过之前，不建大型基础设施（结构后验、CUDA 图捕获、健康账本等）。
- 不让接口替介质计算或记忆。

## 8. 待定问题

1. 分辨率与显存（4 GB）：R、C 与每 token 拍数的取舍；稀疏或分块执行的可能性。
2. 通道与果蝇神经元数量的映射（约 14 万个神经元）：逐神经元还是按细胞类型粗粒化。
3. 物质梯度在没有信息流经的地方为零：果蝇初始结构能绕开多少。
4. 每一拍的计算量，以及 BPTT 窗口长度与显存的关系。
