# 同一局部交换核怎样产生结构维护与重组

2026-10-22，在有限交换核17项数值检查与真实图接口完成后、以下结构扩展实施前登记。沿Claude E6有限槽位与E9有限支持，不增加目标梯度、行为阈值或一个“活动＋标签”的任意混合系数。

## 由两种占据推广到三种占据

每个候选接触处有K个有限位置：未安装位置U、已有但未结合的位置S、已结合的位置C，U+S+C=K。已安装结构量n=S+C，故C≤n≤K。前轮固定结合容量现在由n给出；原有F/C/H及P/D交换不变。另有局部结构底物B。

新增唯一结构事件：

    B_i + U_e + P_i ⇌ S_e + D_i，i=post(e)

与已有结合事件F+S⇌C合在一起后，在这个最小转化图中，结合态须先回到S才能拆除。适用前提是直接拆除结合态的复合通道在所选时标可忽略；这是需要校准的势垒／转化图假设，不由守恒唯一强制。结构保护由该允许转化图与占据关系产生，不另写λ(T)保护函数。C可以解离、运输回S，结构仍能更替。

扩展的自由能为前轮G加上

    Σ_i φ(B_i) + Σ_e [n_e log n_e + U_e log U_e − K_e log K_e]
                  + εn Σ_e n_e

与原C/S混合项相加，恰好成为U/S/C三态占据熵。不是为得到目标形态手填吸引力。εn是单位安装结构的声明能量，尚未校准。

    a+ = k_n B_i U_e P_i
    a− = k_n exp(εn−εP) S_e D_i

其正反比满足同一自由能差。B_i+Σ_post=i n_e、P_i+D_i分别守恒，F/C/H支持组成独立守恒。增长和拆解的方向取决于驱动状态、空位、结构状态与底物，速率系数是共同势垒参数；不是把外部NLL的梯度当作生长命令。

## 非负有限步

本步结构净形成X_i给出B1=B0−X、P1=P0−X、D1=D0+X。固定C时

    n1_e(X)=[n0_e+h a_i K_e+h b_i C_e]/[1+h(a_i+b_i)]
    a_i=k_n B1_i P1_i，b_i=k_n exp(εn−εP)D1_i
    X_i−Σ_post=i[n1_e(X_i)−n0_e]=0

n1随X单调不增，故根唯一。可行区间为

    max(−D0_i,−Σ_post=i(n0_e−C_e)) ≤ X_i
        ≤ min(B0_i,P0_i,Σ_post=i(K_e−n0_e))

与前轮三组交换做一阶分裂，保留所有真实状态。无新增全局求导或历史图。

## 验收与真实图接口

先核对：新增事件的正反亲和；三种组成守恒；G不增加；全占据时没有空结构可拆；解离后可恢复拆解；零底物／零可用驱动态限制增长；可行区间、边序与完整恢复；对独立连续时间方程的时间收敛。

真实图接口仍用相同192细胞545边及Nf/T库存，取n初值1、K=2、B=.5／节点、P=D=.5／节点，保持原F/C/H初态和前轮所有能量／速率；新增k_n=.001、εn=2。所有值是本构参考单位，未从原电导g校准；n不能冒称原脑已学连接。

固定200ms、h=1ms，20ms采样，完整存档后再实际续接20步。新结构量必须由实际净转化与底物／驱动态余额核对，不指定增长或缩小方向、不追加暴露或调参。无外源供能、无脑活动输入，不声称持续开放学习已完成。
