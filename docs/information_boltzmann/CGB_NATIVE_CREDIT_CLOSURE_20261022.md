# 原生资格、资源带宽与持久可塑性的同过程检查

本轮方案先于副本推进保存。延续Claude E2/E3/E5/E6/E9、当前有限转化与局部自由能；不加奖励、评分回传、资格迹保持奖励或人为疲劳变量。主个体保持原档，所有条件干预是显式诊断控制，不宣称其控制器是生命体的一部分。

## 1. 功能和物理状态分开记录

当前r是局部活动写入配置，同时改变导通、结合自由能和活动通道速率。它不是已验证的纯资格迹，也不等于长期突触记忆。实际安装载体、拓扑/强度、支持占据、活动配置分别观察；r清除后的组织和响应仍可不同。生物记忆不要求同一批材料永远存活，原载体ID与同位置重建分开。

现有候选路径是：活动写入r；下游支持经C_(j,k)+P_j→H_j+D_j、H_j→F_j返回；此前r_(i,j)改变F_j结合的速率；C占据使原桥不能直接拆卸。既有原语已接通这一条件路径，尚未证明返回支持携带预测贡献，也未证明完整时间信用。

## 2. 有限带宽直接由原计量产生

对每个节点，活动/写入使用P_i，装配使用P_j；反向活动/写入/运输/装配及正向conversion可能恢复P。具体净方向由状态决定，不能将conversion预先叫作恢复器。

    P_i(t)=P_i(0)+R_i(0,t)-U_i(0,t)
    U_i(0,t) <= P_i(0)+R_i(0,t)

U、R累计实际事件的P负/正变化。P=0时相应正向事件不准入，满r时write+也不准入；输入仍持续。给定P>1、D及其余状态，消耗一次P→D后，下一次同类事件的组成代价增加：

    log[(D+2)/(D+1)] + log[P/(P-1)] > 0。

该式与现有local_learning.depletion_shift一致，不意味着全核已具有生物不应期。还要分别记录电荷反馈、实际恢复、槽位占用和事件等待，不把慢装配自动等同于快响应堵塞。

## 3. 标记与后果的交叉作用

对未占C的原桥，现有binding+实际率：

    lambda(r,F)=alpha_binding * F/[F+exp(epsilon_C-chi*r)]，F=0时为0。

这是原event_delta中组成熵和相互作用能的展开。后果的物理候选是实际下游支持返回，不是外加奖励；r对捕获的影响须以有/无支持返回的交叉差检验。高F饱和时交叉差不保证为正，不能按活跃度自动发信用。

## 4. 本次有界条件审计

读取24448ms的完整reference档，事先只依可准入的事件选择首条i→j→k链。必要的共同准备仅执行原允许的conversion/thermal事件，逐笔计热/电荷；活动标记组用write+，对照用active+，使两支P/D和电荷相同、r不同。不直接清零数组。

四个条件：有/无标记 × 执行/不执行j→k的transport+及j的release+。返回组严格使用下游原C，不凭空注入F。等待0/16/64参考ms后才尝试这两步，等待期间完整原生场/活动/材料/几何继续运行。链已消失或事件不再可准入，则保留失败记录，不搜索替代链或只留成功者。

每个条件在8组匹配未来RNG下沿同一真实OWT片段演化。延迟段与后续32ms都按4ms/字节、2ms子步；输入不停止，延迟组不虚构经历。仅研究副本使用既定未来随机种子；主档RNG不变。保存全部组、实际源/时间/热/事件以及目标原载体ID。

同时测：支持返回前后实际捕获率及交叉差、自然捕获/解绑、资源使用/恢复、r状态、原载体留存与重建。在后续末态副本用原thermal−清除当前活动配置，显式记热，再读取无活动配置的导通、C占据和实际拆卸风险。这是条件消除短时作用的观察，不能伪称自然遗忘、长期记忆成功或语义信用。
