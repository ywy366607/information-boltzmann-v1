## 含义保持与接口迁移

净增长版与周转版各有五项原公式检查：alive、存活量、持续存在、中断耐受、自我维持，共十项。另核验退役静态观察器与统一时变观察器对所有核、标记、初态和有限时域取值相同。十一项Lean检查全部通过。

删除的局部包装有明确替代：

- 两个版本的 `alive_bounds` 改用 `Viability.alive_bounds`。
- `ExchangeBook.code_roundtrip` / `same_code_same_book` 改用 `Encodable.encodek` / `encode_injective`；完整编码预算条件保留。
- 静态 `lift/recovery` 及其辅助证书由 `firstHit` 和 `state_mark_firstHit` 取代。
- `event_state_mark_matches_operational` 的输入表达式改用统一观察器，保持原净增长恢复量的对应结论。

原23个生产模块仍全部纳入构建及审计；没有通过少导入模块、删除反例或合并定理标题来降低计数。六条公理、规则预算、世界时钟、正常/剪断过程及全部周转控制继续核验。完整生命和认知见证仍沿原研究目标建立。
