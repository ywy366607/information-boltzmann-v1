# 同一物理生成元的对称执行：实施前记录

696c15b之后的曝光诊断已确认：源有信息、冻结身体的传递弱。连续时间小规模OU参考进一步发现，现有“源→端口→桥”单向顺序给感觉增益带来一阶积分偏差。实际中点一例，同T4ms/K2时，增益相对误差0.02677；按同一生成元作首尾对称半步组合的解析值为0.000891。这是本次执行方案的提出依据，不冒充盲验证，也不以NLL挑方案。

## 由生成元而非生物机制出发

现有源／端口／桥各自OU算子已包含同一kBT的精确条件涨落。连续场生成元是这些算子的和。原组合`exp(dt L_m)...exp(dt L_1)`的首阶误差含非交换子的dt²项；首尾对称的半步组合使该项抵消，成为条件快场的二阶分裂。每个局部算子仍使用原电容、电导、源电压与同温噪声，不增加物料、驱动或新的反应。

本次把该组合接成可归档的执行选择`symmetric_ou`，不改旧档默认`sequential_ou`。序列为源半步→端口正序半步→桥正序半步→桥逆序半步→端口逆序半步→源半步，全球物理时间仅推进dt。每条通路总经历dt，不能把通路数或半步数乘入外界时钟；每次源/交换的热功都按实际跳变记账。工作区O(N+E)，无历史图、全局Jacobian或生产稠密矩阵；解析小参考仅为仪器。

新组合会消耗不同的噪声序列，因此其随机轨迹与旧组合不同。仅在研究副本上从同一完整状态切换，不覆盖原个体。移动材料新档schema3／身份材料schema2显式标记，旧档仍按旧组合复现；旧版本不得把新档当旧模式继续。完整恢复必须保存选择及三RNG。

## 实际检查

1. 实际局部求解器的均值、每个独立噪声基与解析组合协方差一致，全部子过程热功账闭合；
2. 同T4ms、K=2/4/8/16与连续时间小参考比较，明确快场误差与整个慢快耦合的误差不同，不宣称全系统二阶；
3. 从真实中点保留全部材料/身份/世界/随机状态，在研究支上运行原接下来128个真实OWT字节，两种组合都报原始更新前NLL、反应和实际时间；不用短预算胜负判断学习能力；
4. 新支中点及末态完整存档，新支恢复后完整未来64字节的所有预测、物理数组、账本及三RNG逐位一致；原母本与旧实验不改。无旧新生儿训练。

本次修正的是第一性物理方程的执行忠实度，不把它当作新的预测机制。身体接触的有限阻抗、预测反向相互作用、时序/延迟信用和空间自我生产仍按主线继续。
