# 有限功源驱动的定向传输与外部端口

2026-10-22，基线`eb720ed`，标签`cgb-before-driven-ports-20261022`。沿E1的有源驱动力、有限池和前轮同一自由能推进；本轮是材料／端口接口验收，不是完整语言主体的出生或训练。

## 由同一收支产生的事件

上一轮的互易电阻只能被动均衡电势。定向输运若要逆电势进行，必须由已有功源支付。选取一个由结构身份定向的局部换能单元，事件为

    P_pre -> D_pre，同时q_pre减少zx，q_post增加zx。

正方向取x>0，反方向x<0。z是每次事件转移的荷量，沿用前轮定义。事件的组合自由能导数为

    dG/dx = -eP + ln(D_pre/P_pre) + z(V_post-V_pre)。

因此正反比必为exp[A]，其中A=eP+ln(P_pre/D_pre)+z(V_pre-V_post)。沿用有限尝试频率两态材料：

    j+ = k n P_pre sigmoid(eP+z(V_pre-V_post))
    j- = k n D_pre sigmoid(-eP-z(V_pre-V_post))。

每个已装并联单元贡献相同尝试率，故乘n。定向来自固定的元件极性，P/D来自已有有限功源；当储能不足而场反向足够强时允许逆行并再充能。不是硬剪掉负向流，也没有以活动或奖励制造能量。详细平衡只约束比值；这些速率及极性属于明确材料本构，尚未生理校准。单隔室自边无两个不同电端，不启用本传输通道。

共享一个节点的边竞争同一P/D与荷量。用端点不相交的匹配分组，每组内并行解可行区间[-D_pre,P_pre]的唯一隐式事件量；组间一阶分裂。中点电势精确计入电场储能，末态混合势保证不可逆损失非负。分组是数值执行顺序，不是新的物理模块；减半步长及独立ODE检查其误差。

## 世界端口也保留状态和反作用

外部端口为有限电容Q_a/C_a，经有限电导K_a接到脑节点p(a)。端口交换的电荷在两端相反，热由总储能下降计；Q_a是世界／身体边界的状态，下一次交换会受其过去被大脑改变后的电势影响。关闭外部源后端口并不重置。

真实文本只通过固定UTF-8字节换能给出源电势，不直接加到状态或发放驱动态。源经过已声明有限电导接到外部电容；定电势源一步做功为V_src·ΔQ，电容自能变化之外的部分记为热。源可以供功或回收功，不能把语言信息本身等同于热力学能量。字节电势幅度、端口容量与速率是参考硬件参数，未来需校准。

该端口交付有限状态、有限速率和能量反作用；它尚未把运动输出转成词语、声道动作或妈妈回应。因此不把电气边界反馈说成已经完成语言世界操作闭合。下一层可用同样的端口关系连接已有身体／世界实现。

## 预注册验收

1. 正反比与独立自由能有限差分一致；可在有限P支付下逆电势传输，反向场能重新形成P。无P/D总量时不得产生有源通量。
2. 有限池、支持、材料、脑及外部电荷、总功热账和不可逆损失通过；零源时组合G不增。端口对脑和外部状态都有反作用。
3. 独立单事件连续ODE、步长减半、边顺序细化和完整状态恢复通过；旧三种存档仍能读。
4. 在已有192/545图上，用真实书架文本的相同字节、相同输入时钟，对照有源传输开启／断开；另核对相同后半段真实输入下外部端口的连续状态与重置控制。控制只用于诊断副本，不重置正式个体。
5. 记录作用是否到达、结构是否响应、源功与材料支出、资源和实际时间。这里不验收语言能力、选择性学习或自我，不把端口通路验证当作能力训练。
6. 完成本轮有界实现后保存日志、源码／结果和Git回退点，验证增量备份与完整子核存档，再按用户明确要求关机；不恢复暂停的主个体，不留下实验进程。
