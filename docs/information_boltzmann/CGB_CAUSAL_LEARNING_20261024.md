# 从固定控制到有限因果学习：记忆、付费与安全准入

上一轮证明了具体控制规则可以自维持。这一轮建立一个由实际行动后果改写内部候选模型、再据此选择动作的有限学习器，并给出与生存和能量过程连接时必须满足的准入条件。成果位于**交互机制层**；完整物理介质中的学习维持见证是下一项证明任务。

## 1. 为什么不能直接采用“失败后纠正”

现有维持世界中，动作失配可以进入不可逆匮乏，随后耗尽唯一储备。保留该吸收规则时，增加记忆或只增加电池，都不能让已经丢失的资源重新可达。学习需要可区分的真实反馈、足以经历反馈的资源余量，以及仍可由行动维持或恢复资源可达性的世界路径。

因此本轮把候选记忆、因果顺序、改写代价与安全动作分别核验，避免把旧固定控制的生存证明直接冠到新学习器上。

## 2. 一个实际有内部状态的学习器

`CausalLearning.Memory` 存储有限候选集 V 和有限改写储备 R。H 是完整候选模型家族；每个模型声明：在边界情境 c 下执行动作 a，哪些后果 o 仍然可能。控制器读取自己的候选记忆与边界情境，先产生动作；世界实际转移并返回后果，随后才能筛选模型。

```text
筛选后的候选 = {h ∈ V | h 仍允许实际后果 o}
若筛选改变了候选、且 R>0：保存新候选，R←R−1
否则：保持原候选与改写储备
```

真实模型的身份只出现在正确性定理的环境前提中，不进入控制器函数。`certifiedOr` 提供一个具体控制器：枚举由所有剩余候选共同认证的动作，按给定的有限动作顺序选取。模型变化因而可以实际改变动作。

空候选集不认证任何动作；没有已认证动作时，返回显式的未认证备用动作，该分支需要自己的物理应急政策。这里没有把“空模型集合”当成万能预测器，也没有把零风险安全探索的存在写进一般公理。

候选集不是附在观察者历史旁的免费记忆。已证：

```text
|Memory| = 2^|H| × (B+1)
```

其中 B 是初始改写储备的上限。完整候选掩码具有 |H| 比特的表示容量，储备也有自己的状态。这不是任意学习器的记忆下界；支持表、动作选择程序及全部内部状态仍须进入完整规则书，当前没有声称通过 1% 编码预算。

## 3. 三组已证明结果

| 核心结果 | 精确范围 |
|---|---|
| 因果学习与模型保真 | 只按实际反馈排除候选；付费后可排除与反馈矛盾的模型。如果真实环境始终由家族中的某个候选允许，该候选在所有正概率到达的时刻都不会丢失。共享预测的反馈不产生有效改写。 |
| 有限记忆与改写预算 | 每次有效改写严格减少候选并支付一个所声明的储备单位。任意有限路径的剩余储备加累计支付等于初始储备；候选卡数也有相应下降界。实际分布下的平均预算对所有有限前缀成立。 |
| 控制安全的准入与障碍 | 若所有剩余候选允许的后果都满足给定安全条件，且真实候选仍在集合中，实际后果也满足该条件。如果每个动作都被某个剩余候选指出一种不安全的可能后果，就不存在这种稳健认证下的安全动作。 |

`physical_marginal` 还证明：无论改写储备多少，忘记新增记忆后，一步物理动作/后果律仍严格等于实际选择动作下的世界核。储备耗尽只冻结改写，世界时钟、后果与输入继续推进；没有通过暂停世界来延长学习窗口。

这些是带明确前提的合同。环境属于候选家族是保真前提；安全后果条件是充分控制条件，不能替代原来的 `Exchange` 恢复和存活评分，也不能据此宣称所有世界都允许安全探索。

## 4. 改写付费怎样接回物理能量

`writeAccount` 的储能是内部有限储备 R，热端口是负的实际支付量，不用收支残差补账。`paid_mean_budget` 在同一个学习过程的实际分布下证明：

```text
平均剩余改写储备(n) + 累计平均改写支付(n) = 初始改写储备。
```

一个单位是本接口声明的支付刻度，不是普适的微观写入能耗。感知、模型比较、行动、存储维持及实际热浴成本需要载体能量账户给出。

`totalAccount` 因而要求先为**动作已经由学习器决定的新闭环**提供有效物理账户。该账户可以包含候选寄存器随内容变化的储能，但必须排除单独的改写储备，再组合两者。物理端口与系统边界仍须独立核验。旧固定动作过程的账户不能自动充当这个前提，内部处理时间也不能作为免费额外世界步插入。

## 5. 复查与当前边界

全库证明信任审计核验新模块、旧签名兼容性与源码哈希。独立的 `reviews/causal_learning_20261024.lean` 用有限真值表检查：同一控制器对不同反馈形成不同候选与动作；无信息反馈不收费；无储备时不能免费改写但世界仍产生后果；家族外反馈可使候选为空，空集不认证任何动作。这是接口及推导检查，没有训练、能力曲线或模型优劣结论。

证书见 `results/published/cgb_causal_learning_20261024.json`。旧自维持模型、物料来源和能量证明保持原范围；生命定义原文保留。

本筛选器学习的是后果的**支持/可达性**。若各模型都允许相同后果、仅发生概率不同，支持筛选就没有区分证据；下一步需要有预算的统计证据积累。更紧迫的物理任务是找到安全且有区分力的实际边界经验，将候选记忆与更新通道实现为符合六条公理的介质，再沿连续过程证明已有的生存目标。自举目的、完整 L1–L6 与真实数据上的学习能力仍按各自证据验收。
