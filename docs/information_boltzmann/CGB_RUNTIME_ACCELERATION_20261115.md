原生构造现已接回相同批量因果重放。保留1e-3一致性检查，遇到离散检索的舍入分歧仍逐字回退；没有放宽误差门或更换学习目标。新身体出生及完整恢复都检查该设置。

同时修正分类信用的执行：是否开口的导数只依赖开口前边界；候选话语已有独立完整score梯度。原实现先对实际整句建立反向图，随后覆盖边界特征，只把整句logp作为脱离梯度的审核数据。现在保留相同边界导数和审核；生成话语的审核在no_grad下执行，重说时该分类项没有字节审核，省掉未使用的整句前向。所有提议的梯度仍在原路径逐一累加。

## 其余共同执行优化

1. **草稿作用域的固定投影。** 每个`ScopedDecisionGraph.start`用当前编码器重算经历库条件键、动作值、长后果值及8条工作事实的绑定，固定地址缓冲供CUDA图读取。逐字查询、top-k、偏好、有效掩码、空槽、内容门、S/P/M仍实时计算。每个新草稿刷新，不跨参数或事实更新复用旧投影。
2. **一字节共演化融合。** `coev_decode_fused.py`将原`PastPresentField.exchange`的归一化、共享语言投影、私有FFN、空槽softmax、内容门、时间更新和读出融合为一个FP32 Triton内核。仅CUDA单字节无梯度解码使用；普通因果chunk及全部学习导数沿用原路径。真实256/32维、32/8维、有效掩码和禁用干预与原方程核对通过。
3. **解码删除丢弃统计。** CUDA图调用方不消费逐层诊断，专用路径省掉32层范数/均值等归约；训练和观察仍保持诊断。捕获后不再逐字更改32层Python属性。
4. **机制证据成批求值。** 保持事实顺序、类型和作用域；条件、动作及原始后果批量编码，真实/想象后果仍分别处理。共享特征和神经先验成批执行。CPU/CUDA双精度前向及所有相关参数导数与逐条原式比较通过。
5. **关系分裂成批求解。** 所有合法条件边界一次批量NIG求解，替代每个切点两次独立求解和主机同步。子集零行补齐，新增ridge特征值在logdet中扣除，alpha/似然用实际样本数；保留复杂度惩罚、首次最大边界及证据范围。
6. **SSD事实打包上传。** 同一不可变经历的条件、动作、妈妈后果和后续结果一次传到GPU，再按原字段视图使用，避免每字段各做CUDA同步；没有增设长期事实缓存。
