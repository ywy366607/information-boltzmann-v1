# 从已有局部学习到同一材料生成元

2026-10-22。目的不是把Claude的V2改写成几个生物名词，而是说明有限池、活动痕迹、捕获、逆向支持与新空间通路的共同物理对象；哪些量真正继承，哪些只是有效极限，哪些尚未得到功能证据。

## 同一个状态和同一条账

当前物理状态由材料域的坐标、荷量q、容量、有限B/F/H/P/D、身份，以及实际付费桥的r/C占据组成。新增域不是空软件槽，桥不是候选连接的一个浮点分数。每次变化均由允许计量ν及联合G(x)决定，原局部详细平衡给出正反偏置，有限尝试率给出速度。

对任意已声明可观测量f，跳变部分有精确关系：

    L_R f(x) = Σ_e k_e(x)[f(x+ν_e) − f(x)]
    d E[f]/dt = E[L f]

L还包含同温电场与空间运动；实际求解按已记录的整核分裂推进。这个生成元把局部学习与生长统一起来，不需要另造“结构梯度”。

Claude原V2的连续带符号标签、局部供体、终扣支持、逆向H运输，以及V2f的B付款提供了功能划分和既有参考。当前有限配置核继承这些物理角色，**不是V2连续方程逐位等价的复刻**。旧标签/活动捕获结果仍按旧本构留存；当前热力学核有自己的原生更新。3,000类型的相遇后定向身份程序则直接复用原已拟合数组及来源。

## 痕迹与支持是原生状态转化

在固定存在的桥上，r∈{0,1}、C∈{0,1}；它们的实际漂移由原事件给出：

    L_R r = k_write+ − k_write− + k_thermal+ − k_thermal−
    L_R C = k_binding+ − k_binding− − k_transport+ + k_transport−

此处k已包含当前占据/有限资源的准入。不是把一个全局目标当成标签再乘回结构。

write+把一份P变D、移动已声明荷量并将r从0写为1；active+有相同q/P/D计量但不写r。对内部i→j，储能部分为：

    ΔU_write+ = ΔU_charge − E_P + ε_r − χ C

更明确地，P减少1的贡献是−E_P；电荷项由(q_i−z,q_j+z)的原电容能精确相减。有限池混合贡献log[(D_i+1)/P_i]进入ΔG。反向事件恢复相应物料，热按−ΔU结算。边界同样用世界电容/资源所有者的既有端点规则，不能将软件端口与材料资源位置混为一谈。

binding+将一个F_j变成桥上C，结合能ε_C−χr；其正反比在相邻配置上满足：

    k_binding+(x) / k_binding−(x+ν) = F_j exp(−ε_C+χr)

所以r通过实际共同储能改变支持结合/解绑；χ不是外部学得的“好词分数”。固定F、固定r的条件平衡占据由K/(1+K)给出，K=F exp(−ε_C+χr)。这是该简单有限占据假设下的结果，不把非平衡活体均值一律设成它。

许多同类微载体的平均可形成连续占据与漂移；相对其条件基态的偏移可以有正负。这说明连续标签/支持描述怎样可能作为有效层出现，**不证明原V2的具体钙/激酶时间常数或任意带符号规则已经由此导出**。保留这一差别，才不会用生物名称替代推导。

## 已有记忆怎样改变未来空间

r既改变实际G导通及其同温噪声，也改变原支持反应。transport+把C搬到上游H、同时P→D，release再将H变F。有限B/P/端与实际q一起进入同一域出生/回收比，详见[逐事件空间耦合](CGB_MEMORY_PHASE_COUPLING_20261022.md)。

支持不是无成本复制的标量。被绑定的F不再参加自由池分配；H和F互换虽未必改变瞬时域反应比，却改变下一次捕获和运输的可行性。新接合与新域继续使用这些原事件、原物料、原身份；移动使相遇改变，弹性与同温提议使位置转向，有限端与材料付款使接合可以分叉。没有指定“何时分叉”或“应转向哪边”的教师。

对一个历史载体，以不可复用身份η表示仍是该载体。R=ηr、T=ηC才能区分原载体的状态与同位置的新载体。装配的原准入要求r=C=0才拆解，因此支持和痕迹会影响寿命；桥拆解后的重新装配不继承原r/C。该限制来自所声明的载体状态空间，未证明它就是普适记忆维护定律。若需要支持寿命更长、更多状态或结构承担信息，须从缺失的物料/储能或有效关系继续推导。

## 用什么判断统一已经发挥作用

需要分四层证据：

1. 逐事件计量、联合ΔU/ΔG、局部正反率和完整恢复正确。
2. 当前自然状态中原事件实际运行，新材料也进入相同学习/捕获/运输/接合。
3. 同状态/实际时钟的匹配改变能交付到支持、通道和未来空间；原载体、状态转移和重建分别记录。
4. 在真实信息流里，所保留的结构实际改善之后的预测、行动与维持。

前两层已由连续24→28→43→46→49、实际事件和schema3完整续接交付。第3层以当前49域完整核做[痕迹—周转—回访检查](CGB_TRACE_FATE_PREREG_20261022.md)；第4层仍是实质问题。电势差首先是即时物理不平衡，不能未经推导就称它为未来预测误差；r非零、支持保护和结构增长也不能自动升级为预测贡献。原端口NLL仍据实保留，不能通过改仪器温度或给外部评分回传来美化。

上述四层共享同一生成元，观察器不把结论反馈成新的奖励。下一步应由实际残留能力与失败定位需要的自由度/交换关系，而不是按生物细胞清单逐个添加。
