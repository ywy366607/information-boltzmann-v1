# 同一生成元的数量—周转约束

本方案写于仅寿命物性反演之后、下述数量校准运行之前。固定物性预测几乎全占据；仅寿命反演趋向形成能高端，初步结果在高能量区极平坦，不能把边界点称真实物性或据此断言结构形成能无解。实际需要用不同观察约束同一物理参数。

延续完全相同的五态原反应图，不增加状态/能量项/通路。对给定S，除形成能外全部原物性固定；令原平稳安装概率p0，则改变形成能delta后的：

    odds(p_on) = odds(p0) exp(-delta)。

这是原状态自由能与详细平衡的直接结果：四种安装态一起增加delta，未安装态不变。

## 本轮具体操作

1. 用Control CG1/2全部实际计数，训练均值m=7.6。对整数K∈[训练最大15,128]，平稳独立位置的边际MLE为p=m/K。不把各帧当独立生物重复；这只是明确的边际复合拟合。
2. 依训练边际复合NLL选择K并保存完整剖面；不将寿命分数加进K选择。对每个S，由上式直接反演形成能。若超出原[-10,30]的有限能量范围，标不准入。
3. 固定这一形成能，以CG1/2新出现轨迹拟合唯一共同时钟c；使用原生原反率、实际拆卸首达、首次可见积分和右删失，不再自由调初始态。
4. 训练锁完成后计算CG3寿命与计数分数、出现通量、相关曲线。S=1/2/4/8/16全部报告，不按测试选择。此前看过CG3，探索性状态不变。
5. 训练均值被用于校准，因此不能再把拟合出的训练均值或边际方差当独立成功。未拟合的周转形状、留出锥均值/分布、出现率与时间相关才是附加约束。不同统计量来自相同轨迹，不将其分数相加为独立联合似然。

**预期判别。** 数量能确定有限自由能差、寿命能确定时钟，不意味着当前独立固定位置/平稳/桥到突起的映射就成立。如果寿命长尾仍比观测双尺度参照差、或时间相关/各锥数量不能同时解释，则记录这一条件闭合的缺口。下一步使用真实几何、共享资源和边界/初始资料约束，不凭单个拟合成功跨入第二阶段。物性拟合不写回现有物理个体。
