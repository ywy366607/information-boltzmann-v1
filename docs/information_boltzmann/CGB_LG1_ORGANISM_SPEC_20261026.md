# LG-1：第一个按生成链设计的个体（规格，2026-10-26，Claude）

依据：[生成链](CGB_GENERATION_LAYER1_20261025.md) G1–G8 与第二层 c 的线图结构。标注：**[强制]** 由已证定理或推导给出；**[选择]** 自由参数或设计选择，需单独论证或学习；**[待证]** 依赖尚未证明的命题。

## 1. 身体

- **[强制]** 接触结构是一个线图 L(G)：单元 = 连接（G 的边），团 = 隔室（G 的顶点）。依据 G8 与条件 (B)；"(B) ⟹ 线图"本身仍是 **[待证]**。
- **[强制]** P1b 要求接触结构齐性（顶点传递），所以 G 必须边传递。最小的选择是完全二部图 K_{m,n}：L(K_{m,n}) 是车图，顶点传递。
- **[选择]** 第一版：G = K_{m,256}，两层隔室，每对 (P_i, Q_b) 有一个连接单元。
  - 隐藏层 P_1..P_m：不带编号，**慢**，保留近期输入的痕迹；
  - 字节层 Q_b：256 个，**快**，受驱动。
  - **更正（同日）：**最初写的 K_{256,256} 让 P 也按字节编号，这是错的。电荷从 Q_b 出发，会沿全部连接按权重扩散到整个 P 层，并不会专门进入 P_b，所以 P 不能预设为"上一个字节"。
- **[选择]** 边界：后层 Q 是感受边界，到达的字节驱动对应隔室的储库；前层 P 是内部。参数 boundaryFraction 待定。
- **[强制]** 身份页：边界与内部单元的规则可以不同，但同一页内的规则必须相同（P2c）。

## 2. 单元状态与含量

单元 e = (P_b, Q_{b'})，状态 λ_e = (n_P, n_Q, w)：
- n_P、n_Q ∈ {0..Q_max}：两端的电荷数；
- w ∈ {0..W}：占用的槽位数，即可塑权重。
- **[强制]** 状态有限，并有含量代价（P1a）：content(λ) = n_P + n_Q + w，真空是唯一的零含量态。
- **[强制]** 隔室活动 N_c 定义为隔室内所有连接在该端的电荷之和。团内事件可以整体读取它。

## 3. 平衡能量（结构强制，函数形式选择）

E = Σ_c U(N_c) + Σ_e [ε·w_e − J·w_e·n_P,e·n_Q,e] + μ·总含量

- **[强制]** 能量差只读局部（G1E）。可塑项只耦合同一连接两端（G7），所以 Hebb 型耦合是 w·(前端)·(后端) 的互易形式（第二层第 2 点）。
- **[选择]** U、ε、J、μ 的取值，以及 n_P·n_Q 这一乘积形式；只要求它们是两端的局部函数。

## 4. 事件（全部满足 P1b；平衡环境下由 `p2b_of_micro_weighted` 证明 P2b）

| 事件 | 参与者 | 读取范围 | 速率 |
|---|---|---|---|
| 隔室内转移：电荷从 (e,c) 端移到 (e',c) 端 | {e, e'}，同在星 c 中 | 星 c | κ·exp(−ΔE/2) |
| 跨连接传输：e 的一端到另一端 | 两个通道：通道 1 读 {e}∪星 P，通道 2 读 {e}∪星 Q | 两个团 | **[强制]** G8a 的交叉构造：正向 √χ(aΦ_P + bΦ_Q)，反向 (b/Φ_P + a/Φ_Q)/√χ |
| 可塑：后端一个电荷变成槽位（w+1），或反向 | {e}∪星 Q | 星 Q | κ_w·exp(−ΔE/2) |
| 边界交换：Q 隔室的端点与储库交换电荷 | 边界单元 | 刺激 | 储库势 μ_s：平衡时 μ_s = μ，到达字节 b 时 Q_b 的储库势升高 |

- **[强制]** 学习消耗电荷（G2）：槽位来自后端的电荷，电荷最终来自边界摄入。学习因此与摄入耦合。
- **[待证]** 跨连接传输的两个通道在平衡时满足 P2b，即 G8a 在介质层面的桥接。
- **联合反应实现进展（2026-10-26）：**`cgb_local_medium.py` 已将§2–4的整数能量族落实为联合局部速率，采用 `π∝2^(−2E)` 和对逆事件相同的族内上界；与上表 κ=1 的连续生成元存在登记的相对时标选择。现已接有限交换库存、字节调制的边界化学势及目标到达前的观察方 Q 电荷读出，并登记按反应族抽样以避免边界提议被组合数淹没。已验守恒、局部读取和有限状态微观平衡；64真实字节只验接口，未展示语言摄入学习。正式 `Medium` 实例、身体局部读出、载体精化及能量/维持闭环仍待建立，不能把此进展写成完整准入。详见[共同参考](CGB_UNIFIED_REFERENCE_20261026.md)。

## 5. 预测与条件化

- **[强制]** 时间方向只能来自边界驱动（G6DB）：内部输运是可逆的，本身没有"向前"。
- **[待证]** 预测机制：慢的 P 痕迹总是先于新输入出现。Hebb 槽位 w(P_i, Q_b) 在"痕迹 i 与随后输入 b 同时活跃"时增长；之后痕迹的电荷优先沿高 w 连接流回 Q 层。这一机制尚未推导到能给出预测分布的程度。
- **[选择]** 读出：Q 层各隔室在下一字节到达前一刻的电荷占比，作为预测分布（质量归一读出）。由评估方测量，个体自身不需要计算它。
- **[强制]** 条件化：到达的字节只能经边界储库作用（P3）。这里没有贝叶斯式的全局重归一化，这正是诊断器 ChargeFilter 违反 P1b 的地方。

## 7. 可证伪的预测

- **P1：**m ≥ 256 时，LG-1 在独立未来上的 bits/byte 低于在线一元（4.66），并接近诊断器 lag=0 的水平（3.65–3.68）。理由：P 痕迹的作用相当于隐藏格子，Hebb 槽位相当于整数沉积。由于第 5 节的预测机制仍待证，P1 是最弱的一条预测。
- **P2：**切断摄入（储库不再供电荷）后，槽位不能再增长，学习停止；拿走维持后，权重衰减，预测退回单字水平。
- **P3：**冻结孪生体与学习个体的差距，在生命早期显著，后期收窄。
- **失败的出口：**若 P1 不成立（例如明显差于二元），先检查瞬态读出的时间尺度与容量；若读出机制本身不对，回到第 5 节重新推导预测的物理形式。

## 8. 与诊断器的关系

ChargeFilter 的每拍输运 α·A，约等于本介质中电荷沿连接扩散一个世界拍的平均场；它的整数沉积，约等于 Hebb 槽位填充。二者的根本区别有两点：ChargeFilter 用全局归一化做条件化，而 LG-1 只能经边界作用；LG-1 的学习受含量与摄入约束。

## 9. 修订（2026-10-26，依据第三层推导与诊断）

- **预测与学习**改为采用[第三层](CGB_GENERATION_LAYER1_20261025.md)的结论：
  - 预测 = 快边界在慢内部条件下的 Gibbs 条件分布；
  - 读出权重的学习 = delta 规则，由边界调质单元在驱动相/自由相切换符号。
  - **条件精化（同日）：**Gibbs 条件分布变成字节 softmax 还需互斥标签/读出态条件；独立有界电荷的归一化均值不自动满足它。平均场代码保留 softmax 作为登记的读出选择。有限时间真实采样律、局部场构造及资源门控须另外验收，见[共同参考](CGB_UNIFIED_REFERENCE_20261026.md)；现有诊断分数不作为物理采样已经达到该条件分布的证据。
- **两类边界隔室 [由诊断推出]：**
  - 只用一组字节隔室 Q 时，W₁ 既写入又读出（互易）。读出学习会拖着写入特征一起变，表征坍缩：20 万字节时 4.49 bits/byte，而用固定写入特征时是 3.63。
  - 改为感受隔室 Q_in（整拍受驱动，经 W_in 写入隐藏层）加预测隔室 Q_out（快，自由相读出；只在学习时刻被短暂钳制）。
  - 慢的隐藏层对短暂钳制的响应弱，所以经 W₁ 的物理反向耦合可以保留：反馈强度 0.1 与 0 结果相同，0.3 开始有害。
  - W_in 在本版选择固定（"基因给定"）；内部历史载体可以传播世界信息，G6 并不禁止它影响可塑性。这条联合状态路径及其信用仍待推导。
- **延迟痕迹：**P² 通过与 P¹ 的对称扩散获得滞后的痕迹。时间方向来自驱动。20 万字节时，它把 3.59 降到 3.42（256 隐藏）和 3.37（512 隐藏）。

## 10. 结果（2026-10-26，独立未来 bits/byte 均值，m=512）

| 版本 | seed 1 / 2 / 3 | 冻结孪生体 | 记忆剖面 D=1 / 4 / 8 |
|---|---|---|---|
| 固定 W_in，无内部耦合 | 3.480 / 3.476 / 3.481 | 3.65–3.76 | 0.36–0.41 / ≈0.02 / ≈0 |
| + 对称内部耦合 recur=2 | 3.413 / 3.400 / 3.425 | 3.71–3.84 | 0.59–1.42 / 0.06–0.73 / 0.03–0.57 |
| + 巩固退火 τ=100，η=0.1 | 3.414 / 3.412 / 3.418 | 3.50–3.53 | — |

对照：在线二元 3.68，在线三元 3.23；诊断器 lag 2–8 为 3.20–3.29。

诊断与结论：
- **平衡传播学 W_in（`eta_in`）：**小步长无效，大步长有害。原因是 512 个随机特征已经完整编码了当前字节，W₁ 单独就能表达二元关系；学习 W_in 对即时预测是多余的。
- **对称内部耦合：**提供非加性（合取）的历史特征，带来约 0.07 的改善，记忆延伸到 8 字节。
- **巩固退火：**活着的个体没有改善，冻结孪生体改善约 0.25。G10 的预测成立：巩固服务于平稳知识，追踪需要学习率下限。
- **剩余瓶颈：**隐藏表征不学习。按 G9，学习内部表征（例如 R）而又带误差信号，需要在内部可塑位点放置边界调质单元，代价是 boundaryFraction 上升。跨拍信用（诊断器的 lag 结论）也落在这里。
