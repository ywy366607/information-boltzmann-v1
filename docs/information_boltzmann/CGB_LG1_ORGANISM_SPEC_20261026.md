# LG-1：第一个按生成链设计的个体（规格，2026-10-26，Claude）

依据：[生成链](CGB_GENERATION_LAYER1_20261025.md) G1–G8 与第二层 c 的线图结构。标注：**[强制]** 由已证定理或推导给出；**[选择]** 自由参数或设计选择，需单独论证或学习；**[待证]** 依赖尚未证明的命题。

## 1. 身体

- **[强制]** 接触结构是一个线图 L(G)：单元 = 连接（G 的边），团 = 隔室（G 的顶点）。依据 G8 与条件 (B)；"(B) ⟹ 线图"本身仍是 **[待证]**。
- **[强制]** P1b 要求接触结构齐性（顶点传递），所以 G 必须边传递。最小的选择是完全二部图 K_{m,n}：L(K_{m,n}) 是车图，顶点传递。
- **[选择]** 第一版：G = K_{256,256}，两层隔室，前层 P_b 与后层 Q_b 各 256 个，b 为字节值；每对 (P_b, Q_{b'}) 有一个连接单元。这是二元模型的介质版，用来先对齐"在线二元"基线。之后再加内部隐藏隔室。
- **[选择]** 边界：后层 Q 是感受边界，到达的字节驱动对应隔室的储库；前层 P 是内部。参数 boundaryFraction 待定。
- **[强制]** 身份页：边界与内部单元的规则可以不同，但同一页内的规则必须相同（P2c）。

## 2. 单元状态与含量

单元 e = (P_b, Q_{b'})，状态 λ_e = (n_P, n_Q, w)：
- n_P、n_Q ∈ {0..Q_max}：两端的电荷数；
- w ∈ {0..W}：占用的槽位数，即可塑权重。
- **[强制]** 状态有限，并有含量代价（P1a）：content(λ) = n_P + n_Q + w，真空是唯一的零含量态。
- **[强制]** 隔室活动 N_c 定义为隔室内所有连接在该端的电荷之和。团内事件可以整体读取它。

## 3. 平衡能量（结构强制，函数形式选择）

E = Σ_c U(N_c) + Σ_e [ε·w_e − J·w_e·n_P,e·n_Q,e] + μ·总含量

- **[强制]** 能量差只读局部（G1E）。可塑项只耦合同一连接两端（G7），所以 Hebb 型耦合是 w·(前端)·(后端) 的互易形式（第二层第 2 点）。
- **[选择]** U、ε、J、μ 的取值，以及 n_P·n_Q 这一乘积形式；只要求它们是两端的局部函数。

## 4. 事件（全部满足 P1b；平衡环境下由 `p2b_of_micro_weighted` 证明 P2b）

| 事件 | 参与者 | 读取范围 | 速率 |
|---|---|---|---|
| 隔室内转移：电荷从 (e,c) 端移到 (e',c) 端 | {e, e'}，同在星 c 中 | 星 c | κ·exp(−ΔE/2) |
| 跨连接传输：e 的一端到另一端 | 两个通道：通道 1 读 {e}∪星 P，通道 2 读 {e}∪星 Q | 两个团 | **[强制]** G8a 的交叉构造：正向 √χ(aΦ_P + bΦ_Q)，反向 (b/Φ_P + a/Φ_Q)/√χ |
| 可塑：后端一个电荷变成槽位（w+1），或反向 | {e}∪星 Q | 星 Q | κ_w·exp(−ΔE/2) |
| 边界交换：Q 隔室的端点与储库交换电荷 | 边界单元 | 刺激 | 储库势 μ_s：平衡时 μ_s = μ，到达字节 b 时 Q_b 的储库势升高 |

- **[强制]** 学习消耗电荷（G2）：槽位来自后端的电荷，电荷最终来自边界摄入。学习因此与摄入耦合。
- **[待证]** 跨连接传输的两个通道在平衡时满足 P2b，即 G8a 在介质层面的桥接。

## 5. 预测与条件化

- **[选择]** 预测：前一字节到达后，电荷沿各连接扩散一个世界拍；Q 层各隔室的电荷占比就是对下一字节的预测分布（质量归一读出）。评估方测量这个分布，个体自身不需要计算它。
- **[强制]** 条件化：到达的字节只能经边界储库作用（P3）。这里没有贝叶斯式的全局重归一化，这正是诊断器 ChargeFilter 违反 P1b 的地方。

## 6. 准入义务（四环）

1. 固定身体：G = K_{256,256}，并写明边界集合与身份页。
2. Lean：在 L(K_{m,n}) 上写出 `Medium` 实例，用 `p2b_of_micro_weighted` 证明 P2b，并证明其余五条公理。参数化的 m、n 也要能证。
3. 代码：与 Lean 规则逐项对应；在小实例（m=n=2，Q_max=W=1）上精确枚举，核对 P2b、局部性和守恒。
4. 版本绑定：验收记录同时记下实现与证明的哈希。

## 7. 可证伪的预测

- **P1：**LG-1 在独立未来上的 bits/byte 接近在线二元（3.68），误差在 0.3 以内。理由：Hebb 槽位计数 ≈ 二元计数。
- **P2：**切断摄入（储库不再供电荷）后，槽位不能再增长，学习停止；拿走维持后，权重衰减，预测退回单字水平。
- **P3：**冻结孪生体与学习个体的差距，在生命早期显著，后期收窄。
- **失败的出口：**若 P1 不成立（例如明显差于二元），先检查瞬态读出的时间尺度与容量；若读出机制本身不对，回到第 5 节重新推导预测的物理形式。

## 8. 与诊断器的关系

ChargeFilter 的每拍输运 α·A，约等于本介质中电荷沿连接扩散一个世界拍的平均场；它的整数沉积，约等于 Hebb 槽位填充。二者的根本区别有两点：ChargeFilter 用全局归一化做条件化，而 LG-1 只能经边界作用；LG-1 的学习受含量与摄入约束。
