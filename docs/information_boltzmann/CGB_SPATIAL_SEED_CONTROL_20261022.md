# 空间扩展后的种子因果检查

2026-10-22，先完成四臂后提出的针对性检查，属于事后定位，不冒充初轮预注册。四臂在低密度0.1水平集覆盖整个网格，说明本底成核不可忽略；不能把总材料增加都归因于微种子伸长。

在原先默认J=0.6、D_B=0.005、同一真实字节／端口／时钟条件下，新增一个“未安装种子”初始条件：把原4.8单位种子结构材料均匀放回729个游离底物池，总结构＋底物相等。P/D、支持、痕迹、端口及网格不变。两种初始材料配置的储能不同，实际初始能量／自由能和源功另列，不做等能效率结论。仅在新构造的副本t=0操作，正式个体不重置。

沿用初轮的0.1/0.3/0.5全部水平集和256ms时钟，比较末态材料量、密度分布、连通／环／端点及回转半径。若无种子也生成相同高密度结构，则微种子作用尚未证明；若存在差异，仍只能证明初始空间结构影响后续物理形态，不证明该形态是神经突或有预测作用。
