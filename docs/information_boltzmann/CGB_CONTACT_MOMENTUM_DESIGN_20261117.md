## 2. 一个共同更新：按实际接触校正预测

S继续使用原关联Delta写入，包含实际内容预算修正。定义每头正阻抗Z、归一化动量M=P/Z，实际单位键k，以及原内容保持alpha、写入beta：

```
prior = alpha*S
r = v - prior.T @ k
S_next = admit(prior + beta*k @ r.T)
u = M.T @ k
M_next = M + g*k @ (r-u).T
P_next = Z*M_next
```

S记住观察形成的关联；M预测当前地址上需要怎样修订关联。原S直接使用真实创新r，M用自己的预测u与r的差来修订趋势。外界驱动因此同时包含形成趋势、修正错误趋势和解除已解决趋势。归一化后M和r同单位，频率控制运行速度、阻抗控制相空间尺度，沿用现有分工。

### 内容门与学习参数

迁移时`g=beta`，立即具有原GDN已经学习的内容敏感性。随后使用每层两个可学习标量：

`g = sigmoid(beta_logit + b_layer + a_layer*cosine(r,u))`。

零向量的cosine定义为0，采用同一数值epsilon。新增a/b初值为0，此时P写入门即原beta；两个标量合计64个参数，实际门仍随每头、每个输入变化。a/b属于外界趋势修订，原频率/耦合属于无输入演化。新参数加入原预算优化器、独立命名的参数组，weight_decay=0，与原动力学参数一致。门导数包含cosine对S/P的依赖。

### 更新的数学含义与可核对结果

对单位键，令eta=g/(1-g)。M_next是以下严格凸目标的唯一解：

`argmin_N 0.5*||N-M||_F^2 + eta/2*||N.T*k-r||^2`。

由此直接得到：

1. 接触方向的趋势误差变为`r-M_next.T*k=(1-g)*(r-u)`。
2. 任意`q.T*k=0`，都有`M_next.T*q=M.T*q`。真实键未触及的方向保持。
3. 相同S、相同输入且门值g相同的比较中，两份M历史的差按`(I-g*k*k.T)`运输。内容门因历史而异时，差值额外包含沿k的门响应项；正交方向仍精确保持。反复同键只修订该方向；连续不同键可以逐步改写更多方向。有限状态仍通过实际接触竞争容量。
4. 归一化动量平方范数的精确变化为`2g<u,r-u>+g²||r-u||²`。可区分观察注入与释放的能量；当r=0时，该方向贡献为`-g(2-g)||u||²`。
5. S更新逐项继承原式。改变g只改变P端口。这给出保持当前关联写入、比较历史趋势用途的清晰干预。

g取极限0时保持P，取1时完全校正当前键上的趋势读出。全程仍是固定大小的矩阵与秩一更新。

## 4. 新门必须连同资格交付

当前`observed_momentum`是no_grad捕获，只添加参数到该函数会产生无法训练的门。因此执行须同时实现局部前向资格与实际读出处的后到交付。

每层a/b共有两条局部资格，分别携带对S、P的敏感度。实际层输入及原alpha/beta/k/v作为局部参与的给定输入；S/P自身的依赖完整运输。对一次实际边界转移T：

`E_next = J_state(T)*E + partial_phi(T)`，`phi=(a,b)`。

观察写入和quiet都运输E；quiet的phi直接项为0。固定Z时、写入步骤中，`E_r=-alpha*E_S.T*k`，

`E_M_next=(I-g*k*k.T)*E_M + g*k*E_r.T + k*(r-u).T*E_g`。

`E_g`包含门对phi的直接导数和经S/P的内容依赖。S侧使用原Delta及admission的局部导数。

这两条资格跨实际优化更新时间按实际运行参数递推，语义为局部参与痕迹。优化器改变参数后仍按实际轨迹运输；它估计局部写入责任，不宣称整个跨层、跨优化器历史的精确总梯度。原12条theta资格继续遵守原版本和支付约定，两条新门资格单独管理，避免原`consume()`将未交付的写入痕迹清空。

决策时以实际q把E_P收缩成读出资格，复制进原pending，与对应动作/事件/参数模式版本同行。真实边界目标到达后，经原预测误差和既有选择信用支付到a/b。新资格生命周期、重复支付防护、恢复一致性须和前向核一起准入。当前窗口正常BPTT与历史资格保持各自作用域，避免同一次局部导数重复计入。

资源：32层×8头×32×32的FP32单份P为1 MiB，继续复用。新增两方向×S/P的全层资格为4 MiB；新门参数64个。pending只复制收缩后的读资格。实现应扩展已有Triton捕获核，复用实际键、残差和投影；无逐字节Python循环、无额外全层历史快照。Python参考用于数值合同。
