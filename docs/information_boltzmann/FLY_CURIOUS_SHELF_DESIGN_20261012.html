好奇书架

把一大堆书交给个体，读什么由它自己选。驱动它的是学习进展：惊奇被吸收成知识的速度。它提问，世界给它材料。

2026-10-12状态：设计，尚未实现前置：第 1 层在线学习、从出生开始长的对照路线图第 5 层

为什么要做

就像人把手指放到桌面，因为好奇就会滑动手指感受一样。你把一大堆书本扔给他，他自己也会因为好奇自发学习，从中压缩知识、找到脉络。生命是会主动探索的。用户，2026-10-11

它同时补上我们一路走来留下的两个缺口：

多巴胺没有可以奖励的动作

  • 选 token 是动作，但下一个词早已由文本决定，说对说错，世界都不变
  • 没有后果，多巴胺就无从判断“刚才那样做好不好”，几次测量里它都是平的、没有因果作用
  • 选读什么是有后果的动作：选了不同的书，接下来的世界就不同

读写口本来就该由大脑自己控制

  • 这条线最初的目标是写入、思考、读出互不阻塞，能“视而不见、听而不闻”
  • 一路追下来，接口只是闭环的一端：没有误差信号、在线记忆、熟悉度和有对象的多巴胺，改接口就没有收益
  • 书架把“读什么、何时换”交给大脑，正是主动的毯子

翻转的关系：今天的大模型是人提问、模型回答，它接触什么信息全由提问的人决定。这里是果蝇提问、世界回答；它要的不是答案，是材料，问什么由它自己的不确定性决定。

原理：奖励学习进展，不奖励惊奇

如果奖励的是主体会被吸引到结果
惊奇（预测误差本身）永远学不会的东西：随机字符、白噪声“噪声电视”陷阱：误差永远高，学习从不发生
熟悉（低误差）已经掌握的、重复的东西暗室：什么也学不到
学习进展（误差下降的速度）正在变得能理解的东西噪声和已掌握的内容进展都为 0，于是离开；留下的是正在被压缩的内容

第一次看到一种东西，惊奇高、进展高；第二次，惊奇下降、进展仍高；之后惊奇低、进展低，于是离开。这就是厌倦，它让塌缩和暗室都不会出现。

几条独立的研究线都指向这里：Schmidhuber 的压缩进展（奖励是压缩变好了多少）、Oudeyer 与 Kaplan 的学习进展（儿童发展与机器人）、主动推理里期望自由能的认知价值项（预期信息增益），以及 Friston 把眼跳看作检验假设的实验。

黄色是这次要补上的部分：学习进展、提问式的动作、世界的回应，以及多巴胺对“进展比预期多还是少”的编码。

书架：四个区

语料：data/ib_owt_gpt2 训练集 1,094 万 token、9,786 篇文档（平均约 1,100 token）；验证集 107,728 token、114 篇，只用于评估，不上书架。一本书是一段连续文本；每次读一段（64 词）后做一次选择。

区内容预期行为检验什么
已掌握区一段固定文本循环重复起初有收益，记住后进展归零，厌倦并离开暗室不会出现
正在学习区按主题聚类的多本书（文档按罕见词重叠聚成若干主题）留下来读，在主题之间迁移按进展分配时间
噪声区两本：词表上均匀随机的 token；按词频抽样的随机 token（与真实文本同样的单词分布，更难识别）惊奇一直高，但进展为 0，离开噪声电视陷阱
隐藏关联区成对的书：同一长文档拆成两半，以及共享罕见实体的两篇文档单看都难，一起读压缩突然变好，在两本之间往返探索有没有形成知识结构

版本 1：外挂的学习进展选择器 先做这个

目的：检验前提。按学习进展取材，对这个大脑有没有好处？如果没有，把选择交给大脑也没有意义。这一步不改大脑。

学习进展怎么测

  • 每本书留一小段探针文本（32 词），永不用于训练。
  • 每次读完一段，用固定权重在该书的探针上测一次误差；进展 = 上次访问时的探针误差 − 这次的探针误差。
  • 为什么不用正在读的文本：同一本书前后两段难度不同，误差的变化会把难度差当成进展。
  • 单词误差的波动有 2–3 nats，所以每次决策前至少读 64 词，进展用滑动平均。

怎么选

对各本书的平均进展做 softmax 选择，留一点随机探索；从没读过的书给一个乐观的初值，保证每本至少被试一次。

对照组

组选择方式回答
按进展上面的规则主实验
随机均匀随机选书按进展取材是否更好
按惊奇选当前误差最高的书应掉进噪声区，验证陷阱确实存在
反进展选进展最小的书确认是“进展”本身在起作用

判据

  • 时间分配：在噪声区和已掌握区的时间占比随时间下降；按惊奇的那组应困在噪声区。
  • 学得更好：在固定的、混合所有非噪声书的留出文本上，四支柱（首次预测、恢复、重访节省、健康）优于随机组，比较时按读过的 token 数对齐。
  • 隐藏关联：在成对的书之间往返的比例；读过其中一本后，另一本的探针误差是否下降。

训练前的预言

  • 避开噪声区和已掌握区：几乎肯定会出现，因为进展是用外部探针直接测的。
  • 相对随机组的收益：很小，可能在 0–0.05 nats 之间。这个大脑的学习本身很慢，课程的好处会被稀释。
  • 隐藏关联：取决于在线记忆是否有用；在成年个体上大概率看不到，要看从出生开始长的对照。

版本 2：提问版，它说出的话就是查询

大脑本来每一拍都在说出对下一个词的预测，说完即丢。让世界把它当作检索的查询，从书架里找出相关段落交给它读。这样“说”就成了“问”，选 token 第一次有了后果，而且用的是它原有的运动输出，不需要另外加动作读出。

查询的形式做法特点
期望向量预测编码写入里自上而下的期望词嵌入 ê，在最近一段上取平均，按余弦相似度找最近的段落用的是大脑内部本来就有的向量，最原生
说出的词最近一段里它预测概率最高的词，作为关键词做 BM25 检索罕见词起主要作用，即使句子不通也能问到相关材料

检索库：训练集切成 64 词的段落（约 17 万段），评估文本和探针不进库。奖励仍是学习进展；一个提问换来的进展就是这个问题的好坏。

额外风险：自我强化的回音室，总是问到和自己预期相似的东西。进展奖励本身会抵消它：同类内容读多了，进展下降，主体就会厌倦而去问别的。这一点要直接测：检索到的主题多样性随时间的变化。

版本 3：把选择交给大脑，多巴胺编码进展的预测误差

  • 动作从运动面读出：继续读、换一本、回头重读（版本 2 则是它说出的话）。
  • 学习进展改用大脑内部的信号：预测编码写入的新息随时间下降的速度。这是它自己感到的“我猜错了多少”，不再借用外部的交叉熵。
  • 多巴胺 = 实际进展 − 预期进展。好的选择和好的问题被强化；它最终学会的是“怎样问出能让自己学到东西的问题”。
  • 新奇和熟悉最好来自蘑菇体：稀疏的 Kenyon 细胞加在线记忆，就是果蝇本来计算“这个见过吗”的地方。

前提：多巴胺细胞必须能接收到进展信号。现在它们被核心锁住，所以版本 3 的成败直接取决于第 1 层和从出生开始长的对照的结果。

风险与对策

风险对策
进展信号太嘈杂：单词误差波动 2–3 nats探针固定、每次至少 64 词、滑动平均；先离线测一次探针误差的噪声水平，再定决策频率
决策太少：每 64 词一次，3 万词只有约 500 次版本 1 的选择器不需要学习；版本 3 才面对这个问题，届时再定动作的时间尺度
按词频抽样的噪声与真实文本单词分布相同正是要检验的难版本；如果被困住，说明主体只学会了单词统计
泄漏：探针或评估文本进入训练或检索库建库时排除，并写测试检查
评估偏差：自己选材料，训练分布和评估分布不同评估固定在混合留出文本上，按读过的 token 数对齐比较
算力：每次决策多一次探针评估32 词、固定权重，约占训练时间的十分之一

实施清单（版本 1）

1

书架世界

新文件 scripts/ib/fly_bookshelf.py：从训练集构建四个区的书、每本书的探针；按主题聚类；生成噪声书和重复书；检索库留给版本 2。

测试：探针和验证集不出现在任何书里；每本书的文本连续。

2

选择器与训练接入

训练脚本新增一种世界：训练流来自书架，而不是线性游标；每读一段调用选择器（进展、随机、惊奇、反进展四种）。

测试：选择器只用过去的信息；同一随机种子下可复现。

3

评估脚本

时间分配曲线、留出文本上的四支柱、隐藏关联往返与探针误差、多巴胺在换书前后的反应。

4

训练前先算

离线测探针误差的噪声，确定最小可分辨的进展，再定段长和决策频率；写出预言，请用户确认后再跑。
