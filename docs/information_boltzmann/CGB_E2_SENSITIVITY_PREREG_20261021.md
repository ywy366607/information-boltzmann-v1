# E2先检查功能检验的敏感性

沿用主规划§10/§11的E2路线，目标是验证生成规则保留功能，不以更像成年果蝇作为最终目标。旧E2四个1024词新生儿的在线NLL近乎相同，连null也不损失；这个事实已知。

本轮在旧E2真实布线个体的完整存档上作**急性因果诊断**，不启动训练，不修改存档，不以短段诊断声称学习能力。使用该存档对应的历史代码F:/cgb_e2_head，而非把旧状态装入当前大幅扩展后的原生模型。记录代码、数据和状态来源，GPU空闲才运行。

所有分支从同一完整物理状态和RNG起步。真实OWT validation从索引60000起，先用前一个实际词元提供上下文，再逐词预测下一实际词元；每个词的呈现间隔按原配置的窗口级log-uniform均值和逐tick几何终止生成一次，由所有分支共享。共享新诊断时钟，不冒充已经找回旧训练未存下的pace RNG。预测在下一词到达前读出；无Adam/BPTT，已有在线物理记忆继续演化。

预定分支：real/sham、切除旧MB重采样区域的快速传递、切除CX细胞输出、切除全部快速传递、恢复后的sham。MB及全切必须同步覆盖不在快速边表里的KC→MBON隔室权重，避免名义消融仍有旁路。保留感觉注入、读出权重、现有电导状态和时间常数，旧输入的残余按原方程自然清除。

先做128词诊断；sham检验有数值误差就不得验收。报告每词配对NLL变化、后半段变化、读出差与终点全物理状态差，另记区域的末tick活动（不冒充完整放电率）。对真实文本的因果交付与学习收益分别记录。128词只是短程敏感性预算，不代表收敛或完整功能。

若全切有明显影响而区域消融几乎没有，当前全局NLL不足以验收对应区域；继续找特异布线承载的功能指标与实际输入通路，不靠加大训练和任意换测量来宣布通过。若全切也无效，先定位感觉/读出旁路或个体尚未学会使用回路。只有区域功能与阳性/恢复控制都成立，才以其比较真实、类型重采样、已拟合生成器和破坏特异性的null。

## 首轮后追加的独立复核（运行前登记）

128词结果已读取：MB与CX切除的平均NLL影响很小，全切降低NLL约0.438，sham完全一致。下一步在尚未读取的validation索引61024起512词，只运行real/all_cut/sham三支，保持相同状态和匹配时钟。此复核检验全切改善是否局限于首段，不重新选择脑区或改变参数。补充decoder-bias-only和固定读出基线，用于区分静态语言先验与随文本变化的脑贡献。仍不宣称1024训练词已充分或架构优劣已确定。

## 已学习参考个体的准入（运行前登记）

为避免让1024词早期个体承担成熟功能验收，选取既有m_main/last.pt（历史已学90112词；与旧E2同r2图和同格式物理状态）。只读复本诊断，不续训或改它。使用同一个历史代码加载，逐项核实已存模型张量完全一致，并恢复旧便利加载器遗漏的dopamine_site非张量配置。新validation段63072起128词，五个预定分支不变。只有真实连边相对全切提供正预测贡献，且恢复控制通过，才视为后续E2的候选参考个体；区域功能仍单独准入。此选择在读取该个体本轮分数前登记。

## 已学习参考的独立复核与输入贡献（运行前登记）

63072段结果：全切增加NLL 1.009，但真实脑7.389仍未胜过decoder-bias-only 7.313。因而全切损失可能包含已学读出对持续背景状态的依赖，不能直接解释为利用文本信息的收益。

在未读取的validation索引65000起512词复核，仍由相同完整状态出发，五个原分支全部保留，另加input_lag分支：仅把感觉输入替换为原文本32词以前的输入，目标和物理时钟不变，没有未来信息。此分支用于急性输入对齐敏感性，不当成新的正常预测成绩。增加独立校准的固定读出：只用此前63072段real分支128个读出向量的均值，经同一read_norm/decoder预测65000段；不在新段拟合任何量。该基线保留稳定背景偏置而没有随当前文本变化的脑状态。三种比较分别回答：快速连边依赖、当前文本输入贡献、时变状态相对固定背景的预测收益。MB/CX只有区域破坏损害相应功能才准入；无损就继续记未验收。

## 实际感觉出口的定位（运行前登记）

65000段真实脑6.841优于偏置7.139、独立固定读出7.216；输入滞后损失0.550，全切损失0.879。MB/CX作用均小且跨段符号改变。下一项不靠继续改NLL阈值：按既有ReceptorWriter.injection_index定义感觉入口，切断这些细胞的快速输出，保持文字照常流入感受器、其他边和调质投射不变。使用独立67000起256词，real/sensory_cut/input_lag/sham四支，保持相同完整初态、共享时钟和既有固定读出校准。记录入口细胞数、切除边数及初始KC隔室覆盖情况。此步骤定位语言世界实际调用的回路，为其后的生成/破坏布线对照选择靶区；急性定位本身不是生成器或终身学习验收。
