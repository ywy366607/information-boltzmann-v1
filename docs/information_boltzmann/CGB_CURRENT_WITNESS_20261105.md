# 同一身体的金水结算：v4r

金判断经历对语言能力的影响，水提供已经听过的见证；见证文本、身体网络及快表共同形成读数。v4q用见证被听到时保存的快表概率结算，使快表后续变化不进入g。v4r沿用见证池，评分时对见证文本使用当前快表的只读分布；在接触前后评分相同的一组见证，分别使用当时的网络和快表，之后才接收新见证。读取固定从零历史出发、按见证窗口拼接顺序，不在评估中写表，也不向身体泄露世界位置。

`GenerationFutureValue.empiricalFutureLanguageCrossEntropy`支持从实际重遇的语言测量可用预测能力；`observed_continuation_improvement_is_empirically_paid`仅在各观察项不变差、至少一项变好时给出严格改善，不证明v4r的32段见证就是未来分布。`GenerationActiveInference.action_condition_required`支持世界后果有动作差异时需要区分动作，不能证明当前世界或身体必然满足差异。这里的运行是一种有限估计与构造，不宣称证明整体生命。

## 运行前约定

单个v4q末快照的副本，真实OWT接话世界连续128轮；原快照缺少上一拍部分木的中间量，第一轮不是原个体精确下一拍，后续状态连续。这个限制单独标记，不覆写原快照。保留语言CE×10、SIGReg=.001，所有学习和更新节律沿用v4q。

1. 每轮同时记录当前快表的g和旧快表条件下的g，但仅前者作为金的实际结算，流向同一TD、经历库、木预测和行动。统计正负分歧、差值及行动变化；不将两种口径差值单独称作因果收益。
2. 运行前、64、128轮在相同32768字节独立语言验证上测量；同时记录字节量、实际优化器步数、重放量、显存及动作分布。观测信息流接通与损益，128轮不声明收敛或优于旧方案。
3. 逐字节只读结果必须等于现有peek；测量不改变快表。每轮确认当前g确实是已有金信号和木的训练标签。不得在见证评分中写入未来。
4. 如果当前见证与未来真实文本仍不一致，继续检查见证抽样和重访；不从某一测量口径的变化直接判定妈妈世界或任何机制的成功。

实现 `scripts/ib_local/navigation_live_witness.py`、`language_navigation_kanli_v4r.py`；运行 `scratch/run_current_witness_20261105.py`。本轮不修改或读取妈妈世界运行。

## 结果：接通了，但收益评价还没稳定

128轮：122880外界字节，2624自听字节，512次优化器更新，4096条回放；显存峰值约178 MiB，耗时210秒。独立NLL 1.47376 → 1.48383（64轮）→ 1.47810（128轮）。这一条是单个续接的短预算，不能解释为新规则带来收益或损害的因果比较。按身体已有协议见证评分使用冷启动循环状态，并非重放当初的全部身体状态。

当前快表和旧保存概率的g在48/128轮符号不同；每轮木的10g标签与当前口径完全一致，原来的TD、回放、动作流程接到了这个信号。后64轮g目标MSE：动作均值基本盘.002329，信任后预测.002331，无动作均值.002496；潜在修正的平均信任约.032、其独立策略TV约.000166。木→火总TV约.00491。仍看不出情境修正对收益预测的实质改善。

为定位波动，使用相同初始快照与相同规则额外重放前16轮并加入评分探针，不是第二个独立种子。定义L(N,T)为同一见证上的损失，严格分解：`g = [L(N前,T前)−L(N后,T前)] + [L(N后,T前)−L(N后,T后)]`。这条分解按“先网络、后快表”的顺序；交互效应随分解顺序分配。16轮中网络项标准差.000404、快表项.003617，整体g标准差.003579；数值分解残差为0。故这段里新g的大波动主要随快表变化而来，不应把它直接归因于神经权重学习。

只读表值与已有peek一致，快表无写入；相关9项数值测试通过。输出`results/cgb_navigation_current_witness_20261105/summary.json`及`metrics.jsonl`，分解见`results/cgb_navigation_witness_decomposition_20261105/metrics.jsonl`。本次诊断未保存v4r末快照，不可称可续接个体；老v4q快照及其已知中间木状态缺失未改。下一步研究如何让见证条件与未来遭遇一致并降低快表引起的短期扰动，再评估它是否可被木利用；不能单凭当前g较新就说金水已修好。
