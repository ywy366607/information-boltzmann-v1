### V1.1 同一个对象，而不是三个独立模块

将有限精度、有限容量的共同内部状态记为 `z`。它包括实际预测所用的递归记忆、可学习参数、有限工作区，以及确有必要的结构分配状态；所有这些都计入资源预算。一次事件是同一转移 `z⁺=Φ(z,x)`。**储备是这个状态中未来仍可使用的语言区别；耗散是这些区别在更新中的丢失；摄入是语言引起的学习、校正与巩固。**这些是同一过程的性质，不另设食物、生命余额或逐字节扣费。

三项生成承诺约束同一 `Φ`：

| 生成承诺 | 同一转移必须做的事 | 共同生成的功能 |
|---|---|---|
| G1：上下文相关的有限递推 | 历史改变实际查询、参与和读写；允许非线性交互；状态规模不随经历长度增长 | 顺序记忆、预测、压缩、历史参与的载体 |
| G2：作用于实际内容的有限容量交换 | 某接触得到份额时其他可用份额减少；交换改变真实读写与保持；允许重新获得支持 | 稀缺、竞争、分化、选择性遗忘、保持与释放 |
| G3：结果条件化地改写同一关系 | 到达语言相对预测的证据，结合仍可区分的历史参与，改变内容和分配；不同局部允许不同响应 | 即时学习、条件性的延迟归因、局部增益、结构自修正 |

这是三个作用条件，不是三个新增网络。局部状态若已经承担历史参与、保持与可用度，就复用它；只有出现“现有编码相同、未来需要不同响应”的反例，才为那个区别增加自由度。

### V1.2 已有算法怎样选

**A．关联递推选作语言计算基底。**复用已有 Gated DeltaNet 路径，可学习嵌入、Q/K/V、门控、短卷积、非线性残差和读出，状态跨窗口保留。以下采用 value×key 矩阵约定（代码采用其转置）：

```text
S̄ = α S
e = v − S̄ k
S⁺ = S̄ + β e kᵀ
o = S⁺ q
```

`q,k,v,α,β` 均可学习。已有 tied-write、关联读出和容量定理约束这条路径；它保留现代网络的表示学习能力。`α=1` 子情形的跨拍展开与联合读出误差界已经做过数值核对，实际可学习遗忘门的影响必须进入后续联合界，不能沿用子情形的保持结论。

**B．持久证据交换选作 G2/G3 的局部构造模板。**它已经有具体公式，保留为待接入同一内容状态的构造，不能把它的份额另挂成身体不用的账户。对于确实采用概率混合读出的局部候选：

```text
a = softmax(Ks / τ)
P(y) = Σᵢ aᵢ pᵢ(y)
r = softmax(Ks / τ + log p(y))
s⁺ = (1−γ)s + γr              (0 < γ ≤ 1)
Jᵢⱼ = γ rᵢ sⱼ
```

`s` 是持续状态，`K` 是交互，`pᵢ` 是实际局部预测。`s⁺ᵢ−sᵢ=Σⱼ(Jᵢⱼ−Jⱼᵢ)`，所以总份额守恒；同一状态同时影响预测和后续交换。已有二状态条件构造给出稳定保持与持续反证释放，已有冻结场信息势下降条件。**本版选它的共享状态原则和明确交换式；它与 A 的真实读写连接仍是本版第一项实现工作。**普通 GDN 的 softmax 读出并不是概率混合，不能直接把这里的 `r` 冒充它的梯度。

**C．内容与分配共同学习，不能只移动份额。**对于 B 的实际混合读出，当前对数似然的两项分数为：

```text
内容 logitsᵢ： rᵢ (onehot(y) − pᵢ)
分配 logits：   r − a
```

共享参数要接收两条实际依赖的贡献。所有候选一样错时，分配可以不动，内容仍须能学。对 A 则使用 A 的实际当前预测路径求导，不能换用 B 的公式。固定窗口求导作为即时训练和核查工具，窗口外由保留、取回的历史参与调制当下学习；这种保留并不自动等于完整历史梯度。

| 之前提出的算法 | V1 处置 | 适用条件与用途 |
|---|---|---|
| 关联 delta 写与跨拍矩阵输运 | 采用作内容基底与记忆账本 | 实际键、查询、读出一起登记；输运展开用于证明，不在运行时存整段历史 |
| 持久非线性证据交换 | 采用作局部竞争—保持—释放的构造模板，等待同体连接 | 多稳态与释放只在已列条件下成立；总预算不等于双向预算 |
| 纯乘性再投资 | 保留为代数特例和反例参照 | 零支持吸收、集中态吸收使其不能独自承担健康可塑性 |
| 自然参数/精度同化 `m⁺=(pm+wv)/(p+w)` | 保留为可选的局部增益实现 | one-hot、无全局衰减时可与 delta 对接；混合键下已有不等价反例 |
| 局部再投资、粗粒化交换、双预算循环 | 保留为结构连接工具 | 已给分组时的恒等式不等于分组自行生成；2×2 交换不等于完整优化器 |
| 可逆微观接触、计数槽、出生死亡 | 保留为另一种实现精化与见证 | 不要求语言主体先变成整数占据模型；不得把微观例子的条件迁移到任意实数网络 |

```text
世界含有可复用的历史关系，且反馈与行动有可声明的关系（W）
  → 未来需要区分某些过去；有限载体只能保留其中一部分
  → 上下文相关的查询与非线性交互，把留下的区别用于预测（G1）
  → 到达的语言产生结果证据；局部参与限定谁应被改写（G3）
  → 内容学习与有限份额交换共同改变下一次预测（G2＋G3）
  → 重复支持、冲突证据、局部竞争作用于同一持久关系
  → 在相应动力学条件下形成分化、保持、释放与不同响应尺度
  → 这些结构改变未来预测与交互，重新进入第一步
```

其中每个箭头保留适用条件。不是“世界变化”四个字就推出所有机制，也不是把需要保持写成一个永不遗忘的开关。当前主要接口和来源如下；完整名字、源签名、量词前提与依赖边在[机器切片](../../results/published/cgb_generator_causal_core_20261103.json)与[覆盖清单](../../results/published/cgb_generator_frontier_support_20261103.json)。

**下一项是“份额交换 → 实际关联写入 → 后续读出”的同体连接。**需要写出一个真实写入算子，并同时检查容量约束、内容学习、串扰界和反证释放。现有反例已说明：普通 delta 写能保持列和却改变行和；给旁边另加归一化份额不能修复它。份额如果能被内容幅度任意放大抵消，也不算实际资源限制。

### V1.6 第一段实现：实际内容的容量准入（2026-11-03）

现有 [Gated DeltaNet](../../scripts/ib_local/gated_deltanet.py) 增加可选 `content_budget=b>0`，默认0保持既有行为。令 `U=αS+βk(v−(αS)ᵀk)ᵀ` 为代码中 key×value 的写入提案，采用：

```text
rᵢ = Σⱼ |Uᵢⱼ|，cⱼ = Σᵢ |Uᵢⱼ|
S⁺ᵢⱼ = Uᵢⱼ · b / max(b, rᵢ, cⱼ)
下一次读出和递推都使用 S⁺，不再使用 U。
```

这是本版提出并检查的**容量准入构造 H**，不是从公理唯一推出的规则，也不是 V1.2 的持久非线性证据交换。它选择了一个可计算的可行化算子，先把有限容量约束接到实际内容：同一端点上过大的写入，会压缩共享端点上的旧内容；余量由 `b−Σ|S⁺|` 确定，不存分配表。参数、持久状态、优化器状态数量都不增加。行、列是同一接触的两个限制，不能相加冒充两份资源。

`b` 是明确的表示尺度配置，不是信息 bit 数，不自动等于物理守恒量。浮点精度、矩阵尺寸与其他工作区仍单独计费；下游读出也仍需满足其自己的范数条件。这里保证行/列绝对值**上界**，并不保证每行每列已占用质量相等。因此不能套用2×2等边际分配的分化结论，也不能宣称已经解决赢家通吃。

[Lean 探索准入](../../lean/CGBAxioms/reviews/budgeted_association_write_20261103.lean) 已编译并打印公理依赖，四条对外结论只用基础公理：双向容量上界、可行内容不变、由内容确定的空余容量、实际读出的修正恒等式。它不进入生产1768条计数，也不增加原294条覆盖数字。自动目录会在探索区列出。

**必须保留的代价：**设 `C=S⁺−U`，实际读出变化在普通 delta 的结果上还要加 `Cᵀq`。过载时，即使查询与写键正交，旧记忆也可能因共享端点竞争而改变；已有的正交保持保证不再成立。`C` 仅用于分析，不额外持久保存。原有 NLL 扰动界可以用于包含这项修正的实际 logits 差，但它不保证语言收益为正。

验证：同一测试文件29项全部通过，覆盖CPU/GPU、CUDA Graph学习步骤、所有慢参数梯度、跨块因果与连续状态、完整学习器恢复、容量与真实读出的因果影响。独立FP64核对的读出修正误差为 `1.78e−15`，FP32最大容量超额为 `1.19e−7`。参考样本的 `b=1` 与接口测试的其他值仅用于数值覆盖，未选为语言训练最优参数。

[数值与开销记录](../../results/published/cgb_generator_content_budget_20261103.json)：GTX1650、`[1,8,64,64]`、CUDA Graph各200次，原 delta 提案约10.1µs，带准入约41.0µs。这只是核心算子测量，不是全模型训练速度；仍需在真实模型的预算下确认成本。没有语言训练或能力结论。

**V1.6 当时的接口状态：**容量约束接到实际写入和读出；持久证据交换尚未接通，容量准入没有凭空产生点燃。后续连接见 V1.7，V1.6 的原有模式仍保持不变。

### V1.7 同一记忆中的证据交换、保持与释放（2026-11-03）

在同一个网络类中增加显式 `recurrence="evidence_exchange"` 模式，复用嵌入、可学习投影、短卷积、非线性残差、输出与语言训练接口。**这改变了递推算法，不是普通 Gated DeltaNet 的等价改写。**原模式与默认配置不变，尚未宣布新模式优于它们。

每个头的状态现在为 `(a,M)`：`a_i≥0, Σa_i=1`，`M_i=a_i c_i` 是真正读出的加权关联内容，`||c_i||₁≤b`。每行新增一个份额标量；64×64矩阵加64个数，即矩阵状态增加1.5625%，可学习参数不增加。份额不是另设的食物或奖励：它与内容共同决定下一次更新和读出。已数值核对“相同 M、不同 a，下一次内容更新不同”，所以本构造不能由 M 唯一恢复 a；这是该构造内的状态区别，不是所有生命体都必须有份额数组的定理。

一次实际更新为（`v` 先缩放至L1球内，`k` 是可学习地址logits）：

```text
cᵢ = Mᵢ/aᵢ                     （零份额且零内容时取0）
eᵢ = −½ ||v−cᵢ||²
r = softmax(g a + k + e)
a⁺ = (1−γ)a + γr
M⁺ = (1−γ)M + γ r vᵀ
o = (M⁺)ᵀ q
```

所有内容写入与份额交换都来自同一个 `r`，实际读出使用 `M⁺`。每个头的 `γ=sigmoid(beta_proj(x))`、`g=2·键维数·sigmoid(alpha_proj(x))` 都可学习，其他投影继续由真实语言CE更新。归一化因子“键维数”使中性均匀点的分岔阈值不随宽度任意漂移：该点、固定相同内容下阈值为 `g=键维数`。初始化在其下方，规则允许训练到保持区间；不人为预标哪个行应记住哪个语义。

这里的 `e` 是**明确假设的单位方差高斯潜在值似然**，不是精确的下一字节后验，也不是已推导的多巴胺通路。它与学习得到的地址一起形成局部证据；最终仍由实际语言输出的损失训练这些表征。与 V1.2 的字节概率混合不同，不能直接套用其字节 posterior 梯度公式。零份额可重新获得份额；极端logits、份额下溢和除法的浮点条件数仍须在真实训练中监测。

**同一转移的已证关系。**在非负、归一化份额，`0≤γ≤1` 和初始加权内容界下，新增4条探索结论已通过Lean：份额总量与加权内容界同时保持；真实读出遵循同一更新；匹配内容把份额固定点提升为联合固定点；增量总和等于减量总和。由 `||M⁺_i||₁≤a⁺_i b` 可得行、列内容均不超过b。该模式不再先做普通delta再裁幅，也不调用V1.6的准入函数。

该模式还使整个头的 `Σᵢ||M_i||₁≤b`；V1.6 只限制行列，允许总量达到“键维数×b”。所以两个模式的同名b不是等价可行域，后续比较必须记录这种数值尺度差异，不能把收益全归因于锁存。

**联合稳定性与释放的条件数值证据。**使用实际运行函数，在两行、相同潜在内容、地址中性、`g=2 ln 3`、`γ=0.3` 下，份额为 `(¼,¾)` 与 `(¾,¼)` 的两个完整 `(a,M)` 状态都是固定点。完整5维独立坐标的Jacobian谱半径均为约0.9472，真实查询读出不同；小扰动迭代后误差约2e−8。只改变地址反证、保持其他参数不变，两次更新即可越过分界；撤去反证后继续停留并收敛到另一支。这里是动力学数值核对，不是语言任务成绩，也未把一般稳定性/有限步释放说成Lean已证。

32项测试通过，涵盖实际网络中全部慢参数梯度、因果顺序、跨块一致、加权内容界、无目标标签泄漏、完整学习器恢复和GPU图捕获。原来的29项也保留。核心联合算子 `[1,8,64,64]` 在GTX1650上、CUDA Graph 200次约63.6µs/次；尚不是端到端吞吐或显存成本。

### V1.8 完整网络 GPU 校准与语言对照（2026-11-03）

沿用同一 `GatedDeltaNetLM`，仅比较普通 `decay_then_delta` 与 V1.7 `evidence_exchange`。两组均为256字节、宽128、4层4头、短卷积4、SwiGLU中间维256，共765,088个参数。原模式持久状态82 KiB，新模式84 KiB；新增2 KiB就是实际读写所用的行份额。候选 `b=1` 是此次明确登记的初值，不是理论最优容量，两个模式的可行域和读出尺度不同。

GPU校准中发现并修复旧 `TruncatedInternalTimeGraphTrainer` 的多块累积缺陷：在 `.grad=None` 时捕获的首次反向会在重放时覆盖梯度，较早块的贡献没有正确累加。修复是捕获前分配稳定梯度缓冲；新增测试核对两种递推、每更新两块、连续两次更新的损失、状态和全部参数与普通执行一致。35项GDN测试和5项共享训练器相关测试通过。原有单块数值检查没有覆盖这个问题；不能把先前32项通过解释为多块训练已经正确。首轮20步校准明确标为无效，后续从相同种子重新初始化。

这项问题针对一次优化器更新内重放多个块的累积；原来的单块训练不因这个原因被否定。历史记录保留其原代码哈希，不把修复后的验证追溯套用到旧结果。

### V1.9 扩大覆盖：从分配保持接到内容保持与实际取回

**本轮找到一个可证明的断点，沿用三个生成承诺和同一 `(a,M)` 状态，没有增加身体模块或启动训练。**第三圈逐条核对18条生产定理，覆盖支撑由294扩至315；[机器切片](../../results/published/cgb_generator_causal_core_20261103.json)记录每组前提、用途与未接通处。

V1.7 即使后验恰好等于原份额 `r=a`，所有正份额行仍满足：

```text
cᵢ⁺ = (1−γ)cᵢ + γv
cᵢ⁺ − cⱼ⁺ = (1−γ)(cᵢ−cⱼ)
```

所以分配固定时，不同行的内容仍以同一全局速率趋同。`joint_fixed_lift` 原本只把“所有行内容都等于同一 v”的份额固定点提升为联合固定点，没有证明不同关联可以同时保持。这是当前公式的结构性限制；它能解释部分诊断，但尚未隔离其对语言成绩的贡献。加权读出尺度与份额集中仍是并行待检因素。

现有定理串成的约束为：**局部参与 → 选择性新息写入 → 接触保留率乘积 → 容量交换 → 未来查询实际取回。**`response_gated_vector_history_expansion` 支持在原坐标里携带历史；`held_coordinate_survives_suffix` 支持未触及的区别保持；共享池定理约束释放去向；既有读出界要求区别仍能影响预测。比较两段历史时必须核对实际注入相等，不能仅假设外界输入相同。非零实数差也不等于有限精度下可用的记忆。

一个最小条件修正是把**同一后验分配给局部写入率**，继续复用份额和内容：

```text
λᵢ = γrᵢ                  Σλᵢ = γ
cᵢ⁺ = cᵢ + λᵢ(v−cᵢ)
a⁺ = (1−γ)a + γr           Mᵢ⁺ = aᵢ⁺cᵢ⁺
```

这是可选的构造，不是从必要性唯一推出的方程。现有文件新增4条探索证明已编译、基础公理审计通过：旧规则的内容差收缩；局部写入总预算及L1界；零接触保持/匹配不写/同条件差值保留；实际加权读出的精确变化。生产区仍1768条。CPU/CUDA对实际旧核的2项恒等式测试通过，确认断点确实存在于执行公式。

**尚不替换运行算法。**虽然局部写入可以减轻无关内容的冲刷，真实读出还包含 `Σ qᵢ(aᵢ⁺−aᵢ)cᵢ`：份额下降仍可能遮住留下的内容；softmax通常也没有严格零接触。下一步须把选择性保持、可检索性与容量竞争接成同一可执行关系，并处理极小份额的浮点问题，再做匹配语言对照。不会为这三处各增一个控制器。另已修正：共享池的边际反优势不保证池内各行反垄断；使用量归一化的局部反优势也可由定理给定的Adam形式满足，不能继续笼统宣称Adam没有这一性质。本轮尚未独立审阅。

## 3. 规则怎样落到机制（手工推导）

**预测和感觉是一件事。** 联合权重 `π(i,b) ∝ a_i n_ib`。冻住内部，边界粒子的条件分布是预测（G13，个体版 `freezeOutside_balance`）。钉住字节，内部的条件分布是感觉。同一个粒子，自由时是输出，被钉住时是输入。

**信用是前 × 后 × 新息。**

1. 单一地址、槽硬寻址时，有限行池的漂移是 `x([b=b'] − n_b/Σn)`，正是 G14a，`λ=μ` 由守恒自动成立。
2. 这是特例。语言路径是软地址加 softmax：`value_future_score_factor` 说充分统计量是前向资格乘语言新息；`contact_score_unsaturated_increment` 把新息明确称为第三因子；`mixed_key_delta_differs_from_slot_assimilation` 说混合键下行池和精度写不等价。所以新息要由 T 带到位点，不能只靠行池。
3. 资格不必另开一页：`response_gated_contact_write_distinguishes` 说 S 本身能留住局部响应，`value_sensitivity_two_arrivals` 说敏感度由同一材料状态前向携带。这支持删 `Z0/ZP/ZM`。
4. 回传不必是转置：`value_future_teaching_direction_deriv`、`positive_teaching_alignment_is_local_ascent` 说准入条件只有与精确未来分数方向的可测正对齐。`reciprocal_iter_mismatch` 说配对更新能让失配几何收缩，不用预设对称。

**写在纸上后被否掉的方案：** 让槽跟着共同活动的变化走（对比 Hebb）。字节钉住再放开，变化相互抵消。

**增益。** 空行变化大，满行变化小，槽数就是精度；容量有限所以增益不归零。不被催化的行时间停止，对应 W3 和 `unused_column_kept`。W3 的比较只针对两种 EMA，这里是类比。

**记忆。** 不同种类的 `κ` 差几个量级就是 `bank_power_law_lower_bound` 要的银行；种类是慢状态，所以记忆能力由基因写初值，后天能改。持久记忆只能由吸引盆携带（`hold_vanishes`），纠错需要非线性（`linear_hold_keeps_error`），地址和锁存不能是同一状态（`contraction_has_no_two_latches`）。

**基因和可塑性。** L-1 到 L-3、O-2：世界里不变的写进基因，会变的留给槽。进化算法只调前者。

## 4. 规则解决不了的

1. **长信用。部分解决，代价没解决。** 固定下注时，前向标签就是未来对过去质量的精确导数（第 4.1 节）。开放的是代价：每个标签多一个场，就是前向敏感度的代价；下注本身也在变时没有证明。
2. **适应。一半解决。** 响应适应已由再投资给出：增长阈值就是当前预测（`grows_iff`），均值乘子恒为 1（`mean_multiplier_one`），绝对水平不起作用（`reinvest_scale`），不需要参考状态。没解决的是无输入时的持续活动：Persistence 模块的驱动环流和锁存。G25 说它需要驱动或非加性能量，字节驱动只在有字节时存在。
3. **语言付账。已决定。** 用户定为占据分布的乘性再投资。它仍是声明的合同，不是物理公理，所以覆盖表里 `predictive_growth_contract` 留在世界前提一栏。
4. **代谢的定义。已决定。** 用户定为 gross 等量交换，由 `gross_balanced` 给出。它不满足门控用的旧 `Lives.metabolizes`（要求净内容改变），过门时要用版本化目标 `balanced_exchange_persists`，这件事要在门控里显式登记。`no_exchange_iff` 的精确条件是每个活地址对到达字节的下注都等于总体预测，此时交换为零；共同预测错误也会零交换，不能由此推出交换量随预测变准而单调下降。存活判据不能只读交换量，要读组织结构（`conserving_calm_needs_organizational_viability`；第 9 节给出共同错误的代入检查）。
5. **空间分叉和隔室。一半解决。** 组合部分已证：一分为二时每次分裂加一个叶（`leaves_eq_splits_succ`），用两部分单元读 k 个部分至少要 ⌈log₂k⌉ 层且可达（`clog_leaves_le_depth`、`exists_tree_of_clog_depth`），按分裂路径命名的单元构成嵌套组（`sharedPrefix_ultrametric`）。隔室的定义现在是精确的：归一化只到组内，组总量不变，组外下注不影响组内（`local_keeps_group_total`、`local_ignores_outside`）。没解决的是几何：分裂发生在哪里、形状是什么、从 `Medium.jump` 到部分求和的桥仍未形式化，所以 G8b 只是动机。设计简报记着的“连接和隔室随经历生长没有必要性定理”仍然成立。

## 4.1 两项决定之后的推导

**两项决定是同一个事件。** 容量是有限守恒的一群份额 `a`。字节到达，`a'_i = a_i w_i / π`，`π = Σ a_i w_i`。总量不变，赢家所得等于输家所失（`gross_balanced`）。这个式子同时是复制子、贝叶斯滤波和 Kelly 下注（`wealth_eq_mixture`）。累计财富只是记账数，物理状态是份额。

**新息不用单独运来。** `w_i/π − 1` 就是到达减预测的局部形式。任何携带性状的均值变化等于性状与这个量的协方差（`price_equation`）。混合读取时，同事件信用也是局部的（`log_predicted_deriv`、`credit_eq_new_share`）。所以第 3 节“单一硬地址才成立”要改：边界事件上不需要 T 带新息，T 只剩内部位点和延迟信用要用。风险：混合读取对内容是加性的（`association_read_additive_in_contents`），非线性只来自跨时间的乘积。

**单靠再投资活不过无限流。** 份额归零后永不回来（`extinct_stays_extinct`），全押一个地址后永不离开（`concentrated_absorbing`），落后的地址按几何速度下降（`ratio_after_le`）。流一旦变化，恢复代价无上界。

**输运修这一点，并带来一个硬权衡。**

- 小输运 ε 给每个地址留地板，任何历史之后恢复代价有界（`mix_floor`、`recovers_from_floor`）。
- 把标签随质量前向携带，幸存质量里的标签比例，正是该标签在所有后续字节下的后验（`tag_fraction_eq_posterior`），也正是未来对那次事件的精确导数（`tag_is_exact_credit`）。不需要回传，质量本身就是 `delayed_credit_requires_history_carrier` 要的载体。
- 同一个 ε 同时抹掉标签：标签的可读差距每字节至少缩小到 `1 − ε/n`（`bracket_after`）。

所以恢复快和信用长不能由一个时间常数同时满足。`bank_power_law_lower_bound` 要的多时间常数银行在这里得到了一个新理由（手工连接，这条没有 Lean）。

**尺度闭合。** 一组地址的再投资，等于把这组当成一个地址、下注取组内预测（`coarse_predicted`、`coarse_reinvest`）。这是“同一生成元多个层级”的一条 Lean 依据，只对这个步骤成立。

**这些定理没有说的：** 下注 `w` 全程固定；输运除标签定理外是均匀的；没有任何身体；一生一灭只是再投资的一种实现，子代继承内容没有证明；标签数量受预算限制。稀疏编码、隔室、持续活动仍要长成后测量。

**已有工作（凭记忆，未核对）。** 标签递推就是 HMM 的前向平滑，Cappé 的在线 EM 用的是同类递推；代价上它是 RTRL。计数实现接近粒子滤波，单元只带一个祖先标签时代价低，但有路径退化。第 6 节的“压缩器级别”风险没有消失。

## 6. 风险

- **已有路线。** 去掉 T、R 和空间，就是在线 EM 学习的隐马尔可夫网络，Nessler 2013、Kappel 2014 有近似结果（凭记忆引用，未核对），上限是压缩器级别。
- **混合速度。** G13 不保证收敛，`tempo_band` 说字节率有带，ticks_per_byte 不能随便定。
- **时序方向。** 平静时内部细致平衡没有环流，时序只能来自字节驱动的瞬态。G19c 要求端持有上一符号，G24 限制弱刺激的长期保持。恒定刺激本身也能破坏细致平衡（`constant_protocol_can_be_driven`），这一点对设计有利。
- **净量读不出分量。** `conservation_does_not_identify_components`：`G − N` 只是净量，T 要靠位点读取。
- **gen3。** 容量信用曾有 99% 是抖动噪声，要预先测信噪比。

## 9. 下一步决定：内容与份额的共同学习（2026-11-03，Codex 源码复核）

**推进对象是现有候选生成律的共同转移，不回退 CBIM，也不另开载体。** CBIM 的有效写入—输运—碰撞—读出作为能力参照；果蝇与逆发育作为相互作用的经验约束；三因子、历史区别、局部增益、有限竞争和可释放保持的适用定理继续约束同一个身体。已有必要条件不能因恢复语言成绩而被删除。

首要缺口：再投资改变份额 `a`，尚未构造同一身体怎样学习下注内容 `w` 和输运关系 `T`。这不是要求另造一个预测器。当前 `GenerationReinvestment` 的 `wealth_eq_mixture` 和 `GenerationCountedPopulation.tag_is_exact_credit` 都固定 `w`；后者也固定 `T`，且每个标签另需一个场。它们不能直接作为内容可塑且总历史载体有界的完整学习实现。

已有定理已足够指出缺口，无需新增反例模块：`no_exchange_iff` 的实际陈述是“每个活地址的下注等于总体预测时不交换”，不等于“预测正确时才不交换”。取两个地址各占 `1/2`，对刚到达字节都下注 `0.01`，则总体预测为 `0.01`、更新后份额仍各为 `1/2`。这是符号代入，不是能力实验；它说明只重新分配相同预测者不会修正共同错误。它不否定具有内容学习或新候选生成的更大系统。

因此下一项工作只交付一份**可执行共同转移的设计与准入对应**，从预测前状态开始：

`已有上下文形成预测 → 先评分后到达 → 局部参与与结果共同改写内容和份额 → 在同一有限结构中保持/释放 → 后续上下文读出并再次预测`。

## 10. 联合转移：已可执行的条件参照与身体接线缺口

**后续方向更新（用户授权，2026-11-03）：**现代神经网络可直接承担可复用能力；当前实现推进见[活规格 §9.2](CGB_LANGUAGE_LIFE_MODEL_V1_20261025.md#92-当前推进复用现代递归网络推导共同学习与组织2026-11-03)。本节的混合律保留为条件参照，不再把 voxel 读出改造作为所有实现的前置，更不把概率混合公式硬套到神经隐藏特征上。

**交付范围：** [数值参照](../../scripts/audit_cgb_joint_reinvestment.py) 与 [CUDA 核对结果](../../results/published/cgb_joint_reinvestment_audit_20261103.json)。复用现有定理作代数组合，不增生产区定理或新身体。该参照以显式 logits 为可编辑坐标；它不是 `voxel_body` 的实现，也没有通过完整生命准入。

### 10.1 一次语言事件只有一份预测前快照

在一个已给定的局部竞争组内，令 `a_i = softmax(u)_i`，`p_i(b) = softmax(z_i)_b`。`a` 是有限容量的分配比例，`p` 是同一身体在已有上下文下各参与接触的预测。它们须从同一 `Z_t` 读出，不是另加两个独立预测模块。**下述推导的读出前提是混合律**：

\[
P_t(b)=\sum_i a_i p_i(b),\qquad
r_i=\frac{a_i p_i(y_t)}{P_t(y_t)}.
\]

顺序固定：`Z_t → 预测 P_t → 字节 y_t 到达并评分 −log P_t(y_t) → 计算 r → 同时提交内容与分配变化 → 纳入 y_t 形成 Z_{t+1}`。写入必须归属于预测该字节的旧上下文，不能先推进上下文再重算这次分数。`r`、`p` 与更新方向全部来自同一快照，不能先修改份额，再用新份额重算内容信用。

由 `log_predicted_deriv`、`credit_eq_new_share` 与 G14 `log_softmax_deriv` 直接展开：

\[
\frac{\partial\log P_t(y_t)}{\partial z_{ib}}
=r_i\bigl(\mathbf1_{b=y_t}-p_i(b)\bigr),\qquad
\frac{\partial\log P_t(y_t)}{\partial u_i}=r_i-a_i.
\]

所以再投资与内容学习共用 `r`。`r−a` 是 **routing logits** 的导数，也是完整再投资前后的份额差；不能因此说它是原始份额坐标 `a` 的欧氏梯度。共同错误时 `r=a` 也不意味着内容项为零。

可执行的条件更新为：

\[
a_i^+=r_i,\qquad
z_{ib}^+=z_{ib}+\eta r_i(\mathbf1_{b=y_t}-p_i(b)).
\]

第一式沿用已经选择的完整再投资；第二式实例化当前事件的 G14 方向。`η≥0` 是显式数值步长，未证明自动最优。若 `z` 是身体动力学的输出而不是自由坐标，第二式只能用作输出端信用，不能直接当作修改突触的规则。对于同时改变参与和内容的现有参数 `θ`，正确的当拍回传是

\[
\frac{\partial\log P_t(y_t)}{\partial\theta}
=\sum_i(r_i-a_i)\frac{\partial u_i}{\partial\theta}
+\sum_{ib}r_i(\mathbf1_{b=y_t}-p_i(b))
\frac{\partial z_{ib}}{\partial\theta}.
\]

这里允许共享参数，不能漏掉其中一路，也不能把已经算出的方向再当作新目标重复求导。该式只说明当前事件计算图；跨拍仍须复用实际历史载体，未证明它是自适应全历史的精确信用。

### 10.2 状态映射：哪些已经有，哪些还没有

| 数学对象 | 现有字段或协议 | 接入条件 |
|---|---|---|
| 预测前上下文 `Z_t` | `seg`、`syn`、`fld`、粒子位置及结构索引共同形成的身体状态 | 预测分数只能读到到达前的状态；短窗口内的工作快照计入资源。不是增加后缀表或外部记忆页。 |
| 容量份额 `a` | 已有占据数和 `quanta()` 总量 | 全身总量守恒不等于任意突触子组总量守恒；必须给出组的实际分配测度，并把可用态/边界交换算进去。不能直接把活动量 `Y1` 命名为守恒份额。 |
| 内容 `z` / `p` | 当前实际读出是 `site_z`；由活跃接触的有符号 `Y1` 相加而来 | 当前没有经过验证的“每个接触的条件语言分布 `p_i`”。不能凭定理中的变量名新增一张固定专家表。 |

参照只计算一个组的 `k×256` 内容与 `k` 个份额，状态及临时量均不随经历长度增长；代价为每事件 `O(256k)`，这不是完整身体成本。`r` 是可复用临时量，不逐字节追加标签。float64 仅用于核对数值恒等式，不规定运行体位宽。实际接入应利用已有接触稀疏性及分块工作区；不得按每个突触另分配一个 256 维永久表。

### 10.3 已找出的最早不相容处：两种读出不是同一种读出

`voxel_body.run_ticks` 当前把突触贡献相加成 `site_z`，边界粒子按势差游走。即使先冻结势并假设已充分混合，其分布也是 `softmax(unit·site_z)`，不是上面的 `Σ a_i p_i`；实际运行中 `site_z` 每拍还会变，有限步占据更不能直接套平衡分布。

一个代数反例已足够：两条预测为 `(0.9,0.1)`、`(0.2,0.8)`，份额均为 `1/2`。混合读出首标签概率是 `0.55`；将其对数预测按份额相加后做 softmax，概率是 `sqrt(0.18)/(sqrt(0.18)+sqrt(0.08))=0.6`。同样的局部内容与份额，在两种读出中给出不同预测和信用。无权把再投资公式直接接到现有能量读出。

**据此确定下一实现边界：保持用户选择的再投资合同，先完成现有身体状态到条件预测/份额的可执行映射，并给出其局部读出实现；在映射成立前不改反应表、不调长信用、不启动语言训练。** 若要改用能量读出的学习律，应明确修改设计合同并重新推导，不能宣称与再投资等价。这里的缺口是实现精化，不是再加一个公理。

### 10.4 已核对与仍须保留的约束

CPU 与 CUDA、256 标签、float64 的七组数值核对均通过：混合信用对即时自动微分；共享坐标的两路回传及中心差分；总量及进出平衡/并行提交；共同错误时的内容修正；评分先于目标更新；错误读出律的信用不等价；极小似然的 log 域稳定性。CUDA 梯度最大误差 `1.67e−16`，123 单位预算误差 `2.84e−14`。这是数值/接口审计，不是语言能力实验，也不是新 Lean 证明。四个复用模块 `Generation`、`GenerationReinvestment`、`GenerationCountedPopulation`、`GenerationContextAssociation` 的定向构建通过；仅有已有警告。Lean 源码未修改，定理索引不增加条目。

参照中的守恒只涉及份额；自由 logits 不是已经满足物料守恒的突触占据。实际接入还须证明同一状态坐标如何承载内容和容量，不能把份额守恒外推成身体所有更新都守恒。

| 已有结果 | 在共同转移中的作用及未越过的边界 |
|---|---|
| `reinvest_total`、`gross_balanced` | 给定混合预测与份额，完整再投资守恒；离散局部反应的实现尚缺。 |
| `no_exchange_iff`、G14 | 份额静止可与内容继续学习共存；同事件似然方向不能证明未来有益或长期保留。 |
| `local_keeps_group_total`、`local_ignores_outside`、G10c | 已给定隔室后的局部约束与特定估计问题中的局部增益必要性；不声称隔室已自动生成。 |
| `extinct_stays_extinct`、`concentrated_absorbing`、`recovers_from_floor` | 纯再投资仍存在不可恢复的边界。内容可学没有消除这点；恢复输运与保持必须在同一实际状态中实现。 |
| `tag_is_exact_credit`、`bracket_after`、历史载体必要性 | 固定模型下的标签与混合损失界可复用；对变化中的内容、有限标签数和超长历史，不能扩大结论。 |

因此本次完成的是**联合更新的条件设计、可执行参照和接线反例**。保持/释放、上下文读写与信用必须最终在同一个身体上联合成立；目前没有把数值参照升级为新载体，也没有宣布健康锁存或无限流生命已经实现。
