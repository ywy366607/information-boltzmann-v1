# Claude 原路线与当前进度对照（2026-10-25）

范围：核对原文档、现有代码、已发布结果及当前 Lean 审计库存；本轮没有重跑旧实验、训练新个体或更改动力学。旧报告中的数值按其原数据、划分和验收范围理解。

## 原目标与阶段

原入口 `BRAIN_GENERATIVE_PRINCIPLE_20261018.md` 的提案部分已由 `CONSTRUCTAL_GENERATIVE_BRAIN_FRAMEWORK_20261018.md` 取代。主线是寻找脑的生成规则：活动影响可变结构，结构改变后续活动，世界后果返回支持与改造条件；由短身份程序、相遇和局部作用生成连接，而不是直接复制成年果蝇接线。

2026-10-22 的阶段定义为：先以真实果蝇识别并检验共同生成规律，再改变初态、边界和生态位生成新脑，随后研究语言与社会交互。当前最近的语言候选与 Lean 接口成果不自动完成该历史定义下的逆发育验收，也没有证成同一机制的跨载体充分性。

## 对此前讨论的修正

“当前 Lean 尚未接入可学习边权/突触载体”与“整个项目没有相关机制”是两件事。项目已有 V2 的 K/P/z/g 和 Nf/T 原型，也已有真实数据支持的身份/相遇关系。最近的有限候选记录和来源筛选不能替代它们，也没有证明其具体更新函数全部来自一般公理。

这些资产首先是逆发育的证据与竞争假设，不是下一版必须保留的组件。当前主线应回到“现象 → 共同约束 → 最小生成规律 → 多种机制”，再决定旧代码中哪些关系保留、哪些可约化、哪些应被替代。对应 Lean 是检查这条推导的手段。

| 研究问题 | 本轮核对后的判断 | 下一步交付 |
|---|---|---|
| 逆问题：什么共同规律能解释多类真实现象？ | 已有相遇、条件身份匹配及动态保持证据，尚未由同一生成律联合解释 | 给出自由函数、观测映射与参数来源表，识别不同现象是否真正约束同一对象 |
| 正问题：一般约束能迫使什么发生？ | `ConstraintFreedom.arbitrary_driven_tables_admitted` 已证明核心条款允许任意有限驱动表；这展示一般公理的自由度，未满足额外的生命、世界或完整编码目标 | 区分必然结论、允许的构造与尚未识别的本构；不把“能学习”补成公理来完成目标 |
| 有效理论问题：怎样跨尺度而不逐个装机制？ | 同一过程投影到活动、持久结构和外界交换，可提供共同描述；投影后能否递推及保留哪些因果区别仍须证明 | 给出任务相关的状态充分性、约化适用域与误差，允许多种等价载体 |

“一个生成器”也有实质要求：把多套独立更新函数放进同一个状态向量或求和生成元，仅完成共同记法。需要由共享局部转移及其耦合推出可检验的跨现象关系；规则、参数、身份、几何和初态全部按现有编码口径计费。短规则与预算仍是约束，科学验收依靠留出预测。

## 共同生成规律的自由度审查

| 自由度 | 当前一般约束提供什么 | 仍需从现象识别什么 |
|---|---|---|
| 局部状态与允许转移 | 有限承载、局部读写和闭合收支 | 哪些状态与可观测量对应，哪些状态在约化后仍必需；具体反应图 |
| 转移核／速率 | 非负性、对称关系及特定平衡条件；离散实现另受时钟准入约束 | 驱动下的函数形式、绝对时间尺度和耦合。平衡通量比不指定完整动力学 |
| 身份与接触 | 结构等变及共享编码的检查接口 | 身份如何作用于相遇与保持；接触重组是否由同一状态过程生成。C2 的低秩是已登记选择 |
| 资源、历史与可塑性 | 条件预算、历史区别与递归闭合已有定理和有限见证 | 同一局部变化怎样同时改变未来信号、保持及资源回流；K/P/z/g 不是一般公理指定的唯一坐标 |
| 世界与观测 | 边界感知、实际反馈来源、动作配对的接口 | 真实世界的输入、后果、测量及单位映射；模拟信用与硬件焦耳分别验收 |

旧机制按这张表提供证据，接续关系如下：

| 已有机制 | 当前 Lean 能提供的检查 | 仍需对接 |
|---|---|---|
| E1–E3 活动、有限池与恢复 | 局部作用、收支、非冻结时钟、条件储备界 | 指定离散步与旧模型的关系、稳定区间、传播及工作区成本 |
| E4–E6 局部钙—酶—标签—结构 | 可读历史区别、局部可得信息、记录递归闭合 | 哪些状态可消去、剩余状态怎样携带实际可塑性信息；具体本构的来源与检验 |
| E9 支持选择与更替 | 有限资源、真实来源、收费和历史动作匹配 | 支持是否选择实际有用贡献、跨层传播和延迟范围；原高频/容量失败条件保持 |

## 最近的一步：让已有真实动态证据约束同一规律

先整理 R7 中“保持—出现／消失—数量”对同一候选过程的联合约束，接续已有的来源、观察和删失审计。选择这个切口是因为它已有真实动态数据及未解决的联合预测；不能因此预选“两态捕获”为答案。三类解释须按相同观测过程比较：

| 候选解释（H，尚未独立审核） | 区别所在 | 可以区分它的证据 |
|---|---|---|
| 固定异质性 | 个体出生时即属不同保持类型，观察期间无类型转换 | 分类型条件寿命、同一突起的状态变化；仅总体双时标不足以区分 |
| 动态捕获／共享资源 | 观察期间发生状态转换，保持与其他突起或资源状态耦合 | 同一轨迹的状态转换、数量与周转的联合关系、预先声明作用靶点的扰动 |
| 观察选择造成的表观慢尾 | 首次可见、首帧截断及漏检改变观测分布 | 固定记录规则下的前向观察模型、删失与分辨率敏感性；不靠改观察口径救模型 |

这一步已交付首个 [可识别性推导与锁定数据核验](CGB_R7_IDENTIFIABILITY_20261025.md)：固定差异与动态捕获能精确匹配相同寿命；若独立出现过程也相同，数量与周转仍可相同。两者在原 149＋72 条新出现轨迹上复现相同评分。额外假定捕获态等于可见 Bulbous 时，条件期望正标记约 27.32，实际为 1；该差距审查的是过程与观测映射的组合，不能据此否定一切捕获。推导及竞争解释尚未独立审核，未新增 Lean 证明。

具体接续顺序：

1. 锁定已读过的完整 Control GC1/2 发现集、GC3 历史测试及突变／恢复资料各自的使用记录。完整 Control 没有 GC4，Bulbous 的 GC4 不能替代；已看过的结果不重新声称盲留出。
2. 将已推出的观察等价作为候选筛选约束；同一独立寿命过程的数量／周转拟合不再承担区分固定差异和动态捕获的任务。它们仍可检验具体的独立、平稳及初态闭合。
3. 优先确认状态标记的观测对应、转换记录及扰动靶点，固定允许改变的参数和预测恒等式，再评分可用资料；不靠给隐藏态补漏检率救已有解释。
4. 只为有决策价值的条件关系补 Lean 证明或反例；通过后才实现更大的统一过程，并逐步加入已有身份／相遇约束。R7 局部通过仍只是逆发育的一步。

接续的[状态证据与粗粒化推导](CGB_R7_IDENTIFIABILITY_20261025.md#6-无须先选择捕获载体的相遇保持转化关系)已核对来源文件与标记字段：Control 有三条部分时长标记，跨表同数字 ID 不能直接配对；真实自噬组别也未识别为两态核的单参数干预。新的候选共同接口是 `Q(r)=rΣ(1−r)^n S(n)`，在明确独立试验条件下把保持时窗与局部转化联系起来，允许等价载体粗粒化及有限展开误差界。加入实际相遇强度后得到首次成功通量候选 `J=λQ(r)`；现有资料尚未共同标定这三项，不能据公式宣称脑生成或真实功能已通过。

最终目标是在声明范围内，用有限描述的共同规律，在果蝇条件下正向生成并通过结构、动态及功能证据；之后改变边界、初态和已登记参数，检验是否生成新的适应方式。语言模型与 Tensor Logic、注意力或状态空间算子位于这条路线的实现层。现有语言规格中的固定图、三值存储和局部信用均是待筛选候选，选择要接受生成规律的约束。

原路线审查未新增公理或实验结果；接续的可识别性工作增加纸面推导、精确核验及历史数据的探索性标记检查，没有训练、重拟合或改动动力学。机制解释与后续方案尚未独立审核。
