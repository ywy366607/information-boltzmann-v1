## 1. 保留原模板，补它实际消耗的反应物

E5已有钙、激酶、磷酸酶和标签。E6已有受有限槽位约束的结构转化。E9已有基础支持、标签捕获和支持降低更替。不另造一套学习规则。

先把**结构占据量n_e**和电导g_e分开。n_e是相同结构单元的占据数，容量S_e；每个单元含χ份底物。只有单元电导相同、无额外相互作用的有效区间，才可写g_e=ĝ_e n_e。原V2的g到实际结构量的映射仍需校准；这里不从材料守恒推定真实突触电导。

由有限槽位和物料转化，写出局部反应：

    χ B_i + 空槽位_e  --活化催化物-->  已占结构_e
    已占结构_e  --分解催化物-->  空槽位_e + rχ B_i + (1-r)χ W_i

χ是结构单元的组成计量，不是把多个底物分子的反应级数也设为χ。采用可利用单体在催化步骤中一阶进入的有效反应描述：

    p_e = k⁺_e b_i (S_e-n_e)
    d_e = k⁻_e n_e
    dn_e/dt = p_e-d_e

这一步的适用假设：同一个局部供体内混合快于结构转化，槽位与催化物的有效反应级数已明确。非均匀情况下把b_i换成边端的局部浓度，并保留输运；不能靠重命名“局部”略去真实输运。

E6的既有正/负标签催化项作为速率来源。若以参考浓度b_ref恢复旧模板的尺度，可识别：

    k⁺_e = η m_e [z_e]₊ / (b_ref S_e)
    k⁻_e = η m_e [z_e]₋ / S_e + λ(T_e)

在b_i=b_ref且g/n的单位已经对应时，恰好回到原E6；有限b进入的只有合成端。这里继承m≥0的有效催化占据；受体符号翻转应体现在正、负催化通道的来源，而不能把负浓度放进质量作用。

共享池的方程由化学计量直接给出：

    db_i/dt = Q_i-γ_i b_i-χ Σ_{e∈i} p_e+rχ Σ_{e∈i} d_e
    dW_i/dt = γ_i b_i+(1-r)χ Σ_{e∈i} d_e

因此：

    d[b_i+χΣ n_e+W_i]/dt = Q_i

反应在n=0、n=S、b=0处都指向可行域：不能从空结构拆解、不能越过容量、没有底物便不能合成。无需先提出越界增长再裁剪库存，也没有新增行为设定点。

**原接口漏掉的通量。** 若p=d>0，结构净变化为零，但仍消耗(1-r)χd的材料。仅由max(Δn,0)与max(-Δn,0)记账会看不见这股周转。本轮实现分别返回formed、dismantled与discarded，保留真实总反应通量。

### 1.1 槽位占据公式什么时候成立

固定b和催化率，平衡给出：

    n*/S = k⁺b/(k⁺b+k⁻) = sigmoid[log(k⁺b/k⁻)]

这推导了占据型sigmoid的来源。它没有识别“统计预测的对数突触数”等于log(k⁺b/k⁻)；原birth.py的强度→电导映射不能仅因形式相同就通过机制准入。V3d仍用于识别身份匹配，而组成、槽位容量、速率与电导的对应单独识别。

### 1.2 有限速率的非负求解

一步内冻结催化率，使用隐式Euler而非瞬时分库存。设步长h：

    n_e¹ = [n_e⁰+h k⁺_e b_i¹ S_e]/[1+h k⁻_e+h k⁺_e b_i¹]

对每个供体，未知b_i¹满足一个标量方程：

    F_i(b)=(1+hγ_i)b
           +χΣ_e{[1+(1-r)h k⁻_e] n_e¹(b)-n_e⁰}
           -b_i⁰-hQ_i = 0

其导数：

    dn_e¹/db = h k⁺_e [S_e(1+h k⁻_e)-n_e⁰]
                /[1+h k⁻_e+h k⁺_e b]² ≥ 0
    F_i'(b) ≥ 1

又有F_i(0)≤0，而在b=b_i⁰+hQ_i+χΣn_e⁰处F_i≥0，故存在唯一非负解。n_e¹是位于[0,S_e]内的凸式，不需要裁剪。离散总通量取h p_e¹、h d_e¹；按同一时刻计费，完整计量恒等式逐步成立。

这是冻结催化率的一阶数值方法，不冒充连续动力学解析解。64次标量二分仅为求根精度，不是物理速率、学习窗口或分枝上限。所有供体并行求根，工作量O(64(E+N))，当前验证实现用float64，工作区随当前图而非历史长度增长；它还不是优化后的事件驱动引擎。

### 1.3 材料账与能量账不混同

上式只闭合结构物料。催化物和电活动仍需能量/燃料；不可把r=1的材料回收解释成永动生命。若要求反应有明确热力学能量解释，需写局部反应亲和势及燃料化学势，并满足局部详细平衡；“任意非负速率＋物料守恒”本身不证明热力学一致。开放反应网络的这一要求可对照[Rao与Esposito的原始工作](https://journals.aps.org/prx/abstract/10.1103/PhysRevX.6.041064)。

维护反应也应沿同样方式消耗其实际底物并影响可持续反应率，而非仅积累unpaid。这里没有补入欠款死亡阈值，也没有宣称整个能量/生存闭环已经完成。

## 2. 从有限池到空间分化，条件直接由方程算

沿§2.3已有的“近处活化、远处竞争”，令a为慢扩散的局部活化形态，b为较快输运的游离形态，同一物质在两种形态间转换：

    ∂_t a = D_a ∇²a+f(a,b)
    ∂_t b = D_b ∇²b-f(a,b)

封闭无通量边界下∫(a+b)守恒；扩散差和局部转换共同决定分化。这里没有选择一个为了长分枝而手编的f；先对任一已由反应网络给定的f推导可检验条件。这与质量重分配理论的物理结构一致，见[Brauns、Halatek与Frey的原始工作](https://journals.aps.org/prx/abstract/10.1103/PhysRevX.10.041036)。

在均匀平衡(a*,b*)处，记f_a、f_b为局部导数。空间波数平方q=k²对应线性矩阵：

    L(q) = [[ f_a-D_a q,       f_b ],
            [    -f_a,   -f_b-D_b q ]]

于是：

    trace L = f_a-f_b-(D_a+D_b)q
    det L = q[D_a D_b q+D_a f_b-D_b f_a]

若局部固定总量下稳定，即f_a-f_b<0，而D_b f_a-D_a f_b>0，则出现正增长空间模态：

    0<q<q_c,  q_c=(D_b f_a-D_a f_b)/(D_a D_b)

无通量一维区间长L的允许模态q_n=(nπ/L)²。第一个不均匀模态出现的必要线性条件为：

    L > π/sqrt(q_c)

因此尺寸、局部反应斜率与输运决定何时能分化；不是先给每个细胞指定“分叉B次”。q=0有一个守恒零模，表示总量改变方向，不应误报为形态不稳定。

**需要从原回路算的项。** 固定钙输入时，E5单个K池的局部导数为−α_K h_K(c)−1/τ_K<0，不能单凭“K池存在”就断言满足上述条件。需要从已有E1膜→E4钙→E5酶→E6结构→电流的闭环计算实际增益。若快速变量y的局部Jacobian A稳定，消去它们后，慢活化的有效导数是：

    f_a^eff = f_a-f_y A^{-1} B,  其中δẏ=Aδy+Bδa

该消去要求时间尺度分离；不满足时保留全Jacobian及空间输运求谱，不能预填一个正的f_a代替计算。

### 2.1 已从E1/E4/E5/E6算出的亚阈值闭环导数

先选择可核对的解析极限：无放电、快变量在局部已松弛、固定外源电流和受体占据、滑动阈值固定。设每结构单元的电导ĝ，快受体占据o，E为该输入反转电位：

    D=g_L+ĝ n o
    u*=[g_L E_L+ĝ n o E+I]/D
    du*/dn=ĝ o(E-u*)/D

兴奋与抑制的符号由驱动力E-u*给出，不手填正反馈。令B(u)为原E4解阻断函数：

    c*=τ_c k_N o_N B(u*)
    dc*/dn=τ_c k_N o_N B'(u*) du*/dn
    K*=α_K τ_K h_K(c*)/[1+α_K τ_K h_K(c*)]
    dK*/dc=α_K τ_K h_K'(c*)/[1+α_K τ_K h_K(c*)]²

P的表达式相同，使用自身参数。因而：

    z*=(K*-P*)/(m+1/τ_z)
    dz*/dn=[dK*/dc-dP*/dc](dc*/dn)/(m+1/τ_z)

再用第1节已推导的k⁺、k⁻：

    f(n,b)=k⁺(n)b(S-n)-k⁻(n)n
    ∂f/∂n=b(S-n)dk⁺/dn-k⁺b-n dk⁻/dn-k⁻
    ∂f/∂b=k⁺(S-n)

正、负标签分支分别求导；z=0处用单侧导数或保留完整动力学。在当前亚阈值极限，这给出了由原回路计算局部增益的方法，已用数值微分逐项核对。对真实脉冲工作点还需保留/测量放电与回传、时间尺度、实际占据及平衡条件，不能用这条极限公式冒充全脑增益测量。

此外，结构n是锚定结构时不应擅加D_n扩散。第2节的a若代表可输运的活化组分，需要用其真实输运和反应Jacobian；若研究n的形态变化，应联立下一节界面运动。不能为了套用不稳定波数带而给固定边权发明一个扩散率。回收不完全、外源供给或清除也会破坏两态闭合守恒，此时应使用实际源汇扩展后的完整矩阵。

上述结果证明的是空间模式的准入条件。一个模式是否形成持久极性、多个活跃前端、或最终只剩一个峰，取决于非线性和几何；不能把Turing/质量重分配不稳定等同于已得到轴突分叉。

### 2.2 局部胜出成为上层单元：竞争的组织层级

用户进一步提出：局部赢家形成一个有效功能单元后，它的长期存在由更大尺度的竞争决定；连续跨层仍能支持个体与世界闭环的结构，逐步成为核心。这里的“升层”是有效规律与支持边界的改变，不是给胜者免除成本，也不是再放置一个外部裁判。

这直接沿用原文§2.2–§2.3的跨层闭环与§5支持逆向传递。设A_i是一个细单元拥有的支持因子总量，包含它已有的游离、结合和输运形态；具体反应仍保留各形态，不能只凭总量就抹去其时延。下游j向其上游i转移支持的实际通量为R_{j→i}≥0。最基本的计量为：

    dA_i/dt = q_i^ext+Σ_j R_{j→i}-Σ_k R_{i→k}-C_i-L_i

C_i与L_i分别是实际消耗/失活损失；q^ext是从当前考察边界外进入的源。每笔转移在付款端是汇、收款端是源。若转移由既有标签捕获实现，速率取局部质量作用κ·[z_ij]₊·N_j，N_j是实际游离因子；结合、胞内运输和再释放也各自扣掉对应来源，不能复制一份支持再向上付款。

对任意模块M求和，内部转移严格抵消：

    dA_M/dt = Σ_{i∈M} q_i^ext
              +Σ_{j∉M,i∈M} R_{j→i}
              -Σ_{i∈M,k∉M} R_{i→k}
              -Σ_{i∈M}(C_i+L_i)

因此模块在上层仍满足同一种连续性方程。局部组成部分的竞争并没有消失：它形成了一个带内部记忆、输入输出端口和维持成本的整体，整体能否持续支付内部结构，取决于跨模块边界获得的支持。这是所提层级关系的守恒表达，不新增每层评分函数。

**三条实现要求：**

- 模块化不能重复领取基础供给或初始材料；q^ext随考察边界改变身份，不能每升一层就成为新生成的资源。无外源且C/L非负时，内部循环转移不能使总支持增加。
- 上式的收支聚合是精确的，但功能约化不因此自动闭合。只有模块在某时间尺度有可复现的端口规律，才能作为上层有效单元；内部状态仍保留，不为“升层”删除真实结构或冻结其可塑性。
- 原V2只有一段局部摄取/支持。后续已将可关闭的“摄取→运输池→再释放”有效动力学接入Medium，T→H→Nf逐笔转移，不把Q_i∝T_i当作无偿源项。质量守恒由通量结构给出；一阶驻留速率仍是需要识别的候选，不是由守恒唯一确定的真实轴突动力学。参见[比较方案与运行前登记](CGB_SUPPORT_TRANSPORT_PREREG_20261021.md)。世界后果调制、几何运输和有用结构的跨层选择仍待检验。

最外层同时有**世界信息边界**与**物质/能量边界**：真实输入和行动后果检验结构贡献；支持因子的合成与输运仍支付有限物料/能量。语言输入不是凭空生成支持分子的材料源。标签选择是否识别了贡献，仍用同状态因果干预验证，收支正确不能替代这项证据。

因而“核心”可定义为跨输入、跨时间和跨层协作仍持续参与闭环的稳定结构，不是永远免检的赢家。外界改变后，核心也可能重组；不应期限制短时放电，不能用它否定长期有用记忆的稳定性。

**逐跳支持的解析检验。** 在上述传递候选冻结实际载体、φ=0时，消去终扣与胞体驻留池可得`s=q+Ws`，其中`W_pre,post += [ν/(ν+δT)] [ρ/(ρ+δH)] a_e/(δF+Σ_in a)`。只要退出率和游离清除为正，列和<1；`W²q`给出两次返回通量，而不是从结构相连就认定跨层支持存在。此只读诊断和保持旧库存的新来源标记已实现；实际对照显示标签与活动捕获的远端可达性不同，参见[推导、登记](CGB_REMOTE_SUPPORT_PREREG_20261021.md)及[结果](CGB_REMOTE_SUPPORT_RESULTS_20261021.md)。

### 2.3 稀缺由参与者反过来塑造：从现有材料方程推出

瞬时份额受限不意味着开放过程是零和。对n_i>0，令X=Σn_i、π_i=n_i/X、r_i=ṉ_i/n_i，恒等地有：

    dπ_i/dt=π_i(r_i-Σ_j π_j r_j),  Σ_i dπ_i/dt=0

份额之和不变，但X可以增长、衰退或重组；没有给细胞写入一个“想赢”的目标。

使用第1节既有合成/拆解与开放底物池，先考察N个参数相同、每个容量S有限的结构。在稳态：

    n*(b)=k⁺bS/(k⁺b+k⁻)
    Q=γb+(1-r)χN k⁻ n*(b)

只要回收有损、反应和清除允许该稳态，隐函数给出：

    db*/dN=-(1-r)χk⁻ n*(b*)
             /[γ+(1-r)χN k⁻ dn*/db] < 0

这里N是对同时占用供给的结构数作连续敏感性分析，实际结构数仍为整数。参与者增加会压低底物，减少后底物回升；这个反馈由原反应和有限补给产生，不用额外设一个稀缺性调度器。若幸存者可以无限扩张，总需求仍可能吃满供给，因此决定稀缺的是总消耗与补给，而非头数本身。

**共享竞争不自动产生分化。** 在封闭完全回收的同一材料池中，b=M−χΣn_i。令单元局部反应ṉ_i=f(n_i,b)，均匀点的α=∂f/∂n、β=∂f/∂b≥0，则：

    J=αI−χβ11ᵀ
    总量模态：λ_total=α−χNβ
    差异模态：λ_contrast=α，重数N−1

共享池提供总量的负反馈；局部差异是否放大仍由原回路的α决定。对于固定k⁺、k⁻的槽位反应，α=−k⁺b−k⁻<0，同质竞争可稳定共存。若膜—钙—标签反馈使α>0，微小差异才有可能放大。精确相同的确定性初态不会凭空产生差异，实际反应涨落、输入/位置与身份差异提供扰动来源。

持续分工还需看优势是否随空间、输入和时间改变，以及已解决的输入是否降低新增支持机会。竞争同一个无差别池，可能走向同质共存或少数垄断；有不同局部机会时，争夺重叠部分与互补协作才可能一起维持多样性。不能另加多样性奖励或强制均匀份额来替代这些关系。

### 2.4 不应期限制当下占用；跨层有用性决定长期保留

钠通道按原E2在每次脉冲后失活，再有限速率恢复：

    r⁺=(1-κ_r)r⁻,  r(t)=1−(1−r⁺)exp(−t/τ_r)

如果一细胞以固定间隔Δ反复放电，周期稳态允许：

    r⁻=[1−exp(−Δ/τ_r)]/[1−(1−κ_r)exp(−Δ/τ_r)]

可见有不应期仍允许同一细胞反复占优；是否轮替要联立其他候选及抑制回路。囊泡耗竭在原E3的恒定平均脉冲率f极限给出：

    v*=1/(1+Ufτ_v)
    释放通量=Uf/(1+Ufτ_v)

释放通量封顶，却仍随f单调增加。Claude的T1已经验证：释放封顶不等于大耦合下活动也封顶，快钠池也不等于慢适应。二者都是限制持续占用的物理反馈，而非永久垄断必然不稳定的证明。

若更慢的离子/通道池在赢家活跃时逐渐耗竭或增加抑制，可使其优势随时间下降；只有其他结构随后能接替，才出现活动轮替。原V2的慢A池目前调增强阈值，不能当作已接入膜电流的慢适应。

组织层级与时间尺度必须分开：局部活动可以暂时选出赢家，形成的功能单元可以长期稳定，同时接受更大闭环的支持与成本约束。我们需要检验的是跨层贡献、候选的可接替性及恢复后可再次参与，不是让所有稳定状态都失稳。无永久活动赢家的轨迹编码可参考[Rabinovich等的原始研究](https://journals.aps.org/prl/abstract/10.1103/PhysRevLett.87.068102)；资源空间峰也可能持续粗化至少数域，源汇在特定条件下可使粗化停下，见[Brauns等的原始研究](https://journals.aps.org/prl/abstract/10.1103/PhysRevLett.126.104101)。这些结果不替代本模型的跨层检验。

## 3. 伸长和回收从局部物料通量换成几何

设已有界面上一小片面积dA，结构质量密度ρ_s；向外法向速度v_n。界面在dt内增加体积v_n dA dt，所需结构质量ρ_s v_n dA dt。若该处单位面积的实际合成/拆解质量通量为j⁺、j⁻，直接由局部质量守恒得：

    v_n=(j⁺-j⁻)/ρ_s

这给出伸长/缩回速度的来源；方向来自实际界面的法向与局部活化分布，不来自手设朝目标质心的方向混合。对截面积A、长度L的等密度细缆线，同样有ρ_s A dL/dt=净结构质量输入。

还需在界面处联立底物输运和反应边界条件，让被吃掉的底物确实从相邻池流出。若ρ_s变化，必须保留密度连续性，不能继续使用常密度式。

**完整分叉所需闭合。** 以上为运动学，不单独决定可行形状。必须将第2节的空间活化、局部材料输运和具体膜/骨架力学边界条件联立，求非线性界面演化，检查活跃前端能否分裂并保持连接。当前尚没有给出这套完整自由边界本构；停在这里的是具体物理关系尚待识别/推导，不是已经证明原文第一性原理不足。不会用随机分叉概率或指定树形替换这一处。

## 4. 文档中的构形标度，在哪些条件下能推出

先只考察固定源汇、准稳态被动输运子系统；设连接方向、通量约束给定，物理耗散满足：

    R = min_{div J=s} Σ_e J_e²/g_e + λΣ_e g_e^γ,  γ>0

对g求变分，流J必须先满足相应准稳态；包络关系给出：

    ∂R/∂g_e = -J_e²/g_e²+λγ g_e^(γ-1)
    g_e*=[J_e²/(λγ)]^(1/(γ+1))

慢变化下以实际快流平均，有g*∝⟨J²⟩^(1/(γ+1))；只有波形缩放等条件使⟨J²⟩与⟨|J|⟩²成比例时，才可写主文中的⟨|J|⟩^(2/(γ+1))。原R使用线性维护项时γ=1，给出g∝sqrt(⟨J²⟩)。

这推导了既定输运/成本假设下的构形极值，不自动证明E5/E6会实现这条梯度，也没有证明网络会选择某种拓扑。有源神经元、脉冲、反转电位及行为改变源汇时，必须联立燃料功与开放边界功；NLL不是热力学能量，不能直接放入R后把梯度叫物理生长。

因此下一步需要比较**由局部反应算出的真实结构通量**与上述被动子系统极限，而不是为了得到目标指数又添加一条独立塑形规则。

## 5. 已实现的数值核对及继续顺序

`information_boltzmann/cgb/material_reactions.py`实现第1节冻结速率的局部反应求解、第2节线性谱与§2.1的亚阈值回路导数；没有改旧介质、存档或正式出生默认入口。
