# 语言生命体的嘴：设计（2026-10-28）

只做设计与 Lean，不跑实验。关系图见 `CGB_THEOREM_RELATION_MAP_20261028.md`；本文件只写嘴（说、问、听、节奏）这一块。

**一句话**：嘴是信息世界里的觅食器官。说话不另设价格；它的代价全部来自两个有限身体自身的容量、记忆和弛豫，加上"说的时候不能听"的机会成本。

## 2. 新证：N7 语速（`GenerationSpeechTempo.lean`，2026-10-28，构建与审计通过）

模型：说话者以速率 r 发出单位，有效速率
`useful = min(r, C) · exp(−1/(rτ)) · (1 − exp(−kL/r))`
三个因子分别是：听者每拍最多吸收 C；前文跨过间隔 1/r 后的保留（G20a）；说话者每个单位分到 k/r 次内部反应时的弛豫程度（`unsettled_eq_rpow` 把它连到 (1−α)^(k/r)）。

| 定理 | 内容 |
|---|---|
| `useful_le_rate`、`useful_le_capacity`、`useful_le_inv_rate` | 有效速率 ≤ r，≤ C，≤ C·k·L / r |
| **`tempo_band`（N7）** | 只要某个语速能达到有效速率 u > 0，那么所有慢于 u、或快于 C·k·L / u 的语速都更差。好的语速是一个有界的带，上界同时由**听者容量 C** 和**说话者思考速度 kL** 决定 |
| `slow_retention_vanishes` | 太慢：每个单位都接不上前文（"说到后面忘了前面"），与听者容量无关 |
| `fast_settling_vanishes` | 太快：每个单位都没弛豫好（"没想清楚就说出去"），与听者容量无关 |
| `peaks_wasted`、`uniform_attains` | 均匀信息密度：每格容量为 C 时，n 格最多吸收 min(Σx, nC)，均匀分布正好达到。超过容量的峰值白白丢掉；均匀分布是被迫的，不是一种风格 |

定理里没有任何代价项，所以"无意义的能量"不存在。

## 3. 由已有定理直接推出（不需要新证，只是代入）

1. **Goldilocks（中等可预测处学得最多）= N5 + `agreement_no_write`**
   - 已学会的源：预测准确，什么也不写，进展为零。
   - 纯噪声：意外很大，但它的规律（均匀分布）描述很短，按 N5 能教的总量很小。
   - 学得最多的地方是"有结构、规律长、还没学会"的源。
   - 生物：Kidd、Piantadosi、Aslin 2012，婴儿在复杂度最低和最高的刺激上最容易移开视线。
   - 所以学习进展（Oudeyer 的 competence progress）不是外加的奖励，而是 N5 下可学余量的消耗速率。
2. **锚定话题 vs 提问 = C-1**
   - 当前话题的学习进展 q ≥ 别处平均 c：留下（锚定，继续说这个话题让对方继续给）。
   - q < c：离开（提问，换一块地）。
   - c 不能直接感到，要从近期历史估计（G10–G13）。这就是你说的"基准"，也是 GRPO 组均值的同一结构。
3. **回应必须依赖于我说的话（contingency）= N2**
   - 若妈妈的回应只取决于她自己的状态、与孩子说了什么无关，那么回应关于"孩子的行动"不带任何信息：嘴学不到任何东西。
   - 生物：Goldstein、King、West 2003（PNAS）。母亲按婴儿发声**适时**回应时，婴儿的咿呀变得更复杂、更成熟，且停止操控后仍保持；**非适时**的同样多回应没有这种效果。鸣禽的社会塑造是同一机制。
   - 这是对妈妈的唯一要求（关系图 §9 第 3 条），而且对 LLM 天然成立；不要求妈妈满足我们的公理。
4. **轮流说话 = `peaks_wasted` 用在共享信道上**
   - 两人同时在一条信道上说，那一格超过容量，丢掉的是双方的。
   - 只要信道共享，轮流就是被迫的，不需要手写"轮到谁"的规则。
   - 生物：轮次间隔通常约 200 ms，而产出一句话的延迟超过 600 ms（Levinson & Torreira 2015）。说明听者在对方说完之前就在预测结尾、准备回应：理解和产出重叠。在我们这里，这就是 G13 的前瞻：没有前瞻的身体只能等对方说完再想，间隔会长于它自己的弛豫时间。
5. **只听不问不能持续 = N4**：已在关系图 §6。睡眠/冬眠是 c 暂时变高的时段，有限。

## 4. 为什么 LLM 不受这些限制

它们在每条定理的假设之外：
- 上下文窗口内不遗忘（τ → ∞），所以没有 `slow_retention_vanishes`；
- 权重冻结、不在线学习，所以不需要锚定话题、慢慢消化；
- "想"就是"写"，没有独立的弛豫，所以"没想清楚就说"是它的常态；
- 读写不花代价，写的人没有 C 的约束。

**但读者仍在假设之内**：`peaks_wasted` 对读者的 C 依然成立。

GRPO 一类的长度控制（Kimi k1.5 的组内长度奖励、DAPO 的超长惩罚、余弦长度奖励、L1 的目标长度）都在写的一侧手设价格。Dr. GRPO 还发现，有一部分变长只是按长度归一化造成的记账偏差。它们都没有把读者放进模型。

我们的生命体不需要外加信道容量就能感受到这个代价（2026-10-28 用户决定）：它**自听**，所以它说的每个字也要经过它自己的耳朵，受它自己的 C、k、τ 约束。说话者同时是自己的第一个听者，N7 的带直接作用在它身上。妈妈那一侧不加任何限制。

## 5. 生成原理：放进去什么，让什么长出来

**放进去的（根 + 世界条件）**

| | 条件 | 性质 |
|---|---|---|
| W1 | 妈妈的回应依赖于孩子说的话 | 唯一的交互要求（N2 推出） |
| W2 | 自听：嘴的输出回到自己的感受器，和妈妈的话走同一个耳朵 | 边界物理；自我模型的来源（自听回应完全依赖于行动，N2 下是最强的依赖）；轮流由 `peaks_wasted` 在这只耳朵上推出 |
| W3 | 身体有限：每字节 k 次反应、记忆时间常数 τ、写入预算 | 已有（有限身体） |
| W4 | 嘴是一个普通的门控输出反应，与其他反应用同一个生成器 | 不为嘴单独设计机制 |

**不放进去、应该长出来的（现象，预注册的预测）**

| 预测 | 来源 | 证伪方式 |
|---|---|---|
| P1 先咿呀（自听的发声-听觉回路），后有词 | Oudeyer 的自组织阶段；Goldstein | 发声复杂度随发育单调上升；先于对妈妈的模仿 |
| P2 话题进展下降时提问增多 | C-1 | 按当前话题的进展分组，看提问率 |
| P3 适时的妈妈胜过非适时（回放另一会话的回应）的妈妈 | N2 + Goldstein | 活体对照：同一身体，妈妈换成 yoked 回放。这是语言层的"闭环 vs 致盲"门 |
| P4 发声速率落在一个带内，随 C、k、τ 移动 | N7 | 改信道容量，看速率带是否随之移动 |
| P5 对中等可预测的输入投入最多（停留、追问） | §3.1 | 对可预测性分档 |
| P6 轮次间隔短于自身产出延迟（若有前瞻） | G13 + Levinson | 测间隔分布 vs 弛豫时间 |
| P7 跨语言的信息率趋同 | Coupé 等 2019：17 种语言约 39 bit/s，信息密度高的语言说得慢 | 只能在多语言下看；作为 N7 的旁证 |

**生成器的表达力义务**（待证，先于实现）
- E-mouth：生成器能表达"把学习进展和近期平均比较，再触发输出"这条通路（C-1 的估计 + 门控）。
- E-tempo：生成器能表达一个内部时钟或积累器，使输出间隔受内部弛豫状态门控（输出前等弛豫到位）。

生物参照：言语的音节节律约 4–8 Hz，正好与皮层 θ 振荡相符（Giraud & Poeppel 2012）。节律是听者切分输入的时钟，也约束说话者。在我们这里不手放振荡器；N7 说明速率带由 C、k、τ 决定，振荡（若出现）是 A 类被驱动循环在这一带内的现象。

## 6. 设计问题

**已定（2026-10-28，用户）**
- 自听：要。自我模型从这里来（见 W2）。
- 信道容量：不外加。自听已经让 N7 作用在说话者自己身上（§4）。
- 储备：不另设储备页。语言生命体的"储备"就是它学到的模型本身：不摄入时被强制遗忘（G16a、G20a）侵蚀，摄入（学习）时恢复，这正是"活 = 可恢复的摄入"所要求的那个量。读数：它对流的编码长度。已核 `OperationalLife.alive`：它只要求总含量 `M.total > 0`，以及在时间范围内碰到一次 `materialIntake` 的概率。它不规定储备在哪一页，所以记忆可以充当储备。条件是：学习必须是边界驱动、**提高含量**的交换（耦合 (b)）。如果学习只是在含量不变的前提下改写状态，那么摄入为零，"活"就失去了内容。
- 语言：英文。

**还开着**
1. **供养**：可学的余量随妈妈的回应一起来（回应依赖于行动，§3.3）；除此之外是否还要一个不依赖行动的背景流（关系图 §9 第 1 条）。
2. **规模与手机约束**（`project-life-must-run-on-a-phone`）。
3. **数值从哪来**：生成器里有很多数（每字节的反应次数、遗忘时间常数、门的强度……）。它们只有三个可能的来源：
   - 跨代选择：搜索很多个体，留下好的。这等于训练，用户不想要。
   - 定理：给出允许的范围（例如 N7 的带）。
   - 个体自己的发育和学习：在一生中把数调到范围里。

   我倾向后两者结合：定理定范围，发育定数值。
