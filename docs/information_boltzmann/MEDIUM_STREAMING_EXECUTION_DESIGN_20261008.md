# 持续介质的可用执行方案：传播跨输入，近期输入有短物理路由

日期：2026-10-08。状态：流水候选已实现并进入完整窗口资源验收；原长等待个体的出生检查点保留。本文件取代“资源校准通过就直接运行约20天”的执行决定；已有数值、资源结果保留其原范围。

## 1. 目标与事实

目标是可实际训练和部署的连续个体：D768、8³、有限可学读写口、可学习材料与方向、持续物理状态、完整32事件学习窗口。能力仍以真实OWT首次预测、语境迁移的恢复速度与恢复平台、重访保留评价；资源预算为3072MiB专用显存。

已确认：

- 完整长区间候选：每事件28次观察、112次全场微步；32个真实targets的两窗口耗时344.66/321.28秒，采样专用峰值2490.64MiB，2次AdamW更新完成。这证明数值/资源可执行，实际成本使当前长训练不可用。
- 原D768/8³个体最后两组实际耗时1.9472/2.6772秒/32targets。它的短输入区间与目标配置不同，仅证明相同D和网格已有秒级可运行实现，不能据此声称新机制也同速或能力相同。
- `factor_characteristic_time` 的全域参考是出生几何与最快材料速度的定标，不是每个新输入必须等待的定律。当前将它设为每token间隔，是可以重新选择的输入/材料耦合假设。
- 原始前向每事件有62次全512节点的固定读坐标变换，约18.723G MAC。实际变换具有Householder结构，可精确代数改写。碰撞角度与电导网络另有约69.132G MAC/event，是真正的可学习计算；MAC比例不是墙钟占比。

## 2. 三种问题重构与竞争路线

| 问题表述 | 对应路线 | 决策 |
|---|---|---|
| 同一离散映射算得浪费 | 保留112步，结构化坐标变换、有限线性探针重排、融合与共享回放 | 采用确定的等价消冗余；单项无法保证实用速度 |
| 长物理区间求解过细 | 保持每token全域时间，改Cayley/指数等长步积分 | 暂不选；局部非线性耦合与相位精度仍需证明，稳定不等于准确 |
| 将空间传播延迟误设为每token服务时间 | 在同一持续介质中流水输入，深路径跨后续输入运行 | **唯一主候选**；先闭合近期有限物理路由，再验收速度 |

低深度的新事件动力学模型作为以后独立候选，不在这轮叠加。当前方案不增加世界模型、旁路token网络或新的全场接口。

## 3. 唯一候选的时序与状态

外部输入到达时间、材料的自主弛豫/传播时间、数值求解精度分别声明。每个新词不再等一次全域传播结束；旧信号与通量、电导、STP、适应变量、时间探针历史始终留在同一介质中，跨后续词继续演化。

以先预测当前观察的接口写为：

\[
S_n^-=\Phi_\theta(\Delta_n,S_{n-1}^+),\quad
p_n=\operatorname{Decode}_\theta(R_\theta S_n^-),\quad
\ell_n=-\log p_n(x_n),\quad
S_n^+=W_\theta(S_n^-,x_n).
\]

当前实际观察在预测封存、评分后仅写入一次。与已有“写已知前词→推进→预测下一词”表示等价时必须显式核对carry/桥接，防止重复写入或漏写。状态从不因输入、评估或窗口切换清空。

有限W/R口之间需有可分辨的短物理响应，及时处理最近输入；深部路径同时处理更早上下文。端口继续可学、允许部分重叠并保留总口径预算；数值验收另用近邻分离口确认存在真正经过输运的路径。瞬时读出含motion RHS的邻接依赖，验收必须纳入该通道。

对于无时间戳的OWT，输入与材料的相对时间仍需一个声明的出生定标。本候选以短接口物理路由及出生材料为依据，冻结这个物理参考；当前8³一个局部时间尺度0.0332724可作初值，solver上限0.00831809时名义约4微步/输入。**4是该初值和求解精度产生的数量，不是新的固定思考层数。** 后续网格细化保持物理输入参考，只改变数值步数。时长控制若保留，读取目标揭示前的有限口历史，执行预算与重放schedule单独声明，不以全域完成作为强制接纳屏障。

当前标度下，名义全域参考0.899333跨约27次输入持续实现。32事件初始总物理跨度约1.06472；这仅为参考覆盖，实际有效路径、回返时间与训练中累计时距须分别记录。BPTT边界依旧截断跨窗信用；窗口前部的远期源可能位于窗外，持续状态不等于无限信用。

## 4. 先做的等价优化

读坐标的固定零空间为\(N=(I-2ww^T)[:,1:]\)。保留当前QR得到的守恒列c，避免符号改变，执行：

\[
\operatorname{coords}(f)=[f^Tc,\ f_{1:}-2(f^Tw)w_{1:}].
\]

对线性有限探针可用\(P(FQ)=(PF)Q\)，先测16个局部口，再做通道变换。逐节点平方、方差、归一化和注意力仍按原定义计算；任意SVD基与真正可学习矩阵保留通用分支。该优化保持同一数学算子，浮点求和顺序变化以输出和全部相关梯度容差验收。

短区间之后优先编译/融合固定局部物理块，并让主任务与writer辅助尽量共享原始前向。辅助对writer的梯度路由、状态余切和主任务全参数信用保持；共享回放不是简单删除辅助项。是否能撤掉深层重算和Adam暂存，由新的峰值记录决定，不预先删掉资源保护。

## 5. 预注册预测与最小验收

1. 结构化读坐标与线性探针重排应在数值容差内保留输出、端口位置/状态/参数梯度与旧权重加载；若失败，先修符号、舍入、非线性重排或通用分支，不开始训练。
2. 近期有限路由的响应必须超过步长细化的数值误差，且分离口的响应在关闭输运时消失；封存预测对尚未观察的target无路径。若失败，修短路由/时序，禁止用更广读写接口掩盖。
3. 当前出生的名义全场工作量由112降至约4步/事件，为原来的1/28；实际counts、暖吞吐与峰值必须实测。墙钟加速未知，禁止把1/28当实测速比。
4. 在同一物理间隔细化solver/observer，状态与梯度应趋于一致；改变输入间隔本身明确登记为新时序候选。

数值与接口通过后，只校准同一候选两个完整真实32-target窗口，分开编译与暖耗时，核对第二次Adam驻留、pending、连续恢复及3072MiB预算。原321秒窗口已提供昂贵参考，无需重复一轮长训练来定位同一成本。若仍为分钟级，停止执行候选并修复块融合/双回放；回到秒级后再安排正式充分训练。以原介质1.95–2.68秒/32的可运行量级作为性能参照，不预报新速度。

收益、无收益、模糊三种能力结论仅在资源验收后的真实充分联合训练判断：收益推进唯一主线；充分训练无收益重新检查时间/路由候选；预算不足保留未知。单次响应、空间图样和两窗口NLL均只作其覆盖的数值或接口证据。
