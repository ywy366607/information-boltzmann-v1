# 物料来源、搬运与通量预算（v0.16）

本轮把“进1、出1”的声明接到明确的搬运模型：物料身份固定，身体摄入必须对应物料从可用源进入身体，排出对应进入回收池，外界补给与回收分别登记。证明负责核验给定解释中的搬运和过程一致性；真实载体的物料身份、端口与能量对应仍由物理实现和数据验收。

## 1. 三项核心结果

| 问题 | 已完成的数学结果 |
|---|---|
| 进出账本能否任意填正数？ | 输入/输出由固定身份的物料位置变化计算；所有权状态不变时，正搬运量为0 |
| 总量恒定的周转从何得到供给？ | 身体平衡、可用源平衡及系统—外界物料平衡同时成立；累计摄入受初始库存、外部补给及明确回收约束 |
| 能否接到既有介质与世界时钟？ | 两物料身份的补给—替换—耗尽控制复用原六公理身体；自然感知协议下，正常/剪断分支均有逐拍精化证书，耗尽后任意有限未来的摄入概率为0 |

这三个结果解决来源层的数学接续。完整自我维持、1%编码候选和生物认知见证继续沿原目标构造。

## 2. 搬运对象与推导条件

`MaterialSource` 对有限物料身份集合中的每一项登记一个位置：身体、可用源、回收池或外界。`moved` 统计同一身份在相邻状态之间的位置变化；同一身份不会同时处于两个位置，也不通过改标签创造物料。

接口允许摄入、排出、外部补给、输出外界与明确回收。这里的端口划分、可用性含义及允许搬运，是给定载体解释的条件；它们没有被加入六条一般物理公理，也尚未被认定为真实生物的本构定律。相应解释确定后，`balance` 同时证明：

```text
身体后量 + 排出 = 身体前量 + 摄入
源后库存 + 摄入 + 源出口 = 源前库存 + 外部补给 + 回收
系统后量 + 输出外界 = 系统前量 + 外部补给
```

“系统”包含身体、可用源及回收池。对任意有限搬运路径，`source_budget` 将源平衡累加为精确库存账：

```text
末库存 + 累计摄入 + 累计源出口
  = 初始库存 + 累计外部补给 + 累计回收
```

`intake_bound_without_refill` 随之给出：没有补给和回收时，累计摄入不超过初始可用库存。空可用源在当拍的摄入为0；外界物料先进入源，再参与摄入。

物料可以循环。这个接口显式记录回收，并未假定回收必然发生或无需能量。因此有限物料本身不推出最终死亡；自由能、储能和熵流仍需各自建账。

## 3. 过程与时钟也必须对应

`Realization` 要求三项证书：

1. 精细过程向声明过程的既有 `TimedRefinement`，同一世界时钟逐拍对应。
2. 物料身份统计的身体含量与原身体含量对应。
3. 每条正概率转移的合法搬运及输入/输出量，与声明通道对应。

这使用现有行为精化、首次事件和统一评分工具。没有增加新的生命评分器，或把额外物料状态作为免费控制器：精化必须对每个准入状态和输入保持原事件—后继状态联合律。对实际生物及程序实现，载体映射与其成本还需分别交付证据。

任意旧核并不自动获得来源证书。若原核在资源不足时仍要求摄入，应修复其资源耦合并沿新实际过程评分；不能只给它附一张库存表。这里选定的资源世界是新声明的具体世界，精化保持该世界的既有核构造及原身体动力学，不宣称资源缺失的所有旧世界均被原样实现。

## 4. 补给—替换—耗尽控制

控制使用两个固定物料身份，身体总量始终为1：

| 世界阶段 | 搬运 | 通道摄入 | 可用源库存 |
|---|---|---:|---:|
| 补给尚未到达 | 外界的一项进入可用源，身体保持原物料 | 0 | 0→1 |
| 可用源就绪 | 源物料进入身体，原身体物料进入回收池 | 1 | 1→0 |
| 可用源已耗尽 | 没有补给或回收，保持当前配置 | 0 | 0→0 |

`realized` 同时给出正常/剪断分支的精化、身体含量与搬运匹配。`no_future_intake_after_exhaustion` 通过既有 `Interaction.Refines.firstHit_eq` 推出：源耗尽后，任意有限时域的首次摄入概率为0。该世界不依赖身体反馈，故此控制证明来源与交换的对应，完整自我维持正见证仍需加入有因果作用的身体—环境闭环。

证书覆盖已登记的自然感知协议与两种反馈分支。改变感知、供给或回收协议时，需重新核验实际转移与来源；感知中断、断料和断能保持为不同干预。本轮没有运行能力训练，也没有将这个数学控制称作海绵或细菌模型。
