## 八类测量及其可证伪判据

### 1. 联合使用和联合切除分开

执行 M（因果记忆回注）、T（快表）、R（递推）开/关的2×2×2矩阵；不另开独立收益训练。条件NLL为 `L_MT`：

- 联合使用收益超加性：`L_10 + L_01 - L_11 - L_00`。
- 联合切除损害超加性：`L_00 - L_01 - L_10 + L_11`，与前式符号相反。

例如两个互为备份的系统，单独切一个无损、同时切掉才失效，会得到正的联合切除项、负的联合收益项。不能把两者都称信息协同。逐段配对、5000份区间bootstrap、9999份符号翻转，报告效应量/区间/段数与正负方向；样本单位是文本段，不是把每个相关字节当独立样本。

再固定打乱记忆的action/successor载荷，保持键、读权重、容量和载荷边际分布，查“具体关联的对应关系”是否有用。这比“关掉后变化”多一层区分。

### 2. 实际向下反馈

在固定输入、权重和外部记忆时，分别扰动四层实际S，直接测各层隐活动/状态/输出分布的变化。上层→下层如果为零，就据实报告直接活动反馈缺失，不能拿反向传递熵冒充。

再从完整保存状态分别跑一整轮：原样、只扰动顶层S。对比首个参数更新之前的下层S、整轮后的下层S及下层权重，并核对两边自己说的话与世界输入是否相同。零的直接影响与非零学习影响可以并存；若语言本身分岔，则保留世界/自听这条中介解释。

### 3. 整体与局部稳定性

实际GDN+两种记忆读取的冻结权重驱动系统：四段真实情境，有限差分Benettin重归一，每16字节一次、共256字节，epsilon为状态范数的0.001/0.003。报告全状态条件有限时Lyapunov率、时间块分布及幅度敏感性。

逐层固定实际下层输入，对每头实际S做同样的并行重归一；分别列16头及retention的平均log alpha，找是否仅局部极慢/接近零。原Delta做同样测量。

明确判据：显著负的有限时率支持这些条件下收缩；显著正值需区分瞬态放大与持续发散；接近零只标未能分清，不自动叫临界。条件指数不等于学习、离散行动和可变世界共同组成的混合系统指数。整圈有限扰动结果复用旧完整分叉轨迹，不用单层指数代替。

### 4. 神经雪崩式事件统计

从实际隐活动阈值的**新越界事件**构造级联，区别于把一直高于阈值的坐标逐拍再数一遍。阈值2/2.5/3标准差、时间bin为1/2/4字节，逐段处理、末端未结束级联标为删失。足够事件时比较幂律和几何尾；无足够事件时报告不足。R清零和原Delta作为共同输入/普通递推控制。单一尾部拟合或分支比不构成自组织临界性证明，不添加人为目标分支比。

首端已进行中的级联也排除。固定中位数xmin后，足够尾部样本时做99份离散幂律参数bootstrap KS检查，连同幂律/几何对数似然差报告；它检验该事件定义的尾部分布，不代替有限尺寸标度或相变检验。

### 临界态、雪崩与随机控制的解释

有限时负率说明采样情境中的条件收缩，不能据此证明所有输入、学习和世界变化下都远离临界。四个情境都为负，但4情境符号翻转检验p=0.1263，故不把重采样均值区间当成全局稳定性定理。当前可用结论是：有慢模式，采样范围内没有零增长模式；普通同权重GDN也有。

雪崩采用新阈值越界事件、三阈值×三时间bin，并排除首尾截断级联。当前身体9种设置的条件幂律尾检验均为p=0.01（99次参数bootstrap的分辨率下限），8/9设置的几何尾似然更高。尾部事件相关性仍是该探索性拟合的限制。幂律尾与几何尾比较、离散参数bootstrap的结果逐项保存在机器报告；不以一个接近1的占据比宣称临界。若要进一步证明临界，需要控制参数的相变/尺寸标度和完整混合闭环的扰动分析，本轮没有为追求临界另改动力学。

随机控制保留了各层自身的时间结构、图的节点度数，或记忆载荷边际分布，分别只破坏待检验的层间对应、拓扑排列或具体记忆关联。断连图的不可达对按0效率计入；不再删掉断连点后宣称整图是小世界。相关网络不是实际连接组。

### 用户所问的统计与快表复核

统计检验回答“这点差别是否在不同文本段里一致，还是少数段的波动”。同一16段文本配对计算差值，bootstrap给出段间不确定区间，符号翻转给出无一致方向时的参考分布。它不代替效应量，也不把16384个相关字节当成16384个独立样本。以上p均为探索性名义值，未作整套指标的多重检验校正。

快表上下文复核修的是**测量输入**：读连续文本时，快表必须看到前面的真实字节，不能逐字节调用时把上下文清空；反事实路径的快表必须从各自同一起点副本出发，不能借用实际路径已经产生的概率。身体里的快表仍是模型的一部分，没有更换快表算法。
