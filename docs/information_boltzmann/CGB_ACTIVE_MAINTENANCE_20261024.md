# 行动、交换与能源约束共同实现自维持

本轮在独立修正版中闭合了一个明确的数学子目标：**身体动作维持资源可达性，资源交换补回实际消耗，失去资源则消耗有限储备并进入不能自行复活的空态。** 正常过程持续成立，剪断行动对世界的因果影响后，已有存活指标出现任意未来时刻都成立的固定差距。原 Gemini 模型及其反例保留，便于比较。

## 1. 同一个身体、世界与评分

身体只有三个状态：0 是空态；1、2 分别记住动作 A、B，各有一单位储备和体量。线索可以改变动作，不能让空态复活。摄入时动作记忆保持不变；这样不再发生原版的 B 分支在摄食后切回 A。

世界仍有初态、两种线索、两个资源场景和吸收的匮乏态。正常过程按身体的实际动作改变世界；剪断过程沿用已有的独立边缘幽灵干预。两者保持同一个身体、事件规则和世界时钟 R=1。

摄入使用已经建立的 `Exchange` 总交换量观察：正常身体每拍可以等量进出，体量保持不变。原 `Operational` 净增量观察完整保留；它不是本轮的维持目标，不能用其“没有增重”否定真实周转。恢复窗口统一为 3，阈值为 1/2，包含出生后的线索与首次摄入；没有删除早期评分或事后移动出生时刻。

## 2. 正常持续维持与剪断优势：Lean 已证

`ActiveMaintenance.maintenance_witness` 直接证明已有目标：

```text
Exchange.Persists body world he ledger 0
Exchange.SelfMaintains body world he ledger
```

支撑这两个目标的是全时刻结果：

```text
∀ n, natural_survival(n) = 1
∀ n ≥ 3, cut_survival(n) ≤ 1/2
```

所以可以取起始比较时刻 3、固定优势 ε=1/2。正常过程在第 2 步进入 A/B 各半的匹配状态，此后保持动作与资源场景的对应。剪断过程在第 3 步已有 1/2 概率进入匮乏；匮乏质量单调不减，且该区域的任意未来摄入概率为零，给出所有未来时刻的上界。

这是已有恢复窗口定义下的存活指标与因果维持子目标，不把窗口评分改写为无限路径存活事件。全时刻结论来自归纳证明，有限步枚举用于交叉复查。

## 3. 维持需求和耗尽进入实际动力学

资源场景中的交换事件消耗一单位，并摄入一单位；匮乏事件摄入为零，消耗剩余的一单位。储备归零后，所有刺激下身体都保持空态，实际注册通道率也为零，只剩空闲拍。

`starvation_depletes` 证明正常/剪断的匮乏事件都以概率 1 到达空态。`sustained_exchange` 进一步证明：正常过程从第 2 步起，每拍实际平均摄入和消耗均为 1。这里的正需求来自这套具体维持规则；没有把“所有生命每拍必须付固定成本”加入一般公理。

身体能量账户直接登记：

| 事件 | 储备变化 | 随料能输入 | 消耗并流入热端口 |
|---|---:|---:|---:|
| 保持动作的正常交换 | 0 | 1 | 1 |
| 有储备的匮乏事件 | −1 | 0 | 1 |
| 空态空闲拍 | 0 | 0 | 0 |

热流定义为负的实际消耗量，没有采用收支残差。线索切换保留储备；平衡参考刺激 `calm=0` 与缺资源刺激 4 分开声明，沿用平衡时冻结的六公理准入控制。它们是具体载体模型的规则，不是一般公理唯一推出的反应机制。

## 4. 同一过程上的能量与来源预算

`ActiveMaintenanceEnergy.actual_law` 证明能量核算的分布精确等于上述正常/剪断评分的分布，包含剪断自身的未来。`availability_budget` 对所有 n 证明：

```text
平均储备(n) + 截至 n 的累计平均消耗
  = 初始储备 1 + 截至 n 的累计平均随料能输入。
```

本模型以一单位储备为能量刻度。`isothermal` 提供显式声明 T=1、零内部/随料熵的账户解释，平均产生量等于消耗通量并非负；这一声明下可复用既有可用能预算。物理熵函数、温度和微观热浴仍需独立载体标定。上面的储备预算与耗尽动力学已由固定的端口及事件验证，不能把条件性熵解释扩张成一般热力学推导。

物料来源由三个**固定身份**的载体实现：一份在身体，一份在可用源，一份在回收池。每次正常交换，源→身体、身体→回收池、回收池→源同时发生；匮乏只把身体份额释放到回收池。

`ActiveMaintenanceCarrier.realized` 对正常和剪断分别给出完整的 `MaterialSource.Realization`：体量来自真实位置计数，输入/输出来自实际搬运，并以同一时钟逐拍精化原事件过程。载体的额外身份阶段不参与身体控制，不改变原有任何有限未来观察律。

源与身体的载体各携带一单位化学能，回收池载体为零。`sourceAccount` 把回收池→源的再充能登记为**外界做功输入**，把实际消耗登记为热流，因此身体＋源＋回收池这个较大边界也满足逐事件第一定律。正常持续维持需要外界持续供能；物料循环没有消除能源需求。源→身体的内部搬运在这个较大边界内不再重复计为外界输入。

## 6. 在整体理论中的位置

现在已有“行动后果→资源可达→实际交换与补能→储备维持”的具体正见证，以及同一过程的剪断对照与固定身份载体解释。接下来应研究哪些可塑机制能从经验中建立这种有效控制。

完整 L1–L6 仍要求自举、学习、局部世界模型、感知中断耐受和生态位等证据；本例没有证明有限编码的 1% 预算，也没有实现持续新信息的丰富世界。这些仍作为各自证明与实证目标，原生命定义保持不变。
