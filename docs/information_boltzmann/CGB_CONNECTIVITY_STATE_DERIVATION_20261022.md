# 从端口可区分性推出必须保留的连接状态

2026-10-22。接在[CGB_SPATIAL_MATERIAL_RESULTS_20261022.md](CGB_SPATIAL_MATERIAL_RESULTS_20261022.md)之后。先说明现有粗粒化丢失了什么，再决定下一步状态；不直接加分叉函数。

## 同样的材料量可以有不同的物理后果

取一个空间单元，其左、右、上、下四个端口各有单位电导的材料臂。体积分数、各臂材料量、总电容都相同，内部可能是：

- X：左—右相通、上—下相通，两条通道交叉但不接触；
- Y：四臂真正接合到同一导通域。

给左端电势1，其余三端电势0。在准稳态，由局部电荷守恒：

    X：左右中点V=1/2，上下中点V=0。
       左输入电流1/2，右输出1/2，上／下输出0。
    Y：共同中点V=1/4。
       左输入电流3/4，右／上／下各输出1/4。

这不是学习能力小任务，而是一个边界响应的物理不可区分性检验。同一组局部材料占据数不能判断X还是Y；当前网格单元只有一个荷量／电势，自带了Y式混合的假设。单靠调J、扩散率或显示水平集不能恢复被消去的通道配对。

所以空间材料到可生成大脑的下一步，首先要保留**局部导通域与连接端的配对状态**。这是端口响应要求的状态辨识，不是因为“生物有树突”便补树突。需要消去这些自由度时，应证明在工作时间尺度上端口关系等价；不满足就继续保留。

## 同一反应网络怎样扩展

连接事件消耗两个可用端，形成一个接合态；断开反向回收端。端的总组成、接合的储能、可用驱动和外界功需要一起记账，正反比仍由同一局部自由能确定。每个结构单元可提供多少端，是材料构成／身份规则，不是整棵树要分叉多少次。

伸长可表现为新材料加入已有导通域；转向取决于实际端的空间构型与局部结合／形变能；更多端接入可形成接合或分枝，已有结构相遇则要区分交叉、接触和真正连接。这些过程不能被一个“接近即短接”的网格规则全部替代。

谱系／身份应随实际材料域保留，再在真实接触事件上调用原有有向匹配规则。V3d给的是给定几何下的统计强度；它不直接等于新接合能或反应率，需要保留二者的识别步骤。

这一步缺的是被粗粒化掉的可区分状态，现有守恒、有限速率、局部储能与自我生产原则继续适用。下一轮先明确端／域的有限配置及其允许事件，再写动力学；不预先规定树形、连接数量或行为发言率。
