# 新增机制的第一性原理准入审计（2026-10-21）

**结论：Codex新增内容没有全部通过主规划的机制约束。** 材料收支落实了守恒约束，有限槽位解析步实现了既定方程；空间路径、条件分枝及部分接口分配仍包含未推导选择。后者保留为逆发育/工程诊断候选，不纳入已成立的生命生成法则，也不因接了材料账而获得准入。

## 1. 判据来自哪里

依据[主规划](CONSTRUCTAL_GENERATIVE_BRAIN_FRAMEWORK_20261018.md)“实现时的硬约束”第1–7条、§2.2–§2.3：

> 每一个状态量都写成连续性方程（§2.3），每一个机制都要能归入设计规则的来源（物理必然、下层规律、自我生产），否则视为补丁。

§2.3又要求下层有效规律具有成立范围。故不能用“涉及守恒/临界/对称”这类名称代替推导；需要写出来源、量、通量、反应或转化，以及从它们到实现的步骤。

§6允许遗传规则具有待识别、待选择的参数。有限速率、成本、亲和力可以是待校准或可选择的常数；“参数可学习”不能替任意函数形式提供推导。逆发育拟合是在识别候选规律及参数，也不等于已经证明其微观机制。

**执行顺序（用户本次明确要求）。** 先充分利用文档已有原理完成推导，再实现并检验；不能把“尚未推导”改名为“经验候选”就继续作为正式机制推进。现有经验候选保留作历史对照，停止沿其手设规则扩展。只有给出了具体推导路径、走到可定位的未闭合项，并说明为什么现有原理仍不能决定该项之后，才讨论原理是否需要补充。代码尚缺、参数未知、近似条件未验证、研究者尚未找到推导，都不能直接判作第一性原理缺失。

## 3. 能实际写出的推导，以及它没有推出什么

### 材料收支

设边e的合成、拆解通量为s_e、d_e≥0，结构为g_e，局部供体为i，单位结构成本χ>0，回收率0≤r≤1。在声明固定组成/单位成本的有效描述后：

    dg_e/dt = s_e - d_e
    dB_i/dt = Q_i - γ_i B_i - μ_i Σ_e g_e - χ Σ_e s_e + rχ Σ_e d_e
    dW_i/dt = γ_i B_i + μ_i Σ_e g_e + (1-r)χ Σ_e d_e

求和立即得到：

    d(B_i + χΣ_e g_e + W_i)/dt = Q_i

这给出了守恒恒等式与B_i≥0的可行性约束。它**没有唯一决定**s_e如何取决于标签、底物与受体，也没有推出比例分配、先拆后造或停供后的死亡规则。当前代码的实付维持不超过库存，上式的维持项相应取实付通量；unpaid只是未实现的请求，不能在等式里当已耗散材料。

### 有限槽位解析步

继承E6并假设m≥0，令a=ηm[z]₊，b=ηm[z]₋。一步内冻结a、b、λ时：

    dg/dt = a - κg,    κ=(a+b)/gmax+λ
    g(t+dt)=g(t)exp(-κdt)+(a/κ)[1-exp(-κdt)]

κ=0时取连续极限。a,b,λ≥0使0≤g≤gmax成为不变区间；这解释了解析步为何无需事后裁剪。它仍继承“标签如何设定a、b”的候选机制，不能证明标签一定识别了世界中的预测贡献。

### 条件树为什么不能据数学精确性准入

    P(split | B,m)=B(m+1)/[m(2B+m-1)]

该式是指定有限二叉森林及计数假设下的条件概率。它没有给出B由什么局部通量产生、为什么分叉只为二叉、材料何时导致终止、方向与极性如何形成。将真实分叉密度乘总长先设为B，再以分叉密度接近真实为成功证据，包含条件化带来的自洽，不能替代发育机制推导。

## 4. 修正执行路线

1. **继续使用已有成果的原定角色。** Claude的相遇研究、局部池与营养选择，Codex的稳定匹配、守恒账与恢复实现继续保留；物理来源、参数假设、统计证据分别登记。
2. **不再把经验路径/条件树逐项调得像成年果蝇，作为生成法则的主线。** 这些版本只作参考和对照。观察室展示实际执行的统计候选，不是“第一性生成脑已出生”。
3. **正式生长过程先闭合推导。** 声明局部材料、受体/导向信号、结构和驱动力；由输运、结合/解离及局部耗散给出伸长、转向、分化/分叉与回收事件的发生率。若采用变分形式，必须给出具体能量或有效势及适用假设；不把任意力场重新命名为势能。
4. **闭合同一套局部过程。** 世界感觉/行动后果改变系统自身可计算的信号，进而改变已有标签、支持和有限速率结构通量。m仍固定、维持欠款仅记账时，明确保留这些缺口，不另加发言率或行为阈值修补。
5. **再做机制与活体检验。** 先验证解析极限、守恒、有限速率和恢复；然后在真实流中验证结构分化、预测、保留/回访与行动后果。拟合误差和冻结探针不能代替这一环。
