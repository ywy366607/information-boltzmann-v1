## 同一生成元允许时间选择

固定外部控制A、B时，实际荷量、P/D、r/C与空间状态一起演化。对观测f，先A后B与先B后A的期望差在小持续时间下由τ²[L_A,L_B]f起头；两段持续时间不同则系数为τ_Aτ_B。后面接同一输入T时，比较的是传播后的f。该关系说明有次序效应的可能来源，不保证任何回路都有有用时序学习，更不规定STDP窗口或符号。

原write转移荷量、消耗驱动并改变r；r又改变捕获和导通。若已有r/支持/有限组成可留下次序并影响以后交换，优先使用它们。若只剩快速电荷滤波，后续应补实质慢耦合。抬高目标电势抑制当前正向写入，不足以单独断言完整回路不能产生时间选择。

1. 取哈希验证的真实OWT train[4096,4128)32字节：A=前8，B=后8，T=最后16。ABT是原连续次序，BAT只交换A/B位置。两者相同源字节多重集、相同4ms/字节和总128ms；最后64ms输入完全相同。BAT是机制检查，不是自然语言能力研究。
2. 四组：原过程ABT/BAT，以及只将原write_rate置0的ABT/BAT。关闭正反write共同势垒，热恢复、活动、捕获、输运、空间生长均照常；U/G不变，无瞬时储能功。势垒控制器的实现成本未建模，该组只是诊断副本。
3. 四组分别使用4组预先指定的未来随机数状态。组0沿用父档全部RNG；其余从同一原RNG状态advance 1e6×组号取得，声明是未来浴噪声对照，不伪造已发生的物理时间。每组四臂初始RNG相同；分歧后事件消耗随机数不同，不能声称逐事件噪声严格匹配或16条路径相互独立。
4. 同一T结束后，分开报告q、P/D、r、C、真实载体和几何差异，不把数量变化当预测能力。原过程ABT组0为唯一预定主线：实际新暴露32字节，到23424ms，下一新train4128/validation1280。不按结果挑主线。
