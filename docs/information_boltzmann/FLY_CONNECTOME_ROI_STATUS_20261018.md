## 四种“接上”状态

| 状态 | 含义 |
|---|---|
| **解剖接入** | 该 ROI 的神经元和突触在 165,122 节点的全连接组中 |
| **全脑动力学接入** | 节点参与膜电位、兴奋/抑制电导、延迟和脉冲更新 |
| **专门机制接入** | 有该系统自己的状态、可塑性、调质、输入或输出机制 |
| **操作闭环接入** | 动作改变身体/世界，后果再经感觉和上行通路返回大脑 |

当前模型对绝大多数 ROI 已达到前两层。这个事实不能被说成“这些脑区已经发挥了生物功能”。

## 以后怎样防止“埋头瞎看”

每次新增机制或训练前，先在清单里标记它影响的是哪一层：

1. 只改变通用膜动力学：标为“全脑动力学”，不能声称生物功能接入；
2. 有原生细胞/突触/调质状态：标为“专门机制”；
3. 有动作后果和上行感觉返回：才标为“操作闭环”；
4. 只有相关放电或形态图：保持“未验收”，不能当作功能证据。

当前的下一优先级是 **CX/CAN 持续状态与选择回路**，然后是 **ascending → descending → VNC motor → proprioceptive return**，再补 **DPM/APL 记忆巩固**。不应把 5,619 个 ROI 都各自加一个人为模块；应该按连接组显示的系统级闭环逐层接入。
