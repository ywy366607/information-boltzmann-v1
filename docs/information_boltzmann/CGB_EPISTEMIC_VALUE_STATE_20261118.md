## 原因的可检验形式

实际收益头输入 `X=(z_source,z_action-z_source,option)`。实际学习收益是 `g(X,R,Q,y;theta)`：R是当时支持，Q是行动前旧查询，y是真实后果，theta是当前学习参数。详细预演求 `E_y g`，未来收益头仅直接读X。

新接口把学习状态写成 `K=(R,Q)`，估值读作 `V(z,K)`；在每条假想回应分支经过同一个U之后，下一步读 `V(z_next,U(K,a,y))`。这明确区分物理状态的变化与自身知识的变化，并让它们在同一次预演中共同推进。

## 模型中的解法

`scripts/ib_local/epistemic_value_reference.py`直接复用原relation_features、long_predictor、mother_from_boundary、posterior、log_score和quadrature。有限保持/释放在编码后的真实事实和相同预算上执行。下一步行动仍由原经历读出的有限候选与权重提供。

显式实验模式：`configure(engine)`持存schema，同时建立运行引用；标准restore根据config/engine schema重新接回。`_imagine`在每条原假想后果完成U和下一身体状态预测后，计算携带该分支学习状态的下一步用途。当前即时支付仍使用原冻结Q；未来本地Q采用该分支保留的事实，包含分支里已经得到的假想回应，评分时继续排除目标自身。

`causal_use_value.utility`保持 `10*当前净用途 + gamma*未来用途`，实验模式将第二项换为上述分支均值；真实有限U支付、actor/critic、AdamW、S/P、经历写回和自然文本导航照常参与。参数数量和优化次数保持。
