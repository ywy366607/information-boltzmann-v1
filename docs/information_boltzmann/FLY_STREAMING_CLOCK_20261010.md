# 果蝇大脑：流式时钟——一边感知、一边思考、一边输出（2026-10-10）

> 归档：文中 `scratch/fly_stream/*.py`、运行脚本已复制到 `scripts/ib/fly_interface/`，各实验的 JSON 结果在 `results/published/fly_interface_20261011/`（文件名中 `__` 代表子目录）。

## 动机

冠军个体（CTM-S14 + 自适应准入）是严格串行的：一个 token 注入一拍 → 等脑安静（平均 6.2 拍）→ 读出 → 下一个 token。
这是当初为了证明“性能受内在时间限制”而刻意设计的清晰串行，它把**延迟**（处理一个 token 要多久）和**吞吐**（多久进下一个 token）锁成同一个数。
生物不是这样：延迟几百毫秒，但输入连续流入，上一个音节没处理完下一个已经进来；整脑连接组 LIF 仿真也给感觉神经元连续脉冲、读一段时间的放电。

内在时间（信号沿连接组传到运动面的拍数）避不开，但吞吐可以和它解耦：流水线。

## 机制（`information_boltzmann/core/fly_bptt_learning.py`）

`advance_fly_token_stream(model, state, token, ticks=k, hold_input=...)`：每个 token 恰好占 k 拍，不管脑在做什么；下一个 token 的预测在它到来前一刻读出。
不等安静，所以 token t 的处理在 t+1、t+2 被感知时继续进行。
- `hold_input=False`：token 只在第一拍给一个感觉脉冲（存档的事件形式）。k 拍脉冲流式与“1 拍输入 + k−1 拍安静”的串行事件逐位相同（测试）。
- `hold_input=True`：token 在它的 k 拍里一直在感觉面上；写入器自身的适应（λ=0.9512）把持续刺激变成逐渐衰减的新息。
- 读出：`use_read_gamma_trace` 时读运动膜电位的二阶 Gamma 积分器（每个神经元可学衰减），否则读当下膜电位。
学习器：`FlyBPTTLearner(stream_ticks=k, hold_input=...)`（取代自适应准入）；训练脚本：`--stream-ticks k`、`--hold-input`、`--use-read-gamma-trace`。
四支柱评估全部经过同一个 `learner.observe`，所以训练与评估用同一时钟。节奏固定后不再有每拍的主机同步（可被 CUDA graph 捕获，尚未启用）。

## 差距从哪里来：到达不是瓶颈，处理深度是

先假设“k 小于感觉→运动传导时间，token t 的信号还没到运动面”，测量推翻了它（`scratch/fly_stream/arrival.py`）：
注入神经元（15,912）与读出神经元（2,333）不重叠，但 2,329 个可达读出神经元中 1,424 个与感觉注入只隔一条延迟 1 的边（895 个隔 2，10 个隔 3），
所以读出面最早在第 2 拍就变化；在冠军个体上把注入的 token 换掉，112 次全部在第 2 拍改变读出面。
因此 token t 在它的窗口内就已到达运动面；差距来自读出所需的多跳处理（约 6 拍）在流水线里要等下一个 token 进来后才完成。
出路只有两条：(1) 输出滞后，白拿不泄漏的拍；(2) 脑学会在更少拍内形成有用特征（需要更长学习来判断）。

## 输出滞后（读出滞后于输入一拍）

`read_after=D` / `--read-lag D`：对 token 的预测在它被感知 D 拍后读出（感知的 token 就是目标）。只要 D 小于最早到达时间就严格不泄漏：
MaleCNS 上 D 最大为 1。测试：注入拍后读出与被感知的 token 逐位无关，读两拍后就有关（测试敏感）。

| 零样本 | k=2 | k=3 | k=4 |
|---|---|---|---|
| 流式 | +0.75 | +0.48 | +0.31 |
| 流式 + 输出滞后 1 拍 | +0.65 | +0.41 | +0.25 |

吞吐不变，白拿 0.06–0.10 nats。

16k token 的学习没有缩小差距。用户指出：固定 k 本身是魔法数字，也是强制等待（只是把“脑状态决定等多久”换成“规定等多久”）；

## 没有输入时脑会静默吗（冠军个体，`scratch/fly_stream/silence.py`）

代码里没有起搏电流、内在电流或自发噪声：驱动只有突触电导，全零状态是不动点。连接组里有 52 个生物钟神经元（s-LNv、l-LNv、DN1、LNd、LPN 等），
被当成普通神经元（“cb_intrinsic”等大类名里的 intrinsic 指局部中间神经元，不是内在自发活动）。
实测：从保存的永不重置状态出发，完全无输入 5000 拍——**活动自持，不熄灭**。放电率始终约 2.5%（约 4,100 个神经元/拍，与有输入时相同），
输入驱动的膜能量从 0.52 衰减到 0.0016 后稳定，运动读出仍在变化（每段 3–4%）。活动在游走，不是固定回路：
相邻两拍放电集合的 Jaccard 只有 0.027，相隔数百拍 0.10–0.35（有回返结构）；2000 拍内 28,979 个神经元（17.6%）轮流参与，
集中在中脑局部中间神经元（cb_intrinsic 32,160 个中 20,356 个参与）、视觉投射和 VNC 中间神经元；运动神经元几乎不放电（脑 2/107、VNC 2/708）。
即冠军个体已经有“沉思”状态：内部自己运转，毯的行动侧安静——没有装起搏器，纯靠学到的循环维持。与生物一致：大脑不会静默，诱发活动只是持续自发活动上的小扰动。

## 反射弧（`scratch/fly_stream/reflex_arcs.py`）

离感觉注入面只隔 1 个突触的读出神经元：VNC 运动神经元 623/708，VNC 传出 87/94，下行神经元 610/1314，脑运动神经元 74/107。
即“第 2 拍就到达读出面”的捷径主要是 VNC 反射弧（果蝇版膝跳反射），只携带浅层特征；语言预测需要的深层特征要穿过内部状态约 6 拍。

## 能量按连接组（放电 × 出边 = 突触事件）

工作每拍约 177 万次突触事件（全部突触的 7.0%），静息 164 万（6.5%），工作只多 8%，全部在外围（VNC 中间神经元 ×2.8、上行 ×1.8、感觉 ×2.6）。
中脑局部中间神经元（核心）只占 29% 的突触，却用掉约 70% 的能量，工作与静息相同；视叶局部中间神经元占 43% 的突触，只用 2% 的能量。
出生权重下同一状态无输入 50 拍内熄灭（3.1% → 0.006%）：自持活动是学出来的（`scratch/fly_stream/work_vs_rest.py`、`energy_by_region.py`）。

## 信息在哪里（`scratch/fly_stream/info_probe.py`，线性探针，固定权重，3000 拟合 / 1000 留出）

当前 token（嵌入 R² / 全词表检索准确率）：运动面膜电位逐拍累积 0.019→0.152（2%→22%，第 7 拍仍在上升）；运动面放电是瞬态，第 4 拍最高 0.084 后衰减；
7 拍膜电位轨迹 0.199（32%）> 末拍 0.152 > 放电计数 0.122 > 窗口均值 0.087。下一个 token（嵌入 R²，弱指标）：运动面放电计数 0.026、放电轨迹 0.027，
略高于膜电位（0.018–0.023），接近“由当前 token 自身嵌入线性预测”的参照 0.028。中脑核心（相同 2,333 个神经元）几乎没有线性 token 信息（最好 0.061，下一个 ≈0）。
对读出的含义：读运动面；多拍并保留时间结构（逐拍学权重），不用单拍、不用等权平均（解释了积分读出的失败）；膜电位（累积“看到了什么”）与放电计数结合；
第 7 拍信息仍在上升，读出/“去”神经元要能等更久（与“固定 8 拍优于冠军 6.2 拍”一致）。

## 冠军个体已有的能力（`scratch/fly_stream/early_read.py`）

快读：在自己的节奏里强制第 k 拍读出，NLL 7.064（输入拍，未见当前词，已比一元 7.62 好 0.55，来自上下文）→ 6.912 → 6.800 → 6.730 → 6.695 → 6.641（第 6 拍），
自己停下时 6.615；即第 2 拍拿到当前词收益的 33%，第 3 拍 59%，第 6 拍 93%——早期读出天然可用。
静默：在 16 处切断输入，静默第 1–4 拍对真实下一个词 NLL 7.12–7.17（比一元好约 0.5，“余音”），16 拍后回到一元，32 拍后比一元差而熵下降到 5.86
（落入与上下文无关的固定分布 = 时钟吸引子）。CTM 阶段日志：固定 15 拍、无能量代价时，按确信度选中的拍平均 6–7.5，第 14 拍损失比最佳拍差 0.28——
读出质量先升后降（信息流过运动面后被冲掉），所以学习的停机不需要能量代价也不会漂到上限。

## 去神经元（取代通量规则）：巨纤维失败、虚拟去神经元成功（`scratch/fly_stream/gf_go`、`virtual_go`，续训 4096 token）

巨纤维（DNp01，左右各一，属下行神经元）：冠军个体中左 GF 以约 17% 的拍放电（2 拍周期交替，跟随核心时钟，与 token 无关），右 GF 被抑制不放电。
第一次实现用 ATan 代理 CDF 当“放电概率”，它有柯西重尾、与实际不符（实际 0 放电时仍给 0.05–0.2），损失一直认为“放早了”，拍数失控；
第二次改为真实放电的代理梯度信用（前向 = 实际放电那拍的 CE；更早一拍的放电得 CE_t − CE_fire，放电那拍得 CE_fire − CE_下一拍（反事实一拍，不入生命））。

（第 7 窗 NLL 9.36 是文本难段，虚拟组同窗 9.37，不是损伤。）

读入权重范数 0→0.22（时机逐渐依赖运动面状态），拍数缓慢上升（与“固定 8 拍优于 6.2”一致）。训练变慢（88 vs 58 ms/token：每拍全词表解码 + 每拍采样同步）。

## 读出升级：无窗口的多时间尺度读出（`attach_read_bank`，`--read-bank`）

每个运动神经元的膜电位再经过 6 个指数滤波器（初始时间常数 1–32 拍，可学），沿整条拍流运行、跨 token 边界、永不重置；读出 = output_read(Σ_k g_k f_k)，
增益初始 (1, 0, …) 即与冠军读出完全相同；增益是 O(1) 量，用 50 倍学习率（冻结脑探针标定：2e-4 下 4k token 只动 0.01）。
冻结脑、只训读出（`readout_probe.py`，留出 NLL）：串行节奏（6 拍安静）单拍 6.896 vs 滤波组 6.883（+0.014）；并行节奏（3 拍安静）7.157 vs 7.077–7.093
（0.06–0.08）——并行时滤波组把“被催着走”的代价从 0.26 降到 0.19。装进个体（虚拟去神经元 + 滤波组 vs 只有去神经元，4096 token）：
B 配对 +0.033 −0.021 −0.002 −0.044 −0.042，训练流 −0.014 −0.112 −0.015 −0.036；A 重访节省中位 0.46→0.52、均值 0.47→0.55；
滤波增益 0→0.11，学到的平均时间常数 8–10 拍（约一个 token）。

## 放开主动神经元（`attach_intrinsic_drive`，`--intrinsic`）

连接组注释里生物上自发/紧张性放电的 443 个细胞（多巴胺 PAM/PPL、生物钟 s-LNv/l-LNv/LNd/DN1/LPN、章鱼胺 OA-*、5-HT、DPM、APL），

## 回答：内部思考一定是当前内容吗

已经有一个直接的反例：中脑核心——不带当前内容（线性探针≈0、换成别段文本的活动无影响），也不仅是无用的节拍（静默它 +0.43，占脑贡献 83%），
是“非内容但有用”的内部活动：给运动面提供动力学背景/工作点。放开的主动细胞在 4k token 内还没有形成新的这种角色。要回答是否会出现第三类（非内容、非时钟、却有用），
下一步是接上它们的真实功能：多巴胺调制可塑性（以及更长的学习）。
