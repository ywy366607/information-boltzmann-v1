# 生成大肠杆菌：多态规则表、统一接口、生命门内搜索（预注册，2026-10-26，搜索前写定）

## 0. 为什么重做

趋化 s0–s2 与点燃 s0–s1 都没有生成出目标个体。归因（见 `CGB_GENERATED_CHEMOTAXIS_PREREG_20261026.md` 的诊断与 `CGB_GENERATION_LAYER1_20261025.md` 的盘点）：
1. **感知容量**：64 个单元时，有噪声的理想策略也活不下来，需要约 256–1024 个感受器；
2. **放大**：对势的平衡态 Hill 系数恒为 1（G25c），超敏放大需要驱动或相互作用能；
3. **生成器比理论窄**：二态、可加能量的表够不着 G18 要求的多变量单元；
4. **赢家诅咒**：少数固定训练世界中的运气被选择当成了能力。

本次只修这四点，世界本身（环、峰、成本）不变。

## 1. 世界与接口（固定）

- 与 `cgb_chemotaxis` 相同的环形世界（L = 400，6 个高斯峰，成本为环上平均摄入的 2 倍），时程 10000 拍。
- **统一接口**，每一页都由本质推出：F 感受器（边界，μ = ln c，最多 1024 个单元）；M 马达（边界，1 个单元，状态 ≥ 1 时翻滚）；E 储备（边界，μ_E = 6 + ln(储备/150)，代谢）；D 废物（边界，μ_D = −6，排出 G16）。经 E 吸入的每单位含量另付 0.0005。
- 内部页 1–4 个，每页 2–4 个状态（含量 = 状态编号），每页最多 512 个单元。

## 2. 生成（只有选择，没有手工结构）

- 个体 = 成对规则表（`tableCRN` over `Fin S`，M3）。内部–内部规则守恒含量，所以每个候选都按构造通过 P1–P3。规则系数按浓度给出（每对的系数为 κ/N）。
- **生命门内搜索**：只有通过感知/代谢见证、排出、选择性排出、一拍记忆的表才进入种群。
- **每一代换一批新的训练世界**（每代 8 个新种子），精英每代都要重新评估。最终个体由固定验证集（种子 500–515）上的均值选出。
- 种群 64，150 代，种子 0，10 个进程。

## 3. 预言（留出世界 101–108）

| 编号 | 预言 |
|---|---|
| K1 | 进化个体的存活中位数高于致盲、从不翻滚、固定 0.1 翻滚三个对照的中位数，且至少高出 1000 拍 |
| K2 | 时间比较：μ 上升后的翻滚概率比 μ 下降后至少低 30%（E1 判据） |
| K3 | 驱动必要（G25c）：燃料平静（μ_E = μ_D = 0）后存活中位数至少下降 30% |
| K4 | 最终个体通过完整的门：Lean 中的 Medium 实例、感知与代谢证明、生命层全部义务 |

**失败的出口**：K1 失败时，先用有噪声的理想策略在 10000 拍世界上重新校准；若理想策略能活而个体不能，检查最终个体的结构缺了哪一部分（记忆、比较、放大），以及该部分在突变邻域内是否可达。K3 失败而 K1 成立，说明个体用的是非驱动的机制（例如多态单元内的相互作用能，G18），这本身是一个发现，按 G25c 的另一条路归因。

## 4. 展示

通过门的个体将做成可视化页面：环上的浓度场、一群个体的轨迹，以及它们体内各页的状态随时间的变化。

## s0 的结果（2026-10-26）

种群 64，150 代（约 5 分钟）。留出世界存活 [最小 / 中位 / 均值 / 最大]：进化个体 50 / 790.5 / 3980 / 10000；致盲 50 / 116 / 172 / 541（与从不翻滚相同）；固定 0.1 翻滚 45 / 140 / 523 / 2158；燃料平静 50 / 790.5 / 3980 / 10000（不变）。

- K1 ✗（中位数 790 比对照最高的 140 只高 650，未达 1000）；K3 ✗（燃料平静无影响）。个体用到了感受器（致盲后崩溃）。
- **长出的结构**：受体 1024 个，4 个内部页，其中一页 4 个状态、一页 3 个状态。阶跃响应：μ0 = −1 时翻滚率约 0，μ0 = 1 时 0.2–0.3，μ0 = 3 时 0.6–1.0。这是一个**陡峭的绝对阈值开关**："一路直跑，到浓处停下"。在途中遇到足够高峰的 4 个世界里活下来（三个满 10000，一个 1452），其余世界饿死。
- **它的放大不靠驱动，而靠多份含量的状态**：含 s 份含量的状态，平衡权重为 exp(sμ − φ)，对势的 Hill 系数为 s（G25d，`quanta_hill`，已证）。这是 Hill 解释血红蛋白协同结合的机制，由选择找到，先于我们写下这条定理。G25c 的"平衡态 Hill = 1"只对二态单元成立。
- **没有时间比较**：用的是绝对水平。按 G10b，强度跨两个数量级时固定阈值不可能处处适用，这正是它在低峰世界中失败的原因。剩下的瓶颈只有"比较"。
