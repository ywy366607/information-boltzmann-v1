# 与载体无关的大脑生成原理：同一相互作用如何同时产生结构和学习

2026-10-22。沿主规划§2.2–2.3和Claude的局部池、捕获、支持及身份成果，明确本项目要寻找的是可跨载体实现的生成规则。碳、硅或其他材料提供具体实现；核心对象是有限局部状态、可发生的交换、储能、动力学及其与环境的关系。下列为统一研究假说及推导框架，不将尚待检验的充分性写成定理。

## 1. 生成器应指定什么

不指定成年脑邻接表，也不指定每个功能区的最终职责。生成器给出：

    有限局部状态及组成 → 允许的相互作用 → 能量/熵与动力学
       → 在边界交换中持续演化的结构和活动。

可校准的物性与短身份程序属于生成器的一部分，不是宏观功能清单。Claude的定向身份匹配提供局部相遇后作用的候选身份律；它的统计证据保留，不直接等同于已识别的真实分子结合能。变更载体时改变本构与单位映射，不能把相同参数值视为通用物理常数。

## 2. 五条相互依赖的生成约束

### 有限、局部、可交换

每个区域容量有限，交换和转化有有限速率；实际守恒组分的每次改变有来源和去处。相邻过程竞争同一库存、容量或输运通道。若一个事件改变了状态且恢复需要时间，事件会留下可继续参与作用的残余；残余的内容和寿命仍由具体动力学决定。这样可以生成耗竭、恢复与历史依赖，不预装独立的“疲劳”和“记忆奖励”。

### 开放驱动与耗散相容

环境通过真实边界提供物料、做功和信息结构；内部变化计入储能、物料和热。热力学约束交换的可行性与方向性，具体接触、势垒和迁移率决定速率。显式热浴/有效耗散已是所选择的描述层；要进一步证明其时间箭头来自可逆微观层，需要另给初始统计、消元与尺度依据。

### 活动与可变结构相互作用

活动改变局部结构转化的条件；结构又改变未来活动的传播、存储和边界作用。共同储能中的作用项对两方向均计账；如果改变的只是势垒，则交代它改变的是转化速度，不能把催化误当供能。记忆载体、支持和通道不能分别由互不相干的评分器控制。

### 相同局部过程也能改变空间与连接

输运让材料相遇；付费转化产生或回收域、接触和通道；新结构继续参加原来的交换。伸长、转向、分支和接合应是这套演化的结果。规则允许这些结构不意味着每一参数区间都会产生它们；形态、稳定性和统计覆盖必须实际检验。不能预先指定分叉次数或目标路径，再把采样准确称为机制生成。

### 作用结果返回维持与改造条件

系统的活动改变外部世界，改变后的世界又影响其后续输入、供给和可维持结构。最终要检验的是这条反馈能否选择和维持有用结构。资源竞争提供选择压力，具体生态位决定何种结构有用；“活跃就多分资源”不足以保证预测或学习。预测关系要存在于系统自身状态及实际相互作用中，不能只存在于外部观察器。

五条合起来的候选循环是：

    交换 → 活动 → 有代价的持久改变 → 改变后的输运/感知/行动
         → 改变未来交换条件 → 继续维持、改造或回收。

## 3. 用一个生成元表达，而不是逐个安装功能

令完整状态X包含当前局部组成、快速自由度、持久配置、几何/接触及相关世界状态。对每种允许的局部转化a，声明变化ν_a与速率k_a(X)。连续运动可用相应的确定性或随机运动生成元表示。任意可观测量f的同一演化为：

    L f(X) = L_motion f(X) + Σ_a k_a(X)[f(X+ν_a)−f(X)]。
    d E[f(X_t)]/dt = E[L f(X_t)]。

实际物料守恒要求每个内部通道满足相应组成约束；边界通道单列通量。能量/熵约束原通道与实际反向通道。以恒温、局部平衡浴、已正确计入构形简并的有效状态为例：

    log[k_a(X)/k_reverse(X+ν_a)]
        = −β[ΔE_a − W_a] + ΔS_internal,a/k_B。

若状态带时间反演为奇的变量，反向过程还须反转相应变量和外部协议。此式是声明条件下的有效层约束，不是从牛顿方程自动得到的全部微观理论。它限制正反率之比，不能唯一选出状态图、能量、共同势垒或绝对时间尺度；这些就是待识别的物性与生成程序。默认逻辑率α·expit(−ΔG)只是当前实现之一，不能把该形式当成跨载体定律。

用同一L分别取电荷、组成、r、支持、连接与几何，就得到它们各自的活动、保持、转化和生长方程；不会为每种宏观名称再增一条更新律。消去隐藏自由度后一般产生历史项与涨落；采用即时近似或慢变量闭合，需要给出相关时间和误差依据。不能把E[k(X)]任意替成k(E[X])，也不能每段清掉相关性来获得想要的简洁方程。

## 4. “生成复杂结构”到“生成大脑”还要跨过什么

守恒、有限速率和外部驱动允许多种有序材料。我们的研究任务是找到其中能够同时产生可复用表征、选择性记忆、持续适应及感觉行动闭合的相互作用类，并说明其成立参数区间。复杂性本身不是充分判据。

验证按同一完整过程推进：先核对每次交换和恢复；再在真实流及其合法对照下，区分输入历史贡献与热噪声、检验被保持的结构是否改变未来作用；最后检验行动后果返回后能否维持学习与结构。参数变化、规模扩展和更换载体实现后，检验这些关系是否仍成立。宏观职责可以分化出来，但分化和有用性都不由“对称破缺”四字直接证明。
