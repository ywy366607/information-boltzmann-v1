## 本次实际改变

此前的生成观察器只记录信念，不接管行为。本次新增显式开关
`--mother-native-generative`：原生物理演化和现有语言读出产生分类预测，
行动前信息价值进入实际等待/词语分布，真实外部后果再通过实际政策score更新既有原生参数及语言/动作头。
没有新增神经细胞、发言率稳态、计数新奇奖励或人为多巴胺电流。

当前可计算未知对象很具体：两个预测算法——当前原生参数与保留的31360原生参数。
两者共享当下身体状态、感觉端口、语言读出及实际时钟。每个外部词到达前，
用真实上一输入、安静区间、JO/PAM输入和逐拍感觉带计算各自的分类似然：

`log w_i <- log w_i + log p_i(y | history, actual sensing) - log Z`。

自听继续改变实际脑状态，不充当外部未知标签。当前算法的预测必须逐项匹配实际身体终点读出，
否则中止检查，不能把复算偏差称作新奇。它是预测算法的预序列加权，不是从Adam二阶矩恢复的贝叶斯后验。

行动价值是该有限未知对象与下个外部词的互信息。
等待与当前原生语言分布提出的四个词，在真实脑状态副本中分别演化一个当前平均输入间隔。
未测词仍保留全部原生概率质量，以等待值作中性参照，不裁掉词表尾部。
词分支以完整词表log-partition进入每一拍的提交概率；实际选词采用相同偏置。
真实首次提交立刻成为世界事件。

实际回复结束时，后验相对回复前的KL结算一次，通过等待/提交及所选词的联合score返回。
原生回放保存未压成概率的运动logit，保留词分支对时机的导数，避免饱和或漏掉交叉分支。
已有KC资格时钟按全部真实tick运输信用；响应结束清理的是统计政策资格迹，不清理生理记忆。
跨来源输入先结束旧因果段，再接收新证据，不让另一类输入替前一动作领取信用。

感觉增益通过实际外部预测误差沿原生输入动力学学习；候选关闭旧词频式看见奖励和固定发声KL。
这是实际感觉学习，不等于已建立完整的潜在世界状态/感觉观测后验。

## 本候选不能晋升为完整探索机制

二元假设的单次互信息最多ln2；在固定身份、相干Bayes更新下，一生累计预期信息也最多ln2。
当前算法持续更新，因而这里更准确地称作预测算法加权；它仍没有表示所有不断出现的世界未知。
这是算法身份信息，不是完整世界状态信息。后验集中不能证明世界已被学会。

当前状态原生提交概率约8.24079e-5/拍，候选仅改变到8.24152e-5/拍。
更一般地，二元专家价值最多让提交odds瞬时放大两倍，不能靠它解除目前沉默。
不加巨大温度系数、不恢复固定发言率，不把小因果效应包装成健康恢复。

新增信用确实经过含KC/MBON/DAN的原生动力学求导并更新可训练原生参数；
它尚未把认识信息变成DAN本地三因子教学信号。已有回复PAM、局部phi继续工作，两者必须分开验收。
单步原生参数梯度、原生参数实际变化和行为收益也分别报告。

下一项生成对象应覆盖随真实经历持续变化的外部世界条件及其感觉证据，
并把可归因的后果学习接入已有局部教学与价值回路。
固定祖先身份、发言配额或额外噪声电流均不能替代它。
本候选保留为实际控制与信用路径的实现参照；默认关闭，主线暂停和全部历史状态继续保留。
