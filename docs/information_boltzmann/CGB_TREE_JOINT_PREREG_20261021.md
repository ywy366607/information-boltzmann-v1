1. 对当前48个类型提取真实骨架的根、分叉、端点及压缩degree-2链后的缆线长度分布。按20261022种子重建空间程序相同的类型内body划分，仅训练body估计新规则，测试body评价。类型等权，报告样本覆盖。
2. 把类型的空间目标和分叉密度用于**有限条件分枝过程**。这仍是出生统计候选，不声称成年骨架证明了发育因果。由有限长度与类型分叉密度决定分叉位点总量；共享工作区限制只限制单次处理的锥，不限制累计树大小。均匀二叉树/森林是临界分枝过程在有限分叉数条件下的分布，不引入逐类型成人邻接表。分支间长度分布从训练骨架估计，路径仍由空间目标场引导。
3. 先报告已保存候选，再运行新候选：分叉密度、端点数、分支间长度、总长度、质心与协方差误差一起看，不能只通过分叉数便叫树形完成。空间分布未获支持时如实保留候选标签。
4. 输入/输出几何与接触使用已有E1c训练标签的真实方向重叠缓存，按类型数量归一后和生成结果比较。该缓存含训练突触标签，只能作为方向接触的描述对照；不把它当新的无泄漏发生率输入，不借此重新拟合锁定的发生率模型。
5. 新旧使用同一48类型、左右配置与空间程序。初版完整存档保留；新状态独立保存、测试完整恢复和材料守恒。预期解除累计8锥上限后分叉密度接近训练估计，并在留出同类细胞范围内；接触和空间误差是否改善由联合报告决定。后两者失败则下一步拟合空间分区/导向，不能继续加分叉来掩盖。
