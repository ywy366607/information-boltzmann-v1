## 优先修复

### 1. 四档延迟缺少对应的历史状态

`fly_graph_observer.py:302` 用 `history_H[0]` 补所有缺失历史；`:481` 每个实际 token 仅调用 `forward([H])`，`:493` 草稿也从单一 posterior 起步，跨窗口仅持存 prior。

因此首次转移中四档延迟都读取同一当前状态。CPU 检查将唯一感觉→运动边从 tier 1 改成 tier 4，单步预测最大差异为 **0**。这验证的是当前算子的时间语义，不代表真实连接组没有延迟。

建议：实际一步、草稿和查询共享起点对应的最近四拍区域历史，随持存状态保存/恢复。出生前未知历史置零；实际已执行历史按时间戳读取。草稿逐步追加自己的预测，保持一到四拍的区别。验收使用延迟脉冲到达时刻，以及窗口拆分/恢复等价性。

### 2. 区域保范存在零状态不可达点

`fly_graph_observer.py:314–316` 将 `cur_H + delta` 重标定到该区域旧范数。运动 latent 为零时，输入消息产生的任何 raw 都被乘成零。CPU 检查中非零感觉消息范数 **5.4772**，运动输出与源梯度范数均为 **0**。

非零区域仍可改变方向，所以该发现并不表示所有通信都被关闭；它限制的是区域幅值变化与零状态的激发。latent LayerNorm 范数也不能等同物理能量。

建议：先保留残差 `cur_H + delta`，由实际响应监督幅值；若需要归一化，明确其表征含义并保证零区域可被消息激发。加入零运动区域的可达性检查，避免投影 bias 在测试中掩盖该边界。

### 3. 学生误差引导查询错开一拍

`fly_bptt_learning.py:188` 以 `quiet_states[0]` 为起点；`student_sim[k]` 是起点之后第 k+1 拍，`:200–205` 却和 `quiet_states[k]` 比较。即使学生预测完全正确，沿时间变化的轨迹仍被计为预测误差。

建议：比较 `student_sim[k]` 与 `quiet_states[k+1]`，并一起将扰动起点改到这一参考时刻；或者给学生轨迹显式添加起点，使双方索引含义相同。物理查询 pair 的重新编码→真实下一拍监督本身成立，待修复的是误差引导的时间对齐。验收：完美预测器应产生零引导误差。

### 4. 九通道先压成一个标量，不能宣称精确闭合

`fly_graph_observer.py:123/:163` 对每个采样神经元用共享 `Linear(9,1)`，再做区域映射。辅助通道线性映射至少有八维零空间。

代数反例：合法权重 ge+gi 下，(.10,.10) 和 (.11,.09) 压缩值相同；同一膜电位 .1、反转电位 1/-.2 下，COBA 驱动相差 **.012**。这是允许参数空间内的反例，未测定当前已训练权重的真实误差。

建议：至少独立保留 E/I 和各档待到达队列，再设计低维区域编码；仍可采用压缩代理，但以响应误差验收其信息保留，避免把九通道输入直接解释成低维 Markov 精确闭合。
