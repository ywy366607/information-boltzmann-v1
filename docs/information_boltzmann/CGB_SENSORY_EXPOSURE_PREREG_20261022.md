# 完整曝光与源—身体证据传递：实施前声明

基线696c15b。本轮落实上轮“先核对完整感觉时段”的后续步骤，不新增学习池或调参追NLL。前轮已见首2ms端口信息弱；接下来分别测完整实际输入路径与冻结慢过程的精确场通道，防止把局部弱信号外推成全脑收不到输入。

## 1. 实际源路径的充分统计

当前源接触满足`q_after=a q_before+C(1−a)V+epsilon`，a=exp(−g_source dt/C)，epsilon方差C(1−a²)。因此创新量`y=q_after−a q_before`的分布不依赖之前的脑／源电荷，只依赖当前源V与本次独立热噪声。当前字节保持4ms，由两个实际2ms步骤组成；两次创新量的似然相乘，不冻结中间的运动、反应、痕迹或结构。

源V是唯一显式含当前字节的转移。给定完整实际状态路径，其余运动/反应/桥交换的条件转移因子不显式依赖V，在比较源假设时抵消。这给出完整路径的**仪器**证据；仪器读到了外部源接触，不是主体只凭内部状态已取得的知识。增加只读source_observer，复制观测数组，不归档观察器；有/无观察器的全部物理数组、三RNG和账本必须逐位相同。

对均匀独立±A输入，完整曝光的每位SNR为`A² Σ C (1−a)/(1+a)`。源创新是独立Gaussian，所以二元AWGN互信息可用确定性Gaussian积分求得；同时给出Gaussian输入上界。该设计下，完整实际路径之外的任何内部测量都不能超过这些源证据；不把均匀设计的信息当作自然文本样本的信息率。

## 2. 脑内终点的条件参考

将上一轮8行逆传播推广到多次_field以及指定脑／世界观测。保持相同温度、4ms、两次2ms、源幅度及现有结构参数，只在这个明确的条件参考里冻结中间反应与运动。可解析比较8脑端、与源连通的全部脑端、脑加世界的信号/协方差；所有存储均为有限观测行数×当前空间节点，不创建全脑历史Jacobian。

这个参考只回答现有输运拓扑怎样传递信号，不能叫完整可塑材料的4ms互信息；条件结构是研究者已知，不等于主体的内在模型。允许的数值核对是实际求解器的源基／噪声基与完整恢复。

## 4. 完整曝光执行后的数值跟进声明

上述实际1024字节续接和16字节曝光现已结束，原报告及执行前源码不改。结果显示源接触信息约3.80 nat而冻结脑终点Gaussian上界约0.0374 nat；这里追加时间离散校验，避免直接把分裂算子误差认作身体物性。

在同一实际前16字节的_field入口，用小规模连续时间线性OU解析解作数值参考：x=C^-1/2 q，M=C^-1/2 L C^-1/2，源矩阵B已由现有电导固定；均值传播exp(−M T)，源增益为积分exp(−M s)B ds，噪声协方差I−exp(−2M T)。验证半群组合和同温平衡协方差。诊断仅支持总坐标≤128，超出即拒绝，不作为物理节点/分支限制，不进入生产求解器。

保持真实曝光T=4ms，比较现有场算子K=2、4、8、16、32、64、128的条件通道与连续极限。K是积分分辨率，不改变输入到达时钟。原实际个体仍按dt2ms推进，仪器不替它跑更长经历；无论误差大小都保留原NLL，不把更改K当作恢复旧预测收益。该补充是看到曝光结果后的数值诊断，不冒充最初盲预注册。
