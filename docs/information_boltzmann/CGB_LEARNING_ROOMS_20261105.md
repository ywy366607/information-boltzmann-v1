## 看什么，失败分给哪段

1. 火的辨识条件：128轮内各房间是否实际被访问；各轮是否提供多个不同落点。未到达的房间不能据此判断金或木不会学。
2. 学习进展：易/较难房间未学时是否改善，熟悉和噪声房间在初步适应后是否趋于饱和。实际身体若遗忘，熟悉房间重新有价值是合法维护，不能按名称强行判为0。
3. 导航：在噪声与可学习房间同时可选的决策上，后半程给噪声的策略概率是否低于前半程；时间分配是否随实际进展变化。报告候选机会和策略概率，避免只比裸访问量。
4. 改变后：第五房间此前是否学过，变化后128轮内是否重访，重访后其独立样本误差是否恢复。个体未观察前无法凭空知道规律变了，回去依赖探索与旧经历。
5. 金的方向：实际g是否与独立均衡未来评分的改变同向。若学习存在、动作可达但g反向或只讨好见证池，下一步修金尺；若g有用而预测/选择用不上，下一步查木到火。

任何方向未获支持，按上述位置报告，停止扩量，不把失败归于语义，也不从一次世界宣称所有导航机制不可能。沿用现有Lean概率/容量/真实后继准入与身体覆盖账本；不为新环境增加覆盖计数。
