# 变化世界中的物料载体、恢复与再充能

本轮将上一轮的恢复证书接到固定身份物料载体上。原身体规则、资源变化、付费再学习、事件时钟及正常/原剪断分支保持不变；载体实现逐事件记录物料的来源、留存、释放和再充能。

三组结果是：有限物料实现、恢复与评分保持、身体加源库存的工作预算。主文沿用 T-AM 条目组织这些结果。

## 1. 物料从哪里来，又去了哪里

身体最多含 4 单位，可访问源库存为 4 单位。构造使用 12 个固定身份载体，其余位于返回池。这个数量是充分上界，不是最小性或生物结构主张。

每个正概率事件从**事件前**的三个库存分别选取：

- i 个源载体进入身体，对应原过程登记的实际摄入 i。
- d 个身体载体进入返回池，对应原过程登记的释放 d。
- i 个旧返回载体进入源库存，由外界做功完成再充能。

三个集合在事件前互不相交，因此一个身份在同一拍只搬运一次。刚刚从身体释放的身份不会在同一拍又被用作源补给。源库存保持为 4；身体含量由原局部收支决定，不另选补给量。

`BufferedMaterial.transport_exists` 证明这些搬运确实存在。`Rules` 要求身体含量及单次摄入不超过 4、释放不超过事件前身体含量，并核验每条正概率事件的原收支。

`RenewableLearningCarrier.rules` 在原 `reopen=true, refill=true` 过程中逐项满足这些条件，正常与原边际幽灵剪断分别成立。上一轮禁止重开、禁止储存的配对版本继续保留各自原证书；本轮载体证书的对象是正常身体规则及其原剪断。

## 2. 为什么载体不会偷偷改变学习和生存评分

载体状态包含原身体—世界状态及各身份所在位置。`realized` 给出原有 `MaterialSource.Realization`：

1. 每个当前载体状态、事件和外部时刻，下一状态的联合分布投影后精确等于原过程。
2. 载体处于身体的个数精确等于原身体含量。
3. 实际源到身体、身体到返回池的身份搬运量，分别等于原摄入与释放量。
4. 两者沿用同一外部时钟。

这使额外身份记录无法影响原动作和学习过程。构造对所有合法载体分布都满足投影等式；不是只比较一条初始轨迹，也不靠另加身体记忆来维持原行为。

`RecoveryTransport.firstHit_eq` 进一步处理依赖当前状态和事件的摄入标记：只要标记在正概率事件上对应，任何有限恢复时限的首次摄入概率都保持。`mean_eq` 保持所有时刻的状态评分期望。

实例中的摄入标记直接读取**是否真的有身份从源进入身体**。据此证明：

- `recovery_by_certificate`：现有局部恢复证书直接推出载体过程的实际摄入恢复概率为 1。
- `score_preserved`：用载体实际身体数量和实际摄入计算的评分，逐时精确等于原 `Exchange` 评分。
- `maintenance_preserved`：正常评分全时为 1；原剪断第六拍起至多为 3/4，优势至少为 1/4。

两个实现分支分别精化上一轮已经登记的正常核与原剪断核。剪断仍使用其自身随时间变化的身体边际；没有换成固定旧动作或禁止写入干预。这里验收的是这两个已登记过程的实现。

## 3. 把源库存也放进能量账本

沿用原离散能量刻度：身体及源库存中的每个载体携带 1 单位，返回载体携带 0 单位。外界每再充能一个旧返回载体，需要输入 1 单位做功。

`sourceAccount` 的系统边界覆盖身体、源库存及返回池：

```text
储能 = 身体载体数量 + 源载体数量
外界做功 = 返回池 → 源的实际搬运数量
热流出 = 身体 → 返回池的实际释放数量
```

源到身体的能量已经在系统内部，因此整体边界的外界物料能端口取 0。它不会在身体账户的摄入之外再被重复加一次。写入信用仍是原身体燃料的子账户。

初始身体含量为 2，外部源库存为 4，整体初始储能为 6。`source_energy_budget` 对正常与原剪断的所有有限前缀证明：

```text
当前期望储能 + 累计期望释放 = 6 + 累计期望外界再充能做功。
```

`stock_and_recharge` 同时证明每条正概率事件的再充能做功精确等于原实际摄入量。持续吞吐所需的补给，因此明确对应外界工作端口；有限身份循环利用不会凭空恢复其能量。

## 4. 当前证据与下一步

这是原有限学习维持模型的来源与能量解释证书。温度、熵产生、材料具体物性和空间搬运速率仍需物理标定；本轮已完成的身份搬运与第一定律预算提供其接入位置。完整规则书与 1% 编码、完整 L1–L6，以及几乎必然的长期学习频率，继续分别验收。
