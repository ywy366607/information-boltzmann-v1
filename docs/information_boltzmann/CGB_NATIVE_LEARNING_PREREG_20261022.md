# 同核学习通量与真实流预测：实施前记录

基线0f16741。现有物理核已有带符号的支持变化：捕获增加C，付费运送减少C；r与P/D保留历史，结构装配/拆解和通道配置也双向变化。本轮先测这些已存在过程，不因要复现生物曲线就另加K/P名字或额外标签池。

## 1. 直接读出已有生成元

对原反应事件及其实际正速率a_e，任意状态观测A的瞬时条件漂移为Σ_e a_e[A(T_e s)−A(s)]。对C、r、桥数、总导通和驱动分别算正/负通量与净量，按原事件种类分解。它只是原学习过程的读出，不改变一个速率，也不是新的奖励/梯度。联合U/G/热功沿原账保留；数值检验逐事件跳变量和模型实际变化一致。

延迟、顺序选择和预测价值是不同问题。非零带符号通量不自动证明完整E5时序规则，历史造成之后学习差异也不等于已有预测收益。本轮用持续真实流和匹配分支将这些证据分开。

## 2. 更新前的物理端口预测读出

8个世界端口编码一个真实UTF8字节。每个新字节到达前，只读取已有脑端电势v和原电容；差模有效电容C_eff=1/(1/C_brain+1/C_world)。声明观测读出模型E_b=C_eff(V_b−v)²/2、V_b=±3，则二态归一化给logit(bit1)=2·C_eff·3·v。8位因子化后得到256字节上的正规概率；不加训练读出头、不调温度，不把该观测模型当成任意文本来源必然服从的物理定律。NLL只在给定新字节后计算，先预测再让它影响任何物理状态。

对照包括同一历史得到的固定字节频率、固定逐位频率及源端自身的期望电压滤波读出。最后一项只是已知源电路的记忆参考，不是新的活体机制。NLL以nats/byte报告，和功/热单位分开；这里不是妈妈正常回复NLL。

## 3. 连续个体、语料与分支

从身份轮已完成的`cgb_identity_cached_20261022/coupled_complete.npz`复制完整状态，保留基因、物料、世界、三RNG与256ms历史。首次正式个体不恢复。这是同一材料候选的研究分支，不重新出生。

语料用本地OpenWebText版本433fe0f44ed7894fea29c08b3202aa348ccc6369，`data/ib_owt_10000`的真实byte tokenizer，offset4，词表260。按清单校验文件哈希；选择train中第一个连续字节区间，长度至少1280且无特殊标记；validation另选至少256的连续字节区间。特殊标记不静默塞入8位编码，不跳掉个体已经开始的流。选择偏移和选中字节逐值保存，test不用于选择或评分。

先让原候选共享经历train的前256个字节作为适配前缀；固定频率基线只累计候选已实际看过的旧书架64字节和这个前缀，然后冻结。之后从同一完整状态分三支：

1. native：原速率与全部原过程；
2. no_trace_capture：只把χ从2变0，保持所有实际状态与历史。参数淬变按ΔU记外部工作，ΔG对应账同步；不擦除r；
3. frozen_adaptation：理想动力学屏障关闭运动、装配、捕获、支持运送/释放、写入与热恢复，r/C/结构固定，快电荷、有限P/D换能、极性流和同一世界仍运行。它是明确的副本诊断，不称为原生命过程。

各段保存完整材料状态与外部流游标、基线计数/滤波状态、累计指标和字节来源；从中途恢复后继续相同实际时钟与输入，检查全部未来逐位一致。语料、参数、干预、生成元通量、前/后快照和实际事件数保留。
