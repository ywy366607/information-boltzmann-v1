# 由未来交换到有限结构的现有通路：实施前记录

基线cf607ee，原候选4864ms、A游标896。本轮先检查已有电荷→P/D→局部接合的后果通路，继续真实流，不为获得“有用”结果另加学习分数或反应。

## 1. 已有物理信用的候选含义

原conversion在节点从电荷交换中形成P；P随后实际支付装配、输运与写入。对给定几何和其他组成的一条未安装接触，原装配G包含`−E_P+log[(D+1)/(B P)]`及自由端／身份因子，故其正向率可写为`a_plus=alpha P/[P+K(D+1)]`，K由原储能、B、端和身份确定。P=0时正向事件不可用；这不是新阈值。下游能获得多少驱动本来就会影响它能支付的结构，构成需要检验的物理后果路径。

P较多、耗散较低、接合较多都不能单独等同预测价值。本轮分开报告实际取能、有限驱动支出、物料周转、原载体留存和更新前NLL，不用这些观察结果改变任何速率。发现正后果也只按实际范围解释。

## 2. 观察实际转化来源

在已有event_observer中附带转化收据：每个池／位置的实际组成变化，脑／世界电端的电荷变化，电容能ΔU_q、驱动能E_PΔP、其他内能以及实际ΔU/ΔG和事件发生前速率。电荷／驱动分解与总ΔU必须相符，纯观察不得影响物理状态、RNG或时间。

`ΔP_i=conversion净量−assembly/write/active/transport净消耗+charged跨点交换`，按真正所有者逐点核对。conversion的电容能减少单列为电场向驱动过程交付的能量，不能把它全部叫作已经存入P的可用功；差额含热，且可正可负。外部源工作、运动/传输热和信息NLL另外核对。

结构载体生存用实际出生／死亡记录，不用“同一对后来又出现”代替同一载体仍活着。诊断记录器只保留当前接合→ID、有限初始cohort和计数，拆解后重新安装有新ID；不进入物理动力学。中途归档同时保存观察器状态，以使后续指标也能精确恢复。

## 3. 连续真实A→B→A

继续原byte数据与既有固定320字节频率：先完成A剩余128个新字节，再经历独立validation的B256新字节，最后回访A适配前缀256。每支384新字节+256已见回访，4ms/byte、dt2ms，4864→7424ms；跨段不重置任何物理状态或驱动/支持/痕迹。先预测再输入，原参考端口读出不重调温度或拟合头，优化器更新0。

主支native保持自然来源候选。两条条件因果支从同一父档，对所有自然有r=1/D可用的边界端口，按既有顺序分别条件执行write−或active−，产生匹配的电荷、P/D与材料，只改变存储r；收据完整记录。这是在允许跳变上构造的条件比较，不声称选择控制器或强制实现这些跳变的概率/代价已模型化，不把条件支作为自然主线。三条初态RNG相同；保留/重构两支的比较才隔离该配置，不能拿它们与native的差异全归因于记忆。

每32字节记录观察量，各阶段完整归档；B中点存档后128未来字节核对全部评分、物理、三RNG、会话及转化/载体观察器。候选以后只沿native支续接，条件跳变支不得混成主个体。

## 4. 短程噪声配对检查

单条随机轨迹长期分离不证明记忆长期有用。额外用8组明确记录的未来噪声种子，在每组内保持两条条件支同状态/同RNG，读取同一接下来64真实字节（256ms）。只改变研究副本未来噪声，不覆盖历史或自然主线RNG。每组都用同一原生跳变匹配。

预先报告的配对量：电容能向conversion交付量、最终P能变化、初始结构载体／目标边界载体留存、总结构变化，以及原始前序NLL。报告全部8组和配对均值/描述性区间，不依响应选种子或调物性；小预算不做容量／收敛／语言能力判断。短程控制结束可由父档和种子重构，不为每个已完成控制都额外保存全脑权重。

结果无论正负都用于定位现有通路：物理后果、相关性、条件因果、预测学习分开。保持同一局部物理、生长与存档主线；全目标仍包括完整时序/延迟信用、预测表示及语言行动世界。
