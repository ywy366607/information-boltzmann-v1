# V3d：把匹配码拟合稳，交付可用的生成器

状态：2026-10-21，新增拟合之前登记。沿用 V3c 的真实 male-CNS 类型数据、极性几何缓存与 E1 划分。
目的：区分匹配规律本身的解释力和优化不稳定造成的损失；保存能重新生成类型对强度的码。

## 问题与模型

保留原式：`b + out[a] + in[b] + geometry[a,b]·w + C[a] A C[b]^T`。
有方向 A 不约束；对称对照用 `(A+A^T)/2`。正则仍为
`lambda * (mean(C^2) + mean(A^2))`。它是连接强度的生成模型，尚不是分子身份鉴定。
只处理原本存在、符合 V3c 门槛的真实类型对；没有增加负例或改变目标。

目标：右侧 `log(W_R[a,b] / (n_R[a] n[b]))`，右侧至少 3 个突触且源类型两侧存在。
划分：CPU torch Generator seed=1、3000×3000 随机矩阵，训练 >=0.10，验证 <0.05，测试 [0.05,0.10)。
几何：只用已有 train-label 的 4 与 2 µm 正反向重叠及零重叠指示。
特征标准化只用训练对；不改变无正则线性项可表达的函数。
测试集是已在 V1/V3 多次报告的历史留出集，不称新独立复现。

## 拟合和选择

- 主要模型：有方向 k=64；对照：对称 k=64、有方向 k=256。
- 种子：0、1、2。初始正则网格：3、5、7、10、14、20、30。
- 同一种子按正则从小到大延续，保留每档的全部参数；每档先 Adam 4000 步，再 L-BFGS 最多 200 次迭代细化。
- 每 200 个 Adam 更新记录训练误差、目标函数和验证误差；L-BFGS 记录每次闭包计算。
- 若平均验证最优在网格边缘，按预定出口向外扩到 1 或 100；不看测试结果决定网格。
- 每个模型按三个种子的平均验证误差选同一个正则，不选测试最好的种子。
- 每个模型的选中正则增加一次 seed=0 冷启动，用来检查延续路径依赖；若明显落后，记录局部极小值而不隐去。
- 选中模型做额外细化，报告目标函数与预测变化；有明显改善则标记仍未收敛。
- 线性的度零模型、几何模型与左侧复本参照用训练集最小二乘求到收敛；同时记录与旧 1500 步基线的差异，避免分母改变造成假增益。
- 所有模型和正则由验证集锁定后，才统一评分历史测试集；报告种子均值、标准差与逐对配对 bootstrap 区间。
- 拟合预算结束仍不收敛就如实报告，不把有限运行时长解释为表达能力上限。

## 预言

1. 有方向 k=64 相对几何的历史测试增益，三种子平均至少 8 个百分点。
2. 稳定拟合后，同一超参数的三个种子测试解释比例标准差 <=2 个百分点。
3. 有方向 k=64 比对称 k=64 至少多解释 2 个百分点。
4. k=256 相对 k=64 的增益不到 2 个百分点，即 64 维已接近这一生成器的有效维数。

以上均可能失败。失败分别指向：旧增益不稳、优化仍未解决、方向性不是主要因素、匹配需要更丰富的码。

## 交付与边界

输出逐次曲线、数据/划分/代码哈希、参数量、实际优化更新与耗时、完整码和正则选择结果。
在数值接口测试中验证稀疏取值与原来密集表达的值、梯度一致，验证存档恢复和类型码重建预测。
不运行新的母女训练、不修改原果蝇个体，不将强度预测分数称为生命、自我或语言能力。

## 运行中预登记的秩尺度补充（256 维运行和任何测试评分之前）

从原正则的代数尺度推出：在相同相互作用与最优因子尺度下，正则系数应随 k^(4/3) 改变。
256 维约需 64 维的 6.35 倍；64 维的验证好区间 10–14 对应约 63–89。
因此在保留原网格和全部结果的基础上，256 维补测 lambda=70、140，各用相同的三个种子，
与原来的 30、100 合并按平均验证误差选择。细化、冷启动、额外更新检查沿用上文。
补充结果另存 refined_report.json，原 report.json 保留。没有按测试结果挑选新增网格。
