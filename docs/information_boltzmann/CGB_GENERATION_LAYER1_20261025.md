# 生成链第一层：公理对平衡律强制了什么（2026-10-25，Claude）

Lean：`lean/CGBAxioms/CGBAxioms/Generation.lean`。五条全部证毕，只依赖 propext / Classical.choice / Quot.sound。

本层只用 P1b（事件只读写参与者，参与者两两接触）、P2a（封闭事件守恒）和 P2b（平衡环境下细致平衡，权重 π 为正）。记 `scope D` 为与 D 中每个单元都接触的单元集合。

## 已证

| 编号 | 定理 | 说的是什么 |
|---|---|---|
| G1 | `jump_rate_local` | 一次跃迁 x→y（改变集为 D）的总速率，只取决于 D 上的新值，以及 D∪scope D 上的旧状态和刺激。 |
| G1E | `equilibrium_ratio_local` | 因此跨一次反向速率为正的平衡跃迁，比值 π(y)/π(x) 也只取决于同一份局部数据：**能量差是局部的**。 |
| G2 | `content_fixed_by_closed_single_unit` | 封闭事件如果只改变一个单元，就不能改变该单元的含量。**体内含量只能靠至少两个单元参与的转移来移动。** |
| G3 | `JumpProcess.reversible_mul_invariant` | 用任何"沿每次移动都不变"的正函数乘以 π，细致平衡仍然成立。**局部能量差只把 π 确定到"移动不变量的函数"为止**；全局耦合可以从这里进入，比如转移守恒下的含量总量。 |
| G4 | `local_markov_of_single_unit_moves` | 如果单元 u 的每个取值都能通过"只改变 u"的平衡移动到达，那么 π(x 中 u:=λ)/π(x) 只取决于 x 在 {u}∪scope{u} 上的取值：**平衡律在 u 处对接触关系局部马尔可夫。** |

## 合起来的图景

平衡律 = 局部决定的能量差 × 移动不变量的函数。

- **只有能量差是局部的**（G1E），能量本身不一定。
- **非局部性的已知来源是移动不变量**（G3）。G2 说明守恒量必然产生这种不变量：体内的含量总量在封闭转移下不变。
- **单单元移动齐全的单元，条件分布是局部的**（G4），这正是 Gibbs 采样的局部规范。按 Hammersley–Clifford 定理，处处局部马尔可夫的正分布可以分解为接触团上的势；这一步尚未在 Lean 中证明。

GPT 的四节点环反例与此一致。**预测：**反例中那个不相邻节点的耦合，是其受限移动集合的某个不变量的函数；把对应的单节点移动补齐后，耦合就消失。请 GPT 核对。

## 尚未证明、留给攻击的命题

1. **G3 的逆命题。**移动不变量是不是非局部项的唯一来源？即：局部的精确 1-形式是否一定是"局部函数 + 不变量函数"的微分？这一点可能存在上同调障碍，没有证明前不使用。
2. **单单元移动从哪里来。**G2 已经排除了体内改变含量的单单元事件。所以单单元移动只可能出现在两处：同一含量层内的构象变化，以及边界上与储库的交换。哪些单元在哪些取值之间有单单元移动，必须由身体给出，不能假设"全部都有"。
3. **G5 猜想（下一条要证的）。**平衡环境下，边界与处于同一势的储库交换含量。如果边界交换连通了各个含量层，并且体内转移在每一层内不可约，那么不变量函数就被钉死为 exp(−μ·含量)：π 等于局部部分乘以每个单元的单体项，整体是局部的。
4. **第二层。**能量之外还剩的自由度：对称导通量 C、跃迁通道、时间尺度，以及有输入驱动时的不可逆部分。生命目标能从中排除哪些？

## 第二层开端：内部永远处于局部细致平衡（2026-10-26）

| 编号 | 定理 | 说的是什么 |
|---|---|---|
| G6 | `rate_interior_stimulus_free` | 由 P1b + P3：若一次跃迁的改变集及其接触范围都不含边界单元，它在任何刺激下的速率都等于平衡环境下的速率。 |
| G6DB | `interior_detailed_balance` | 再加 P2b：这类内部跃迁在**任何刺激**下都对平衡权重 π 满足细致平衡。 |
| G7 | `coupling_vanishes_beyond_scope` | 若另一处改变（例如一个可塑变量）落在 D∪scope D 之外，它不改变 D 上那次移动的平衡偏好：log π 的混合二阶差为零。 |

与已有结果的关系：
- `ConstraintAudit.empty_boundary_every_stimulus_reversible`（GPT）以及 `jump_blanket` 给出的是**整体**版本：边界看到的是平衡环境（或根本没有边界）时，整个动力学可逆。P2b 注释里的"不可逆性只能经由刺激进入"是同一意思的非形式说法。
- `twinCycle` 说明，如果去掉 P2b，单元内部的构象循环可以携带不可逆性。
- G6DB 是**局部且更强**的版本：即使边界正被驱动，每一条内部跃迁仍逐条保持平衡速率比。
  - 内部此时并不处于平衡态：边界注入的概率流可以穿过内部；
  - 但每一步的正反速率比都由平衡能量决定，即随机热力学里的"局部细致平衡"。
  - 驱动只能在与边界接触的那一圈跃迁上破坏这个比。

推论方向（待证）：可塑变量也是状态的一部分，所以内部可塑性的速率比由同一个局部能量决定（G6DB），并且只与接触范围内的活动耦合（G7）。可塑变量影响活动的方式，与活动影响它的方式，是同一个函数（混合二阶差对称）。这正是"互易的、局部的、Hebb 型"可塑性的来源。

## 第二层推导：内部可塑性被迫的形式（纸面推导，依赖 G6DB、G7；与 T7 的关系见末尾）

**设定。**状态分为快变量（活动 s）和慢变量（可塑变量 w），都是单元的局部状态。内部跃迁在任何刺激下都满足局部细致平衡（G6DB），能量为平衡能量 E(s,w)。

1. **学习倾向由局部能量固定，与刺激无关。**
   - 一次内部 w 移动的正反速率比是 exp(−ΔE)，ΔE 只取决于 w 的接触范围内的状态（G1E，G6）。
   - 刺激只能通过改变 s 的分布来影响 w；它不能改变"给定 s 时 w 偏向哪里"。
2. **互易。**ΔE 是同一个函数，所以 w 改变 s 的偏好的方式，与 s 改变 w 的偏好的方式相同（log π 的混合二阶差对称）。这就是一般化的 Hebb：**w 对活动起什么作用，活动就按同一统计量反过来塑造 w。**只有接触范围内的变量能进入这个统计量（G7）。
3. **单靠活动和可塑变量，学习不能改变符号。**
   - 设慢变量的步长小、时标分离。w 的漂移约为 −C·⟨∂_w E⟩，期望取在当时驱动下 s 的分布上；导通量 C ≥ 0，只改变速度，不改变方向。
   - 在任何阶段（清醒或平衡），w 都朝"降低当前出现的活动构型的能量"的方向移动。
   - 极大似然式的对比学习还需要一个反号项 +⟨∂_w E⟩_free（"睡眠期反学习"），而它在 (s,w) 的局部细致平衡下无法实现。
4. **要能改变符号，必须有第三个变量。**
   - 若存在一个局部"相位"变量 p，使三阶混合差 Δ_wΔ_pΔ_s log π ≠ 0（能量中有 w·p·f(s) 这类三体项），那么 p 翻转时 w 对同一活动 s 的偏好也随之翻转。
   - 由 G7，p 必须位于 w 的接触范围内。
   - 由 G6，p 自身的驱动只能源自边界，经由活动传入。
   - 结论：**清醒/睡眠或奖惩式的有符号学习，要求每个可塑位点都与一个由边界驱动的调制变量接触，并带有三体耦合。**这是三因子规则的必要性。生物上的对应是调制性投射（例如果蝇蘑菇体中 DAN 末梢与 KC→MBON 突触的接触）。
5. **学习要消耗摄入。**
   - 若可塑变量的取值占用含量（P1a：有限取值，并有含量代价），由 G2，体内不能单独改变它的含量。
   - 增强必须从邻居转移含量，最终只能来自边界摄入。学习因此与负熵摄入直接相连，对应 T-AM 和 T4。

**与已有结果的关系。**
- T7 原表述只用 P1b，并注明 Hebb／三因子"不能直接推出"。本节在加上 P2b 和 P3 后推出两点：一是互易的局部 Hebb 型倾向；二是"要有符号可变的学习，就必须有三因子"。这仍然只是必要条件：它没有推出具体的函数形式，也没有推出必须使用对比学习。
- T-O 的资格迹结论与此兼容。跨拍信用必须压缩进局部状态，而调制变量 p 正是这种信用能抵达的地方。

**缺口。**
- 慢变量时标分离下的平均（漂移 = −C⟨∂E⟩）尚未形式化。
- "极大似然需要反号项"依赖生命目标对预测质量的要求，即必要性一层，尚未证明。
- 第 3 点的严格版本需要说明：在 C 可以依赖局部状态的一般情形下，平稳偏好的符号不变。

## 第二层 b：整合瓶颈（2026-10-26，Lean 代数核心已证）

**来源。**P1b 规定事件的参与者两两接触，所以改变单元 v 的事件只能读取一个含 v 的团。若 v 的邻居分成几个彼此不接触的部分，每个事件至多读一个部分，于是上翻、下翻总速率都是"各部分单独函数之和"。细致平衡要求两者之比等于平衡因子。

| 编号 | 定理 | 内容 |
|---|---|---|
| G8a | `two_part_balance` | 两部分、乘积因子 φ₁φ₂：取上翻 aφ₁ + bφ₂，下翻 b/φ₁ + a/φ₂（交叉构造），总能实现。 |
| G8b | `three_part_balance_impossible` | 三部分、每部分因子都非常数：任何非负的下翻速率都会在某处为零，与正速率矛盾，**不可实现**。 |

- **数值核对**（线性规划，随机耦合各 30–50 组）：1、2 个互不接触的耦合邻居全部可行；3、4 个全部不可行。能被 2 个团覆盖的结构（{0,1}+{2,3}、4 环）可行；需要 3 个团覆盖的（三角格子 6 邻居环、{0,1}+{2}+{3}）不可行。
- **推论：**单个单元在能量上至多对 2 组互不接触的邻居敏感。要整合更多输入，只能经过中间单元逐级汇合，即二叉树式会聚。
- **可证伪的预测：**这对应神经元树突以二分叉为主的形态，可用连接组骨架的分支度分布检验，尚未检验。
- **尚未形式化：**从 `Medium.jump` 到"各部分之和"的桥接（需要按事件读取的部分对速率求和分组）；非乘积型平衡因子的一般刻画；多值单元。
- 仓库中原先没有此结论（已检索 Lean、文档、代码）。文献中是否已有同类结果尚待查证。
