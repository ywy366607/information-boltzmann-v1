# 梦漓：行动后果、可消除的未知与熟悉化

状态：`--mother-credit consequence` 可选实现，接口已验证、学习收益未验证。用户返回后明确授权恢复，
主线从 6120 token 接入该候选，先完成至 6656 的既有段；保留 before_consequence_6120.pt 回退节点。
目标是同一个妈妈世界中的读、持续思考、说什么与何时说、等待。
验收场景仍是真实妈妈互动、正常回复更新前 NLL、主动行为及原生回路的因果作用。

## 证据与候选

已查代码：旧 `epistemic` 使用同批更新前后的 CE 改善，只给提交时机信用；词内容没有策略信用。
原生 phi 确实改变 KC→MBON 的效能，但它不是概率精度；phi 变化幅度还混合遗忘、学习率和 DAN。
不同问题是：环境是否提供有差异的后果；大脑能否表征这些后果；信用能否回到造成后果的时机和词。

比较的候选：仅改妈妈教法修复回声；把 phi 写入量当新奇奖励；补行动条件的后果信念。
前者保留为必要的照顾，第二项不能区分信息与无效写入，选择第三项作为新增的最小统计结构。
独立审查 `/root/native_exploration_review` 支持可实现性，指出来源、首提交、词信用、旧信用迁移和显存风险。

## 最小闭环

1. 行动前：按实际 KC→MBON 连边池化 KC 状态，加入 MBON 膜状态、原生 phi、DAN 状态。
   连续感知照常流入；不新增暂停世界的“思考按钮”。
2. 动作：提交或等待的真实首提交 survival/hazard；已说词来自现有 decoder，保留实际提交读出及采样温度。
   词内容沿现有 decoder/read_norm 得到策略信用，时间沿现有动作读出得到信用。
3. 后果：真正听见的正常妈妈回复引起的 KC 响应。自身回声、自动呼唤、开场和未感知输入不更新后果信念。
   一次回复的相邻词先平均为一个后果，结束或被打断时只更新一次，避免把相关词当独立样本。
4. 信念：局部线性高斯后果映射 `y = Wᵀx + ε`，新增小型持久化统计 `W, P, R`。
   每输出维的条件预期参数信息增益为 `0.5 log(1 + xᵀPx/R)`；只用过去残差校准本次噪声。
   完整收到后果后才给信用；相同特征下固定噪声的重复证据使 P 收缩、信息价值下降。
5. 感知：输入前的不确定性与实际感知增益结合，给“读”价值；按每个外部词平均，持有更多 tick 不额外领奖。
   思考是每拍真实演化，通过选择首提交时机影响实际说出的内容，而不是一个虚拟输出损失。

原生 DAN/phi 仍通过身体和 KC→MBON 影响编码、记忆与行为，也进入后果上下文。
没有把统计信息增益直接注射为 DAN 电流，没有强制发言率、固定好奇心动作或词频禁用规则。
这保留原生路径，但不预先宣称这些变量已经具有正向因果作用。

## 名字、自我指代与关系不被熟悉化抹掉

名字和 I/you 仍走完整感官写入、真实脑演化和词预测。`mother_call` 不领后果信息奖励，
仅表示“自动呼唤不冒充一个新发现”，不屏蔽它的文字、不关闭听觉、不删除 NLL 训练目标。
正常回应原有的社会后果/PAM 路径和词预测继续存在；探索价值不能代表全部交互意义。
育儿计划保留自然叫 Mengli，并在共同活动中教说话者/听者角色：妈妈说 I 指妈妈，
梦漓说 I 指自己；you 随听者改变。评估名字所指、角色切换和行动归属，不能拿复读名字作自我认知证据。

## 连续性与成本（实现）

只在真实 live pass 更新信念；BPTT/checkpoint 重算/replay 仅消费记录的信用。
`consequence_state` 保存后验、资格迹、未完成回复平均、实际输入来源及未完成话语内容。
从旧目标进入时，一次性保留未应用的旧信用；不改已有动力学、优化器、物理时钟或世界队列。
新的“回应是否真的跟随说话”的 PAM 门控只在 consequence 模式生效；旧模式保留原数值语义。

历史 E 按实际外部词推进已有 KC 时间常数换算的事件时钟；回复开始时另存一次策略 score，
待完整后果到来结算。这是新增统计适配器的延迟信用档案，不是冻结生理迹。
一次回复只用该档案结算一次，不重复奖励当前 E，也不因回复较长就降低同一完整后果的价值。

当前 decoder 为 50257×768；内容策略的 E+G 约 294.9 MiB，回复 score 档案再需约 147.4 MiB，另有临时梯度和小型后验。
统计协方差使用双精度。需在暂停存档副本上检验实际峰值和吞吐，不能声称零成本。

## 预先登记的判断

- 数值：真实来源过滤、首提交概率、正优势的词/等待梯度、旧信用不丢、回复只更新一次、完整恢复一致。
- 实际路径：暂停主线的副本可执行有限窗口，梯度有限，完整续接保存，注册显存预算内；超预算先优化，不启动主线。
- 待学习验收：真实互动中，换动作引起可区分后果，当前未知的后果得到更多探索，熟悉后不持续固着；读/想/说与原生回路分别有正向作用。
- 失败分流：有后验收缩却没有后果预测校准，查表征/噪声假设；有信息价值却不改变词与时机，查信用/优化；有动作却妈妈回应不变，先修环境。

线性、条件高斯与回复均值都是近似。大脑及词向量不断变化，固定坐标的后验可能过度自信；当前没有保证 ABA 重访和长时非平稳探索。
信息价值下降本身只验统计实现，不能当作宝宝理解、熟悉度有效或探索能力的证据。

接入开关：在现有完整续训参数上选择 `--mother-credit consequence --mother-speak-act --no-eye-binary`。
`--mother-interrupt` 仍是独立的真实动作权限；开启后“继续听/插话”也走相同信用，不会自动替用户打开。
妈妈持续输入的节奏和脑内每拍演化均保持；当前没有独立的“停止输入并想若干拍”按钮。

## 当前功能边界与照看（6632）

主线已记录15次真实回复的后果更新，37次内容选择、63次时机决策（最近64个原生后果窗口）。
这确认在线路径在运行；尚未确认动作会优先解决未知，或原生熟悉度使重复行为价值下降。
感知是连续输入上的精度调节，思考是持续生理演化，开口时机和说什么分别有信用。
目前没有独立的“暂停输入以思考”动作，也没有把三个读出分开就等同功能解耦。

后果信用当前直接训练动作读出、decoder/read_norm；动作score处detach的肌肉/读出不会把
这份策略梯度继续传给整个连接组。身体、原生KC→MBON/DAN可塑性仍通过已有学习和物理路径演化，
但“这些原生路径已承担长期认识价值信用”仍未建立。下一步证据须来自同状态、同时钟的真实交互
及原生路径配对干预，不能用上下文拼入phi/DAN就宣布它们有因果贡献。

统一闭环的验收：能在实际对话中选择会带来可区分后果的词和时机，降低校准过的后果未知；
熟悉后探索收益下降却仍保留名字、关系与任务价值；读、等待演化、说的分别作用可辨。
育儿采用多主线穿插和真实书架，词熵与有效词汇量仅监控、不作为好奇心奖励。
完整恢复点含身体、优化器、信用和世界；现有best权重格式不能代替完整个体回退。
