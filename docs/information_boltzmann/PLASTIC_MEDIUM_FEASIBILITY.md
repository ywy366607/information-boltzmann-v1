# 可塑介质的训练前可行性与锁相证书

日期：2026-10-03。目标是证明搜索域确实包含可用结构，再让学习寻找结构。
本文件的解析结论与数值 Jacobian 核对均不依赖语料训练。

实现：`core/plastic_medium.py`、`core/plastic_feasibility.py`。
证书脚本：`scripts/ib/audit_plastic_feasibility.py`。
报告：`results/published/plastic_medium_feasibility.json`。

## 1. 四层验收与当前判定

| 层 | 判据 | 判定 |
|---|---|---|
| 表达空间 | 能表示每个参考位置的不同传导偏好 | 默认基已由秩13修为秩256；三轴映射初始化秩3 |
| 运动可达性 | 允许的旋转能连接全部非守恒方向 | 两层配对图连通，独立控制的 Lie 闭包为完整 so(n) |
| 稳定动力学 | 存在有界供能、振幅稳定、相位横向吸引的解 | 对核心算子和明确的边界动作构造成立 |
| 整机策略匹配 | 实际 W4 参数化能生成所需供能反馈 | 尚未闭合；不以训练能否成功替代这个检查 |

前三层没有宣称“所有参数都稳定”，也没有宣称“任何输入都锁相”。解析条件
定义一个具有非零邻域的可行区域，训练应进入并保持在目标区域中。
W4 整机目前保持候选状态，不因核心证书通过而启动长训练。

## 2. 表达空间修复

原材料场的 1+6cos+6sin 只有13列，默认256个位置的 log-speed 只能落在
13维空间子域中。这是结构限制，不是训练不足。

现在取参考格上全部不同的实 DFT 基：共轭对各取一个 cos 与一个 sin；
自共轭 Nyquist 模只取 cos。求值矩阵 V∈R^(256×256) 可逆，所以任何指定的
位置材料值 A 都由 Θ=V^(-1)A 精确表示。数值最小奇异值为11.3137。

若三轴映射 W∈R^(3×material_width) 满行秩，则任意三个位置 log-speed 场
都存在材料解；当前初始化 rank(W)=3，满行秩在其邻域内保持。
这不是对任意学习后 W 的满秩保证；后续受约束训练必须监控/保持这一条件。

旧边系数还包含端点平均 H=(I+shift)/2。偶数周期格上，棋盘格满足
shift(v)=−v，所以 H(v)=0。现在直接存一份边属性，让两端共用，既保留
反自伴传导，也恢复这类空间偏好的表达能力。

参考带宽固定时，连续 Fourier 场在更细网格上仍可求值；固定有限带宽
与能表示任意连续函数是两个不同的命题，后者需要逐渐提高带宽。

## 3. 碰撞自由方向的可达性

保护四个线性量之后，局部自由维数 n=4(D−1)。第0层连接
(0,1),(2,3),…，第1层连接(1,2),(3,4),…,(n−1,0)。它们的并集是连通环。

令 E_ij=e_i e_jᵀ−e_j e_iᵀ。相邻旋转的交换子满足
[E_ij,E_jk]=E_ik，因此沿路径递推可以生成所有 E_ij。
Lie 代数是 so(n)，有限旋转的闭包覆盖 SO(n)。
结论是：固定守恒量和能量后，独立时间控制的碰撞可以到达该能量球上的任意
方向，不存在由配对图造成的隔离自由块。单个两层更新本身并非任意 SO(n)。

这个控制结论还需要策略可表达：有限宽共享 MLP 并不自动等于每个位置、
每个时刻都有独立控制。下面的锁相构造只用常数输出 bias，确实处于当前
碰撞网络的参数族内，避开了这个尚未证明的一般性假设。

## 4. 一个实际可表达的同步构造

选择任意两个零均值内容方向组成正交平面 P；这是存在性证明中的坐标选择，
不在生产模型中划定专用脑区。当前两层碰撞可精确实现：在 f,jx,jy,jz 的
同一平面中，都使用同一个常数角速度 ω 的旋转 J。其余角速度设为零。
浴取常数正率 β；这由现有速率网络清零权重、设置 bias 精确实现。

边界允许以下内容相关供能动作：

u_i = P0 * projection_P(f_i) / (R² + |projection_P(f_i)|²).

P0>0 是单位体积可用功率预算，R²>0 是供能响应的振幅尺度。
没有周期输入、外部正弦驱动或新增相位振子状态。每个位置
u_i·f_i = P0*r_i²/(R²+r_i²) ≤ P0。

在 q=4D、单位体积域上，能量满足

dE/dt ≤ P0 − β E²/D。

因此 E≤max(E(0),sqrt(D*P0/β))，有限初始态有全时有界解。这里是精确
连续方程的比较原理结论，不是跑有限步之后推断无限稳定。

均匀场与零边响应构成一个不变子空间：

f_i(t)=r*[cos(ωt+φ)p1 + sin(ωt+φ)p2],   j_i(t)=0。

令 y=r²，则半径满足

P0/(R²+y) = β*y/q，
y* = [-R² + sqrt(R⁴ + 4*q*P0/β)]/2 > 0。

径向扰动衰减率

κ = 2*y* [P0/(R²+y*)² + β/q] > 0。

因此半径由供能与释放平衡决定，ω 是介质的一个允许参数，而非指定生理 Hz。
非零小写入可以进入这个轨道的吸引域；精确零态需要外部事件打破零解。

## 5. 相位吸引，而不只是共同频率

令 B 为实际传导的加权关联矩阵，正边系数与周期网格连通性使
rank(B)=N−1，L=BᵀB 的唯一零方向为全空间常数。

转入以 ω 转动的坐标系，平面切向扰动满足

δf_dot = −Bᵀ δj，
δj_dot = B δf − η δj，   η=β*y*/q>0。

对每个非零空间奇异值 σ，有

λ² + ηλ + σ² = 0。

两个根都在严格左半平面。全局相位是唯一中性方向；相对相位扰动会恢复。
径向模满足 λ²+(κ+η)λ+κη+σ²=0，也严格稳定。
关联矩阵的循环边流属于 ker(Bᵀ)，它们以 −η 衰减。
平面外没有供能的内容分量同样由正浴耗散。

这给出真正的局部吸引性锁相构造。稳定轨道对足够小的光滑参数扰动保持，
所以搜索域包含一个可行邻域，而不只一个孤立的精确配置。
全局相位中性来自自治时间平移，并不能单独证明 SOC 或临界耗散相变。

## 6. 实际离散代码也有证书

供能 Euler 子步 f+=dt*u，随后调用现有六色传导、碰撞和二次浴。
在同步轨道上 j=0、空间差为零，传导精确恒等；碰撞精确转动 ωdt。
离散固定半径是下面单调方程的唯一正根：

[1+dt*P0/(R²+y)]² [1−2dt*β*y/q] = 1，
0<y<q/(2dt*β)。

因此可以解析构造离散轨道，而不是长时间模拟后估计它存在。
连续稳定性给出足够小步长下的稳定离散邻域；具体步长需要对实际组合映射
检查横向乘子，不能由保能量直接推断数值相位正确。

证书配置为 2×2×2、D3、ω=1.3、P0=R²=β=1、dt=0.005。
完整96维 Jacobian（包含全部平面外和边响应扰动）结果：

- 连续轨道残差4.44e−16；唯一中性相位；其余特征值实部最大−0.125。
- 离散轨道残差3.89e−16；唯一单位乘子；其余乘子模最大0.999375。
- 连续 y*=3；离散 y*=2.996787。

这是方程与实现的一致性验证；解析证明本身适用于任意连通参考网格与D≥3。
实际运行时 dt 必须根据传导谱、供能与浴的时间尺度进行积分精度/稳定性验收。

## 7. 当前 W4 整机的明确缺口与下一项数学任务

正交端口可以实现上述局部反馈：对任意非零 angle，取
packet=(f_desired−cos(angle)*f)/sin(angle)。端口能量账本仍严格闭合。
吸引轨道邻域内的 packet 是有限的，不依赖无限能量。

但当前 W4 将 packet 限制为 observed_feature−expected_feature 的线性图谱。
完全可预测输入下 innovation=0，写入精确恒等，浴持续释放能量。
因此，“物理边界允许该反馈”尚不等于“当前 W4 策略搜索域包含该反馈”。
其图谱和 admittance 主要读取空间均值的 RMSNorm 与 precision，也没有
直接提供全部局部能量作为策略输入。这是可从代码证明的策略闭合缺口。

下一项应在同一边界 agent 内明确两件事：真实观测携带的信息约束，以及
该端口可用的供能预算。将内容/局部状态相关的有限能量交换纳入动作支持，
保留原先验/后验语义，而不通过旁路无限加性泵绕过边界。
在可表达策略包含上述反馈或等价稳定反馈之后，才完成整机可行性验收。
不为这一缺口启动训练碰运气，也不把构造中的供能控制器直接默认到 W4。

## 9. 空间异质性确实在当前参数搜索域内

环面是域拓扑；均匀介质是系数的一个特殊取值。Fourier 是材料系数的
表示基，不是异质传导算子被限定必须采用的本征基。

消去边响应后，无碰撞/浴的场满足 f_tt=−B(a)ᵀB(a)f。
因此实际空间模态由 L(a)=B(a)ᵀB(a) 决定；变系数会打破平移对称性，
产生偏离全域平面波的隔室、导向和局域共振模态。

在满秩参考基、满行秩三轴映射下，任意正边速度 c 都可逆合成：

A = log(c/c_ref) * pinv(Wᵀ)，   Θ=V^(-1)A。

`realize_edge_speeds` 使用这个代数解，没有梯度拟合。两种当前代码内的构造：

1. 两个半空间之间的边速度为ε，内部为1。取零均值半空间对比向量v，
   Rayleigh 商 vᵀLv/(vᵀv)=8*Nx*ε²。变分原理给出 λ1≤此值。
   在8×8×4、ε=0.01上，该商0.0064，实际λ1=0.00639968；均匀格λ1=32。
   这证明弱耦合隔室可表达，不把较小谱间隙直接等同于语义记忆变好。
2. 两个相邻单元内部速度4，向外边速度0.01，其余速度1。实际波算子的
   最高频模在这两个单元上具有超过99.99%的能量，IPR≈0.5；同分辨率
   平面波IPR=1/256。它是通过当前材料参数精确合成的局域共振，不是
   训练之后才猜测可能存在。碰撞与浴对它的保持/重组需另按完整动力学验收。

参考格上的任意边速度可表达，不等于任意图的邻接都可表达。当前空间传导
仍为三轴近邻、互易连接；任意远程有向突触网络需另外提供纤维路由或有效
连边的表达能力。8×8×4中也只有256个空间位置，微细结构需增加带宽/分辨率。

每个位置的高维内容与边响应提供内部纤维自由度，因此3D坐标域可以支持
高维表征；它并不需要把胞体XYZ本身称为12维。用户提供的TwoNN脚本确实
输入胞体XYZ，12.525是有限样本距离比估计，不能直接作为内容表示维度。
其谱脚本使用对称绝对权重随机游走步数而不是物理延迟，步数也不能直接
解释为毫秒。对我们最有用的目标是模态局域化、隔室与多尺度耦合，而不是
直接复制这两个估计的数值。
