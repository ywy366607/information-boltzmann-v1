# KC轴突间调制：真实接触、释放与cAMP

本轮把此前漏掉的KC轴突间化学通路接到现有末梢释放和接触级学习规则。没有解除胞体快兴奋权重的限制，也没有把所有轴突接触当作兴奋电流。主线32384继续暂停；33000候选没有新增正式输入或优化器更新。

## 生物依据与实现边界

[Manoim等，2022](https://pmc.ncbi.nlm.nih.gov/articles/PMC9613607/)发现，KC轴突间的乙酰胆碱可经mAChR-B抑制钙及cAMP信号；不同KC亚型的表达并不相同。因此，本轮保留接触位置和原有延迟，新增局部受体占有与细胞内抑制信号，分别进入现有钙相关释放接口和DA驱动的cAMP学习接口。受体动力学、运输及两路效应增益按KC可学习；初值是有效模型初值，并非测得的分子密度或生物时间常数。

[2026年的电位依赖研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC12948350/)指出，mAChR-B作用还受去极化调节。当前KC轴突局部电位/AP和该受体的电位依赖尚未接入；本轮不能称为完整受体电生理还原。统一非零初始增益也不是αβ/γ/α′β′表达图谱，亚型表达约束仍待接入。细胞内运输场是有效Gi/o信号，未指定未知分子的身份。

## 解剖与计算路径

- 原缓存的1,119,929个非calyx KC→KC接触，映射到727,972个接收形态节点，涉及619,572条连接；包含此前快胞体模型固定为零的全部612,115条纯轴突连接。
- 保留4,184,720个KC形态节点、709,034个释放位置和已有1–4拍延迟；接收位置投影到原树的最大距离约3.582µm，这是几何映射误差，不能称为受体分子定位。
- 已保存的旧延迟末梢包驱动局部受体，受体信号沿同一KC原树传播，没有跨树虚构连接。
- 钙效应门在资源释放计算之前生效，改变实际消耗与发出的包；cAMP门进入接触级学习规则，不直接把DA活动乘一个分数。启用相对突发/cAMP积分时，门作用于积分输入，保留已有积分历史。
- 新增两份逐节点持久状态，共33,477,760字节（约31.93MiB）；新增24,384个逐KC可学习参数。没有新建全局历史Jacobian。路由索引、求解临时空间、优化器与反传开销另计，不能把状态增量当作总运行显存。
