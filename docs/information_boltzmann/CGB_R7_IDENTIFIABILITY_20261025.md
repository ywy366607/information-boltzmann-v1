# 逆发育的可识别性：相同现象何时无法确定生成机制

状态：**可识别性与生物机制解释仍为纸面推导＋数值核验；有限支持的首次成功恒等式、截断界和概率范围已由 Lean 验证**。生物机制尚未独立验收。不拟合新参数，不推进物理核或训练。沿用已公开并已看过的 R7 Control 结果，因此是探索性审查与历史评分复核，不是新的盲检验。

本次问题是共同生成规律能被哪些证据识别：①寿命能否区分出生差异与经历导致的改变；②加上数量和周转是否足够；③什么额外观测或干预能区分。固定差异、动态捕获及观察选择仍是竞争解释；以下先给出前两者的精确等价构造，未通过拟合排除观察选择。

## 1. 一个离散等价构造

令 n 从首次可见开始计数，每步是原数据的一分钟观测间隔。这是观测层的离散核，不把它认作完整神经系统的基础时间分辨率。D 表示消失且吸收。

**固定差异 H₁。** 每次新出现时，以概率 p 取慢类型、1−p 取快类型；一次存在期间类型不变。两种类型每步继续存在的概率分别为 v、u，其中 0≤u<v<1。寿命的存活函数为：

    S(n) = (1−p)uⁿ + pvⁿ。

**动态捕获 H₂。** 每次首次可见时都在 U；每步 U→U 的概率 u，U→C 的概率 k，其余 1−u−k 到 D；C→C 的概率 v，其余到 D，没有 C→U。合法性要求 0≤k≤1−u。初始 U₀=1、C₀=0：

    Uₙ₊₁ = u Uₙ，Cₙ₊₁ = k Uₙ + v Cₙ。
    Uₙ = uⁿ，Cₙ = k(vⁿ−uⁿ)/(v−u)。

因此取 **k=p(v−u)**，就得到与 H₁ 完全相同的 S(n)。由于 k≤v−u≤1−u，此映射始终给出合法的离散过程。证明可由递推代入及归纳完成；这是已给出推导、尚未 Lean 验证的条件命题。

原观察规则中，在持续 d 拍后结束的概率是 S(d)−S(d+1)，右删失的概率是 S(d)。两者在所有 d 上相同，所以任何只依赖起止帧的似然都无法区分 H₁/H₂。即使样本无限多、优化完全收敛，这个等价构造仍然存在。

**适用范围。** 类型是每次出现时抽取，寿命彼此独立；捕获没有反向转换，首次可见时为 U；当前观察只区分存在／消失。若固定类型跨多次出现保持，或已观测到状态标记、资源耦合或特定干预，等价需要重新审查。

## 2. 数量和周转也可能相同

给两个模型相同的、独立于这些隐藏类型／捕获状态的出现过程，并匹配窗口初始残余分布。每个对象的可见存在区间由出现时刻和寿命确定。寿命的联合分布相同，意味着整组可见区间的分布相同；数量、出现／消失、计数相关和 Fano 都是这些区间的函数，因此分布也相同。

例如在平稳、恒定观测出现率 λ 的条件下，两者都有：

    E[N] = λ Σₙ S(n) = λ[(1−p)/(1−u) + p/(1−v)]。

这纠正了上一轮计划中的一处期待：**联合数量—周转可以检验某个闭合，却不保证识别隐藏机制。** 观察到资源依赖的跨对象相关，可能排除独立模型；要把它归因于动态捕获，还需与共同外界驱动、固定差异等解释比较。

## 5. 干预到底约束哪一层

核对[原论文的方法与机制模型](https://www.nature.com/articles/s41467-020-14781-4)以及固定版本的 `Description.docx`、`DataImport.m`、`DataImportBulbous.m` 和 `MechanisticModel.m`：作者区分普通突起、短暂 bulb、稳定 bulb 和突触；其机制候选把保持与所积累资源耦合。作者的 Control／Atg6／Atg7 模拟通过改变可用资源总量表达组别差异，资源初值由各组平均 bulb 数校准。该数值不是独立测得的分子库存，也不是对未见数量的预言。上调自噬条件还改变了资源对保持的作用形式。

因此，把基因型直接当成我们两态核中“只改 k”或“只改 v”的干预，没有完成作用靶点识别。论文实验为资源可用性与保持的联系提供依据；其具体资源占据数、反应形式及观察阈值仍是候选，不能移入一般公理。当前也不能把格式有冲突、缺标记字段的 rescue 表与其它组当作同质验收材料。

### 条件干预关系

下列是选定局部过程后的条件预测，不是已登记为真实自噬基因的作用方式。先确认干预靶点，才能用数据验收。

- **只改变捕获。** 保持直接消失概率 δ=1−u−k 与 v 不变，改变 k，则 u=1−δ−k 也必须改变。由寿命反演出的参数应保持 `1−u−p(v−u)=δ`。所以“捕获改变而快率必不改变”不能直接宣称为预言。
- **只改变 C 的保护。** 保持 u、k 不变而改变 v，则 `p(v−u)=k` 必须保持；慢项系数也随 v 改变。只看慢寿命不足以验收这个干预。
- **直接观察转换。** 同一突起的状态出现／退出记录，可区分一次存在期间类型不变与 U→C；只记录最终寿命不能提供这个区别。
- **检验共同资源。** 需要观察或干预邻近负载／资源，预先推出跨对象响应。任何跨对象相关都要同时检查共同输入和测量因素。

这些恒等式保留为条件预测；当前真实基因型尚未识别为其中某一个单参数干预。接续应优先使用共同观测层能支持的关系，再用标记与靶点资料检验更细机制。

## 6. 无须先选择捕获载体的相遇—保持—转化关系

为了让逆发育接回脑生成，提出共同的可检验接口，而非再指定一个生物部件。令 T≥1 是一次接触在离散观察层上持续的可作用拍数，`S(n)=P(T>n)`。登记候选 H_G：每个可作用拍有相同局部成功概率 r；成功试验与原接触寿命独立；首次成功前不改变原接触过程。T 的起点须对应实际可作用接触，当前 R7“首次可见突起”到该起点的映射仍待识别。

给定 T=t，没有成功的概率为 `(1−r)^t`。按首次成功的拍数分解，得到：

    Q(r) = E[1−(1−r)^T] = r Σₙ≥0 (1−r)ⁿ S(n)。

这一步来自所登记试验与寿命的概率结构，不是守恒单独推出常数 r 或独立性。对于上文的两项存活函数：

    Q(r) = r[(1−p)/(1−(1−r)u) + p/(1−(1−r)v)]。

由此得到三个有用结论（概率解释依赖 H_G；一般分布关系为纸面推导，有限支持的下述部分已形式化）：

1. **精确粗粒化。** 具有相同 S 的两种隐藏实现给出相同 Q，无需为计算这项首次成功概率展开其内部状态。这只保证声明的输出；成功本身改变保持、r 依赖隐藏资源、或存在多伙伴竞争时，需要联合过程，不能沿用独立乘法。
2. **可用时窗的共同约束。** 若一个条件在所有 n 上都增加 S(n)，它在所有 r 上都不降低 Q(r)。在单几何寿命 `S(n)=sⁿ` 的特化中，`Q=r/[1−(1−r)s]`；增加 s 会使较小 r 的相对成功率增幅更大。这提供“延长保持可能放宽伙伴选择”的条件预测，无须预设错误伙伴名单；多项混合仅逐项单调，不自动继承所有相对比值结论。
3. **有限观察的误差界。** 只使用前 H 拍，令 `Q_H=r Σₙ=0…H−1 (1−r)ⁿS(n)`，则 `Q_H≤Q≤Q_H+(1−r)^H S(H)`。这是给定真实 S 的截断界，估计 S 的统计不确定性另计。它给出未观察尾部的明确区间，允许在有误差界时停止展开，无须把拟合长尾当成已观测的无限记忆。

若某类伙伴每单位观察时间的实际相遇数期望为 λ_j，各次机会满足上述条件，则首次成功通量候选为 `J_j=λ_j Q(r_j)`。λ_j 连接相遇证据，r_j 连接身份／局部作用，S 连接保持证据；三者约束同一个输出，而非三套独立评分。J 不是稳定突触总数，后续保持和资源回流仍需计入完整过程。现有 V3d 给的是已连接对的条件强度，不是 r_j；不能未经校准便把低秩分数代入成功概率。不同动物、阶段和资料中的 λ、r、S 也不能直接拼数。

### 后续验收与判错

先登记实际接触、转化事件和标记的对应，在发现材料上约束 λ、r、S，再固定输出 J 的预言。若同一对象的观察／干预显示 r 与保持共同变化，就检验联合状态依赖；若实现不满足上式，先检查首次成功时序与寿命定义；若上述前提都通过而 J 的预测失败，审查 H_G。所有候选仍受局部性、资源和完整编码合同约束。

本轮只建立接口与条件预测，没有用现有组别重拟合 r，没有增加捕获载体、噪声或反馈组件。它允许在未识别微观材料时推进有效规律，同时将物理实现和真实能力的检验保留在各自层级。

## 7. 对旧两态表述与生成脑路线的修正

连续时间版本若 U→C 率为 c，U→D 率为 f，C→D 率为 s，初始为 U，令 α=f+c，则在 α≠s 时：

    S(t) = [1−c/(α−s)]exp(−αt) + [c/(α−s)]exp(−st)。

慢项系数是 c/(α−s)，消失前捕获概率是 c/α；只有 s≪α 时才近似相等。α=s 时为 exp(−αt)(1+ct)；其他参数区间的指数系数还可能为负。因此“两态捕获必然给出正权双指数且慢组权重等于捕获概率”需要修正。上述离散映射的 k/(1−u) 是观测到 C 的概率；它也不等于连续时间中发生过、却可能在两帧间已经消失的全部捕获概率。

对统一生成脑的意义是：**由现象反推规律，首先识别的是指定观测／干预下的等价类。** 应当寻找这个等价类中满足资源与因果要求的简洁实现，再靠新的作用条件收紧它。被动观察相同不保证干预响应相同；粗粒化必须保留目标行动需要区分的状态。当前结果提供了机制筛选的判据，没有把捕获、资格迹或任何生物部件提升为一般公理。
