## 从实际方程定位断点

已有问题：11月17日起持续追踪的内容收益采信为零，C2完成准确支付后仍存在。本轮新增定位是收益头的训练与使用计算不同。

- 使用：`navigation_internal_rollout.continuation`，预测为C2当前基线 `b_C2` 加裸头残差 `r_plain`。`causal_use_value.begin`的行动前采信快照也用这条裸头路径。
- 目标：真实有限U净用途的10倍；收益标签带结算版本，原actor/critic沿用后到信用。

同一条真实经历在两条路径间的差额：

`read - train = b_C2 - b_old + r_plain - r_context`。

旧损失在某个参数处拟合准确时，实际读出误差仍等于该参数处的差额。训练改变参数也会改变差额，故本轮分别保存实际差额与实际更新方向，不把当前差额当成训练后的固定误差下限。
