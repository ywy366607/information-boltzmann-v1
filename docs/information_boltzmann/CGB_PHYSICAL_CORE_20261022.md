## 1. 实际守恒量、能量与熵

对一个局部单元i，n_ia表示内部形态a的占据数，m_a是它携带的某种守恒组成。内部转化必须满足每次事件的Σ_a m_a Δn_ia=0；跨单元输运在付款端与收款端相反。边界源汇单列。信号、相关性、预测误差不是因为被写成“池”就成为守恒量。

    dM/dt = 边界净物质流入
    dE/dt = 边界净输入功率 − 向外热流
    dS/dt = 边界熵流入 + 内部熵产生，内部熵产生 ≥ 0

能量式的输入功率包括物质携带的能量和外部做功；不能遗漏它们又将源项称为免费供给。系统自身熵可下降，但必须由边界交换与总熵产生共同核对。高耗散、低耗散或接近临界都不从上述不等式被单独选中；其形成需要具体动力学与边界条件。

结构的分解回收材料，并不自动回收已散失的可用功；质量账和自由能账分别成立。有限状态允许持久亚稳结构，不能普遍规定断供后每个记忆都立即消失。

## 2. 转化方向与速率不是同一件事

给定单一温度T的环境、微观可逆性、明确的热库／功源，并选取适合的局部配置粗粒化后，局部正反转化率应满足局部详细平衡。对于固定外部控制参数下的成对配置x↔y：

    A_xy = [w_xy − (F_y−F_x)]/(k_B T)
    ln(k_xy/k_yx) = A_xy

F包含已保留态的内部能量与被消去微态的熵贡献；w_xy是该事件从已声明的功源实际获得的功，反向事件相反。含动量等时间反演奇变量时需要相应的反演态，不能原样套用该配置表达。多温度环境需要逐库记热，不压成一个温度。

这不是反向传播或参数训练。它约束正反事件偏置：只有外部驱动或状态自由能差能支付持续的定向转化。参考开放反应网络的[非平衡热力学原始框架](https://journals.aps.org/prx/abstract/10.1103/PhysRevX.6.041064)。

可将一对正速率写成k_xy=α_xy exp(A_xy/2)、k_yx=α_xy exp(−A_xy/2)，其中α_xy=α_yx。此式是给定速率比的参数化，不是唯一速率定律；α仍需由势垒、接触、局部容量和有限输运推导或识别，并满足执行范围内的有限速率约束。改变势垒主要改变转化快慢；改变驱动力改变正反偏置。通过活动改变势垒或控制参数的过程本身若需做功，也必须付款。

在封闭、无外功的详细平衡系统里，仅改变成对事件的共同速率因子，不能凭空改变最终平衡分布。这为“活动痕迹是不是只在调节通行速度”提供了可以检验的区别。

## 3. 活动、结构与经历如何进入同一物理过程

保留两类自由度：变化较快、承载驱动的局部状态；变化较慢、改变储能与输运能力的结构配置。名称与生物细胞类型无关。

以具有实际电荷q的被动网络为一个可核对的物理极限：

    V_i = q_i/C_i
    J_i→j = G_ij (V_i−V_j)，G_ij≥0
    E_q = Σ_i q_i²/(2C_i)
    dE_q/dt = Σ_i V_i I_i^ext − Σ_edges G_ij(V_i−V_j)²

每条无向边只计一次。该式在固定C与拓扑／结构的快时段成立；有源元件另列功源。这里的q是真正声明了单位的荷量，不能把NLL或未校准的预测残差直接当作q。

结构改变时，还要计入结构能量、材料转化及变化的储能参数所交换的功。例如C依赖结构n时，能量变化中有(∂E_q/∂n)dn/dt；这笔交换必须与慢过程配对，而不能只让n提高G、降低传输耗散，就认定n因此自动增长。C(n)、G(n)及结构能由几何、局部构成或明确有效本构确定，不能为得到理想学习效果任填函数。

因此“学习”的待生成含义是：外界历史改变了慢配置；慢配置又改变未来的输入响应和行动。我们不先写入“流量大就长”“误差小就奖”或目标梯度，而要找到输入功、局部状态与结构转化之间的实际耦合。快状态改变慢转化的势垒还是驱动力，必须逐项说明。预测价值留给真实流中的因果检验，不由热力学名称直接推出。

## 4. 维护与选择应从同一转化网络中区分

已有结构可以因有限寿命发生损失，也可处于长寿命亚稳态；维持成本由其具体更新、恢复与运输过程给出。新增结构同样需要材料和可用功。二者的速率可不同，但不先用“维护预算”和“学习奖励”两个独立评分器决定。

局部可用状态有限、内部输运有限时，多个过程争用同一组成和功源，竞争由实际通量产生。若活动改变局部转化通道的可用性或势垒，就会影响哪些改变更容易发生；若它只提高所有高频位置的速率而不区分作用，则不能据此声称完成了贡献信用。

前轮的标签捕获／活动捕获保持为两种已执行的参考本构：它们揭示了可达性与选择性的矛盾，但不把两者任意加权当作新的根本规律。接下来应比较它们能否由同一状态转化网络在不同驱动、势垒或时间尺度极限下导出；需要独立状态时，要说明该状态储存什么、为何不能被消去、代价多少。

## 5. 层级与外部世界

把一组局部单元作为模块求和，内部物质和功交换相消，留下边界交换与内部耗散。同一收支关系可以递归使用；作为上层有效单元还需要可复现的端口关系和适用时间尺度。

自我生产要闭合的是：

**外部交换驱动活动 → 活动与慢结构转化交换功和材料 → 结构改变后续感知与行动 → 行动改变外部交换条件。**

最后一环使结构是否有用取决于它在世界中的作用。仅有能量耗散、稳定吸引子或内部供给循环，并不等于已经形成上述完整操作闭合；下一步用相同机制的真实世界后果比较来接这条关系，不加外部隐形教师评分。
