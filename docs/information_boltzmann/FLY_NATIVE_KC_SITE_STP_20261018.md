## 作用位置和守恒

709034个实际突触前位置各自保存可用资源x与利用率u。同一位置的多个伙伴共享
一次释放和一次消耗；不同位置的状态独立保存，沿原几何接触、权重及延迟发送。
普通KC输出、可塑KC→MBON、KC→DAN及局部KC→APL四路共同读取这些释放包。
旧全KC STP不能与本模块叠加，避免同一事件被消耗两遍。

沿已有动态突触资源模型，每个实际拍按以下次序推进：

```
a = u + U*(1-u)*s
r = a*x*q*s
x_next = 1 + (x-r-1)*rho_rec
u_next = U + (a-U)*rho_fac
```

s来自原生KC放电，q来自该位置已有的APL/DPM受体后调节。r是本拍实际消耗的
资源份额：局部抑制同时减少发送与消耗；没有脉冲也照常恢复。0≤x,u,q,s≤1时
释放不超出资源，恢复不凭空增加到容量以上。采用每拍解析恢复，无任意恢复阈值。

已有图权重以静息孤立事件效能为参考，因此电学包使用`a*x*q/[U*(2-U)]`；
资源消耗仍使用未归一化的r。首次静息事件保持旧效能，后续资源历史真正改变输出。
这项单位约定不是新的奖励、强迫发言或事后电流补偿。

U、易化与恢复时间常数按4064个KC分别可学习，初值沿用原模型的0.25、100及
200模型拍。它们是初始化，未标定为生物毫秒；正值时间常数不设人为上限。
