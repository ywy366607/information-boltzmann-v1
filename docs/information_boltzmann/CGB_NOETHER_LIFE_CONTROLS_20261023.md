# 守恒桥接、冻结控制与低复杂度生命参照（2026-10-23）

本轮把已有诺特对应接到实际介质的事件语言，并将冻结副本与简化被动吸收模型引出的修复接到当前操作目标。原六条公理、原开放动力学和 `Operational.EncodedCandidate` 字段不变；本轮原记录为v0.12；生物参照澄清为v0.13；后续v0.14见[物质交换接续](CGB_MATERIAL_EXCHANGE_20261023.md)。本报告下述“摄入”与“冻结排除”均按旧 `Operational` 净增量标记解释。

## 1. 诺特定理现在用在哪里

`NoetherBridge.lean` 定义 `closedPart` / `closedJump`：保留既有闭合事件的动作与速率，只屏蔽触边界事件以构造分析用子生成元。原 `jump` 继续包含所有事件，运行过程没有被替换。

令 Q 为身体总含量的实数表示。现有 `JumpProcess.noether` 被以下桥接直接调用：

```text
P2a
 ⇔ 对任意刺激，闭合子核逐跃迁保持Q
 ⇔ L_closed Q = 0 且 L_closed(Q²) = 0
 ⇔ 对所有f，L_closed(Q·f) = Q·L_closed f。
```

`ObservableSymmetry` 明确是乘法算子与生成元对易，不把乘权操作本身视为归一化随机演化。`p2a_iff_closed_expected_drifts` 进一步对应到任意归一化分布下的一/二阶矩零漂移；连续时间前向方程轨道上的矩不变按该动力学语义理解，本轮没有构造完整连续半群。

在原开放核中，`content_drift_boundary` 对任意函数g证明：

```text
L_open[g(total)](x)
 = Σ_a [若a闭合则0，否则 rate(a,s,x)·(g(total(act(a,s,x)))−g(total(x)))]。
```

这把“闭合守恒”和“开放交换”接成同一事件账本。边界通量的物料含义明确；世界储能、热/功、负熵对应仍由资源账本负责。

已有seed提供闭合对称的正控制；违反P2a的twinToggle不能通过双矩检查。新增三状态控制的一阶漂移处处为0，但中心的二阶漂移为2，证明只查均值会遗漏随机抵消。

**已有下游依赖。** `Operational.not_persists_of_closed_moments_and_empty_boundary` 从闭合双矩条件恢复P2a，再在空边界下推出无摄入与当前目标不持续。它直接依赖诺特桥接，定理不再只是理论文档和审计清单中的条目。

## 2. 冻结控制与真实生物参照分开登记

**对象更正（用户澄清后）。** 海绵动物是生命，大肠杆菌也是生命；二者作为本理论应能容纳的低复杂度生物参照。此前把用户所说“海绵”擅自定义为被动吸水过程没有依据，撤回该解释。以下表格记录目标漏洞与修复，不以排除真实海绵为目标。

海绵的协调收缩与细胞调节、大肠杆菌趋化中的短时记忆及行为调节，为不同复杂度的感知—内部状态—行动闭环提供具体研究对象。[海绵收缩研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC9287330/)、[大肠杆菌趋化研究](https://journals.asm.org/doi/10.1128/jb.02171-14)

原定义保留“一定程度的智能和主动性”。它们应按生物尺度作功能验收，不统一要求神经系统、显式世界模型或高等认知。具体生物对象与完整L1–L6的对应仍需逐项验证；本轮数学控制不承担这一生物学判定。

|---|---|---|

## 3. 本轮实际补入当前操作目标的内容

`LifeControls.lean` 使用当前 `Operational.recovery/alive/survival`，不复用旧菜单结论冒充当前过程。

- `during_zero_on_closed`：时间协议下，一个在正概率转移中封闭且没有成功事件的区域，任何有限时域首次事件概率均为0。
- `recovery_zero_without_intake`、`alive_zero_without_intake`、`survival_zero_without_intake`：全部状态无摄入时，正常与剪断分支分别为0，允许任意已登记时变刺激协议。
- `not_persists_without_intake`、`not_selfMaintains_without_intake`：当前持续存在和闭环收益目标均无法满足。
- `not_persists_of_frozen`：全局全刺激下冻结的介质不能持续存在。
- `kernel_from_frozen_state`、`recovery_zero_from_frozen_state`：只要当前身体状态对所有刺激均为吸收态，其他状态是否有摄入事件也无法帮助该状态。
- `not_persists_of_frozen_initial`：持有物料的吸收初态也被当前目标排除。

“冻结”在这些证书中指正速率事件不改变所表示身体状态。v0.14证明这种状态恒定仍可同时登记正的进出通道，因此此处是旧净增量目标的排除证书，真实零交换另查通道及来源。quiet时冻结、部分变量保持与有限时域记忆，继续按各自干预协议检验。

## 4. 被动满载体的严格反例

复用既有 `RecoveryControls.body` 的同一吸收机制：外界输入为真时，把空位填满；填满后不再变化。证明它满足全部六条公理，且有实际正速率摄入事件。

`filledPassive` 仅把出生状态设为已满；所有动作、速率和输入接口不变。`passive_intake_not_persistence` 同时给出：

```text
满足六条公理
+ 满足世界速率1的准入
+ 初始总含量为正
+ 某个状态存在正速率摄入事件
+ 在给定实际世界中，对任何δ均不满足Operational.Persists。
```

最后一项来自满载初态的零实际恢复，而非初态为空、没有输入菜单或未满足时钟。当前判据因此能识别“填满后永远保存”的捷径。该见证没有声称满足完整1%规则预算、丰富世界条件或所有被动材料的物理本构关系；它检验的是定义的逻辑区分能力，未运行训练或能力实验。

## 5. 如何纳入理论及继续推进

主文档已把简化模型的漏洞—修复—现有证明—待补目标连成同一叙述，同时将海绵动物与大肠杆菌列为正参照：

下一步先按所研究生物的功能与时间尺度登记三类干预的匹配条件：资源/物料/能量断源、记忆或内部预测损伤、行动后果剪断。对照应在同一身体与世界时钟上比较，分别沿干预后的未来过程评分；不得用“所有可能反射的最优值”替代有定义的配对对照。

v0.14已补上通道级交换账本、完整编码预算与保持原状态律的观察器；恒定含量下的周转能被识别。相同动力学可有零/正平衡账本的控制同时表明，真实交换需独立的来源与实现证据。资源/负熵及主动推理继续沿匹配干预建立，完整生命正见证仍是独立目标。
