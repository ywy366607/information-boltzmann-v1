# KC长期记忆下沉到实际塑性接触

从完整33000词的位点资源候选继续，新增真实训练输入和优化器更新均为0。
候选 `E:/fly_stream_overflow/native_kc_contacts_20261019/last.pt`，窗口仍为1词元，
词间实际拍、完整脑状态、资源、世界队列、未结算信用和RNG全部保留。

## 什么变了

原来61210条KC→MBON连接各存一个φ和一个局部资格迹。同一连接上的真实释放
位置即使经历不同，也会先汇总活动再写同一个φ。现在按原始位置和MBON伙伴，
展开为463628个塑性接触，覆盖391849个不同释放位置；每个接触分别保存：

- φ、资格迹、多巴胺次序迹、背景统计及已启用的cAMP状态；
- 原学习率、遗忘、资格迹时钟等参数的条件历史敏感度。

同一物理释放位置的伙伴共享原始释放包和资源消耗，突触效能各自保留。
这表示接触的有效突触记忆，不把不同伙伴的旧记忆强行并成一个纯突触前变量。
塑性仅扩展已知KC→MBON连接上的真实接触，不给所有输出任意添加记忆。

同一组学习参数与同一套三因子、时间次序、遗忘方程被复用。没有增加奖励、
新写入规则、发言先验或一个新的外部学习器。相关方程提取为共享函数，原路径
和新路径共用，旧接口回归检查继续执行。

输出按实际接触计算`释放包 × 原份额 × 原连接权重 × (1+φ_contact)`再送达MBON。
资格迹读取该处已经受APL/DPM和资源调节的实际释放，不提前做连接平均。
原生前向可塑性即可更新φ，参数学习仍可用单词窗口；本轮未做新的真实优化器更新。

主动推理的上下文坐标、反事实上下文施加及后果信用特征也读取当前接触级φ。
读出使用原接触份额保持初始坐标和既有后验维度，不把历史连接φ误当作活跃记忆。
这是读出统计，不会把物理接触状态压回连接平均；读出关闭对照同时回到旧参考。

## 连续性

初始φ及各生化/信用字段从它原来所在连接逐项展开，全部旧字段保留作历史。
这样保存已有学习，初始有效输出应与展开前一致；不要求后续局部经历仍然相同。
旧整连接字段不再重复写入同一段新经历。旧探针若假定整连接布局，会明确拒绝，
不能用历史φ冒充当前正在学习的φ。

新增物理/条件敏感度状态约44.22MiB，另有接触身份与索引。没有新增优化器参数。
资格迹和φ相关的条件跨窗口信用同步展开；这仍是固定其他细胞到达信号的条件
导数，不是全脑多跳RTRL。其他新慢材料的历史信用继续单列。

## 多巴胺边界

当前教导仍是原生DAN回路送达MBON隔室的快/慢多巴胺，再按接触所属MBON映射。
没有新造教导信号，也没有把它称为逐bouton的多巴胺局部递送。DAN→KC的实际
接触、受体亚型、逐位置递送与扩散仍待接。当前完成的是记忆分辨率和读写通路。

已有实验显示隔室内ACh释放塑性及bouton异质性，支持保留位置分辨率；具体有效
φ的生化实现仍需分开核实：
[Stahl等，2022](https://elifesciences.org/articles/76712)、
[Davidson等，2023](https://www.eneuro.org/content/10/10/ENEURO.0275-23.2023)。

完整恢复、初始输出、同状态写入/读出控制、单窗口和历史信用数值以
`results/published/fly_native_kc_contacts_20261019.json`为准。短程送达不等于持续
熟悉化、行动降值或交流收益，未测项继续保留。
