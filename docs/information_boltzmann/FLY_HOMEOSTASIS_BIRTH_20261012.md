# 稳态内在可塑性与“从出生开始长”（2026-10-12）

## 为什么需要它

“从出生开始长”的第一次尝试中，两个新生个体都在约 128 词处梯度非有限（对照支也一样）。原因：新生大脑几乎全静默，多巴胺细胞 0 Hz，
各靶细胞的多巴胺按指数衰减；阶段性信号除以“当前平均水平”，它的梯度 ∝ 1/平均水平，多巴胺越淡越爆。修成固定亲和常数 K 的受体占有率
c/(c+K) 后能跑，但新生个体的多巴胺细胞仍然 0 Hz、阶段性信号恒为 0——在线规则什么也写不进去，在线支就等于对照支。

用户的追问把问题推到根上：真实果蝇的多巴胺细胞会自发放电吗？受体占有率怎么定？文献：清醒果蝇的 MP1/MV1 多巴胺细胞在无刺激时有持续活动
（Berry 2012）、未训练时有 0.03–0.3 Hz 的自发慢钙振荡（Plaçais 2012），电压成像直接看到 PPL1 多巴胺细胞与 MBON 的自发放电与爆发；
果蝇节律神经元在离体全脑里有钠依赖的自发放电（Sheeba 2008）；Kenyon 细胞静息时几乎不放电、阈值高（Turner 2008）。具体 Hz 没拿到，不编。

**根本原因**：连接组只有连线，没有细胞自身的性质（离子通道、静息电位）。新生个体 0 Hz、成年谱系约 140 Hz（核心像节拍器）都不是生物的样子。
用户的原则：会说话的果蝇已不是果蝇，不照搬数值，但第一性原理要一致；内在参数应无量纲、有理有据；每只果蝇不一样。

## 机制（`attach_homeostasis`，`--homeostasis`，`--homeostasis-seed`）

- 每个神经元一个内在驱动 b（以自身阈电流为单位，b > 1 会自发放电），作为电流进入；不走梯度。
- 目标频率 ν* = c / τ_m（每拍脉冲数，τ_m 为连接组给出的解剖膜时间常数，3–78 拍）。c 是无量纲占空比：c → 1 是节拍器式的规律放电（成年核心），
  c ≪ 1 是涨落驱动的不规则放电（信息最多）；真实大脑典型 c ≈ 0.01–0.2，取几何中点的中位数 0.05。
- c 在神经元之间对数正态分布（σ = 1；放电率跨数量级，Buzsáki & Mizuseki 2014），每个个体用自己的种子抽一次——个体差异来自随机性，不是指定。
- 规则：b ← b + (ν* − s) / 100。每次放电约下调 1% 个阈电流，每个不放电的拍上调 ν*/100；长期平均正好落在 ν*。100 = 以 10% 精度估计自身放电率
  所需的脉冲数（1/√N）：神经元不可能比测量自己更快地调节自己。时间尺度按自身脉冲计数，放得少的调得慢。
- 与 ALIF 的区别：ALIF 快（几十到几百拍）、只能压低、无目标（带泄漏的比例负反馈）；稳态慢（~100 个自身脉冲）、双向、有目标（积分控制），
  能叫醒静默细胞。两者并存。
- 不用于成年谱系（核心的抑制刹车依赖接近 1 的占空比，加了等于换脑），只用于从出生开始长的个体。

感觉神经元被输入强驱动，稳态把它们的驱动调到负值（感觉适应），b 的 1% 分位 −19。

## 受体亲和常数 K 与在线规则的标定

- K = 孕育后各靶细胞紧张性多巴胺的均值 = 0.000554（成年谱系 0.0108，约其 1/20——这里多巴胺细胞约 1.8 Hz 而不是 140 Hz）。原则：受体工作在本底浓度附近。
- 新 K 下多巴胺以稀疏的单个脉冲到达，相对本底的跳变大，阶段性信号（占有率差）约 0.1–0.5（成年谱系约 0.01）。原 η/κ = −30 是按 0.01 标定的，
  记忆 φ 会长到数个单位（实测 30 个窗口 sd 0.2 → 0.79、最大 3.3 → 7.9）。改为 **η/κ = −1**（κ = 0.02，η = −0.02）：φ 就是窗口内“占有率变化的负值”
  的滑动平均，每步都是新旧值的凸组合（窗口 × κ ≤ 0.04），所以永远在 (−1, 1) 内，不需要任何上界。
- 短窗口检查（孕育后续训 960 词，在线支配置）：梯度全部有限（19.8 → 1.4）；φ 最大 0.78、sd 0.007 → 0.077 平稳增长；
  **η 被梯度持续推强**：−0.02 → −0.016 → −0.029 → −0.044 → −0.056 → −0.067（成年谱系 8,192 词里 η 只走了可能幅度的 2%、方向来回摆）。

## 对照训练（`run_birth2.sh`，两支都从同一个孕育后状态出发，各 16,384 词）

两支：Kenyon 轴-轴突触钉在 0、终生稳态、K = 0.000554、同一数据与世界顺序；一支加 O(1) 在线多巴胺规则。之后测：A→B→A（固定慢权重，记忆照写 vs 冻结）、
静默 MBON / Kenyon 细胞、Kenyon 稀疏性、多巴胺对惊奇的跟踪、精度探针。

**训练前的预言**
1. 两支都能学（NLL 从约 8.2 下降），在 16k 词内学不到成年谱系的水平（它活了 13 万词以上）。
2. 稳态在学习中维持放电率：核心不回到节拍器（占空比 < 0.2），Kenyon 细胞保持稀疏。风险：BPTT 加强某些输入使局部放电升高，与稳态拉锯。
3. **路径依赖假说的检验**：新生个体的蘑菇体被使用——静默 MBON / Kenyon 的损失明显大于成年个体的 +0.004；在线支大于对照支。
4. 在线支 η 的幅度继续增长（梯度方向一致），“记忆照写 − 冻结”的重访节省差为正。不确定性大；若为 0，看两处：MBON → 运动面是否被加强、
   多巴胺是否开始携带惊奇。
5. 若两支都不用蘑菇体：问题不在路径依赖，而在任务——被动读文本时熟悉度没有用处；出路是交互世界（好奇书架），按目标第 6 步先做小实验验证。

## 训练中的发现：新生个体把思考拍数推到上限（两支都有）

| 词 | 3,840 | 5,376 | 6,912 | 7,680 | 8,320 | 8,448 |
|---|---|---|---|---|---|---|
| 对照支平均思考拍数 | 7.4 | 8.8 | 11.3 | 22.2 | 25.8 | 32（上限） |
| 在线支平均思考拍数 | 6.0 | 6.4 | 7.4 | 9.4 | 27.0 | 27.3 |

成年谱系里读出质量约第 8 拍达到峰值后变差，go 神经元自然停在那里；稳态下的新生个体，多想几拍一直有用，而思考没有代价，于是 go 神经元
一路推到 32 拍上限。这与“多想没有价值”（成年个体第 3→10 拍收益 0.065 ± 0.46）相反——新生个体的处理深度在增长，多想在这里是有价值的；
它让“时间的机会成本”（路线图第 3 层）第一次有了可分配的东西。代价：每个词的拍数约 4 倍，窗口慢 4 倍，显存逼近上限。

**工程处理**：在线支两次因显存预算（3.9 GB）中止——第一次是缓存碎片（实际占用 1.56 GB、保留 3.87 GB），已改为接近上限时在窗口之间
释放缓存（不改任何计算）；第二次是思考拍数到上限后真实峰值升到 3.8 GB。从 8,256 词的检查点以 4.05 GB 预算续训，并用 `--world-skip`
跳过已抽过的 257 个窗口，使后半段与对照支看到同样的世界序列。对照支末段（16,384 词）重访 A 比新文本还差（8.87 对 7.26），可能与思考拍数
推到上限后的动力学改变有关，待测量确认。

**对照预言**：1 成立（两支都学，NLL 8.2 → 约 7.3）；2 成立（稳态在学习中维持放电率，Kenyon 1.7–1.9 Hz、稀疏且按内容区分）；
3 **不成立**（新生个体同样不用蘑菇体，静默它的损失仍约为 0）；4 部分成立（η 被梯度持续推强 −0.02 → −0.21，但重访节省差在噪声内）；
5 成立——两支都不用蘑菇体。另：两支后段重访 A 都比新文本差（约 8.6–8.9 对 7.3），与思考拍数推到上限同时出现，与在线规则无关。

**原因（第一性原理）**：被动读文本、逐词预测时，熟悉度几乎没有用处——罕见度是词本身的属性，读出面直接看得到，不需要蘑菇体来告诉它
“这是新的”。路径依赖不是主因：从零长起的大脑也不走蘑菇体。多巴胺/蘑菇体是一个**需要后果的回路**（学“什么带来好 / 坏结果”），
而这个世界里没有任何动作有后果。

**出路**：交互世界（目标第 6 步）。先用“好奇书架”小实验验证：按学习进展选择读什么，是否比随机好、能否避开噪声和重复；
这一步不依赖蘑菇体。成立之后再把选择交给大脑，让多巴胺去预测“这个选择带来的进展”。
