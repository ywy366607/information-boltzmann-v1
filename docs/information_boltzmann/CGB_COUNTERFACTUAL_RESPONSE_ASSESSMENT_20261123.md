## 论文实际说了什么

论文Definition `def:counterfactual-jepa` 与 `eq:residual-transport` 定义：

\[
\hat y_b=y_a+\mu_b-\mu_a=\mu_b+(y_a-\mu_a).
\]

这里固定同一个过去事件及扰动，改变行动。论文 `eq:residual-contrast-identity` 说明：反事实误差等于预测行动差与该事件真实行动差的误差。加性扰动下精确；一般情形由行动与扰动的相互作用决定误差。短物理步长的结论另使用分离输入通道、光滑性和可用表示等条件。梦漓外界轮的对应对象是实际回应生成与编码过程，应从这条实际映射检查上述结构。

论文Table `tab:main-cf` 同时报告 **Copy（所有候选都复制已发生结果）**、原预测和残差修正。输入信息与候选区分能力由这些对照共同解释。闭环重规划另比较 persistent / fresh / none 扰动；将残差继续用于下一时刻，对应其中的持续性问题。

## 与身体原有后验的关系

`causal_relation_program.py::mechanism` 将真实证据构成设计X、残差Y和query；`posterior` 调用 `quadratic_revision.py::evidence_correction`：

`mean = (query @ X.T) @ solve(X @ X.T + ridge*I, Y)`。

它已具有按特征几何传播残差的能力。固定特征/基线、只追加一次证据时，令 `P=(X.T X+ridge I)^-1`，更新可写为：

\[
\mu_b^{post}=\mu_b^{prior}+
\frac{\phi_b^TP\phi_a}{1+\phi_a^TP\phi_a}
(y_a-\mu_a^{prior}).
\]

因此比较对象包括原关系后验的几何增益和论文全搬运的增益1。真实身体的 `revise` 还选择保留/释放证据，`compose`执行生成关系与动量影响。最终比较应运行真实修订路径，固定同一参数/坐标与同一实收证据，保存修订前后的支持身份；上式提供追加证据子情形的数学对应。

原事件shadow仅保存冻结均值、实收向量及搬运值。需要的U后验比较对象是结算现场原参数/角色/证据与修订后实际预测；优先从完整档案重构，或在现有旁路同场保存。旧终态参数另列，避免混入前后坐标变化。
