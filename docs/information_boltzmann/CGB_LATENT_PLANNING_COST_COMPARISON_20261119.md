# 潜空间规划的计算结构与当前原生预演成本

用户询问LeWM、AdaJEPA等怎样想象规划、是否同样缓慢。以下为2026-11-19原论文及官方实现核对，作为当前残差积分实验后的路线依据。当前活跃运行和积分语义保持。

## 原始资料

- [LeWM论文§3.2、§4.2和附录D](https://arxiv.org/html/2603.19312v3)：观测编码为192维状态，动作条件预测器递推；CEM每轮300候选、保留30条，最多10或30轮，规划跨度5。论文报告完整规划不足1秒。实际当前/目标图像编码后，未来通过潜预测器生成。
- [AdaJEPA§3.2、表2](https://arxiv.org/html/2606.32026v1)：执行动作块、获得真实转移、默认一次局部自监督更新，再规划。H200上的全局特征CEM重规划0.24→0.27秒；DINO空间特征9.53→9.56秒。默认最近5样本缓冲，逐episode独立适应。
- [AdaJEPA原CEM实现](https://github.com/agentic-learning-ai-lab/adajepa/blob/main/planning/cem.py)：候选动作按batch送入`wm.rollout`，按潜空间代价选elite。
- [LeWAM§3.2、表6及计时协议](https://arxiv.org/html/2610.12818v1)：学习动作分布生成候选，沿动力学作5步梯度细化。同H100的四任务计时，LeWM CEM414—771ms/plan，LeWAM16.3—21.1ms/plan；平均吞吐比32.3倍。计时单位均为一次planner调用。
