# 共同世界、多视图与可执行程序：后续数据升级候选

记录日期：2026-11-16。来源：用户关于JEPA柏拉图表征假设、五感与共同物理交互、图片—代码—语言—问答的数据构想。

**状态：后续候选，当前不实施。** 用户明确本项不是当前主线。保持现行同一完整身体的OWT/FineWeb-Edu自然文本学习、计算效率和整圈验收；本记录不触发数据切换、视觉/声音接入、QA/SFT、妈妈API恢复、新身体或新实验。实际运行入口仍以[当前台账](CGB_CURRENT_STATE_AND_RESEARCH_LEDGER.md)为准。

## 1. 要保留的核心洞察

用户提出：模态是物体与环境相互作用在感官上的不同投影。石头撞击地砖、地砖振动、声音传播来自同一世界过程；世界并没有彼此独立、需要事后配对的视觉世界与听觉世界。模型要学习的是不同观测如何对应同一事件。

对应的建模候选为：

\[
z_{t+1}=T(z_t,a_t),\qquad x_t^{(m)}=R_m(z_t,c_t^{(m)}).
\]

共同对象是场景状态与转移；模态是带观测条件的读出。物理对应由共同原因、交互及传播机制给出，守恒是其中的约束之一；语言描述还包含观察者的选择和表达方式。

**数据单位由孤立图片/句子扩展为“同一次事件及其可核对的观测”。** 一次事件可以产生多种语言、多个局部描述、VQA、代码、图像/视频，并在未来加入声音。增加数据利用率的候选机制是共同结构受到多种观测的交叉约束，而不只是把样本数量扩大。

## 2. 论文依据及其实际用途

- Balestriero、LeCun：[Proving and Improving the Platonic Representation Hypothesis with JEPAs](https://arxiv.org/html/2610.39302v1)，2026-10-29，arXiv:2610.39302v1。实验用同一图像的不同描述构造good views，与同一句话的遮盖视图比较；建议从不同观测采样、裁剪并轻度遮盖。在该文跨模态对齐指标上，2160万样本达到next-token prediction在9亿样本处的相近水平，约42倍样本差、14倍文本词元差。这个数字不能直接当本项目语言训练、问答或因果学习的提速比例。
- 理论结论依赖共享正样本关系、可逆到世界状态的观测及最优解旋转唯一性等前提；[2026-11-12的批评论文](https://arxiv.org/html/2611.16182v1)指出同状态理想极限下的退化及其与实证条件的区别。因此本候选借用可验证的视图构造和实证发现，不将“同源即必然对齐”登记为已证明机制。
- [Kubric官方实现](https://github.com/google-research/kubric)已提供物理模拟/渲染及图像、深度、分割、轨迹、碰撞等共同来源，可作为未来设施参考。已有生成工具不等于本项目数据创新及学习收益已成立。

## 3. 数据构造：共同生成源、观测与干预

优先保留本来就有源码的SVG、图形、动画、程序化场景及可用真实资产，再按场景执行：

```text
程序＋对象身份/状态＋动作＋执行环境
                  ↓
           事件与转移记录
                  ↓
图像/视频、空间标注、不同描述、局部问答、未来的声音
```

两类变化分开组织：

| 变化 | 对应学习用途 |
|---|---|
| 同一次事件，换相机、措辞、语言、局部描述 | 辨认共同对象和关系，减少观测方式干扰 |
| 改变材质、动作、支撑或其他条件，再执行 | 预测条件改变后的后果，区分竞争机制 |

相同场景可以覆盖对象、位置、遮挡、接触、先后和动作后果等不同关系，避免只生成大量同义复述。程序是可执行关系和数据来源，不要求模型记住唯一源码文本；等价代码可以产生同样观测。

从照片反推代码时，代码是解释候选。重渲染与可见关系可核对，隐藏的质量、材质、遮挡结构和物理机制不能仅凭像素重建认定为真。将观测事实、推断假设和生成设定分别标记。

## 4. 对未来身体的接入要求

- 延续同一感知—语言共演化图和共同世界关系；按模态精度、预测时域、似然端口接入，不另造互不往来的私有骨干。
- 全景图、局部描述和单个问题覆盖的信息不同。问题指定对象/关系/未知项，按其可观测范围预测；不把所有视图强压成一模一样的完整向量，也不凭不可见信息惩罚模型。
- 离线VQA可用于条件预测与关系核对。如何训练问答头、是否采用示范监督须另作决定；本候选不覆盖当前无QA/SFT约束。
- 主动提问仍由身体选择要补充的未知关系、预演取得证据的用途，行动后接收真实回应并修订同一关系。存在VQA数据不等于已经学会主动提问。
- 保留生成程序和事件来源有利于后续追踪资格：过去谁参与、改变什么、产生什么后果，以及该证据何时重新影响预测和行动。观测内容、参与身份与信用信号继续区分。

## 5. 以后启动时的研究靶子

**在匹配训练计算量和数据曝光后，同源多视图加干预轨迹，是否使模型更快学会新场景关系，并将这些关系复用于后续预测、行动和取证？**

届时比较单观测、同源多视图、同源多视图加干预轨迹；同时记录不同场景数量、词元/像素曝光与计算预算，避免把多份派生数据当独立新事实。训练/留出按整个场景及程序家族隔离，检查未见组合、视角及表达中的用途。需要充分的专业数据与训练，不以短玩具探针宣布能力。
