# 妈妈互动后继分布：时间先后核查

2026-11-10，运行前设计。

已有：2837连续个体、水库中的单条未合并真实决策边界对、行动后身体特征、原预测器；局部关系已支持额外证据的纯函数预演。接下来需要候选回应，但不能把不同经历直接当作当前情境的等概率假设。

本次只读核查按真实写入时间排序兼容记录：前半作历史，后两段先校准再检验；预测必须只读更早记录。比较（1）仅按情境查找后继，（2）情境与实际行动共同查找后继，（3）将本次行动在独立后段内部确定性错配的对照，以及（4）原长预测头。前两种从少量历史后继形成加权分布；用校准段残差得到共同的正方差尺度，在后段报告特征空间预测MSE、方差标准化残差、条件高斯NLL、动作扰动的分布变化。每次报告有效样本数及时间切分，不拿这些估计直接换成真实认知价值。旧单条经历只被用作真实历史，并非被标成世界干预或竞争解释。

预期决定：若行动条件对未来真实后继有可重复的辨别力，且分布校准可用，以此作为影子U候选分布进入同体预演；若几乎不改善或显著失准，继续收集妈妈真实回应并针对既有动作—后继头做概率校准，先不让不可信的影子预演影响行动。当前检验是对记录及分布接线的诊断，不以小模型的精确语义回答作为指标，不进行能力裁决、不训练、不更改任何状态。
