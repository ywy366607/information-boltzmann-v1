# 同一生成过程中的痕迹、周转与真实回访：实施前声明

当前已接通r→捕获/导通、支持与驱动组成→空间转化。这里检验它们在当前完整生成元中实际怎样影响后续交换与结构，不用早期小核探针代替当前证据。

1. 从当前自然49域完整档、原三RNG、原3000类型程序及域/载体身份继续。新train[2688,2816)128真实OWT字节，随后回访刚刚确实见过的train[2560,2688)128字节，学习全程保持活动，先预测再输入。前128为新暴露，后128为回访，不把回访填入新游标。实际每字节4ms、dt2ms，全部至14080ms，下一新train2816/validation256。
2. 自然支不改任何痕迹，是预定下一自然候选。另在完整副本上条件化已有write−与active−：两者对q/P/D计量完全相同，只有前者移去r，后者保留。按全部现存r=1载体的稳定ID顺序遍历，局部D不足或反通道不可用就如实跳过；不补资源、不挑未来成功的目标。C、拓扑、坐标、类型、原RNG相同，原反应ΔU/ΔG与热照常记账。它们是允许跳变的条件反事实，不是自然学习策略，也未建模外部实验控制器的选择成本。
3. 两种痕迹条件各保留χ，另各付实际ΔU外功将χ改为0，构成四个诊断副本。无χ仍保留r的导通与其他既有路径；不能称清除了所有记忆。设置功/热单列，不混进之后的外界源功。检验同电荷/驱动组成下绑定/解绑原生率，以及后续真实流中的支持、周转、新域、实际世界反作用。
4. 每个载体以不可复用的身份追踪，旧位置被新载体占据和原载体留存分开。观察r/C属于哪个活载体，不用总边数或重复占位替代记忆。物理状态与观察器全部存档；各支中点后128未来字节的全部预测/评分/物理/三RNG/观察器逐位恢复。
5. 假干预检查为相同完整副本只装观察器、不开任何物理改动；相同真实流未来须逐位一致。自然副本不调用痕迹条件函数，保持唯一连续个体主线。

可证伪预言：匹配条件下r必须实际改变原局部捕获/导通率，而不是只有报告中的非零值；当χ=0时，由χ产生的绑定差异应消失，而r门控导通仍可不同。若当前可用目标为0或支持差异为0，照实记录，不换状态追求阳性。未来相同实际时钟上允许路径分化，单条不同噪声消耗轨迹不当稳定学习收益或中介效应估计。
