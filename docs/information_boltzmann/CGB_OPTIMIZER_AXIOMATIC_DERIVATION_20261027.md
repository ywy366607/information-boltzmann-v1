# 通用优化器的公理化推导（2026-10-27，设计前先证，小分支）

起因：壳层 Kalman 第一版（`CGB_OPTIMIZER_SHELL_KALMAN_PREREG_20261027.md`）是先把想到的组件都放进去，再用实验去筛。结果 4 条预言失败，其中一处甚至做反了。导演指出这丢掉了公理化的思考方式。本文倒过来做：

1. 先写明"通常任务、通常数据"的世界前提；
2. 用定理确定每个前提逼出哪个组件，以及哪个组件被别的组件蕴含（冗余）；
3. 只保留必要组件；
4. 实验只用于检验前提是否成立、实现是否忠实。

定理都在 `lean/CGBAxioms/CGBAxioms/GenerationGradientFilter.lean`。

## 前提与组件

| 前提 | 组件 | 定理 | 状态 |
|---|---|---|---|
| W0 优化器本身是嵌套在模型外层的生命体：状态有限且局部、只读写参与者（P1b）、在无限流里从不重置、记忆与擦除有成本 | 不新增组件，只筛掉不合法的实现 | CGB 公理、`InformationThermodynamics` | 约束，见下节 |
| W1 梯度有噪声（r > 0） | 记忆（对历史做平均） | `memoryless_gain_excess`、`memoryless_strictly_worse`：不带记忆比最优多出 r²/(P+r) | 已证 |
| W2 最优点会漂移（q > 0） | 有限记忆：增益不能衰减到 0 | `vanishing_gain_loses_under_drift`：所有增益都 ≤ q/(4M) 时，误差方差会超过 M；G10a 给出最优增益在 0 与 1 之间 | 已证 |
| W2' 漂移速度未知、会变 | 增益随世界自适应 | G10b `no_fixed_gain_for_two_volatilities` | 已证 |
| W3 各方向统计不同：尺度、信噪比、出现频率 | 按方向的增益，按出现次数计时 | G10c；`no_shared_shrink_for_two_snr`；`occurrence_clock_beats_time_clock`：每 k ≥ 2 步才出现一次的方向，按步数计时的方差 (1−β^k)/(1+β^k) 严格大于 (1−β)/(1+β) | 已证 |
| W4 参数之间相关，曲率不沿坐标轴 | 关系基（非对角） | `diagonal_cannot_whiten`：曲率有非零交叉项时，没有对角预条件能把它化成单位阵的非零倍；GPT 的可分性定理 | 已证（2×2 一步白化的形式） |
| W5 共享资源下的竞争（赢家通吃） | 不需要单独组件 | `usage_normalized_gain_anti_dominant`：按本方向累计用量归一的增益本身就是局部反支配的 | 已证被 W3 蕴含 |

## W0 筛掉的实现

- **跨团的全局运算不合法**，例如对整个大矩阵做全局特征分解，除非这个矩阵本身是一个接触团（P1b）。W4 的关系基只能在团内实现，例如一层的输入侧。
- **依赖总步数 T 的调度不合法**，例如余弦衰减到已知终点（生命在无限流里，不知道 T）。预热、衰减都必须由前三个组件在线自己长出来。
- **每个局部单元的状态只能是 O(1)**：不能存历史，只能存充分统计量。
- **嵌套自检**：在大脑里，"优化器"就是突触可塑性的机制本身（局部资格迹、局部储库、广播调质）。推出来的通用优化器在极限下应当和主线的三因子、O(1) 局部规则一致；对不上就说明有一边错了。

## 冗余（不作为独立组件）

| 候选 | 为什么冗余 |
|---|---|
| Wiener 收缩 | 就是后验均值；标量情形由 `shrink_optimum` 给出最优系数 S/(S+N)，包含在 W1–W3 的滤波里 |
| 离散壳层（G25 有序填充） | 连续的后验已经按证据分出深浅；离散化只关乎存储成本，不关乎性能 |
| 双曲步长 | 就是对参数信念做滤波时的均值更新（自然梯度），和 W1–W3 是同一个组件 |
| 防赢家通吃 | 被 W3 蕴含（`usage_normalized_gain_anti_dominant`） |

## 尚未推出（推出前不实现第二版）

1. **步长的形式。**按方向的步长用曲率（Newton：g/h）、经验 Fisher（g/Σg²），还是尺度归一（Adam：g/√v）？三者在局部二次模型下不等价。
   - W0 允许每个参数存 O(1) 的割线信息（上一步的 Δθ 和 Δg），可以在局部估计曲率 h ≈ Δg/Δθ。
   - 要先证明：在 W1–W3 的模型下，哪种形式是必需的，或者哪种严格更优。
2. **动量是否独立。**滤波对象换成参数以后，动量在病态问题里的加速作用，能否被 W4 的关系基取代，还没证。
3. **W4 的一般形式。**现在只证了 2×2 一步白化。收敛速度受条件数所限的一般陈述还没证。

## 和第一版的关系

- 步长的形式恰好是这里第一个没推出来的问题。它做反了，主干抖动，正说明不能凭直觉选。

第二版要等以上未推出的几项先证完，才能写预注册。
