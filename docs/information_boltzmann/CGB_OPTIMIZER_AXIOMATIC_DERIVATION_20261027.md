# 通用优化器的公理化推导（2026-10-27，设计前先证，小分支）

起因：壳层 Kalman 第一版（`CGB_OPTIMIZER_SHELL_KALMAN_PREREG_20261027.md`）是先把想到的组件都放进去，再用实验去筛。结果 4 条预言失败，其中一处甚至做反了。导演指出这丢掉了公理化的思考方式。本文倒过来做：

1. 先写明"通常任务、通常数据"的世界前提；
2. 用定理确定每个前提逼出哪个组件，以及哪个组件被别的组件蕴含（冗余）；
3. 只保留必要组件；
4. 实验只用于检验前提是否成立、实现是否忠实。

定理都在 `lean/CGBAxioms/CGBAxioms/GenerationGradientFilter.lean`。

## 前提与组件

| 前提 | 组件 | 定理 | 状态 |
|---|---|---|---|
| W0 优化器本身是嵌套在模型外层的生命体：状态有限且局部、只读写参与者（P1b）、在无限流里从不重置、记忆与擦除有成本 | 不新增组件，只筛掉不合法的实现 | CGB 公理、`InformationThermodynamics` | 约束，见下节 |
| W1 梯度有噪声（r > 0） | 记忆（对历史做平均） | `memoryless_gain_excess`、`memoryless_strictly_worse`：不带记忆比最优多出 r²/(P+r) | 已证 |
| W2 最优点会漂移（q > 0） | 有限记忆：增益不能衰减到 0 | `vanishing_gain_loses_under_drift`：所有增益都 ≤ q/(4M) 时，误差方差会超过 M；G10a 给出最优增益在 0 与 1 之间 | 已证 |
| W2' 漂移速度未知、会变 | 增益随世界自适应 | G10b `no_fixed_gain_for_two_volatilities` | 已证 |
| W3 各方向统计不同：尺度、信噪比、出现频率 | 按方向的增益，按出现次数计时 | G10c；`no_shared_shrink_for_two_snr`；`occurrence_clock_beats_time_clock`：每 k ≥ 2 步才出现一次的方向，按步数计时的方差 (1−β^k)/(1+β^k) 严格大于 (1−β)/(1+β) | 已证 |
| W4 参数之间相关，曲率不沿坐标轴 | 关系基（非对角） | `diagonal_cannot_whiten`：曲率有非零交叉项时，没有对角预条件能把它化成单位阵的非零倍；GPT 的可分性定理 | 已证（2×2 一步白化的形式） |
| W5 共享资源下的竞争（赢家通吃） | 不需要单独组件 | `usage_normalized_gain_anti_dominant`：按本方向累计用量归一的增益本身就是局部反支配的 | 已证被 W3 蕴含 |

## W0 筛掉的实现

- **跨团的全局运算不合法**，例如对整个大矩阵做全局特征分解，除非这个矩阵本身是一个接触团（P1b）。W4 的关系基只能在团内实现，例如一层的输入侧。
- **依赖总步数 T 的调度不合法**，例如余弦衰减到已知终点（生命在无限流里，不知道 T）。预热、衰减都必须由前三个组件在线自己长出来。
- **每个局部单元的状态只能是 O(1)**：不能存历史，只能存充分统计量。
- **嵌套自检**：在大脑里，"优化器"就是突触可塑性的机制本身（局部资格迹、局部储库、广播调质）。推出来的通用优化器在极限下应当和主线的三因子、O(1) 局部规则一致；对不上就说明有一边错了。

## 冗余（不作为独立组件）

| 候选 | 为什么冗余 |
|---|---|
| Wiener 收缩 | 就是后验均值；标量情形由 `shrink_optimum` 给出最优系数 S/(S+N)，包含在 W1–W3 的滤波里 |
| 离散壳层（G25 有序填充） | 连续的后验已经按证据分出深浅；离散化只关乎存储成本，不关乎性能 |
| 双曲步长 | 就是对参数信念做滤波时的均值更新（自然梯度），和 W1–W3 是同一个组件 |
| 防赢家通吃 | 被 W3 蕴含（`usage_normalized_gain_anti_dominant`） |

## 步长的形式（已推出）

在每个方向上，用局部二次模型 L = h e²/2（e 为到最优点的距离），观测梯度 g = h e + ξ，噪声方差为 σ²。走一步之后，E e'² = (1 − ηh)² e² + η² σ²（`stepErr`）。

| 结论 | 定理 |
|---|---|
| 误差 = 最优值 + (h²e² + σ²)(η − η*)²，η* = h e²/(h²e² + σ²) 唯一最优 | `step_error_square`、`optimal_step_minimizes` |
| η* = (1/h) · S/(S + N)，其中 S = (h e)² 是真梯度的功率，N = σ²：曲率尺度乘以信号占比 | `optimal_step_newton_times_signal` |
| 有噪声时，不同距离上的最优步长不同。固定步长必须配调度，而 W0 不允许依赖总步数的调度，所以信号占比只能在线估计 | `no_fixed_step_two_distances` |
| W6（非凸数据）：曲率为负时，沿步长方向的损失没有下界，二次步长不存在，所以步长必须有界 | `no_optimal_step_negative_curvature` |

**推论：**
- 每个方向需要：
  - 局部曲率 h：W0 允许每个参数存上一步的 Δθ 和滤波后的 Δg，用割线 Δg/Δθ 在局部估计；
  - 信号占比 S/(S+N)：由 W1–W3 的滤波给出；
  - 一个步长上界：W6。
- **Adam 的 g/√v 缺了 1/h。**它的分母是 √(S+N)，接近最优点时 S → 0，最优步长应随之缩小，Adam 不会，所以需要人为的学习率衰减。
- **SGD 两者都缺。**
- 推出的结构"曲率 × 信号占比 × 截断"与 Sophia（曲率估计加截断）很接近，这是外部旁证。多出来的部分是：信号占比（让收敛时的步长自动缩小，不需要调度）、按出现次数计时、W2 的有限记忆。

## 步长上界与动量（已推出）

| 结论 | 定理 |
|---|---|
| 设局部模型只在半径 R 内有效。没有一个固定上界能在两个不同的 R 下都拿到全部进展，所以上界必须在线跟踪（W0 不允许按时间安排） | `no_fixed_bound_two_radii` |
| 在线规则：实际下降符合预测，就乘以 γ > 1；不符合，就除以 γ。上界一旦落进 [R/γ, R·γ]，就一直留在里面。"实际下降 / 预测下降"是一个全局量，也就是广播的调质（G9、第三因子） | `bound_stays_in_band` |
| 按曲率走一步（1/h）就到达二次方向的最优点；此后任何非零动量 β 都会让它重新偏离。所以在白化的团内，动量是冗余的 | `newton_step_exact`、`momentum_after_exact_step` |

γ 的具体取值是登记的选择，不是推导出来的。

## 连续壳层是必要的（已推出）

| 结论 | 定理 |
|---|---|
| 一次观测的误差 (1−K)²P + K²r，在 K = P/(P+r) 处唯一最小 | `gain_error_square` |
| 稳态增益按稳态方差 P* 计算。对证据少、验前方差 P ≠ P* 的方向（新出现的、罕见的），它严格次优 | `steady_gain_worse_for_fresh` |

长尾数据里罕见方向永远只有少数观测，所以增益必须跟随每个方向自己的后验方差，也就是它的壳层深度，而不是一个稳态值。这就是第 2 项里"随证据加深的后验方差"的必要性。

离散壳层（把 P 量化成几层，G25 式有序填充）对性能不是必要的。只有当 W0 要求每个参数只存很少几个比特时，它才可能成为有限存储下的最优编码（率失真意义上）。这一点尚未推导，第二版不加。

## 由定理确定的最小优化器

每个接触团（例如一层）内：
1. **关系基**：只在输入侧取 Kronecker 因子的特征基，并且只在团内计算（W4，受 W0 约束）。
2. **按方向的滤波**：在这个基里，每个方向跟踪真梯度的均值 m、噪声 r̂、漂移 q̂。
   - 按出现次数计时（W3）；
   - 记忆有限、自适应（W1、W2、W2'）；
   - 后验方差随证据加深，就是连续的壳层。
3. **割线曲率**：每个方向 h ≈ Δm/Δθ（W0 允许每个参数存 O(1) 的上一步信息）。
4. **步长**：Δθ = −clip((m/|h|) · S/(S+N), ρ)，其中 S ≈ m²、N ≈ r̂（`optimal_step_newton_times_signal`、W6）。
5. **全局调质**：ρ 由"实际下降 / 预测下降"在线调节（`bound_stays_in_band`）。
6. **团内不加动量**（冗余）。不单独加防赢家通吃（被 W3 蕴含）。不加离散壳层、Wiener 收缩、双曲步长（都是同一组件的另一种说法）。

**嵌套自检：**
- 第 2 项相当于局部资格迹；
- 第 2、3 项相当于局部增益（G10c）；
- 第 5 项相当于全局广播的调质。"实际下降 / 预测下降"本质上是一个奖励预测误差。

这正好是主线三因子学习的结构，推导和主线是一致的。

2. **团与团之间残留的病态**是否仍需要动量。团内已证明冗余。

这两项不改变团内的组件选择。第二版可以按上面的最小结构写预注册：只实现这六项，每一项都对应一条定理，实验只检验前提和实现是否忠实。

## 第二版预注册（2026-10-27，实验前写定）

**AXO 优化器**：只实现由定理确定的六项，每个矩阵就是一个团。
1. **关系基**：只取输入侧（右因子）的特征基。R = EMA₀.₉₅(GᵀG)，每 10 步更新一次特征向量；行保持原坐标。
   - 换基时，线性量（m、上一步的 θ 与 m）按 Q_oldᵀQ_new 精确变换；
   - 方差类的量（P、曲率、噪声和漂移统计）沿用。这是近似，与 SOAP 处理 v 的方式相同；
   - 差分统计在换基后重置。
2. **按方向的滤波**，在这个基里对每个元素做：
   - P ← P + q̂，K = P/(P + r̂)，m ← m + K(g − m)，P ← (1 − K)P；
   - r̂、q̂ 由相邻两次观测的差分统计（EMA₀.₉₅）给出；
   - 出现时钟：一行的梯度范数不低于本层最大行范数的 0.1 倍，才算"出现"。出现的行更新滤波；没出现的行，m 和统计都不动（登记的判据）。
3. **割线曲率**：h̄ = EMA₀.₉(Δm·Δθ) / EMA₀.₉(Δθ²)，在每次观测之间计算，使用 |h̄|，下限为 10⁻¹²。
4. **步长**：u = (m/|h̄|) · max(m² − P, 0)/m²，每个元素截断到 [−ρ, ρ]，然后 Δθ = −u（转回原坐标）。
   - 这里信号占比用后验方差 P：步长用的是滤波后的均值 m，它自带的不确定性就是 P。由 `optimal_step_newton_times_signal` 推出：(1/h)·S/(S+P)，S 用 max(m² − P, 0) 估计。
5. **全局调质**：在同一个 batch 上计算走步前后的损失。
   - 实际下降 ≥ 0.5 × 预测下降（预测下降 = Σ(m·u − ½|h̄|u²)）时，ρ ← 2ρ，否则 ρ ← ρ/2；
   - γ = 2 和 0.5 都是登记的选择；起始 ρ = 10⁻³；
   - 多出的一次前向计算如实记为成本。
6. **团内不加动量。**

**不调学习率**：AXO 没有学习率，ρ 由第 5 项在线决定（W0）。基线优化器的学习率在 {0.001, 0.003, 0.01, 0.03, 0.1, 0.3, 1, 3} 中，按种子 0 选定。

**消融**（每次只去掉一项）：
- AXO-diag：去掉关系基，检验 W4；
- AXO-steady：用同样的 q̂、r̂ 算稳态增益，检验连续壳层；
- AXO-noclock：所有行每步都算出现，检验 W3；
- AXO-fixedρ：ρ 固定，在同一个网格上调参，检验全局调质能否取代调参。

**基线**：SGD（动量）、Adam、Muon、SOAP；任务 A 另加 RowRes。

**任务**：与第一版相同（A 正交和相关、B、B0、C），评估种子 1–5，报告最小、中位、平均、最大。

**预言**（中位数）：

| 编号 | 预言 | 依据 |
|---|---|---|
| Q1 | B 上 AXO 优于 Adam，也优于 AXO-diag | W4 |
| Q2 | C 上 AXO 优于 AXO-steady；而且 AXO 主干行的损失不高于 Adam | 连续壳层；步长定理保护主干 |
| Q3 | A 上 AXO 的尾部准确率 ≥ AXO-noclock，且 ≥ 最好基线 − 0.03 | W3 |

预言：Q1–Q5 全部不成立；Q6 成立，但这是因为 AXO 发散了，不能算支持。连调好 ρ 的 AXO-fixedρ 也远不如基线，所以问题不只在全局调质。

### 原因：公理和定理没有错，推导漏了公理已有的要求

下面三条都在 `GenerationGradientFilter.lean` 里写成了定理，并在任务 B（种子 0）上用诊断脚本证实：

1. **用走步的同一个 batch 评价这一步，是有偏的**（`in_sample_decrease_bias`、`in_sample_decrease_bias_mean`）。
   - 在本 batch 上测得的下降，比在新数据上的下降多出 ηξg，噪声平均后是 ηξ² > 0，而且步子越大偏差越大。
   - 实测：batch 为 32，维数为 64；有 41% 的步在本 batch 上看是下降，在新数据上其实是上升。ρ 因此一路放大到 1000 以上，最终发散。
   - 这违反了体系里已有的"先预测、后观测"：T1 中的 Kelly 赌注必须在结果揭晓前下。
2. **没有扣除自己走步造成的梯度变化**（`own_step_biases_noise_estimate`、`residual_removes_own_step`）。
   - 梯度差分里含有 hΔθ，也就是优化器自己行动的后果。持续同向的步子会把噪声估计往下拉 h²ab。
   - 实测：r̂ 在 100% 的元素上被截成 0，信号占比恒为 1，滤波退化为不平滑。
   - W0 说优化器是生命体，生命体会行动；而 `CausalRecord.action_feedback_witness` 已经说明，同一个感觉在不同行动之后含义不同。推导时把优化器当成了被动的滤波器。
3. **基选错了**（`secant_needs_diagonal`、`secant_exact_iff`）。
   - 逐方向的割线曲率要准，当且仅当曲率在这个基里没有非对角项。
   - 实测：在 GᵀG 特征基里，非对角质量的中位数是对角的 2.6–3.7 倍；在输入协方差的特征基里是 0。
   - 线性层曲率的输入因子是前突触活动的协方差 E[xxᵀ]，它也是局部量（三因子中的前突触一侧）；而 GᵀG 是按误差加权的协方差。第二版照搬了 SOAP 的选择，没有做推导，这一条是补丁。
4. **测量分辨率**（实现层）。
   - 在任务 A 上，预测下降低于 float32 损失的分辨率之后，实际下降测成 0，被判为失败，ρ 被连续减半到 1e-55，再也回不来。
   - 低于分辨率的比较不携带证据，应当让 ρ 保持不变，而不是记为失败。

### 方法上的漏洞

Lean 只检查"在这个模型里结论成立"，不检查模型有没有漏掉真实系统里的变量。第二版的模型里没有"优化器自己的步子"这个变量，所以 Lean 发现不了原因 1 和 2。

从第三版起，增加一道**模型完备性检查**：
- 实现用到的每个量，在 Lean 模型里都必须有对应的变量，系统自己的行动一定要包括在内；
- 每个估计量都要先在闭环模型里证明无偏，再写代码。

## 第三版的推导：持续学习的优化器（2026-10-27，实验前）

**前提 W7（语言世界）**：数据流里有会回落的冲击，比如话题、文档、对话片段，长度超过一次观测。无限流里不能打乱重放（需要存下全部历史，违反 W0），所以 W7 必然成立。i.i.d. 是靠打乱数据人为造出来的。

### 闭环（`GenerationGradientFilter.lean`）

| 定理 | 内容 | 要求 |
|---|---|---|
| `fresh_decrease_unbiased` | 在这一步没见过的数据上测下降，噪声平均后等于真实下降 | 全局调质用下一个 batch 打分（先预测、后观测） |
| `estimated_curvature_residual_bias` | 用估计曲率 ĥ 做效应副本，残差偏差只剩 −(h−ĥ)²ab，是二阶的 | 噪声和漂移统计用 g − ĝ_pred |
| `eigenbasis_decouples` + `secant_exact_iff` | 前突触协方差的正交特征向量之间没有交叉曲率，逐方向割线因此精确 | 关系基取 E[xxᵀ]，不取 GᵀG |
| `trust_with_deadband_stays_in_band` | 低于分辨率时不改变 ρ，仍然保持在区间内 | 调质带死区 |

### 竞争、防赢家通吃、锁存（`GenerationContinualOptimizer.lean`）

| 定理 | 内容 |
|---|---|
| `polar_conserves_direction_mass` | Muon 的极分解 OᵀO = 1 意味着每个输入方向上的更新质量恒为 1。Muon 是一条按方向的守恒律：守恒带来稀缺，稀缺带来行之间的竞争 |
| `column_budget_allows_wta` | 只有按方向的预算时，正反馈收益的最大值 2 可以由一行拿走所有方向达到，即赢家通吃（G19a） |
| `row_budget_allows_copies` | 只有每行的局部储库（G22）时，最大值可以由所有行拿同一个方向达到，即复制，不分化 |
| `doubly_budgeted_form`、`doubly_budgeted_max_iff_permutation`、`doubly_budgeted_max_differentiates` | 两种预算同时存在时，最大值恰好是置换：每行拥有一个方向，每个方向属于一行。竞争加局部储库，就是不赢家通吃的分化 |
| `linGain_closed`、`linear_damage_eq_adoption`、`no_linear_gain_separates` | 线性增益的写入和遗忘是绑定的（G24 的优化器形式）：冲击的损伤和持久变化的采纳是同一个量 |
| `linear_protect_implies_slow` | 把长度为 c 的冲击的损伤限制在 ε 以内的线性增益，在 mc 步后最多只采纳 1 − (1−ε)^m；延迟锁存的损伤是 0，采纳是 1 |
| `deferLatch_holds`、`deferLatch_releases`、`deferLatch_senses` | 延迟锁存在短于窗口的反证下保持，在达到窗口长度的反证后释放：出口可达（H1），输出依赖刺激，不是瞎的（H2） |
| `held_budget_starves` | 已巩固的元素如果一直占着守恒预算又从不释放，空闲预算会降到 0，整层锁死。巩固的元素必须让出预算 |

### 由此确定的机制（每个矩阵是一个团）

1. **关系基**：前突触协方差 E[xxᵀ] 的特征基。
2. **按方向的滤波**，在这个基里对每个元素做：
   - 出现时钟（W3）；
   - 后验方差 P 随各自的证据变化（连续壳层）；
   - 预测步加效应副本 ĝ = m − h̄u；
   - 噪声和漂移统计用残差。
3. **割线曲率**，然后步长 (m/|h̄|)·S/(S+P)。
4. **双预算分配**：每个元素提出步子大小的平方 |u|²，然后同时满足两种预算：
   - 每个输入方向一个守恒预算（竞争，取 Muon 的守恒）；
   - 每行一个会耗竭也会恢复的局部储库（G22a，防赢家通吃）。
   
   用交替行列缩放（Sinkhorn）求解。已巩固的元素不参与分配（`held_budget_starves`）。
5. **巩固锁存**，对每个元素：
   - 连续 c 次确认（信号占比高、方向一致）后进入巩固态，写入增益降为 0；
   - 进入巩固态后滤波继续运行（不瞎）；
   - 连续 c 次反证（残差与巩固值矛盾）后释放；
   - 计数按出现时钟累计。
6. **全局调质**：ρ 由下一个 batch 上的实际下降与预测下降之比决定，带死区。
7. **团内不加动量。**

**相关工作**：同时满足行和列两种归一化的思路，与 Sinkhorn 式梯度归一化相近；按方向守恒与 Muon/NorMuon 一致；巩固锁存与突触巩固（CaMKII 双稳态）以及 EWC 的保护目标一致，但这里是在线的、可释放的。

### 实现前的机制检查发现了两处推导遗漏（只用合成二次问题，不用登记任务）

1. **割线有偏**（`secant_own_noise_bias`）。
   - 原因：步子是从上一个 batch 的噪声算出来的，两个 batch 的梯度之差又含有这份噪声。
   - 实测：曲率被高估约 2 万倍。
   - 修正：在下一个 batch 上，同时算旧参数处的梯度（`secant_same_batch_exact`）。这一次额外的梯度给出：精确的效应副本 g_t(θ_t) − g_t(θ_{t−1})、无偏的割线、固定参数处的噪声残差 g_t(θ_{t−1}) − g_{t−1}(θ_{t−1})，以及新 batch 上的打分。
   - 统一的原则：**测量自己行动的后果，必须用这次行动没见过的数据。**
2. **换基时清零噪声统计**，使它永远不成熟（第二版也是这样）。改为像 P 一样按 T² 转入新基。

另外，调质的"没有证据"判据改为测量噪声：新 batch 上实际下降的噪声标准差是 √Σu²r̂，由 `fresh_decrease_unbiased` 中的噪声项给出。预测下降不超过它的 2 倍时，不改变 ρ。按信任域的标准做法：只有上界真正起约束作用时，成功才放大 ρ；失败时把 ρ 缩到实际步长的一半。

修正后的机制检查（合成问题，种子 7/11）：
- 曲率约为真值的 1.0 倍（活跃期间）；
- r̂ 是真值的 0.94 倍（中位数；10%–90% 分位为 0.54–1.52）；
- 静止时 95% 的元素被巩固；
- 长度 4 的冲击只移动了 17%，长度 24 的冲击移动了 98%，并被采纳；
- 静止期每个元素约 400 步释放一次，误差在此期间继续下降，没有锁死。

### CLO 的组成（每个矩阵是一个团）

- 前突触协方差的特征基。换基时按最大重叠对齐方向，线性量按 T 转换，方差类的量按 T² 转换。
- 按元素的滤波：
  - 出现时钟，没出现的行不走步；
  - 效应副本预测 m⁻ = m + (g_t(θ_t) − g_t(θ_{t−1}))；
  - P⁻ = P + q̂，r̂ 和 q̂ 取自固定参数处的噪声残差。
- 同一 batch 上的割线曲率。
- 步长 (m/|h̄|)·max(m² − P, 0)/m²，截断到 ±ρ。
- 巩固锁存，窗口 c = 8：
  - 信号未检出（m² ≤ 4P）连续 8 次就巩固，巩固后步长为 0，滤波继续运行；
  - 信号检出连续 8 次就释放。
- 分配：
  - 每个方向的质量守恒（列和不变）；
  - 每行一个储库 a ← a + 0.05(1 − a) − 0.05·(相对使用量)·a；
  - 行目标与 a 成比例；
  - Sinkhorn 迭代 10 次；
  - 已巩固的元素不参与分配。
- 全局调质：新 batch 打分，接受阈值 0.5，γ = 2，起始 ρ = 10⁻³，加上证据带。
- 不加动量，不调学习率。

### 校准检查找到的推导遗漏（合成问题，不是登记任务；`scripts/witness/clo4_calibration_check.py`）

1. **出现判据**。
   - 按"本层最大行范数的一个比例"判断出现，等于所有行共用一个参照，是富人俱乐部式的规则（`shared_reference_flips`）。用户先指出了这一点。
   - 改成拿这一行自己的过去作参照也不行：一行学会后梯度变小，会被误判为"没出现"（实测：大 batch、均匀分布下只认出 41%）。
   - 步子要的是期望损失，期望梯度就是每步梯度的平均（`expected_gradient_is_mixture`），所以每个元素每步都更新，不再判断出现。W3 本身仍然成立，但它关于条件估计，而步子用不到条件估计。
2. **预测与步子的信念不一致**（`consistent_prediction_excess`）。步子按 ĝ = m·frac 走，预测却用 m，高估了 (1−frac)·m·u。改为预测也用 ĝ。
3. **正部插入估计**（`positive_part_bias`）。零信号且方差校准正确时，m² − P 的平均是 0，而 max(m² − P, 0) 的平均是 P/2。改为先做时间平均（EMA 0.9，登记）再截正。
4. **效应副本改用平滑后的曲率 h̄·Δθ**。batch 自身 Hessian 的噪声是滤波器看不到的；按 `estimated_curvature_residual_bias`，改用 h̄ 后偏差是二阶的。割线和噪声残差仍取自新 batch。

**修正后的校准**：二次问题上，实际下降与预测下降之比的中位数为 0.78、0.83、1.01（种子 7、8、9），ρ 保持在 0.27–2.0。

| 2 | 0.129 | 0.824 | 0.16 |
| 4 | 0.192 | 0.293 | 0.65 |
| 8 | 0.691 | 0.461 | 1.5 |
| 16 | 1.806 | 0.771 | 2.3 |

延迟锁存的保护和代价是对称的。短于窗口的冲击被挡住；长于窗口的冲击先被巩固，回落时又要多等一个窗口才释放。

**锁存在漂移任务上的代价**：
- C：CLO4 7.96（主干 1.15），CLO-nolatch4 1.73（主干 0.28）。
- B：CLO4 0.67，CLO-nolatch4 0.31。

硬锁存把增益直接置零，缓慢漂移的主干和仍在缓慢收敛的方向都被冻住了。另外，CLO-noalloc4 在 C 上的主干误差为 0.091，是所有臂（包括基线）中最低的，但它的瞬变部分很差（6.59）。

### 原因与下一步（推导，未运行）

1. **锁存是健康的（H1、H2 都满足），但不够聪明。**
   - 它只看持续时间，不看幅度，也不看证据的年龄。
   - 按定义健康，只说明它不会锁死、不会失明，不说明它对世界的结构是最优的。
2. **从世界的结构可以推出所需的形式。**
   - W7（会回落的冲击）是"稀有的大跳变"，漂移是"持续的小变化"，所以创新的分布是混合的、重尾的。
   - 在这种噪声下，贝叶斯滤波的更新对大的创新是有界的（大跳变被压低），对小的创新近似线性（漂移被跟上）。
   - 同方向的大创新连续出现时，"体制已经变了"的后验会上升，于是被采纳。
   - 再加上语言世界持续时间的重尾性（风险递减）：释放门槛随着这个值已经稳定的时间（年龄）增长，即壳层加深。
   - 这是一个软的、按幅度、持续时间和年龄三者共同决定的保持，而不是把增益硬性置零。按 `no_linear_gain_separates`，它必须是非线性的。
3. **E 的失败需要先诊断**：两层非线性，存在负曲率（W6），并且两个团同时移动。
4. **交叉熵 / 稀疏行留给第五版**：事件率 × 事件大小（`partition_is_unbiased`、`event_part_is_rate_times_size`）。

## 有益的锁存与第五版预注册（2026-10-27，运行前写定）

### 体系的完善：从"健康的锁存"到"有益的锁存"

H1 和 H2 只保证锁存健康：出口始终可达，锁住期间仍在感知。第四版表明，健康的锁存仍然可能有害：
- C：硬锁存（增益为 0）冻住了漂移的主干，7.96 对不加锁存的 1.73；
- D：固定窗口对待一个 16 步的冲击，和对待一个 500 步的主干一样用力；
- E：在非凸学习的平台期提前巩固，W2 在第 20 步就 100% 巩固，学习停止。

在"缓慢漂移 + 稀有可回落跳变"（W7）的世界里，有益的锁存在 H1、H2 和让出预算（`held_budget_starves`）之外，还必须满足（`GenerationContinualOptimizer.lean`）：

| 条件 | 定理 | 内容 |
|---|---|---|
| B1 放行漂移 | `frozen_hold_loses_on_drift` | 冻结的估计在随机游走下误差无界增长，所以小的创新必须继续写入 |
| B2 有界影响 | `mixture_update_bounded`、`mixture_weight_at_zero` | 混合噪声下贝叶斯更新为 y·w(y) < 1/(c·a·y)，单个大创新的影响趋于 0；小创新的权重接近 1/(1+c) |
| B3 随年龄加深 | `release_threshold_monotone_in_age`、`succession_odds_decreasing` | 变化风险随年龄递减时，释放所需的连续反证数不减；风险恒定时为常数，所以固定窗口只适合无记忆的世界。继承律 1/(T+2) 给出的几率 1/(T+1) 递减 |

保持的深度就是连续壳层，只是这次按证据的年龄来编号。这些条件不只属于优化器，也适用于以后生命体自己的记忆：在一个会漂移、也有可回落冲击的世界里，凡是要保持的东西都应当满足 B1–B3 和 H1、H2。

### CLO5（`scripts/run_optimizer_continual_v5.py`）

在 CLO4 的基础上，把硬锁存换成软保持：
- **按创新加权**：每个创新 ν 按"普通噪声 vs 跳变"的后验 w 写入（B1、B2）。
- **跳变方差**：从 25 倍的普通创新方差起步，之后每个元素在线估计。
- **接受为持久变化**：同号跳变连续 k* 次才接受，k*(年龄) = 1 + log(π_b(年龄+2)) / log(1/s_b)（B3）。π_b（冲击起始率，初值 0.01）和 s_b（冲击持续概率，初值 0.5）在团内汇总，以 EMA 0.99 更新。
- **接受之后**：年龄归零，新值的壳层是浅的。

**机制检查**（合成问题，不是登记任务；`scripts/witness/clo5_hold_checks.py`，结果见 `results/published/optimizer_clo5_hold_checks_20261027.json`）：

### 新定理：线性级联挡不住冲击（`linear_burst_damage_integral`）

任何线性的记忆（单个池，或时间常数逐级变大的 Benna–Fusi 级联，其平均动力学是线性的），只要最终完全采纳持久变化，长度为 L 的冲击造成的损伤按时间累加恰好等于 L，与形状无关。线性级联可以推迟、摊开冲击的损伤，不能减少它。

所以，把软保持搬进介质时：
- 级联（G20 两态池串联）负责随年龄加深（B3）和幂律遗忘；
- 挡住冲击（B2）必须另有一个非线性开关（G23/G24 的驱动或协同开关；生物中的对应是 CaMKII 双稳态、标签与捕获的阈值）。

2. 在 Lean 里证明"几何时间常数的两态池链给出幂律遗忘，寿命随层数增长"。
3. 把"级联 + 开关"装进语言生命体的介质，用冲击世界检验三点：累计损伤小于 L（线性做不到）、幂律遗忘、持久变化仍被采纳。
4. 在发育尺度上检验双预算分化：细胞群在守恒资源和局部储库下，应当形成稳定的多样性，而不是独占或克隆。

## 第六版的推导进展（2026-10-27，进行中，尚未预注册）

B（稳定的旋转回归）上 CLO5 停在 0.31，最好的基线是 0.049。诊断用的是类 B 的合成问题（D = 48，种子 77–79，不是登记任务）。

1. **漂移估计的正部偏差**。q̂ = max(E[e²] − 2r̂, 0) 在 20 步窗口上逐元素截正，56% 的元素带着相当于 r 的 2–6% 的虚假漂移，P 因此有一个约 √(q̂·r) 的下限（`positive_part_bias` 又一次应验）。改为：长窗口（0.999）、剔除跳变后先平均再截正。类 B 问题上从 0.24 降到 0.20。
2. **软保持在稳定世界里反复接受单个离群值**：
   - 继承律 1/(T+2) 对应均匀先验，年龄为 0 时认为每两步就会变一次；
   - 接受一次就把年龄清零，P 又被加上跳变方差 J，形成恶性循环。
   
   修正：
   - 风险用 Beta(1, β) 先验，β 由团内汇总的变化率学出（`beta_hazard_decreasing`；`beta_hazard_succession` 表明继承律是它的特例）；
   - 接受后的方差取 Sn/k（`accepted_run_variance`）。
   
   类 B 问题上降到 0.15–0.17。但合成检查里漂移跟踪变差（0.12，第五版是 0.044），长冲击后的恢复也变慢。
3. **步子里的第二次收缩是重复计算的先验**（`posterior_shrink_error`、`posterior_mean_is_bayes_action`）。S/(S+N) 来自"一次原始观测、没有其他知识"的模型；m 已经是后验均值，再收缩就是每一步重复用一次先验，接近最优点时步子停滞。但直接去掉收缩后结果更差（一个种子发散），因为 Newton 步依赖逐元素的割线曲率，而它噪声很大（E[1/ĥ] > 1/h）。

**下一步（推导先行）**：曲率按 Kronecker 结构估计。
- 平方损失下 H = I ⊗ E[xxᵀ]，曲率 hᵢⱼ = λⱼ，λⱼ 就是 Rx 已有的特征值；
- 一般情形按 aᵢ·λⱼ 的秩一结构，只估计每行一个 aᵢ。
- 先在 Lean 里写出逐元素割线与 Kronecker 估计的方差比，再实现，然后对收缩问题重新检验。

第六版的代码 `scripts/run_optimizer_continual_v6.py` 是草稿，不是预注册版本。第五版里漂移、风险、接受方差和收缩这四处的计算被抽成了方法，以便第六版覆盖；行为不变，机制检查的输出逐字相同。
