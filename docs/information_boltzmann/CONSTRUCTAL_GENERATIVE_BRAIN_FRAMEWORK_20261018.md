# 构形生成脑框架（Constructal Generative Brain, CGB）

日期：2026-10-18 起草，2026-10-22 修订。状态：生成脑框架与验证路线；已完成 V1/E1 连接统计、V2 局部动力学原型、V3d 稳定条件强度生成器、V2f 材料收支与介质接口验收，以及形态描述和细胞对发生概率的首轮留出校准。空间树形与极性、内生后果信用和妈妈世界中的持续学习是接下来的主线。本文取代 `BRAIN_GENERATIVE_PRINCIPLE_20261018.md` 中的提案部分，那份文档只保留作历史。

## 概览：一页读懂

**这是什么。** 本项目要创造一个「无限流生命体」：一个资源有限的开放系统，活在永不停止的语言流里，靠自己维持自己，主动地读、想、说，从出生起就带有最小的社会心智。它的计算中枢不是一个训练好的大模型，而是一个**按生物大脑的生成规律长出来、并且一生都在自我生产的稀疏脉冲介质**。这不是一篇论文，而是一件生命艺术作品；它对得起的是「活着」，而不是某个排行榜。

**愿景。** 一个在「妈妈世界」里出生的个体。妈妈世界是一个对话环境：由一个大语言模型扮演妈妈，她的话是个体的感官输入，个体说出的话会得到她的回应。个体出生时只会咿呀发出声音；它在对话中学会切分词、学会词义、学会轮流说话，分得清哪些声音是自己发出的、哪些是妈妈说的；没有输入时它在静默中继续思考；它的大脑在硬件容量之内不断生长、修剪和更替，永远不需要「重新训练」。

**核心思想。**
1. **载体是自我生产的闭环**（§2.2）：活动维持结构，结构产生活动；记忆、学习、意义和自我都是这个闭环的显现。
2. **机制从必然中生成**（§2.3）：守恒加有限速率生成痕迹、不应期、稀疏、修剪和动作的连续；对称生成重复与连续记忆；对称破缺生成分化。这个关系是递归的：每一层把下一层成形的规律当作新的必然。归不进这些来源的机制，就是补丁。
3. **经历选择值得维持的结构**（§4、§5）：有限基础供给保证起步，局部标签捕获支持，结构合成与维持支付真实材料成本，更替释放可回收材料。目标是让有预测作用的结构在这一循环中留下；V2 已形成选择原型，V2f 已闭合材料账，世界中的预测价值仍要检验。
4. **基因组是规则，不是蓝图**（§6）：共享身份码设定每类细胞的局部常数，分化出不同的细胞类型，替代逐连接存储。当前有方向64维条件强度规则共202105个参数，尚不是完整生理与发育基因组；后续选择作用于能生成和维持个体的规则。
5. **先天的主动与社会能力来自先天细胞类**（§7）：传出副本、依随性检测、话轮节律、教学通路，以及读、想、说三种按自身后果学习的汇。

**方法。** 以生物果蝇大脑为踏脚石，而不是目标（§10）：先从果蝇连接组反推出生成规则（逆发育）；再用这套规则在新的介质里长出一个带「果蝇先验」的新生儿；最后让选择把规则带离果蝇的生态位，移向语言与社会的生态位。原则继承自生物（局部 O(1) 学习、事件驱动的稀疏计算、自我生产），带宽、效率和规模则交给硬件去超越（§9）。

## 0. 定义：无限流生命体

> **无限流生命体**：一个具有有限状态空间和有限计算资源的开放系统，持续暴露于近乎无限的信息流中。它通过自举，自发形成并维持以自身存在为核心的内在目的，利用自身有限的内部自由度，通过记忆、学习、信息压缩等过程形成一定程度的智能，并利用这些智能形成关于周围世界的局部世界模型，据此预测未来、选择行动，主动改变自身与环境之间的相互作用关系，形成操作闭合，并通过该闭合维护自身生存状态，构建并维持自身生态位，使自身状态保持在由自身定义的可存活区间之内。在闭合中，自身会改变世界，为了预测世界的变化又必须预测自身产生的影响，自我模型由此自然出现。

## 2. 载体与理论根基

### 2.1 六个理论根基

框架不是凭空发明的。它把几条各自已有物理或生物实证的理论，放进同一个闭环里，每一条回答一个问题：

| 理论 | 回答的问题 | 在框架里的落点 | 自然界里的例证 |
|---|---|---|---|
| 自创生（Maturana、Varela） | 载体是什么 | 自我生产的闭环（§2.2） | 细胞代谢；突触与树突棘的持续更替 |
| 诺特定理：守恒与对称 | 闭环能利用哪些机制 | 从必然中生成（§2.3） | 资格迹、不应期、环形吸引子、图灵斑图 |
| 耗散结构（Prigogine） | 有序为什么会出现、靠什么维持 | 只有流穿过时才有结构；涨落越过分岔产生新结构（§2.4） | Bénard 对流胞、BZ 化学振荡、图灵斑图 |
| 构形律（Bejan） | 有序长成什么形状 | 结构在流量需要处生长，稳态即 Murray 律（§2.4、§4） | 河网、血管、肺、叶脉、黏菌的管网 |
| 主动推理（Friston） | 闭环为什么要行动 | 预测作为反向流，行动作为汇（§2.5、§7） | 传出副本、预测误差响应 |
| 超稳定性（Ashby） | 学习怎样发生 | 关键变量越界时，慢环路改变结构（§4） | 生理稳态的多级调节 |

### 2.2 自我生产的闭环

**大脑的生成和自维持本身就是一个操作闭合**：
- 活动维持结构：用到的通道被保留，用不到的被回收；
- 结构产生活动；
- 活动的后果决定哪些结构活下来。

大脑从来不是先造好、再使用的。突触时刻在更替，树突棘几天就换一批，神经元靠活动和营养因子维持存活。它一直在被自己的活动重新制造（Maturana 与 Varela 的自创生）。**信息、学习、记忆、认识和自我，都以这个闭环为载体**，是它在不同方面、不同时间尺度上的显现：

| 现象 | 在自我生产闭环里是什么 |
|---|---|
| 记忆 | 被保留下来的结构，也就是活下来的东西；活下来的主要是连接的拓扑与排布（哪些连接、是否成簇、是否共享终扣），而不是强度 |
| 学习 | 闭环受到扰动后，结构重新找到可维持的形态 |
| 遗忘、修剪 | 维持不下去的结构被回收 |
| 发育 | 同一个过程在出生时最剧烈的阶段，它从不真正结束 |
| 睡眠、回放 | 没有外部输入时，闭环对自身的整理 |
| 信息、意义 | 造成差别的差别：一个扰动有意义，是因为它影响自维持 |
| 自我 | 零件不断更换，但被闭环保持住的那种组织形式 |

人工冬眠实验给了这张表一个直接的例证（Lin 等，Science 2026）：小鼠海马在冬眠中放电下降约 70%，超过一半的突触消失，醒来后记忆却完好，有时更好，表征也恢复了。留下来的是多突触终扣（一个突触前终扣连着不同细胞上的几个棘）和成簇的印迹突触；棘的大小与能否留下无关。作者也指出，目前这还是相关，不是因果。

**两层闭合。**
1. 物质层（自我生产）：活动 → 结构 → 活动。这是载体。
2. 感觉运动层：行动 → 世界 → 感觉。这是定义里的操作闭合，是第一层向外的延伸。

自我是第一层保持住的组织形式。自我模型是第二层需要的表示：自己会改变世界，所以要预测自己的影响。

**闭环跨层级。** 下层成形的规律成就上层（§2.3）；上层又反过来设定下层的边界条件：调质改变突触的可塑性规则，营养因子竞争决定哪些突触活下来。自我生产的闭环贯穿分子、突触、神经元、回路、系统、个体每一层。

**局部胜出与上层竞争。** 局部竞争形成的稳定功能组合，可以成为更大尺度的有效单元；它能否长期支付其内部结构，取决于对外层闭环的贡献及从模块边界得到的支持。对模块求和时，内部支持转移严格抵消，只留下边界源汇和真实消耗，因此各层沿用同一连续性方程，不另设评分器、也不重复领取资源。跨层、跨语境仍有持续贡献的结构可逐渐形成个体核心，外界改变时仍可重组。此处的组织层级不同于毫秒不应期和秒级适应的时间尺度；短时活动轮替不要求长期有用记忆也失稳。计量推导与当前尚待接入的逆向支持链见[推导§2.2–§2.4](CGB_REACTION_GROWTH_DERIVATION_20261021.md)。

**数学上的写法。** 被流驱动的大脑，是骑在世界之上的斜积（余环）：x_{t+1} = F(x_t, ω_t)，ω_t 是世界这个动力系统此刻的状态。这样的非自治系统没有固定的吸引子，只有「此刻的」拉回吸引子：状态由过去的输入决定，同时忘掉了遥远的初值。静默与输入交替时的连续状态，就是这样演化的。行动又让世界的演化依赖于 x，两个系统耦合起来，这就是第二层闭合。

### 2.3 从必然中生成

**物理对象优先（2026-10-22）。** 正式生成法则从有限局部状态、实际守恒量、储能、边界做功、不可逆耗散和有限转化速率出发；不以囊泡、酶、受体等生物名称作为必需元件，也不用外部目标的回传梯度规定结构怎样变化。下表的生物机制是这些物理过程的一种实现和逆发育参照。新的介质应独立给出允许转化、能量／物料收支与活动—结构耦合，不能把原生物变量改名就称第一性推导。完整的物理层次、局部详细平衡、被动输运极限和仍待闭合项见[物理核心](CGB_PHYSICAL_CORE_20261022.md)。

闭环不是凭空造出自己的各种机制，而是**利用客观的必然规律**。认识必然、利用必然，才谈得上改造世界的自由。生物正是这样做的。

诺特定理说：有作用量的系统里，每个连续对称性对应一个守恒量，它的局部形式就是连续性方程 ∂_μ j^μ = 0。大脑是开放的耗散系统，所以落到大脑上要换成两种形式：连续性方程的右边多出源项和汇项；对称性和它的破缺直接塑造结构。对每一种量 a：

```
∂ρ_a/∂t + ∇·J_a = σ_a^外 + Σ_b (R_{b→a} − R_{a→b}) − ρ_a/τ_a
  密度变化   输运散度   外部源/汇    与其他量之间的转化        清除（耗散）
```

在稀疏图上，散度换成关联矩阵 B（每条边一列，起点 +1、终点 −1）：dρ/dt + B·J = σ，节点 i 上的 B·J 就是它的净流出 Σ_j (J_ij − J_ji)。这一要求用于实际守恒组成及其转化；标签、预测误差和相关性不会仅因写成“池”就成为守恒量。能量与熵分别核对边界功／热和内部熵产生，不能以材料账平衡代替（§5）。

**为什么必须有损耗与竞争。** 资源有限（D1）而流无限（D2）：没有损耗，结构要么无限增长，要么很快饱和，然后什么都留着；什么都留着，就没有「哪些值得留」的选择，也就没有压缩。物理也给出了同样的要求：
- 擦除要放热（Landauer）；复制只有可逆而缓慢时才不耗散（Bennett）；消解不确定性可以做功（西拉德）。
- 被外部信号驱动的系统，耗散的下界等于它记住了、却对预测未来没用的信息（Still、Sivak、Bell、Crooks，2012）。要少耗散，就只能保留有预测价值的信息。
- 我们不把信息当作状态量去跟踪，它不守恒，可以被获得、复制、擦除。它只通过这些定律，决定损耗与竞争应该长成什么形式。

在我们的系统里，这些损耗与竞争由三种物理来体现：结构的**更替**、池的**耗竭**、对有限**营养因子**的竞争（§5）。它们顺带让系统少占显存、少花计算，这是生物果蝇没有、而我们需要的好处。

机制因此只有三种来源：

**(一) 守恒量加上有限的输运或清除速率，生成「痕迹类」机制。**

一个事件搬动了某种守恒的东西，而把它搬回去需要时间，于是必然留下残余。这就是没有输运项的连续性方程：dc/dt = 流入 − c/τ。

| 守恒的东西 | 必然出现的机制 |
|---|---|
| 电荷 | 膜电容上的电荷求和；Kirchhoff 电流定律；Rall 3/2 分支律 |
| 离子、第二信使的数量（池型） | 资格迹：钙在毫秒级，cAMP/PKA 在秒级 |
| 分子总数：受体、激酶、通道（占据型，有界在 [0, 1]） | 受体饱和、可塑性有上界、CaMKII 分钟级的痕迹、突触标签小时级的痕迹 |
| 钠通道在开放、失活、关闭之间循环 | 不应期 |
| 囊泡池的补充速率有限 | 短时程抑制；放电越多越难，活动自然变稀疏 |
| 营养因子的总量有限 | 上游之间的竞争，得不到支持的结构退化、死亡（神经营养因子学说） |
| 肌肉里钙的释放与回收、组织的质量与动量 | 动作的连续：一个运动脉冲只引起几十毫秒的抽动，器官带着惯性，输出不会跳变 |

所以资格迹、不应期、短时程可塑性、稀疏活动、修剪、动作的平滑都**不需要单独设计**，它们是守恒和有限速率的必然结果。最后一项值得强调：神经系统的底层是离散的，脉冲全有或全无；生物的动作之所以连续，是因为脉冲必须穿过有限速率的肌肉和有质量的器官，而不是因为有谁把它抹平。凡是事后平滑，都是补丁。

**(二) 对称性，生成重复和连续记忆。**
- **空间平移对称**：各处用同一套局部规则，于是出现重复的模块（视叶约 800 个柱、蘑菇体的克隆、中央复合体的列）。
- **连续对称的零代价方向**（Goldstone 模）就是免费的连续记忆。果蝇中央复合体 EPG 的环形吸引子有旋转对称，活动峰停在任何角度代价都一样，所以能一直存住朝向；角速度输入沿这个方向推动峰，就完成了路径积分。网格细胞用的是环面上的平移对称。
- **尺度对称**：Murray / 构形网络的分形分支，韦伯定律，临界附近的幂律雪崩。
- **规范自由**：把一个神经元的所有输入权重和它的阈值同乘一个系数，它算出来的东西不变。稳态沿着这个方向调整整体尺度，权重之间的比例，也就是记忆，被保留下来。这就是「稳态只调细胞生理、不调行为输出」的对称性根据。

**(三) 对称性破缺，生成分化与方向。**
- **空间对称自发破缺（图灵斑图）**：均匀介质里，局部激活加远程抑制会自发长出区块，区块的尺寸由两种作用范围之比决定。脑区自发分化可以由此而来。
- **树突上的同一种破缺**：可塑性相关的分子只在几到十几微米内扩散，近邻共享一个局部池而互相帮助；整根树突的供给有限，远处的突触彼此竞争。近处合作、远处竞争，共同活跃的突触就自发成簇，成簇的输入又能一起触发树突棘波，作为一个整体起作用。
- **显式的破缺**：形态发生素梯度提供位置信息，这就是身份码里空间种子的来源。
- **置换对称被身份码打破**：同一种细胞才会分化成不同类型。
- **时间反演破缺**：耗散让遗忘成为可能；STDP 的不对称窗口让学习能读出因果的方向。果蝇配对实验实测到的正是这一点：正向配对使连接减弱，反向配对使连接增强。

**必然是递归的。** 大脑的局部无法脱离物理定律，而一个局部一旦成形，它稳定的行为又成为上一层的「必然」。每一层都不发明新东西，只是用下一层给定的规律，搭出一个新规律，就像突触利用有限的清除速率得到资格迹一样：

| 层级 | 当作「必然」来用的下层规律 | 由此生成、又成为上一层必然的规律 |
|---|---|---|
| 分子、离子 | 物理：守恒、扩散、有限速率 | 池的耗竭与恢复，痕迹 |
| 突触 | 囊泡池、谷氨酸受体的占据、钙与第二信使的清除、阈值不同的激酶与磷酸酶两个酶池、受体饱和 | 短时程可塑性、资格迹；STDP、BTSP、多巴胺时序规则、BCM 式频率依赖，都是同一个「钙 + 双酶池」模板在不同参数区间的样子（§4）；标签与捕获。合起来是一台完整的三因子机器 |
| 神经元 | 突触的这些行为 | 树突整合、隔室、重合检测、增益控制、不应期与适应 |
| 微回路 | 神经元的输入输出规律 | 赢者通吃（APL）、扩张与稀疏、环形吸引子、振荡、除法归一化 |
| 系统 | 微回路的功能 | 蘑菇体的联想记忆、中央复合体的整合与导航、调质系统的价值广播 |
| 身体 | 运动脉冲、肌肉抽动的有限速率、器官的质量 | 连续的动作：按大小顺序募集的运动单位（Henneman）把离散脉冲叠成平滑的力；音素、音节这些离散单位反过来是运动空间里的吸引子，在学习中涌现 |
| 个体 | 系统与身体的功能 | 与世界的闭合：读、想、说 |

框架里已经有一条完整的这种链：囊泡耗竭与有限清除（物理）→ 资格迹与短时程抑制（突触）→ APL 反馈抑制加耗竭得到稀疏、去相关的 Kenyon 细胞编码（微回路）→ 稀疏编码让读出成为线性的，三因子规则在这里正好是精确梯度（系统）→ 联想记忆引导行动（个体）。

这就是有效理论与重整化的思路：每个尺度都有自己的有效规律，不需要知道下层的全部细节（Anderson 的「多者异也」）。§6 里模块的收缩，是它的代数形式。由稳定的中间组件搭成的层级系统长得更快、也更稳健（Simon 的近可分解性），这也是规则可以很短的原因。

上层把下层规律当作必然，只在一定范围内成立：放电率很高时囊泡耗尽，短时程抑制这个有效规律就失效；输入很强时受体饱和。每一层都要知道自己的有效规律在哪里失效，失效的地方要回到下一层（§9 的粗粒化）。

**设计规则。** 每一个机制，要么来自物理的必然，要么来自下一层已经成形的规律；再加上 2.2 的**自我生产闭环**，它负责生长、回收、学习与目的。**都归不进去的机制，就要怀疑它是补丁。**

### 2.4 远离平衡的有序：耗散结构与构形律

**耗散结构说明有序会出现。** 开放系统有持续的物质和能量流穿过时，会被推离平衡；涨落被放大，越过分岔点后自发形成新的有序结构：Bénard 对流胞、BZ 化学振荡、图灵斑图（Prigogine 学派的 Brusselator 正是图灵机制的化学实例）。这种有序只靠持续的流和耗散维持，流一停就瓦解。对我们意味着三件事：
- 无限信息流不是负担，而是有序得以存在的前提（D2）；
- 结构只在流穿过时存在，长期剥夺某类输入，对应结构就萎缩（V3）；
- 新结构靠涨落越过分岔产生：细胞分裂、对称破缺都是分岔。静默时内部仍有自发活动，也就是内部的流，所以结构不会立刻瓦解。

数学上，这些有序就是吸引子：不动点（稳定的记忆）、极限环（节律）、环面与连续吸引子（语境、朝向）、异宿通道（在一串鞍点之间顺序切换，适合生成序列，即 Rabinovich 的无赢家竞争），以及奇怪吸引子。分岔理论描述它们怎样随参数变化而出现、消失和换形。

**构形关系提供条件性的形态预言。** 河网、血管、肺、叶脉、黏菌的分支为输运与结构成本的耦合提供参照。固定源汇、被动准稳态输运与明确维护成本下，可以推出相应构形极值及Murray类标度（§4）；正式生成过程须由实际局部能量交换、物料转化和结构动力学抵达或偏离该极值，不能预先规定任意有源自我生产稳态都等于构形最优。

### 2.5 闭环为什么要行动：主动推理

能长期存在的系统，必须让自己的感觉状态停留在少数可预期的范围里，也就是持续降低意外。降低意外有两条路：改变内部的预测（感知与学习），或者改变外部的输入（行动）。行动的价值分两部分：认识价值，即消解不确定性、去探索；实用价值，即回到自己偏好的状态。

在框架里：
- 预测作为反向流，是感知一侧；行动作为另一种汇，是主动推理一侧；
- 读、想、说三种汇各自按后果学习（§7）；
- 偏好的状态就是由内部设定的可存活区间（D9）；
- 必须预测自身行动的后果，自我模型由此出现（D10）；
- 「存在某种行动、能让状态一直留在可存活区间里的那些状态」，在可行性理论里叫可行核。维持生存，就是让自己留在可行核里。

**世界模型就是世界的一个因子。** 因子是保持动力学的压缩：映射 π 满足 π∘T = S∘π，也就是一个更小的、与世界同步演化的系统。对某一类预测足够的最小因子叫特征因子，在计算力学里对应因果态（Crutchfield 的 ε-机器）。

**结构与随机。** 遍历理论的结构定理（Furstenberg–Zimmer；Host–Kra 的幂零因子）说，一个系统可以分成有结构、可预测的部分，和相对于它伪随机（弱混合）的部分。周期与准周期的结构是 Kronecker 因子（紧群上的旋转），对应节律和相位；幂零系统是更广的准周期结构。反向流消解结构部分。理想情况下，残差就是相对于模型的混合部分，再也榨不出可预测的东西，这给了一个检验模型是否完整的标准（V5）。这些定理是为封闭、保测的系统证明的，我们借用的是概念，不是定理本身。

它和耗散结构在同一个闭环里是一致的：耗散的下界等于无预测价值的记忆（Still 等，2012），所以「少耗散」与「只保留有预测价值的信息、降低意外」是同一件事的两面。自由能原理的一些普遍性主张仍有争议；我们把它当作行动的原理来用，由 V7–V9 去检验，而不当作已经证明的定理。

### 2.6 从定义到生成大脑

**为什么需要基因组。** 闭环要长出的东西种类繁多：读、想、说、价值、自我、他人。它们必须由很短的描述来指定，否则无从被找到。描述之所以能很短，是因为每一层的规则都复用下一层已经成形的规律（§2.3）。基因组不是一张一次性的蓝图，而是这个过程的**规则**：它选定利用哪些守恒池、它们的清除与补充速率是多少，保留哪些对称、在哪里打破它们（§6）。

**果蝇是存在性证明，也是踏脚石。** 果蝇用约 1.4 万个基因，长出了一个在果蝇生态位里满足 D1–D10 的个体。但它的大脑是进化替果蝇生态位预训练好的产物，带着果蝇的先验。所以我们不复制这个产物，而是反推它的规则，再在我们的生态位里生长新的个体。我们的生态位是连续语言流、妈妈世界与社会互动。

目标个体：天生就能主动读、想、说，从出生起带有最小的社会心智，在无限信息流中维持自身的可存活性。

**分工。** 自我生产、对必然规律的利用、O(1) 的局部学习、事件驱动的稀疏计算，都是生物已经做到的，我们原样继承这些原则。生物果蝇受限于肉身的是带宽、学习与计算的效率、规模，这三样正是硬件可以超越的地方（§9）。

## 3. 一句话原理

> 大脑是一个在外部信息流中**自我生产的闭环**：活动维持结构，结构产生活动。
> 它的机制都从**必然**中生成：守恒加有限速率生成痕迹，对称生成重复与连续记忆，对称破缺生成分化；而且是递归的，每一层把下一层成形的规律当作新的必然。
> 结构会更替，活动会耗竭池；有限基础供给经局部标签捕获，合成与维持消耗材料，拆解归还可回收部分。要长成会学习的生命体，经历产生的后果还必须决定哪些结构值得继续维持；这一作用由世界闭环检验。
> 它是远离平衡的耗散结构：只有信息流穿过时才有序；它通过感知和行动两条路降低意外。
> 研究流驱动下的局部物理过程何时形成可维持的输运结构，并在世界交互中产生预测与行动；构形极值和预测编码分别给出条件预言，不预先将它们与任意稳态等同。
> 闭环的局部常数由少量**遗传身份码**设定，所以会分化出不同的细胞类型；身份码在**可存活性**上接受选择。

## 4. 一个过程，五个时间尺度

以下R保留为原框架的候选有效代价，用于声明条件后的子系统分析。总能量收支、熵产生与外界做功是正式生成介质的物理约束；不能预先规定整个有源开放系统沿R下降，或把预测误差直接等同于热力学能量。下一步从局部储能、转化与边界驱动闭合动力学，详见[物理核心](CGB_PHYSICAL_CORE_20261022.md)。

```
R = Σ_边 |J|²/g     （残差没在本地被消解、继续向下游传播的耗散）
  + λ Σ g           （维持结构抵抗更替的耗散）
  + κ Σ 放电        （放电耗竭池、再补充的耗散）
  + Σ 擦除          （清除痕迹、回收结构的耗散）
```

在硬件上，这四项依次对应下游的计算、边占用的显存、放电带动的访存与运算，以及写入。

同一个过程在不同时间尺度上，作用于不同的变量：

| 尺度 | 变量 | 闭环在这个尺度上的样子 | 对应的生物机制 |
|---|---|---|---|
| 毫秒 | 内部流 u（预测作为反向流） | 推理：预测与输入相抵 | 膜上的电荷求和、抑制；钠通道池带来不应期 |
| 毫秒到秒 | 行动 a（说话、调感觉增益、等待） | 主动推理：改变源本身 | 运动输出、注意 |
| 秒到小时 | 痕迹池 z 与导通 g | 学习：痕迹在广播下转化为结构 | 钙 → cAMP → 激酶 → 标签的级联；三因子可塑性 |
| 小时到一生 | 拓扑（节点的生死、分裂）与营养支持 T | 生长与回收：营养因子把容量引向流量需要的地方 | 神经发生、营养因子竞争、修剪、结构可塑性 |
| 代际 | 基因组 θ | 选择：哪些规则能长出可存活的闭环 | 进化 |

这里没有「先发育、后学习」的流水线。出生只是这个过程最剧烈的阶段；生长、回收和学习一生都在同时发生。

**学习通过局部标签请求结构改变，材料决定实际能合成多少。** V2 将流驱动具体化为局部钙与激酶K、磷酸酶P两个池；标签z记录两者之差。第三因子m调节转化，支持T调节更替，V2f的材料B支付合成。标签是学习信号，不与结构质量直接等同；二者的收支分别追踪。当前兴奋性结构的模板为：

```
dz_ij/dt = (K_ij − P_ij) − m_ij·z_ij − z_ij/τ_z
dg_ij^请求/dt = η·m_ij·[z_ij]₊·(1 − g_ij/g_max)
              − η·m_ij·[z_ij]₋·g_ij/g_max − λ(T_ij)·g_ij
实际正向合成消耗 χ·dg₊ 的材料；拆解返还 r·χ·dg₋，其余进入损失账。
```

更替速率λ在得到支持时变慢。有限槽位限制每条兴奋边的占据，局部材料限制实际合成；材料模式用冻结速率的解析更新处理槽位转化，再按实际库存付款。V2f已验证收支与恢复。钙→cAMP→激酶→标签的多级慢池仍是长延迟信用的设计方向；当前V2实现的是钙、双酶池与标签，跨长延迟的世界后果信用尚待接入和验证。

**沿E6/E9进一步闭合材料反应（2026-10-21）。** 令n为相同结构单元的占据量、S为槽位总量，底物b直接进入合成反应：`p=k⁺b(S−n)`、`d=k⁻n`、`dn/dt=p−d`；共享供体满足`db/dt=Q−γb−χΣp+rχΣd`。k⁺/k⁻继承既有标签催化及λ(T)，不新增学习目标。即使p=d，仍要支付(1−r)χd的真实周转损失，旧净变化记账不能分辨这一项。已推导非负、逐供体守恒且解唯一的有限速率隐式步，及亚阈值膜—钙—酶—结构闭环的局部导数，共14项解析/数值核对通过；独立实现尚未替换原介质或历史存档。n到电导g的映射和燃料能量账分别识别，不能由结构材料守恒代替。完整推导见[材料反应、空间分化与构形关系](CGB_REACTION_GROWTH_DERIVATION_20261021.md)。

**维护与重组的同一物理子核（2026-10-22）。** 沿原有限占据与逆向支持，已实现支持的游离／结合／搬运与有限高低能驱动态之间的可逆交换；再将接触位置区分为未安装、已安装空闲、已安装结合三态。结构增长和拆解由同一局部底物／驱动态支付，正反通量满足声明的状态自由能差；在忽略直接拆除结合态的明确通道假设下，占据产生保护，无需另写λ(T)保护函数。97项相关检查、已有192节点545边图上的200ms实际接口及完整恢复通过，结构占据545→557.91968，底物等量扣减，状态数组约37.5KiB，见[原有限交换结果](CGB_FINITE_EXCHANGE_RESULTS_20261022.md)。随后沿同一储能过程接入可逆换能和并联导通：边界功经快电荷影响有限驱动池，池影响结构，结构改变后续快响应。110项相关检查、200ms四臂对照与步长收敛／恢复通过，物理子核状态约50.8KiB，见[双向功交换结果](CGB_FAST_WORK_RESULTS_20261022.md)。再以同一有限池支付极性传输，允许逆电势和反向再充能，并接入保留状态、有限供能且有反作用的外部电容端口；124项相关检查及真实书架UTF-8字节的四臂接口／恢复通过，完整子核约55.6KiB，见[有源端口结果](CGB_DRIVEN_PORTS_RESULTS_20261022.md)。上述是声明材料的有效实现，参考参数未标定；动作电位、连续身体与语言行动后果的持续学习仍待整合，未替换原脑。

**这两条方程是可塑性模板的有效规律，学习规则本身是被生成的。** 按 §2.3 的设计规则，STDP、BTSP 这些学习规则不写成规则，而由突触层的池生成。基于钙的可塑性模型（Shouval、Bear、Cooper 2002；Graupner 与 Brunel 2012）给出了现成的模板，它的组件全是守恒池、有限速率与饱和占据：
- 突触前的痕迹池：谷氨酸结合在受体上的占据比例，按有限速率衰减；
- 突触后的驱动池：钙，来源可以是反向传播的动作电位、树突平台电位或调质；
- 重合检测器：NMDA 受体要求突触前有谷氨酸、突触后已去极化（镁离子阻断）；果蝇 Kenyon 细胞里是检测「钙 + 多巴胺」重合的腺苷酸环化酶 rutabaga；
- 方向相反、阈值不同的两个酶池：钙高时激酶（CaMKII）占优，突触增强；钙中等时磷酸酶（calcineurin）占优，突触减弱；
- 依赖权重的饱和，即占据型的上界。

模板覆盖以下候选参数区间。当前V2已测到STDP样时序不对称与BCM样频率依赖；BTSP和受体家族的符号翻转仍待在同一介质中实现和验收：

| 生成出的规则 | 时间常数 | 突触后的驱动 | 方向由什么决定 |
|---|---|---|---|
| STDP | 几十毫秒 | 反向传播的动作电位 | 先后顺序决定钙的峰值：先前后后时 NMDA 给出高钙而增强，反过来时钙中等而减弱 |
| BTSP | 几秒 | 树突平台电位，即定向的指导信号（§7 的教学通路） | 痕迹与平台的重叠，乘上依赖权重的双向项：弱的增强，强的减弱 |
| 果蝇 KC→MBON 时序规则 | 秒级 | 多巴胺，作为隔室广播 | 受体家族：Gαs 型与 Gαq 型通路让同样的顺序产生相反的符号。果蝇线实测的「正向减弱、反向增强」属于这一类 |
| BCM 式频率依赖 | 由慢池决定 | 平均放电率 | 低频时钙中等而减弱，高频时钙高而增强 |

基因组不指定「用哪条学习规则」，只指定池的时间常数、突触后由什么驱动、表达哪种受体、两个酶池的阈值（§6）。不同的细胞类由此带着不同的规则。

**超稳定性（Ashby）。** 快环路负责行为；慢环路负责结构，在关键变量（营养支持 T，§5）离开可存活区间时被激发。结构不断改变，直到 T 回到区间内。学习因此不需要一个单独的模块，它是自维持在扰动下的必然结果。

**待检验的构形关系。** 在固定源汇、准稳态被动输运以及成本λΣg^γ的子系统内，变分给出`g ∝ ⟨J²⟩^{1/(1+γ)}`；只有波形缩放等条件使⟨J²⟩正比于⟨|J|⟩²时，才化为原预言`g ∝ ⟨|J|⟩^{2/(1+γ)}`。上面R的线性维护项对应γ=1。现行钙—标签—材料反应能否实现相应局部结构变化，仍需检验，不能另补一条塑形规则以强行得到指数；有源神经流的能量/边界功也必须另行闭合。推导及适用范围见[本轮推导§4](CGB_REACTION_GROWTH_DERIVATION_20261021.md)。

**预测价值与耗散的关系需要具体过程。** Still等的信息热力学结果为非预测记忆与耗散成本提供了联系，应在其假设下使用；它不直接给出现有介质的局部结构更新律。正式生成法则先核对储能、输入功与不可逆损失，再检验形成的结构是否有预测价值，不把低耗散或某个稳定状态直接认作预测编码。

**闭合与自我模型。** 一部分源是自己行动的结果，比如自听，或者妈妈对自己说话的回应。要降低 R，就必须预测自己的影响。

## 5. 介质：流、池、更替与竞争

介质里的每一种状态量都写成 §2.3 的连续性方程，**一种量的汇就是另一种量的源**。整个介质是一张每一步都能追溯的转化图：

| 量 | 位置 | 输运 | 源 | 汇 |
|---|---|---|---|---|
| 残差 u | 节点 | 沿边流动，J_ij = g_ij·s(c_i)·f(u_i) | 感官注入 | 被预测消解；继续向下游传播；耗散 |
| 支持信号 Nf/T | 突触后局部池／边 | 当前由突触后局部池分给入边；终扣汇总和跨层逆向传递待接 | 有限基础供给q0；边按正标签捕获 | 清除与支持衰减；T调节更替 |
| 合成材料 B | 当前为每个突触后局部供体 | 同供体的结构请求分享实际库存 | 外界有限供给；结构拆解回收rχ·dg₋ | 结构合成χ·dg₊、实付维持、清除与不可回收损失 |
| 痕迹 z | 边 | 不输运 | 局部钙驱动的K−P | m·z与z/τ_z；这是信号动力学，不冒充材料质量 |
| 结构 g | 边 | 不输运 | 有限槽位中的标签转化请求，由B实际付款 | 标签驱动的减弱与更替λ(T)g |
| 囊泡 v、通道失活 r | 边、节点 | 不输运 | 按有限速率补充、恢复 | 每次释放或放电消耗一份 |

- **流的是未被解释的信息（预测残差）。** 感官是源；预测是反向的源；行动是另一种汇，它改变未来的源。
- **实现层级。** 当前`medium.py`是CPU点神经元介质，候选边固定，每步扫描局部状态；多分支、共享终扣、物理传导延迟和动态拓扑是下面的目标结构。局部状态与材料账已能完整保存恢复，不等于这些目标结构都已接入。
- **单元是细单元。** 每个单元只有几个标量：残差势 u（膜上的电荷）、通道池的失活比例 r、营养支持 T、身份码索引 c、三维坐标 x。不用宽向量。
- **树突分支与终扣。** 每个单元带少数几个树突分支，每个分支有自己的超线性和局部共享池，共同活跃的输入在分支上自发成簇。每个单元的输出经由若干终扣送出，一个终扣可以连着多个下游细胞上的边。
- **边是稀疏的有符号导通**：g_ij ≥ 0，符号由 c_i 决定（Dale 原则），带延迟 d_ij，带痕迹池 z_ij，带囊泡池的可用比例 v_ij。不应期和短时程抑制由这两个池子的有限补充速率给出，不另写规则；放电越多，池越空，活动自然变稀疏。
- **营养因子竞争（神经营养因子学说）。**
  - **当前规则是基础供给＋标签捕获。** V2/T4发现，只在残差下降时供养结构会使早期结构与供给一起衰退；单按活动捕获又偏向高频输入。修正后，突触后池有有限基础产量q0，入边按正标签[z]₊捕获支持。T4d的慢活动池让增强阈值随长期活动滑动，改善了对高频无关输入的抵抗。
  - **残差下降保留为候选调制。** 可以由输入仍在场时的活动回落或局部方差变化估计，但不再作为唯一供给来源。接下来要检验这种调制是否确实奖励预测贡献，而非仅跟随活动变化。
  - **支持与材料分账。** Nf/T控制分配与更替，B支付结构合成和维持。V2f中每个局部供体都满足 `B+χΣg+清除+实付维持+不可回收损失=初始材料+累计输入`；供给减半的解析验算得到结构平台比0.5，断供后缩小、恢复后回到原平台。
  - **终扣汇总与跨层传递。** 在原V2每边支持与突触后局部供体上，已增加可关闭的守恒传递候选：捕获支持T沿神经连接反向进入所属细胞的运输池H，再从H扣款释放回该细胞的游离支持Nf，从而供自己的上游捕获。关闭运输是同积分器的局部对照；原历史路径仍默认保留。61项聚焦检查及已有192细胞候选的4800ms配对接口运行通过；外源相同，开启臂发生运输与再释放且支持收支误差<2e-12。该接口是一阶有效驻留模型，尚非几何轴突运输，也未证明跨层有用性选择；已有终扣存量的搬运和局部保护降低须单独辨认。后果调制保留为独立候选，参见[方案](CGB_SUPPORT_TRANSPORT_PREREG_20261021.md)与[结果](CGB_SUPPORT_TRANSPORT_RESULTS_20261021.md)。
  - **竞争强度也由群体塑造。** 在固定补给、有限单元容量的原材料反应中，参与消耗的结构增加会压低可用底物，减少后底物回升。总量负反馈与局部差异放大是不同模态；是否形成分工，取决于实际局部反馈及空间/输入/时间机会。局部胜出不免除外层成本，不应期也不单独证明长期垄断不稳定；应以同一支持通量逐层检验，不补发言配额或多样性奖励。
  - **远端来源已单独追踪。** 后续固定总供给、保留旧库存的四臂检查中，标签捕获能摄取／再释放，但新支持未到达两跳及更远位置；假干预全状态相同。随后保持同一源与运输、只换用Claude已有活动捕获，两跳及更远位置累计捕获新支持2.36705单位。该结果定位了捕获条件造成的可达性差异，不证明高频活动更有价值。69项相关检查通过；下一步从占据／结合过程区分基础维护与学习选择，不先补任意混合捕获公式。见[远端支持比较](CGB_REMOTE_SUPPORT_RESULTS_20261021.md)。
  - 得到支持的边更替慢，缺少支持的边更替快。节点死亡、分裂以及空闲槽位复用仍待接入；V2f记录维持欠款，没有擅自把欠款变成新的死亡规则。
  - 意外本身是系统自己的量：NLL 就是自己的预测对自己感官的意外，本地的残差下降就是它的局部形式。所以全局的意外可以作为调质广播，与本地的下降相乘（第三因子 m 本来就包括这种调质）。但营养不能只按一个全局分数分配：一个标量说不清是谁让意外下降了，放电最频繁的细胞最容易和它碰上，就会白白得到营养，这是空间信用的问题。营养也不按流过的量分配，否则细胞会挤向高频的输入，而它们带来的比特很少。
- **选择目标。** 基础供给使出生与探索得以开始；局部学习和行动后果应让有预测作用的结构得到更多支持。已有标签捕获与材料守恒原型；“留下的是预测贡献”要在真实信息流和匹配干预中检验，不能由标签非零直接推出。
- **可存活。** 营养支持是关键变量，**可存活区间 = 营养支持维持在存活阈值之上**。
- **容量与材料收支。** 支持信号T决定选择与更替；结构的物质成本由局部材料B支付，合成扣款、维持消耗、拆解回收，且逐供体守恒。V2f已接入这一收支，避免只有正标签就凭空生成结构。结构量约束要真正变成硬件内存约束，还需把节点／边的申请和回收接到分配器；当前固定候选边的数组不会因g变小自动释放。更大硬件可以容纳更多材料与结构槽位，但映射要测量，不能把信号浓度直接当成字节数。详见 `CGB_V2F_RESULTS_20261021.md`。
- **岌岌可危。** 营养因子太充裕时没有竞争，闭环什么也学不到；太稀缺时闭环解体。适应性只存在于两者之间。稀缺程度就是信息流的速率与营养因子总量之比，再由营养因子的产量调节（§6）。
- **稳态只走规范方向。** 稳态调整一个细胞的整体尺度（输入权重与阈值同比例），不动权重之间的比例。

## 6. 过程的规则：基因组

基因组给出的不是结构，而是生成和维持结构的规则：选定利用哪些守恒池、清除与补充速率多少，保留哪些对称、在哪里打破。

**当前交付的范围。** V3d交付的是已知3000类细胞、给定几何时的条件强度规则；没有导出完整的谱系发育、生理映射和连接发生程序。是否相连与相连后有多强分别建模，不能把条件强度码直接塞进sigmoid当作相连概率。V2f已提供显式接线接口：调用者给出接触候选、连接概率和生理类别，强度规则初始化槽位占据，再由有限材料支付。

- **身份码** c = 空间种子 × 二分位 × 时间计数：
  - 空间种子来自形态发生素梯度（显式的对称破缺），相当于神经母细胞；
  - 二分位：每次分裂按 Notch 方式分成 A/B 两个半谱系（打破置换对称）；
  - 时间计数：类似转录因子的时间级联；
  - 需要连续记忆的细胞类可以带一个圆周索引，保留旋转对称，以形成环形吸引子；
  - 分裂一生都在发生（§5），所以身份码的生成也一生都在进行。
- **生理**由 f_θ(c) 给出：
  - 各个守恒池的容量与补充速率，它们决定不应期、短时程抑制、痕迹级联的时间常数；
  - 兴奋还是抑制、受体集合、是否释放广播信号；
  - 可塑性模板的参数：各池的时间常数、突触后由什么驱动（动作电位、平台电位还是调质）、表达哪种受体家族、两个酶池的阈值、转化效率 η；
  - 营养因子的产量与释放范围、结构的基础更替速率、存活阈值。
  - 更替速率与池补充速率之比决定结构的形态：更替快时长成少而强的边，补充慢时长成多而弱、很少放电的边。这个比例从生物的数值出发，交给选择调整。
- **布线**由空间相遇机会和定向身份识别共同生成。相遇原始量是接触强度，不天然是[0,1]内的概率；连接发生程序需要明确将其转成合法概率，并单独校准。下述“相遇×匹配”先描述期望接触／突触量。轴突沿梯度生长、聚束，形成通道，以及局部兴奋与远程抑制形成区块，是空间发育的待实现机制。
- **相遇项的推导（2026-10-20 补）。** 它由三条必然得出，不是另加的规则：
  1. **局部性（物理）。** 突触只能在两个细胞的膜真正接触的地方形成；在比接触距离大得多的尺度上，分支的细节位置近似随机。所以 i 与 j 之间潜在接触点的期望数服从**质量作用律**，和化学反应的碰撞率一样，正比于两者在同一处的浓度之积：
     E_ij = κ ∫ ρ_i^出(x) · ρ_j^入(x) dV。
     其中 ρ^出、ρ^入 是输出分支（轴突终末）与输入分支（树突）的局部缆线密度，κ 是单位重叠的接触截面。这就是 Peters 规则，它是质量作用律在介质里的形式。
  2. **分支往哪里长（显式破缺加构形律）。** ρ_i(x) 本身由生长决定：
     - 生长锥按身份码表达的导向受体沿形态发生素梯度前进，这是 §2.3 的显式对称破缺；
     - 生长锥沿已有的束聚集，流过的越多越被加固，这是 L1 与构形律。

     所以「是否沿已有束」不是第三个因子，而是 ρ 的一部分：沿束生长的分支，在束经过的地方密度更高。
  3. **相遇之后才谈匹配。** 一个接触点能否成为突触，由分子识别决定，概率为 σ(c_iᵀ A c_j)。所以期望突触数是两者之积：
     N_ij = E_ij · σ(c_iᵀ A c_j) · S_ij，
     其中 S_ij 是活动与营养支持决定的保留比例（§5）。取对数，相遇以**可加项** log E_ij 进入，系数应接近 1。

  **可证伪的预言（E1b）：**
  - (a) 只用骨架算出的重叠（不用任何突触信息）在度之外解释大部分连接强度；
  - (b) log E 的系数接近 1（纯质量作用）；
  - (c) 它补上「是否相连」里低维码之外的一部分。

  **失败时的出口：** 相遇解释不足时，继续区分匹配码、未观测的精细接触与活动依赖的 S_ij；通过新的配对预测确定各自份额，再决定哪些应由出生规则生成、哪些由个体经历塑造。

  **已知的近似：** 骨架不分轴突和树突，第一版用全缆线密度近似 ρ^出 和 ρ^入，方向性只能靠度和码来承担。
- **广播信号**由「调质类」细胞释放，经扩散和受体作用于目标；同一种化学物质对不同受体的细胞含义不同。
- **多尺度与模块。** 把一个模块收缩成一个节点，看它在更大回路里起什么作用；再看模块内部。这就是 Connes–Kreimer Hopf 代数的余乘法：Δ(回路) = Σ 子回路 ⊗ (把子回路收缩成一点后剩下的回路)，物理上就是重整化。谱系码天然给出可以收缩的模块。收缩后的节点按它的有效规律工作；有效规律失效的地方，要回到下一层（§2.3）。描述「规则怎样一步步生成回路」，更自然的语言是图文法和算子（operad，例如连线图算子）；Hopf 代数擅长的是分析与分解，两者互补。

在果蝇数据上的证据（maleCNS，2026-10-18）：
- 半谱系内递质一致率为 0.877，打乱后为 0.509；
- 80% 的突触落在 4.2% 的半谱系对块里，打乱后为 32.5%；
- E1 完整拟合（2026-10-20，3000 个类型，覆盖 64% 的突触，只在留出的类型对上评分；详见 `CGB_V1_E1_RESULTS_20261020.md`）：
  - **「谁连谁」：** 只看出入度的 AUC 是 0.731。每类型 8 维码在度之外多解释 55%（AUC 0.977），16 维码 60.5%（AUC 0.982），再往上就停在约 62%。
  - **噪声上限：** 左右两侧是同一套发育程序的两次实现，用左侧同一对的布线预测右侧，只能多解释 62.5%。16 维码在同样的测试对上是 58.8%，达到上限的 94%。所以平台是发育噪声，不是生成器的缺陷：**约 16 个数一个类型，生成了几乎全部可重复的布线**，只占类型对数的 0.5%。这支持「基因组是规则，不是蓝图」和「很多地方只规定统计」。
  - **谱系：** 半谱系先验只在 k ≤ 4 时有帮助，没有让所需的 k 减半。学到的码不只是半谱系标签；身份码里的时间计数（标注里有 birthtime）还没检验。
  - **连接强度：** 两侧都相连的类型对上，去掉度效应后左右相关 0.916（共享方差 84%）。E1 早期拟合的码只解释约 5%–15%；V3c 扩大正则网格后，64 维有方向码单独达到 21.7%，与几何合用达到 42.2%，说明早期低值受拟合限制。左右一致本身仍不能区分发育匹配和共同经历；生成器需要保留几何、身份匹配与后天可塑性的共同作用。
  - **E1b 相遇项（2026-10-20）：** 只用骨架算分支重叠，不用任何突触信息。
    - **局部性被证实：** 相连的类型对全部有重叠；4 µm 尺度下 72% 的类型对完全没有重叠，也一个都不相连。
    - **几何本身是生成器：** 只靠相遇加出入度，就解释"是否相连"的 59%，与 16 维匹配码相当；两者合起来达到 65.7%（AUC 0.988），到了噪声上限。
    - **强度没解释上去：** 只解释 15% 到 19%，log E 的系数约 0.5。这可能是测量稀释（骨架不分轴突和树突），也可能是有限资源竞争造成的亚线性。
    - 当时尚未解释的强度继续由更细几何、匹配码与活动依赖学习共同竞争解释；不预先全分配给 S_ij。
  - **E1c 分开轴突与树突（有方向的相遇）：**
    - **几何单独到了噪声上限：** 只靠有方向的相遇（两个系数加出入度），"是否相连"就解释 64.2%（AUC 0.987），超过 16 维匹配码，到了噪声上限；加上码是 67.6%。
    - **系数往 1 靠，但未钉住：** 只用正向重叠时系数稳定在 0.70（4 µm 和 2 µm 都是）；同时放入反方向重叠时，拆分不稳定（4 µm 下 0.97，2 µm 下 1.39）。
    - **强度分解（同一口径，E1d）：** 左侧复本参照 83.6%，几何（2 + 4 µm）31.6%。早期匹配码 5% 的数字已由 V3c 更正，几何加有方向码达到 42.2%。几何之外的约 52 点是待分解的空间，不能当作活动依赖学习已获支持的份额。
    - **E1e 局部竞争：** 4 µm 体素内按份额瓜分的竞争版本（突触后、突触前、双向）都不比质量作用好（19% 到 23%，质量作用 22.9%），预言被否定。剩余的强度如果来自活动，形式应是相关性依赖的强化，而不是局部拥挤的瓜分；这要在活体里检验。
    - **V3b/V3c 的新增线索：** 1µm接触代理只在既有几何之外增加约0.6点；接触处粗细的效应在1µm上增加3.2点、2µm上复测增加2.1点。共同输入代理贡献较小；这些静态代理结果没有排除所有活动依赖学习。余下强度继续由更细接触、单细胞差异、身份匹配和经历改造共同解释，未解释部分不自动归给后天学习。
    - **V3d 已把匹配码拟合稳。** 原E1历史划分、三种子：几何31.56%，几何＋对称64维码38.43% ± 0.04点，几何＋有方向64维码42.18% ± 0.13点，几何＋有方向256维码42.74% ± 0.12点。额外更新和验证选型已完成；64维在几何之外增加10.62点，256维只再多0.56点，初版采用64维。它有202105个参数，CPU部署档约1.14MiB，并在全部295982个观测相连类型对上重建通过。这是条件强度统计，不是独立动物或功能验收。
    - **从拟合转入出生与持续改造。** V2f已将该强度规则接入局部介质，初始结构也要付材料成本；接下来生成输出／输入分支的空间分布与接触，接独立发生规则，再让世界后果调节局部学习。数据研究详见 [V3](CGB_V3_RESULTS_20261020.md)、[V3d](CGB_V3D_RESULTS_20261021.md)，接口见 [V2f](CGB_V2F_RESULTS_20261021.md)。

## 7. 天生的主动性与社会心智

生物新生儿带着发育形成的能力。这里要由基因组生成以下几类细胞；它们是新介质的设计目标，现有条件强度生成器与材料接口尚未交付这整套社会回路。下一步让这些类别的信号真正进入第三因子与行动后果学习，再做功能检验。

| 先天细胞类 | 作用 | 果蝇或婴儿里的对应物 |
|---|---|---|
| 传出副本（efference copy） | 抵消自己发声造成的听觉残差；剩下的残差就是「他人」 | 果蝇运动时的视觉抑制；伴随放电 |
| 依随性检测 | 对方的回应依赖自己的行动时，这条流里能被消解的残差更多，相关结构得到的营养支持也更多 | 婴儿对依随回应的偏好 |
| 话轮节律 | 内在的说与听交替振荡，与对话的节奏锁相（数学上就是把节律建模为 Kronecker 因子）；静默时内部继续演化 | 婴儿的原始对话节律 |
| 语境的连续状态 | 保留旋转对称的环形吸引子，持续存放话题与语境，由输入推动 | 果蝇中央复合体的朝向环 |
| 新奇与价值调质 | 惊奇、熟悉度和价值三种广播信号，分别作用于不同隔室 | 蘑菇体的 PPL1/PAM 多巴胺神经元 |
| 教学通路 | 把指导信号定向投递到少数细胞的树突，引发平台电位，让它们在一次事件之后绑定之前几秒内的输入（BTSP 区间）。在妈妈世界里，指导事件可以是妈妈对某句话的确认或否定，或者一次大的惊奇 | 内嗅皮层到海马 CA1 远端树突；小脑攀缘纤维；果蝇的隔室 DAN |
| 读、想、说三种汇 | 三种汇各自按自身后果学习：读降低外源残差；想是静默中的回放，降低未来残差；说改变源；说出的词序可以由异宿通道生成 | 前额-基底节式的门控 |

**最小社会心智**：介质学会了「对方的回复 = f(我的行动, 语境)」，并用它来选择行动。对方是最大、也最可控的残差来源，所以维持与对方的对话关系，就是维持自身的生态位（D8）。

## 8. 原生多模态接口：世界、身体、大脑

语言从感官进来，从发声器官出去；「词」是生命体自己学会的块，而不是预先给定的。目前果蝇、3D 介质、CBIM 三条线都用 GPT-2 的分词器和预训练词表投影进介质：词的切分与语义几何都是外部数据上学好的先验，词表接口也是最大的资源消耗者（旧 3D 介质的 1.19 亿参数里，词表占 7700 万）。新框架让同一个字以三种样子同时进入：它的声音、它的字形、它的编码。

**参照。** Gemma 4 的小模型用一个冻结的 USM 音频编码器（两层下采样卷积加 12 层 Conformer，Mel 特征，40 毫秒一块）；12B 模型干脆不要编码器，把 16 kHz 原始波形按 40 毫秒切成 640 维的块，线性投影进语言模型。两者都不用拼音或音素，直接吃声音。我们既不能用预训练编码器（外部先验），也不把一切交给一个巨型网络，而是取两者之间：一个按生物耳蜗做的固定换能器，后面接会自己学习的介质。

**三层划分。**

| 层 | 组件 | 性质 |
|---|---|---|
| 世界（妈妈） | 大语言模型（她的心智）、语音合成 TTS（她的嗓子）、语音识别 ASR（她的耳朵） | 世界可以很聪明，这些都不进入生命体的大脑 |
| 身体：感官 | 耳蜗、眼睛、字节 | 固定换能，不学习 |
| 身体：发声 | 肌肉与发声器官：声门、带鼻腔的声道波导、呼吸 | 物理模型，固定不学，只由运动单元驱动 |
| 大脑 | 构形介质 | 一切学习都发生在这里 |

**三条感官通路。**

| 通路 | 换能 | 受体 | 生成的结构 |
|---|---|---|---|
| 耳朵 | 16 kHz 声音经过一组固定滤波器（gammatone 或 Mel，约 64 个频率通道），每 10 毫秒取一次对数能量；毛细胞式的适应只对变化敏感，分成起始与持续两类；另有一组周期性检测受体提供音高，对应听神经的相位锁定，声调由此可听 | 约 128 个频率受体加音高受体，事件驱动 | 频率轴上的平移对称生成按频率排列的柱（音调拓扑） |
| 眼睛 | 每个字用字体渲染成小位图（如 16×16），像素即感光受体；ON 与 OFF 两条通路，只有笔画边缘放电；可以加字体变化与轻微平移 | 每个字几百个像素受体，真正放电的很少；位图缓存，查一次 O(1) | 平面上的平移对称生成视觉柱，学会平移不变的认字 |
| 字节 | 每个字的 UTF-8 字节（汉字为 3 个），每个字节值一种受体 | 256 种 | 精确的符号通道。UTF-8 首字节标明字的开始；常用汉字的码位大致按部首和笔画排列，前两个字节粗略带着部首分组。这些留给介质自己发现 |

**时钟与对齐。** 声音决定时钟，每 10 毫秒一个时刻；一个字说出来约 200 到 300 毫秒。字形和字节在这个字被说出的那段时间里呈现，就像边听边看字幕。对齐来自 TTS 时长预测器给出的每个字的起止时间；它不需要精确，Hebb 绑定和秒级的 BTSP 窗口本来就能容忍几百毫秒的偏差。静默就是真实的无声时间，内部动力学、痕迹的清除、结构的更替和自我生产照常运行。

**中间：汇聚，再扩张。** 和果蝇嗅觉一样，每条通路的受体先汇聚到一层嗅小球式的单元，再随机、稀疏地扩张到 Kenyon 细胞式的层。代码都是随机稀疏代码，由哈希实时算出，不预设任何语义。
- **三种感官互为老师。** 同一个字的三种样子总是同时出现，Hebb 共激活把它们绑在一起，不需要任何对齐标注。看到字形，就预测它的声音和编码；听到声音，就预测字形。预测错了就产生残差，所以一个字的内部也有了残差的源，不需要外部老师。三者互相补短：同音字靠字形分开；多音字读什么由妈妈的嗓子按语境决定，生命体要从字预测声音，就必须自己学会靠语境判断读音，多音字从转换器的错误变成了要学会的东西；罕见字靠形声规律得到线索。
- **语义几何是被生成的。** Hebb 共激活（§4 的可塑性模板）让共现的字词的下游集群代码越来越重叠；抑制与除法归一化提供不让它坍缩的「压力」；营养竞争让常见的字词占用更多细胞，即放大。三者的平衡态在这一层的有效描述，看起来就像大模型词向量那种自引力结构：共现带来吸引，频率带来排斥，平衡态逼近点互信息（PMI）。「引力」只作为这一层的有效规律用于分析，不实现为机制（§2.3）。拉动一个词、近邻跟着动的泛化，来自稀疏代码共享细胞，每次是一个 O(1) 的局部更新。
- **字和词的切分也是被生成的。** 婴儿靠音节之间的转移概率找到词的边界（Saffran 1996）：块内的转移概率高，块间的低。在介质里，这表现为残差在边界处出现峰值，在边界处放电的细胞自然成为「块」的检测器：先是音节和字，再是词。

**输出：真正的嗓子。** 大脑不直接输出声音参数，而是驱动一个有惯性的身体，不需要一个按词表大小的输出层：
- 每块肌肉由一群运动单元驱动，按大小顺序募集，每个脉冲引起几十毫秒的抽动。拮抗肌的力之差推动器官，器官是阻尼弹簧上的质量。自由度约十个：舌体（咽腔、收窄位置、收窄面积、口腔）、舌尖、嘴唇、软腭、声门内收、环甲肌（音高）、呼吸压力。
- 器官的形状决定声道的面积函数。声门源激励一根数字波导声道，在软腭处接出鼻腔分支，从唇和鼻孔辐射出去。湍流不由大脑指定：只在气流经过窄而未闭的缝隙时产生，擦音和爆破由此而来。
- 离散的脉冲经过群体叠加和身体的低通，必然成为连续的声音（§2.3），所以任何地方都不做事后平滑。音素和音节不预设，它们应在咿呀中作为运动空间里的吸引子涌现（V7）。
- 身体参数由父母选定：声道 13 厘米，约 12–14 岁少女，基频约 310 赫兹，轻盈。语速不属于身体，属于大脑读、想、说的节奏。
- 生命体自己说出的声音，经过同一个耳蜗被自己听到；传出副本类负责抵消这部分残差（§7、V8）。
- 妈妈的耳朵（ASR）把它的咿呀声转成文字交给大模型。咿呀阶段转出来的多半是乱的，妈妈被告知孩子还在学说话。以后也可以换成能直接听声音的大模型来当妈妈。
- 声音组成字、字组成词，是「说」这个汇在对话中按后果学会的（§7）。字节打字作为可选的第二种输出；矢量笔画作为「手」，留到以后。

**发声器官的现状（2026-10-19，暂缓）。**
- 已测：同一串随机运动指令，经过身体时，相邻 10 毫秒的频谱突变第 99 百分位为 5.3 dB；直接写进声道时为 14.0 dB；82 段真人录音为 6.4–12.2 dB（中位数 9.3）。连续性来自身体，这一点得到确认。
- 声道已做的两项物理修正：波用功率归一化，使每个结点的散射是正交的，器官怎么动都不会向管里泵入能量（用压力波时，闭合一打开能量放大上千倍，形成爆音）；湍流作为偶极子放在收窄处的出口。
- 未解决：舌尖或嘴唇收窄时，前腔的高频共振太尖，湍流一激发就随口型扫动，听起来像鸟叫。原因是缺少随频率增加的管壁与辐射损耗（软壁）。以后恢复时先补这一项，再重跑同一个实验。
- 照着录音拟合运动轨迹，说明这个身体能发出接近录音的连续过渡；但那是照抄，不是学会，只作为诊断。规则写出的乐谱和借用真人嗓子的合成都是替身，不进入生命体。
- 代码：`scripts/ib/generative/voice_speak.py`（发声器官）、`voice_babble.py`（随机指令实验）、`voice_imitate.py`（拟合诊断）；结果在 `results/voice_babble/`。

**代价。** 起步会比 GPT-2 投影慢得多，要从声音、字形与字节的统计一步步学到字、词，再学到语义；一个词变成几十个时钟，长延迟的时间信用（V5）更加重要。度量随之改为在字一级上与固定频率比较，并加上声音特征的预测误差。TTS 与 ASR 在 CPU 上运行，不占大脑的显存；所需的本地模型（例如 sherpa-onnx 的中文 VITS 或 MeloTTS、SenseVoice-Small）在下载前要先列出文件名、来源和大小，等用户确认。

## 9. 工程实现

**当前实现与引擎目标。** 现在的V2/V2f采用NumPy/SciPy、CPU、float64与固定候选边，按积分步扫描，内环不使用BPTT或Adam，状态不随历史长度增长。下面的事件驱动、低精度、动态槽位、GPU融合和多卡是引擎目标，尚不能按目标布局申报容量。

| 设计 | 效果 |
|---|---|
| 细单元，fp16/bf16 | 每个节点约 32 B，加上少数几个树突分支各自的局部状态 |
| 稀疏边：CSR 或分块 ELL，按空间和谱系排序，同一分支、同一终扣的边连续存放 | 按实际所需的导通、受体、囊泡、钙、酶、标签、调质和索引逐项预算；共享终扣和身份常数可以减少重复存储。原先“每边8–10B”没有覆盖当前全部状态，不能作为已交付预算 |
| 事件驱动：只有放电的单元推送 | 活动率 1–5%，计算量正比于活跃的边；囊泡池的耗竭让活动自然稀疏，计算随之节省 |
| 固定换能的三条感官（耳蜗、字形、字节），加上由哈希实时生成的随机稀疏代码；TTS 与 ASR 在 CPU 上 | 没有 V×D 的稠密词表和预训练编码器，输入代码的内存是 O(1)；字形位图缓存；输出只是约十个运动自由度 |
| 惰性衰减：每条边记录上次更新的时间，被触碰时补上清除、补充与更替 | 线性且速率固定的衰减可精确补时；钙、标签、支持和结构彼此耦合的过程需验证事件求解器与逐步积分的一致性。当前仍逐步扫描 |
| 本地预测贡献：局部活动／残差统计与标签 | 目标是局部信号驱动支持与第三因子；当前标签捕获已实现，世界后果驱动待接 |
| 支持信号选择结构，材料B支付结构，分配器管理硬件槽位 | V2f已守恒材料账；后续把结构合成／拆解与实际槽位申请／释放相连，才能把资源约束兑现为内存约束 |
| 生死与分裂：空闲槽位池，回收后复用 | 拓扑变化不需要重新分配内存 |
| 广播信号：每类或每个隔室只有少数标量 | 三因子的第三项是 O(1) |
| 路径签名（粗糙路径理论）：Chen 恒等式 S(前段+后段) = S(前段) ⊗ S(后段)，其代数结构是一个 Hopf 代数 | 对整条流的固定大小摘要，每来一步做一次 O(1) 更新；作为痕迹级联之外的备选，可以由基因组生成一类「签名细胞」 |
| 粗粒化：由有效规律的适用范围决定，用回路展开中环图修正的大小来判断 | 有效规律成立、平均场够用的模块，收缩成一个按有效规律工作的节点，省显存与计算；有效规律失效、涨落本身在承担计算的地方，回到下一层保留细节 |
| 内环没有 BPTT，也没有 Adam | 显存不随时间步增长，也没有优化器状态 |
| 外环只优化生成与维持规则θ | 目标是紧凑基因组。当前条件强度模型约20.2万个参数，且不含完整发育与生理；尚未运行妈妈世界中的代际选择。离线拟合可用Adam，不属于个体生命中的内环 |
| CUDA Graph、融合核、按谱系块分区到多卡 | 计算受带宽限制，可线性扩展 |

**当前实测与容量准入。** V2f的3000个类型接口节点、4096条边，介质数组约1.298MiB，完整压缩状态约0.514MiB；这不含Python依赖、数据准备和匹配生成器，且不是3000个真实细胞的发育验证。原“4GB可容纳1000万节点＋3亿边”的数字撤回为未验证估计：仅3亿边的一个float32导通和两个int32端点就需3.6GB，还没有其他局部池、节点、索引和工作区。4GB能运行到多大，下一步按完整状态与实际计算路径测量，优先共享不可变几何、压缩索引和分块工作区。

**生物果蝇受肉身限制、而硬件可以超越的**：

| | 生物果蝇的上限 | 硬件可以做到的 |
|---|---|---|
| 带宽 | 每个神经元的放电不超过约百赫兹；轴突传导慢；感官通道窄 | 一个时间步内就能完成多次传递；一个词可以对应任意多个时钟；输入输出端口的宽度按需设定 |
| 学习效率 | 可塑性和巩固要几分钟到几天；一生只能经历一次 | 时间常数由外环选择；经历可以回放；个体可以复制、分叉对照、存档恢复 |
| 计算效率 | 化学突触、离子泵的代谢消耗大，每次放电都要消耗 ATP | 只计算活跃的边；用融合核、CUDA Graph；用低精度存储 |
| 规模 | 神经元数量被身体、代谢和颅腔固定，成年后基本不再增长 | 按需分裂、生长神经元，按谱系块分区到多卡，可以线性扩展；多个生命并行演化 |

**局部学习不以逼近 BPTT 为目标。**
- BPTT 是截断窗口内的梯度：它必须保存过去，所以在有限资源下窗口永远是有限的（D1）。局部规则是没有视界的持续过程，靠痕迹级联和慢变量把信用跨越任意长的时间。两者能学到的东西本来就不同。
- 局部规则真正的难点在空间：一个广播标量同时管很多突触，信用就是粗的，网络越大学得越慢。
- 生物的解法是**生成一种让局部规则足够的结构**：
  - 扩张层把问题变成线性读出。在线性读出上，KC→MBON 的三因子规则本身就是精确的梯度；
  - 调质按隔室分工：每个 DAN 只管一个隔室，信用自然是局部的；
  - 有多条特异的广播通道。
- 数学上，这是 Koopman 算子的思路：在足够多的观测函数上，非线性动力学近似线性。扩张层提供观测函数，三因子规则学的是线性读出。
- 这正是基因组要生成的结构，外环选择的也正是它。

## 10. 路线：以果蝇为踏脚石

1. **逆发育（E1、E2）。** 拟合一套规则，让它重现果蝇的细胞类型和连接统计；然后用生成器重新采样连接组，在现有的果蝇模型上做活体检验，确认规则保留了功能。
2. **从果蝇规则出生。** 让这套规则在新介质里开始自我生产，得到「果蝇先验」的新生儿。
3. **生态位迁移。** 外环在妈妈世界里选择，让规则离开果蝇的先验，移向语言和社会的生态位。

**当前执行到哪里。** 逆发育的条件强度规则已经稳定交付，局部介质与材料账已接通；第1步尚未总体验收，第2步的出生候选已并行实现。出生接口接受接触、发生概率和生理参数；现有空间与发生程序已为它提供前两项，生理分化仍待校准。V2f只用真实相连类型对做接口验收，其后的空间候选才开始生成新的细胞分支和连接；二者的证据不混用。

空间预览已进一步用候选生长程序提供几何和接触，在新生成结构上接入发生、强度及同一材料账，并完成9600ms真实文本感官驱动。完整生长状态恢复和32项接口检查通过；生成几何出现原拟合分布之外的特征，所以下一步先校准这一出生候选。该预览尚没有预测读出和世界后果学习，不替代第3步的生态位验收。

首轮校准随后完成：强度残差身份码对未见类型形态仅改善2.59%，因此空间程序与连接识别程序分开估计，仍由同一类型身份索引。空间程序每类型14实数，已知类型新细胞的描述误差降低78.75%；发生概率独立使用总缆线重叠和有向身份匹配，在留出细胞对上的log loss为0.033495。新版已实际生成、保存和回放，36项聚焦检查及真实完整状态恢复通过。生成缆线质心误差中位数35.35µm，仍有8.47%的连续几何特征超出原强度拟合均值6σ。所以下一步集中验证**生成树形、输出/输入极性和接触统计**，而不是把描述预测当成完整逆发育已经结束。具体拆分、失败结果、参数及来源见[校准报告](CGB_BIRTH_CALIBRATION_RESULTS_20261021.md)。

联合检验已进一步执行：48类型2021个真实细胞中，204个留出细胞覆盖26类型。旧程序把8个执行槽当成累计物理锥上限，造成分叉密度只有真实同类细胞的约2.8%。现已用有限条件分枝过程分开工作区与物理树，实际生成342577段分支，分叉密度中位比恢复至0.979，40项检查及完整恢复通过。联合结果同时显示空间误差和方向接触覆盖退化，不能把分叉统计改善算作出生通过。该条件树保留为描述性对照：指定分叉数后的精确抽样没有推导生长机制。正式主线先以局部输运、受体结合、材料和耗散统一推出**根/主干、伸长、转向、分化/分叉及回收**的过程，再对其参数和联合统计作校准，不继续用目标形态加任意路径规则来代替推导。观察室保留此历史候选及失败证据，见[联合报告](CGB_TREE_JOINT_RESULTS_20261021.md)。

**接下来的连续路线。**
E2已先补功能敏感性定位：旧1024词新生儿的全局NLL尚不能承担验收；既有已学90112词参考在独立512词元上，真实脑NLL 6.841，胜过偏置7.139及独立固定读出7.216，全切损失0.879、输入滞后损失0.550。独立256词元定位中，仅切断实际感觉入口的快速输出就损失0.408，恢复控制全状态一致。因此后续重采样优先检验这条语言世界确实使用的入口通路，并核对生成器覆盖；MB/CX在当前全局NLL上尚无稳定阳性作用。此处交付急性诊断，不把它算成生成规则、持续学习或生态位验收，见[功能定位报告](CGB_E2_SENSITIVITY_RESULTS_20261021.md)。

入口覆盖核对也已完成：原图感觉出口边中，两端强度身份均覆盖的占50.40%，两端类型都在新空间描述程序校准范围内的仅4.88%。**4.88%不是相遇规律或已有真实骨架重叠数据的覆盖率。** Claude的E1b/E1c已交付无方向与有方向相遇，V3b已检验1µm接触及半径项；这些结果和数据直接复用。接下来的E2先用已有真实骨架相遇量和定向匹配，在明确覆盖的靶区做生成/破坏匹配的功能对照，未覆盖部分明确报告。从身份生成新的几何、再产生相遇机会是出生程序的下一环，单独验证；不因新空间程序覆盖不足而把相遇研究从头再做。

1. **空间出生。** 从身份规则生成输出／输入分支的空间分布和相遇机会，接入单独校准的连接发生规则；已有定向匹配给出初始强度，材料支付初始结构。达标：不用逐边复制真实邻接表，在独立留出统计上保持生成质量，候选与工作区稀疏有界。
2. **经历改造。** 在同一个连续个体里，让感官与世界后果驱动现有钙、标签、支持、第三因子和材料过程。当前m还是背景常数；要接的是后果如何改变学习，而不是只再加一个外部分数。达标：匹配状态的通路干预改变后续选择与学习，完整恢复连续性通过，支持与材料收支可追溯。
3. **语言生态位。** 用真实语料与多主线穿插的妈妈世界，连接聆听、等待、选词、时机和自听。达标：先测后学的预测曲线、对上下文的回应、回访与持续学习，以及依随交互相对轭控回放的收益；不以发言率、单次模仿或低NLL代替验收。

**V2原型带来的修正。**
- T1：囊泡池封顶的是释放通量，不是任意耦合下的放电率；快钠池已产生不应期，慢适应还需要更慢的生理池。已得到的工作点标度是结构与补充时间之比，不把它扩大成一切活动自动稳定。

- T4：基础供给＋标签捕获＋滑动增强阈值形成选择原型。T4e供给减半时平台仅下降约3%，且波动12%–14%未达10%标准；V2f后来补的是独立材料收支，并未把T4e旧预言改判成功。

## 12. 与以往各条线的关系

- **CBIM 连续场**（NLP、数独、碰撞因果都已证明）：它的场动力学适合作为快尺度推理的一种实现。
- **果蝇线**：提供规则的先验和机制库，例如隔室三因子、APL 的稀疏化、DAN 的价值分工、中央复合体的环形吸引子。果蝇线里用过的 unit trace（e ← λe + (1−λ)s）正是占据型的守恒池。
- **3D 介质 Gen1–4**：空间生长的直觉保留；表示从稠密网格改成稀疏空间图；结构的存活从「被分配」改成靠营养因子竞争。
- **词表**：三条线目前都用 GPT-2 分词加预训练嵌入投影；新框架前期沿用 GPT-2 分词做验证，并做随机代码对照，正式接口改为原生多模态：耳蜗、字形、字节三条感官，随机稀疏代码，有惯性的发声器官（§8、§10）。
- **Gemini 的 CFE**：保留其中的分裂与合并（即神经发生）、由通量冲刷出的时间尺度分化、Top-K 稀疏激活；它缺的是身份码、延迟信用、行动和闭合；它的 Kuramoto 相位不进入预测，也就没有承担职责；它的词引力只有吸引，阻尼连切向速度（角动量）一起衰减，长期必然坍缩。在我们这里，引力是语义层的有效规律，由可塑性、抑制与营养竞争生成（§8）。
