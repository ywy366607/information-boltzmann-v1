# 从已有生成元得到原生反向流与感觉匹配端口

2026-10-22。实施前推导，**本文件对应的端口接口尚未实现**。承接当前冻结观察器对照：原电势→bit约定并不是已经安装的内在预测。下面不加学习头、奖励或新的生物状态，而从已有电荷连续性定义一个可实现、可证伪的原生信号。

## 1. 分清边界状态与体内驱动

按实际端口角色，将材料分成边界B与体内H。q_B是边界当前电荷，x_H包含体内荷量、P/D、r/C、几何/拓扑和身份。现有电容能Σq²/(2C)与原零参考电极给出中性参考q_B=0；它不是新设的行为目标或发言率。

将改变q_B的通道分成：体内桥/本地有限驱动/域回收，以及感觉边界和世界电容之间的通道。世界源驱动先改变世界电容，脑侧通量随后进入同一连续性方程。

    d E[q_B]/dt = E[I_body(q_B,x_H) + I_sense(q_B,x_world)]

预测角色不能简单由“端口电势”这个变量名决定。先看在当前体内状态下，中性端口会得到什么原生驱动：

    N_B(x_H) = (L_body q_B) 在 q_B=0 的值
    I_expected_sense = −N_B

它是身体当前能够抵消的感觉电流，是**构成关系意义上的预期**；是否能预测之后的真实感觉，必须另测，不能从电流非零直接叫主观贝叶斯信念或自我。

中性参照不把体内x_H固定在初态。x_H的活动、痕迹、支持和空间结构仍持续改变，I_expected随当前生成体变化；残差的参照与整个体的固定吸引点不是一回事。

## 2. 被动反向流可直接从原通道取出

在固定当前材料的被动部分，令L是实际正导通的图Laplacian：

    I_body^passive(V_B,V_H) = −L_BB V_B − L_BH V_H
    N_B^passive = −L_BH V_H

第一项是对边界电势的即时反馈，第二项只由已存在的体内状态给出。不能把这两项混成一个端口读数，再先验地宣称它就是预测。L_BB半正定来自每条实际通道G≥0，不必另加预测损失。

## 3. 原反应在中性端口的电流也不需新状态

现有允许事件e的电荷改变量为ν_e，原率为α_e expit(−ΔG_e)。当前计量/端/资源准入不依赖q，α也不依赖q。只改变用于评价的端口电势时：

    ΔG_e^neutral = ΔG_e^actual − Σ_(b∈B) V_b ν_(e,b)
    N_B^reaction = Σ_(e为体内通道) ν_(e,B) α_e expit(−ΔG_e^neutral)

这是原二次电容能差的精确恒等式，不是梯度学习。仪器可直接计算，不必真的清空主体电荷。若做物理中性制备副本，必须给外电极补偿电荷，并实际记录制备ΔU/功；不得把虚拟评价当成一次无代价身体操作。

对固定载体的上述反应，负增量导纳为Σ_e α_e s_e(1−s_e)ν_Bν_Bᵀ，s=expit(−ΔG_e^neutral)，是半正定矩阵。这与被动反馈共同解释残差电势怎样实际改变原事件的亲和和概率。变维相变不能未经推导套用这一固定载体结论。

## 4. 变维通道必须明确计入

当前域出生有条件高斯荷量分配，父荷Q被分为Q/2±ξ，ξ均值0。接受比在解析消元后与ξ独立。所以中性端口Q=0的直接出生荷量漂移严格为0，即便出生的空间接受率积分未知；**出生的噪声不为0**，不能据此称已求出完整预测分布。

现有回收通道禁止删除实际端口。若端口是父域，允许的叶域回收带来已知q_child。用现有精确逆向率乘q_child计入N_B即可。中性评价只改变其出生反比中的荷量项：

    L_birth^neutral − L_birth^actual
      = [q_child² − (q_parent+q_child)²]/(4 C_parent)

原λ_recovery=α min(1,exp(−L_birth))随之精确评价；其他混合/端/几何/身份项不变。运动本身不直接改q。这样N_B的**中性瞬时一阶矩**可以包含完整当前生成元，不能把旧桥/池子电流子生成元冒充它。

## 5. 感觉匹配状态来自同一边界转化

当前实际八个端口一一对应世界电容，且基本感觉G>0。固定中性脑端和当前身体r/C、P/D，对候选世界电势V计算原感觉电流S(V)：原被动G·V加上原边界write/active通道的电流。它不读取未知下一字节。

每条边界电荷转化满足ν_world=−ν_brain，其率的电势响应使dS/dV≥0；加上基本G后严格递增。因此：

    S(V_expected) = −N_B

给出唯一感觉匹配世界电势。根的有限括区可以由实际G和Σ|ν|α的有界跳变电流推得，不需添加数值噪声或把根裁到±3。若感觉G为0或端口映射多对一，必须报告不可辨识/不可达，不能沿用一一对应的反解。

这个V_expected对应**世界电容的感觉状态**，不是外部数据驱动器的下一字节，也不等于未经传播的源电压。它首先要对照下一实际4ms后的世界电势、持久性预测和因果源滤波；语言NLL仍保留，不能改名混用。

## 6. 主观证据怎样回到原学习与空间

真实感觉不能被体内反向流抵消时，边界q发生改变。它的真实储能与原ν·V项改变write/active/conversion的ΔG和正反比；write实际付P写r，r改变原结合/解绑、导通和支持搬运，有限池再影响同一个域出生/回收及空间接合。随后体内状态改变，下一次N_B也改变。

这里的链条仍然是已有物料/储能/有限反应：**体内状态给出原生反向流 → 感觉与它在真实边界相遇 → 未平衡的荷量改变原事件亲和 → 痕迹/支持/空间改造 → 新的体内反向流**。推导没有把仪器NLL或外部probe的系数写回身体。

这解释应接在哪里，不保证已经有有用预测。只有当原生信号在新的实际感觉上具有可重复前瞻性、且原生学习改善这种关系，才能称它承担了预测角色；更完整的行动选择、语言后果和自我模型继续按主规划验收。

## 7. 下一实现要求

实现只读的原生端口构成接口，保留所有物理/RNG/历史；与直接中性制备副本的原事件/OU/精确回收率逐项核对，确认端口索引重排不改身份。对当前完整档作同状态、实际时钟的感觉匹配/一个物理荷量量子的偏离及sham，制备功热单列；不能用静态根成立声称4ms随机路径严格平衡。随后在真实流中记录该信号与之后的实际感觉，原生学习继续，外部观察器不回灌。
