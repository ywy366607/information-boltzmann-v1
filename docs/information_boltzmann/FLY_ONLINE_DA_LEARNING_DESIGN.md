## 0. 旧规则做到哪一步、为什么停用

`dan_plastic_lr`（规则名 `delayed-pulse-ema-terminal-coactivity-v1`，`fly_bptt_learning.py` 的 `_dan_update`）：

- **每个窗口只更新一次**：对所有“突触后神经元收到多巴胺”的突触，Δw = lr · dan_gate[post] · h[pre] · h[post]，用窗口末的膜电位乘积；

停用原因：COBA 改造后它的专用测试在灵活 tick 下挂起，被跳过，并注明“问题解决前不启动这一组”（提交 4dcc71e）；之后从未训练过，`dan_plastic_lr` 一直为 0。

## 2. 规则：多巴胺在突触前末梢写下的释放增益

果蝇蘑菇体的可塑性是**突触前**的、**不需要突触后活动**的：Kenyon 细胞活动 + 多巴胺 → Kenyon→MBON 突触释放改变（Hige 等 2015）；方向由先后顺序决定（Handler 等 2019：先 Kenyon 后多巴胺 → 压低，反之 → 增强）。
连接组里收到多巴胺的是神经元，所以按 `pre` 修正同样的近似：神经元 i 收到的多巴胺作用于 i 的全部输出末梢。规则（只对 39,850 个多巴胺靶神经元，其余神经元恒为 1）：

```
资格迹（突触前活动痕迹）  e_i ← λ_e · e_i + (1 − λ_e) · s_i          s_i = 本拍放电（0/1）
第三因子（末梢的阶段性多巴胺） p_i = (D_fast,i − D_slow,i) / (D_slow,i + D̄)   D̄ = 靶细胞平均慢浓度
释放增益记忆               φ_i ← φ_i + η · p_i · e_i
作用                       末梢输出脉冲 × g_i，g_i = exp(φ_max · tanh(φ_i / φ_max))
```

- `s_i`、`D_fast/slow` 都是已有的物理量；p_i 用有界的半饱和形式（纯“相对自身”的形式对只收到微量多巴胺的靶细胞发散，B 里遇到过）。
- **作用点**：放电经短时程可塑性得到“传出脉冲”（`transmitted_pulse = u·x/norm·spike`，环形缓冲里存的就是它）；g_i 乘在它上面，和短时程可塑性的释放概率是同一个生理量（突触前释放），不新增通路。
- **为什么只有突触前、没有突触后**：这是果蝇蘑菇体本来的规则；同时状态是每个神经元一个数（O(N)），而不是每条突触一个数（O(突触)）。
  代价：记的是“哪些末梢在多巴胺起伏时活跃过”，不是突触对突触的联想。若测到联想才是瓶颈，再升级为 Kenyon→MBON 子集上的每突触迹（第 6 节变体）。
- **方向**：p 有正有负（多巴胺高于 / 低于自身慢水平），η 的符号由学习决定，覆盖“压低 / 增强”两种。
- **界**：φ_max = ln 4，增益在 1/4–4 之间（与现有多巴胺可塑性缩放的夹取同一范围，不新增数）。
- **不加遗忘项**：p 的长期均值为 0，φ 是有界的随机游走；按初值估计饱和要约 6,000 个窗口（约 19 万词），超出本阶段。以 φ 的分布作健康指标；若测到饱和，再加“随使用而遗忘”。

## 3. 可学的量与初值（按 GDN 的教训：门不从 0 开始，但留在稳定区）

| 量 | 形式 | 初值 | 依据 |
|---|---|---|---|
| η | 每个大类一个标量 | 3 | 实测 p 的时间 sd ≈ 0.01、核心放电率 ≈ 0.13：每窗口 φ 变化约 0.02，可见但远离发散 |
| λ_e | 一个标量，exp(−1/τ_e) | τ_e = 50 拍 | 与多巴胺快浓度初值相同（同一配对窗口） |

初值 4 的阈值灵敏度曾让窗口内回传发散（多巴胺 → 核心 → 多巴胺的环）；增益同样作用于核心末梢，所以 η 从小处开始，tanh 界保证增益不爆。实现后先跑一个短窗口的梯度检查再训练。

## 4. 与 BPTT 并存

- **窗口内**：φ 和 e 的每拍更新都在计算图里（与其他物理状态一样，按词做检查点重算），BPTT 能看到“这一拍写下的增益如何影响后面的拍”。梯度因此流向 η、τ_e、**多巴胺细胞的输入突触**——第一次有理由让多巴胺变得有信息，从根上打破零起点死锁。
- **窗口之间**：φ、e 作为物理状态延续（永不重置，与膜电位一样在窗口边界截断梯度）。超出 32 词的学习就在这里：φ 一直在写，不需要回传。
- 慢权重仍由 BPTT + SGD 学习；现有的 `pre` 多巴胺学习率缩放保留不动（结构性的“陌生 → 学习率放大”通路因此保留，作为检验项）。

## 5. 每拍的代价

- 状态：φ、e 各 165,122 个 float = 1.3 MB；与已走过的拍数无关（O(1)）。
- 计算：每拍 4 个逐元素运算 + 一次乘在传出脉冲上，相对一拍的突触传递（2,500 万条突触）可忽略。
- 反向：每拍多存 2–3 个神经元长度的向量；按词检查点时只在重算一个词的拍时存在。

## 6. 变体（不先做）

- **每突触迹（真正的三因子）**：只在 Kenyon→MBON 6.1 万条上，e_ij = 突触前痕迹 × 突触后伪导数，额外 0.5 MB。在蘑菇体够得到输出之前没有意义（第 1 节）。
- **遗忘项**：只在测到 φ 饱和时加。

## 7. 开关与测试

- 默认关闭：`attach_online_da_plasticity(model)` / `--online-da-plasticity`；关闭时与现状逐位相同（测试）。
- O(1)：跑 100 拍与 1,000 拍，持久状态字节数相同（测试）。
- 因果不泄漏：本拍的目标词不进入 φ 的更新；把目标词换掉，φ 与读出逐位不变（测试）。
- 窗口内梯度：η、τ_e、多巴胺细胞输入突触得到有限非零梯度（测试）。
- 检查点：φ、e 存入物理状态，续训逐位延续（测试）。

## 8. 实验与训练前的预言

从 `dasite_pre`（`pre` 第一段）分出两支，同数据续训 8,192 词：对照（不开）与在线学习（开）。约 2 × 50 分钟。

评判（四支柱 + AG，不比单窗口 NLL）：
1. **在线学习的因果贡献**：固定慢权重，A（256 词）→ B（256 词）→ A 重访，φ 继续写 vs φ 冻结——重访节省之差就是 O(1) 学习本身的贡献，与 BPTT 的权重更新无关。
2. 训练中的主动评估：新上下文首次预测、A 重访节省、恢复。
3. 多巴胺是否开始随时间变化：靶细胞上阶段性的时间 sd（现在约 1%）、与惊奇 / 罕见度的相关。
4. 熟悉度 → 学习率通路（精度探针，ρ ≈ +0.2）是否保留。
5. 健康：φ 分布、放电率、稳定性。

预言：
- 起初几乎无变化（p 很平，φ 每窗口只动约 0.02）。
- **最可能出现的正结果是第 3 项**：梯度第一次有理由让多巴胺细胞携带信息，阶段性的时间波动与和惊奇的相关应上升。
- 第 1 项（超出窗口的重访节省）预计很小：φ 每个神经元一个数，记的是“近期哪些末梢在多巴胺起伏时活跃”，不是联想；256 词的 B 会覆盖一部分。若为零，原因与出路：容量 / 联想不足 → 第 6 节每突触迹；或多巴胺仍平 → 看第 3 项是否动了。
- 风险：多巴胺 → 核心末梢 → 多巴胺的环自我放大（同初值 4 的发散）；tanh 界与小 η 应能压住，训练前用短窗口梯度检查确认。

## 9. 实现中的修正（2026-10-11，实现后、训练前）

1. **只用 Kenyon 细胞的末梢（4,063 个），不是全部 39,850 个多巴胺靶细胞。** 用户指出：真实果蝇的蘑菇体本身是短闭环
   ——Kenyon→MBON 61,210 条、MBON→多巴胺细胞 2,862 条（反馈）、多巴胺→Kenyon 133,216 条与 →MBON 3,408 条（调制投射）、
   MBON→运动读出面 411 条（97 个 MBON 中 50 个一跳、全部两跳内到达运动面），外面还有“行为 → 世界 → 感觉”的大环。
   静默蘑菇体几乎无损失只说明这个个体从没用过它（BPTT 把一切都建在核心上），不是没有路——第 1 节的推理正是“系统不能拆开”的循环陷阱。
   把核心也纳入时，核心末梢增益 → 核心给多巴胺细胞 64% 的兴奋 → 多巴胺 → 核心末梢增益，加上不遗忘的积分，窗口内回传对任何 η > 0
   都发散（η = 0.3 / 1 / 3 全部非有限，η = 0 正常）。只用 Kenyon 末梢后稳定。
2. **η 取生物的符号：负（先活动后多巴胺 → 压低）。** 这让 Kenyon → 多巴胺细胞（Kenyon 给它们 25% 的驱动）→ Kenyon 成为负反馈（熟悉度）。
3. **加“随使用而遗忘”**（第 2 节预留的出路）：φ ← φ + e·(η·p − κ·φ)。原因：我按“p 每拍随机变号”估计 φ 只做 √t 的随机游走，
   实测 p 的符号能持续上百拍（快慢两个痕迹都平滑），φ 按 t 线性漂移，活跃的 Kenyon 细胞约 1,000 拍就到界（η = ±3 时 5 个窗口 φ 的 sd 到 3.9、最大 100）。
   遗忘只在末梢活跃时发生（被新经历覆盖，不依赖时钟），稳态 φ* = (η/κ)·p：该 Kenyon 细胞活跃时遇到的平均阶段性多巴胺——
   正是蘑菇体要存的“这个 Kenyon 模式对应多少多巴胺”的联结值，自然有界。初值 κ = 1/80（Kenyon 活动约 0.04 时记忆约 2,000 拍 ≈ 200 词，
   是窗口的 6 倍），η = −0.4（稳态 |φ| 约 0.3），都可学。
4. **短窗口检查**（`dasite_pre` 续 480 词）：15 个窗口梯度全部有限、梯度范数正常；φ 的 sd 0.04–0.06、最大 ≤ 1.16；阶段性 |p| ≈ 0.007–0.011。
   另外：多巴胺到达用浮点原子求和，记忆把它反馈进状态后，同一输入两次运行相差约 1e-6——泄漏测试改为在这个噪声量级内比较（换目标后差 2e-6，同目标 1.4e-6）。

**更新后的预言**（8,192 词 × 两支）：起初几乎无差别（蘑菇体对预测的贡献 ≈ 0，φ 的增益变化约 ±5%）；能否起作用取决于 BPTT 是否
加强 MBON → 运动面这条现成通路，以及多巴胺细胞是否开始携带罕见度（Kenyon 细胞已编码罕见度 R² 0.26，熟悉度正是这个负反馈环要算的东西）。
最可能的正结果仍是多巴胺随时间的波动与和惊奇 / 罕见度的相关上升；重访节省预计很小。

## 10. 换成果蝇原本的刹车（2026-10-11，用户提问后）

用户问：真实果蝇有递质的“容量 / 疲劳”，不会有无界自我加强吧？对照检查发现，第 9 节的增益乘在短时程可塑性**之后**的传出脉冲上，
等于绕过了囊泡耗竭——放大因此不受资源限制。两处都改用果蝇原本的机制：
1. **记忆改变末梢的基础释放概率**：u0_eff = sigmoid(logit(u0) + φ)（φ = 0 处逐位等于 u0）；剩余囊泡 x 照常消耗，放得越多耗得越快，
   输出自己封顶。这也是多巴胺在 Kenyon 末梢的实际作用方式（cAMP/PKA → 释放）。tanh 上界与“随使用而遗忘”都删掉。
2. **遗忘由持续的多巴胺驱动**（Berry 等 2012：学习后多巴胺神经元的持续活动侵蚀记忆；睡眠时它们安静，记忆保留更好）：
   φ ← φ + η·p·e − κ·(D_slow / 靶细胞平均 D_slow)·φ。Kenyon 细胞收到的紧张性多巴胺是靶细胞平均的约 5 倍（中位 5.0，最高 19），
   所以 κ 初值取 1e-4：中位 Kenyon 末梢的记忆约 2,000 拍（≈ 200 词，窗口的 6 倍）；按 1/2000 取则只有约 400 拍。η = −0.4 不变。
3. 其他已有的刹车保持原样：APL 全局反馈抑制（Kenyon→APL 4,693 条、APL→Kenyon 4,633 条）、ALIF。连接组里没有的（再摄取、D2 自受体、受体脱敏）不加。

**短窗口检查**（`dasite_pre` 续 640 词，20 个窗口）：梯度全部有限、范数 1.7–2.2；φ 的 sd 0.007 → 0.027 → 0.021（上升后趋平），最大 ≤ 0.65。
不需要任何人为上界就稳定。测试 29 个全部通过（η = 0 时与无规则逐位相同；释放概率只在 Kenyon 末梢变化、留在 [0, 1]；状态 O(1)；换目标不泄漏；梯度到达 η、τ_e、κ）。

**更新后的预言**：φ 在 logit 上约 ±0.02，释放概率只变几个百分点——起初两支几乎无差别；能否起作用取决于 BPTT 是否加强 MBON → 运动面、
多巴胺细胞是否开始携带罕见度（η 可学，若记忆有用它会变大）；最可能的正结果仍是多巴胺随时间的波动上升；重访节省预计很小。

## 11. 让蘑菇体像蘑菇体：Kenyon 细胞的轴-轴突触（2026-10-11）

**问题**：用户指出“多巴胺多处忘得快”不符合果蝇：学习与遗忘走不同受体（Dop1R1 / DAMB），遗忘来自少数特定多巴胺细胞学习后的持续活动（Berry 2012、2015），
新学习会覆盖旧记忆（Shuai 2010），各分区规则不同（Aso & Rubin 2016）——更像“多巴胺打开可塑性窗口”。而第 10 节的写法因紧张性多巴胺几乎是静态空间图，
实际是固定时钟衰减（中位 Kenyon 末梢约 2,000 拍，与内容无关，且 κ 是人设的）。
**更深的问题**：可塑性窗口要成立，Kenyon 细胞必须稀疏、由输入驱动。实测（`kc_recurrence.py`，`pre` 第一段）每个 Kenyon 细胞约 38 Hz，读与静默相同，
每个词 34% 的 Kenyon 细胞放电，随机两词的激活集合 Jaccard 0.63，82% 的兴奋来自其他 Kenyon 细胞（PN 只占 3.5%；PN 权重占比出生 24% → 学习后 15%）。
**突触位置**（neuPrint male-cns v1.0 roiInfo，服务器端汇总，共传输约 0.9 MB）：Kenyon→Kenyon 1,153,844 个突触中，叶 955,703（83%）、柄 82,866（7%）、
蘑菇体分区外 ~81,000（7%，多为 unspecified / INP）、花萼（Kenyon 树突）只有 33,915（2.9%，来自 30,817 对，存于 `data/malecns_v1/kc_kc_dendritic_synapses.feather`）。
点神经元模型把轴-轴突触当成了驱动胞体的输入。**零样本**：只保留花萼份额（权重的 3.9%）→ 每个 Kenyon 细胞 0.0018/拍，每词 1.8% 放电，常活跃 0.02%，
Jaccard 0.12，ΔNLL −0.002（全部去掉时 0.0015/拍、1.5%、0.12、+0.000～+0.003）。
**改动**：
1. `attach_kenyon_dendritic_only` / `--kc-dendritic-only`：Kenyon→Kenyon 兴奋权重按花萼份额缩放一次（只在首次开启时），无花萼突触的 612,115 条钉在 0
   （学习器 `clamp_edges` 每步保持，学习不能把轴-轴驱动长回来）。
2. 规则改为“多巴胺打开可塑性窗口”：w = (该末梢紧张性多巴胺 / 平均) · e；φ ← φ + w · (η·p − κ·φ)。末梢活跃且多巴胺到达时写入、可被覆盖；
