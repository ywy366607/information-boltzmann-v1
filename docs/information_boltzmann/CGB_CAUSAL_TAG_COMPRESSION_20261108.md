## 哪些区别可以丢：从未来后果定义

令A(u)是已声明身体/记录转移的一步线性化，m(o)是实际到达结果对状态的信用读出。过去参与方向e经过未来片段w时的信用是：

`credit(e,w,o) = m(o)·A(w)·e`。

定义N为**对所有已声明的未来延续与结果读出，都不产生区别的方向**。只在当前读不到还不够，因为它可能通过后层S、短卷积或记录，在未来重新起作用。

已证明：

- `silent_is_invariant`：N在这些未来转移下保持不可见。
- `silent_is_largest`：任何“转移下保持、结果永远读不到”的可丢弃线性子空间，都包含在N里。
- `reduced_step_exact`、`reduced_source_step_exact`、`reduced_read_exact`：商空间E/N具有相同的递推、实际参与源与信用读出。
- `exact_code_kernel_le_silent`：任何对**同一未来族**完全正确的线性编码，都不能比N多丢区别，即使它的解码器允许非线性。

这给出相对于所声明信用合同的最粗线性无损码。N不是“所有未来都已知”的在线实现；这个定义用于规定压缩应保留什么。实际GDN允许的未来族若很丰富，N可能很小；不能由这个存在性构造声称模型必然有一个很小的精确资格。

## 为什么必须同时保留归属

作用相同的两次参与，可能对应不同的参数。如果只把活动相加，两个方向还可能抵消成零，而各自仍需要相反的修正。

`ownership_cannot_be_replaced_by_total`给出严格反例：只读取两份参与之和，无法对所有情况恢复其中一份的责任。这是逻辑反例，不是合成能力实验。

因此资格的正确压缩对象是**参与到后果的联合映射**，不是一句话的字节，也不是若干活动向量的平均：

```text
E(p) = Σ_j U(j) · V(j,p)
U(j)：当前共享作用方向，覆盖与合同有关的native/记录自由度
V(j,p)：它对原参数或已登记局部方向p的归属
```

p取有限的实际参数坐标或局部方向描述，不能给每个历史事件永远新增一个p。若坚持保留全部逐事件身份，右因子也会随生命史增长。

后来真实结果m到达，信用一次收缩共享基，再分别分配：

`c(p) = Σ_j V(j,p) · m(U(j))`。

`factored_capture`证明这与原资格映射的结果相同。它没有将语言误差替换成无意义的食物分数，也没有增加内部词表头。大小五行上，水保留参与关系，金由真实结果来结算，修正仍回到原来的土、木与火。

## 一个共同生成律

原完整资格映射满足 `E_next = A·E + B`。新参与B可以有自己的有限因子“源方向＋归属”；源的秩必须从实际门控/投影算子得到，不能一概设为rank1。

本轮给出可执行的代数规则：

1. **输运：** `U ← A·U`。所有权V保留；不是重新存一段旧历史。见 `factor_transport`。
2. **吸收：** 若新源b可写成 `Σ_j a(j)U(j)`，直接 `V(j,p) ← V(j,p)+a(j)·owner(p)`。不增加槽位。见 `in_span_source_absorbed`。
3. **保留余量：** 对任意源，`r=b−Σ_j a(j)U(j)`。合并产生的丢失严格等于 `owner(p)·r`。见 `source_absorption_residual`。
4. **按未来信用合并：** 若r属于N，即使其状态范数不为零，仍可合并而不改变任何已声明未来信用。见 `silent_residual_merge_exact`。
5. **换基：** 若现有作用基可由较小的新基表示，必须同步变换V。`basis_recompression_exact`和`recompression_preserves_capture`证明所有权与结果都保持。

源输运与新源可先形成有限的K+L列临时工作区，再压回固定上限。`bounded_factor_step`证明精确压回的条件是合并后的作用能由该固定基表示。这个span条件要检查，不是Lean替实际GDN保证低秩。

运行时求系数和余量可以采用有界线性代数；本轮未选择QR/SVD实现，也未执行计算。使用任意独立PCA、SIGReg或latent相似度，不能自动代替上述因果条件。SIGReg可以维持表示不塌缩，但并未给出资格递推闭合与信用保持。

## 容量满了以后，怎样决定是否可靠

无法精确合并时，不能靠“余量很小”直接称正确。结果放大能力和归属系数也必须计入：

`|credit_full(p)−credit_compressed(p)| ≤ ||m|| · |owner(p)| · ||r||`。

`source_capture_error`直接针对上述吸收规则给出这条界。只控制U的范数、不控制右因子V的规模，仍可能放大误差。

对于原NLL边界，若**相同前向下**每个logit方向误差不超过ε，`nll_capture_error_bound`证明信用误差不超过2ε。若连前向概率也变了，还需另外计入概率变化，不能套这个界。

估计信用只有在超过误差预算时，其符号才有保证：

- `estimate > error`推出真实信用为正。
- `estimate < −error`推出真实信用为负。

误差范围内的结算应记录为未分清，而不是把噪声当正/负证据。本轮符号条件只认证所声明条件路径的信用，不保证Adam步或未来泛化必然改善；此前的下降余量合同继续适用。

`bounded_error_over_lifetime`复用已有误差递推定理，给出长期预算不随时间发散的充分条件：局部增益L与压缩缺陷δ须满足 `L·budget+δ≤budget`。若实际动力学没有这个闭合条件，局部小误差会累积；不能仅凭O(1)存储就宣称无限期可靠。

## 资源账本与当前范围

有限因子化的坐标量为 `K×d_effect + K×d_owner`，另加当前源、临时分解和误差统计。相对于生命史可固定，但不是免费：

- 作用基若仍覆盖全部native/记录坐标，其左因子成本还在；真正缩小左侧必须利用上述可丢弃子空间或误差合同。
- 对全模型所有参数保存稠密V，在1B模型上仍很贵；必须明确实际可塑隔室、所有权的稀疏/因子结构，并计入资源，不能把V藏掉。
- K=2是前轮起始方向预算，不是本轮证明出的普遍足够值。
- 如果native状态和所有保留记录都已失去某种必要区别，压缩无法补造它；当前构造规定哪些参与必须在当时留下可读区别。

本轮形成了一个明确方案：**在原学习侧维护固定预算的“共享作用基＋归属因子”，由实际参与生成，由同一递推输运，由后来结果捕获；只有在责任和误差条件允许时合并。** 不以复制完整历史求精确，也不把一条未知的压缩码当作机制已完成。

## 固定容量生成律：已经写成有限更新函数

[GDN局部源](CGB_GDN_LOCAL_SOURCE_FACTORS_20261108.md)已确定原第2/13层主前向的门控参与源。以下不再假定有一个未知的“好压缩器”，而是选择一个可以逐项核对的有限算法。

学习侧状态只有 `Code = (U,V,ρ)`：K个共享作用、K行原参数归属，以及一个覆盖已丢失作用的误差半径ρ。原参数集合P固定；本轮所选门控族为16400个坐标，不随经历新增身份。

### 一份新参与怎样插入

新源由作用b和归属owner给出。先用K次标量投影求系数与余量：

```text
a = 0; r = b
依次经过 j = 0,…,K−1:
    c = <U[j],r> / ||U[j]||²       # U[j]=0时取0
    a[j] += c
    r -= c·U[j]
W[j,p] = V[j,p] + a[j]·owner[p]
```

`projectSource`给出这次有限扫描；`project_source_split`证明始终有 `b=Σa(j)U(j)+r`。一遍扫描不要求U正交，因而不宣称已经求得整个span的最小二乘解。具体余量进入下一步的精确误差账；若采用QR改善投影，必须沿前轮已证规则同步换基V。

此时只有K+1个候选作用：原K列与余量r。比较丢掉其中一列造成的**所有参数统一误差上界**：

| 丢什么 | 代价 |
|---|---|
| 丢新余量r，保留原作用U | `max_p |owner(p)| × ||r||` |
| 丢旧第j列，改用r | `max_p |W(j,p)| × ||U(j)||` |

`chooseDrop`按固定顺序扫描，选择严格更低的代价，平局保持已有选择。`chosen_cost_minimal`证明它在这K+1个候选中代价最小，没有声称全局最优rank-K近似。

选定以后：

- 丢r：`U`不变，`V←W`。
- 丢旧第j列：`U[j]←r`，`V[j]←owner`，其余归属采用W。
- `ρ←ρ+选中代价`。

`insertCode`实现这一步。`insert_defect_identity`证明整个更新丢掉的作用恰好是 `owner(p)·r` 或 `W(j,p)·U(j)`，没有遗漏参数归属。`zero_cost_insert_exact`证明：出现零代价候选时插入无损；这包括空槽，以及投影余量确实为零的情形。

它不是FIFO，也不是按活动大小单独淘汰：一个向量很小但归属很大的作用，丢失代价仍可能很高。

### 一整拍的误差怎样累计

定义未压缩的所选参与参考 `F(p)`，它只用于证明，不在运行时保存。代码维持：

`对所有p，||F(p)−ΣU(j)V(j,p)|| ≤ ρ`。

共同转移A先作用于U。设有已认证的联合增益上界 `||A||≤L`、`L≥0`，则输运后的半径是Lρ。增益是输入证书，不需要在更新函数中展开完整Jacobian；如何由实际算子获得有效L仍要实例化。

当前有限个新源依次插入。其代价根据**当时更新后的U/V**重新计算，不是把同一份初始代价重复相加。`insertionBill`记录这些实际选择的总账，`insertion_bill_radius`给出精确递推：

```math
\rho_{t+1}=L_t\rho_t+\sum_i \mathrm{cost}_{t,i}.
```

`transport_error_certificate`、`insert_error_certificate`和`finite_step_certificate`把原转移、实际丢弃与误差证书接在同一个Code上。源列表是当前拍的临时输入，处理完即释放，不存成历史列表。

`finite_step_closed_budget`进一步证明：若当前半径不超过B，且本拍实际账满足 `L·B+bill≤B`，则更新后的半径仍不超过B。没有这个条件时，存储仍固定，但半径可能增长；代码保留这笔不确定性，不把丢失的信息重新称成已知。

### 反馈到达时，什么信用可以用

实际结果给出当前读出m。估计信用为 `ĉ(p)=m(ΣU(j)V(j,p))`，已证：

`|真实所选参与信用−ĉ(p)| ≤ ||m||ρ`。

`certifiedCredit`只在 `|ĉ(p)|>||m||ρ` 时接受它，否则本路长信用记0。`certified_credit_alignment`证明接受的符号与所选参与参考一致；`certified_selected_pairing`证明沿其反方向的小步具有非正的一阶配对。

这是**所登记参与源**的信用证书。其他直接参数源、有限步曲率、Adam和浮点误差继续进入实际更新的准入；没有把这条局部结论写成完整参数更新或长期能力改善。长信用未分清时，身体仍可摄入、预测和即时学习，不为误差账暂停生命流。

## 怎样只算窗口外，又不另存年龄队列

总资格连续携带所选主前向参与。结算时，扣除本窗口已经计算过的**同一参与源参考**：

`窗外估计 = 总资格估计 − 本窗口主前向参与信用`。

`matched_recent_subtraction`证明：减去相同窗内信用，不增加总资格原有的误差界。窗内标量可以从现有有界计算图中取得，按调用标签区分主前向与胶囊重算；不能拿所有参数的整窗梯度直接当这一项。

`mismatched_recent_subtraction`证明：若混入另一份权重日程、不同记录边界或不同源定义，就必须额外计入窗内错配误差。总账与当前图尚未做到同参考前，不接入相减。这处理的是学习账本，不清除身体S、短卷积或经历。
