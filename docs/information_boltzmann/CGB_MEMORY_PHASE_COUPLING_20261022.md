# 活动痕迹、支持捕获与空间转化为何是同一个过程

2026-10-22；由[域反应比](CGB_DOMAIN_RATE_DERIVATION_20261022.md)和现有native反应计量直接推导，不增加任何物理状态、学习分数或生物组件。

## 1. 把耦合写成原有有限事件

域出生的log正反比L包含：`log[B(B−1)P/(D+1)] + (B+F+H+P+D−2)log2 + Q²/(4C)`，加上既有端、形变、身份与形成能。下面均在B≥2/P>0/有自由端的可行条件下比较；若事件耗尽P，出生会直接退出可行反应集，不能继续对log0求差。

**支持结合。** 既有binding+把一单位F_j写入桥支持C_e：F_j减1，C_e增1，其他局部电荷/驱动/端不变。因此j处的L严格下降log2，正反比减半；支持仍在原有桥上，不随新域的资源分配获得额外一份。痕迹r通过共同结合能E_bound−χr改变结合/解绑率，再由这次实际组成改变空间转化，而不是给新域增加一个奖励。

这不是说正向出生率一定减半：其接受率为min(1,exp L)，饱和时可能不变，逆向概率则随对应反应比改变。当前参数下较大的理想混合熵项常使出生饱和、回收很小，必须与实际轨迹一起读，不能把比值直接称适应收益。

**支持向上游搬运。** 原transport+将桥C_e减1、上游H_i增1，同时P_i减1、D_i增1；不改变电荷。因而：

    ΔL_i = log[(P_i−1)(D_i+1)/(P_i(D_i+2))] + log2

有限驱动支出与运回的资源组成共同决定偏置；不是“收到支持就一定生长”。之后原release+将H_i变回F_i，两者总数不变，因此L_i在该声明的理想混合/等域本构下保持不变；释放仍会影响桥的可用支持及原反应。

**活动写入。** 原write+移动荷量z、消耗P并写r。父端i的变化为：

    ΔL_i = log[(P_i−1)(D_i+1)/(P_i(D_i+2))]
            + [(Q_i−z)²−Q_i²]/(4C_i)

另一端j的电荷项也相应改变。相同计量的active+不写r，因此立刻的出生比相同，但未来的捕获、导通和回收可行性不同。热r翻转不搬运P或荷量，立刻的出生比不变，仍改变原捕获/电导和受保护回收边界。区分这些路径，可避免把所有“r=1”都误当有用经历。

这些等式统一了Claude既有捕获、逆向支持、有限驱动与新增空间状态：原活动留下实际储能配置；配置改变原支持反应；资源搬运与支出改变同一自由能的空间转化；新结构再改变之后的电荷和活动。局部物理闭环已可逐事件追溯，预测贡献和世界中的有用性仍需持续学习验收。

## 2. 与当前状态的生成元相接

瞬时改变χ并支付ΔU时，r/C/q/P/拓扑保持原样，所以当前域反应比与可行集不变；原绑定/写入/搬运率则可改变。对当前可精确求的域回收率f，桥/池子生成元给出：

    L_native f(x) = Σ_e k_e(x) [f(x+ν_e) − f(x)]

它是后续回收条件被原学习过程怎样改变的局部因果响应，单位为参考ms的−2次方。出生接受率需空间积分，当前另外报告出生尝试上界的同类响应；不能把上界代入当作真实出生率。

实现使用共享不可变基因、完整复制物理/RNG的研究副本逐项枚举允许事件；没有外部目标梯度，计算结果不进入内环速率。该诊断只包含桥/池反应，不能冒充同时含OU、运动与相变的完整时间响应。当前父档的χ响应可能很弱或为零，照实保留，不扫描状态直到找到漂亮例子。

具体实现：`capture_phase_generator.py`与`material_fork.py`。源档的物理状态、随机数和历史保持不变；逐事件单元核对只检验这些计量与自由能等式，不作为人工能力研究。
