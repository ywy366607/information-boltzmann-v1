# 具体编码与完整候选审查

本轮把现有变化世界身体编入已有规则语言，并核验完整候选的缺项。三组结果是：具体规则表与进出账户、登记预算及世界丰富度的尺度限制、原中断协议下的失败路径。学习维持、来源搬运和再充能的已有正结果全部保留。

这次审查明确了下一步需要改变什么：当前单位置实例适合证明机制，完整候选还需要真实参与的空间结构、更丰富的世界接口，以及能够跨过短暂中断的恢复机制。

## 1. 从身体规则到现有解释器

`RenewableEncoding.book` 使用既有 `Description.ExchangeBook`，没有新增解释语言或免费查找表。登记数据包含：

| 数据 | 实际内容 |
|---|---|
| 身体位置 | 1 |
| 局部状态 | 8，包含空态 |
| 刺激字母 | 7，包含 calm |
| 接触、身份、边界 | 接触 `(0,0)`、身份页 `0`、边界位置 `0` |
| 含量表 | `[0,2,1,1,4,4,3,3]` |
| 初态及 calm | 状态编码 `1`、刺激编码 `0` |
| 守卫事件 | 7 个非空状态 × 6 个非 calm 刺激，共 42 条 |
| 每次发生的进出量 | 与 42 条事件逐一对应，随规则书保存 |

原来一个依赖当前状态和刺激的通道，现在编成互斥的守卫事件。对全部 56 个状态—刺激组合，`compiled_rows` 与 `compiled_rates` 核验：空态或 calm 无启用事件；其余恰有一个速率为 1 的事件；启用事件的更新和进出量与原规则相同。42 条中有 22 条保持身体状态不变，它们仍保留实际进出周转。

`accountable` 在原解释器上证明整本书的逐事件物料收支及闭合事件约束。这里完成了身体表格规则的编译及账户核验；全模型的时钟、世界、物料实现到完整编码候选的组合仍需分别提供证书。

数据直接从 Lean 定义导出为 `cgb_renewable_rulebook_20261024.json`，还单独列出原边界读出表 `[2,2,0,1,0,1,0,1]` 及字母标签。额外读出接口数据显式保留，不把它解释成已由规则书免费编码的通用规划器。

## 2. 状态空间、归档字节和基因预算分别计费

| 对象 | 本轮计数 | 所表示的内容 |
|---|---:|---|
| 身体当前状态 | 3 bit 固定宽度 | 8 种局部状态 |
| 原外部世界当前状态 | 4 bit 固定宽度 | 9 种环境状态，不包含整个转移规则 |
| 12 个物料身份的位置记录 | 24 bit 字段上界 | 每个身份用 2 bit 记录四种位置；合法配置是其子集 |
| 原联合状态及全部身份位置字段 | 31 bit 上界 | 3+4+24；不是规则书长度或最小实现长度 |
| 身体规则书与 transfers 的规范 JSON 数据 | 4079 byte | 无换行、UTF-8、键排序、紧凑分隔符 |
| 含标签和独立读出表的整个交付归档 | 4328 byte | 包含结尾换行的实际文件大小 |

后三种表示不能互相替代。3 bit 当前身体状态不等于3 bit 规则书；外部资源身份也不能自动算作12个身体接线位置。

`Good`、恢复分析量、路径、分布和 Lean 证明是审查对象，不是身体的额外运行输入。世界规则、资源初态及再充能端口独立登记。上一轮载体选择使用有限集合上的存在性选择；其具体可执行算法与全数据编码仍待提供，本轮没有用身体规则表代替这些实现成本。

登记预算仍按原 `Description.bits`，即固定 `Encodable` 自然数的二进制长度加封装位。上述 JSON 字节数是实际可读归档成本，**没有代入原 1% 分式**。本轮通过通用下界判定预算，无须展开整本书的完整自然数编码；没有声称测得该注册长度的精确数值。

## 3. 当前实例为何达不到登记的 1%

原参考约定为同一批带标签身体位置的有向稠密接线，分母长度是 `n*n`。任何规则书的 `Description.bits` 至少为 1，因此：

```text
1% 条件：100 × 规则书位数 ≤ n²
本实例：n=1，要求 100 × 至少1 ≤ 1，不能成立。
```

`small_reference_obstruction` 对任意 `ExchangeBook` 证明：只要 `n²<100`，该预算就不成立。`no_one_percent` 应用于当前具体书；`no_encoded_candidate` 进一步证明，无论选择哪个世界、可靠性参数或中断长度，都不能把这本单位置书作为登记的1%编码候选。

这是当前实例与参考约定的结论。研究方向是实际参与行动、学习与维持的空间结构及共享规则；本轮保留原参考和解释器，没有通过增加闲置位置或把外部资源身份计入身体来放大分母。

## 4. 世界丰富度的准确范围

原世界有9种状态，身体有8种全局状态。`world_richness_limit` 证明原目标中的

```text
κ × 身体状态数 ≤ 世界状态数
```

只能在 `κ≤1` 时成立。后续需要构造实际更丰富、仍保持可恢复条件的世界。这个状态空间倍率要求与“有限随机世界能否在无限时间产生持续信息流”是两个不同问题；本轮结论只针对已登记的倍率条件。

## 5. 原中断协议下的具体失败

完全沿用 `Medium.interrupt`：第四拍起，连续 T 拍把身体输入改成 calm；在这个具体身体中，calm 使身体事件冻结，而世界继续演化。T 为任意正整数。

一条实际支持路径是：

```text
search/probeA → search/answerA → aSpent/feedA
→ aReady/feedB → aReady/missB → aReady/probeB → aReady/trap
```

唯一的随机分支具有 1/2 概率，其余指定转移的概率均为 1。第四拍本应付费重开候选，中断使身体保留旧 A 动作。世界进入 B 探测窗口后，旧动作将其推入不可恢复状态。

`interrupted_trap_mass` 证明第六拍该状态质量至少为1/2；`interruption_failure` 由原实际未来评分推出第六拍存活评分至多为1/2。因此，`no_positive_interruption_tolerance` 证明这个实例在原协议下无法满足零失效参数 `δ=0` 的任何正长度中断耐受条件。

正常过程全时评分为1、原剪断持续差距至少1/4的结果仍然成立。新结论定位了这些正结果尚未覆盖的恢复条件；下一版先构造至少一拍中断可恢复的实例，再重验学习支付、来源收支、正常评分和原剪断差距。
