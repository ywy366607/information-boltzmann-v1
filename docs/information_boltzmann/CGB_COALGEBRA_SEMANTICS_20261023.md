# 从有限规则到无限交互：余代数语义与精化证书

接续 `851012b` 的有限描述和实际世界恢复。当前工作仍服务于从真实果蝇识别生成规则的主线；本轮建立规则与实现之间的行为证明接口，没有改物理规则或新增生命机制。

## 1. 在公理体系中的位置

沿用原五层：公理约束介质，扩张公理选择物性，机制由它们推出，算法实现机制，真实数据检验预言。余代数作为**过程语义与证明方法**连接机制和算法，不成为第七条物理公理，也不要求物理系统额外服从某个奖励函数。

完整链条是：

`有限规则书 → 已有身体—世界联合核 → 交互余代数 → 双模拟/精化 → 任意未来观察与摄入测试保持`。

这种数学语言适用于一般状态机，本身不区分生命和普通控制器。区别仍由既有资源交换、可塑结构、持续存在和操作闭合的性质给出，并需要相应见证。本轮未把“能写成余代数”当作生命成立的证据。

## 2. 一步展开到底包含什么

`Interaction.Machine S I O` 给出：

`step : I → S → O → S → ℝ`，且非负、对输出和下一状态联合求和为1。

这是有限状态/输出版本的 `S → (D(O×S))^I`。状态是当前完整物理状态，不是反传窗口；输入是登记的外部交互条件；输出是明确选择的可观察量。输入类型可以无限，证明对所有准入输入成立时才可以概括整个输入类。

`Policy = List O → I` 表示外部测试者只根据已见输出选择下一输入。有历史的外部测试者不是额外装进身体的无限记忆；规则书和内部状态的资源预算保持原义。

本轮没有调用一个未经构造的“最终余代数”或假定无限路径上的概率测度。我们使用所有有限观察柱集的概率来表述无界未来行为，并证明这些概率非负、空串概率为1、所有单步延长概率之和等于原前缀概率。这里的“所有有限”量词没有统一时域上限；检查几个有限样本不能代替它。

## 3. 双模拟：同一步必须保留输出与状态的相关性

`Coupling P Q R s t` 为两种表示的下一步提供共同分布，左右边际分别是原来的**输出—后继状态联合律**；所有正质量配对继续落在关系 R 中。

只分别匹配输出分布和状态分布太弱：相同边际仍可能隐藏不同的输出—状态相关，进而产生不同未来。本接口要求共同输出，并保留与后继状态的联合关系。

`Bisimulation P Q R` 要求每对相关状态、每种准入输入都满足这种一步条件。已证明：

- 任意在 R 上相同的继续观察值，其一步期望相同；
- 对任意因果输入策略、任意已有历史、任意未来有限输出串，其概率相同；
- 若找到一个概率不同的未来串，就能反证这个状态对应不是双模拟；
- 存在此类稳定关系可推出双模拟相似；所有此类关系的并仍满足一步条件。

因此，证明对象从“运行了多少步都没出错”变为“这个对应关系始终能继续”。本轮证明的是双模拟推出观察行为相同；未反过来声称一般概率系统中观察串等价必然推出双模拟。

## 4. 从实现状态到规则状态的精化

`Refines P Q f` 要求，对于任意输入、源状态、输出和目标后继状态，将 P 的后继按 f 汇总后，恰好等于 Q 的输出—后继联合律：

`Σ_(s': f(s')=t') P(i,s,o,s') = Q(i,f(s),o,t')`。

它不是“声明两个系统应该一样”。实现必须交出上述全称等式的证明，之后才能取得后续定理。f 可以重排、重新编码或在条件满足时合并状态；这不授权未经证明的池化、删连接或丢失资格/资源历史。

已证明这个条件生成双模拟，继而保留所有观察串概率、所有观察事件的首次发生概率。恒等表示满足它，两次已证明的精化可以复合。

`TimedRefinement` 另要求两边用原世界给定的同一个正时钟，才能作为物理实现证书。已证明相同步数的物理时间 `n/clock` 一致。单纯的步编号行为相同不会自动推出相同秒数；对照明确拒绝时钟1与2混用。

这里还没有一个自动发现最小商状态的算法，也没有证明当前 Python 生成核与 Lean 规则书之间已经存在精化证书。接下来的具体实现应使用这个接口逐项交付，而不重复长时间抽样冒充证明。

## 5. 实际恢复没有被换成另一种成功定义

`InteractionBridge.Machine.ofKernels` 将已有核的转移加上有限观察标签。已证明对标签求边际后精确得到原核，所以观察器不改变动力学。

`Medium.interactionCoalgebra` 包装原有身体—世界核和已登记感知协议。`Medium.intakeCoalgebra` 对正常、ghost剪断分支都直接复用上一轮核，以身体含量是否增加作为布尔观察。已有身体和世界的状态都保留，原更新顺序与时钟不变。

已证明：

- 输入策略按观察历史长度提供世界拍数时，余代数的首次事件概率等于原 `FirstHit.during`；
- 正常世界进一步等于原 `actualRecover`；
- 正常和剪断分支都与 `Operational.recovery` 对应；
- 对两个有完整精化证书且世界时钟一致的介质，实际恢复概率与物理时间都保持；
- 若还保留当前身体含量，则“身体非空且恢复概率至少为 p”的测试保持。

观察接口具有明确范围：只保留摄入标签的证书不能自动证明言语、行动时机、储能或结构成本也被保留。它们应进入共同的观察接口/状态对应义务。物料摄入与可用自由能的区别保持上一轮结论，世界端能量账本仍待推导。

## 6. 数学控制与反例

`InteractionControls.lean` 提供三类控制，均为证明接口的数学测试，不是训练能力研究：

1. **可合法去除的冗余状态。** 给任意机器添加一个完全不影响原转移、独立重采样的比特。证明忘掉该比特满足全称精化，所有未来行为保持。它验证多对一表示的正例，不说明任意原生细胞或状态都不重要。
2. **当前相同、未来不同。** 两个确定过程第一拍都输出 false；第二拍分别输出 true 和 false。证明第一拍观察相同，未来串概率分别为1和0，故初态不双模拟。单步样本相同不能作为忽略历史状态的理由。
3. **时钟不可混用。** 即使离散机器完全相同，也不能以不同时钟出具物理精化证书。

另有通用桥接定理，直接覆盖上一轮的正常/剪断实际恢复。没有借这些控制宣称已生成生命、出现自我或完成真实果蝇还原。
