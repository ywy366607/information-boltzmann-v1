# 可执行关系：Lean 准入与先预测后结算

在 `CGB_EXECUTABLE_RELATION_PROTOTYPE_20261109.md` 的离线原型上，增加一个研究侧有限运行接口：受限程序数据 → Python 校验 → 固定 Lean 模板检查指定输入的执行 → 有界关系库 → 先预测 → 收到结果后登记误差。每次仅一个待结算项，容量满时明确拒绝，不自动决定遗忘策略；不保存旧 autograd 图。接口尚无持久化，也未连接生产身体或模型生成。

定理依赖：`CGB.Description.code_roundtrip`、`bounded_books` 证明其各自编码语言的表示和有限数目，不能直接转述为本 Python 解释器的定理；`delayed_credit_requires_history_carrier` 表达特定假设下历史区分的必要性，不能保证本关系可归因；`reactivation_exact_held` 需要其具体可微与保持前提，本接口不声称满足。此轮无新增身体定理覆盖。

运行 `python -m scripts.ib_local.probe_causal_relation_runtime`：用之前研究者以 case 0、1 拟合的程序及 8 个输入做 Lean 样本执行检查，随后按次序对真实身体的 case 2 的 4 个有限移除收据预测、结算。留出 MAE 0.023107 nats，训练均值及零基线均 0.036373；一个正确线索方向预测错误。记录为 `results/cgb_causal_relation_runtime_20261109/report.json`。这只是对既存收据的离线回放，样本经研究者选取、数量很小；预测结果并未改变身体、动作或未来输入，不证明因果发现或信用改善。

Lean 核对的是给定程序在列出的输入上能执行且结果符合 Python 计算，使用 `Std` 和 `decide`；不是所有输入的解释器等价证明，更不证明经验规律或前提真实。候选是受限 JSON，不接收任意 Lean 源码；当前模板恰好要求两个整数输入。工具需启动本地 Lean 子进程，超时及候选长度、操作数均有限，但工具不是安全沙箱。

当前最早的未闭合处：身体还没有提出关系，也没有消费预测；关系库只记录误差，没有根据后果修改程序或影响后续预测。下一步需由现有身体输出候选数据，在持续状态中连接真实预测及后到结果，并配合禁读/错配检验。不能将这次离线重放称为闭环完成或语言能力收益。

## 身体读出候选接线

`LayerExperienceRecall.install_causal_relation` 接受 Lean 样本检查过的双输入程序，安装仅在事件边界进行；旧检查点默认关闭。此接口与上一节原型的输入语义不同：输入是实际读取权重的百万分数和该记录的年龄，而不是事后才能获得的梯度。程序输出解释为读取乘数的增量，裁剪到 [-1,1]，因此实际乘数是 [0,2]。这是待验证的具体候选，不是定理推出的唯一动力学。

实际损失到来后，`PretrainedExperienceLearner.step` 把每个参与读取乘数的负损失导数记录在同一层的关系状态中；程序建议和导数不是同一个量，不把二者之差当作预测误差。信息流已连到真实取回和局部误差，但程序没有学习或自我生成，当前反馈也没有修改程序：尚未完成“后果修正关系”。保存和恢复包含候选与统计，关闭时保留旧行为。ScalarCreditLearner 的专门标量实验路径不使用此经历读出，不能声称该入口已接入。

真实 340M 检查点研究副本以恒定 +0.25 程序做一个128词元的前向和 CE 导数检查，无优化器更新，也没有改变主个体。第2/13层各获得256个有效读取反馈；零程序相对原前向最大差0，候选冻结与求导前向最大差0。**更正**：此前 v2 用的 ScalarCreditLearner.predict 绕过经历表，其基线 0.535989 不可用于该比较。修正为两边均经过经历表后，原 CE 为 0.965808，候选 CE 为 1.157938。该人为程序仅用于接口干预，不用于生产。修正结果见 `results/cgb_causal_relation_body_20261110_v4/report.json`。目前 Lean 只证明有限样本的算术执行，不证明这些读权调制有益。

## 有界自修改首试

`probe_causal_relation_revision.py` 对同一研究副本连续两个128词元窗口进行测试：第一窗原样执行，实际 CE 给两层读取强度的局部导数；将导数方向用于选择提前经 Lean 检查的常数程序，第一窗提交一次、不重置递推态；第二窗在同一连续起点比较旧程序和新程序。第2层由0变+0.02，第13层由0变-0.02；第二窗 CE 从 2.007728 变为 1.985690（-0.022038），结果见 `results/cgb_causal_relation_revision_20261109_v3/report.json`。这是单一窗口的接线证据，不代表长期或跨窗口因果信用收益，也不是语言模型自行写程序。v2 比较用的 ScalarCreditLearner.predict 绕过经历表，零变化无效；v3 使用实际附着读取。

首次在 GPU 模型已加载后启动 Lean 失败；后来预先验证三种可能的程序后再载入模型。并行启动 Lean 测试和实机准入又出现30秒超时，应串行运行。当前修改只是固定模板的标量调节，非自主递归改进；关系的地址与内容如何产生、修改并对应跨窗口责任仍需后续实现。
