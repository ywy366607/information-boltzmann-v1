# MengLi 联合保证案例

状态：**需求覆盖与证据边界**。本文件回答“哪些生命要求已有何种证据、尚缺哪一种共同实现”；它不另立生命定义，也不把条件合同当作已训练的语言生命。

## 1. 主张层级

- **A0：定义成立。** 无限流生命体以 [原始定义与实现主链](CGB_AXIOMS_V0_20261022.md) 为准：L0 生存连续性贯穿 L1–L6。
- **A1：分散机制可证明。** 有限性、守恒、边界、选择、记忆、信用、局部学习、保持/释放与主动闭合已有大量 Lean 结果，具体条目见自动索引和关系图。
- **A2：条件联合合同可证明。** 部分机制可在同一抽象开放轨迹上共同陈述。
- **A3：共同动力学可实现。** 一个局部 `Φ` 同时实现这些机制。这是当前工程主张，尚未完成。
- **A4：MengLi 在连续语言世界生存。** 需 A3 的实现对拍及长期真实语言闭环检验，尚未完成。

A1/A2 是实质进展，但不自动推出 A3/A4。

## 3. 已验证资产的边界

- 物理记忆见证证明特定有限介质可在非冻结动态下保留实际写入的区别；它不是语言个体。
- GDN 精度同化、状态界、静默读写和局部字节评分桥证明特定语言递推路径可表达并可做接口对拍；它不是完整生命，也不是最终架构。
- `LanguageLifeAdmission` / `GenerationSelfProduction` 的联合结论说明给定条件可在同一开放轨迹兼容；其中世界响应、信号、学习机会等仍是条件。
- 优化器、果蝇和生态见证是共同规律的投影或参照，不得反向替代 MengLi 的联合实现。

## 4. 当前唯一总装任务

以关系图的 G1 最小依赖核审计一个候选共同递推。第一份共同状态接口已在 `GenerationColumnRefinement` 落地：先检验现有局部 `LocalMedium` 状态能否精化语言递推所需的读出、历史区别、边界结果和动作闭环。若不能，反例必须明确显示缺失的可区分自由度；只加入该自由度，并立即给出不变式、参考实现对拍和连续语言因果检验。

这使 Lean 与模型同步：Lean 限制什么能加入，模型暴露哪一条桥还没有足够状态。它避免等待“所有证明完成”后才造模型，也避免用未经共同精化的局部机制拼出一台表面完整的机器。

## 5. 结论纪律

当前可说：项目已建立 L0–L6 的规范目标、主生成逻辑和大量可复用的形式机制；现有联合合同明确了总装要求；语言只作为唯一信息摄入语义。

当前不可说：已从公理无条件生成完整 MengLi；已证明某个现有 GDN/飞脑/优化器满足定义；已在真实语言世界证明长期生存、主动性或 1B 低资源能力。
