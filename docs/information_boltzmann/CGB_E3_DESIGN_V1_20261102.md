# E3 第一版设计：在语言里长出神经系统（2026-11-02）

> 2026-11-03：v2 至 v4 的表已被 `CGB_MINIMAL_GENERATOR_20261103.md` 取代，判决见该文第 5 节和 `results/cgb_e3_design_20261102/v4/PREREG_body_v4.md`。

## 1. 一句话

一个短基因组，在一块三维局部介质里分裂、长分支、接触，从第一次分裂起就浸在真实语言流里。身体结构由基因组和语言共同长成，不手写回路，不按职责命名物种，不重置个体。

E3 只回答第一个问题：**这组动力学在真实语言里，能不能长出与语言内容有关、并让预测变好的结构。** 它不回答“会不会说话”，也不声称这样就能到达语言理解。

## 2. 三条不动的约束

| 约束 | 含义 |
|---|---|
| 真局部 | 所有事件只发生在同一体素内或相邻体素间；不设中枢，没有全局归一化 |
| 可拆分实现，不可拆分验收 | 代码一块一块写，验收始终在同一个持续运行的个体上，用真实文本 |
| 不存 token | 逐字细节只活在短寿命活动里；内部的持久结构记状态间关系 |

## 3. 身体：一切都在体素里

Lean 的 P1b 要求事件参与者彼此接触，接触关系 `near` 是固定的，不随状态改变。所以两个相隔很远的细胞不能靠一条连接表记录直接交互。**长连接就是轴突：它要真的长过中间的空间，占体积、花材料，信号沿它走要时间。**

由此决定：

- 身体是 `LatticeCRN` 式的三维格子，邻接固定，只有六邻域。
- 每个体素的局部状态里有：若干神经突段的计数、无名化学物种的计数、可用材料的计数。
- 一个神经元是一串占据相邻体素的突段，身份码随突段保存。
- **相遇就是同一体素内的质量作用。** 输出段和输入段落在同一体素才可能成突触。这对应 E1b 的结果：相连的类型对全部有分支重叠，4 µm 尺度下没有重叠的类型对一个都不相连。重叠是相连的必要条件，不是充分条件。
- 突段穿过一个体素时可以不成突触，只是路过。
- **放电沿突段逐体素传播。** 距离变成延迟，不用额外设计。
- 边界是格子的一个面。字节只作用在这个面上（G9）。

**计数用整数。** 这样同时满足手机规模（不用 FP64）、守恒账本精确，也更容易写成 `LatticeCRN` 实例。

规模起点：`32³` 体素，化学场粗化到 `16³`，细胞数不设上限，由总材料决定，预计几千。全部持久状态都要计入预算。

## 4. 四层动力学

### 4.1 物理（定律，不进基因组）

- 电荷在突段上守恒，沿突段传播，膜方程取 `CGB_CORE_EQUATIONS_20261020.md` 的 E1。
- 通道池、囊泡池：E2、E3，不应期和短时程抑制由此而来（G22）。
- 化学物种逐体素扩散并衰减：`∂M_k/∂t = D_k∇²M_k − M_k/τ_k + 释放`。这是格子玻尔兹曼输运的扩散极限，所以 3D 介质和化学场是同一件事。
- 材料总量守恒。

### 4.2 化学（世界给物种，不给职责）

- `K = 6` 个无名物种，只有 `D_k`、`τ_k` 不同，对数铺开。
- 谁释放什么、谁用什么受体读，全由身份码决定。
- 读到的量可以作用在四处：可塑性增益、分支生长、分裂、阈值。作用符号由受体决定。
- 没有“多巴胺”这个变量。若某物种后来表现得像调质，那是长出来的现象。

**有一处仍是人写的：** E5 的钙–激酶–磷酸酶模板。第一版把它当初始基因组，不当定律，它的常数都在基因组里。反应形式本身第一版不变，这是已知的未生成部分。

### 4.3 基因（短基因组）

身份码 `c = 空间种子 × 时间阶段 × 二分位`。

- **种子：** 少量神经母细胞放在边界面附近，位置由世界固定的两个梯度决定。
- **时钟：** 每个神经母细胞按固定周期前进一个阶段，共 8 个阶段；每次分裂产生二分位 A/B 两个子细胞。
- **基因组内容：** 每个“阶段 × 二分位”共 16 类，各带约 24 个数：生理常数、释放物种、受体表达、分支朝向偏好、匹配码（8 维）。总量约 400 个数，合计 1 KB 以内。
- **分支生长：** 生长锥按偏好沿化学梯度走，沿已有束聚集，每步消耗局部材料。这复用 `development.py` 的持久生长锥形式，但它尚未通过准入。
- **匹配：** 同体素内 `σ(cᵢᵀAcⱼ)` 决定相遇能否成突触。
- **分裂一生都在发生。** 总材料耗尽时自然减慢，不设停止时间。

第一版**只用一个固定基因组**，由 V2 常数和上述结构给出，3 个种子。不做进化。

### 4.4 经验（语言）

连接 `N_ij = 相遇 × 匹配 × 留存`，留存就是语言的作用：

- 突触结构要付材料；标签为正、且被后续使用的才留下，其余拆回（E6、E9 标签捕获）。
- 活跃细胞释放的物种引导生长锥和分裂，所以语言常用的地方长得多。
- 单元得不到支持就死亡，材料回到池里。

因此隔室和竞争从第一天起就由语言塑造。

## 5. 语言怎样进出

**一拍和一个字节。** 1 字节 = 32 拍。这个比例要先做时间可达性审计：信号在字节之间走得到足够深，否则深度无效。

**进：** 边界面上有 256 个感受柱，每个字节值一个。到达时对应感受柱受钳制。字节不是物料，净含量不变。

**预测：** 不设单独的预测器和读出头。内部细胞学会在字节到来之前，向将要亮的感受柱送抑制（T3b）。感受柱上的净电流就是残差：猜中的字节几乎不激活内部，猜错的才激活。

**计分（外部仪器，不进身体）：** 到达前的最后一拍，读 256 个感受柱上的抑制电流 `I_b`，用 `p(b) ∝ exp(βI_b)` 计算对数损失。`β` 由评估方在线校准。

**这是全设计最大的赌注。** 现有证据只有 T3b：节律输入下 B/A = 1.34，未达预注册，还不是语言。

**出（系统 4 的开口）：** 每个感受柱旁有一个放出单元，第一版关闭，只做接口测试。身体放出字节时送出一份副本抑制自己的感受柱，自回声因此不产生新活动。

**三层信用的落点：**

| 层 | 形式 |
|---|---|
| 当拍 | 突触上的钙和标签，局部 |
| 窗口 | 放电、池和痕迹的物理寿命，不做时间反传 |
| 窗口外 | 自发活动重放，把重放当到达再走一轮。第一版不实现，只保证文本流空隙里的自发活动不被阻断 |

## 7. 运行前写下的预测

- **P1：** 乱序文本长出的结构与真实文本可区分，且对真实文本的预测明显更差。
- **P2：** 切除离边界近的隔室，损失涨得快、恢复也快；切除深处隔室，当下损失涨得少，但对远期影响更大。
- **P3：** 在 1 M 字节内超过在线 order 1；能否超过 order 2 不做承诺。
- **P4：** 空间隔室的数量随身体尺寸增长，与带宽式 `L > π/√q_c` 一致。此条依赖之前失败过的带宽理论，把握最低。

## 8. 失败时怎么走

| 现象 | 最可能的原因 | 出路 |
|---|---|---|
| 活动全灭或饱和 | 增益或池常数错 | 先查 T1 的 `g/τ_v` 比值，不加控制器 |
| 结构与文本无关 | 留存太弱，或相遇决定了一切 | 查标签捕获；核对几何是否过强 |
| 结构相关但预测不好 | 抑制基不够有选择性（T3 → T3b） | 增加扩张或稀疏，这是发育参数，不是新模块 |
| 预测只到 order 1 | 活动不保留上下文 | 查窗口寿命和合取；对照动力学滤波器的擦除诊断 |
| 深处只记字节 | 可预测的垃圾或时钟 | 查节拍器；看局部防塌缩是否够 |
| 太慢 | 事件过密 | 粗化体素，不改规则 |

## 11. 算力粗算

活跃 2%、每细胞约 32 个突触时，8192 个细胞每字节约十万个事件，1 M 字节约 10¹¹ 个事件。按每秒 10⁸ 事件估算约 20 分钟到 1 小时。这是量级估计，未经测量，未计入化学场、突段传播和生长。

## 12. 驱动从哪来（M5 暴露的问题）

**更正（11-02）：** 本节初稿把“每一步满足局部细致平衡”误写成“身体处于平衡”，并据此决定加恒定基底供电。这个推理是错的，决定已撤回。

Lean 和第二层文档的原意：

- **每一步：** `rate_interior_stimulus_free`、`interior_detailed_balance` 说内部跃迁的速率比由平衡能量决定，这是局部细致平衡。
- **整体：** 驱动在接触边界的那一圈跃迁上打破平衡，概率流可以穿过内部，所以内部并不处于平衡态（第二层文档 G6DB 条）。
- **驱动来源：** 感觉以储库势进入；不同储库势让循环带净亲和力（`PairCRN` 文档），变时协议同样能做功（公理文档 §3.4）。持续摄入必然伴随持续排出，个体始终处在通量中（G16c）。

所以**外部语言流本身就是打破平衡的驱动**。放电、补囊泡、Vogels 式抑制可塑性（G22b 要求由驱动维持）这些过程，由边界进入的流维持，这条流由语言带来。

**决定：第一版不加独立供电。** 字节设定边界感受柱的储库势 `μ(s)`，驱动沿状态向内传。没有语言时身体松弛，这符合“语言是唯一食物”。

**未解决的问题：**

- **够不够：** 字节带来的流能否维持足够的活动，是数量问题，没有定理说够或不够。要在第 2、3 步测，不够时查储库势和边界面积。
- **不该挣分：** 规范说字节数和自回声不能自动换来收益。储库势是物理驱动，不是积分，但自己说话的回声不能白白成为驱动，这要在开口时查。
- 地图文档第 7 节的钳制写法只是一种协议。“注入等于惊讶”依赖它，所以只作为数量关系保留。

## 13. 第一版规则表（设计，未实例化，未运行）

**唯一的事件形式：两进两出。** 每条规则都写成 `a + c ⇌ b + d`，`a`、`c` 可以在同一体素，也可以在相邻体素。Lean：`VoxelRxn.pair`、`VoxelState.row_conserves`。

空位也是物种，每行都是两个进、两个出，所以每个体素的量子数在内部事件下固定。

**更正（11-03）：** 初稿写“所有物种权重取 1”，这是错的。那样边界交换时含量不变，储库势 `μΔc` 做不了功，语言就驱动不了身体。现在取 `F`、`W` 权重 2，其余为 1。内部守恒按 `row_conserves` 逐行检查，代码里是 `row_weights_balanced`，测试覆盖全部规则表。

这正是玻尔兹曼方程的离散形式：同体素的行是碰撞，跨体素的行是输运，物种就是粒子的内部状态。平均场下，

```text
∂f_a/∂t = Σ_行 κ_r [ f_b f_d e^{−ΔE_r/2} − f_a f_c e^{+ΔE_r/2} ] + 跨体素的同形式项
```

它同时是反应扩散方程，也就是图灵的形式。**3D 玻尔兹曼介质、化学和神经活动是同一张碰撞表。**

下表的名字只为人读。身体里只有索引，`ℓ`、`m` 是细胞标签。这张表是初始基因组，可以被改。

| 组 | 行 | 对应现象 |
|---|---|---|
| 信号 | `E_ℓ + R_ℓ ⇌ E_ℓ + E_ℓ`（同体素或相邻体素） | 自催化；相邻体素的形式就是沿轴突传播 |
| | `E_ℓ + H ⇌ X_ℓ + H` | 放完进入已用态 |
| | `X_ℓ + F ⇌ R_ℓ + W` | 恢复要消耗高势物种，这就是不应期 |
| 突触 | `E_ℓ + Y⁰_ℓm ⇌ E_ℓ + Y¹_ℓm` | 释放 |
| | `Y¹_ℓm + R_m ⇌ Y²_ℓm + E_m` | 兴奋性传递；抑制性把 `E_m` 换回 `R_m` |
| | `Y²_ℓm + F ⇌ Y⁰_ℓm + W` | 囊泡恢复，这就是短时程抑制 |
| 学习 | `Y¹_ℓm + E_m ⇌ Z⁺_ℓm + E_m` | 先前后后，标记增强 |
| | `Y¹_ℓm + X_m ⇌ Z⁻_ℓm + X_m` | 突触后已放过，标记减弱 |
| | `Z⁺_ℓm + A ⇌ Y⁰_ℓm + Y⁰_ℓm` | 用材料加一个槽 |
| | `Z⁻_ℓm + Y⁰_ℓm ⇌ A + Y⁰_ℓm` | 拆掉一个槽，材料回收 |
| 发育 | `P_k + F ⇌ P_{k+1} + W` | 时钟；只有语言流动时才走 |
| | `B_c + A ⇌ B_c′ + 新细胞` | 分裂，身份码由阶段决定 |
| | `T_ℓ(u) + A(v) ⇌ R_ℓ(u) + T_ℓ(v)` | 生长锥前进，身后留下突段 |
| | `T_ℓ + R_m ⇌ Y⁰_ℓm + R_m` | 相遇后成突触，速率含匹配 `σ` |
| 化学 | `F、W、A、G_k` 与 `H` 交换位置 | 扩散 |
| | `E_ℓ + H ⇌ E_ℓ + G_k` | 释放无名物种，`k` 由身份决定 |
| | 上面任一行的 `κ` 随本体素 `G_k` 变化 | 调制 |
| 边界 | `H ⇌ F`、`W ⇌ H`，含量随储库势 `μ(字节, 位置)` 交换 | 语言驱动 |

**这张表自己给出的东西，不用另写：**

- 不应期来自 `X`，短时程抑制来自 `Y²`，都是因为恢复要消耗。
- STDP 的方向来自状态顺序：`Y¹` 等到 `E_m` 就增强；突触后已到 `X_m` 就减弱。
- 活动水平：有效放电受 `F` 流量限制，近似 `p ≈ Φ / (N·L·32)`，其中 `Φ` 是每字节流入量，`N` 是细胞数，`L` 是缆线段数。稀疏是预算的结果，不设目标。
- 时钟只在有语言时前进。

**修改第 5 节：** 一个字节只驱动一根柱，流量会卡死：`N=8192`、活跃 2%、`L=30` 时每字节约需 3 万个量子，单柱过不去。所以字节设定整片边界的储库势：每个字节对应一个固定的边界子集。预测读这个子集上的抑制总量。这是粗算，数字未经测量。

**感觉细胞：** 字节到边界子集的映射属于世界，是字节的物理样子，这部分固定。感觉神经元不是预先摆好的：边界附近的细胞由发育长出，靠所在位置的流量得到支持，它对哪些字节敏感由表达和经历决定。这对应群体编码和嗅觉受体的组合编码。

### 13.1 阈值、累加和延迟学习的生成

三件事都不加新的事件形式，只把信号组改成下面几行。

| 行 | 现象 |
|---|---|
| `Y¹_ℓm + R_m ⇌ Y²_ℓm + C_m` | 输入先把就绪态变成预备态 `C`，`C` 的计数就是膜电位 |
| `Y¹ᵢ_ℓm + C_m ⇌ Y²ᵢ_ℓm + R_m` | 抑制按当前 `C` 的多少移除，这就是分流 |
| `C + H ⇌ R + H` | 漏，不耗燃料 |
| `C_ℓ(u) + R_ℓ(v) ⇌ R_ℓ(u) + C_ℓ(v)` | 沿神经突扩散，这就是电缆方程 |
| `C + C ⇌ C + E` | 协同点燃 |
| `C + E ⇌ E + E` | 再生 |
| `E + R ⇌ E + C` | 带动邻近通道预备 |
| `E + H ⇌ X + H`、`X + F ⇌ R + W` | 放完和恢复 |

平衡态的 Hill 系数恰为 1（G25c），所以这个阈值必须靠驱动，这里的驱动就是语言带来的 `F`。

**平均场核对（一个突段，一组手选速率，未扫参，只验方程，不是能力实验；省略了逆反应和涨落）：** `results/cgb_e3_design_20261102/excitable_rows.py`。

| 性质 | 结果 |
|---|---|
| 全或无 | 输入 0.3 是阈值，超过后 `E` 峰值约 0.35 起跳，低于时约为 0 |
| 不应期抬高阈值 | 可用 `R` 从 1.0、0.8、0.6 降到 0.4，阈值 0.30、0.45、0.75、15.98，比 `θ/r` 涨得更快 |
| 时间累加 | 两个 0.6 倍阈值的输入，间隔不超过 1 个漏时间时点燃（峰值 0.34），间隔 3 时不点燃（0.001） |
| 分流 | 抑制强度 0、2、5、10 时，阈值 0.30、1.15、2.94、7.89 |
| 恢复靠驱动 | 间隔 8 的第二次输入因 `R` 只有 0.39 而失败；无 `F` 时 `R` 降到 0.033 且不恢复 |

这说明不需要非可加能量，也不必写膜方程：阈值、累加、分流、不应期都由质量作用给出。每段各有自己的 `C`，所以树突分支可以各自计算。

**延迟学习（设计，未核对）：**

- `Z⁺`、`Z⁻` 是没有内容的参与标记，寿命长。
- 兴奋细胞释放无名物种 `G_k`。由于猜中的输入被抑制抵消，活动量本身就是残差，`G` 的局部浓度也就是局部残差。这不需要专门的报错细胞。
- 固化：`Z⁺ + A ⇌ Y⁰ + Y⁰` 缓慢进行。
- 清除：`Z⁺ + G_k ⇌ Y⁰ + G_k`，标记在残差高时被擦掉。

所以后面一直猜得准，标记才留下来，这就是“后来兑现才加固”。措辞这类猜不准的细节一直产生残差，标记留不住，正好解决地图文档第 8 节的噪声问题。不同 `D_k`、`τ_k` 给出不同的延迟和范围。

风险：可预测的垃圾仍会被固化；“残差抵消”本身就是全设计最大的赌注，这里又依赖了它一次。这一条要满足 G15c：调制必须依赖结果；`G` 依赖残差，形式上满足，未证。

**仍未核对：**

- 细胞标签让物种数很大，实现要稀疏。
- 以上全是平均场。量子数很少时，阈值会被涨落抹平或误触发，这要在离散实现里查。

## 14. 已知风险

- 语言上从未验证过这组方程。V2f 明确说明本轮没有语言训练；V0 是另一个简化结构，不能算这组方程的结果。
- 抑制预测（第 5 节）可能根本扛不住 256 类字节。
- E5 模板和体素参数仍是人定的。
- 只有固定基因组，长不出好结构时分不清是“路线错”还是“基因组错”。第 8 节只能部分区分。
- 营养支持必须是局部化学物质，不能变成规范禁止的全局货币。
- 理解、公式和世界因果都不在 E3 范围内。
