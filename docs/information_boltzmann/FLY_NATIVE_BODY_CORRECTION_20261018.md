# 原生闭环要求与代理反馈撤回

用户要求原生机制承担闭环。上一轮的单维执行器以及更早的下行平均反馈都不满足，
其“身体接通”验收撤回；历史数据、代码与完整个体状态保留。

## 已落实的纠正

- 正常运行默认不执行两种代理反馈，不能从旧配置自动继承开启。
- 原来的下行、VNC、运动、上行及感觉细胞和 CNS 突触保持原状。
- 旧身体参数、物理字段及优化器状态保留，避免恢复时丢状态或重新出生。
- 代理参数的旧政策导数单独封存；其他参数的资格迹、待结算回复和时钟保留。
- 只有明确指定的冻结历史复核可以运行旧代理方程。复核报告必须标为历史代理，
  原生因果矩阵不再把该分支命名为 body_interface。
- `native_body_route_20261018/last.pt` 是仅撤下代理的完整迁移副本，仍在 32804，
  新暴露为零；不把它称为已完成原生身体的候选。

## 真正的闭环接线要求

原生脑内状态 → 具体运动/传出神经元 → 实际效应器 → 世界真实改变 →
相应感受器 → 原生感觉/VNC/上行通路 → 神经调质和可塑性 → 后续选择。

在语言世界，嘴是新外设，果蝇没有天然的 token→肌肉生物映射。
可以学习这个外设的编码映射，但不能把成功/发声标签变成“本体感觉”，
也不能用复制一个神经活动平均值来伪造身体返回。
原生运动、感觉和学习回路要保留各自身份、拓扑、持续状态和实际因果作用。

纠正时的语言/时机头从混合输出面读取，包含下行、运动和内分泌等类别。
因此即使剔除了代理反馈，**原生运动末端对语言执行的唯一接管，以及真实外设返回，仍未完成**。
下一项实现应聚焦这个执行端点及真实外设契约；验收须匹配真实时钟、同状态和 RNG，
区分神经输出、实际提交、外界回复、自听及感官返回。
没有外设接线证据时明确标缺，不能通过加高维状态、扩大增益或更换变量名称替代它。

后续实现已推进到逐细胞运动末端接管语言外设，见
`FLY_NATIVE_MOTOR_PORT_20261018.md`。这更新了语言执行入口的状态；
真实肌肉/受体、本体感觉和身体交换仍未实现。

## 生物依据与边界

原生本体感觉—运动的互动不是“先判定说话，再广播一个标量”。
Gorko 等的头部运动实验支持连续的本体感觉—运动回路参与决定运动后果：
[Nature 2024](https://www.nature.com/articles/s41586-024-07222-5)。
具体细胞/效应器配对仍要以来源数据为依据，不能从群体名称推导。
