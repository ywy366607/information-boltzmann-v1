# 从现有身体生成二元概率读出：v4t

## 转移与问题

沿用v4s身体、字节快表、经历库、见证池及所有学习节律。在说话前，已有F同时读取当前状态和候选话语的内言状态，预测四项后果。本版只把其中“话尾有没有被接上”的分量变成伯努利概率，其余NLL4、NLL32和连续10g含义不变。

动作均值的接话分量截到[0,1]；F原接话分量作为对数赔率修正，`p = sigmoid(logit(base) + correction)`。仅在logit端点使用机器精度保护。保留现有基于过去平方误差的混合权重w，用`base+w*(p-base)`形成实际进入决策的概率。w不是p，也不是概率分布自动给出的“可信度”；二者分别记录。当前F和编码器沿已有平方误差梯度学习，接话这一项恰是Brier损失。不新增神经参数或单独教师。

水保留的二元结果继续回放。合并的平均标签只在同一预测p下保留Brier的参数相关项；特征和动作状态近似合并仍有误差，不声称精确还原历史因果。木的概率经原有决策链影响火，世界实际匹配结果回到同一身体，再更新F、历史误差和水中的结果。世界匹配是本世界观察接口，不代表通用语义理解或“有益”。大金仍结算原来的语言进展，Brier只用于木的预测正确性。

## 现有Lean到身体

复用`GenerationUnifiedOptimizer.lean`：

| 已有声明 | 兑现条件与本版代码 |
|---|---|
| `bernoulli_expected_brier_gap` | 给定真实条件概率q，期望分数的差为(p−q)²；`_compose_prediction`形成p，继承的`_outcome_loss`计算平方误差 |
| `bernoulli_expected_brier_calibrated` | q使期望分数最优；是训练目标性质，不是训练结果已校准 |
| `bernoulli_prediction_error_expectation` | 结果先于更新，y−p在固定q下均值为q−p；实际先决策、后世界回应，再记录误差 |
| `brier_score_is_not_outcome_prediction_error` | 实际记录负Brier和y−p两个量，均不冒充大金的g |
| `calibrated_evidence_penalty_is_square` | 与首条同一评分族的差值表达；不新增一种机制 |

`reviews/typed_wood_admission_20261105.lean`另核对概率边界、凸混合、负Brier恒等式和合并标签条件。数值测试核对梯度、范围和继承的其他通道不变。完整覆盖账本继续用`audit_latent_body_coverage.py`生成，新增v4t列，不把旧v2审计自动继承成v4t覆盖。当前全库1807条，跨版本已审阅22条；本版新增5条局部声明，属于同一个评分族。v4t其他1802条未逐条审计；这个数不表示它只具有5条性质。

## 运行前约定

从完整v4s第256轮末快照续接：权重、两种记忆、快表、优化器、见证池、世界和随机状态、待结算信用全部保留，概率链接改变是本次干预。旧误差统计需要继续适应新链接，前128轮不作为主要比较区段。

先做2轮真实文本接线检查及保存/恢复检查；概率、梯度和对动作分布的作用成立后，再单seed连续256轮OWT接话世界，外界字节245760。每64轮在相同32768字节验证，保存末状态。预算固定，不追加种子、不调参、不访问妈妈世界。

末128轮记录：当前动作的模型概率、实际使用概率、基线概率，实际结果、Brier、对数损失、按动作和10个固定等宽诊断分箱的预测均值/发生频率。分箱仅用于报告，不生成标签、不用于训练。每箱样本量也报出；不凭少量样本或总体Brier宣称已校准。

实现验收：概率范围/归一化、非零梯度、因果重放、对应通道的决策TV和完整状态恢复。效用验收：实际概率的末段Brier是否胜过动作基线，独立语言NLL是否恶化超过.01；否则记录未获支持，停止扩量。实际选择的数据只能评估被选动作的预测，不能当作所有候选的反事实校准。无论成败都更新同一覆盖账本和实际运行证据。

连续收益仍保留真实值；本轮不实现其分布尺度，不分位数分档。它的噪声和未来兑现仍是独立未完成条件。

实现：`language_navigation_kanli_v4t.py`，入口`run_representative_witness_20261105.py --typed`；结果`results/cgb_navigation_typed_wood_20261105/`。旧v4s运行保留原源码哈希；runner扩展命令行不改变其默认模式的算法。
