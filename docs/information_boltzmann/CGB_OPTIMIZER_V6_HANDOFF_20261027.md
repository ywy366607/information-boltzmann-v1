### 三个需要分开的问题

1. **信息问题**：为区分会影响未来行动的历史，身体至少要保存什么？既有 `history_readout_exists_iff` / `history_transition_exists_iff` 提供读出与递推闭合的约束，尚不指定高斯统计或逐参数方差。
2. **控制问题**：在已声明的世界变化和误差代价下，何时改写、何时保留，什么代价可接受？噪声与持久变化之间的区别有可识别性限制；年龄、曲率和阈值是可能的证据，必须明确其来源。
3. **实现问题**：同一项有效改写怎样在本拍时间、完整状态和通信预算内执行？低资源要求从这里约束可行集合，不能在实现完高成本滤波器后再考虑压缩。

现有路线把这三者压成了“准确估计每个梯度 → 最优步长 → 生物可塑性”。这一步缺少跨时间信用、功能保留与完整成本的桥梁。

### 整步保证不能由组件保证拼出来

新增确定性代数审查：取梯度 `(1,1)`、真实对角曲率 `(1,1000)`、ρ=10。当前 tanh 形式产生提议约 `(0.99668,0.001)`，二次目标下降约 **0.50049**。在两行一列、可用储库相等的预算特例中，平方更新被平均为相同步幅约 `(0.70476,0.70476)`，同一目标的下降变成 **−247.18180**。

这里核对的是代码预算公式在理想等额条件下的代数特例，未声称原实验实际到达了这个状态。它已足够否定“标量步稳定，因此分配后的整步稳定”的推理。最终硬截断也不能消除此例，因为两个分量都远小于ρ。下一次稳定性证明必须覆盖实际执行的分配后更新；不能仅在 `_bound` 上加更强定理。成本与功能约束应进入同一个决策问题，再推导更新，不能在已推导的下降步之后另接一个不受该证明约束的重分配。

### 保持与适应存在信息上的共同边界

若一个短冲击与一次持久改变在前 L 拍的可见记录完全相同，同一初态的因果学习者在这 L 拍得到相同状态分布。假设两世界希望的输出分别为0和δ，对任一共同输出 a：

`(a² + (a−δ)²)/2 = (a−δ/2)² + δ²/4 ≥ δ²/4`。

对随机输出取期望仍成立，至少一个世界的期望平方误差不小于δ²/4。这是纸面可识别性下界，可由既有历史分离合同理解，无需再造生产模块。世界提供了不同的额外线索时前提不再成立，应把这些线索计入可读历史。

因此“任意短冲击都无伤，同时任意永久变化立即接纳”不能作为普遍验收目标。应声明变化类、可读证据、误保留与误改写的代价，再推导可达的响应/保持权衡。固定延迟、年龄风险、混合状态各属于需要论证的实现选择。锁存是否有益须由其对未来预测/行动的因果贡献判定，存在很久本身不是价值证据。

### 完整成本与计数审查

当前 `CLO6((K,D))` 初始化直接张量占用为 **69KD + 8D² + 32K 字节**，已在(8,32)、(32,32)核对。69KD包括17个FP32逐参数数组及一个bool数组，含继承而未使用的字段；8D²为输入协方差与基。它不是不可约下界，而是当前实现成本。尚不含权重、梯度、后续Wprev/h_step/tau2、临时区或Python对象。

若直接铺到十亿参数，仅69KD部分就是69GB（十进制），更不能用“O(1)资格迹”表示低显存。这里 O(1) 最多是数组数量不随经历长度增长；输入侧全特征分解及基乘法还需分别核算 D³ 与 KD² 量级工作。定义整个矩阵为“一个团”也不能免除通信、时限和数据搬运成本。

`age` 使用FP32，在2²⁴处再加1已经不改变值；Python步数又是可增长整数。数学无界运行、有限固定比特实现与有误差的年龄压缩须分别建立合同。该观察不要求改用INT64：应先判断只需保存哪些风险区别以及饱和/量化误差。

### 下一步与停止条件

1. **先明确被学习的量及可读证据。** 在主体共同递推中指定哪种持久状态变化影响未来预测/行动，哪些已交付后果能区分更新有益或有害。现有历史分离/递推合同监督这个选择；不把外给梯度的可获得性当作免费前提。
2. **在完整资源约束下推导改写。** 同时计入保持代价、证据不确定性与本拍可执行变化，先获得一个整步性质，再决定是否需要方差、曲率基或分配。任何新增状态必须说明不可由已有状态提供的区别及位数；不能把逐参数高斯滤波设为默认。
3. **用真实流验证对应的因果主张。** 真实字节数据、持续完整状态、先评分后学习、学习冻结/历史破坏等有作用的干预；语言能力判断按仓库充分训练和独立未来验证要求执行。对不使用回执的主体，不把断回执算成有效行动验证。

“允许参数暂时不动”不等于“有用的锁存”。现有 `GenerationLatchHealth` 已区分不可恢复的闭陷阱、刺激盲区和可达退出；`GenerationLinearMemory` 约束持有与纠错的区别。下一步须让同一完整状态递推同时给出保留区、仍然有效的证据路径、可付费的退出和未来功能增益，再复用这些结论，不能只补一个阈值。也不能把这些目标写进结构字段当作公理而声称它们已被生成。

**接口。** 可写状态为θ，执行θ←θ−u；本拍可读证据给出收益方向ĝ及误差范围ε，身体给出合法改写集合F（包含0）。在同一登记目标L、本拍可信范围内，若实际梯度g与曲率满足：

`|g_i−ĝ_i|≤ε_i`；`L(θ−u)−L(θ)≤−g·u + ½ Σ_i h_i u_i²`，`h_i>0`，

则完整更新有上界：

`L(θ−u)−L(θ)+C(u) ≤ Φ(u)`，

`Φ(u)=−ĝ·u + Σ_i ε_i|u_i| + ½Σ_i h_i u_i² + C(u)`。

C是以目标单位登记的非负改写机会成本，C(0)=0；若没有可信的单位转换，不把物理焦耳与语言损失直接相加，取C=0并把实际费用放入F。ε不是现有方差P的别名；可信区间、偏差、漂移与使用域都需说明。对角h可以是完整耦合二阶项的上界，不要求消除交叉作用，也不要求特征基；建立有效且不过度保守的h仍是具体模型的义务。

**纸面整步保证。** 选择F内使Φ最小的改写u*。因0∈F，`Φ(u*)≤Φ(0)=0`，故`L(θ−u*)−L(θ)+C(u*)≤0`。近似求解时也必须验收最终执行的Φ与预算；不能在取得保证后再接一个改变u的分配函数。若只得到`Φ(u)≤η`，结论随之变为同样的η误差保证。外界自行变化引起的目标漂移另计，该式不保证下一世界拍的损失单调下降，也不保证长期信用正确。

**可算特例。** 声明单隔室、对角上界、`C(u)=Σc_i|u_i|`、`|u_i|≤ρ`及二次预算`½Σu_i²≤B`。注意二次预算在这里是明确的执行代价模型，尚未标定为物理能量。拉格朗日资源价格λ≥0给出：

`u_i(λ)=sign(ĝ_i)·min(ρ, (|ĝ_i|−ε_i−c_i)_+/(h_i+λ))`。

预算未耗尽时λ=0；需要约束时求使预算满足的λ。资源压力增大意味着分母增大，而非把低收益方向强行放大。该式的阈值来自最坏方向误差与登记费用，分母来自曲率和共享预算；不是再附加收缩、年龄保持或平均分配。

多个实际隔室若具有合法的二次预算`½Σ_i a_ci u_i²≤B_c`，相同推导把分母改成`h_i+Σ_c λ_c a_ci`。a由真实资源参与关系决定；这只给出局部价格的形式，不证明一般求解可在本拍完成，也不证明功能分化。物料消耗并非二次时应回到实际F重推，不能把这个特例强加给介质。对有限整数事件则在合法局部变化上使用同一收益/费用比较；大模型不枚举所有全参数修改组合。

**已执行的数值参考。** 同一梯度(1,1)、曲率(1,1000)、ρ=10，预算与上一节有问题的分配使用的平方总量相同：受约束更新约(0.99668,0.001)，净收益下界0.50049，预算满足。把预算降到1/4，资源价格由0.00333升到1.00667，更新约(0.49834,0.000999)，收益仍为0.37467。ε=1.1、ĝ=(1,1)时证据不能保证改写有益，参考返回0；B=0也返回0。只是单步解析模型/数值求解检查，未训练、未证明一般语言优势。证据文件为`clo6_single_decision_reference_20261027.json`。

## 本轮已验证的缺口

## 稳健性 R 的准确作用域

`newton_contracts_iff` 和 `overestimate_keeps_contraction` 证明正曲率标量二次目标、准确梯度、未再分配的 Newton 更新。估计恰为真值的 0.5 倍时因子为 -1，只有临界振荡，不能称严格收缩。`saturating_step_bounded` 证明步幅有界，不证明误差收缩、持续学习或累计状态有界。

上浮 2σ 不是已证的真实曲率上界：需要估计偏差、相关性、漂移和覆盖概率条件。当前平方损失可核对精确 Hessian，交叉熵和隐层模型还存在输出耦合及非对角误差。

完整更新还有列/行分配和最后硬 clamp；它们可能改变原始下降方向、饱和形式和目标预算。需要证明最终执行更新的下降/有界条件，或明确给出预算残差和下降失败的条件，不能只检查 `_bound`。

长期生命体的 R 应分层：无扰动局部稳定；有扰动时误差有界并有可计算噪声底；环境持久改变时仍能响应；短冲击期间保留有益结构。逐步严格收缩所有内部状态会连历史差异一起消除，并非合适的全系统公理。R 作为声明世界类中的准入合同，不添加“永远不崩”这种目标公理。

Doyle 原文证明 LQG 类没有统一的保证裕度，并非每个 LQG 实例裕度为零，也不是 CLO6 的直接反例：https://authors.library.caltech.edu/records/e39yd-evs06 。

- 壳层与当前资源时钟尚未证明等价：`normalized_observation_clock` 证明的是观察增益的归一化及范围；`steady_gain_worse_for_fresh` 和 `pooled_gain_risk` 给出特定估计风险模型下的增益差距。资源时钟没有显式的每方向后验误差方差，所以现有证明不能把它等同为该模型中的壳层，也不能仅凭这点宣布实际任务必须加壳。
