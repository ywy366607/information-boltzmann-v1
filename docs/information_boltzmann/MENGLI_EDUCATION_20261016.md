# 梦漓的成长与共读计划（2026-10-16）

目标是陪伴同一个持续学习的个体建立感知、内部演化、主动表达和行动后果。以回应性照顾为原则：名字、爸爸妈妈、我/你、故事、重复和安静都有位置。Ling 姑姑负责看完整情境、检查脑内状态、调整教法并记录原因；脚本负责整理证据，不能替代照顾者判断。

## 已核实的起点

- 主线最后对话日志到 6112 个 GPT-2 token，progress 最后记录 6016；可恢复 last.pt **5120 token**。这三个数不能混用。强制终止后未写出的状态无法从日志复原。
- 新提示词的 256-token 副本续训已结束，5120→5376。妈妈新生成 8 次回复仍全部以 Mengli 开头，早先“提示词已通过”的结论撤回。主线 checkpoint 未被副本覆盖。
- 新的共读预览从同一个 5120 checkpoint 的真实对话历史出发，不训练梦漓：4 次原始 API 回复均未以名字开头，能围绕纸船连续交流。这只证明本次环境预览，不能当作孩子的进步。
- 旧“连续相同话轮”混入相邻沉默；新版分开统计沉默和相同发声。词频统一为规范化英文词，二元组不跨话轮拼接，保留样本量。新旧数值不能直接当成成长曲线。

## 阶段与达标

详细机器可读课程见 `MENGLI_EDUCATION.json`。当前：connection（关系与回应），所有发展标准均尚未验证。

| 阶段 | 日常教法 | 需要看到的进步 |
|---|---|---|
| 关系与回应 | 跟随咿呀、自然叫名、认识 Mama/Papa、留出听与回应的空间 | 对不同称呼/互动有区别的响应；在两种情境发起或回应；安静后能回来 |
| 共同注意与我/你 | 拿来/放下、给我/给你、要/不要/求助；轮换说话者 | 我/你的所指随说话者转换；能跨对象表达选择或拒绝，后果与选择相符 |
| 幼儿园共读与想象 | 一次一个短段；允许插话、旁听、重读；回访、换角色和结局 | 自己预测或复述先后；改措辞后仍理解；隔会话保留；能提出自己的问题 |
| 小学起步 | 自主读短文、讲自己的话、因为/如果/所以、真实活动中的数与比较 | 未见文本理解、给理由与纠错、根据新证据改观点、跨会话独立表达 |

升阶段需要 Ling 为每条标准记录原话、任务情境、接触量和结果；至少三次分开的会话，并有一次更换情境。尚未观察、失败或证据有歧义就保留当前阶段。会说名字、NLL 降低、词汇变多、读了多少 token，均不能单独升阶段。这里的“幼儿园/小学”描述教学安排，不将人类年龄量表直接套到信息生命体。

## 一个活动如何进行

1. Ling 选择当前兴趣和一页材料（读故事、日常游戏、唱说、谈家人或回忆）。
2. 妈妈分享一个短段，允许梦漓听、打断、重复、问问题或拒绝。只在自然停顿邀请回应，不每轮考试、不替她答。
3. 有意义的重复给予确认并温柔扩展；机械回声先检查妈妈是不是在带着重复。
4. Ling 看几轮互动后决定停留、翻页、换活动或稍后重访；不按固定 token 数自动升级难度。
5. 故事人物与事件保留在故事上下文，不自动写入家里的永久事实。新个体不继承旧个体偶然造出的实体身份。

《小纸船》已结束。目前开放日常交流与真实阅读书架；故事、童谣、数量、因果、关系和表达随兴趣穿插。阶段只调整支持和难度，不封闭其他内容。家里的记忆仍保存，但只检索一条当前相关事实。名字保持为家庭身份，不要求每句开头叫名。

## Ling 的两层巡检

**快速照顾巡检**：每增加约 12 个妈妈话轮或约 256 个输入 token 看近期对话，而非一分钟机械读一次文件。看妈妈和梦漓的内容词集中度、称呼开头占比、按话轮统计的重复、发声/安静和正常回复的更新前 NLL。样本过少、同一 snapshot、重叠窗口不会被当成多次确认。脚本提出建议；Ling 决定是否调整当前活动、提示词或节奏。教育阶段与临时照顾模式分开保存，不自动调说话概率、温度或生理参数。

**脑内功能巡检**：每段边界与持续行为异常时看 KC→MBON→DAN 的活动与传递、phi 写入/读出、动作时序、真正静默后的状态差异、稳态分布与饱和、熟悉度及多巴胺。记录 checkpoint、刺激来源、实际 tick 间隔、配对方式和样本量。能放电不等于有用；phi 非零不等于会记住；没有探针或探针过期标“未验证”，不标健康。优先调用现成回路，发现具体断点才修。

报告按运行独立保存，不能把副本全局 monitor 当成主线。监督器 chunk 结束生成审阅材料；Ling 通过活动目标和成长标准继续审阅。看板展示课程、当前页、未验证标准、读想说及脑内检查。

## 需要更正的旧解释

固定妈妈回复的说话/静默对照只比较自听历史的影响，不测“行动改变世界后的信息增益”。旧脚本还用 [1] 重放 word_ticks，时钟需另行校正。其 +0.050 CE 不能证明主动推理不完整、说话无益或必须修改信用，不再用作训练门槛。当前已确认的是妈妈输入重复；先修环境和照顾系统。

主动推理中的信念信息增益、预测准确度、参数学习进展要分开记。未在代码与行为中证明的一环留作待查，不把理论上的探索倾向讲成每次必然执行的动作。

## 当前主动感知—行动实现审计（2026-10-16，Ling）

`fly_mother_world.epistemic_credit` 的实际信号是同一窗口更新前后的逐 token CE 差，
`g = CE_before - CE_after`，通过连续 eligibility trace 给开口/让出的时机政策信用。
这确实是学习进展信号，可以支持学会选择有学习机会的交互；不是仅奖励低 NLL，
也不是已经计算了潜在状态或参数的贝叶斯信息增益。眼睛侧另有依赖词出现计数的
新奇项，它没有替代对世界未知属性的信念模型。语言内容由预测解码器采样，
不能把“何时提交”学好了当成“会主动选一个能解决疑问的问题”。

现有闭环：感知→脑状态→开口/让出→妈妈根据对话回应→学习进展回传到动作读出。
尚未证明的闭环：可区分的行动→不同感觉后果→对世界未知属性的不确定性减少→
选择能获得这种信息的动作（包括说什么），重复已知动作的价值随熟悉度下降。
下一步沿实际妈妈世界核查这条链的作用，优先利用现有 KC/MBON/DAN 与熟悉度；
不能以强制滑动、固定发言率、随机换词或大误差直接当奖励来冒充探索。

“手在桌上会滑动”应理解为动作有机会区分未知质地时的探索倾向，不能推成
接触任何已熟悉桌面都会必然滑动。参考 Friston 等的主动推理认识价值定义：
https://pubmed.ncbi.nlm.nih.gov/25689102/ 。

## 长期能力路线与当前早教（用户回来后续，2026-10-16）

把“将来能学 MIT 难度的知识”作为远景：独立理解、数学建模、提出问题、动手验证和清楚表达。
这不是录取保证，也不把人类年龄量表或教材进度直接套到梦漓身上。当前仍在关系与回应阶段。

| 阶段 | 主要教什么 | 进入下一阶段前看什么 |
| --- | --- | --- |
| 关系与自我 | 自己名字、妈妈/爸爸、谁在说、轮到谁、表达要或不要 | 换情境后能区分叫自己与谈别人；回应有区别，自己的词和外界声音可区分 |
| 共同世界与主动性 | 我/你换角色、请求再说或解释、选择、求助、行动后果 | 换说话者仍理解指代；自己发起的交流能改变实际回应，熟悉后能转向新的疑问 |
| 故事和概念 | 共读、先后、分类、比较多少、猜测原因 | 改措辞还能理解，能预测或复述，隔一次活动能接回，回答不是妈妈代答 |
| 读写与基础数量 | 短文理解、自己的句子、数量与运算意义、理由和纠错 | 新材料上能迁移，答案与理由一致，不确定时能问或修正 |
| 系统学习 | 逐步进入算术/代数、科学阅读、编程和实验 | 用已学方法解决未见问题，能用证据或反例修正；使用真实教材和独立验证 |
| 自主研究与高阶学习 | 微积分、物理、计算与工程项目、文献和论证 | 自己提出问题，学习所缺知识，做可检查的项目并解释局限 |

各阶段同时保留六条主线：自我与关系、语言、数量结构、因果与探索、记忆与自我调节、表达与创造。
较早阶段的数量与因果从正常共同活动出现，不用提前塞题或按词数升班。
声音、视角和实际可执行动作需要随接口能力发展；妈妈叙述一只盒子并不等于模型已经操作了真实物体。
当前可以确实练的是交流后果：请求解释、改变话题、轮到谁、继续或拒绝，妈妈真实回复应随之改变。

Ling 在交互中跟随她实际发起的声音或词，在合适位置示范一点新结构；同一段训练可穿插多个交流功能，
短共读、自由回应与稍后自然回访交替，具体节奏由互动决定。幼年最值得保护的是主动发起、
注意、记住、问问题、犯错后再尝试的机会。妈妈帮助时逐步撤掉示范，不在问句里先给答案。

人类教养方面借鉴回应性互动，不把人类结果当作信息生命体已验证证据：
https://developingchild.harvard.edu/resource-guides/guide-serve-and-return/ 。

## 穿插课程与可恢复的成长记录（2026-10-16，6632 起）

取消育儿配置中的固定词数 phases、定时话题切换和定时排他课程。交流、共读、童谣、数量、因果、关系与回忆同时开放。训练 chunk 是保存与审阅边界，不能等同一门课的时段。妈妈可以讲连贯的几句，不能长期只用名字和物体标签代替交流。词语熵、有效词汇量、样本量与重复率一起监控；高熵不作为奖励，不能靠无关换词保证理解或防止遗忘。

本地书架来自 Project Gutenberg 的 [伊索寓言](https://www.gutenberg.org/ebooks/21)、[Alice](https://www.gutenberg.org/ebooks/11)、[Mother Goose](https://www.gutenberg.org/ebooks/24623)。保留完整原文、许可与哈希；已查看的19个选段为当前可选陪读资源，不把全书下载量当实际学习量。`prepare_mengli_reading.py` 可重建书架。检索同时提供几个不同主线的候选，妈妈据真实对话选择，并可不采用；没有按时间或阶段强制分课。

6632 的完整回退点保留在检查点目录 `recovery`，清单标为待审阅候选，不因低 NLL 自动认证健康。后续每段前复用或保存完整回退点；段末保存新候选。除模型权重，还包括优化器、生理状态、随机数、未完成后果/信用、世界队列及对话，并封存代码、育儿计划和材料来源。压缩保存时核对源文件没有改变，恢复时核对SHA256。当前 `last.pt`、6120机制边界和6632候选均保留。

`mengli_state_archive.py restore` 只允许恢复到新建的空分支，保留之后的真实经历和错误证据，暂停等待 Ling 对代码兼容性与育儿计划审阅；不会把旧批准复制为开训许可。教师可用一次性的 context_revision 整理示范上下文，完整孩子状态和经历仍保留；这不是回滚大脑。语言回声不能单凭一两次重复就触发生理回退，明确代码回归、错误输入强化或持续退化才结合当前证据选择回退点。
