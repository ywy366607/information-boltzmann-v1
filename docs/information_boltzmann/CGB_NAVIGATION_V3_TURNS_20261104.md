# 第三版：轮流对话的闭环，立道检查与整体验收（Claude，2026-11-04）

接 GPT 的 [第三版总装](CGB_NAVIGATION_V3_ASSEMBLY_20261104.md)（GPT 额度用尽，未完成）。先读 [主动导航方案](CGB_ACTIVE_LATCH_NAVIGATION_20261104.md) 开头的"必读：立道与修德"和 §11.5。

## 1. 为什么改成轮流

GPT 的逐字节版本让身体在每个外界字节都可以决定开口。新初始化的决定头开口概率约 0.5，于是 1200 字节里说了 401 次，401 个后续段里 391 个在结算前被下一次行动打断，没有一个后果能到达（`connectivity_diagnosis.json`）。这是出生时的火亢：动作太密，后果回不来，金无可判，信用为零。用重叠记账去补救，补不出归属。

改法：
- 世界按轮次回应。每一轮是一段回应（480 字节）加同源后续段（480 字节，用来测泛化进展）。
- 每一轮结束时，身体按自己的状态决定开口还是继续听；沉默时世界接着往下读。
- 开口后，身体每听到自己说出的一个字节，就决定一次停或不停，长度上限 32 是资源界，截断会计数。
- 轮次的结束是世界的事件，不是身体的定时器；身体可以连续沉默任意多轮，说话率不设定。

这样每一轮就是一次完整的经历，后果一定会到达，可以归属。允许打断（在对方说话途中插话）留到以后：那需要先学会低开口率，否则又回到火亢。

## 2. 实现（新文件，GPT 的源码未改）

- `scripts/ib_local/language_navigation_turns_v3.py`：`TurnDialogueEngine`，沿用第二版已逐位核对过的对话循环（两次有界更新、采样与因果重放一致性检查），并加入：
  - 开口、停止的伯努利决定，由 `LatentNavigationV3.plan_from_state` 读出（它带经历读出）；
  - 策略信用覆盖开口、每次停或不停、以及所说的字节，沉默同样得到信用；
  - 每轮在长后继到达后，向 `ExperienceMemory` 写一条经历，带本轮进展（后续段位置此前未暴露时）；
  - 按年龄的消融改为移除注入的行动态（GPT 第二版的消融取的是后继，对经历表不对）。
- `scripts/ib_local/run_language_navigation_turns_v3.py`：同一个旧个体，宽世界（`BroadLanguageWorld`，4013 万字节来源），模式为 `active`、`silence`、`sequential`（说话、自听，但世界不理会所说内容，只顺读），外加 `--disable-latent`。
- `scripts/ib_local/check_navigation_turns_v3_gate.py`：立道检查。个体从检查点载入内存，学习开启，活 128 轮；检查点不写，这个内存中的个体用完即弃。之后逐环做前向和单次反向的测量。

**木→火的修订是看到数据之后做的，在此明确说明。** 原检验只采样 16 次：开口概率约差 4%，16 次里预期只翻转约 0.66 次，有约一半的机会一次都看不到。所以原检验功效太低，修订度量直接量分布的变化。同时这也说明，新生时木→火确实很弱：唤起几乎决定不了说什么。这是要靠学习长出来的部分，训练中要跟踪。

另外两个弱点，接通但不算强：
- 说的话很短，中位数 2 字节，只有 12% 能在 4 字节索引上匹配，所以大多数开口其实没能改变世界给什么，火对世界的作用还弱。
- 写入 128 条，合并 0 次，表在纯粹地积累。4096 条会在约 4096 轮后写满，届时再看合并和替换。

## 4. 整体验收（预注册，跑之前写）

同一个旧个体、种子 11，每臂 2500 轮（5000 次更新、240 万外界字节），一次只跑一个：`active`、`silence`、`sequential`、`active --disable-latent`。验证集与第二版相同（32768 字节 sidecar）。

预测：
- **P1（主要）**：主动的最终验证 NLL 不比沉默差超过 0.02。第二版里主动 3.478、沉默 1.478，原因是回声井；世界变宽后，这个差距应当消失。
- **P2**：主动的平均可用进展高于 `sequential`。说的话能改变世界给什么，这一点才有价值；如果两者相同，说明火对世界还没有作用（见上一节的弱点）。
- **P3**：潜表有用。主动最终的按年龄消融中，去掉年龄超过 4096 的经历，NLL 应当变差（>0）；`active_no_latent` 的验证 NLL 不低于 `active`。
- **P4（五相，诊断用）**：说话率不长期塌到 0 或 1；报告说话长度、匹配率、进展、合并与替换、各年龄段的读出质量，看是否有一相长期独大或缺失。

只有单个种子，结论限于这个预算。失败要给出原因和下一步出路。

## 4b. 整体验收结果（单种子 s11，各 2500 轮 / 5000 次更新 / 240 万外界字节）

`sequential` 和 `active_no_latent` 第一次运行时，D 盘写满，存检查点时失败。删除了已被取代的第一、二版检查点（清单和哈希见 `results/cgb_language_navigation_v3_20261104/DELETED_PT_DISK_FULL.json`），然后原样重跑。失败那次的日志保留在 `*_diskfull_failed`。

| 臂 | 最终验证 NLL（起点 1.513） | 后半程 5 个验证点的均值 | 开口率 | 匹配率 | 可用进展 [min / median / mean / max] | 读增益（起点 0.05） |
|---|---|---|---|---|---|---|
| active | 1.471 | 1.480 | 0.49–0.53 | 11–15% | −0.0064 / 0.0013 / 0.0018 / 0.046 | 0.014 |
| silence | 1.478 | 1.472 | 0 | — | −0.0062 / 0.0013 / 0.0016 / 0.050 | 0.004 |
| sequential | 1.480 | 1.473 | 0.50–0.53 | 0 | −0.0062 / 0.0013 / 0.0016 / 0.041 | 0.012 |
| active_no_latent | 1.488 | 1.497 | 0.48–0.52 | 11–14% | −0.0083 / 0.0013 / 0.0018 / 0.048 | 0（固定） |

判读：
- **P1 通过。** 主动不比沉默差：最终值 1.471 对 1.478，后半程均值 1.480 对 1.472，都在单臂自身 ±0.02 的波动以内。第二版的退化（3.48）随着回声井被去掉而消失了。
- **P2 不通过。** 主动 1.480，`sequential` 1.473，可用进展均值都约 0.0017。按动作类型分开看主动臂：
  - 沉默 0.0018（n=1240）；
  - 开口但没匹配上 0.0018（n=1095），这和沉默完全一样，世界照常往下读；
  - 开口且匹配上 0.0014（n=165），回应的 NLL 是 1.60，高于沉默的 1.46，跳到别处反而更难学。
- **开口概率 2500 轮没有变化**，中位数始终约 0.50；说的话中位数 1–2 字节。原因：开口带不来任何好处，策略没有梯度方向，强化学习的信号又只有约 0.002，淹没在噪声里。
- **P3 不通过。** 现场按年龄消融，所有年龄段的 NLL 变化都 ≤ 4×10⁻⁵；读增益被学习压低（主动 0.05→0.014，沉默→0.004）。`active_no_latent` 后半程比 `active` 差 0.017，但它自己的波动达 0.04（1.484–1.525），而且现场关掉读出几乎没有影响，所以这个差别不能归因于潜表，更可能是两条轨迹的动作和接触分化之后的噪声。
- **五相诊断。**
  - 土与金接通了：意图跨回应保持，每轮都有进展，经历每轮写一条。
  - 但火无用：开口不改变能学到什么。
  - 于是水所藏的也没用：在不重复的宽世界里，过去的经历对预测下一个字节没有信息。
  - 木虽然生（唤起能改变开口概率），却生不出有意义的火。
- **根因与 Lean 一致。** `active_closure` 需要"被动供给有界"（`passiveBounded`），才能推出"不能永远被动"。这个世界里，沉默时有无限的新真实文本，而且最好学，所以开口没有必要。需要来自世界：世界不需要它说话，它就学不会说话。

**出路**见第 5 节：
- 让被动供给有限；
- 加动作条件的世界模型；
- 用预演的进展做决定（主动推理的认识价值），代替只靠事后弱信号的强化学习。

## 5. 下一步：木火通明（用户，11-04）

用户："现在是单纯的 JEPA 潜空间预测，但是这个预测没接到动作上，这就相当于只有木，但是没有火。我的设想是它能感知到自己在语言空间中的未知，并且自己知道要往哪里走，这样木火才通明。"

现状核对：
- 用上了 LeJEPA 的 SIGReg，以及逐字节预测 32 / 512 字节后的潜状态。
- 没有用上动作条件的世界模型：`LatentNavigationV3.observed_outcome_loss` 未被调用，开口决定也不看预测的后果。
- 决定只靠事后的进展做 REINFORCE，信号太弱，2500 轮里开口概率没有动。

Lean 已有的依据：`action_condition_required`，世界对动作敏感时，不看动作的预测器必然错；`active_closure`，被动供给有界时，不能永远被动。

设计（同一转移，一起接，不分阶段验收）：

1. **知道自己在哪里。** 决定时刻的潜位置 z = encoder(h)，即 SIGReg 约束下的 JEPA 潜空间。
2. **感知自己的未知（木）。**
   - 地图记的是"在这里学到了多少"，不是"这里有多难"。只看误差，会被永远学不会的噪声吸引（噪声电视问题）。
   - 两个来源：
     - 经历表已经按状态存了每次经历实测的进展，读出就是非参数的进展地图；
     - 再加一个进展头 G(z')，由实测进展训练，用于泛化到没去过的地方。
3. **知道往哪里走（火）。**
   - 动作条件的世界模型 F(z, a) 预测"说了 a 之后落到哪里"，用真实经历训练（LeWM），即 `observed_outcome_loss`，目标是实际的短、长后继。
   - 决定时，身体自己生出 K 句候选的话，加上"沉默"，用 F 预测各自落点，再用 G 加经历表估计落点的进展。
   - 按预测进展的 softmax 选择，保留探索。这就是主动推理里的认识价值，也正好防暗室：沉默而重复时学不到东西，它就会开口。
4. **土与金的回路。**
   - 回应到达时，实际落点和 F 的预测之差是土的消化信号，用来训练 F。
   - 实测进展是金的验收，用来训练 G 和经历表的进展标签。
   - 想象出来的进展和实测进展是否一致，本身要报告，作为"木是否通明"的度量。
5. **世界必须满足前提（被动有界）。** 沉默时，对方只围着当前的话题转（重读近处的有限片段）；开口时，按所说的话转到新的地方。否则开口永远没有必要，见第 4 节的结果。

新增立道检查：
- F 对动作敏感：不同候选的话，预测落点不同，并且和实际落点相关；
- G 的预测进展和实测进展正相关；
- 实际的选择随预测进展变化；
- 在重复的被动供给下，个体会开口。
