# 可复用恢复判据与原剪断比较的闭合

本轮完成两项接续：将恢复证明提炼为可复用的局部充分判据，并为上一轮的变化世界补齐原 `Exchange.SelfMaintains` 目标。身体规则、世界、物料与能量端口、生存评分及外部时钟均沿用上一轮。

正常过程所有时刻的存活评分为 1；原边际幽灵剪断过程第六拍起至多为 3/4。因此同一新世界中，原持续存在与自我维持目标同时成立，后者从第六拍起具有至少 1/4 的持续优势。

## 1. 从局部恢复条件推出原评分

`RecoveryCriteria.Ranked` 登记一个分析区域 G 和一个自然数分析量 r。它们是证明对象，不是额外身体状态、时钟输入或生命公理。验收四项条件：

1. G 中的身体有正含量，且初态在 G 中。
2. 每条正概率事件从 G 出发，仍留在 G。
3. 每条尚未实际摄入的正概率事件，都使 r 严格下降。
4. G 内的 r 严格小于已有恢复时限 H，已有恢复阈值不大于 1。

`ranked_firstHit` 据此证明：从 G 中任一状态出发，按同一实际未来核演化，在 H 步内至少发生一次已登记摄入的概率为 1。`survival_of_ranked` 再结合正含量与初态，推出原 `Exchange` 正常评分全时为 1；不把“能够恢复”或“已经存活”作为判据的前提。

这是一个局部充分判据。它覆盖有界的确定恢复进展；允许随机等待、自环或仅以某个概率恢复的机制，需要相应的概率型扩展。摄入事件之后 r 可以重新变化，因此判据允许反复学习和补给循环。

## 2. 在现有变化世界中复核

`RenewableRecoveryCertificate.certificate` 使用上一轮已定义的可恢复区域 `Good`：资源失配阶段取 r=1，其余可恢复阶段取 r=0，恢复时限仍为两拍。

可恢复区内，非失配阶段已有实际摄入；失配阶段不摄入，但其正概率下一步进入可探测窗口，使 r 从 1 降为 0。闭合性同时核验身体的燃料、候选改写和世界通路，防止只让分析量下降却丢失实际恢复能力。

`survival_by_criterion` 用上述通用定理重新推出原正常评分全时为 1。原实例证明保留，新增证书提供可复用的验收路径；未改写动力学以迎合判据。

## 3. 原剪断究竟损失了什么

本轮使用原 `Medium.cutMove` 与 `lawCut`。每拍剪断分支都从自己的当前身体边际抽取幽灵身体，并以该身体推动世界；实际身体继续接收所在世界的反馈。前五拍的稀疏联合分布由原递推逐拍证明，不能用固定旧动作或另一个配对模型代替。

第五拍，剪断过程恰有：

| 实际身体与世界 | 概率 |
|---|---:|
| 已备足储备的 A 身体，位于 A 取食区 | 1/8 |
| 已备足储备的 A 身体，位于 B 取食区 | 1/8 |
| 已备足储备的 A 身体，位于 B 失配阶段 | 1/4 |
| 已重新开放候选的身体，位于 B 探测窗口 | 1/2 |

因此身体边际中，A 已备足状态与待辨识状态各占 1/2。位于 B 探测窗口的实际身体本应执行探测；剪断抽到旧 A 动作的概率为 1/2，于是第六拍进入不可恢复世界状态的概率为：

```text
1/2（位于探测窗口）× 1/2（幽灵仍执行旧动作）＝ 1/4。
```

`cut_seed_mass` 验证该质量精确为 1/4。该世界状态在所有身体输入下保持吸收，其所有实际摄入标记均为假。通用的 `firstHit_zero_of_closed` 证明那里任意有限时限内恢复概率为 0。

随后只需概率质量的单调性，无须继续枚举时刻：剪断过程已经陷入该区域的质量不会减少，故所有 n≥6 都满足存活评分≤3/4。这个上界保留剪断自己的后续边际演化，不要求它冻结在第五拍。

## 4. 当前证书与理论边界

三组核心结果为：

- **通用恢复判据**：局部闭合、未摄入事件的有界严格进展与正身体含量，推出原评分的全时持续存在。
- **现有模型的判据证书**：不改身体、世界和时钟，复核可反复付费辨识过程的正常持续存在。
- **原剪断的全时差距**：正常评分=1，剪断第六拍起≤3/4，推出同一变化世界的 `Exchange.Persists … 0` 与 `Exchange.SelfMaintains`。

上一轮的两个开关对照继续承担各自作用：禁止候选重开或禁止储存补给，第六拍评分≤1/2。它们与原剪断是不同干预，本轮分别保留了证书。

这些结果仍适用于已经声明的可恢复变化世界：诊断期间分支稳定，探测窗口和食物供给规则明确。一般随机等待下的恢复、几乎必然的长期再学习频率、真实物料来源与热力学标定、完整规则书与 1% 编码、完整 L1–L6 仍按各自目标推进。下一步优先将同一恢复证书与实际供给、时间及载体实现证书组合，明确适用范围。
