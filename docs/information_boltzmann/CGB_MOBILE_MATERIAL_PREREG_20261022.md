# 可移动有限材料：同一反应图的粒子分辨实现

基线abf1d04。已有端状态能区分交叉与接合，但网格把前体端的位置全部给定。本轮把端库存放到实际有限材料单元上，保留其坐标、电荷、物料、身份编号，局部相遇才允许接合。不是另加“伸长/转弯/分叉”指令。

## 微观状态与共同能量

N个有限材料单元，每个有L_i个连接端，坐标x_i、独立电荷q_i/电容C_i，以及整数B/F/H/P/D局部组成。接合是稀疏实际桥，记录两端、取向、支持占据c∈{0,1}和痕迹r∈{0,1}；没有桥就没有桥上的存储载体。接合消耗B_post、P_post和双方端；空桥拆解返还B_post、D_post→P_post与端。c或r未释放前不直接删除桥，保留该通路的明确反应屏障假设。

    U = Σq²/(2C) + e_PΣP + e_HΣH
        + Σ_bridge[e_n + k(|x_a−x_b|−l_0)²/2 + e_C c + e_r r − χrc]
        − J Σ_i d_i(d_i−1)/2 + U_world
    G = U + Σ_{i,species} ln(n_is!)
          + Σ_i[ln((L_i−d_i)!)−ln(L_i!)]

自由端简并度、局部理想组成与桥的内部二态由同一状态空间计数得到。大组成数时ln(n!)的Stirling极限对应上一层占据自由能；当前不是用连续r/C的小数强行切断历史，而是有限二态的跳跃实现。实际n从0→1创建载体，r=c=0；从1→0仅在二者已返回0时释放，状态数有物料上界。

沿用相同反应图：支持捕获/释放、付费逆向运送到H、H↔F、付费痕迹写入与热恢复、电场↔P/D、付费极性电荷传输、结构装配/拆解。每个允许事件的正反共同尝试率κ，速率κ·sigmoid(−ΔG)，反向κ·sigmoid(ΔG)。κ是声明的有效势垒/有限机会速率；平衡比由整个G确定，不能将频率或低NLL直接当作供给。表面机会依赖排除该桥后的相邻桥数，确保正反κ一致。所有组成变化按实际整数事件扣款。

## 空间输运与热浴

同一桥形变能给出力−∂U/∂x，不另给目标方向。各粒子按对称高斯位移提议，方差2DΔt，以min(1,exp(−ΔU))接受；它是等温可逆局部输运的有限步实现，须验证Δt细化。硬核排斥、有限容器和最大桥长是显式材料/环境边界，拒绝越界提议；不能把容器中心当作生长靶点。允许桥长≤接触尺度，因此形成/断开有相同空间可达性。

热浴可给系统能量，也可带走能量。每次事件/运动记Q_out=−ΔU，电源功单列；单条随机轨迹上的G可上升，不能套用原确定性核的逐步G下降验收。局部正反率比、总能量账、组成、完整RNG恢复才是本轮准入。世界端口沿用有限电容/有限耦合，外界电压做功明确记账。

新的相遇用当前坐标的稀疏邻域搜索发现，只保存实际桥，候选工作区O(N+E_near)，历史不无限累积。痕迹/支持仍在桥上；其携带的物理材料移动时不丢失。分叉是同一有限端接合事件在已连接材料上继续发生的结果，而非单独分叉率。
