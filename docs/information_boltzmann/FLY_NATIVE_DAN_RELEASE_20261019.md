# 互惠突触在实际DAN位置调节释放

本轮从完整33000词空间教师候选零暴露扩展；主线32384仍暂停。
新增的是局部化学释放链，未来BPTT窗口1，实际物理拍与连续状态保留。

## 接入的断点

原KC→DAN反馈把各KC的释放先汇总到整条DAN，再把同一额外释放广播到
该DAN全部输出。它保存了反馈的总强度，却丢失了反馈发生的位置。

现在使用390个DAN提供的全部1404101个形态节点、1403514段及187404个
实际释放位置。145727条原KC→DAN边的281930条局部路线，接收KC实际
释放位置的包；原236767条DAN输出边按535422条位置路线读取释放。
同一物理释放位置的多个伙伴共享一次资源消耗，接触份额仍加总为旧边的1。
DAN→KC另保留225150条两端空间路线，使输出既读DAN释放位置，也到达
实际KC接收位置。形态根之间不添加连接，细胞之间不补桥，不按ROI归并。

局部链为：

`KC位置释放 → 实际互惠接触 → 局部受体激活 → 钙相关信号与树上运输 → 当地释放资源 → 实际DAN释放位置 → 原图目标/KC局部教师 → 原接触φ`。

受体采用质量作用的占据/解离递推；正的归一化钙相关状态由受体驱动、
清除并沿完整形态运输。它代表有效释放激活，不是测得的摩尔钙浓度。
实际释放由细胞动作电位驱动及局部钙相关信号共同决定：
`p = 1-exp(-rate*(AP + gain*Ca))`，释放资源`released=x*p`，随后恢复。
AP是原细胞脉冲，gain沿用既有可学习KC反馈材料；亲和度、解离、运输、
钙时钟、释放率、资源恢复分别为可学习参数，不给出生物时间上限。
包的单位按静息资源下的一个独立AP归一化，保持旧图边效能的参考单位；
它不增加实际资源，不能把归一化包当作单个分子/囊泡数。

启用后，全图多巴胺递送及KC空间教师都读取实际DAN位置包。原全细胞KC
反馈广播只在显式关闭新来源的配对参考中使用，正常路径不叠加两套反馈。

## 生物与功能边界

互惠轴突接触、KC胆碱能输入和DAN突触前钙响应有实验依据；具体受体亚型、
离子通道和参数不是由连接组直接给定。因此本轮实现有效局部受体/钙相关
释放动力学，**DAN动作电位仍沿用原细胞脉冲**。主动Na/K/Ca电缆、VGCC
分子门控、局部电压到胞体的耦合、完整胞外DA体积递送仍为明确缺口。
不能把本轮说成已经重建了整条DAN的全部电生理，也不凭局部活动证明学习收益。

[Cervantes-Sandoval等，2017](https://elifesciences.org/articles/23789)
支持互惠胆碱能反馈及其对DAN突触前钙和学习的作用，未提供本实现全部微观参数。
