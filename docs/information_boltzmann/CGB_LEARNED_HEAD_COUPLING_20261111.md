## 两种势能

**weighted**：每层将各头完整S投影成头节点，Q/K注意力产生对称非负边权，乘原交换子平方势能。初始K=0、Q非零，均匀权重精确恢复原势能和力；K第一步即可获得梯度。力包含边权对S的导数，不能只把已有力乘边权却称为势能梯度。log_strength可学习。

**free**：每层对完整S做头间注意力及非线性读出，softplus形成非负势能，无固定交换子项。初始只用源S把力范数配到原交换子量级，不用未来后果。宽度32是本次有限候选，未声称这一个小网络就具有通用逼近能力。

共同保留原二次势、S/P、步长、内步数及对称分裂积分。学习期间势能参数改变，不能沿用固定参数系统的能量守恒结论；自由势能未强制共同换基对称性，原Q不作为其守恒证书。隐含状态保持量的作用继续记录，不凭非零Q宣称锁存收益。

## 参数类别审查

可学习参数是跨事件保存的规则；内容相关量是当前输入/状态计算出的活动，两者可以同时存在。

| 当前量 | 参数粒度 | 是否随内容变化 | 本次处理 |
|---|---|---|---|
| RMSNorm gain | 每层每通道可学习 | gain本身不随输入；RMS统计随每个位置变化 | 保留 |
| Q/K/V与输出投影 | 每层可学习矩阵 | 投影后的Q/K/V随当前输入变化 | 保留 |
| alpha遗忘门 | A_log、dt_bias每层每头；输入投影可学习 | 每位置每头alpha依赖输入 | 保留 |
| beta写入门 | 每层输入投影与每头偏置可学习 | 每位置每头变化 | 保留 |
| 输出门、MLP gate | 每层可学习矩阵 | 每位置每通道变化 | 保留 |
| S/P | 事件持续状态，不是Adam参数 | 由实际经历与内运动改变 | 保留 |
| 头间作用 | 原固定函数/全局kappa | 原力随S变化；新边权/势能也随S变化 | 本次实验变量 |
| omega | 当前各层共享的固定频率 | 不随内容变化 | 本次保持，避免同时改变量；后续可考虑每层时间尺度学习 |
| dt、内步数 | 数值积分配置 | 固定 | 作为数值分辨率/计算预算保留，不直接当学习门 |
| 容量、槽数、存档频率、eps | 资源边界/数值定义 | 固定 | 不把所有常数都变成可训练自由度 |
| 检索温度、ridge、阈值、损失系数 | 固定配置或跨事件校准 | 部分读出已由真实误差校准 | 本次不一起改；先按独立误差与实际尺度决定是否需学习 |
