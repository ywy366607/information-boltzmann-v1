# 什么样的世界能孕育无限流生命（2026-10-27）

用户："不只是世界什么时候值得学习，而是什么样的世界能够孕育出无限流生命体。什么样的世界才能产生这种可以学习、记忆、感知的生命体。"

生命的必要条件反过来约束世界。下面按层排列：已证（Lean 定理名）、待证、待建。

## 第一层：有生命的世界

| 条件 | 内容 | 状态 |
|---|---|---|
| 被驱动 | 边界持续注入自由能（不只是物质）；时间上永不停 | ✓ `stream_never_dry`（G26）；食物化学能 `NestedWorld.foodE` |
| 能耗散 | 有汇；输入不停则输出不停 | ✓ G16 `export_forced`、`endless_intake_endless_export` |
| 守恒且局部 | 交互是真的，行为后果回到自己 | ✓ 公理；`NestedWorld.axioms_torus` |
| 有周转、无锁死 | 物质会漏，尸体会被分解；否则富者俱乐部使世界塌缩（G19a） | ✓ `leak_bound`、G26c `corpses_must_go`、`frees_only_by_dissolving` |

## 第二层：值得感知、记忆、学习的世界

| 能力 | 世界须有 | 状态 |
|---|---|---|
| 感知 | 差别落在可分辨带宽内并高于噪声 | ✓ G25e `gain_times_band` |
| 记忆 | 过去预测未来；相关时间在感知时间与记忆时程之间 | ✓ G19b/c；`hold_vanishes`；`leak_bound` 给出记忆时程上限 |
| 比较（一生之内） | 环境平均会变 | ✓ C-1 `no_fixed_leave_threshold` |
| 学习（跨代） | 规律跨代会变、一生之内稳定 | ✓ L-1 `innate_optimal_of_constant`、`learner_loses_of_constant`；L-2 `innate_loss_quarter`、`learner_beats_innate`；L-3 `history_useless_of_independent`（`GenerationLearning.lean`） |

| 交互的信息可达性 | 世界状态的信息要能以足够的范围与强度到达生物的边界（例如营养斑块的扩散晕大于搜索步长）；可测为"只感知本格的理想觅食者 ÷ 全知理想觅食者"的时间比 | 测得（2026-10-27，雨点世界、雨量 0.05）：全知 30%、局部 2.4%、盲走 0.08%（`nested_forager_bound_20261027.json`）；同一身体在恒定食物 8 下 95% 活过 8000 拍（`nested_maintenance_threshold_20261027.json`）。待证：可达性定理 |

用户 2026-10-27："一个生命体能否学习，不只是取决于它自己，还取决于世界以及它们的交互。自己机制再怎么健全，世界有缺陷、交互有缺陷也是不行的。"生命与可学习性是（生物、世界、交互）三元组的性质；`NestedLife` 的定义本来就在联合介质上。

**实例（2026-10-27，质量作用修正之后的生态位扫描，`nested_niche_sweep_*_20261027.json`）。** 交互的两处缺陷都在世界与交互，不在生物：
1. *交互律错了*：常数池子导通量让整池像一个单元，摄入随 √f 增长、每份食物的扩散随 1/√n 变慢；按 7.1 改成质量作用后，摄入正比于 f。
2. *世界的斑块结构错了*：小而频繁的雨，富集区只有雨点那几格、寿命几十拍；雨一多处处都富，盲走就追上局部觅食者。更快的扩散、更长的食物寿命都把场抹平（梯度淹没在泊松噪声里），感知更没用。只有**少而大**的雨（每千拍一场、每场 ~1.3 万份）让"梯度区 + 长寿的核心"出现：最好的局部觅食者吃到 13.3，盲走 4.1，世界平均 4.7。
3. *量尺也要按物理来*：可行性看脚下食物的时间平均（摄入 ∝ f，储备平滑几百拍），不看站在阈值以上的时间比例；"理想局部"取同类最好的（记忆 1–30 拍、速度 1–10 格/拍），速度 10 比 1 把局部均值从 6.6 提到 13.3——斑块稀疏时，搜索速度决定感知有没有用。
预言（待选择检验）：选出的生物会快跑、会停留在斑块上，并把储备的跨膜交换在贫瘠处关小（质量作用下的平衡会把储备漏回贫瘠的格子）。

**合起来：世界必须有一整段宽的时间（与空间）尺度谱**，每种能力需要谱上的一段。只有一个时间尺度的世界，最简单的活法赢。W1、W2、雨点世界都只有少数几个尺度，所以最多养出"感知 + 短记忆"。这是世界的性质，不是生物的缺陷。

## 第三层：能孕育、且永不停止的世界

| 条件 | 内容 | 状态 |
|---|---|---|
| 永远非平稳 | 平稳世界有固定最优规则（C-1、L-1），生命找到它就退化成固定机器；任何固定规则在任何时刻之后都还会输，当且仅当世界永不平稳 | ✓ O-1 `settled_fixed_optimal`、O-2 `beaten_forever_iff_never_settles` |
| 繁殖与变异在世界内部 | 生命不能从外面设计，须在世界里复制、出错、被筛选 | 待建：Lean 中守恒、可逆的分裂事件 |
| 生命成为彼此的世界 | 持久的非平稳来自别的生命（它们有记忆，制造的环境有相关又不断变化，红皇后）；简单生命让世界更有结构，更有结构的世界奖励更强的记忆与学习：自我放大的梯子，顶端是别的心智（语言生命体的世界） | 待建（多物种生态球） |

## 顺序

1. 生态球第一版（当前）：世界与生物都过准入门，网页可无限运行。
2. 尺度谱定理：把 C-1、L-1、L-3、G19 合成一条：世界相关谱缺哪一段，就有不需要相应能力的最优策略。
3. 开放性定理：平稳 ⇒ 固定最优 ⇒ 无限流生命要求永远非平稳。
4. 分裂事件进 Lean 与模拟器：生态球自己繁衍，选择在世界内部发生（取代外部 ES/GA）。
5. 多物种：生命成为彼此的世界。
