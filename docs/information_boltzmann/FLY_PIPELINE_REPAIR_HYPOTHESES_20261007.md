# Fly pipeline repair：竞争假设与前瞻预测预注册（2026-10-07）

状态：EXPLORE。本文独立重构病因并登记待检验预测，不选择赢家、不批准下一轮训练。未查看任何后续机制诊断输出，未运行实验、训练或修改核心代码。候选是可能的解释；必要性与证据到结论仍需独立审查。

## 1. 证据账本与问题边界

以下是父任务给定的已知观测，不是本文前瞻诊断的结果：

- 已完成一个motor-only、预测先于观测的持续个体；3000次fresh训练更新、96000个fresh OWT训练token、98304个总生命事件；每窗口32事件。
- 主终点最后32000个fresh训练target：模型NLL 7.38905，固定词频NLL 7.45343，匹配target优势约0.06438 nat/token。
- 六次active fresh B均比其匹配固定词频参考差；去除各B的最初32个target后，该现象仍存在。
- 来源至运动区1..14 tick的到达路径已经数值验证。对固定delay=14且source/loss同时落在同一个32事件窗口的路径，直接窗口内配对覆盖为18/32；这是边界计数，不是实际信用幅度或能力估计。
- sensory writer与synapse参数的任务梯度非零；head与物理参数以共享任务目标、AdamW lr=2e-4联合更新；硬spike前向使用ATan代理反向。

从这些观测可说：所测训练流有相对固定词频的预quential收益，所测fresh B没有相同收益。不能据此声称传导不存在、writer完全不可训练、全部motor信息无用，或某种bias机制已经成为唯一病根。非零梯度也不等于有用的硬前向位移。

源码检查对象：`core/fly_pipeline.py`、`core/fly_reservoir.py`、`core/fly_bptt_learning.py`、`scripts/ib/train_fly_pipeline_stream.py`。begin接口没有current-token参数；commit使用旧态和一次到达计算；head为pointwise RMSNorm与decoder；32事件边界detach所有物理字段而保留值。固定参考的实际文件/hash、词频数据预算须沿用已完成运行的账本，不能以当前工作树默认路径倒推历史运行的参考。

约束：感觉区唯一观测写口，实际motor区唯一读口；生产个体never-reset；无token→decoder捷径；4GB；专业OWT；不新增toy能力任务；3000次联合更新是已有最低曝光要求，不是收敛保证。本文不启动下一轮训练。

## 2. 三个结构不同的问题表述

1. **条件概率问题**：训练流上的收益能否转移到fresh B？差异出在边际概率校准，还是在从motor变化提取条件信息？
2. **持续状态问题**：A→B切换时，旧context留在conductance、ring、ALIF、STP及writer baseline中；正确传导的B刺激是否被旧状态改变了作用？
3. **学习动力学问题**：联合更新是否给出了有效的任务位移？有限历史信用、代理导数和Adam位移是三个不同对象，不能用一项非零范数将其一并证明。

隔离提案：先前的bias解释、额外Gamma、settle、多视界头、变分读出均不是本文的预设答案。先判别病因，再决定是否有结构修改的必要。

## 3. 正交竞争假设

### H1：词表边际校准与条件项失配

**因果轴**：head输出概率几何。个体对所遇训练文本形成的边际或共同logit偏移，在fresh B上失准；条件信息可能仍然存在。

**当前边界**：训练优于参考、B劣于参考与此相容，但不能区分bias参数、Wread共同背景与decoder条件项。bias-only不是固定unigram；动态logits也并非纯条件项。

**前瞻P1**：在同一到达态、同一参数快照、同一已评分真实B targets上，登记原始head与预先规定的固定参考校准反事实。若校准反事实同时减少相对原head的损失、且保留非零motor条件项时获得相对固定词频的正收益，支持校准失配；仅令动态项为零回到unigram是恒等结果，不能支持此病因。

**反证/歧义**：若合理的预登记校准方向不能解释B excess，而条件变化仍使其变差，转向H2/H3。只改善一个事后挑选的alpha或bias-only分数属于歧义，不构成机制识别。

### H2：当前motor表征缺少可迁移的目标相关性

**因果轴**：表征与任务用途。物理响应到达motor，但其内容无法以当前head从A迁移到B；可包含有变化但主要无关的表征。

**当前边界**：已验证到达、训练流收益，排除了“根本没有通路”的泛化解释；二者不能证明fresh B的条件信息充足。现有head失败也不等价于motor中信息不存在。

**前瞻P2**：在同一真实流到达态与head参数下，预登记地比较完整motor特征与用过去已观察特征形成的共同特征反事实，不使用B目标挑选特征。若真实事件变化持续提高A预测却不能提高B预测，且P1校准不恢复B的条件收益，支持“当前表征/head组合不迁移”。

**反证/歧义**：若B的事件变化在控制校准后提供稳定正收益，否定“没有可用B条件信息”的局部说法。冻结head的负结果不能证明全体motor信息不可解码；未经独立训练的替代decoder失败也不能证明不可解码。这里的最强可检验对象是当前表征/head组合。

### H3：持续物理状态的context切换代价

**因果轴**：完整物理状态与输入的交互。B脉冲进入已有A状态后受到适应、资源、conductance、writer baseline或环中旧脉冲影响；已到达并不等于已适合B预测。

**当前边界**：去掉B前32事件后仍差，削弱了“只有第一桥接token或不超过14 tick的直接传导延迟”的解释；更慢状态和递归路径仍未被排除。

**前瞻P3**：从完整已存生命周期态建立只读诊断分支，固定参数并使用真实B后续输入；分别跟踪各物理字段的旧context响应和motor/head响应。若超出直接到达时间的B excess与特定持续字段的衰减/重整一致，并且完整状态—参数同步反事实解释了该差异，支持状态切换路线。任何反事实都必须同时包含h、ring、ge/gi、b、x/u、baseline；不冷启动、不改生产态。

**反证/歧义**：若相关完整态差异已降到底噪而B excess仍在，否定该状态残留的局部解释。参数保持的分支不能证明真实学习恢复；把h单独覆盖、或让两分支拥有不同真实文本曝光，不能识别该机制。

### H4：跨32事件边界的参数信用缺失

**因果轴**：可微时间历史。值持存的慢态与长路径在detach后失去其进入态对参数的依赖；模型可有记忆，而学习只看到短期后果。

**当前边界**：delay14的18/32配对证明部分可达且部分跨界，不证明实际遗漏项大小。writer/synapse梯度非零不能排除遗漏。

**前瞻P4**：用同一完整前向轨迹、同一个已评分目标，比较截断梯度与包含进入态参数切线的参考；对固定spike光滑诊断分支，登记

    g_history = g_window + (∂L/∂z_enter)(∂z_enter/∂theta).

若遗漏项高于数值底噪、改变实际候选位移的方向预测，而且其来源落在跨界的已验证路线/持续字段，支持局部信用偏差。

**反证/歧义**：遗漏项在充分涵盖相关历史的参考中仍低于底噪，或不改变相关方向，否定该局部解释。仅把评分窗延长并改变目标集合不是同一比较；只能做单32事件probe时，H4保持未检验。上述等式针对光滑参考，不将其冒称硬spike的普通导数。

### H5：代理梯度、实际Adam位移与硬前向不一致

**因果轴**：优化信号与执行映射。解冻body后，阈值/reset/ALIF/STP路径的代理信用，或保存Adam矩形成的位移，不能按代理线性预测改善真实硬前向。

**当前边界**：没有当前阶段的已登记finite-response结果；非零梯度仅证明算法有路径。不得把所有损失上升预先归给代理导数。

**前瞻P5**：同一完整状态、真实窗口、原始梯度与保存的两组Adam历史，登记实际post-clamp位移Δtheta：

    d_sur = g_ATan · Δtheta.

对预登记尺度比较硬前向与固定全部spike的光滑分支；后者以自己的g_fixed·Δtheta验证Taylor响应，不能拿g_ATan代替其普通导数。

- d_sur>0且高于底噪：先定位实际优化位移非下降，不要求代理不一致解释。
- d_sur<0、光滑分支通过自己的数值检查，而硬前向出现可重复异号：支持硬事件/代理方向错配。
- d_sur与两分支均下降：否定该窗口、方向、尺度上的错配。

**歧义**：单尺度非线性、底噪内响应、不同起始态、丢失一个优化器或clamp，均不能裁决。单窗口机制结果不升级为3000更新的长期因果结论。

### H6：联合学习的head/body共同适应不足

**因果轴**：子系统学习时间尺度。body改变motor特征的坐标和分布，head同时追逐这些变化；等learning rate不等有效学习速度，fresh B可能暴露这种共同适应缺口。

**当前边界**：本次没有冻结body对照或同态更新交互的决定性结果。H6可在每个局部方向都下降时成立，故与H5不同。

**前瞻P6**：在同一个原始state/参数点和真实窗口，预登记head-only、body-only、joint实际保存Adam位移的局部损失响应；所有点都保留完整状态并仅作为数值分支。定义

    I = ΔL_joint - ΔL_head - ΔL_body.

若两组独立方向改善而joint的正交互残差超出数值底噪和小步平滑残差，支持局部耦合代价；若joint响应近似相加且更好，则否定该局部代价。

**歧义**：正I只说明该尺度的交互，不证明head追踪滞后。共同适应的长时主张需之后独立批准的充分真实流比较；本轮不做下一次训练。

### H7：motor post-reset电位读口丢失高驱动事件信息

**因果轴**：具体可观测量与reset几何。源码begin把motor读成 `v_pre * (1 - SpikeFn(v_pre - threshold))`；同tick的motor spike/STP输出脉冲存在，但没有作为head的直接读特征。超过阈值的电位被该读口置零。

**数学事实与当前边界**：对固定threshold，任何两个不同的v1、v2只要都越阈，就有h_post(v1)=h_post(v2)=0；这是post-reset电位映射的非单射性。它证明这个字段可以合并不同高驱动状态，不证明被合并的差异具有词预测用途，也不证明现有未spike motor单元无法携带这些信息。没有新测量。

**前瞻P7**：在同一个pre-observation时刻，从既有真实历史形成的完整态，只读记录实际motor v_pre、h_post、spike及STP transmitted pulse。若因果变化在v_pre或脉冲中超过底噪、却在h_post中被reset抹去，支持该局部观测损失机制；所有候选字段必须只来自真实motor、由oldring产生，不能包含current target的感觉积分。

**反证/歧义**：若相关事件变化已由未spike的h_post单元完整保留，或motor根本未发生上述reset损失，就否定所测局部路线。把训练于h_post的现有head直接用于v_pre而得到较差NLL，是校准失配，不证明v_pre无用；把替代字段的norm变大当成语义收益也无效。任务用途需要后续独立批准的、相同曝光/容量的读口比较；本轮不训练、不改读口。

**与其他候选区别**：H7是测量映射丢失，H1是已观察特征的概率校准，H2是当前表征/head组合的跨context用途，H5是参数更新与硬前向的一致性。H7可以在P5的更新完全有效时仍然成立，不可混成“背景梯度”或“代理信用”的同义说法。

## 4. 必要性与数学闭合

以上七个病因均为**可能**，没有一个仅凭现有风险观测达到“必要”。必要对象是以下可推导的一致性条件：

1. **因果信息集必要**：每个p_t由当前target到达前的物理态、过去观察及过去参数更新历史决定；当前target只能在封存后评分/写入。没有此条件，预quential风险定义失效。
2. **同目标风险必要**：模型与固定词频必须评分同一targets，包含声明的桥接target。令q为固定参考，实际logits写为log q+δ（允许加无关标量），则

       L_model - L_q = mean_t[log Σ_v q(v) exp δ_t(v) - δ_t(x_t)].

   这包含共同背景和条件变化；不能从bias-only或logit范数推出各项任务用途。
3. **精确历史信用的遗漏项必要**：若进入态依赖theta且该依赖影响损失，完整光滑历史梯度必有进入态切线项；32事件detach不含它。但它是否足够大、有用或足以解释B失败，均待检验。
4. **实际优化位移必要**：Adam矩、weight decay与clamp使Δtheta不等于简单的−lr*g。只有实际位移才能检验优化方向；必须覆盖两优化器及全部当前训练参数。
5. **硬事件评分不能冒充普通导数**：ATan是登记代理，不是硬spike阈值的普通导数。代理预测与硬有限响应需分别验证；这并不推出代理必然无效。

“增加delay”“冻结body”“固定bias”“换局部ELBO”等修复均尚无必要性证明。传导1..14存在不意味着所有有效路径只长14；当前目标到达前缺乏目标自身是因果要求，不是系统缺陷。

## 5. 决定性最小诊断集合与停止规则

本文件只登记设计，不执行。对任何之后批准的机制检查，固定同一个生产checkpoint副本、完整物理/优化状态、真实OWT来源、参数分组、目标和预先选择的窗口；不选择“表现最好”的诊断窗口。

最少信息集合：

- **head风险与观测分解（P1/P2/P7）**：区分边际校准与当前motor条件用途；禁止用alpha=0的恒等unigram冒充修复成功。
- **实际位移与双前向分支（P5/P6）**：区分优化位移、代理错配和局部共同运动；检查同态完整性。
- **状态/信用归因（P3/P4）**：仅在前两项不能定位矛盾时检查完整持续态与进入态切线。没有足够历史或完整字段时登记未检验，不以h-only替代。

每个标量/字段在诊断前固定数值底噪定义：同态同参数同刺激重复、identity/零位移及声明精度的一致性上界。只有超过其对应单位的底噪才判断符号；若经验底噪为零，需要显式浮点误差界，不能将任意tiny值当作精确效应。物理字段分别报告，不把不同量纲混成一个“完整态范数”。

所有前瞻预测使用支持/局部反证/歧义/未检验四种结论。若数据检查或身份检查失败，停止解释机制；若P5显示d_sur>0，优先诊断实际更新法；若P1/P2显示B有条件收益但总风险差，优先检查校准；若均不能解释，再处理P3/P4。局部阳性不自动授权长训或新结构。

## 6. 替代解释、假胜利路径和研究树接口

- 完整训练语料词频q的离线数据预算与个体96000 fresh训练曝光不同；它是用户要求超过的固定实用参考，不能把未超过它直接改写为物理架构不可能学习。
- fresh decoder初始化修复与时序修复是独立变更。现有结果不能将收益唯一归给timing，也不能把历史checkpoint的失败重新归给fresh-init缺陷。
- 六个256-target B段、单seed和非平稳主动学习构成有限证据。去掉前32仍差削弱短桥接解释，却不消除更慢适应、文本差异和更新历史；需保留完整及预声明去桥接结果。
- active B/replay会真的更新同一个体。B是首次见到这些验证targets的主动预测风险，不是参数冻结、未学习的传统held-out风险；replay必须单列。
- 共同背景在旧阶段曾主导decoder缓存梯度，居中后已明显缓解。不得把旧倍率迁移成当前全部body学习的病因。
- 禁止由脉冲峰推语义收益、由非零梯度推有效信用、由局部头校准推整体学习成功、由主终点训练流收益推fresh B泛化。
