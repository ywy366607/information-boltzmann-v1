## 3. 待实机判定的问题

C2局部目标依赖当时支持、查询、行动和到达后果；同版本只保证结算口径相同，不保证不同支持情境下的收益相同。当前收益头显式输入没有支持/查询，但source潜状态可能携带其中部分信息。

首个受控配对固定真实source/action、参数、共同查询与目标，只改变实际支持。分别观察后果分布、事前expected、固定真实incoming的有限U净用途、裸预测、采信后延续价值及总排序；相同事实换序作阴性对照。

- 预测分布不同，不自动意味着用途不同。
- 读入相同而用途不同，可以复现表示别名；不能单凭它宣称解释了当前采信0。
- 真实incoming用于事后反事实评分，不进入事前预测。
- 支持情境、旧标签及当前读出是否相容，须用当前实际材料判定，不能先改标签或加状态。
