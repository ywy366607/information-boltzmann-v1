# 无限嵌套：有限身体、无限层级与粗粒化（2026-10-26）

问题：将生物放进世界、世界再放进更大世界，无限重复后，是否有共同的极限状态？本轮直接推导条件性质，不为得到某种生命/智能现象添加一般公理。证明在 `lean/CGBAxioms/reviews/infinite_nesting_20261026.lean`，不进入生产模块清单；数值不是能力实验。本轮不改变主路线或训练个体。

## 先区分三个数学问题

1. **同一有限身体的区域包含**：`O₀ ⊇ O₁ ⊇ ...`，或反向向外扩张，所有层都用同一批底层单元。
2. **增加真实内部状态**：每一层引入新的可区分自由度。每个有限深度可以是有限模型，但其极限未必仍是有限模型。
3. **粗粒化表示**：把一个复杂内层编码为外层一个格子的局部状态，或只观察内层的部分信息。前者需要付完整状态容量，后者需要证明动力学闭合。

现有 `NestedWorld.axioms` 证明给定有限内层的具体联合构造满足六公理；它没有构造无穷递归类型、无穷跳跃过程或无穷路径测度。无限语法包装、无限独立物理层与无限时间经历是三个不同概念。

## 本轮 Lean 已证的五组结果

| 结果 | 精确前提与结论 | 对应证明 |
|---|---|---|
| 有限区域层级会稳定 | 递减有限集链最终恒定。若前n次都严格减少，则 `n+|Oₙ|≤|O₀|`。最后一次变化可以任意晚，不能以单元数界定稳定索引 | `finite_regions_stabilize`、`strict_region_depth` |
| 无限独立层不能装进有限全状态 | n个独立可选布尔量若能编码进完整状态S，则 `2^n≤|S|`。不存在对所有n都成立的这种编码 | `independent_bits_bound`、`no_unbounded_independent_bits` |
| 有效层数受累计预算约束 | 若前n层的非重复费用或同一串行路径延迟各≥ε，累计≤B，则 `nε≤B`。ε>0时不可能所有前缀都受同一有限B约束 | `depth_budget_bound`、`no_uniform_cost_infinite_depth` |
| 静态重复冻结不产生新驱动 | 冻结O外部再冻结P外部，恰好等于只允许O∩P内改变。对可数层的交集冻结仍保持原详细平衡权重 | `freeze_twice`、`infinite_freeze_balance` |
| 藏起内层会丢失动力学闭合 | 存在非负、对称的微观跃迁速率及二值观测，无法用只依赖当前观测值的粗速率精确描述所有微观初态 | `reversible_projection_not_closed` |

第三组的累计合同是额外条件，不是由几何包含或六公理直接推出：并行层的截止时间不是延迟之和，同一物料不能按包围层数重复收费，持续补给也会改变固定总预算。空间层级稳定与时间轨迹是否停止同样无关；区域不再细分，身体仍能无限继续变化。

作为第三组的精确对照，`geometric_prefix` 和 `geometric_costs_fit` 证明每层费用 `2^(-(k+1))>0`，但前n层总费用恰为 `1−2^(-n)<1`。因此“无限多项都为正”并不推出总量无穷：真正不允许的是每层都有共同正下界。这个几何序列可由有限规则描述；如何逐层寻址、分辨和执行，以及完整状态是否有限，仍须另计，不能仅凭费用可求和就声称构造了无限介质。

第四组只针对固定的区域族以及原细状态空间上的对称冻结，不是把外部积分掉后的有效动力学。它说明没有凭包装产生新的平衡稳态流或持续能源；满足详细平衡的系统仍可从非平衡初态松弛。状态依赖的身体边界、移动和时变冻结协议须另验反向对称性。

## 一个有用的反例：外层的“记忆”可能来自被隐藏的内层

取微观链 `0 ↔ 1 ↔ 2`，两条边的正反速率均为1，它对均匀权重满足详细平衡。外层只看 `A={0,1}`、`B={2}`。

- 微态0被读为A，去B的瞬时速率是0。
- 微态1也被读为A，去B的瞬时速率是1。

所以没有一个统一的 `A→B` 速率能对所有微态精确闭合。外层需要保留能区分0与1的额外状态、内层条件分布，或明确登记近似。历史可以帮助估计隐藏态，但本反例不指定必须使用哪一种资格迹、神经机制或推断算法，也不声称所有初始分布下粗过程都非马尔可夫。

这把一个架构问题变得具体：**每套一层后，外层保留的状态是否仍足够决定所需未来响应？**复用已有的 `history_readout_exists_iff`、`history_transition_exists_iff` 与 `CausalState` 检查这个条件，比直接宣称递归越深越智能更有约束力。

## 能谈怎样的无限极限

无限嵌套本身不选出一个唯一状态。固定有限载体可能达到区域层级的稳定，但不是动力学停止；不断增加独立自由度会离开有限身体类；可求和的层级代价允许形式上有无穷多层，却仍需一致的状态投影、有限速率/不爆炸条件与实际表示预算。

这里没有证明临界性、分形、意识、智能增长、非平衡稳态或完整生命。这些可以成为后续有明确模型和预测的研究问题，不是嵌套操作的自动结论。对“逐层细化观测”的相关状态情形，有限S只有有限多个可区分类别，严格信息细化不能无限继续；这可作为既有容量定理的下一应用，本轮不另加定理。
