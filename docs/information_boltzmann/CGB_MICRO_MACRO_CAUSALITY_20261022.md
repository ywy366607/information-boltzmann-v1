# 从微观交换到时间方向、记忆与学习

2026-10-22。用户以邓煜、Zaher Hani、Xiao Ma从牛顿动力学到流体方程的工作纠正推进方向。本文件约束后续统一过程：学习的有效方程应从允许的物理交换和保留的相关性推出，V2原型是参照，不能将STDP/BCM作为额外目标安装。

## 原论文提供的路线

[2024年原论文](https://arxiv.org/abs/2408.07818)在稀薄硬球、给定初始统计与Boltzmann–Grad尺度下，从可逆粒子动力学推导玻尔兹曼方程，控制碰撞历史的相关项，使推导延伸到玻尔兹曼解保持所需正则性的长时间。[2025年续篇](https://arxiv.org/abs/2503.01800)连接流体极限，得到不可压Navier–Stokes–Fourier及可压Euler等方程。

这不是给牛顿方程添加耗散规则：微观相互作用、初始统计和受控的极限共同决定宏观描述。时间参数和微观演化在出发点已经存在；宏观不可逆性的形成还涉及初始相关结构与所保留统计量。不能把“可逆微观规律”与“只看少数变量得到的耗散过程”当作矛盾，也不能将这项工作说成从F=ma凭空创造时间或所有意义的因果性。

## 对当前生成核的具体要求

1. 明确有限物理状态及局部交换。当前q/P/D/r/C/物料/几何给出一套候选有效层；OU热浴、构形跳变率和激活势垒已是本构假设，尚不是从硬球等更底层运动导出的定理。局部详细平衡约束正反比，不唯一规定状态图、共同势垒与时间尺度。
2. 用原相互作用形成历史相关性。快电荷改变原事件亲和，事件改变驱动组成和载体，支持改变寿命和后续交换；这些过程可以保存或抹去历史。程序推进一个时间步不是时间因果形成的证明，改变输入顺序后产生不同随机路径也不等于选择性学习。
3. 对消去的自由度交代闭合依据。碰撞产生的相关性不能每段强行清零；同样，不能为了一个短状态公式就把实际痕迹、有限资源与传播历史重置。已有V2中的多级慢状态提示哪些相关性可能要保留；只有确认现有状态无法承载所需相关性时，才引入有物料/储能/速率来源的状态。
4. 学习的验收落在选择性保持与未来功能。输出分布熵、热力学熵、微观相关性和预测收益分别计量。噪声引发的结构分歧不能单独升级成记忆；实际世界中可重复且有后续用途的历史贡献才是下一目标。

## 消元为什么可能产生记忆

对固定投影P和Q=1−P，将同一生成元L作用的可观测量分成保留与未保留两部分。在算子表达成立的范围内，按块精确消元得到：

    du_P/dt = PLP u_P + PLQ exp(t QLQ) u_Q(0)
              + ∫_0^t PLQ exp((t−s)QLQ) QLP u_P(s) ds。

初始隐藏相关性和历史卷积来自同一个L，没有另造“记忆奖励”。只有相关时间足够短、尺度分离及误差得到控制时，才能把它约成即时Markov有效率；否则应保留所需自由度。这是本项目借鉴的推导结构，不是把稀薄硬球定理直接套到当前生成材料上。

## 当前证据如何改变下一步

[时间次序检查](CGB_NATIVE_TIMING_RESULTS_20261022.md)已在完整个体中执行32实际字节、16诊断分支及共同未来热浴控制。不同历史确实留下慢物料/配置差异，并可在清除快速电荷后改变未来交换；但差异幅度与同次序不同噪声的差异相当，尚未验到选择性时序保持。此时正确下一步是分析哪些相关性被支持留存、哪些仅反映随机周转，并推导它们的保留/释放条件；不因尚未复现V2某一窗口就先加“配对规则”或人为强化记忆。
