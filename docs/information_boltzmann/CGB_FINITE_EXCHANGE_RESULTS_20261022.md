## 实际新增

支持只在游离、接触处结合、搬运后释放的形态间转化；每节点的有限驱动组成分为高／低能态。运输既可正向消耗高能态，也可反向回收。由声明的状态能和占据熵确定正反偏置，共同势垒参数决定速度。

结构处有三种有限占据：未安装U、已安装空位S、已安装结合态C。结构量n=S+C，U+S+C=K。新增结构事件消耗同一局部底物与高能态，拆解回收底物并允许逆向能量转换。

    支持结合：F + S ⇌ C
    支持返回：C + P ⇌ H + S + D；H ⇌ F
    结构转化：B + U + P ⇌ S + D

维护与重组现在可以由同一占据／转化图研究：在本候选允许的通道中，C需先回到S才可拆解，得到支持的部位因而具有不同寿命；不再额外乘一个人为保护系数。但“直接拆除结合态可忽略”是明确的势垒／时标假设，必须校准，不是守恒唯一推出的结论。

## 为什么有物理收支

同一自由能包括游离形态的混合熵、U/S/C有限占据熵、以及支持结合、结构和驱动态的储能。每对正反通量满足其状态自由能差；没有独立的预测奖励或结构目标函数。

内部支持组成、结构底物组成、驱动组成分别守恒。闭合等温子过程G不增加，内部能量改变与浴热相配。离散隐式推进也会带来数值耗散，不能把有限步的全部G下降都当作真实连续模型的物理熵产生；时间收敛单独验证。

结构增长现在实际扣减B与P；不只是“提出增长请求，再按库存裁剪”。它仍只是一个声明了理想混合、有限位置和允许转化图的物理本构候选，能量／容量／速率还没有从连接统计或具体载体校准。
