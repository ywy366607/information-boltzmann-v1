# 身份规则到移动材料：实施前推导与识别边界

基线cccdd06。复用Claude路线中已交付的发生与有向条件强度程序，不重训/改写其统计成绩。目标是把这些身份参数接到实际相遇后的同一物理反应，而不是复制成年邻接表或另抽一个永久Bernoulli开关。

## 1. 从相对条件概率到识别自由能

已有发生程序的条件log-odds可分为几何项b(g)与有向身份项h_o(a,b)。在同一接触几何、物料和其他状态下，两身份的条件odds比为exp[h_o(a,b)−h_o(c,d)]。以原材料测度P0为参考，满足这些相对条件比的最大相对熵分布为：

    P_id(s) ∝ P0(s) exp[Σ_actual_bridge h_o(type_pre,type_post)]
    F_rec(a,b) = −[h_o(a,b)−mean_reference(h_o)]   (kBT=1)
    G_id = G_material + Σ_bridge F_rec

参考平均在原3000类型的均匀有序对上，利用码均值计算，不建立900万项表。去掉同一常数的规范自由度后，不把发生模型的几何/偏置重复加到已实际相遇的材料上。这是**对新材料的相对条件识别势的逆标定**，并非声称成年果蝇在热平衡或该分数就是其真实分子结合能。原发生模型仍是其原数据上的有效条件律；这一步声明了使用它配置新材料时的参考集合与条件。

物理端不能只写一个自由能名字。静态条件比只识别F，不能识别U与构型熵的分解。令α∈[0,1]为明确的材料参数：U_rec=αF_rec，构型自由能贡献(1−α)F_rec。α=0/1给两种合法载体，前者把识别差存入未分辨内部配置的相对配分权重，后者存为势能。G和结构条件概率相同，但热账不同；本轮两种都核对，不能由同一静态数据强行判定α。每次桥形成/断开计入相应ΔU和ΔG。

有向身份允许a→b和b→a为不同的极性桥，二者都支付双方端与材料，允许互惠，不把生物数据中的两方向强行设成互斥。基础未赋身份核仍保留原单桥语义；新核通过同一端库存容纳不同极性。

## 2. 强度身份项到输运物性

条件强度程序log强度中的身份部分h_s(a,b)与其几何部分分开，统一参考中心化。对同一参考接触，继承其相对输运规模，声明新材料的Onsager系数：

    L_ab = L_reference exp[h_s(a,b)−mean_reference(h_s)]

其物理含义是**单位已付款桥材料的输运物性**，不是凭空创建exp(h_s)个不付材料的桥，也不是把条件强度偷当发生率。L_reference有待测/可学习的单位转换；这里没有用统计模型来识别毫秒或绝对电导。相同身份系数乘共同正反电荷转化尝试率，保持亲和不变；被动电导与其同温涨落方差同时使用该系数。该形式对应局部线性输运/势垒的对数参数化，继承的码提供局部物性参数，热力学并不唯一决定其数值。等同生物突触数与物理电导的实证校准仍未完成，保留为可证伪的物性接口，不列为逆发育功能成功。

只有活动/桥存储承担的原反应仍会改变r、c、有限P/D与结构；身份不直接发奖励，不调用优化器改活体状态，不设发言/分叉目标。任何遗传参数变化都须保留来源并计入储能变化，不能悄悄换码。
