## 2. 嵌套的定义（草案）

**N0 一个宇宙。** 只有一个联合介质 `J`，单元 `U = U_生物 ⊔ U_世界`（世界里也可以有别的生物）。`J` 自身满足六条公理，它的外边界是最外层的储库（"太阳"、更大的环境）。

**N1 生物是子介质，边界由接触定义。** 生物 = 单元子集 `O ⊆ U`。它的边界**不是声明的**，而是 `∂O = {u ∈ O | 存在 v ∉ O 与 u 接触}`。交互就是参与者跨越 `O` 内外的普通事件。于是：
- 局部性（P1b）对交互自动成立；
- 守恒（P2a）对交互自动成立：含量在两侧之间转移，不凭空产生；
- 平衡环境下的细致平衡（P2b）由整体给出；
- 储备、成本、死亡都必须是 `O` 内单元的含量与事件，不能是外部代码。

**N2 递归。** 子介质的子介质仍是子介质（线粒体在细胞里，细胞在身体里，身体在集体里）。"世界"只是相对于某个子介质的补集，本身没有特殊地位。

**N3 无限信息流是时间上的，不是空间上的（用户更正，2026-10-26）。** 生命定义的"近乎无限的信息流"指世界随时间持续产生新信息。一个小盒子只要一直随机演化，就是无限信息流。初稿把它写成空间尺度前提（"生物只接触世界的极小部分"），这是错的，已撤回。
- 环形世界的真正毛病不是小，而是**不产生信息**：峰固定、食物按确定性方程再生，生物摸清一次就再无新东西，所以盲游最好。"上帝"式的全知来自世界是死的，不来自世界小。
- 世界写成满足公理的介质后，事件速率有限、跃迁随机，被外边界驱动时落到非平衡稳态，边界刺激是熵率为正的过程。所以 N3 不作前提，改为要证的定理 T-N7。
- **比较（趋化）是否必需是现象，不是本质**：取决于世界的时间尺度（源的寿命、找到它所需的时间、储备能撑多久）。应写成条件定理与预注册预言，不能为了逼出比较去调世界。

**N4 运动。** `Medium` 的接触关系是静态的，所以"生物在世界中移动"必须由状态表示。候选（待定）：
- (a) 相对运动：生物的边界单元固定，与之接触的世界单元的状态随运动被"搬运"（世界流过生物）；
- (b) 位置是含量：生物占据格子是格子状态的一部分，移动是生物单元与世界单元交换位置的事件（滑翔子式）；
- (c) 接触关系带状态（要改语言，代价最大）。
需要先判定哪一种在公理内、且不引入外部规则。

## 7. 大肠杆菌世界的联合介质（设计，2026-10-26，实现前写定）

**两层嵌套。** 推出的大肠杆菌是一个全混合的反应锅（约 1500 个单元两两接触）。把这些单元摊到世界格子上再移动，会破坏内部的全接触（接触关系是静态的）。所以按 N2 再套一层：在世界尺度上，一个细菌就是一个格子；该格子的局部状态包含细菌内部整个反应锅的状态，这是更细一层的介质。

**世界介质 `W`。** 环上 L 个格子，相邻接触。格子的局部状态 = (食物份数 n ∈ 0..V，废物份数 m ∈ 0..V，细菌部分 ∈ {空} ⊕ {内部反应锅的状态})。

| 事件 | 参与者 | 公理 |
|---|---|---|
| 内部反应 | 1 个格子（细菌所在） | 内部 tableCRN 的规则；P2b 由内部介质给出 |
| 感知（受体结合/解离） | 1 个格子：受体单元与本格食物交换份数 | 由 T-N4，本格是势 ≈ ln(n/V) 的储库 |
| 进食 | 1 个格子：储备页 E 从本格食物取份数 | 守恒；进入身体的才算储备 |
| 排废 | 1 个格子：废物页 D 把份数放进本格废物 | 守恒 |
| 移动 | 相邻 2 个格子：交换"细菌部分"，食物与废物留在原地 | 局部、守恒；速率读马达单元的状态（参与者的状态） |
| 食物与废物扩散 | 相邻 2 个格子 | 局部、守恒，平衡时细致平衡 |
| 世界的外边界 | 少数源格子与外部储库交换食物；废物在汇格子离开 | 世界自己的驱动（P3 对世界成立） |

**储备、成本、死亡都在细菌里。** 储备 = E 页的含量；成本 = E → D 的实际事件（由能量驱动）；死亡 = 生命定义里的"不可恢复"（`Recoverable`，生命门在联合介质上检查），不再由外部代码判定。

- **T-E2 联合准入**：具体的大肠杆菌世界规则表满足 T-E1 的条件（可判定、逐条检查）。

**仍是现象（条件定理 C-1，不调世界）。** 比较是否必需，取决于源的寿命、扩散长度、搜索时间、储备时长；按这些量写成预言。

### 7.1 两个由公理推出的设计约束（2026-10-26）

- **自主运动必须由代谢驱动。** 平衡环境下，相邻格子之间"细菌部分"的交换正反速率相等（P2b），没有持续定向运动。持续向前游的事件必须同时把储备页 E 的一份含量转入废物页 D（前进 = 交换位置 + E→D；后退 = 交换回来 + D→E，被能量差抑制）。朝向是细菌内部的一个状态，翻滚改变朝向。这是主动物质的标准物理，也是鞭毛马达消耗能量的原因。
- **格子层的速率用对称导通量写。** 细菌内部的配对规则在按计数合并后，速率 = κ·(源配对数)·e^{−ΔE_单元/2} = κ·√(源配对数·目标配对数)·e^{−ΔE_格子/2}，其中 ΔE_格子含计数的混合熵（多项式系数）。所以格子介质的一般形式是：速率 = C(x, y)·e^{−ΔE/2}，C 对称。这与已证的 `fromConductance`（所有可逆核都可写成 C/π）一致。

### 7.3 写具体世界时由公理推出的三件事（2026-10-26）

1. **身体本身是物质。** 格子状态 = (食物份数, 废物份数, 可选的细菌内部状态)。若细菌内部全部单元处于 0 态时含量为 0，就会与空格子同为零含量态，违反 P1a（真空唯一）。所以细菌的身体要占一份基本含量 B：细菌不能凭空出现，也不能凭空消失（P2a），死亡留下的是物质。
2. **代谢的驱动来自世界本身的梯度。** 旧模型里储备口与废物口的势 μ_E = 6、μ_D = −6 是手设的。嵌套后，进食是从本格食物池取份数，排废是放入本格废物池；所有单格规则都守恒格子含量。驱动只来自世界的外边界：源格子以高势补入食物，汇格子以低势取走废物。细菌的燃料就是世界里"食物多、废物少"的势差（T-N4：池子的势是 ln(n/V)）。
3. **可以有多个细菌。** 每个格子至多容纳一个细菌，移动只能进入空格子；多个细菌共享同一世界的食物，竞争自然出现，不需要另设规则。

### 7.4 T-E2 的形式化路线

格子状态空间巨大（细菌内部按计数），不能逐状态判定。T-E2 改为对规则族的一般引理：给定内部的 `tableCRN` 规则表满足 M3 的义务，则提升后的单格规则（内部反应按计数、导通量 κ√(源配对数·目标配对数)、能量含混合熵）、受体结合、进食、排废、扩散、驱动移动、翻滚满足 M4 的全部义务。
