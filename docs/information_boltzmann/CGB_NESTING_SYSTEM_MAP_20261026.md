# 体系整理：生物与世界的嵌套、交互的规范（2026-10-26，草案，先审后做）

用户指出：最近"这里改一下、那里改一下"的根因是**没有真正嵌套**。生物是按公理写的介质，世界却不是；两者之间的交互也没有受公理约束。本文先盘点现状，再给出嵌套与交互的严格定义、要证的定理和工作顺序。在本文审定之前，不再改世界或个体。

## 1. 现状：哪些受公理约束，哪些不受

| 对象 | 现在的形式 | 受公理约束吗 |
|---|---|---|
| 生物 | `Medium` + `Axioms`（P1a–P3），Lean 实例由规则表生成 | 是 |
| 世界（Lean） | `Life.World`：任意有限马尔可夫链，`sense : W → U → I` 决定每个单元感到什么，`moves : W → (U → Λ) → W → ℝ` 读取**整个**生物状态 | **否**。不守恒、不局部、不可逆性无要求；"世界只读边界"是额外假设 `ReadsBoundary` |
| 交互 | 刺激 `I` 是抽象标签；生物边界事件与"储库"交换含量，储库是势 μ(I)，不记账 | **否**。含量从储库凭空来去，世界一侧不减少 |

## 2. 嵌套的定义（草案）

**N0 一个宇宙。** 只有一个联合介质 `J`，单元 `U = U_生物 ⊔ U_世界`（世界里也可以有别的生物）。`J` 自身满足六条公理，它的外边界是最外层的储库（"太阳"、更大的环境）。

**N1 生物是子介质，边界由接触定义。** 生物 = 单元子集 `O ⊆ U`。它的边界**不是声明的**，而是 `∂O = {u ∈ O | 存在 v ∉ O 与 u 接触}`。交互就是参与者跨越 `O` 内外的普通事件。于是：
- 局部性（P1b）对交互自动成立；
- 守恒（P2a）对交互自动成立：含量在两侧之间转移，不凭空产生；
- 平衡环境下的细致平衡（P2b）由整体给出；
- 储备、成本、死亡都必须是 `O` 内单元的含量与事件，不能是外部代码。

**N2 递归。** 子介质的子介质仍是子介质（线粒体在细胞里，细胞在身体里，身体在集体里）。"世界"只是相对于某个子介质的补集，本身没有特殊地位。

**N3 尺度前提（世界前提，不是公理）。** 生命定义要求"近乎无限的信息流"。对嵌套的表述：生物一生中接触过的世界单元，只占它所在世界的极小部分；或世界是无界的、随生物所到之处展开的流。这是"不是上帝"的形式化。

**N4 运动。** `Medium` 的接触关系是静态的，所以"生物在世界中移动"必须由状态表示。候选（待定）：
- (a) 相对运动：生物的边界单元固定，与之接触的世界单元的状态随运动被"搬运"（世界流过生物）；
- (b) 位置是含量：生物占据格子是格子状态的一部分，移动是生物单元与世界单元交换位置的事件（滑翔子式）；
- (c) 接触关系带状态（要改语言，代价最大）。
需要先判定哪一种在公理内、且不引入外部规则。

## 3. 要证的定理（全部在 Lean 中）

| 编号 | 内容 | 已有基础 |

| T-N1 | 由接触诱导边界：联合介质满足 P1b ⇒ 子介质只经 `∂O` 感受外部（P3 的"只有边界感知"成为定理）；外部也只经 `∂O` 读生物（`ReadsBoundary` 成为定理，毯子两半都由 P1b 推出） | `blanket_of_axioms`（一半） |
