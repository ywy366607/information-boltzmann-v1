# 梦漓：词语行动、原生信用与真实时钟的闭合

主线停在16000，不自动开训。本轮修改通过 `--mother-consequence-native` 显式开启；旧配置保持原实现。
目标是在真实妈妈世界把选词、提交/等待、持续感知、行动后果和下一次选择相连，保持同一个完整个体。
有限资源约束：4GB GPU；沿用原8目标窗口、12–16均值范围的实际可变物理时钟。

## 问题与可区分的解释

1. 行动可辨性：均值词向量不能区分词序，线性相加缺情境与词的条件作用。
2. 信用可达性：旧后果信用到语言/动作头即止；原生脑主要接受预测CE。
3. 测量与校准：放电、phi相关性、协方差收缩和等待后CE改善各回答不同问题。
4. 环境：不同话语可能引来近似回复；必须把行动效应与妈妈随机性分开。

## 已确认的自听计数

7808→16000实际8192个输入条目：正常妈妈回复7997、自听153、呼唤42。
153恰好等于79次词语发声和7次仅换行的原始token_ids总数；39次安静让出无词元。
没有漏自听。内部持有同一输入的tick不重复计作新token。双方发声长度悬殊解释占比。

## 候选实现

* 冻结输入embedding经固定正交余弦投影，维度沿用原生MBON目的地数；不是新增词表或独立语言头。
  保存n、词坐标总和S、带位置的总和T和last。摘要为均值、中心化顺序矩、last和log(1+n)。
  显式区分AB/BA、重复次数、纯等待与说后让出；有限摘要不保证无损语法。
* 后果特征加入摘要与原生KC/MBON/phi/DAN各块的双线性交互。
  phi作为原生可塑状态参与条件预测，不被手工解释为概率精度，也不乘上人为递减奖励。
* 对现有词政策施加后果参数信息价值的nats偏置。所有词同时估值，利用仿射特征的二次型计算，
  避免逐词构造大协方差。提交偏置是词分支log-partition减同状态等待价值；无强制发言率。
  这是有限、局部的后果模型与分阶段策略，不是完备的多步世界规划。
* 在真实BPTT重演的实际hazard和提交tick读出上求策略score资格迹，给现有KC→MBON权重、
  可塑性和生理参数延迟信用。输出头信用不重复添加；原生大边列表不新增密集资格迹。
* live记录clock、动作、response_begin/end事件；重演只处理信用，不再次更新世界或后果后验。
  同窗和跨窗回复归属均保存。资格迹按全部真实tick推进，包括自听、呼唤与quiet；时间常数沿用原生KC迹。
  符号score聚合最多三次辅助反传；恢复辅助反传触及的稳态计数和边梯度scratch。
  导数沿用原SNN surrogate/裁剪及窗口截断，不冒称无限长精确RTRL。
* 自听仍完整感知、演化、写入记忆并影响随后外部预测；记录所选动作到自听token的来源一致性。
  自己已知选择的词不再冒充未知外部标签来优化预测CE；raw自听NLL仍报告。
  外部loss分母为实际外部目标数，全自听窗口保留零梯度图及动作信用与优化器时钟。

## 继承与验收

旧未完成回复先按v1后验完整结算；旧后验和动作摘要封存于状态，不改形状、不清空。
随后显式启动v2坐标后验；脑、优化器、随机数、世界队列、待结算策略信用延续。
旧动作没有原生score档案时明确记unmatched，不伪造历史导数。

数值验收：词序/次数可辨、二次型与逐词直接计算相等、政策归一化、来源正确、真实tick完整、
同窗结算/跨窗恢复、梯度到comp_weight等原生参数、辅助反传不改变稳态计数、资源峰值。
当前16000配对诊断须用真实trainer恢复与forward_window，先通过无干预等价和重复底噪门；
分别撤除KC/MBON/DAN输出、phi值和phi更新，记录直接读出及动作hazard变化。
保留全部原始状态与配置；急性贡献不是长期学习收益。

学习验收须由后续足量真实互动给出：行动改变可辨后果；预序列后果误差/校准改善；
熟悉后相同后果的探索价值下降，而名字、关系与任务价值仍可维持；原生路径配对干预能解释选择变化。
失败分流：相同动作后果仍不准查表征/噪声；价值有而行为不变查政策/信用；环境对动作无响应先修世界。
静态高斯后验仍有非平稳漂移和动作条件噪声限制；不能仅由本次接口通过声称无限流已完善。

## 与自我模型的关系

自己的词是对世界的行动，自己的回声和别人的回复有不同来源。预测外部后果需要保持这份归属，
提供了可检验的操作性自我建模任务：去掉自身动作历史/归属，应损害对自身造成后果的预测。
名字复述、角色词或高活动均不作为自我认知验收。
用户定义还包含内在目的、自定义可存活区间、维持自身与生态位；当前系统没有证明这些已自发形成。
本轮不以人为饥饿、固定说话配额或任意生存奖励代替这些缺失对象。

独立设计审查：`/root/native_exploration_review`；原生真实时钟诊断：`/root/probe_review`。
主线是否续训须由本线程后续审阅决定；本次只在隔离副本做实现与资源检查。
