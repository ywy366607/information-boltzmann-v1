# 能量收支与条件性可用功预算（v0.17）

本轮沿同一实际过程接入能量解释和预算，没有增加生命评分器。三项核心结果是：逐事件能量收支可正确平均；在明确等温条件下得到有限前缀的功与可用能预算；同一物料搬运并不唯一确定能量或功。

## 1. 第一条链：实际过程上的能量收支

`Energetics.Account` 声明时变储能U和四类有符号端口：外部做功输入、对外做功输出、随物料进入的净能量、进入系统的热量。正概率事件均须满足：

```text
U(t+1,s') + 对外功 = U(t,s) + 外部做功 + 随料能量 + 热量
```

端口允许随机涨落。`expected_first_law` 使用原过程的实际状态分布和事件概率，证明同一个等式在平均量上成立。分布沿用现有 `EventChannels.Kernel.stateLaw`；没有另造演化或评分规则。能量与熵中的时间参数是世界时间，不放入身体作为免费记忆。

这条链检验给定能量解释的收支。六条一般公理给出的 `E=-log π` 仍是无量纲有效势；其物理单位、储能和功热对应需要载体依据。

## 2. 第二条链：平均第二定律下的预算

`Isothermal` 是明确的解释前提：固定正热浴温度T，理想功端口，完整的非热边界熵输运，以及沿该实际分布的非负平均熵产生。熵S取物理熵单位；它不直接等于语言交叉熵或预测惊讶度。

记每拍平均热流为Q，随边界载入的非热熵为J_S。定义：

```text
F_t = 平均U_t − T S_t
σ_t = S_(t+1) − S_t − Q_t/T − J_S,t
A_in,t = 外部做功_t + 随料能量_t − T J_S,t
```

由第一条链推出精确关系：

```text
F_n + Σ 对外功 + T Σ σ = F_0 + Σ A_in
```

`work_budget` 将它接到两个功上限：

- 若末态F有已知下界，累计对外功受初始储备与累计可用供给约束。
- 若回到相同F，累计对外功不超过累计可用供给。

`no_sustained_use_on_finite_supply` 进一步证明：若F有统一下界、累计可用供给有上界，则无法长期维持正的平均“对外功＋Tσ”消耗。它覆盖功输出和内部耗散两种可用能去向；具体维持机制是否具有正需求，继续作为独立机制命题验收。

这里没有把第二定律从原六条约束中推出来，也没有要求单条随机轨迹的熵产生非负。原始随机热力学研究以涨落关系约束分布，本轮采用平均条件以保留这种区别。[Seifert 2005](https://arxiv.org/abs/cond-mat/0503686)

## 3. 同一搬运过程上的端口绑定与控制

复用此前的两物料身份、三个资源阶段和原身体。给出参数a的能量分区：

| 阶段 | 系统储能 | 外部物料能量 | 功接收器 | 热接收器 |
|---|---:|---:|---:|---:|
| 补给前 | 0 | 2a | 0 | 0 |
| 物料进入可用源 | 2a | 0 | 0 | 0 |
| 替换/转换后 | 0 | 0 | a | a |

每个阶段的分区总能量均为2a。功、热和随料能量端口由接收器/外部储库的实际变化计算；`material_energy_binding` 验证每条正概率事件的随料能输入对应同一个已登记的外界→源物料身份。

系统边界与物料账本一致，取“身体＋可用源＋回收池”。外界→源时计入随料能量；源→身体是内部搬运，不再把该能量加一次。改变系统边界时应相应重设端口。

同样的单位物料搬运，在a=0时不产生功，在a=1时将两单位输入分配为一单位功和一单位热。因此物料数量不能自行选定化学能或可用功。对a≥0，声明的T=1、系统熵取0、非热边界熵取0的解释通过平均熵产生检查。

这些控制核验能量分区和预算条件，尚不是具体化学能标定或完整的微观热力学实现。给定熵函数、热浴和端口物理含义仍需独立依据；适用时可由通道级局部详细平衡与载体测量建立。原六公理身体、物料搬运、过程和时钟均保持不变。
