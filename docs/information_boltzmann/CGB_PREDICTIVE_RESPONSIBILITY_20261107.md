# 当前结果修正历史参与：预测混合候选

## 问题与共同转移

schema2已经保住完整局部计算并接通四层旧导数，但128题held/full均0/8，固定当前状态只换旧数字内容的效应约1e-5。缺口是任务相关内容归因，不能继续以非零梯度代替。

本候选schema3保留同一身体、16条/层的实际输入及固定递推边界、原快表和全局经历库。每条旧记录由当前参数重执行。本层当前查询对该记录内位置归一化，形成该记录自己的响应；再通过同一身体的后续原生层得到一个下一字节分布。另有不注入新局部记录的null分布。不同记录的预测先分开，最后才混合概率。

预测前的份额为a，真实字节y到达后的解释份额为r：

\[
p(y)=\sum_i a_i p_i(y),\qquad
r_i=\frac{a_i p_i(y)}{\sum_j a_j p_j(y)}.
\]

唯一的语言目标仍是-log p(y)。对选择logit的偏导是a-r；对每个分布的导数是其自身预测误差乘r。共享参数还经过查询、候选内部重算及当前状态，完整保留这些路径。r只在结果到达之后报告，不作为新奖励或外部责任标签。

**实际递推**继续采用schema2的平均取回转移；上述null/单记录后缀是从相同进入状态执行的有界条件预测，假设分支的递推状态丢弃，不写回实际个体。条件预测没有新增独立网络。候选数最多1+4×16；各记录最长128位置，计算与存储不随总历史长度增长。它是一个明确的有限预测模型，不是重构完整历史梯度。

## Lean依据与适用范围

- `GenerationCountedPopulation.tag_fraction_eq_posterior`：非负、归一化转移及正似然下，标签质量的后验比例等于标签似然/总似然。此处混合概率具备相应非负/归一化性质；不把有符号GDN矩阵直接称为定理中的概率质量。
- `GenerationReinvestment.log_predicted_deriv`、`credit_eq_new_share`：到达结果对分量的信用和更新份额的关系。
- `GenerationClosedLoopCredit.objective_deriv_advantage`：共享预测参数时保留直接评分导数，不只改选择概率。
- `GenerationActiveNavigation.reactivation_exact_held`：旧边界固定的局部重激活导数。

模型内后验表示“哪段候选计算更解释当前观测”；经验因果仍由固定状态的内容干预及后续功能交付检查。不新增Lean定理，不增加身体覆盖数，不嵌入CPU/Lean内核。
