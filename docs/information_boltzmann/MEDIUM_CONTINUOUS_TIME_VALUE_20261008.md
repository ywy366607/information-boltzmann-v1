# Continuous time value: preregistered no-update diagnostic

User target: determine whether measured dynamic information and continued neural
evolution can support better prediction, before new training. The existing
32-target response audit established timing sensitivity, not task superiority.
Its five isolated wait durations are not a learned causal stopping policy.

## Competing explanations and minimal decision

1. Omitted motion is a read bottleneck: test the existing dynamic-read production
   parameter direction on512 subsequent real targets, with field/shuffle controls.
2. An ill-calibrated continuous cadence impairs the current representation: test
   one shared positive time scale, preserving all state through the sequence.
3. An apparent time benefit is integration error: compare1 versus2 substeps at
   the same total duration, and check two shrinking perturbation resolutions.
4. Current frozen representations lack transferable signal: a flat or harmful
   local intervention leaves joint adaptation and temporal-relation readouts as
   separate candidates; it does not certify them as necessary.

The smallest new time test is one scalar, not an untrained content policy or
label-selected per-token stopping. Independent plan review by
`/root/rtc_contract_review` accepts this scope.

## Exact trajectory protocol

Use the same complete96k individual, next1024 actual OWT targets, pending carry
as first observation. For each trajectory start from that same full snapshot,
observe the same inputs, evolve, then predict the unseen next target. Parameters
never change. Every counterfactual carries its own complete state for all1024
events, including across512; this is a read-only intervention, not live-learning
validation. Baseline duration is saved configuration, not a newly chosen number.

For each preregistered numerical resolution epsilon in{2^-8,2^-9}, execute full
continuous trajectories with duration=duration0*exp(+epsilon) and exp(-epsilon).
Select the single downward sign using the first512-target mean difference only.
Evaluate that same sign on the subsequent512 targets of its continuing state;
report both256-target halves and all baseline/positive/negative means. No
held-out tuning, best resolution selection or state reset at the split.

Run a1/2-substep baseline refinement at fixed duration as a numerical control.
Record actual advance calls, elapsed time and parameter hashes for every arm.
Two epsilons check local derivative stability, not tune a model hyperparameter.
If the selected time direction benefits both subsequent blocks and retains sign
under shrinking epsilon, cadence calibration is locally promising. Opposite
block signs or numerical-control effects comparable to the intervention mean
the result is ambiguous; retain those alternatives explicitly.

## Time semantics

The current duration controls both the model's dynamics dose and elapsed clock.
This test changes the relation between token arrivals and those learned dynamics.
It establishes continuous cadence sensitivity/possible local utility, not an
agent's ability to alter real external timestamps or a content-adaptive internal
clock. Fixed external timestamps with an independently controlled internal
rate would require an explicit separate interface. Solver substeps change only
numerical resolution of one total duration; they are not new reasoning events.
