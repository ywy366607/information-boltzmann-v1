## 1. 得到的共同结构

初始化需要审查三次传递：

1. 原始参数经过softplus、exp、sigmoid等映射，形成物理系数。
2. 物理系数与实际S/P、状态幅度、频谱、读出矩阵一起决定可观察作用。
3. 后续误差沿真实资格迹返回，形成Adam方向；预算门控决定实际写入。

同一个表面现象“参数几乎不动”，可以来自不同位置。应分别记账初值、实际作用、返回信用、预条件方向和实际更新。

本次最值得接续的对象是**头间势能的坐标尺度及其学习交接**。当前初始化给了一个有单位的系数0.005；实际头间作用还强烈依赖S的幅度、头间交换几何和自身频谱。这个系数在当前32轮中仅有很小变化，因此当前弱作用主要是继承的工作区间，而非被训练主动压到零的结果。

## 3. 原生出生顺序消除了两个静态阅读误报

`native_navigation_body.create`先构造完整图和各端口，再调用`initialize_native`。该函数遍历全部Linear/Embedding并重新抽取非零矩阵；o_proj和mlp.down使用实际深度的`0.02/sqrt(2*32)=0.0025`，其他矩阵使用0.02。

因此，只读`momentum_to_boundary`、`question_to_hidden`构造器的zeros，容易把兼容迁移设计错认成当前原生身体的出生状态。类似地，GDN构造器里的四层残差常数被原生32层初始化覆盖。当前记录中的实际权重更新进一步验证这些端口已参与学习。

零最终线性端口的数学关系为：y=Wx，W=0时，dL/dW=(dL/dy)xᵀ可以非零，dL/dx=WᵀdL/dy为零。它会延后一部分上游信用；直接端口本身仍可开始学习。只有继续核对完整接线和出生时序，才能判定实际影响。

## 4. 头间作用的尺度关系

生产势能包含双线性交换表达式的平方。固定pair权重时，对任意正尺度c：

    U_pair(cS) = c⁴ U_pair(S)
    F_pair(cS) = c³ F_pair(S)
    F_self(cS) = c F_self(S)
    (|F_pair|/|F_self|)(cS) = c² (|F_pair|/|F_self|)(S)

CPU直接调用原`potential`与`force_analytic`，在c=0.5、2上核对四次、三次缩放关系，误差0；解析力与autograd相对误差1.90e−16。该关系在pair系数为0、权重固定时精确成立；学习后的状态相关权重附加其导数项。

这给出一个具体设计问题：单独统一lambda，无法保证不同状态幅度、频率和头间几何具有相同相对作用。实际频率横跨约128倍；其自身回复尺度也随omega与Z变化。后续候选应围绕每个实际头的无量纲作用强度及数值稳定条件构造，保留已学习S/P及资格身份。

## 5. 对“参数小→梯度小→必然难学”的修正

在lambda=softplus(theta)=0.005处：

    d log(lambda) / d theta = sigmoid(theta)/lambda = 0.99750416

当前正值映射在相对尺度上仍灵敏。

若一段梯度及其整个匹配历史共同乘c>0，则Adam的m乘c、v乘c²；epsilon可忽略时m/sqrt(v)保持。Wiener相干门控里的signal和energy也都乘c²，其比值保持。CPU用生产`coherence_gate`在c=0.001、1、1000核对，结果完全相同。

因此，物理作用弱与优化步小分别取证。实际作用的改变可能改变梯度方向、信噪结构、延迟返回及epsilon相对量级；这些才是需要沿当前身体继续分解的交接。

## 7. 结论与接续

已处理过的初始化事项包括频率分散、完整图非零出生与实际深度残差缩放、记忆非零接入；近期已完成的是角色拆组和标量可学习化。它们分别处理不同交接。
