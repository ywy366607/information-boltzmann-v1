# 以同一带电构形承载痕迹：由位移、储能和反向作用闭合

2026-10-22，本构推导与实现依据，写于新运行之前。基线3b23d56。[当前时序检查](CGB_NATIVE_TIMING_RESULTS_20261022.md)未检出超过噪声的选择性保持；这不先验否定现有状态容量。本轮检查一种明确的物理载体实现，不将STDP、BCM、时序评分或语言损失装入生成核。

## 当前标量载体与一个不同的物理实现

旧载体的r是有内部能的二态构形，r改变导通和支持结合；原write还搬运荷量，但thermal只改变r，其亲和为±(ε_r−χC)，与局部电场无关。这是一种合法的有效材料，不是遗漏了所有材料都必有的项；若载体构形本身不带极化，不能强说它违反物理。

新的物理假设只有一个：**这同一个二态构形包含一对有限束缚电荷。** r=1时在实际定向接触源端形成−z、目标端形成+z，r=0时没有分离的净端荷；z沿用原charge_per_event。电荷对包含在已付款载体的组成里，总荷量为0，未另生成免费物料。微观介质是否具有这个性质，需要识别/选择，不能从守恒唯一推出它一定成立。

内部接触两端是原i/j；边界接触的源端是世界电容，目标端是实际身体端口，支持/燃料所有者仍是身体。此处没有新建神经元类别或额外历史变量。

## 同一个物理构形的所有转化都必须移动它的电荷

记Q为可移动荷量，b(r)为上述束缚端荷，原数组q存实际净端荷：

    q = Q + b(r)
    U = Σ_i q_i²/(2C_i) + Σ_world q_w²/(2C_w)
        + ε_r Σr + ε_C ΣC − χΣrC + 原物料/驱动/几何/身份能。

如果保存Q坐标，同一能量写为Σ(Q+b(r))²/(2C)；代码继续保存q，避免增加一套冗余物理数组。不可再加一份“极化能”重复计算已有电容储能。

write与thermal是到达同一r构形的两条物理通路，所以二者在r增加s时都执行：

    Δq_source=−s z，Δq_target=+s z，Δr=s。

它们均有ΔQ=Δq−Δb=0：移动的是载体内部束缚电荷。write额外P→D，thermal没有这个驱动组成变化。原active不改r，依然搬运可移动荷量。捕获/支持运输与空间相变沿用原计量；只有r=0的裸载体可被回收，所以没有删掉束缚荷却遗漏荷量的情况。

因此在正向构形转化前：

    ΔU_thermal = −z(V_source−V_target)
                 + z²(1/C_source+1/C_target)/2 + ε_r−χC。
    ΔG_write = ΔU_thermal − E_P + log[(D+1)/P]。

所有事件仍使用原α expit(−ΔG)，正反配置满足原局部详细平衡。输入场可偏置构形转化；构形的写入/热回转又真实改变局部场。这是同一电荷位移的互易作用，没有额外“记住重要输入”的评分。

不能只让场影响r，却漏掉r变化造成的端荷，亦不能在允许r变化的不同通路中对同一个束缚构形采用不同位移。旧标量材料没有这项解释，仍完整保留作对照；新材料不是靠改名使旧结果自动成立。

## 支持、通道与空间沿原过程继续

r/C仍通过同一−χrC作用能影响捕获/解绑，r仍改变原导通及同温涨落。新增电端荷会影响原conversion、write、active和域出生/回收亲和；这些后续变化来自同一净荷/电容能，而不是新空间指导向量。原材料库存、端数、身份匹配、几何运动和相变继续生效。总状态维度不增，热通路每事件仅多两个原电荷更新。

这提供一个原生的**输入场—实际构形—支持/输运—后续场与空间**闭环。它是否保留可重复相关性、提高预测或维持能力，需单独测量；不能因写出互易关系就宣称已经产生自我。
