# CGB 核心方程：让物理世界替大脑计算（2026-10-20 草稿）

状态：推导草稿，待讨论。补的是 `CONSTRUCTAL_GENERATIVE_BRAIN_FRAMEWORK_20261018.md` §4、§5 里没有闭合的部分：残差的演化、流的函数形式、第三因子、营养分配、更替和可塑性模板。

## 0. 原则：把物理限制变成白给的计算

生物高效，是因为它几乎所有的运算都交给物理定律去完成：守恒、扩散、饱和、耗竭、质量作用。大脑并不显式地算这些，世界本身就是计算器。

大模型的注意力耗能，是因为每一步都要显式地算：所有位置两两做点积，再做一次全局 softmax。它没有嵌在物理世界里，没有世界替它算。

| 大脑需要的运算 | 替它计算的物理 | 注意力里对应的显式计算 |
|---|---|---|
| 求和、积分 | 膜电容上的电荷守恒（Kirchhoff） | 加权求和 |
| 减法：预测抵消输入 | 抑制电流与兴奋电流在同一处相抵 | 残差连接、显式相减 |
| 除法：增益控制 | 分流抑制：电导乘以驱动力 (E − u) | LayerNorm |
| 乘法：重合检测 | 质量作用：反应速率正比于浓度之积（NMDA 要谷氨酸和去极化同时在场） | QKᵀ 点积 |
| 配对：谁和谁交互 | 空间相遇：只有长到一起的分支才能接触（E1b：几何单独就解释到噪声上限） | 全部 N² 对都算 |
| 归一化、竞争 | 守恒的共享池：总量固定，各方按份额分 | softmax |
| 指数滑动平均、记忆 | 有限速率的清除：dc/dt = 流入 − c/τ | 状态缓存、KV cache |
| 变化检测、新奇 | 池的耗竭：持续输入耗尽囊泡，只有变化能通过 | 无对应 |
| 空间平均、广播 | 扩散：格林函数就是距离加权平均 | 全局向量 |
| 有界、饱和 | 占据型分子的上界 [0, 1] | 裁剪、权重衰减 |
| 探索 | 热噪声：通道随机开关 | 采样温度 |

每一行都是**世界白给的**，代价只是一点能量和时间。下面的方程都只用这些物理，每一条都注明它的必然来源。凡是写不进这张表的运算，都要怀疑它是补丁。

## 1. 状态量（每个元件只有几个标量）

| 位置 | 量 | 物理 |
|---|---|---|
| 细胞（或树突分支）i | 膜电位 u_i；钠通道可用比例 r_i ∈ [0,1] | 电荷；占据型的通道状态 |
| 细胞 i | 快钙 c_i^f、慢钙 c_i^s；营养支持 T_i | 两个清除速率不同的池 |
| 终扣 j→ | 囊泡可用比例 v_j ∈ [0,1] | 有限补充的池 |
| 突触 ij | 受体占据 o_ij ∈ [0,1]；局部钙 c_ij；激酶 K_ij、磷酸酶 P_ij ∈ [0,1]；标签 z_ij；结构 g_ij ∈ [0, g_max] | 占据型分子与池 |
| 空间点 x | 调质浓度 M_k(x)；营养因子浓度 N(x) | 扩散的化学物质 |

身份码 c（谱系码）决定每类细胞的常数：时间常数、受体家族、释放哪种化学物质、阈值。这些常数就是基因组。

## 2. 方程

**E1 膜：电荷守恒 + 驱动力（求和、减法、除法都白给）**

  C du_i/dt = −g_L (u_i − E_L) + Σ_j g_ij · o_ij · (E_{s(j)} − u_i) + I_i^感官

- 兴奋输入（E_s 高于阈值）相加；抑制输入（E_s 接近静息）同时做减法和除法，即分流。
- **预测是反向的抑制流。** 预测细胞把抑制送到感官输入所在的同一隔室上。当预测与输入一致时，兴奋电流和抑制电流相抵，净电流为零。所以"残差"不是另算的变量，它就是膜上的净电流，u 就是框架里的残差势。
- J_ij = g_ij · o_ij · (E_{s(j)} − u_i) 就是 §5 里 J = g·s(c)·f(u) 的具体形式：s(c) 是由身份码决定的反转电位 E_s，f 是突触前释放经受体占据后的结果（E3、E4）。

**E2 放电：钠通道池（阈值、不应期、适应都白给）**

  当 u_i > θ_i / r_i 时放电，s_i = 1，u_i 复位，r_i ← (1 − κ_r) r_i；平时 dr_i/dt = (1 − r_i)/τ_r

可用的通道越少，越难再放电。这个快池（τ_r 几毫秒）给出不应期。**更正（V2 T1）**：它在两次放电之间会完全恢复，不会留下放电率适应。适应需要第二个慢池（钠通道慢失活，或钙激活的钾电流，τ 为数百毫秒到数秒），形式与 r 相同，只是时间常数不同。

**E3 释放：囊泡池（短时程抑制、新奇检测、稀疏都白给）**

  突触前放电时释放 R_j = U_j · v_j，v_j ← v_j − R_j；平时 dv_j/dt = (1 − v_j)/τ_v

持续不变的输入会把池耗尽，只有变化能传过去。活动越多池越空，稀疏是自然结果。

**E4 受体占据与重合检测：质量作用（乘法白给）**

  do_ij/dt = R_j (1 − o_ij) − o_ij/τ_o
  dc_ij/dt = κ_N · o_ij · B(u_i) + κ_b · s_i^回传 − c_ij/τ_c

B(u) 是 NMDA 受体的镁离子解阻断曲线：只有突触前递质在场、突触后又已去极化时，钙才进来。这就是 Hebb 的乘积，由质量作用免费算出。s^回传 是反向传播的动作电位或树突平台电位。

**E5 可塑性模板：钙驱动的两个酶池**

  dK_ij/dt = α_K h_K(c_ij)(1 − K_ij) − K_ij/τ_K       （h_K：高阈值陡峭，激酶）
  dP_ij/dt = α_P h_P(c_ij)(1 − P_ij) − P_ij/τ_P       （h_P：低阈值，磷酸酶）
  dz_ij/dt = (K_ij − P_ij) − m_ij z_ij − z_ij/τ_z      （标签池：§4 的痕迹）

- 钙高时激酶占优，标签为正；钙中等时磷酸酶占优，标签为负。
- STDP、BCM、BTSP，以及果蝇多巴胺的时序规则，都是同一个模板在不同参数区间的样子（§4 的表）。基因组只给参数，不给规则。
- 与 §4 的 dz/dt = |J| − m·z − z/τ 相比，这里把流入项 |J| 具体化为钙驱动的酶池差 K − P。它保留了"流入、转化、清除"的结构，并带上符号。

**E6 结构：标签转化，受饱和约束（权重有界白给）**

  dg_ij/dt = η · m_ij · [z_ij]₊ · (1 − g_ij/g_max) − η · m_ij · [z_ij]₋ · g_ij/g_max − λ_ij g_ij

结构是有限槽位的占据，所以增强按剩下的槽位、减弱按已占的槽位成比例。这里不需要裁剪，也不需要归一化。

**E7 第三因子：扩散的调质加上受体（广播与符号白给）**

  ∂M_k/∂t = D_k ∇²M_k − M_k/τ_M + Σ_{释放 k 的细胞 l} q_l s_l δ(x − x_l)
  m_ij = Σ_k ρ_k(c_i) · M_k(x_ij)

- 扩散替我们算出"附近释放者的距离加权平均"。在图上，扩散退化为调质细胞到它所覆盖隔室的投射，这就是果蝇里每个 DAN 管一个隔室。
- ρ_k(c) 由受体家族决定，Gs 型为正、Gq 型为负，所以同样的顺序可以给出相反的符号。
- **意外的广播不需要写进方程。** 调质细胞本身也服从 E1：它们接收未被预测抵消的输入，所以它们的放电天然就是残差。

**E8 预测怎样被学会：抑制可塑性自动达到平衡（预测编码白给）**

抑制性突触用同一个模板（E5），但突触后的驱动换成突触后自身的活动偏离一个设定值：

  Δg_inh ∝ s_pre · (s_post − ρ_0)

这正是 Vogels 等人（2011）的抑制 STDP。它让每个细胞的抑制精确地跟随兴奋，达到"细致平衡"。可预测的输入被抵消，只有残差通过。所以预测编码不是额外的目标，它是抑制可塑性的不动点。

**E9 营养：按贡献分配，由质量作用免费完成**

  释放：Q_i = q_i · [c_i^s − c_i^f]₊        （活动刚从高处回落：残差刚刚被消解）
  ∂N/∂t = D_N ∇²N − N/τ_N + Σ_i Q_i δ(x − x_i)
  摄取：dT_j/dt = κ_T · a_j · N(x_j) − T_j/τ_T − Σ_{j 的边} φ g_jl       （a_j：终扣近期的活动）
  更替：λ_jl = λ_0 / (1 + T_j/T*)        （受体结合的 Michaelis–Menten 形式，饱和白给）

- **释放：** 两个清除速率不同的钙池相减，就是一个导数检测器。慢钙高于快钙，说明细胞的活动刚刚回落，它刚被"解释掉"了，于是它释放营养。这是 §5"残差下降时释放"的物理实现，每个细胞 O(1)，不需要算比特。
- **分配：** 营养因子在空间里扩散，被近期活跃的终扣按质量作用摄取。谁在残差下降的那一刻正在放电，谁就拿到营养。"按贡献分配"由重合检测免费完成，不需要记账。
- **消耗与存活：** 每条结构持续消耗营养（φ g）。营养支持高的终扣更替慢，得不到支持的边更替快，最终消失；营养长期低于阈值的细胞死亡回收。营养的总产量有限，所以结构总量天然有界。

**E9 修正（V2 T4 之后，2026-10-20）：基础供给 + 标签捕获**

  释放：Q_i = q0_i     （靶细胞持续、有限地分泌，基础产量由身份码决定）
  摄取：dT_ij/dt = κ · [z_ij]₊ · N(x_ij) − T_ij/τ_T − φ g_ij      （只有被标记的突触能捕获）
  更替：λ_ij = λ_0 / (1 + T_ij/T*)

- **为什么改**：T4 显示，"残差下降才释放"会自我瓦解：结构衰减，抵消事件变少，营养随之塌陷。按原始活动摄取，又天然偏向高频终扣。
- **自然界的老师**：
  - 经典神经营养学说：靶组织持续、有限地分泌营养；
  - 突触标签与捕获（Frey & Morris 1997）：有限的可塑性蛋白只被近期标记的突触捕获。
- **结果**：标签 z 来自 E5 的钙 + 酶池模板，它已经编码了因果和预测，所以营养自然流向有因果作用的突触。E9 与 E5、E6 合成了同一件事：**营养是被标签捕获的守恒资源**。
- **原来的"残差下降释放"**（慢钙减快钙）降级为一种可能的调制：它可以放大释放，但不能作为唯一的来源。

**还没解决的问题：**
1. **前馈兴奋边怎样得到营养。** E9 的营养流向在残差下降时活跃的终扣，那主要是预测细胞的抑制终扣。前馈的兴奋边要靠它下游的下游释放的营养（营养随结构逐级逆向传递），还是靠自己突触后细胞的活动？这一处决定了空间信用怎样跨层传递，是最重要的待定项。
2. **预测放在哪里。** 是抑制到同一隔室就够（E8），还是需要两隔室细胞（顶树突接收预测、基树突接收输入；Larkum）？这决定了 E1 要不要分隔室。
3. **E9 的触发是否会被"刺激刚结束"欺骗。** 刺激撤掉时活动也会回落，但那不是被解释掉。区分两者需要输入侧的信息，可能需要用到 E3 的囊泡池状态。

## 3b. 以天地万物为老师：三个待定项在自然里的答案

**方法。** 对每个待定项，去找至少两个彼此无关的自然系统。它们受同样的物理约束，又解决了同一个问题。如果不同的载体趋同到了同一个解，那个解多半是必然，不是偶然，就可以放心用；找不到趋同的，就当作待检验的选择。

**1. 前馈边的信用：守恒的"货币"沿供应链逆向流回。**
- **黏菌与河网：** 食物源造成压力差，网络里各管的流量由 Kirchhoff 定律一次性解出，这是物理替它算的。流过多的管变粗，流过少的萎缩。上游的管道之所以得到"信用"，只因为下游的汇在消耗，流量的连续性把信用传了回去。
- **神经营养的依赖链：** 发育中的交感神经元依靠靶组织给的 NGF 存活；它得到支持后变得健康，才能再支持自己的输入。营养因子经轴突逆向运输回胞体，再从树突释放给上游。
- **生态与经济：** 能量沿食物链、货币沿供应链逆向支付，按各环节的贡献分配。Holland 的"水桶传递"算法（1985）就是这种机制的计算版：规则的强度沿规则链逐级向上游付款。

**趋同的解：** 营养是守恒的货币，逐级逆向传递。一个细胞能分给上游多少，取决于它自己从下游拿到多少；分给哪个上游，按那个上游的活动和它自己的活动是否重合来分（质量作用）。改成方程：

  Q_i = q · T_i · [c_i^s − c_i^f]₊     （自己得到支持，才有能力再支持上游）

于是信用像电流一样沿结构逆向分流，由守恒保证总量不变，任何细胞都不需要知道全局。

**2. 预测放在哪里：同一处的"负像"就够了。**
- **弱电鱼的电感觉叶（ELL）：** 鱼自己放电会干扰自己的感受器。主细胞通过反 Hebb 可塑性学会一个"负像"：传出副本经平行纤维送到同一个细胞上，精确抵消自己造成的那部分信号，只剩外界的变化（Bell 1997）。
- **小脑样结构**（哺乳动物的背侧耳蜗核、鱼的侧线系统）用的是同一种机制。

**趋同的解：** 对自己行为造成的、可预测的输入，在同一隔室上用可塑的抑制或负像就能抵消（E8 足够）。更抽象的、跨感官的预测是否需要两隔室，留给 V2 检验。V2 先只用 E8，看它能走多远。

**3. 怎样区分"被解释掉"和"刺激结束"：比较输入和输出两种钙。**
- **细菌趋化：** 用积分反馈只对变化敏感，同时由受体的占据知道外界的浓度还在不在。
- **神经元：** 本来就有两个来源不同的钙。树突上的突触钙（NMDA，表示输入还在）和胞体上的放电钙（表示输出）。

**解：** 释放的条件改为"输入还在，而输出回落了"，即突触钙高而胞体钙降。

  Q_i = q · T_i · [o_i^平均 − ε] · [c_i^s − c_i^f]₊

刺激结束时输入也消失了，就不会释放。这一条只找到一个半老师（细菌、神经元的两种钙），列为**待检验的选择**。

## 4. 计算代价：为什么它天然便宜

- 每一个池都是指数形式，有闭式解。所以只在事件到来时更新，用"上次更新的时间"补上中间的衰减（惰性衰减），从不全量扫描。
- 乘法、归一化、配对都由局部的质量作用和共享池完成，只发生在长到一起的元件之间。相遇的稀疏性（E1b：72% 的类型对从不相遇）直接变成计算的稀疏性。
- 扩散只需在少数调质和营养通道上做，每类或每个隔室几个标量。

## 5. V2 要检验的预言（每条都只用上面的方程，不加规则）

1. 只有 E2 和 E3：不应期、成对脉冲抑制、稀疏的活动率自己出现，时间常数等于池的补充速率。
2. E4 到 E6：改变参数就得到 STDP 窗口和 BCM 的频率依赖；权重有界，不需要裁剪。
3. E8：给一个可预测的输入序列，抑制会学会抵消它；序列一变，残差立刻出现。这是预测编码的最小演示。
4. E9：营养按"慢钙减快钙"释放时，参与抵消残差的终扣留下来，其余的更替掉；把释放改成"按流过的量"，细胞会挤向高频输入。
