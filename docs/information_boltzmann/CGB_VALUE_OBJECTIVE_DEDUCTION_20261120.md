## 1．可直接从现有身体判定的七项性质

### 1．在线支付直接度量的是有限关系修订

`finite_use_value.score_scope/observed`在同一次比较中，用同一encoder、同一批旧查询，比较旧关系R与修订后R'的预测分数。`score_state`还显式清除organization与variable_uses以确定这个计价端口。记其为：

U = S(theta,Q,R') - S(theta,Q,R)。

完整学习后固定同一查询的变化则是：

S(theta',Q,R')-S(theta,Q,R)
= U + [S(theta',Q,R')-S(theta,Q,R')]。

以上是抽象的参数变化分解。生产U的theta实际是结算时参数theta_s；行动前是theta_0。生产对应应使用S_s(Q,R')-S_0(Q,R)=U+[S_s(Q,R)-S_0(Q,R)]，最后一项已有representation_shift记录。它是该端口变化；支付是否需要补偿该项，要看其行动间差是否翻转真实用途排序。32笔已有结算加回后0笔反号，当前奖励保持。

身体绑定：`scripts/ib_local/finite_use_value.py:19,28,94`、`scripts/ib_local/causal_use_value.py`的settlement。Lean：`NativeValueObjectiveAudit.parameter_update_gap`。

### 2．跨轮U包含评价对象切换项

把每轮实际模型、查询与作用域合并为F_t，持存关系记为R_t。其严格恒等式为：

sum_(t=0..n-1) [F_t(R_(t+1))-F_t(R_t)]
= F_n(R_n)-F_0(R_0)
  + sum_(t=0..n-1) [F_t(R_(t+1))-F_(t+1)(R_(t+1))]。

固定F时，最后一项为零，支付和望远镜化为终点改善；当前身体的查询、编码和作用域随生活改变，最后一项有实际定义。它属于目标迁移账目，正负均可。适应性评价本身有功能，应当显式识别该项，而非强行将生命体改成全局固定目标。

直接结论：每轮局部U、整段U均值、独立共同对象的长期改善分别对应不同数学量。用它们轮流采用候选，会切换研发问题。

Lean：`changing_score_sum`、`fixed_score_sum`；证明对任意生产评分函数及状态序列成立，没有模拟学习器或设定世界响应。

### 3．一次观察已经会给出接近固定强度的保留偏置

`relation_retention_use.advance/biases`从零统计接收一次r时，偏差修正后的first=r、second=r²。因此：

b = tanh(r / (abs(r)+epsilon))。

当abs(r)远大于实际epsilon=1e-8时，b接近sign(r)*tanh(1)，即正负0.761594；优先度倍率接近2.142与0.467。不同奖励幅值被近似归一为相同强度，一次观察即可显著改变保留排序。这里的first/rms比值提供有界方向调制，count未额外提供观察数量的可信度衰减。

这是现有数学规则的确定性质。来源经验迁移把此规则应用到尚无自身观察的新未知项，因而少量旧观察也会立即带来同等级别的取舍作用；迁移实验启动前就可以从公式得知这件事。具体后果大小才需要真实数据。

Lean：`first_corrected_moment`、`first_positive_ratio`、`first_positive_zero_epsilon`；最后一项是epsilon=0的精确极限情形，生产有限epsilon由前一项保留。

### 4．事实身份相同，条件用途的符号仍可变化

实际用途标签是两个预测分布对到达后果y的对数评分差：

b_i(c,y) = log p(y | c,R) - log p(y | c,R minus i)。

对两个不同、正规化、正的预测密度p和q，若p处处不小于q且在正测度集合严格大于q，其积分便大于q的积分，违背两者积分均为1。因此不同的正规化预测密度存在各自占优的后果区域。Student-t预测满足正密度和正规化前提。评分取每坐标平均时仅增加同一正比例，不改变此结论。

这直接说明，某次事实的正负贡献属于“条件、预测器、证据集合和真实后果”的关系。旧身份过滤解决引用同一性；跨条件采用旧符号还需要适用性依据。14/43符号反转是该性质在本段生活里的观测频率，经验并非建立这个性质的前提。

身体绑定：`relation_retention_use.begin_fresh/finish_fresh`与`causal_relation_program.log_score`。本项给出密度积分推导，尚未在本次Lean文件中形式化。

### 5．均衡混合内部参照与世界标签，会学习混合目标

`native_amortized_decision.predict`对world/native按来源总量均衡加权，两种记录进入同一个输出；`features`未把kind作为输出条件。两类记录的kind被保留以控制权重和溯源。

对同一可表达条件，设内部参照为n，世界标签的条件均值为w。均衡无ridge的平方拟合最优值为(n+w)/2；有ridge和prior时最优值相应收缩。若n含偏差delta，该情形下混合目标中保留delta/2。来源条件分布不同时，条件混合比例随覆盖情况变化。

内部参照和世界标签本来可以服务于同一条件价值，前提是标签对象、条件和预测跨度一致。此处直接推得的是：来源均衡本身并不会自动把目标变成真实世界条件均值；需先证明两个标签的语义对应，再讨论拟合精度。原生预测函数实际返回策略加权的局部q，total用于选择概率，已核对源码，二者不可混称。

Lean：`source_mixture_excess`、`equal_sources_no_ridge`；绑定生产ridge平方拟合在同条件上的目标性质。一般核拟合继续复用`NativeAmortizedDecision.dual_normal_minimum`。

### 6．旧事实绝对评分对编码尺度敏感

对现有Student-t评分，如果目标、预测均值同时乘c>0，预测方差乘c²，则每坐标对数密度改变-log(c)，MSE改变为原来的c²。预测关系可按同一坐标变换保持，绝对分数仍变化。

`run_native_causal_use_value.evaluate`随当前模型encoder重新编码旧目标，跨模型的旧查询绝对分数需要检查这种坐标贡献。同次有限U在同一坐标比较前后，公共-log(c)会相消；该性质恰好解释为何单次支付的坐标处理和跨阶段绝对评分要分别绑定。

本项来自`causal_relation_program.log_score`的密度公式及`evaluate`实码，不需要训练数据估计。

### 7．行动共同方向的估值变化会被实际actor消去

`conditional_actor_reference.evaluate`及实际actor对可用动作估值中心化，再进入softmax。所有可用动作同时增加c，对各动作概率的作用为零。任意两动作的logit差变化只取决于其修订差delta_a-delta_b。

因此预演绝对值变化、内部活动变化与动作概率变化的大小，受不同算子约束。需要优化的是能改变有效比较的方向；共同模式被消去属于当前策略的确定行为。

已有Lean：`RootNativeCorrection.logit_difference`、`common_shift_preserves_difference`。这是原先已证明的性质，现将它放回整体目标审计，避免重复把它当新实验发现。

## 2．直接演绎形成的研究优先级

最先明确两个交接：

1. 完整身体学习转移到底包含哪些被定价变化：R修订、theta更新、S/P推进和条件切换，各自对同一后果对象的作用如何进入延迟信用。
2. 世界标签、内部教师、条件预测和actor读取的量，是否是相同条件下、相同跨度和单位的目标。先建立这些等式或明确余项，再提高拟合精度。

这将“木估值不准”上升为“金定价的对象—水保留的信用—木预测的对象—火比较的对象”是否对应的问题。由方程已经确定这些对象的定义有差别；何种差别承担当前实际损失，随后用现有记录和最少干预识别。

最小生成规则的候选应作用于同一完整学习转移：B' = U_body(B,a,o)，为同一未决关系和实际后果建立可重激活的信用，再进入未来价值递推。现有经历、资格、关系和延迟结算继续作为载体，完整B属于数学状态定义，无需把全部历史或优化器复制进每条经历。具体压缩载体须对齐已识别的充分条件。
