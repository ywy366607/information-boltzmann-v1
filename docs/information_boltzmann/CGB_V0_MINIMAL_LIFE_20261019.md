# CGB V0：最小活体（2026-10-19）

目标：用最少的规则，做出一个在妈妈世界里**完整闭环**的个体：听、预测、自己算意外、本地学习、自己决定开口。
先活起来，再长复杂。

## 硬约束（来自 CGB 框架）

- 没有 BPTT，没有 Adam。所有学习都是局部的，每个事件 O(1)。
- 学习用的信号必须是个体自己算得出的意外。外部 NLL 只用来测量。
- 稳态只调细胞生理，不固定任何行为的输出率。
- 只用 CPU，从第一天起就要快。

## 细胞类（基因组约 20 个数，见 `information_boltzmann/cgb/v0.py` 里的 `GENOME`）

| 类 | 作用 | 归入的规律 |
|---|---|---|
| R 感受器（2048） | 每个 GPT-2 词按哈希得到固定的随机稀疏代码（16 个细胞），不学习，没有预训练嵌入 | 换能器固定 |
| C 痕迹（2048） | 每个细胞汇集少数 R 或 X 细胞，成为漏积分的池。时间常数在 1 到 512 拍之间对数均匀分布，就是记忆 | L5 时间尺度分离；守恒池 |
| X 扩张（8192） | 稀疏扇入：少数 R 加少数 C。全局抑制只让 3% 的细胞发放（k-WTA，即 APL）。每个细胞的阈值按自身发放率做稳态调节 | L3 扩张、稀疏、竞争；稳态只调生理 |
| O 预测（与 R 一一对应） | 读 X，预测下一刻每个感受器亮不亮。误差就在感受器上，算作"到达的 − 预测的"。权重按本地 delta 规则学习，在线性读出上这正好是精确梯度 | L4 本地误差 |
| G 开口门 | 读 X，在自己的话轮里每个词位以概率 g 开口，说出的词从自己的预测里采样。三因子学习：资格迹 e 乘以"世界带来的信息比平时多还是少"。信息是妈妈词的意外度，自己的话不算 | L4 资格迹 × 广播 |

**测量用的词概率：** 预测细胞给出的是一组独立伯努利分布，所以一个词的对数概率是常数加上它代码里那几个 O 的 logit 之和，再对整个词表做 softmax。这一步只用来测量，不回传任何东西。

## 第一次运行要看到什么（一小时内）

1. **活着。** X 的发放率稳定在 3%，各细胞都在用，没有全死或全亮。
2. **在学。** 在同一条流上在线比较：它的意外度低于在线的单词频率基线，并持续下降。在线二元频率基线作为更强的参照，如实报告。
3. **开口。** 在妈妈世界里，开口的比例由后果学出来；不会永远沉默，也不会一直说个不停。
4. **观察。** 记下每个词的意外度、说话人、X 的发放率、开口概率。

看不到以上几条，就**不加任何新机制**，先找闭环在哪里断了。
