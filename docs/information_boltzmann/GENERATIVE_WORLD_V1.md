# 共同生成世界 v1：世界先行，持存体后接

日期：2026-09-30。状态：已实现、数值验证、可交互运行；材料参数尚未从真实记录拟合。

## 1. 本版交付

共同状态包括物体中心与动量、每个物体的径向弹性模态及其动量、房间有限声学模式及其动量。所有接触和界面作用来自同一个可微 Hamiltonian 的导数。

实际代码：

- `information_boltzmann/world/model.py`：PyTorch 可微储能与非负耗散参数；
- `information_boltzmann/world/simulation.py`：同一生成律的解析梯度执行器、积分、功率账、检查点；
- `scripts/world/serve_world.py`：持续世界服务；
- `present/world/index.html`：物体/场/双耳/分离能量图；
- `scripts/world/audit_world.py` 与 `tests/test_generative_world.py`：数值验证。

暂不装入机器人策略、多模态主干或 IB 持存场。

## 2. 共同储能

\[
H=\sum_i\left(\frac{|p_i|^2}{2m_i}+m_i g z_i
+\frac{\pi_i^2}{2m_i^\eta}+\frac12m_i^\eta\omega_i^2\eta_i^2\right)
+\sum_k\left(\frac{P_k^2}{2\rho}+\frac12\rho\omega_k^2 a_k^2\right)
+U_{contact}+U_{interface}.
\]

房间基函数为归一化 cosine 模式，omega_k=c|k|。保留 non-DC 模式至注册的 cutoff；默认房间 3×2.4×2 米、226 模式、480 Hz 截断、8000 Hz 采样。

接触半径为 r_i+s_i eta_i，同一个接触势

\[
U_{contact}=\tfrac12 k\,[\text{penetration}]_+^2
\]

同时产生中心受力和弹性模态受力。物体位置变化、材料振动与接触反馈不由独立事件回调创建。

接口为第一版降阶标量位移阻抗：

\[
U_{interface}=\tfrac12\sum_i\kappa_i
\left[\eta_i-\sum_k\phi_k(q_i)a_k\right]^2.
\]

其对 eta、a 与 q 的导数都进入动力学，包含随源位置变化的几何反作用。不存在单向创建声波包或预设“碰撞音效”。这是可证明交换账闭合的低阶近似，后续通过真实材料/表面记录辨识接口及扩充模态。

将 a_k 解释为纵向位移的标准化模态，房间声压读出为

\[
p(x)=\rho c\sum_k\omega_k\phi_k(x)a_k.
\]

左右耳在不同空间点读取同一场；没有分别为耳朵添加延迟规则。反射边界由房间模态给出。

## 3. 学习与物理初值

质量、模态惯性、模态频率、接触与界面刚度用 log 参数保持正值。材料、声场、接触和摩擦损耗用平方参数保持非负，提供可微瞬时耗散功率。

本版世界运行时参数固定，模型尚未优化。三种材料使用公开标注的启动参数，不声称对应已标定的木材/金属/橡胶。颜色是表面观测属性；气味和热化学尚未生成。

下一项科学任务是从真实同步运动、振动/音频和接触记录辨识共同生成律及材料状态。把本版自身生成的数据拟合成功，只能说明执行/辨识接口可用，不能证明现实规律已学会。

## 4. 积分与能量账

保守步使用 kick—精确自由/谐振演化—kick。耗散在两侧半步执行；每一个动量收缩都把精确减少的动能登记为热。

接触法向的耗散作用于真正的相对表面速度，包含中心和材料模态速度；切向摩擦作用于相对切向速度。界面交换本身不扣能量。

账本：

\[
\varepsilon(t)=H(t)+Q_{heat}(t)-H(0)-W_{external}(t).
\]

积分残差单独显示，不归入热以制造完美账本。推动只改变已有物体动量，外部功按推动前后真实动能差登记。

储能方程的连续形式与数值执行分别验证；目前没有声称任意输入下的无条件无限时间有界。

## 5. 数值验证与当前边界

已验证：优化执行器与可微储能的梯度一致、单一接触同时改变中心和模态、无激励时无声、界面双向耦合、观察点移动只改变观察、外部冲量功正确、损耗与热一一对应、时间步细化降低残差、检查点后下一块波形逐元素相同。

20 秒注册运行，约 4.3998 J 初始能量：最大账本误差 0.001631 J，约 0.0371%；计算 5.14 秒，约 3.89 倍实时。结果保存在 `results/published/generative_world_numerical_audit.json`。

这是有限模态数值世界闭合结果。低频截断会产生空间/时间分辨率限制及带限前驱尾部，尚未验证精确传播前沿；头部绕射、移动障碍物造成的声学遮挡、完整表面流固接触和真实材料标定仍是明确升级项。图中声场截面是高度 0.35 米，投影到地板显示。

## 6. 运行与持存

```powershell
python scripts/world/serve_world.py --port 8090
```

打开 `http://127.0.0.1:8090/`。点击声音开关后可听双耳波形；选择物体并推动，观察输入功与响应；移动观察点改变双耳测量。

自动每 2 秒把世界状态保存到 `results/generative_world_live/world_state.npz`，启动时默认接续该状态。保存包含生成律权重、所有动量/场、世界 ID、物理时间、热、外部功与曲线历史。停止服务不作为世界内部重置。

`--fresh` 或页面“重建初始世界”是明确的开发者重新初始化操作。页面暂停只暂停物理时间；相机/观察点属于外部测量装置，当前尚未计入一个真实机器人身体。

当前 CPU 执行，不启动 GPU 训练。可选 Numba 仅编译同一解析梯度，不更改动力学。
