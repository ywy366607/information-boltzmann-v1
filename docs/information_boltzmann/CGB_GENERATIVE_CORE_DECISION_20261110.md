## 2. 本轮得到的两项实质判断

### GDN已有非交换性，新增交换子不解决旧卡点

已核实际实现 `scripts/ib_local/gated_deltanet.py` 的 `decay_then_delta`，以及 `gdn_field_reference.py:76` 和 `gdn_fused.py`。固定当拍上游特征、门和归一化键，在内容预算裁剪之前，矩阵更新是

\[
S^+=A_xS+B_x,\quad A_x=\alpha_x(I-\beta_x k_xk_x^\top),\quad B_x=\beta_x k_xv_x^\top.
\]

两个不同输入的线性部分已经满足

\[
[A_a,A_b]=\alpha_a\alpha_b\beta_a\beta_b(k_a^\top k_b)
(k_ak_b^\top-k_bk_a^\top),
\]

一般非零。完整仿射更新可写为

\[
L_x=\begin{pmatrix}A_x&B_x\\0&I\end{pmatrix},\qquad
L_x\begin{pmatrix}S\\I\end{pmatrix}=\begin{pmatrix}S^+\\I\end{pmatrix}.
\]

这给现有更新一个可组合的代数表达，不新增网络。小规模FP64代数核验：交换子范数0.1920014，公式误差5.55e-17，连续两次更新与齐次矩阵组合误差2.22e-16；仅核等式，不是能力实验。

真正的限制是：固定同一输入、0≤β≤1、单位键、α<1时，两份S的距离每拍至多乘α；该局部核不能同时把两个不同状态吸回两个稳定值。改变输入、门、上层状态和学习的整个身体不受这条固定映射结论等同约束。慢权重和经历库也不等于每拍衰减的S。

因此本轮不把“非阿贝尔”“矩阵”当作GDN之外的新能力，也不据此再装锁存头。要增强的是已经学到的关系能否脱离某一次具体输入复用、组合，并在坐标变化后仍正确作用。

### BFSS的丰富性来自共同结构，不能直接提供生命体的保持动力学

BFSS原文式4.1/4.2包含矩阵、费米伙伴和规范结构；“唯一相互作用是交换子平方”仅适合讨论其玻色势能部分，完整模型还有费米耦合。[原论文](https://arxiv.org/pdf/hep-th/9610043)

忽略常数的玻色哈密顿量可写为

\[
H=\tfrac12\sum_i\|P_i\|_F^2+\tfrac14\sum_{ij}\|[X_i,X_j]\|_F^2.
\]

从此式可直接看到：彼此对易的矩阵构成平坦势能方向；它没有选定一组抗扰动记忆。经典闭合哈密顿流在正则相空间保持体积，不能具有把一个开放邻域永久压缩到孤立吸引子的耗散吸引机制。丰富的相互作用、热化或混沌与可学习的长期关系保持是不同性质。[BFSS动力学研究](https://arxiv.org/abs/1810.03378)

采用其“少类对象、共享作用规则、结构由相互作用生成”的组织方法；实际身体继续采用开放输入、选择性遗忘、持存关系和真实结果驱动学习。非微扰不等于非梯度；不能把一个梯度优化器换掉就称为非微扰生成。

| Hopf代数、物理弦、M理论完整结构 | 本候选不实现 | 当前没有需要其额外结构才能表达的身体操作；组合先用现有类型化算子 |

Monoidal category中文为“幺半范畴”；“单子”对应monad。弦图是复合过程的数学语言，不要求物理弦。已有文献直接将弦图语法映射到随机矩阵语义并表达干预，因此SCM与弦图不是两套需要并排训练的模型。[Causal inference via string diagram surgery](https://discovery.ucl.ac.uk/id/eprint/10140097/)

非对角是坐标相关的；非交换不是“有非对角元素”的同义词。模空间通常描述满足指定条件的对象按等价关系所得空间，不把全部训练参数直接改名模空间。全息原理涉及引力系统的信息界与边界描述，不能推出少量有限精度变量能无损存任意长历史。[Bousso](https://arxiv.org/abs/hep-th/0203101)

胞腔层沿用统一文档的修正：H¹是否为零不是当前预测是否正确的裁判，也不自动给出唯一修正方向。优先实际兼容残差和世界证据，不引入一个“上同调正确性奖励”。[谱胞腔层](https://arxiv.org/abs/1808.01513)

## 4. 选定的共同核心：一种关系记录，三个操作

关系记录为

\[
r=(\text{条件/角色接口},\ \text{共享操作的有限组合},\ \text{有限证据与版本}).
\]

条件和角色可以是可训练连续表示；关系不要求写成自然语言或ASCII程序。作用于当前对象、产生可检验后果，是它作为符号关系的功能。因果库保存该关系与证据；已有字节快表继续承担精确字面记忆，不将两者混成一种表。

三个操作保持为：

1. **绑定**：当前查询把条件、对象和准备采取的实际动作接到关系端口。参与集合和适用域从这里产生。
2. **组合执行**：少量共享、可训练的操作依次作用，形成后果分布；前一步输出可继续进入下一步预测与行动选择。必须复用现有世界模型和内部续行接口，不另建与身体无关的矩阵模拟器。
3. **证据修订**：真实结果校准刚才的预测，修正实际参与的关系、绑定和共享参数；反证使条件细分或关系释放，可复用证据支持合并。存储与执行均受固定预算限制。

用G_i表示共享操作，T_w=G_(i_k)∘…∘G_(i_1)只是结构表示；具体操作允许条件化、非线性与随机后果。固定d维的纯线性矩阵代数维数不超过d²，不把长算子串当无限新增记忆。绑定与组合选择需要可训练实现，类型正确可以由构造保证，因果预测正确由真实后果学习。

**比前一轮新增的约束：共享操作应首先来自身体已有的状态转移，关系保持以外部可观察作用为准。**齐次矩阵表示说明GDN局部更新已能被组合；整圈还有非线性、取水、行动和世界回应，不能只缓存GDN局部乘积冒充整个世界模型。新的关系参数化应共享或约束现有预测转移，而不是再独立拟合一套F。

### 长期稳定的具体抓手

对明确支持的线性接口，换基z'=Uz、T'=UTU⁻¹，并同步输入输出端口，可以保持作用。一般非线性编码器更新不自动是这种换基，必须用已有真实证据比较旧关系与当前重编码后的作用；旧证据版本不可混配。慢存储与快执行使用同一关系身份，而非把会漂移的向量当永久身份。

“对称性更大”也不是一律更好：若任何对象、角色、动作都能任意互换而读出不区分，就丢失了信用所需区别。保留的是不改变外部作用的重参数化；真正改变后果的对象/行动差异必须留下。因果抽象的目的正是压缩前者、保留后者。[HOWM](https://proceedings.mlr.press/v162/zhao22b.html)

### 相对最小性

删去绑定，会回到混合向量难以确定谁参与；删去可组合执行，经历退回静态提示，不能生成后续规划；删去真实证据修订，关系只能自洽地重复错误。这里给的是针对当前目标的最小设计承诺，不以“三”作为所有可能生命体的数学下界。

## 5. 同一核心怎样承担多项必要条件
