# 原生运动末端接管语言外设

本轮将实际说词的入口移到连接组内逐个标注的运动神经元。它们的轴突释放向量进入可学习的语言外设，外设提交的词进入真实妈妈世界；自听和妈妈回复仍从既有感官入口返回。原来的感知预测头继续预测外界输入，选词另有独立参数。主线保持暂停。

## 接线与执行约束

`--native-motor-port` 选择当前 MaleCNS r2 图中的全部 815 个 `cb_motor/vnc_motor` 神经元，保留有序 bodyId 与图内索引。每个细胞的实际释放分别进入映射；不用群体平均，也不用膜电位或预测头代替末端释放。

没有实际运动末端释放时，语言外设没有可执行指令。这个条件是数字外设的事件协议，未加入发言率先验、额外身体变量或新奖励。有释放也不要求说话：原有时机策略仍可选择等待。说话时机只直接读取选定运动细胞的已有状态，其他脑区通过原生连接影响它们。注意力通道保持独立。

选词、时机、实际提交、释放细胞及幅度均进入回放记录。信用回放核对真实时钟和释放事件，再沿实际策略回传到运动外设及已有原生可学习参数。资格迹与历史未结算信用保留。这里使用原有 BPTT 代理梯度；末端是否发生事件的离散切换不作精确梯度声明。

语言外设是果蝇没有的数字效应器，其编码需要学习。本轮没有宣称还原口器肌肉、完整身体或本体感觉；也没有把发声标签伪装成感觉电流。外界后果只来自真实提交后的自听、环境和妈妈回复。
