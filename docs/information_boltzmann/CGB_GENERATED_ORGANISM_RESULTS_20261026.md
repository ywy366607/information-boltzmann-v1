# 第一个生成的个体：结果（2026-10-26）

预注册：[CGB_GENERATED_ORGANISM_PREREG_20261026.md](CGB_GENERATED_ORGANISM_PREREG_20261026.md)。

**做法。**只固定世界接口：食物页 F、到达页 A、一个被世界读取的马达单元。内部页、单元数、能量与规则全部由选择决定。
- 选择设置：种群 48，80 代，适应度为 4 个训练种子上 2 万拍的存活。
- 时程的修正：最初的 3000 拍太容易，随机生成的规则表也能活，而且根本不用食物信息。现已改为 2 万拍；从不换源的个体在 2 万拍中存活中位 1565 拍，所以选择压力确实落在"会不会利用食物信息换源"上。
- 评估：在 8 个留出种子上进行。

## 演化出了什么（读规则表，事后解释）

- **饱食储库**：食物令牌经 F 快速转入 I1（κ≈17.6）。I1 的占据量就是"最近吃了多少"，所以与漏吃次数负相关。
- **马达由饱食抑制**：M 与 I1 同时充上时会一起放电归零，吃饱时马达很快复位。I1 一空，马达就以一定速率被激活。
- **代谢流**：有食物时，令牌经 F → A 流入 A 的储库（汇）。这是非平衡稳态，对应 G16 的"必须排出"与 M2 修正后的储库功。
- I0 页只剩一条无效的内部交换，是退化的残留。

这就是大肠杆菌的"奔跑—翻滚"策略：近期摄入好就继续，摄入一停，翻滚的风险率就升高。它是选择的结果，不是设计的产物。

## P2 失败的原因

- G12 是一条**最优性**定理：只有区分阈值两侧的漏吃次数，期望摄入才能最大。而这次的选择压力是"活满 2 万拍"，活满之后不再有提高摄入的压力（它的摄入 0.596，低于积分器的 0.73）。
- 这正是生成链 G12 节早已记下的缺口："摄入差距要转化为存活差距，需要成本落在两类策略的摄入率之间。"
- I1 漏得很快，一拍不吃就几乎清空，所以记忆实际上是二值的。
- **出口（已在运行）**：
  - 成本 0.7 的苛刻世界，只有接近最优的策略才能存活。预言：届时换源曲线呈阈值形，记忆超过 1 级。
  - 另用种子 1 重复演化（成本 0.6），检验结构是否可复现。

## 生成器层的修正（同日）

- M2 原先把刺激写成边界单元的状态能量，导致任何恒定环境下动力学都满足细致平衡，没有代谢。现改为事件的储库功 −μ·Δc，平衡环境下势为 0。
- 去掉了 P1b 的接触齐性（见公理文档的修订记录）。

- **结构可复现**：s1 演化出另一种实现（只有一个内部页），但核心相同，都是"摄入的令牌与马达一起放电"，即摄入抑制马达。
- **P2 三次都未达到预注册的阈值标准。**原因检验：在同一批世界中直接模拟理想策略。

| 世界 | 理想阈值（漏吃 n 次就走） | 漏吃 1 次后恒定风险率 0.15 / 0.25 |
|---|---|---|
| 成本 0.6 | n=2：均值 17542，摄入 0.676；n=3：17544，0.697 | 14937 / 15508，摄入 ≈ 0.61 |
| 成本 0.7 | n=3：均值 12860，摄入 0.688 | 4912 / 4918，摄入 ≈ 0.59 |

  - **阈值的优势是真实的**，在苛刻世界中尤其大（12860 对 4900）。所以原因不是"优势太小，选择看不出来"。
  - **G12 的方向得到支持**：成本 0.7 时，演化个体（10574）远好于恒定风险率策略，换源曲线在漏吃 3 次处达到峰值，正是理想阈值 n=3 的位置。选择越严，个体越接近计数器。
  - **剩下的差距在锐度**（约 2300 拍存活，0.08 摄入）。纸面推导：N 个二值单元的随机计数服从二项分布，区分 n 与 n+1 的能力受 N 限制（G11b 要求不同历史的状态可区分）。s2 的记忆页只有 8 个单元。
  - **可证伪的预言**：放宽单元数上限（例如到 64），换源曲线会更陡，P2 可能通过。
- **P1 在 s2 中失败**（内部页 ρ = −0.27）。s2 的 F 页有 4 个单元，可能承担了记忆，但预注册只检查内部页，按标准判失败。G11 本身并不要求记忆必须位于内部页。
