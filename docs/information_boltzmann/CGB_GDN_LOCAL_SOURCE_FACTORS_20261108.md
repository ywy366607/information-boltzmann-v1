# GDN 局部参与：共享源方向，保留各参数归属

> **固定容量续推：** [资格压缩文档](CGB_CAUSAL_TAG_COMPRESSION_20261108.md#固定容量生成律已经写成有限更新函数)现给出投影、归属合并、K+1候选最小丢弃、误差账与后到信用的同一有限更新；新增26条通过，系列共132条。记录方向成本亦已补计，以下50–403 MiB只含native与归属。

## 本轮决定

把[资格压缩方案](CGB_CAUSAL_TAG_COMPRESSION_20261108.md)落到原第2/13层的实际门控。第一版跨窗资格先覆盖 **a_proj、b_proj、dt_bias、A_log在主前向原生调用中的参与**；其余参数保持原学习/冻结设置，原已解冻投影的即时学习保留，当前MLP仍冻结。不是宣称其他参数不需要长信用，而是先把最直接影响保持和改写的参数族做成一个有预算的实例。

**发现：两层共16,400个门控参数，主前向每个词元的原生更新最多共用16个源方向。** 归属系数保留各权重的区别。这是所选调用的当拍源因子化，跨时间累积后的秩仍须处理。

只做Lean、代数和文档；不训练、不运行模型、不作影子更新、不新增整身快照。实际生命态仍为524更新、seen450757、next_case14，反馈14未到。

探索源码：[gdn_local_source_factors_20261108.lean](../../lean/CGBAxioms/reviews/gdn_local_source_factors_20261108.lean)。局部源阶段22条探索定理通过单文件内核及逐条公理依赖检查；当时本系列五文件共106条。生产区仍1807条，身体覆盖该阶段增加0。阶段检查记录：`scratch/bounded_causal_tags_20261108/local_source_proof_result.json`；后续132条的当前状态见页首。

用当前五行角色说：土中的门控留下参与，水保存共享作用与不同归属，后到的金按真实结果收缩它，再修正土中保持与改写的方式，影响以后木与火能取用什么。资格侧车服务这条共同关系，不单独创造一套奖赏或决策回路。

## 实际更新与五类作用

核对当前安装源 `E:/cgb_gdn340_probe/vendor/flash-linear-attention-0.2.2/fla/layers/gated_deltanet.py`：投影142–146行，门控260–261行。模型hidden1024、每层4头、每头256维、短卷积宽4，24层纯GDN。**先衰减，再delta写入**：

```math
M=\alpha S,\qquad r=v-k^\top M,\qquad S^+=M+\beta kr^\top.
```

对当前一步，完整方向分成：

```math
dS^+=\alpha(I-\beta kk^\top)dS
      +d\alpha\,R+d\beta\,B
      +\beta\,dk\,r^\top-\beta k(dk^\top M)
      +\beta k\,dv^\top,
```

其中 `R=(I−βkkᵀ)S`，`B=krᵀ`。`native_direction_source_split`证明分解没有丢掉key、保持或旧状态项。

| 参与路径 | 当前S上的直接源 | 压缩意义 |
|---|---|---|
| 保持α | R | 同一头的所有保持门参数共享这一矩阵值源 |
| 写入β | B | 同一头的写入门参数共享创新外积 |
| value变化dv | βk·dvᵀ | 单个方向是外积；不同value坐标/时刻不自动相同 |
| key变化dk | βdk·rᵀ−βk·(dkᵀM) | 两个一阶外积；有限改动还有二阶余量 |
| query变化dq | dqᵀS⁺ | 当拍不直接改本头S，但改变输出，并可进入后层S、卷积缓存和记录 |

`key_edit_with_remainder`还给出有限key改动的确切二阶项，不能把一阶资格当成任意大改动的精确预测。

### 两种“低秩”必须分清

R是**一个共享的矩阵值作用方向**，它自身仍可能是满秩矩阵。`erase_injective`和`retention_matrix_injective`证明：当 `1−β‖k‖²≠0` 时，`S↦(I−βkkᵀ)S`是单射。

因此，单头一千多个保持参数共享一个R，不意味着可以把R本身存成一个外积。省下的是“每个参数各存一份作用”，不是凭空把256×256记忆压成256维。

## 哪些参数共用，怎样分账

固定当前进入该头的特征x。官方门控为：

```math
z=W_a x+d,\quad \ell=-e^A\operatorname{softplus}(z),\quad
\alpha=e^\ell,\quad \beta=\sigma(W_bx).
```

记 `c_z=−αeᴬ·exp(z)/(1+exp(z))`，`c_A=αℓ`，`c_b=β(1−β)`。

| 原参数坐标p | 源U | 归属系数owner(p) |
|---|---|---|
| `a_proj[h,j]` | R | c_z·x_j |
| `dt_bias[h]` | R | c_z |
| `A_log[h]` | R | c_A |
| `b_proj[h,j]` | B | c_b·x_j |

`alpha_gate_deriv`、`native_retention_gate_deriv`、`native_write_gate_deriv`与`retention_projection_family_deriv`由门函数和真实更新推导出这些源；`retention_owner_contraction`证明整行参数干预和上述归属收缩一致。softplus在此采用光滑分支，Torch阈值20以上的线性分支仍要分别接入。

每层的保持族参数数为 `4×(1024+2)=4104`，写入族为 `4×1024=4096`，共8200；两层16400。每头两个矩阵值源，两层四头共16个。

### 经历重算中的参与必须另列

当前 `pretrained_gdn_experience.py:retrieve` 会用同一原生block重算被选胶囊；每条胶囊包含65个位置，且在一次批查询中共享同槽的重算。因此同一门控参数在**整次实际调用**中不只参与主前向的一步。每个重算位置都可能产生不同的R、B和归属；不能把整次调用的源数也写成16。

第一版登记的源集合是主前向门控使用；旧胶囊重算中的直接参数源仍由原有梯度处理，暂不声称其窗外资格已覆盖。所选主前向参与留下的影响，之后若经由记录进入重算，其状态/记录传递仍须包含在共同A中。

形式上是 `B_total=B_main+B_replay+B_other`，本版资格跟踪 `E_main_next=A_total·E_main+B_main`。这是明确的参与源分账，不是完整参数导数；即使最终都更新同一个原参数，也不能把这几项混为已经覆盖。若以后扩展重算源，必须重新计算源数量与预算，不能只改名字。

完整共同转移把局部S方向送到后续激活、所有有关cache和记录方向。若其局部线性化为L，同一源的参数作用为：

`E_new(p)=owner(p)·L(U)`。

`shared_source_survives_transport`和`shared_source_delayed_capture`证明：后来结果m到达，只需先算一次 `m(L(U))`，再乘各参数的归属系数。不能在输运前就用一个标量奖励替代整份作用。

## q/k/v等投影没有被漏掉

`projection_row_shared_source`证明：对任何一行原投影，其权重的当前参与都可以共享“该行输出单位变化经L输运”的作用，系数就是各输入坐标x_j。`projection_all_rows_factor`进一步给出整张投影的有限源展开。

这里的L必须包括**原始投影值进入短卷积缓存**这条支路。只在SiLU、归一化后的key/value上记录源，可能漏掉当拍读出为零、下拍卷积却起作用的参与。`visible_zero_does_not_erase_cache`明确了不能据当前输出为零删除该方向。

q/k/v每层各1024个原始输出，不能享受“门控族每层8个源”的同一规模结论。本轮保留其源公式，为后续扩展准备；第一版长资格先选门控族，其余参数的原学习/冻结设置保持。

## 固定容量候选怎样走一步

这是学习侧候选流程，尚未安装到身体：

1. 同一真实主前向经过第2/13层时，按上表产生局部门控源与归属；源取自当前S、特征和门，不保存整段历史。调用标签区分主前向与旧胶囊重算，后者不计入16个新源的合同。
2. 旧资格按共同一步方向算子输运：`E_old→A·E_old`；共享因子实现为 `U→A·U`，归属V保留。后层权重冻结时，方向仍经过其输入/cache路径。
3. 把新源逐条输运到同一交接点，插入固定K列的作用基。能表示就合并V；不能表示则保留余量并按前轮信用误差合同压缩。可逐条处理，只需K+1列临时空间，不必同时追加16份整身方向。
4. 后到真实语言结果收缩资格，给原门控参数形成信用。只在估计超过压缩误差界时认证符号；未分清的余量不能冒充正确归因。
5. 窗内梯度与窗外资格分别登记，复用`transport_sources_split`与`capture_sources_split`。若用“总资格减窗内资格”，两者必须来自同一参数干预定义、权重日程和源；不能把实际历史权重下的资格与当前权重重算的BPTT直接相减。

K是固定资源预算，不是证明出来的“足够小的自然常数”。16是每拍主前向门控新源数的上界，不是整次调用所有源或累计资格秩的上界。压缩保持哪些区别，仍由[前轮的未来信用与误差合同](CGB_CAUSAL_TAG_COMPRESSION_20261108.md)规定。

### 实数方向参考与可学习资格的关系

这里推导的是可审计的因果方向参考，用于明确源和归属。真正有限的资格编码可以近似或学习，但必须报告被删方向对后果的误差；没有要求生物资格迹等于Jacobian。当前方案也不沿历史保存反向图：它每拍覆写有限方向。不过应用完整一步导数仍有计算代价，不能把“无历史BPTT”说成“免费”。
