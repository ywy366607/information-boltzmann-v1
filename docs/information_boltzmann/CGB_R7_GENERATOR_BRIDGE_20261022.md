# R7真实保持与原生成元的条件投影

本推导写于条件投影运行之前；完整轨迹的单/双指数结果已知，因此此轮属于预先定义操作的探索性机制比较，不把已看过的CG3再叫新的盲检验。原CG1/2拟合与CG3留出的来源仍保留，不回改它们。

## 直接投影已有通路

取原标量材料的一个已安装、r=1的接触，固定几何、其它物料与外场，仅保留原binding±与thermal−通道；r变0视为这一痕迹保持事件结束。支持总数S=F+C不变，C∈{0,1}。这不是新加两态学习方程，而是原生成元在明确限制通道下的首达扇区；它还不是完整细丝的生物观察映射。空间回缩、write、transport、非中性输入及其它接触暂不在这个条件计算内，不能将结果泛称全核失败或成功。

用原event_rate直接求：

    b = rate(binding+ | r=1,C=0,F=S)
    u = rate(binding− | r=1,C=1,F=S−1)
    d0 = rate(thermal− | r=1,C=0)
    d1 = rate(thermal− | r=1,C=1)
    T = [[−b−d0, b], [u, −u−d1]]。

若首次被观察时未结合支持的概率为a，初始行向量π=(a,1−a)，则S(t)=π exp(Tt)1。每分钟观测的事件概率为π exp(Td)[I−exp(T)]1，右删失概率为π exp(Td)1。这个首达分布保留支持交换，通常不能任意替成两个正权指数；简单双指数只是一种慢交换/分群极限。

当前参考参数εr=2、χ=2、αthermal=.02、αbinding=.05均来自先前物性，不由R7重新选择。固定C的原消失率d0/d1≈1.7616；R7观测混合点估计速率比约7.84，但二者的观察层次不同，不能仅凭这个比值宣布排除χ=2。应比较完整T的首达分布。

## 本轮固定操作

1. 标量reference_complete全档只读取参数与哈希，不推进物理个体；率调用从同一MobileExchange.event_rate取得。新带电物性不混入这一中性标量扇区，它还需单独保留电荷状态。
2. 对未识别有限支持数S取1、2、4、8、16五个固定条件，每个条件保留原参数及binding/thermal相对时钟。只用Control GC1/2估计一个共同时间单位映射c（reference ms/min，范围[.001,1000]）与首次可见的未结合概率a∈[0,1]。不能分别重调结合、解绑和消失率去追上数据。
3. 各S全部报告，若需要代表项只按训练似然选，不按已知测试结果选。原CG3只作相同资料上的探索性外推比较。记录端点/优化界、多起点与额外迭代；率单位、原始源及假设一并保存。
4. 同时报原单/双指数分数，明确它们是观察参照；不把双指数参数装回物理个体。若当前条件投影匹配不足，接下来定位观察映射、交换时间尺度或原物性约束，不自动添新状态。

本轮是把真实动态证据接到已有候选L的第一步，仍属于逆发育。完整果蝇验证还需要空间、伙伴身份、保持/回缩和实际干预的同方程联合重现。
