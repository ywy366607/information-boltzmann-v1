# 当前物理状态、观测概率与未来预测

2026-10-22。当前主线已经自然生长到52域，并交付痕迹→支持/导通/未来交换。继续推导时先解决一个真实歧义：现有端口NLL是明确的诊断分布，不等于脑内已经实现了那个分布的计算。

## 1. 从代码实际拥有的量出发

`learning_observation.port_bit_logits`令每bit的logit为2 C_eff A V_brain，然后将8个独立bit概率相乘，给出256字节的分布。它在输入之前测量，因而是合法的前序评分；但其系数/分解是一种固定观测约定，未证明它是自然文本的条件似然或主体的未来预期。

Claude原`medium.py`保留了局部可塑性/支持过程，`v0.py`则另有预测读出和局部似然更新。新热力学核继承实际物料与相遇/身份规则、重写有限占据生成元；尚未把V0读出及其更新以物料/储能/有限速率闭合后接入。不能因为r/C参与动力学，就把上述外部logit约定当作已经闭合的内在预测回路。

当前电势不平衡、原生电流及电荷转化都是真实可观测量；“能解释当前输入”与“在输入前对未来形成可检验的预期”还要区分。新的预测状态若有必要，须明确它保存什么、怎样改变原局部通路和怎样付款；不将NLL、probe系数或外部标签直接当作电荷/营养。

## 2. 为什么坏NLL不能唯一定位物理缺口

令H是全部过去的因果信息，X是当前可观测内部状态，Y=(Y_1,…,Y_8)是下一字节。固定诊断采用q(Y|X)=∏_b q_b(Y_b|X)。按条件熵恒等式：

    E[−log q(Y|X)]
      = H(Y|H) + TC(Y|H)
        + Σ_b I(Y_b;H|X)
        + Σ_b E_X KL[p(Y_b|X) || q_b(Y_b|X)]

其中TC=Σ_b H(Y_b|H)−H(Y|H)≥0，且X可测于H。四项分别是环境本身的不确定性、独立bit分解的损失、当前被测状态未保留的可预测信息，以及观测概率不匹配。式子只使用概率定义/条件分解，不新增脑内目标。

因此端口NLL上升不能独自说明是哪一项上升。对有限维的拟合观察器也不能反过来声称已估计全部信息量：它只检验某类读出能否访问预测信号，不是最优条件分布，更不代表全脑所有信息。

## 3. 固定外部观察器，保持身体学习不变

先在原专业OWT的新训练字节中记录输入前的端口电势、因果源滤波、上个实际字节及已有桥/池通道的瞬时端口电流。最后一项由原OU流与局部反应生成元直接求和，不含未知新源；域相变项没有空间接受率积分，故明确叫“桥/池条件电流”，不冒充完整出生生成元。

仅拟合外部冻结的低维观测概率：对角仿射16参数、全仿射72参数、双特征136参数。比较相同容量的脑端口/因果源/上字节，以及脑+源/源+上字节；另给匹配训练预算的字节和bit频率基线。不预设脑端口应获胜，也不因某个拟合好就把它装回脑中。

训练时的中心、尺度、先验和全部系数在验证前冻结；在新的独立语料split中先预测再输入，物理脑原生学习持续，观察器不更新。原raw端口分数仍原样报告。观察器没有反向通路，原物理参数/三RNG/载体和新旧游标不受它影响。

若观测校准已能消去大量raw损失，但仍未胜过同预算源/频率，那么当前结果应定位为“原约定过度自信、被测状态的额外预测信号尚未交付”。若有稳定额外信号，再沿它所对应的物理自由度推导内在预期及其局部反应；不是把外部观察器的梯度回传。
