## 什么叫"严格生成、不要补丁"

1. **公理只证一次，证整类。** 世界与生物都是同一个 Lean 类（`CGB.NestedWorld`）的实例；类里的规则语法要足够一般（任何守恒、可逆、接在边界上的事件），由一条定理证明整类都是公理模型。不为某个想要的行为单独加机制。
2. **结构与数值都由生成决定。** 哪些规则存在（体内、交换、耦合交换）由语法枚举候选，速率与能量由选择定；速率压到下限等于"这条规则不存在"。我不挑结构。
3. **适应度来自世界内部。** 生物在世界里分裂繁殖，后代带着有变异的基因组；谁留下的后代多，谁占满世界。外部选择器（GA/ES）只作为对照或启动，最终的物种来自世界自己的演化。
4. **量尺由物理与原则定，在运行前写定。** 世界的生态位按"可行、感知有用、最省"声明（已完成，见 `rain_torus_w0.json`）；生物的常数按物理原则声明，不按结果调。
