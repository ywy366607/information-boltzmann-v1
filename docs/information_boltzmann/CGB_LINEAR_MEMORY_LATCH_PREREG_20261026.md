# 推论：线性递推记忆不能锁存；给 Gated DeltaNet 加锁存槽（预注册，2026-10-26，实验前写定）

## 1. 把 GDN 放进体系

Gated DeltaNet 的每一行状态 x 更新为 x ↦ α(x − β⟨k,x⟩k) + 写入，其中 ‖k‖=1，β∈[0,2]，α<1。

| GDN | 体系 |
|---|---|
| α（标量门） | 不选择的排出（G17：不选择的排出会遗忘一切） |
| (I − βkkᵀ) | 选择性排出：只擦除 k 方向 |
| βvkᵀ | 写入（摄入） |

Lean 定理在 `GenerationLinearMemory.lean`：

| 定理 | 内容 |
|---|---|
| `dot_delta`、`delta_nonexpansive` | ‖x − β⟨k,x⟩k‖² = ‖x‖² − β(2−β)⟨k,x⟩² ≤ ‖x‖² |
| `deltaStep_sub`、`gated_delta_contracts` | 两段历史的状态之差每步按 α² 收缩（平方范数），写入项相消 |
| `histories_merge`、`histories_merge_uniform` | T 步之后差距 ≤ ∏α_t · 初始差距；若 α_t ≤ ᾱ < 1，则 ≤ ᾱ^T。记忆视界有限 |
| `linear_hold_keeps_error` | 线性映射若保持信号 s（Ls = s），就同样保持沿 s 的扰动：L(s + t·s) − s = t·s。**线性记忆的保持与纠错绑在一起**，正如平衡态的写入与遗忘绑在一起（G24）。纠错需要非线性的吸引子，也就是锁存 |

**已有工作（查过）**：G17 预言"排出必须选择性"，这一方向已由 KDA（Kimi Linear，逐通道衰减）和 Gated DeltaNet-2（逐通道的擦除门与写入门）实现，并在语言建模上取得改进。这是对体系的外部验证，不算新贡献。DeltaProduct 和负特征值改进的是状态追踪的表达力，仍然是线性、非扩张的。**我们没有找到**"线性记忆无法纠错，因此需要非线性锁存槽"这一论证在 LLM 架构中的对应工作。

**本质与现象**：锁存是现象，条件是"有界状态 + 噪声 + 长且可变的延迟"。语言中存在这种条件（长程的离散状态，如嵌套、指代对象、开着的引号），低精度推理（手机、int8/fp8 状态）又放大了噪声。

## 2. 实验

- **任务**：flip-flop。每步一个指令：w0/w1 写入一个比特（概率 0.1），i0/i1 忽略并带一个干扰比特（0.8），r 读出（0.1），读出时要输出最后写入的比特。训练长度 256；测试时写入与读出之间的间隔 G ∈ {16, 64, 256, 1024, 4096}，中间全是忽略指令。
- **公理条件**：状态有界（每一步后裁剪到 [−1,1]，即 P1a 的有限容量），每步加噪声 σ·N(0,1)（低精度舍入）。σ ∈ {0, 0.02, 0.05}，训练与测试使用同一 σ。
- **模型 A：GDN**。d_k = d_v = 16，q、k 做 L2 归一化，α = exp(−softplus(·))，β = sigmoid(·)，单层，读出头读 [Sq, 输入]。
- **模型 B：GDN + 4 个锁存槽**。z ← tanh(a ⊙ z + Ux + c)，a 初始为 2（增益 > 1，可双稳），可学习；读出头再读 z。z 同样加噪声并裁剪。
- 每个配置 3 个种子，训练 3000 步，batch 64，Adam 3e-3。

## 3. 预言

| 编号 | 预言 |
|---|---|
| L1 | σ = 0.05 时，A 在 G = 1024 上的读出准确率 < 0.75，B ≥ 0.95（三个种子的中位数） |
| L2 | σ > 0 时，A 的准确率随 G 单调下降（无恢复力，噪声随机游走）；B 在 G ≤ 4096 内保持平坦 |
| L3 | σ = 0 时，两者在 G ≤ 256 上都 ≥ 0.95（任务可学；差别来自噪声，不来自容量） |
| L4 | B 学到的 a 中，至少有一个槽的增益 > 1（双稳），并且被用于读出（把这个槽置零后准确率下降 > 0.2） |

**失败的出口**：若 A 在 σ>0 时仍能长程保持，就检查它是否利用了裁剪边界（单侧恢复），并改用"投影到球"的有界方式重测。若 B 失败，检查它的槽是否学成了单稳（a < 1），以及写入是否被干扰比特扰乱。

**修订（冒烟测试后、正式运行前）**：在 GTX 1650 上每个训练步约 0.8 秒。为把总时长控制在约 3 小时，训练长度由 256 改为 128，步数由 3000 改为 1500。其余设置和预言不变。

## 第二部分：锁存需要守恒（导演追问后补，第二个实验运行前写定）

第一部分的锁存槽是 z ← tanh(a⊙z + Ux)：有饱和，但**没有守恒、没有选择性释放、增益无上界**。一旦学得 a 很大，输入就翻不动它，槽会锁死，成为吸收态。这在单比特任务里检验不出来。体系要求：

| 需要 | 依据 | 层 |
|---|---|---|
| 锁存可释放 | G16 `export_forced` | 本质 |
| 释放有选择性 | G17 `retention_needs_selectivity` | 本质 |
| 不可锁死 | `irrecoverable_absorbing` | 本质 |
| 每个扇区一次一项（不全亮、不全灭） | R1/R2、P2a | 现象（类别型内容） |
| 不让少数槽包揽一切 | G22c `shared_potential_forces_nesting` | 现象（共享资源） |

**模型 C：守恒扇区锁存**。共 8 个扇区，每个扇区 2 个槽，z_s 在单纯形上（守恒，Σ=1）；更新为 z_s ← normalize(r_s ⊙ z_s^a ⊙ exp(U_s x))，即 G13 的玻尔兹曼形式加自激指数 a。r 是每个槽的局部储库：占用时以速率 ε 耗竭，空闲时以速率 ρ 恢复（G22a），二者可学，并约束在 (0, 0.05]。读出用 z_s 的第一分量减 1/2。

**任务：多寄存器 flip-flop**。4 个寄存器，指令为 w_j b（写寄存器 j）、i b（忽略，带干扰比特）、r_j（读寄存器 j）。训练长度 128；测试时每个寄存器写一次，然后经过 G 步忽略再逐个读出。噪声 σ = 0.05，状态有界。

**对照**：A（GDN）、B（GDN + 8 个 tanh 槽）、C（GDN + 8 个守恒扇区），每个 3 个种子。

| 编号 | 预言 |
|---|---|
| C1 | G = 1024 时，C 的读出准确率中位数 ≥ 0.9，且 ≥ B |
| C2 | 锁死：测试中给每个寄存器反复写入相反的比特，统计符号从不翻转的槽（或扇区）的比例。B 的这一比例 > C，C ≤ 0.1 |
| C3 | 用量均衡：按每个槽（扇区）对读出的贡献（置零后准确率的下降）计算基尼系数，C 的基尼系数低于 B |
| C4 | A 在 G = 1024 时 < 0.75（与 L1 相同的机理） |

**失败的出口**：若 C 不如 B，检查储库是否耗竭过快，使保持时间短于 G（局部储库的速率是现象参数，需要 ε·G ≪ 1）；若 B 也没有锁死，说明在这个任务里单靠饱和就足以防止赢家通吃，那么守恒的必要性要在更强的竞争条件下（寄存器数多于槽数）再检验。
