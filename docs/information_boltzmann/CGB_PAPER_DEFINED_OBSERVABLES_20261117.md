## 公式清单

1. Box 1：实际各阶信号的直和 Ψ=(θ,φ,ξ,...)；实际边界矩阵 B[n]；Hodge算子 L[n]=B[n]^T B[n]+B[n+1]B[n+1]^T。报告各阶谱、核/Betti数及信号在梯度、旋度、调和子空间的分量。边界矩阵必须有实际结构依据。
2. Box 2式1及其序参量：φ-=B[n]φ，φ+=B[n+1]^Tφ；X±=mean(exp(iφ±))。同时报告复数、幅值和时间轨迹，不能用PCA比例或一般头对PLV代替。
3. Box 2/图3：实际有向环路O上的 Xo=mean_{α∈O}(exp(i*sα*φα))，sα随该环路方向取±1。测不同真实环路的幅值、相位和时间演化；不预设环路是空洞或填面。
4. Box 3式3/4：由同一实际B构成跨阶Dirac算子D；报告D的谱/本征态、DΨ和D²=diag(L[n])核对。计算DΨ与本体满足Dirac动力方程必须分别给证据。
5. 图4：若报告带质量Dirac算子D+γ0*m，需明确m为分析参数；其谱和ρc(E)是对应算子的量，不是模型实际物理能谱。不能把人为设置的Dirac模拟叫原身体的轨迹。
6. 图5及其三元渗流原始研究：由实际结构连边开关定义结构网络，由实际调控者→目标连边定义调控网络；原序参量为R(t)=最大连通分支节点数/总节点数。实际连续作用保留原连续值，无原生开关时不能阈值化后宣称原模型发生三元渗流。周期轨道/分岔图需真实控制参数扫描和轨迹，不以一次自然波动替代。
