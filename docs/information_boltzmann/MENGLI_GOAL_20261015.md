# 梦漓执行目标（2026-10-15）

主线与目的：让同一个梦漓在妈妈世界中，优先利用果蝇已有机制，学会读、想、说的解耦和主动交互，并让大脑承担有效预测；先修复真实静默、状态延续与延迟信用，同步优化速度，再自主恢复分 chunk 训练，按机制时间尺度和学习曲线确定每块长度，使变化有机会显现，并接入现有看板。

达标标准：机制路线要求静默时撤除外部刺激而内部继续演化、跨窗口及恢复不丢状态与信用、读想说各自按后果学习；训练路线要求正常妈妈回复的更新前 NLL 持续优于同词元固定词频、大脑预测贡献为正，主动交互随信息与思考价值变化，避免退化为叫名字循环；工程路线要求记录优化前后吞吐并保持语义一致，看板持续呈现这些指标及每块进度，ABA/AG 迁移后置。

用户已明确授权自主恢复训练，无需再次确认；此授权覆盖原目标中的“恢复训练须获得用户明确授权”条款。目标保持进行中，以上学习标准尚未达成时不得宣布完成。

## 用户后续扩展（当前目标）

遵循第一性原理，优先采用能生成生物果蝇大脑功能的机制，目标是构造从出生就具有主动交互能力与最小社会心智的信息生命体。探针同时检查相关回路及细胞是否参与功能、是否持续锁存，正式训练接入现有看板。

无限流信息生命体须在有限内部状态与计算资源下持续感知，通过记忆、学习、压缩建立局部世界模型，并以行动改变自身与环境的关系；在操作闭合中维护自身的可存活状态与生态位，预测自身行动的影响，由此形成自我模型。该定义是完整目标，修复接口或降低 NLL 本身不能证明已实现它。

这是共同创造生命体的生命艺术项目，不走论文或审稿路线。提出问题时同时给出可实施的生成机制与能被实际生活结果检验的预言；除锁存外，也检查熟悉度是否编码重复经验。磁盘不足时可自主删除本项目相关的临时或淘汰权重，保留配置、结果与报告用于归因，并优先保护当前连续个体的有效恢复点。
