# 生成大肠杆菌：梯度世界的预注册（2026-10-26，搜索前写定）

**用户问：大肠杆菌还不能生成出来吗？**觅食世界生成的个体已经有奔跑—翻滚的核心策略，但大肠杆菌的标志是时间比较与完美适应。觅食世界不要求这些，选择也就不会生成它们。所以要换成大肠杆菌的世界。

## 1. 世界（固定）

- 一维环形空间，长 L = 400，位置连续。浓度场 c(x) 是 6 个高斯峰之和，峰高在 [1, 100] 之间按对数均匀抽取，宽度 σ = 25，另有本底 0.01。每个种子重新抽取峰的位置和高度。
- 个体每拍以速度 v = 1 前进。马达状态为 1 表示翻滚：本拍不前进，方向随机重抽为 ±1。
- 每拍摄入 = c(x)/C_ref，C_ref = 20；成本固定为 0.5；储备的初值与上限沿用觅食世界（150 / 300）。
- **接口**：食物页 F 的储库势 μ_F = ln c(x)，这正是化学势的形式。马达页 M 只有 1 个单元，由世界读取，其储库势为 0。去掉到达页，因为这个世界里没有"到达"。

## 2. 搜索（与觅食世界相同的选择流程，只换世界）

- 内部页 0–3，单元数至多 64（为了检验上一轮的锐度预言，单元上限放宽）；能量与规则全部由选择决定。
- 内部规则必须守恒含量（M3），所以每个候选自动过门。
- 适应度为 4 个训练种子、2 万拍的存活；评估在 8 个留出种子上进行。

## 3. 推论（纸面推导，写在搜索前）

浓度的绝对尺度在不同峰之间相差上百倍。任何"浓度高于固定阈值就继续跑"的策略，不可能在所有峰上都对，这与 G10b 同构。浓度乘以常数，即 μ 加上常数；在这种平移下保持有效的策略，只能依赖 μ 的差，也就是时间比较。μ 恒定时反应回到基线，就是完美适应。

| 编号 | 预言 |
|---|---|
| E1 | 时间比较：μ 刚上升时 P(翻滚) 低于 μ 刚下降时，至少低 30%（按上一拍的 Δμ 分组） |
| E2 | 适应：在固定位置给 μ 一个 +2 的阶跃，翻滚率先下降，20 拍内回到阶跃前水平的 ±30% 以内 |
| E3 | 有一个内部页的占据量跟踪近期的 μ（与过去 10 拍 μ 的滑动平均的 Spearman ρ > 0.5） |
| E4 | 致盲（μ_F 固定为 0）后存活接近随机奔跑—翻滚 |
| E5 | 存活显著高于"从不翻滚"和"按固定概率翻滚"的对照 |

## 4. 失败的出口

- **E1 成立、E2 不成立**：时间比较出现了，但没有完美适应。这时检查峰高的范围是否足够大，因为适应的必要性随尺度范围增大。
- **E1 也不成立，但个体能活**：检查它用的是绝对阈值还是别的线索，并检查世界是否真的要求时间比较（与理想策略对比）。

## 修订（冒烟测试后、正式搜索前）

冒烟测试（种群 12，2 代）显示，在固定成本 0.5 下，"从不翻滚"能活满 2 万拍（平均摄入 1.05），因为绕环一周会经过所有峰，致盲个体同样能活。世界没有对趋化提出要求。修订为：**每个种子的成本取该种子环上平均摄入的 2 倍**。此后任何被动策略都无法维持，只有留在高峰附近才能存活（高峰处的摄入可达 2–5）。这与觅食世界把时程改为 2 万拍是同一类标定，只改世界，不改个体，也不改预言。

## 第一次搜索的结果（s0，2026-10-26）

种群 48，80 代，训练世界 4 个（种子 1–4），留出世界 8 个（101–108），存活按 [最小 | 中位 | 均值 | 最大] 报告：

| 个体 | 存活 | 平均摄入 |
|---|---|---|
| 进化个体 | 45 / 124.5 / 5093 / 20000 | 1.23 |
| 致盲 | 45 / 124.5 / 2794 / 20000 | 1.10 |
| 从不翻滚 | 50 / 116 / 172 / 541 | 0.75 |
| 固定 0.1 翻滚 | 45 / 140 / 523 / 2158 | 1.15 |

E1 ✗（上升后翻滚 0.96，下降后 1.00），E2 ✗（三个基线下都不适应），E3 ✗（没有内部页），E4 ✗（致盲远好于随机奔跑—翻滚），E5 ✓（但见下文，这是停留，不是趋化）。

**进化出的表没有内部页**：3 个 F 单元，1 个马达单元，翻滚率约 95%。在本世界里翻滚就是这一拍不动，所以它的策略是"原地停住"。它只在开局就靠近高峰的两个世界里活满。

**按第 4 节的出口检查。**世界是否要求时间比较：理想的时间比较奔跑—翻滚（上升时翻滚 0.05、下降时 0.9）在同样 8 个留出世界中的存活为 47 / **20000** / 12535 / 20000；"一降就翻滚"为 50 / **20000** / 15021 / 20000。世界确实要求时间比较，也奖励它。失败在搜索上：

1. **第 0 代随机表的最好适应度就已经是 5233.7**，80 代后是 5241：选择一步也没有前进。原因是训练世界只有 4 个，一个"开局在高峰旁"的世界就能让"停住"拿到 20000/4 = 5000 的均值。适应度主要是运气。
2. **G19（`memory_separates`）**：没有记忆的个体只看得到当前的 μ，分不出上升和下降。时间比较需要一个慢的内部池记住过去，加上一条比较路径；只有其中之一时没有任何适应度好处，单步突变跨不过去。这两点是 E1–E3 失败的原因，也给出了出口。

## 修订 2（s1，搜索前写定）

只改搜索的统计量，不改世界、不改个体的表示、不种任何结构：训练世界由 4 个增到 16 个（种子 1–16），种群 96，代数 120。预言 E1–E5 和留出世界不变。理由：适应度应当估计在世界分布上的存活，4 个样本时它被单个幸运开局主导。

再预言一条可证伪的：**s1 的最好个体至少有一个内部页**（G19：时间比较需要记忆）。若 s1 仍然没有内部页且 E1 失败，说明障碍在"两部件同时出现"上，下一步是推导在 M3 表里时间比较的最小结构，并检查它是否在单步突变可达的邻域内。
