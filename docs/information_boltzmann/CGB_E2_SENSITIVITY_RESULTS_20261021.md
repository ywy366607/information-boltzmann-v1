# E2：找到语言世界实际使用的布线（2026-10-21）

本轮完成了E2的功能检验定位：已学习参考脑利用当前真实文本改善预测，且感觉入口的快速输出承担可测收益。下一步可在这段有阳性对照的通路比较生成布线和破坏布线。生成规则保留功能仍待检验。

这沿用[主规划](CONSTRUCTAL_GENERATIVE_BRAIN_FRAMEWORK_20261018.md)§10/§11：用果蝇检验规则，再让规则在新介质出生、持续改造，迁入语言生态位。形态与功能证据并列记录，不把成年果蝇形状当最终目标。

## 1. 为什么先改E2的检验入口

旧E2四个各学1024词的新生儿，真实、类型重采样、生成器和null几乎无差。此次先在旧真实布线个体上切边：

| 旧新生儿诊断段 | 真实NLL | 全切NLL | 全切−真实 |
|---|---:|---:|---:|
| validation 60000起128词元 | 7.4032 | 6.9648 | −0.4384 |
| validation 61024起512词元 | 7.6658 | 7.5225 | −0.1432 |

初段MB、CX切除的变化分别为+0.00038、−0.00014。全切甚至改善预测，因此这个早期个体的全局NLL不适合证明“生成器保留了有用功能”。它不能据此判定果蝇结构、生成规则或局部学习的能力上限；1024词只是早期预算。

随后只读既有m_main存档，历史学过90112词，与旧E2使用相同r2图和兼容状态格式。本轮没有新训练、优化器步骤或BPTT。

## 2. 已学习参考确实在利用当前文本

每支都从相同完整物理状态和RNG出发，目标词、积分时钟相同；输入持续流入。先读63072起128词元，再预登记独立65000起512词元复核。

| 独立512词元段 | NLL | 相对真实脑 |
|---|---:|---:|
| 真实脑 | **6.8406** | 0 |
| 切断全部快速连边及KC→MBON隔室权重 | 7.7198 | +0.8792 |
| 仅把感觉输入换为32词以前的内容 | 7.3907 | +0.5502 |
| 语言头仅保留已学偏置 | 7.1392 | +0.2986 |
| 独立校准的固定读出状态 | 7.2162 | +0.3757 |
| 原样恢复sham | 6.8406 | **逐项完全一致** |

固定读出只使用63072段真实脑128个读出向量的均值，经同一read_norm/decoder预测新段；没有在新段拟合。偏置基线是历史语言头的已学偏置，**不是独立估计的固定词频模型**。滞后输入分支只看更早的实际词，不包含未来目标。

全切损失在前128词元段为+1.0090，在独立512词元段为+0.8792。独立段也胜过两种静态基线，支持其收益包含当前输入相关的时变脑状态，而不仅是语言头依赖一个持续背景。

分成连续32词元块，做5000次块重采样的段内描述区间：全切差[0.6733,1.0714]，输入滞后差[0.4561,0.6579]，固定读出差[0.3028,0.4519]。这只描述该有限段的波动，不代表跨语料泛化或收敛。

## 3. 沿实际感觉入口找到功能通路

MB、CX切除在512词元段分别变化+0.0091、−0.0047，描述区间均跨零；较短前段符号与幅度也不稳定。因此它们目前不适合以全局NLL验收重采样。区域活动改变说明干预到达了回路，预测收益需要另证。

下一项按既有ReceptorWriter.injection_index选入口，不按结果筛选类型。在独立67000起256词元，保留感官输入，仅切断14426个入口细胞的快速输出：769092条兴奋边、64005条抑制边；这些入口没有另走KC隔室权重的边。

| 感觉出口定位段 | NLL | 相对真实脑 |
|---|---:|---:|
| 真实脑 | **7.3233** | 0 |
| 感觉入口快速输出切断 | 7.7312 | **+0.4078** |
| 输入滞后32词 | 7.7513 | +0.4279 |
| 原样恢复sham | 7.3233 | **逐项完全一致** |

切除损失在后半段仍为+0.4928，段内块描述区间[0.3010,0.5411]。这里得到的是**感觉入口→内部快速传递→预测**的急性功能证据。尚未隔离其中哪类连接规则关键，也不能把切断全部出口等同于破坏细胞特异匹配。

## 5. 下一步：在已定位的通路比较规则

E2继续检验**生成规则保留了什么功能**。现在有了实际调用的感觉出口靶区，下一比较应分开：保留类型匹配但重新分配细胞、保留粗粒度边际而破坏类型匹配、由已拟合的相遇×定向匹配规则采样。对照同时记录边数、权重、延迟、度和感觉/读出覆盖，避免把总传递量改变误当匹配规则的作用。

覆盖清单已经实际核对：3000类强度与发生程序身份顺序一致，空间程序其中2822类有描述校准。感觉入口14426个细胞中11661个具有强度身份；但在原r2图的844194条感觉出口边里，两端身份都覆盖的仅50.40%，两端类型都有空间描述校准的仅4.88%（41223条）。该空间子集均在抑制边表，兴奋性感觉出口没有两端空间类型均覆盖的边。缺口不是继续微调分叉数可以解决的。

原图边数与前节切掉的非零边数不同：后者使用已学习权重，原图还含后来为零或受约束的边。覆盖统计也仅证明身份/空间描述可调用，并不证明真实细胞对几何已经校准。完整清单见`results/published/cgb_e2_target_coverage_20261021.json`，入口为`e2_target_coverage.py`。

这里的4.88%仅指新空间描述程序的两端类型校准覆盖，**不是Claude已经完成的相遇研究或真实骨架重叠数据只有4.88%可用**。E1b/E1c的无方向/有方向重叠、V3b的1µm接触及半径项，以及后续发生率接口均是现有资产，直接复用。

因此不能直接把现成生成器套到整个入口后称为完整重采样，但E2也不必等待新空间程序覆盖全部入口：先复用真实骨架相遇特征和已拟合定向身份，在明确覆盖的靶区比较生成/破坏匹配，未覆盖部分单列，不暗中保留后声称全区已生成。由身份长出新几何、再产生新接触是出生程序的独立问题；身体与脑内生成的边界按§8显式保留，不据这项覆盖统计另起一条相遇研究路线。

既有读出下的急性替换只回答兼容性；新介质出生个体的持续学习、后果调制和生态位收益仍按§10推进，沿用局部过程，不在个体生命内重新引入全局BPTT。
