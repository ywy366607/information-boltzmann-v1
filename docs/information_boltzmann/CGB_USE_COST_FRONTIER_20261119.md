## 误差和收益的可计算界

后果预测以条件均值为目标，平方误差的可达下界是0；评价单次随机后果时，最优均值预测的风险是条件方差。当前模型内的动作抽样方差可由原actor概率和原Q直接计算，schema5三条平均0.000514052；它描述当前模型内部Q的动作抽样，世界回应及学习转移的实际条件方差要由对应后果估计。

原有限U支付是旧事实坐标Student-t对数密度的平均改善。固定当前encoder、共享先验beta_j、旧查询及最多N条证据时，后验scale2_j >= beta_j/(1+n/2)。密度在预测均值处最大，因此：

peak(n)=mean_j[lgamma((nu+1)/2)-lgamma(nu/2)-0.5 log(nu*pi*beta_j/(1+n/2))]，nu=2+n。

U <= max_{0<=n<=N} peak(n)-mean(old_scores)。`finite_use_bounds.py`直接计算当前固定条件的证书；它同时给每个查询最有利的峰值和最小尺度，属于宽松的乐观上界。真实同一个U、世界后果及共享参数决定这些峰值能否共同达到，真实任务的最优值由这些约束下的可兑现后果定义。

真实2493身体的一条归档事件、当前坐标中的用途上界为1.311873913；同一事件实际有限U用途-0.005437329。该数作为固定条件上界检查，运行目标使用前述同等时间真实学习收益。

### 数学对应与实现缺口

`NativeSuccessorAddress.lean::cell_constant_read_exact`验证的是地址内读值为同一v(a)时的质量合并。实码`joint_successor.reduce_cells`按地址分组，而`prospective_decision.value`继续使用每个代表点的连续raw边界计算问题、话语及原actor；同一fresh地址中的这些后续计算仍然随内容改变。下一优化直接在此处测同组内的价值变化，并按价值变化和动作排序影响分配精算预算。

设原分组质量w_g，组内真实平均后续值v_g，代表值r_g，则

`|V - sum_g w_g r_g| <= sum_g w_g |v_g-r_g|`。

这给“质量×组内价值误差”以明确位置。便宜4096点地址积分已经存在，昂贵部分是代表点的原生决策执行。先对fresh主质量和合并尾部追加成对、稳定身份的代表点，比较同一动作差值；对值近似相同的分支复用，对能改变当前排序的分支细分。所有质量保留，新增点来自原后继分布；固定样本序列、端口、世界时间和真实U继续共享。

当前1.31187支付证书固定坐标/先验/查询，并放宽所有查询同时达到密度峰值的约束。更贴近执行的参照是同一身体和可用动作集合里的最大真实期望后续收益。若模型估值误差逐行动至多epsilon，则该集合内的真实策略损失至多

`2*epsilon + [max_a Qhat(a) - sum_a pi(a) Qhat(a)]`。

因此同时推进预演校准和策略选择；单独把选择变硬会直接依赖当前估值误差。此式是代数分解；epsilon由相同条件下可核验的参考与真实后果校准，不由代表点之间的标准差代替。

### 执行顺序

1. 完成已启动的原话语和原评分合批整圈比较，确定等价执行的真实总时间。这期间活跃运行源码冻结。
2. 读取同边界原分层积分点与实际端口，在主质量fresh组和尾部做成对精算，测组内变化对动作差值的贡献，沿上述已有Lean映射绑定误差加权关系；直接进入同源整圈验收，比较实际用途、共同旧事实保持与总时间。
3. 预算调度以“额外计算对行动排序和实际后续学习的改善/耗时”为反馈。世界的新回应经土进入金，金分别校准木的估值和水的保留依据；下一次木从水读取已验证关系、决定哪里继续精算，火据此选择行动。稳定旧关系提供可复用计算，重要新关系获得额外预算。
