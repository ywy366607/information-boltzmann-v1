### 根本实现错误及真实复现

原critic单位由`language_navigation_kanli_v4b.SCALE=100`定义：`V=100*真实收益`。`world_cycle_step`却计算`y=g+γV/10`，随后继承`_settle_previous`再乘100训练critic。因此在critic自身单位下：

`旧目标 = 100g + 10γV = 100g + 8V`，而正确单位应为`100g + .8V`。

这不是经验调参：旧自举映射对V的斜率为8，正确为.8。它不证明完整非线性学习一定发散，但确实将原折扣自举变为放大，并污染critic误差、精度、TD资格调制及后续话语选择。316轮真实TD目标逐项复现最大误差0；critic误差EMA复现最大误差7.28e-12。相同已存估值上，旧目标与原预测的平均绝对差116.558，换正确单位后3.545；后一数值仅是固定日志的算术比较，不是修复训练后的收益。

另一处尺度交接：`continuation`预测10*g，草稿、开放角色及内部续行候选却直接乘按100*g critic误差计算的precision。修复统一先转换成critic单位，再用原precision；保持同一个收益，不新增探索奖励或放大温度。外层已有独立残差校准的作用不混入此换算。

新增`navigation_gain_units.py`封装换算；旧检查点默认schema0保留历史语义，下一事件边界必须显式`--repair-gain-units`迁移schema1。旧参数/Adam/误差EMA/观测收益/资格不清零、不直接重写；之后用正确目标继续学习。49项相关检查通过，含实际生产完整事件、Bellman导数、跨单位相同softmax及完整下一事件恢复。完整3884身体的修复迁移/实际学习尚未运行。
