# 从已有有限驱动推导局部适应，并定位V2时序缺口

2026-10-22。承接Claude的V2/T4d和当前原生端口结果；不增加BCM函数、活动均分目标或NLL奖励。先明确现有过程已经生成什么，避免把V2整套学习误称已迁入。

## 同一事件的实际门槛

当前内部写入由源端s向目标端t转移z份实际荷量，材料所有者i的P变D，载体r从0变1。边界写入的电源端是世界电容，材料所有者仍在身体，不能混作同一个索引。kBT=1，原联合自由能给出：

    ΔG_write = −z(V_s−V_t) + z²(1/C_s+1/C_t)/2
               −E_P + ε_r−χC + log[(D_i+1)/P_i]
    k_write = α_write expit(−ΔG_write)

这里每项来自现有电容储能、有限驱动、载体储能/互易结合和理想混合计数，没有新生物命名。令ΔG=0得到该正向事件达到一半尝试率的电势降θ；它不是净正反通量为零的阈值，因为反向事件在相邻配置上定义。

    θ = [z²(1/C_s+1/C_t)/2−E_P+ε_r−χC+log((D+1)/P)]/z

在固定电势、支撑、容量与载体时，一次共享P→D消耗使下一个可写位置的门槛上移：

    Δθ = {log[(D+2)/(D+1)] + log[P/(P−1)]}/z > 0，P>1。

P=1时耗尽后下一个正向事件不可准入，不是在物理自由能里塞无穷大。恢复D→P、实际输运以及域分配会继续改变同一门槛；恢复还交换原荷量，其能量/热账必须保留。此时“越用越难继续写”来自已付费的有限组成，不必另设“高于全脑平均就罚”。支持结合使θ降低χ/z；强活动既消耗驱动又可能留下r并捕获C，二者竞争，由原反应速度决定结果。

接口`local_learning.py`逐条核对原event_delta与原event_rate，直接暴露这项当前生效的学习本构，未替换求解器。它不反馈新的速率，也不把有限池的恢复时间强称生物秒级稳态。

## 与Claude已有V2的对应和实质缺口

Claude的medium.py已经包含快慢局部状态、K/P占据差形成的有符号标签、标签捕获及随自身慢活动变化的增强阈值。T4d在原实验中已有抵抗高频混杂的证据；新材料核保留其原型/归属，不把新接口通过当作该收益已经迁移。

当前物理核具备有限组成导致的适应、二态痕迹、捕获和空间后果；但它的直接写入亲和取决于**电势降**：抬高目标端电势会抑制正向写入。它不等同V2里输入先到、随后目标去极化共同产生的局部配对探测。仅把r相对均值叫“有符号标签”，或把log(P/D)改名“BCM”，都不能补上这个差别。

下一步沿既有自由度和允许转化求时序响应，分别检查电荷传播、P/D恢复、r及C的延迟；只有现有自由度确实不能承担必要的时序储存时，才引入有明确材料、储能和势垒的新配置。允许的最小扩展需给出反向事件与同一账，而不是把V2描述式阈值乘到原率上。

## 信息、成本与稳态各自的层次

给定噪声和可分辨动态范围后，特定信息最大化问题可导出响应分布；这不直接给出全脑活动均分。物理自由能里的配置熵不等于输出Shannon熵，二者不能混用。有限活动成本提供真实竞争，具体稀疏编码和有用分化仍须在实际流中验证。局部恢复可形成自身适应，不预设发言率或所有单元共同目标。

本轮先核对当前完整个体中上述门槛、实际消耗与恢复的方向，以及边界电端/材料端的差别。该结果是原生学习通路的具体定位，不自动证明时序学习、未来预测或完整主体。
