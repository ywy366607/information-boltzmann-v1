## 4. 定位到的价值压缩

`continuation`对取回槽i使用：

```
gain_i(z) = base[option_i] + confidence[option_i] * residual(z, action_delta_i, option_i)
V_cont(z) = sum_i normalized_weight_i(z) * gain_i(z)
```

32次决策的3类动作收益置信系数共96个值均为0，故这一路在实测状态中化为：

```
V_cont(z) = sum_{c in silence,generate,reuse} p_c(z) * base_c
```

`p_c`是该次取回并加权的经历在各动作类别上的总权重。不同未来状态仍可改变地址、类别混合权重，其他直接经历收益支路也仍在运行；这一路的状态价值通过三个类别基值交付。脚本核对了全部有支持的实际未来值均位于这三个基值的最小值和最大值之间。

| 同期原记录 | 正常 | 最大群撤回 | 同量随机撤回 |
|---|---:|---:|---:|
| 8轮中实际话语改变默认顺读落点 | 6 | 8 | 6 |
| 内容收益原预测MSE，单位(10g)² | 2.35665 | 0.42017 | 2.10418 |
| 类别基线收益MSE，同单位 | 0.10113 | 0.04038 | 0.58444 |
| 草稿分布距均匀分布平均TV | 0.003115 | 0.003510 | 0.003386 |
| 取得非零收益训练梯度的轮数 | 8/8 | 8/8 | 8/8 |

正常分支原预测MSE约为类别基线的23.3倍。校准依据累计实际误差抑制这项预测，符合其功能。`_compose_prediction`训练使用 `base+residual`，`_compose_used_prediction`交付使用 `base+confidence*residual`；正常分支收益更新的梯度范数为0.381665—1.690729，采信为0时学习仍然运行。

这给出了可复现的整条解释：**行动可以切换真实输入；木的详细未来状态经过收益读出时被压缩；四份不同世界落点的候选得到接近均匀的选择分布；真实学习随后仍修订同一预测器及过去参与。**
