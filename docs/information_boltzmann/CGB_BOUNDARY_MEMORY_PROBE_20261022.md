# 实际边界痕迹的匹配原生跳变检查

256字节实跑已结束，原档不变。末态自然出现n=C=r=1的端口，也出现C=1/r=0的端口；据此追加本检查，不把它当原先盲预言。

对每个实际有r=1且D可用的已安装端口，从同一完整状态分支，分别条件执行两个原来就允许的反向跳变：write−和active−。它们产生完全相同的电荷迁移、P/D转化，前者另外使r从1变0。两条跳变均使用实际ΔU/ΔG并记热；不直接给r赋值，不忽略复位成本。此处是在允许的转移上作条件因果干预，不假装这些跳变在自然实跑中恰好被选中。

核对两条跳变之后所有物理数组除port_trace之外相同、三个RNG相同；能量／自由能之差必须正好等于该存储配置项，全部收支闭合。在此同电荷、同物料的条件下比较原边界解绑速率、派生导通，再继续同一下一真实字节4ms。active−的同态sham须逐位一致。随后差异可经原反应与场动力学继续传播，属于痕迹的条件因果交付，不直接解释为预测收益。

不强制制造可用端口；无符合条件者标未测。有多个端口就全部报告，不挑响应最大者；只保存第一组两条完整末态，其余可由父档、端口和原生跳变精确重建。全部新经历在独立副本，原候选与其游标不改。

上述四个自然端口的原生跳变检查完成后，再追加冻结场的物理可辨别性分析，原始跳变结果不改。对同一post-jump配置，T4ms、同温、其余源位保持给定，仅比较该源位±3两个假设；精确Gaussian通道给出`KL=0.5 Δmu^T Sigma^-1 Δmu`，等先验最优二假设错误率为`Phi(−sqrt(Δmu^T Sigma^-1 Δmu)/2)`。报告全部四口，不以结果选物性或改读出；这是条件仪器的辨别能力，不是主体已识字或形成内在概率模型。
