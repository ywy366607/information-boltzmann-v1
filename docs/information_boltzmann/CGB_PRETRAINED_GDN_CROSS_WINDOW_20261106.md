# 预训练GDN：跨结算窗的连续学习对照

## 问题与共同转移

用户确认：短窗NLL仍可作为当前教学信号，但必须跨很多结算窗观察长期经历的作用。本轮接续同一纯GDN语言实例，保留“当前上下文取回旧经历→当前参数重算旧局部响应→进入当前语言预测→当前误差修正门控、投影与取用”的共同转移。定义仍以完整生命体闭环为目标；这里只扩大语言学习段的运行与观察时间，不替换已有1792轮导航个体。

## 运行前固定的协议

- 权重：`m-a-p/340M-20B-GatedDeltaNet-pure-baseline`，固定本地已验哈希的约4亿参数权重；原生分词。层号1、12（从0开始）。
- 普通BPTT每128词元结算；旧局部片段重算65词元。原生两层attention参数、编码器与读入口可训练；其余预训练参数保持既有值。
- 语言CE系数10，SIGReg系数.001；原生参数FP32主副本AdamW学习率1e-4，新增参数3e-4，weight_decay=0；沿用接口检查设置，不按验证结果搜索。
- 真实OWT数据版本 `433fe0f44ed7894fea29c08b3202aa348ccc6369`。A为train起始片段，B为train中偏移2,000,000的另一片段；源字节和最终词元流均存SHA256。它们是不同真实文本段，不预先声称是不同语义域。
- 共用4步512词元的实际暖启动，完整保存为两臂共同起点。随后A新读128步、B新读128步、A精确重访128步：每臂384次更新、49,152个目标词元。其中新到达32,768、重访16,384；跨阶段桥接位置照常计分，不重置递推矩阵、经历、权重或优化器。
- 容量固定512条，两层各256。此数由本轮流程要求得来：先走A、B合计256个窗口，每层每窗口一条，使A不会在B结束前被FIFO全部挤掉。预计片段/初态存储约600MiB，放CPU；每次仍只取每层2条。不是将每条定理各加一页状态。

## 对照和测量

主对照只有两臂：

1. **full**：旧片段用当前原生参数重算，当前误差沿此分支更新原生参数。
2. **held**：相同经历、相同取回、相同重算值，只将旧重算响应在当前编码器之前detach。当前编码器、读取偏好、读入口及普通BPTT仍学习。因此在完整共同起点，两臂前向必须逐位一致。

这一对照隔离的是旧计算的学习信用，不把记忆内容收益与其混为一谈。另每32步，在同一完整起点、同一参数版本和目标上，只遮掉源年龄>128的选中值，其他贡献不重分配；比较当窗NLL并记录实际年龄和权重。先对称复算原预测，差值必须为0。探针不修改经历、递推矩阵、权重或训练收据。

主要读数：完整流、真正首次到达目标和重访目标分别累计的prequential NLL（先计分后更新）；各阶段与桥接分数；超过128/1024/4096词元的取回参与；遮读旧经历的NLL差；每64步的独立validation及A/B未训练续文的冻结旁路评分。旁路从完整活状态分出，不写回主个体，不能冒充在线分数。

判读：full相对held的配对NLL差反映该预算内跨窗原生信用的净效应；旧值遮读差反映当前预测对历史内容的利用，两者分别报告。若新读、重访和独立文本取舍不同，就报告取舍。按连续16个窗口为块报告配对不确定性，仅代表本次单seed文本流，不作已收敛或所有语言任务的结论。

### 更早的接口：相对读取信用不能直接解释为保留价值

当前表满时`ExperienceMemory.read`始终将两条候选权重归一到和为1；`LayerExperienceRecall`没有当次空贡献竞争项。`RecallInlet`的投影可以整体学成零，但那是共享投影，不是每次读取的独立拒绝选择。两层全部置零及单候选空位在本次都仅是研究者的只读控制，身体本身尚不能据此选择未使用份额。

对局部混合`R=Σ_i w_i v_i`、`w=softmax(ell)`和当前调制`δ=∂L/∂R`，其加性logit信用为：

```
c_i = -∂L/∂ell_i = -w_i <δ, v_i-R>
Σ_i c_i = 0
```

所以它回答“比本次混合更该多用哪条”，而非“这条对不读是否有帮助”。若所有候选都不如某个空贡献配置，非零的相对信用仍会给其中一些候选正号。已完成连续运行里，各次原始`credit_sum`的最大绝对值FIFO为2.98e-8、信用组1.49e-8，与该零和结构吻合；读偏好参数的tanh链式系数及Adam处理后的数不要求继续零和。

因此更早的错接在**将相对混合偏好直接解释为持续占槽价值**。先前“保留→再取稀疏”的定位继续成立，但不是全部原因；本轮查出了它上游的共同参照问题。现行归一化矩可在第一次正相对反馈后给出较强保护，这不是校准过的未来价值。下一实现目标是让零贡献/未使用份额进入同一有限竞争，由当前语言误差同时训练用量与保留依据；这属于现有读取—结算—保留关系的修订，不另设外部奖励、食物或重要性账户。本轮**尚未实现该修订**，不将诊断空位冒充身体已有选项。

Lean对应边界保持明确：历史载体必要性要求保存需要区别的历史；held再激活构造允许在现在重用旧参与；它们都没有证明softmax的正相对信用就是长期保留价值。`GenerationSeedMemory.partial_has_hop`只证明其特定布尔环存在占据到空位的接触，`GenerationUnifiedOptimizer.real_transfer_total`证明其结构中两侧总额守恒；两者可供构造参照，不能仅因出现“空位”就记成本预训练身体已覆盖这些候选定理。本次不改Lean及覆盖数。
