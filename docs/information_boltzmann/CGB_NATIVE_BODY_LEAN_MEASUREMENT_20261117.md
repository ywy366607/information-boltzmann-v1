## 2. 动力学按实码表达

来源为 `bfss_gdn_capture.py::observed_momentum` 与 `adaptive_hamiltonian.py::potential/quiet`。
当前谱模式下，数学表达为：

```
prior = α S
Δ = β k (v − priorᵀ k)ᵀ
S⁺ = prior + Δ + admission_correction
P⁺ = α P + Δ

P½ = P − dt/2 ∇Φ(S)
S* = cos(ωdt) S + sin(ωdt)/Z P½
P* = cos(ωdt) P½ − Z sin(ωdt) S
P⁺ = P* − dt/2 ∇Φ(S*)
```

`Φ` 包含原码两个矩阵交换差的平方项、softplus 耦合强度和 sigmoid 内容权重；
`∇Φ` 对整个势能求导，包含权重随 S 变化的部分。
`ω` 使用学习到的基础坐标、内容上下文与 frequency_scale；Z 对应实际 impedance。
这里描述一个求解器子步，实际 subdivisions/steps 决定重复次数。
卷积历史、语言流和外层更新没有被上述矩阵投影取代。

Lean 已检查 `write_difference` 的代数恒等式。它用于校验状态缩减，没有重新提出该旧诊断为能力发现。

## 7. 从实际共享依赖生成可核查的高阶测量载体

对实际二部关系 `depends(relation, typed_unknown)`，采用候选 **Dowker 关联复形**：

> 一组关系构成一个单形，当且仅当原记录中存在同一个带端口类型的未知项，确实被组内每个关系依赖。

这是把二元关系变为关联复形的标准构造，见 [The Rectangle Complex of a Relation](https://link.springer.com/article/10.1007/s00009-022-02213-0)。
**它固定测量对象为共享未知关系的组织结构。** 没有增加身体存储、力或控制器；没有用共同活跃阈值、五行名称或程序输入数自动宣布存在一个面。
原文的测量量仍为 Hodge 算子/Betti 数/Dirac 算子；Dowker 负责明确这些量在哪个从实机导出的复形上计算，不是拓扑动力学论文原模型的同义词。

`NativeDowker.lean` 证明支持条件向下闭合。真实数据实例又检查：

1. 支持集合逐项对应原依赖；每个单形携带真实共同未知项 witness。
2. 0—3 阶单形完整：有共同支持的组合全部收录，边界面的端点、顺序和方向符号正确。
3. **B₁B₂=0、B₂B₃=0**，逐项整数检查通过。
