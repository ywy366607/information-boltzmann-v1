# 从“全连接组 SNN”到“功能性果蝇脑”的统一方案

> 后续接线状态以统一注册表及 `FLY_NATIVE_MOTOR_PORT_20261018.md` 为准。运动末端到语言外设已有实现和急性检查；下文初始盘点不能当作最新运行开关。真实身体反馈仍缺，不能把语言外设当作完整身体。

## 结论

当前系统可以准确地称为：**在完整 MaleCNS 连接组上运行的 COBA/SNN 动力学模型，并为部分蘑菇体和调质回路加入了生物机制**。它还不能称为完整的果蝇大脑，因为大量脑区虽然进入了通用膜和突触更新，却没有承担其生物系统职责。

这不是要给 5,619 个 ROI 各自添加一个模块。正确的单位是“有因果职责的系统”：感觉表面、嗅觉中继、蘑菇体记忆、调质、中央复合体、上下行身体回路、视觉通路、关联状态和内分泌慢变量。

## 什么必须固定，什么应该学习

### 固定的生物骨架

- 细胞和突触的解剖位置；
- 突触方向、Dale 符号和连接组延迟；
- 已知的细胞类型/超级类归属；
- 已知的快速突触切断、树突/轴突位置和 graded 细胞事实；
- 已有的神经递质预测和受体家族证据。

### 带生物先验的可学习量

- 各类细胞的膜、突触、适应和释放时间常数；
- 阈值、输入增益、局部抑制和传递效率；
- 调质的清除、亲和度、受体占据和下游效应；
- eligibility、短时可塑性、巩固和遗忘速率；
- CX 持续状态的漂移、竞争和行动选择增益；
- 身体反馈对感觉、可塑性和行动的影响。

学习量必须使用正值、范围或先验约束，慢机制使用较慢学习率。未知生理量不能被生物学常数强行标定，也不能用一个外部 reward/emotion/hunger 标量代替整条通路。

## 统一的动力学接口

每个系统都使用同一种接口：

```text
sensory / body input
    -> native state update
    -> synaptic and modulatory interaction
    -> persistent plastic state
    -> native output / action
    -> world or body consequence
    -> sensory / ascending return
```

其中：

- 膜电位和短时突触状态是短期状态；
- 突触效能、隔室记忆、eligibility 和慢调质是持久状态；
- 轴突负责时序和路由，突触负责传递和可塑性；
- 调质不是标签，而是改变受体、阈值、释放和学习窗口的物理变量。

## 统一验收，不逐个测

每次构建一个系统版本，统一运行同一套审计矩阵：

1. **Reachability**：解剖路径是否可达；
2. **Native activity**：输入是否经过该系统并产生符合时间顺序的状态/脉冲；
3. **Causal delivery**：同状态、同 RNG、同真实时钟下关闭该路径，后续原生状态、预测和行动是否改变；
4. **Persistent learning**：脑、优化器、RNG、物理状态、待结算信用和世界队列是否精确恢复；
5. **Closed loop**：动作是否改变身体/世界，后果是否由感觉和上行通路返回；
6. **Language capability**：在真实连续语言中用 prequential NLL、学习曲线和行动后果判断收益。

放电、形态、相关性和单次 NLL 只能分别记为活动、结构、相关或预测指标，不能合并成“功能已完成”。

## 实施顺序

1. **注册表驱动的全脑审计器**：先自动输出每个系统六层状态，停止手工逐个检查；
2. **统一调质/受体/可塑性接口**：把 dopamine、OA、5-HT、DPM、APL 统一成带先验的本地状态和效应接口；
3. **CX/CAN 持续状态与选择**：接入航向/上下文/行动竞争状态，但不凭空加入语义标签；
4. **ascending → descending → VNC motor → proprioceptive return**：形成真实身体后果环；
5. **ALPN/ALLN/ALIN/ALON 和视觉投射的专门时延与局部回路**；
6. **ENS/内分泌慢身体状态**：只使用可观测身体交换变量，避免 hunger/reward 代理；
7. **统一真实语言训练**：从保留分支开始，保存完整状态，主线保持可回退。

当前所有候选都应标注为“统一机制建设中”，不能把已经运行的通用 SNN 误称为功能性果蝇脑。
