# 付费学习期间的持续自维持：一个有限数学见证

这一轮将上一轮的候选筛选学习器接入满足六条公理、带实际资源消耗的有限介质。正常过程从未知状态取得反馈，支付一次内部改写，再依靠形成的记忆控制后续资源通路；沿用原来的 `Exchange` 评分，所有时刻的存活评分都是 1。禁止改写的配对过程保留相同初始燃料、感知、世界与时钟，第三拍起评分为 0。

这是明确规则下的存在性构造，回答“有限、付费的学习能否与连续维持共存”。安全辨识阶段和资源规则是本模型声明的条件；六条一般公理的作用是约束并验收这个构造。完整生命定义、自举目的及真实数据上的学习能力继续按各自目标验收。

## 1. 有限内部状态与因果顺序

身体有四个物理状态：真空、未知、已辨识 A、已辨识 B。未知状态同时携带一单位维持燃料和一单位改写燃料；两个已辨识状态各保留一单位维持燃料。候选集合、改写储备和动作都由当前身体状态解释，没有旁挂历史。

`memory` 将这四个状态映射到上一轮 `CausalLearning.Memory` 的可达部分。共同初始候选是 `{A,B}`，共同初始控制选择安全辨识动作。实际反馈使候选变成 `{A}` 或 `{B}`，具体动作由同一个 `certifiedOr` 选择器转成 A 或 B。

`paid_learning` 证明身体的反馈更新严格实现 `CausalLearning.advance`：它使用反馈到达前选定的动作，且燃料减少量等于该筛选器的实际改写支付。`acquired_control` 证明两类反馈确实形成不同的候选与后续动作。真实分支身份只用于陈述两种情况，不作为控制器参数。

| 时刻 | 身体与世界 | 资源收支 |
|---|---|---|
| 初始 n=0 | 同一未知身体进入安全辨识阶段；世界下一步返回 A/B 反馈，各占 1/2 | 储备 2；摄入 1，维持消耗 1 |
| n=1 | 身体读取实际反馈；本步改写，世界进入对应资源区 | 摄入 1；维持与改写共消耗 2 |
| n≥2 | 已形成的 A/B 记忆控制资源区通路；两个区域给出相同的取食刺激 | 储备 1；每步摄入 1、维持消耗 1 |

世界按旧身体状态推进，身体按当前边界反馈更新；没有让新写入的动作倒过来改变已经发生的反馈。辨识和改写占用已有世界步，感知持续进行。后续两个资源区的感觉输入相同，因此持续分支选择须由内部记忆承担。

## 2. 三组核心结果

| 核心结果 | 证书与范围 |
|---|---|
| 付费学习的介质实现 | `plant_admission`、`paid_learning`、`acquired_control`：六条公理、事件时钟 1、活体反馈步对候选筛选器的压缩实现和反馈依赖的控制选择；死亡转移清空身体。全部细胞均为边界的单细胞模型；一般多细胞架构与规则书编码另验。 |
| 学习与持续自维持共存 | `maintenance_witness`：原 `Exchange.Persists … 0` 与 `Exchange.SelfMaintains` 同时成立。正常评分全时为 1；原边际幽灵剪断过程第三拍起至多为 1/2。`frozen_survival`：仅抑制反馈改写的配对过程第三拍起为 0。 |
| 同一过程支付维持和改写 | `actual_law`、`account`、`availability_budget`：能量核与上述评分核完全相同，正常与剪断均有全部有限前缀的精确预算。额外改写消耗由具体规则指定，热端口使用实际消耗。 |

第三拍的禁止改写过程仍可能持有燃料，但资源已经不可达，故其存活评分先降为 0；下一步匮乏事件再清空身体。这个区别保留了原评分的含义：存活取决于当前身体及实际未来摄入机会，不能用“还有电”替代。

真空吸收、零储备关闭实际事件通道、A/B 取食后保留各自记忆也均已检查。旧固定控制见证和所有既有证明保持原范围。

## 3. 同一物料与能量账

身体总含量按本模型的燃料单位标定：未知为 2，已辨识为 1，真空为 0。所有正概率事件满足：

```text
后储备 + 实际消耗 = 前储备 + 实际摄入。
```

正常过程每个活动步摄入一单位；反馈改写步消耗二单位，其余活动步消耗一单位。匮乏不摄入，并清空剩余燃料。改写的一单位与持续维持的一单位分别计入，不能把未花掉的初始写入燃料当成学习效果。

对于正常和剪断过程中的任意有限前缀 n，已证：

```text
平均剩余储备(n) + 累计平均实际消耗(n)
    = 2 + 累计平均实际摄入(n)。
```

这些摄入是显式外部供给。当前没有将持续供给说成闭合有限燃料源或自行补能循环；下一步的来源实现应沿用既有物料搬运与补能验收。温度 1、内部与携带熵 0 的等温解释只核验声明账本的相容性；具体材料的能耗、熵和热浴标定仍需独立依据。

## 4. 它推进到哪里，下一步做什么

上一轮建立了通用的有限因果学习合同；本轮提供了其中一个在六公理介质内的可维持实例，并用禁止改写对照证明该实例的资源控制确实依赖反馈形成的记忆。

此实例只辨识一个保持不变的未知分支，支付一次后停止改写。候选支持表、安全辨识经验及其资源可支付性均由规则明确提供。持续流中的环境变化需要接着处理：从实际摄入补回可改写储备，在模型与反馈冲突时重新开放候选，并在相同世界时钟和存活评分下验证再次学习。模型只在概率上不同的情况，还需要预算内的统计证据积累。

完整编码与 1% 预算、感知中断耐受、完整 L1–L6 以及真实数据上的泛化分别保留为后续验收目标。没有运行训练或能力基准。
