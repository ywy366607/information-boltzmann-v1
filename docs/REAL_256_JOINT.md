# 256px 真实数据：同图联合训练

## 本轮要做什么

数字/1px 测试继续用于回归，不再把更多颜色、九宫格当成生图能力目标。
本轮直接以 256×256 原始数据的等比例缩放目标训练一个 Slice–H–Deslice 图，
不用外挂生成器，不增加私有任务骨干，也不调用 `lm.generate()`。

保留任务 TToken、控制前缀可见性、修复后的 `per_head` 高斯排列。
**不启用额外零值 sink/MoE 路由**：它不是已有任务 token 的同义词，之前的
sink 试验也没有证明它能解决生成。保留该可选机制，待出现具体路由证据再试。

## 数据：14 个固定监督样本

| 任务 | 本轮监督 | 数量 |
|---|---|---:|
| 文生图 | ShareGPT-4o 原始目标：热气球农田、波斯猫与港口 | 2 |
| 重建 | 上述真实数据图像本身，无文本证据 | 2 |
| 编辑 | 官方删除杯子、把水槽变红配对；同源图各加一条保持不变指令 | 4 |
| 图生文 | OpenGV 图像及原始描述的第一个完整英文句子，同时监督重建 | 2 |
| 分割 | DAVIS 黑天鹅/骆驼第 1 帧及官方前景标注，同时监督重建 | 2 |
| 下一帧 | 同一视频第 0、1 帧预测第 2 帧 RGB 和官方前景 | 2 |

ShareGPT 来源是本机已有原文件，不是手工画出的数字；其中生成图片不应冒称
相机实拍。身份编辑是明确登记的原图不变监督。I2T 是完整句子，不是人为编的
单词分类标签；也不冒称完整长描述或真正 IT2T 问答已经覆盖。

DAVIS 使用[官方训练/验证集下载入口](https://davischallenge.org/davis2017/code.html)，
只按 HTTP Range 提取两段视频的前四帧与掩码，校验 ZIP CRC，实际传输
2,686,251 字节；未下载整个 833MB 压缩包。训练只用前三帧，第 3 帧未用于本轮。
二值分割由官方对象 ID 合并为前景，不从 RGB 阈值伪造分割真值。

## 同一权重怎样运行

- d64、16 Slice、4 层、4 头；多模态部分从随机权重开始。
- Pythia-70m 使用已缓存的预训练权重，始终冻结。只有语言输出任务调用冻结
  decoder 来计算 token NLL；每生成一个文本 token 重跑同一联合图。
- 数据接口显式传递 `task_id`、图文精度、历史精度和 `target_time`。
  旧真实数据训练助手未传这些字段，本次独立入口完整传递。
- GDN-2 只在 `tau>0` 处理物理先验；静态生成/编辑仍是 F2 语义写入。
  视频没有动作标签，因此动作精度为 0，不伪造“向东走”。
- 新增 token 语言版本的同图未来后验包装：训练目标只进入观察后验 q，
  预测 p 始终接收原始历史。单测确认换未来真值不会改变预测 RGB。
- RGB 使用现有异方差 Gaussian NLL，保留 F2、同图转移 KL 和分割/文本似然。
  没有新增任意边缘损失、路由均衡项或循环。

4GB GTX1650 上，冻结 Pythia + 原生 256px 未来 p/q + 原损失反向已通过，
单样本峰值已分配显存约 **2,803MiB**。训练采用单样本更新。

## 训练和展示

入口 `scripts/train_real256_capacity.py`：初始 LR=3e-4，800 步余弦降至 10%；
前 160 步仅生成，然后循环全部 14 样本。每 200 步保存完整共享候选并更新
`present/real256_joint.html`，展示原图、目标、原生输出、真实/预测掩码和实际回答。
主干从零训练，不继承旧数字权重；旧成功检查点不覆盖。

```powershell
python scripts/prepare_davis_micro.py --cache D:/ml_cache/davis_micro
python scripts/train_real256_capacity.py --sharegpt-manifest D:/ml_cache/sharegpt4o/pilot_manifest.json --davis-manifest D:/ml_cache/davis_micro/manifest.json
```

训练不是能力通过的同义词。最后重新实例化、加载同一非 LM 权重及登记的冻结
Pythia 依赖再复测；不做权重平均，不把多份单任务权重拼成“冠军”。检查内容：

- 自然图同时看 PSNR 和边缘内容，不能只靠配色。
- 编辑保留同源图的不同指令对照，不允许记住源图就忽略语言。
- 图生文展示 graph-greedy 原始回答、EOS 和完整句子 exact，不只看教师强制准确率。
- 未来预测必须与“直接复制当前帧”比较，并报告去历史证据的变化；预测图像
  看着像下一帧不代表已经学会动态规律。

## 首轮结果：800 步，已独立重载

候选 `checkpoints/real256_joint.pt`，SHA256
`995a81e62c258d5d5f561fa0a1caea00c86b65cc9cc7966c0fbad1ff20c0acfe`。
完整记录 `results/published/real256_joint.json`；总耗时约 419 秒，峰值已分配
显存 2,821MiB。每张 T2I 目标实际呈现 126 次，其余各 45–46 次。

| 同一重载权重 | 起始 → 末尾 | 当前解释 |
|---|---|---|
| 文生图 PSNR | 9.86 → 18.29 dB | 边缘相关仅 0.024，仍是配色/平滑轮廓，不是内容过拟合 |
| 重建 PSNR | 9.86 → 26.25 dB | 边缘相关 0.724，源图结构已有明显恢复 |
| 编辑及 identity 对照 PSNR | 9.43 → 21.10 dB | 边缘相关 0.479；删除与改色的指令交换均影响输出，但尚不能称编辑准确 |
| 图生文 token NLL | 4.682 → 2.314 | teacher accuracy 57.7%，完整回答 exact **0/2**，EOS **0/2** |
| 官方分割 IoU | 0.077 → 0.186 | 未学好对象边界 |
| 下一帧 PSNR | 7.91 → 21.10 dB | MSE 比直接复制当前帧平均高 0.00217，动态预测未通过 |

生成交换提示后的 MSE 差分别为 +0.0315/+0.0297，说明文本确实控制了输出，
但主要作用仍是低频配色。两组同源编辑的指令对照也有正差，不能把这当作
已经正确执行局部编辑。未来去历史证据一正一负，必须保留该失败，不报宏平均
“世界模型成功”。原始错误文字回答直接保存在 HTML 和 JSON，不人工美化。

**结论：真实任务同图训练已开始并跑通，尚未形成统一能力冠军。** 384 项测试
通过，包括 token 后验目标隔离、冻结语言边界、真实银行时序与身份编辑检查。
下一步先在该固定银行增加有记录的联合训练覆盖，观察完整回答和内容细节；
不要因短程输出平滑就直接宣称必须 MoE 或循环。开放域泛化、纯文本问答、
真实 IT2T 问答、1px 保持与动作条件控制均不在本轮验证范围内。
