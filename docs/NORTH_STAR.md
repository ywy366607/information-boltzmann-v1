# Slice 全分辨率原生多模态：北极星

状态：**架构与验收的唯一来源**。理论等价关系、历史失败和单端口结果是研究证据，不得替代本页的产品目标。

## 1. 北极星不是某条能量曲线

本项目的目标是训练**一个架构、一个计算图、一个检查点**，原生完成文本生成、视觉知觉、图像生成、编辑、重建、分割和下一帧预测：

> 全分辨率视觉场 \(X\) 与语言序列 \(H\) 持续联合演化；固定数量的 Slice \(S\) 只是瞬态工作空间。所有能力由同一动力系统在不同模态精度、时间边界和观测似然下产生。

因此，不能通过外挂扩散器、独立分割骨干或端口私有主干换取单项分数。逐层能量下降、Hopfield/TTT/DeltaNet 等价和循环都是候选解释或后续机制，不是北极星本身。

## 2. 锁定架构

每个非共享层执行一次：

\[
(S_k,w_k)=\mathrm{SliceRead}(X_k),
\]
\[
(S_k^+,H_{k+1})=\mathrm{MoT}(S_k,H_k),
\]
\[
X_{k+1}=X_k+\Pi_k\,\mathrm{Deslice}_{w_k}(S_k^+-S_k)+L_k(X_k).
\]

- \(X\in\mathbb R^{B\times HW\times d_x}\) 始终保留原像素地址；不得被永久 patch/slice 序列替代。
- \(S\in\mathbb R^{B\times M\times d}, M\ll HW\) 每层重新从当前 \(X\) 读取。
- \(H\in\mathbb R^{B\times T\times d}\) 与视觉对等更新，不是静态前缀。
- MoT 使用视觉/语言私有 QKV、输出层和 FFN，只共享拼接后的注意力空间。
- 语义视觉写入必须经过 Slice/Deslice；一次调用只编码一次、终端解码一次。
- `need_text/need_pix/need_seg` 只选择监督与读出，不能改变主干动力学。

## 3. 一个图的能力闭环

“空白”必须由显式精度表示，不能把真实黑图或空字符串等同于模态缺失。当前边界坐标为图像精度 \(\pi_x^{obs}\)、文本精度 \(\pi_h^{obs}\)、动作精度 \(\pi_a^{obs}\) 和目标时距 \(\tau\)。训练目标还必须显式给出各终端观测的似然精度 \(\lambda_x,\lambda_h,\lambda_{seg}\)；输入缺失精度与目标监督精度不是同一个量。

| 输入边界 | 同时监督的原生能力 | 终端似然 |
|---|---|---|
| 图像缺失、文本存在 | T2T + T2I | 文本类别 + RGB 场 |
| 图像存在、文本缺失、\(\tau=0\) | I2T + 重建 + 分割 | 文本 + RGB + 点场类别 |
| 图像与指令均存在 | IT2T + IT2I 编辑 | 文本 + 编辑后 RGB + 分割 |
| 当前信念存在、未来观测缺失、\(\tau>0\) | I2I 先验预测步 | 未来 RGB + 未来分割 |

真实语言阶段把当前单 token 类别似然替换为自回归 token 似然，但不得更换视觉主干。传统重建与分割只是同一终端状态的不同观测模型。

时间方向必须按主动推理定义，而非把“world”当作任务标签：过去和当前观测先形成 (q(z_t\mid o_{\le t}))，再经动态模型形成未来先验

\[
p(z_{t+1}\mid z_t,a_t,H_t).
\]

训练时 (o_{t+1}) 是校正该先验的似然证据；推理时未来观测缺失，执行 prior-predictive rollout。动作条件进入同一转移即成为世界模型。当前单帧数字实验只是无动作、一阶 Markov 退化，不能冒充完整世界模型。

时间/动作属于转移控制面：逐层 zero-AdaLN 可以渐进注入 \((\tau,a_t)\)，但文本内容仍通过 MoT 与视觉交换消息。zero-AdaLN 不是跨模态接口，也不能代替历史状态。完整阶段必须让同一持久场接收 \((X_{t-N+1:t},a_{t-N+1:t})\) 的因果历史；当前 \(\tau\in\{0,1\}\) 只验证“一步当前/未来分叉”。历史不是第二个视频骨干：与 Transolver 的 NS 用法一致，同一欧拉坐标上的多帧场值先作为逐点有序特征进入一次全分辨率编码，随后仍走原来的 Slice–MoT–Deslice 主路。

### 固定地址如何演化

固定 Slice/Deslice 不等于静态场。官方 Transolver 的 NS 基准在固定 \(64\times64\) 欧拉网格上，把过去 10 帧作为每个网格点的输入通道，预测该点下一帧的场值；训练时滚动窗口使用真值，测试时把预测帧放回窗口自回归。Physics-Attention 也确实用同一组 `slice_weights` 完成 Slice 和 Deslice。流体“搬运”由非局部算子改变固定坐标上的场值，不是移动网格地址。因此“Read/Deslice 共用权重必然阻止未来运动”是错误的必要性判断；它至多是低秩基容量的待检验假设，不能驱动架构改造。

## 4. 主动推理统一层

统一的是生成模型和边界条件，不要求非共享层的标量损失跨层“共同下降”：

\[
\mathcal F_{t+1}=
\mathbb E_q[-\lambda_o\log p_\theta(o_{t+1}\mid z_{t+1})]
+D_{KL}\!\left(q_\phi(z_{t+1}\mid o_{\le t+1})\|p_\theta(z_{t+1}\mid b_t,a_t,H_t)\right).
\]

- 知觉：外部观测精度高，更新后验信念。
- 生成/编辑：缺失或低精度区域可写，语言先验给出偏好；`Deslice(μp−S)` 是当前 prior action。
- 未来推理：当前后验经 (p(z_{t+1}\mid z_t,a_t,H_t)) 成为下一时刻先验；未来似然只在训练/滤波时出现。
- RGB 用逐点高斯/平衡观测似然，文本与分割用类别似然。
- 每种终端似然按自己的观测精度逐样本加权；精度为 0 时该证据项严格消失。动态先验与后验输出有界对角 `logvar`，禁止用一个固定方差 MSE 冒充完整自由能。
- 未来后验必须由同一个 Slice–MoT–Deslice 感知图在“未来已观测、\(\tau=0\)”边界下产生；动态先验与未来后验在同一全分辨率 latent 图表中计算 KL，并共享 RGB/文本/分割似然头。
- 一篇 2026 年理论预印本给出了有条件的 SIGReg–主动推理对应：当编码器噪声固定，且 SIGReg 在总体上成功把表示约束为各向同性高斯时，LeJEPA/LeWM 的预测损失加 SIGReg 可化为信息瓶颈/VFE 的同方差退化。这不等于有限批次 SIGReg 就是本项目逐样本、状态条件的 KL。主线以显式异方差 \(D_{KL}(q_{t+1}\|p_{t+1})\) 为准，转移 SIGReg 默认关闭，只保留作已登记的退化对照。

F2 的 `gap=KL(q||q*)`、surprise 和 prior action 是规范训练组成；它们支持“VFE 训练的摊销主动推理”，不自动证明全局或逐层单调下降。

### LeJEPA / LeWM 参考边界

- [LeJEPA 官方最小实现](https://github.com/galilai-group/lejepa/blob/main/MINIMAL.md)是架构无关的多视图一致性加 SIGReg；没有时序 predictor，也没有 AdaLN。它可作为聚合后验防塌缩项，不能单独充当世界模型。
- [LeWM 论文](https://arxiv.org/html/2603.19312v3)把逐帧全局 latent 历史送入因果 Transformer，预测下一 latent；[当前官方代码](https://github.com/Mengarr/lewm/blob/main/src/lewm/module.py)在每层用 zero-init AdaLN 注入动作，并自回归 rollout。它只有状态流 \(x\) 和一个动作条件 \(c\)，没有 Goal/Action/Horizon 多通道；目标图像只在 rollout 后作为 MPC 代价，不进入 predictor。
- 可借用的是“因果历史 + 动作 zero-AdaLN + 下一信念预测”；不可借用的是另建全局 CLS 世界模型或只训练 latent MSE。我们的动态先验必须留在全分辨率 \(X\)/固定 Slice 主路，并继续接受 RGB、文本和分割似然校正。
- [SIGReg–VFE 理论分析](https://arxiv.org/abs/2607.13612)表明 LeWM 的 MSE + SIGReg 在固定编码噪声和总体高斯约束成立时可成为本框架的信息瓶颈/VFE 退化；论文也明确其经验验证仍待完成。LeWM 没有显式后验精度、观测重建项或逐样本状态条件 KL，因此本项目不在显式 \(q\|p\) 上重复叠加 SIGReg。

## 5. 先能力，后循环

当前顺序不可颠倒：

1. 用固定彩色数字场证明一个检查点同时完成四种边界、三种读出。
2. 对每个边界执行因果消融：去掉图像精度、文本精度、物理时距或 Deslice 后，对应能力必须显著下降。
3. 再扩展到连续位置、自然图像与自回归文本。
4. 基础能力准确后，才引入共享层循环或层内迭代，让高不确定区域获得额外读取次数；循环必须重读同一持久 \(X\)，禁止 RGB 往返。

循环验收关注“额外计算是否只分配给不确定区域并提高任务指标”。若要主张层内 Hopfield/TTT 式能量下降，必须另给同坐标目标和干预实验；若要主张全局变分下降，应在训练目标中显式定义并测量，而不是比较不同层的私有 F2 标量。

已发布生成证据：active-F2 检查点在固定 90 个数字×九宫格银行上达到数字、颜色、位置均 1.00；打乱数字词或位置词会破坏对应属性，关闭 prior action 使数字 top1 从 1.00 降至 0.478。共同 Anchor 能量并未跨层下降，因此“当前网络已实现全局 F-descent”已被否证，但这不影响能力北极星。

首轮统一检查点的四项综合分数为生成 0.930、当前重建/知觉 0.843、编辑 0.865、未来 0.375。前三项及相应模态消融通过；未来时距消融为负，证明原先仅把 \(\tau\) 加到输入坐标不足以形成动态先验。该失败直接触发了 zero-AdaLN 时序控制修正，不能用宏平均分掩盖。

zero-AdaLN 单独加入后未来仅为 0.382，且破坏前三项，故被否证为充分条件。再加入全分辨率固定方差转移 KL 后，未来综合分升至 0.415；时距存在时目标位置 IoU/分割 IoU 为 0.183/0.224，消融后为 0.033/0.059，说明动态先验已产生因果空间作用。但宏分 0.736 仍低于首轮 0.753，当前冠军不变。

官方 Transolver 审计推翻了此前的“共享地址权重是下一必然瓶颈”。相应四个结构缺口已经落地修正：固定欧拉有序历史；显式动作与动作精度；同图、异方差的动态先验/后验 KL；逐样本进入自由能的终端模态精度。原 `next_place` 任意列表循环也已替换为周期微世界：历史给出惯性速度，独立动作给出冲量。当前只证明结构、梯度和一轮训练冒烟通过；尚未证明新检查点的未来准确率与四能力不回归，因此不能宣布世界模型能力闭环。

进一步的“Goal/Action 私有 zero-AdaLN、无 SIGReg”诊断没有解决问题：完整银行上生成/当前/编辑/未来分别为 0.892/0.824/0.821/0.227，未来主指标仅 0.137。动作完整时的位置/分割 IoU 为 0.124/0.150，动作置零后反而升至 0.159/0.175；历史消融下降 0.022，但动作、时距和未来目标消融分别改善 0.030、0.042、0.027。该检查点被拒绝，实验性私有通道已回退，冠军保持不变。以后完整动作条件必须在未来配对位置 IoU 和分割 IoU 上**分别**优于 `action_precision=0` 才能获准；均值或宏分不能掩盖任一负项。下一候选应是 action token 与空间/Slice token 的因果耦合及反事实动作监督，而不是继续增加 AdaLN 或 SIGReg。

后续 v6–v13 系列进一步收缩了瓶颈。单一 action token 不能可靠寻址；把 τ 作为临时 token 可减轻但不能消除图表错位；加入由 Slice 软质心、相对位移和动作共同参数化的 attention bias 后，旧银行首次得到动作位置/分割同时微正（+0.00029/+0.00213），但效应接近零。加入 τ=0 proposed-action 与 τ=1 no-op 反事实后，horizon/history/action 可同时转正，却会破坏当前与编辑。冻结、分阶段训练和全局 PCGrad 均无法同时保住动作因果；PCGrad 完整银行仍为动作位置/分割 −0.00073/−0.00081。

v14 已把第一种方案直接实现为条件 VFE 内的五动作配对观测能量，而非动作分类器。它只得到 +0.000373 的微弱对角能量间隔，对比损失仍接近随机五选一的 \(\ln 5\)。完整审计中历史位置/分割因果为 +0.0122/+0.0106，但动作两项为 −0.00113/−0.00758；未来主指标 0.109，且编辑 0.798 略低于门槛。该检查点被拒绝，说明“把反事实关系写进损失”仍不足以让当前 action-attention bias 控制最终写入位置。

随后先修正了动作 `(dx,dy)` 与网格 `(y,x)` 的坐标顺序；v15 证明这是代码正确性问题但不是能力瓶颈，动作位置/分割仍为 −0.00027/+0.00114。v16 又加入零初始化、动作条件的 Slice 分配场周期平流；它保持固定欧拉 (X)、同一 Deslice 和零动作恒等，但动作位置/分割变成 −0.00760/−0.00458，故该机制被拒绝并默认关闭。

只读诊断解释了为什么：每层 `w_read` 的点间标准差仅 0.0069–0.0118，Deslice 写入增量的点间标准差仅 0.00036–0.00129；平移近似均匀的分配概率不会产生一个网格单元的场迁移。下一步若继续 transport，必须先把**空间解析的持久信念内容**与固定坐标图表分清，再让动作条件的欧拉算子演化内容；不能盲目平流混有坐标嵌入的整个 (X)，也不能把网络深度偷换成四个物理时间步。五动作配对观测能量继续只作验收测量。

为统一生成动作与物理动作，v17–v18 把外部动作直接接入成功的 F2 prior action：仅在第一次物理转移构造列归一化的 `T_a(m_dst|m_src)`，执行 `S_write ← T_a S_write` 后仍用原 `Deslice(w_read)`。v17 的恒等 softmax 饱和，`T_a` 实际未被使用；v18 改为非饱和随机转移 `T_a=(1-rho)I+rho P_a`。v18 保住三个静态门，并让整体动作位置/分割首次在新银行双正（+0.00185/+0.00170），但仍低于 0.005；单独把 `T_a` 置恒等后位置完全不变、分割略好，故新增转移不是因果来源。

这证明的不是“VFE 不能动作”，而是当前瞬态、弥散 Slice 的软质心并不是跨时刻稳定的状态地址。下一项若继续，应让动态先验与未来后验在一个可配对的 Slice 坐标中定义转移似然，或直接在持久点场内容上定义固定地址算子；不能再只靠终端 RGB/分割损失期待瞬态 Slice 自动获得身份。

`ActiveInferenceGDN2` 的 v19–v29 系列把该缺口进一步收敛。瞬态
`w_read` 落地会使记忆分割消融变负；固定 atlas 落地的 v20 则为双正。v21
在 Slice 对应尚不可靠时执行 history predict-before-correct 搬运，反而降低
动作与记忆效应，因此历史搬运成为默认关闭的显式消融，而不是由理论自动
进入主线。

更大的收益来自边界去混淆：未来样本中的 `Predict next frame` 只是任务标签，
不含目标语义；将其设为文本缺失后，未来主指标由约 0.117 提升到 0.153，
历史与动作效应同时增强。模式仍由真实边界 `history/τ/action` 全局定义；只有
携带目标内容的语言才作为语义证据。这不是取消语言条件，而是禁止任务标签
冒充观测。

最终的坐标闭合修正区分固定坐标基底与可搬运内容：
`X_content = encode(image) - encode(black_at_same_xy)`。GDN-2 只在固定
atlas 上压缩、搬运并散射该内容；语义生成继续由 F2 language prior 负责，且
GDN 写回在 `τ=0` 严格关闭。稠密任意投影被否证，因为它会重新破坏物理
图表；v29 改用从 0.1 开始的逐通道 prior trust，在一个检查点上保留生成/当前/
编辑 `0.891/0.764/0.901`，并得到 causal-memory 位置/分割
`+0.00040/+0.00073`、history `+0.02172/+0.03085`、action
`+0.01941/+0.00134`。它首次满足记忆消融双正，但动作分割仍未达到 0.005，
且只有单 seed，因此状态是 **partial**，不是完成。完整设计与停止条件见
`docs/ACTIVE_INFERENCE_GDN2.md`。

## 7. 检查点验收

统一检查点至少报告每个边界的文本准确率、RGB PSNR、数字身份、颜色、配对位置 IoU、分割 IoU，以及对应精度/时距消融的下降量。固定银行、随机种子、配置和检查点必须一起发布。

当前微基准只是架构闭环，不是开放域 VLM 声明。只有单检查点同时过门，才扩数据；任何单项提升若破坏另一能力或引入旁路，均不算进展。

## 8. 变更治理

每个架构 PR 必须回答：

- 是否仍只有一个持久全分辨率视觉场和一条 Slice 语义写回主路？
- 新能力是否来自边界/似然，而非端口私有主干？
- 哪个固定银行指标会改善，哪个干预能排除旁路？
- 是否保持已通过的生成能力？
- 失败时应删除哪项机制，而不是再加哪个模型？
