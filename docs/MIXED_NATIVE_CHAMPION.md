# 64px / 256px 原生混训：同一统一检查点

## 目标与边界

同一份权重在原生 64×64 和 256×256 上完成生成、知觉、编辑、重建、分割、
文本输出和下一帧预测。不以两份权重、图像放大、私有任务网络或新增循环代替。
特殊任务 TToken 保留；额外 sink/MoE 暂不启用，既有试验未证明其能解决生成。
北极星仍为 `NORTH_STAR.md`。

## 原生分辨率修复

Slice 核心参数不依赖点数，但旧外围代码使用构造时 `res` 检查或还原空间尺寸。
本轮令编码、局部卷积、RGB/分割还原、动作坐标和 GDN-2 atlas 按本次输入推断
方形网格边长。不改参数数量，不修改全局 `self.res`，不插值位置参数。
64px/256px 两个计算图可同时反向到同一组参数；变尺寸前向与同权重、相应尺寸
实例的结果逐值一致。旧 patch 对照仍依赖固定位置表，不在此次支持范围内。

当前支持方形网格，不声称已支持任意长宽或不规则网格。参数可复用也不等于
不同采样密度下数值严格不变，局部卷积仍以像素为邻域，因此要实际混训验收。

## 第一轮混训（已完成）

入口 `scripts/train_mixed_native.py`，从真实任务候选 `real256_joint.pt` 续训。
一个 d64/M16/L4 图、冻结 Pythia-70m，保留修复后的逐头高斯布局；GDN-2 仅 τ>0。
新增优化器，LR 3e-4 经 3,200 次更新余弦退火至 3e-5。

每次更新选择同一个样本，分别从原始文件获得 64px 和 256px 目标；两个原生
损失各占 1/2，累积梯度后只更新一次。六类任务轮换，记录每个样本的真实曝光。
14 个真实/明确派生样本上增加两个零时距对照：同一视频、当前图、历史和
future TToken，τ=0 的目标为当前帧。这样任务标签不能单独决定目标时刻。

```powershell
python scripts/train_mixed_native.py --sharegpt-manifest D:/ml_cache/sharegpt4o/pilot_manifest.json --davis-manifest D:/ml_cache/davis_micro/manifest.json
```

每 400 步保存候选，分别展示两个原生尺寸的目标、输出、掩码和实际文字回答。
结果为 `results/published/mixed_native_64_256.json`；展示为
`present/mixed_native_64_256_{64,256}.html`。旧保护权重不覆盖。

### 3,200 步独立重载结果

`mixed_native_64_256.pt` 的 SHA256 为
`fa923cd0427d7bdf33068851cf88bede75c891094e42f764eb60cea164052b2a`。
64px/256px 的真实完整描述都达到 **2/2 exact + EOS**，不再把两张图答成同一句。
对应换图 NLL 增量平均为 0.160/0.148，仍未达到此次登记的 0.3 门槛。
重建 PSNR 30.91/31.85dB，编辑与 identity 宏平均 24.07/24.45dB，但实际编辑

这是已独立重载的双分辨率候选，不是完整统一冠军。

只读排查补充：1600 步 CPU 逐词诊断中，第一处答案分歧为 outdoor/urban，
换图显著改变这两个候选词的概率，图像梯度非零；随后 3200 步实际完整解码
转为全对，故之前串台不能简单归因于读图路径断开。CPU/训练 GPU 数值略异，

3200 步冻结视觉场的逐样本 logit 最小二乘读出诊断也没有恢复自然图边缘。
这些目标拟合结果不是生成图片、不是新权重，也不是最优 RGB 拟合上界。

## 本阶段逐样本检查

两个分辨率分别检查，宏平均不得掩盖失败。此次固定银行的工作阈值：

| 任务 | 每个样本要求 |
|---|---|
| 文生图 | PSNR ≥20dB，边缘相关 ≥0.5，换提示后目标 MSE 增量 >0.001 |
| 编辑及不变指令 | PSNR ≥23dB，边缘相关 ≥0.6，换指令后目标 MSE 增量 >0.001 |
| 重建 | PSNR ≥25dB，边缘相关 ≥0.7 |
| 图生文 | 完整句子 graph-greedy exact、EOS，换图 NLL 增量 >0.3，重建 ≥25dB |
| 当前分割 | 官方前景 IoU ≥0.85，重建 ≥25dB |
| 下一帧 | IoU ≥0.85、PSNR ≥25dB；τ>0 时全图及变化区域 MSE 均优于复制当前帧，去时距后目标 MSE 变差 |

这些是本阶段容量检查，不是开放域标准；图像仍需并排观看内容和编辑区域。
预算结束必须重新实例化并加载一份权重复测两种尺寸。即使本表通过，完整目标
还需把纯文本、真正图文问答以及 1px 能力加入同一检查点并验收，不得提前称
“统一冠军”。更长训练是否足够，要由本轮轨迹和实际输出回答。

## 完整端口第二轮（训练中，尚未验收）

`--full-bank` 在上述 16 条监督基础上显式追加 26 条，总计每个分辨率 42 条：
2 条纯文本算术问答、4 条真实图像问答、10 条 noisy 1px OCR、10 条原生 1px
数字生成及掩码。原来的自然图生成、编辑、完整句子描述、真实视频任务全部保留。

真实问答为经过原图核对的人工监督，不冒充 ShareGPT 官方问答：热气球与猫的
两张图分别回答“是否有猫”“是否有热气球”。同图换问题或同问题换图都会翻转
答案，分别检查两种观测是否被使用。解码沿用训练 collator 的观测前缀，已生成
token 只进入因果语言上下文，不作为视觉证据；不能丢掉问题后仍声称图文问答。

1px 在每个原生网格直接用 Bresenham 绘制，固定 14px 字形、1px 线宽，不把
64px 栅格放大。OCR 是旧噪声字形生成器的固定集回归，不是新字体泛化。
1px 生成须 RGB 笔画 IoU ≥0.9、分割 IoU ≥0.95、PSNR ≥30dB，换数字提示
后原目标笔画 IoU 至少下降 0.1；不能靠几乎全黑画布的高 PSNR 通过。
新增所有文字任务须 exact+EOS；相应换图/换问题 NLL 增量各 >0.3。

续训按任务与数据类型分组轮换，避免十个 OCR/字形把自然图回放比例挤掉。
第一轮 3,200 步始终使用原 16 条银行，未中途更改数据或损失。
第二轮从其最终权重启动，新增优化器，LR 1e-4 经 6,400 步余弦降至 1e-5，
每 800 步分别评估两个原生尺寸。图、似然和冻结 Pythia 不变；无 sink/循环。

```powershell
python scripts/train_mixed_native.py --init checkpoints/mixed_native_64_256.pt --sharegpt-manifest D:/ml_cache/sharegpt4o/pilot_manifest.json --davis-manifest D:/ml_cache/davis_micro/manifest.json --full-bank --steps 6400 --eval-every 800 --lr 0.0001 --tag mixed_native_full_64_256
```

新产物前缀 `mixed_native_full_64_256`；第一轮与旧保护权重不覆盖。
启动后每 50 步记录当前步数/曝光，检查点步数单独记录，避免把日志进度当成
已保存权重。训练入口通过不等于这些新增能力已经合入成功权重。

### 完整银行首次评估与恢复记录

800 步，64px/256px 均保持真实描述 2/2、纯文本 QA 2/2；图文 QA 都为 3/4。
1px OCR 仅为 1/10 与 2/10，1px RGB 笔画 IoU 全为 0。当前分割平均 IoU 为
0.847/0.867，但仍需逐样本通过，而不是只看平均数。自然图细节尚未闭合。

约 1050 步后出现 CUDA OOM。Windows System Event 2004（13:13:24）明确记录
系统虚拟内存耗尽：并行 CPU 诊断占 7.00GB，训练进程占 6.62GB。不能把它
解读成已证明单独运行的 256px 图必然超出 4GB 显存。诊断本只需 RGB 头梯度，
却保留了全分辨率主干反向图；已改为无梯度主干前向加独立末端导数。

`--resume-training` 恢复优化器、原始总步数退火、样本轮换位置与保存时曝光；
新检查点额外记录随机数状态。旧 800 步文件没有 RNG，因此本次不声称完整
GPU 轨迹逐位重现。确定性测试证明已有 RNG 的中断恢复与连续训练逐位一致。
约 250 次未保存更新不可恢复，从 800 步重跑；原失败报告保留。
