# 连续粒子 Slice-Cayley：第一版结构性加速候选

2026-09-11。用户授权开始结构性加速。此候选保留全体连续位置与速度、驱动/OU/读出和时间分裂，用有限通道替代逐候选串行随机碰撞；不是标准LBM，也不声称等价原玻尔兹曼碰撞。独立工作树主模型和原检查点保持独立。

## 最终机制

实现 `scripts/ib_slice_collision.py`。M=16个可学习通道，W=softmax(assignment(x))；将W各列中心化并按列范数归一化后除sqrt(M)得到U，每列粒子和为零。加1e-8保护近零范数。通道特征由W质量归一化聚合[x,v]；分别经过q/k投影，加独立可学习channel_mixing后取反对称部分，tanh及rate/M约束得S。可学习速度轴B每行归一化。展平速度空间中的第a个基向量为P_a=U_a outer B_a。

Gram=PᵀP=(UᵀU)逐元素乘(BBᵀ)。实现低秩Cayley：

Vflat' = Vflat + dt P solve(I-dt/2 S Gram, S Pᵀ Vflat)。

不构造ND×ND矩阵，不循环粒子对。P的每一列在每个速度方向的粒子和为0；PSPᵀ反对称，因此冻结子步更新守恒所有方向总动量及总动能。位置不动，恒定统一速度不变；不同速度轴允许速度协方差变化。不是把速度简单平均后全局归一化。成本包含O(NM²+M³+NMD+M²D)，固定M/D时对N线性；不能省略Gram/求解成本或宣称任意精度下M恒定。

原碰撞概率score项归零，因为碰撞变为确定性映射；OU继续原随机抽样。candidates/accepted=0表示无二元抽样过程，不表示无相互作用，活动需用速度更新范数衡量。新碰撞参数重新初始化并加入优化器，原碰撞参数和对应优化器状态被移除，共用参数及优化器状态保留。这里只作旧checkpoint迁移后的运行测试，不叫严格续训。

## 已排除的假加速

第一版通道统计接近，实际更新被FP32舍入抹掉，不能用其速度数字证明有效碰撞。加入列归一化与可学习通道混合后解决数值恒等。

第二版将同一个正交变换作用于所有速度方向，额外保持整个速度协方差，无法改变全局各向异性；此版本未作为最终结果。最终引入速度轴，在展平速度空间操作，新增协方差确实变化测试。新版rank(P)可达M，最多作用于M维子空间；保留M>=3是配置约束，不声称新版M=2数学必然恒等。

## 内存与最终实测

最初1024粒子试跑触发2.4GiB进程显存上限（主动留出系统余量），没有继续提高上限。改用共享驱动token投影与激活重计算，保留梯度，以重算换取显存。已有Triton OU前后向继续使用。重算通过非饱和状态/参数梯度及在线更新测试。

全部从500步检查点相状态和共用参数出发，碰撞新初始化seed11；N>32重复原经验支持后各自接收独立粒子噪声，是运行扩展探针而非已训练的大个体。16事件预热后64真实OWT事件/4次更新，含能量记账；以下均为最终v3、M16、共享驱动+重算+Triton：

|粒子数|64事件训练秒|字节/秒|模型张量峰值MiB|
|---|---|---|---|
|32|6.943|9.22|811.6|
|128|6.395|10.01|811.6|
|512|6.620|9.67|880.5|
|1024|6.720|9.52|1088.4|

原32粒子同预算参考9.804秒；最终候选该短窗口约减少29%耗时。不能根据短窗口宣称128必比32快。原1024数字此前仅冻结单事件前向，不能与这里完整训练直接构成加速倍数。新候选最主要成果是1024粒子完整更新窗口变得可运行，未证明语言质量相同。

实际初始单步相对速度变化6.20e-5，非零；32到1024碰撞参数最后梯度范数4.61e-6到8.76e-7，非零。单步相对能量误差约8.3e-8；动量总和最大绝对误差32粒子3.8e-6、1024粒子6.1e-5（绝对总和误差随N增长）。此强度未与原随机碰撞有效混合强度匹配，不能暗示物理效果等价。

## 验证与限制

相关测试45项：守恒、非零变化、协方差可变、置换等变、统一速度不变、状态gradcheck、参数梯度、FP32百次演化、OU前后向、驱动重算、deepcopy隔离、既有接口等。核心数学与机制经独立审查。

尚未建立：局部性、详细平衡、H定理、相空间体积保持、热化、语义记忆、临界性或收敛。状态依赖的P/S即使每步Cayley正交，也不意味着完整非线性映射体积保持或可逆。通道均匀导致U=0、速度轴退化、有限秩覆盖不足和质量归一化敏感性仍需长训练监测。固定rate界也未匹配原跳跃率，不是原模型的“更快内核”。
