# Historical Information Boltzmann scripts

This directory is retained for provenance and for reproducing prior commits.
It contains mutually incompatible architecture generations, temporary
diagnostics, and one-off runners.  It is not an active development surface.

Active shared operators live in `information_boltzmann/`; supported runnable
entry points live in `scripts/ib/`.  A historical script can re-enter the
active line only through a named migration with a configuration, unit tests,
and a registered evaluation protocol.
