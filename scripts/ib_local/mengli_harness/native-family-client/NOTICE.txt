The official/ directory and lib/client.js are generated by node build.mjs and
excluded by this directory's .gitignore. External node_modules are never edited.
Each generated official package retains its original name, version, locale,
assets and LICENSE. Only the project-owned copies receive hooks described by
build.mjs and chat-hook.js. There is no independent frontend application.

Rebuild: node build.mjs
Test: node --test tests/native-family.test.mjs
Profile integration: buildNativeFamilyPatch({packageRoot}) from profile.mjs.
The function is synchronous and ensures the generated bundles exist.
MENGLI_DSH_PACKAGE_ROOT can override the local official package root for CLI builds.
