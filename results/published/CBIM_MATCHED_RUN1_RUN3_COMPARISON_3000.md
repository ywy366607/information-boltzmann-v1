## 三、核心物理与架构结论

1. **混淆变量的彻底剔除**：
   - 之前在未对齐测试中，Run 3 表现出 +0.27 nats 的 NLL 劣势，主要来自于 $(4, 4, 4)$ 紧凑网格带来的 4 倍空间容积压缩，以及 Arm A 全局动态线性读出将多圈未衰减回声全部灌进分类器；
   - 一旦将 Run 3 统一对齐到 $(8, 8, 4)$ 环面和 Arm C 局域探针高斯核读出后，NLL 劣势立即从 +0.27 nats 缩减至仅 0.06 ~ 0.09 nats，且在 Site 2 上直接反超 Run 1！
2. **碰撞计算的绝对必要性（真物理确立）**：
   - Run 1 在离散速度网格下，关闭碰撞只损失 +0.395 nats；
   - Matched Run 3 在完全相同的 256 格点下，关闭碰撞损失高达 **+0.794 nats**，关闭全动力学损失高达 **+1.241 nats**（在 Site 3 高达 +2.73 nats）；
   - 这确立了：**当速度方向被释放到 $S^2$ 连续流形后，玻尔兹曼碰撞算子真正承担了关键的推理与非线性混合计算**。
