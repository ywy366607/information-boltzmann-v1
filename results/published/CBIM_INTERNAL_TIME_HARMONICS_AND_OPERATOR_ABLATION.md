# CBIM 内部时间谐波周期（T=128/256）与算子分解消融研究记录

> **测试对象**：3000 步连续神经算子 CBIM Checkpoint (`BBest.pt`)。
> **四项核心实验完整闭环**：
> 1. **零场基线控制**：测得 $L_{\text{zero-field}} = 9.1367\text{ nats}$，破译未缩放闭环 $K \ge 8$ 平台期之谜；
> 2. **匹配保持预算闭环推演**：$\gamma_{0, K} = \gamma_0 \frac{3}{K}$ 彻底消除能量冻死，长程闭环 $K=8 \to 32$ 收益高达 **$-0.6051\text{ nats}$**；
> 3. **单步致密内部时间轨迹（K=1..512）与谐波分析**：在空间 DC 流形上发现精确的基频谐波族（$T_0 = 256.0, T_2 = 128.0, T_3 = 85.3, T_5 = 51.2$），证明内部思考是低维慢流形上的相位旋转，Readout 本质是**最优观测相位问题（Optimal Observation Phase）**；
> 4. **额外步算子消融（TC vs Viscosity vs Subspace vs TCD）**：纯计算算子 $T+C$ 能量守恒且维持在 $7.58 \sim 8.07\text{ nats}$；在黏性辅助下，$TC+\text{Visc}$ 在 $K=64$ 达到 $8.7781\text{ nats}$。

## 一、 实验一：零场基线控制（Zero-Field Control Baseline）

在 1024 个连续 Token 上评测系统彻底失去场记忆时的极限语言底线：

| 实验条件 | Validation NLL | 相对基准偏移 | 物理状态描述 |
| :--- | :--- | :--- | :--- |
| **1. 词表均匀随机猜测** | $10.8249\text{ nats}$ | $+1.8290$ | 纯均匀最大熵 $\ln(50257)$ |
| **2. 绝对物理真空 ($F=0, \mathbf{e}_{\text{tok}}=0$)** | **$9.1367\text{ nats}$** | $+0.1408$ | 场与输入完全清空 |
| **3. 零场注入 Token 探针 ($F=0, \mathbf{e}_{\text{tok}}=\text{embed}(x_t)$)** | **$9.1367\text{ nats}$** | $+0.1408$ | 场清空，仅有当前词探针 |
| **4. 无记忆瞬时写入 ($F_{\text{prior}}=0, \text{Write}, K=0$)** | **$7.9524\text{ nats}$** | $-1.0435$ | 孤立写入波包即时读出 |
| **5. 无记忆单步演化 ($F_{\text{prior}}=0, \text{Write}, K=3$)** | **$11.0142\text{ nats}$** | $+2.0183$ | 孤立波包在真空中色散色湮灭 |
| **6. 全连续物理流（正常记忆流，$K=3$）** | **$8.9959\text{ nats}$** | 基准 ($0.0$) | 稳态背景场支撑的物理记忆流 |

### 关键物理机制解释：
1. **单字先验吸引子（Marginal Unigram Prior, 9.1367 nats）**：
   在特征核读出（Characteristic Kernel Readout）中，当 $F=0$ 时，经 RMSNorm 与注意力投影后一阶矩 $R=0$、二阶方差矩 $E=0$。后置多层感知机将该零输入映射为固定偏置常数向量 $\mathbf{c}_0$，解码器将其解码为训练集的**无条件单字边际分布**。其交叉熵正是 $9.1367\text{ nats}$（比均匀白噪声低 $1.69\text{ nats}$）。
2. **破译未缩放长程闭环平台期之谜**：
   在未做保持率缩放的闭环实验中，$K=8, 16, 24$ 的 NLL 死死稳定在 $9.1290 \sim 9.1454\text{ nats}$。这并非语言计算的饱和，而是因为每步乘以 $e^{-K \gamma_0}$ 导致背景场能量彻底被抽干（$E \to 0.0000$），模型退化为了零场单字先验机。

## 二、 实验二：匹配保持预算闭环推演（Matched-Retention Rollout）

对外部记忆时间尺度（Token Clock）与内部计算时间尺度（Internal Pondering Clock）进行解耦，令内部微步耗散衰减率满足：
$$\gamma_{0, K} = \gamma_{0, \text{ref}} \cdot \frac{3}{K} \implies \sum_{k=1}^K \gamma_{0, K} \Delta\tau = \text{Const}$$

| **$K = 1$** | $8.9093$ | $0.0557$ | $9.6251$ | $0.0235$ | $+0.7158$ | $50.7\text{ tok/s}$ |

### 结论：
- 一旦消除未缩放累积耗散导致的能量冻死，**闭环深思考的收益全线爆发**：
  $K=8$ 和 $K=16$ 闭环 NLL 达到 **$8.78 \sim 8.79\text{ nats}$**，相比未缩放基准净降 **$-0.50\text{ nats}$**！
  $K=32$ 净降 **$-0.6051\text{ nats}$**！
- 证明双钟解耦（Two-Clock Decoupling）是物理连续神经算子的核心铁律。

### FFT 功率谱分析（FFT Power Spectrum Peaks）：
对去趋势后的内部时间损失轨迹 $\tilde{L}(k)$ 进行傅里叶变换，发现极具物理意义的离散共振峰：
- **峰 1（基频半波/基频共振）**：$T_1 = 256.0\text{ microsteps}$ ($f = 0.00391$)
- **峰 2（二次谐波，即 128 步周期）**：**$T_2 = 128.0\text{ microsteps}$** ($f = 0.00781$, 功率 $1.11 \times 10^2$)
- **峰 3（三次谐波）**：**$T_3 = 85.3\text{ microsteps}$** ($f = 0.01172 = \frac{3}{256}$, 功率 $1.52 \times 10^2$)
- **峰 4（五次谐波）**：$T_5 = 51.2\text{ microsteps}$ ($f = 0.01953 = \frac{5}{256}$)
- **峰 5（七次谐波）**：$T_7 = 39.4\text{ microsteps}$ ($f = 0.02539 = \frac{6.5}{256}$)

### 物理重大洞察：
1. **内部动力学是空间 DC 流形上的速度空间相干振荡**：
   从表中的傅里叶壳层分解可见：$K \ge 4$ 后，非零波数模式（$q=1, 2, \ge 3$）在空间谱上全部被连续谱黏性 $e^{-\nu |k|^2 \tau}$ 耗散湮灭（DC 占比 $1.000$）。
   **剩下的全部动力学是 8 个速度方向与 16 个内容维度构成的 128 维空间在碰撞与平流驱动下的相位旋转（Phase Rotation）与拍频（Beating）！**
2. **读出本质是“最佳观测相位问题”而非“单调停机问题”**：
   $K=64$ 到 $K=192$ 之间的 128 步差值，正是**环面上基频 $T_0 = 256$ 的严格半周期反节点（$\frac{T_0}{2} = 128$）**！
   在 $K=96$ ($8.6727$) 和 $K=192$ ($8.7061$)，内部波场转到了与 Characteristic Kernel Readout 探针几何正交对齐的“最佳可读相位”；而在 $K=160$ ($9.0736$) 和 $K=256$ ($8.9663$)，波场转到了不良读出相位。
   这为后续 Controller 的设计提供了坚实动力学基础：**模型不是在等待能量耗散收敛，而是在等待波场转动到最佳观测窗口**。

## 四、 实验四：额外步算子分解消融（Operator Component Ablation）

比较当 $K$ 扩展到 $K=256$ 时，内部各个物理算子所起的核心作用：
- **Branch 1: `TC (Pure Comp)`**：纯计算流（平流 advection + 碰撞 collision，零耗散）；
- **Branch 2: `TC + Viscosity`**：计算 + 连续谱高频黏性 $\nu |k|^2$（无子空间遗忘，无全局衰减 $\gamma_0$）；
- **Branch 3: `TC + Visc + Sub`**：计算 + 高频黏性 + $U \Lambda U^\top$ 子空间特征遗忘（无全局衰减 $\gamma_0$）；
- **Branch 4: `Full TCD`**：完整统一耗散算子（含全部项）。

### 核心物理发现：
1. **纯计算流 $T+C$ 保持纯能量且维持惊人能力（$7.58 \sim 8.07\text{ nats}$）**：
   在不施加任何耗散阻尼时，$T$（正交 Cayley 酉变换）与 $C$（李代数保模辛旋转）实现纯信息重组，波包的高对比度与全频结构得以完整保留，其 NLL 全程稳定在 $7.58 \sim 8.07\text{ nats}$！
2. **黏性是正规化，而过度子空间遗忘与 $\gamma_0$ 是深思劣化的根源**：
   对比 `TC + Viscosity` 与 `Full TCD`：
   在 $K=64$ 时，`TC + Viscosity` 达到 **$8.7781\text{ nats}$**，显著优于 `Full TCD` 的 $8.9813\text{ nats}$；
   在 $K=256$ 时，`TC + Viscosity` 保持在 **$8.8860\text{ nats}$**，比 `Full TCD` 的 $9.0258\text{ nats}$ 领先 $0.14\text{ nats}$。
   这证明：**深微步中真正需要保留的正则化仅有高频谱黏性 $\nu |k|^2$（防止激波与数值奇点），而全局遗忘 $\gamma_0$ 与子空间消除 $U \Lambda U^\top$ 应当由外部 Token 时钟控制！**
