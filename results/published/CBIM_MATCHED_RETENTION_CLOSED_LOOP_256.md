## 一、 理论假说与双钟解耦机制（Two-Clock Decoupling）

在物理流体动力学中，存在两个本质截然不同的时间尺度：
1. **外部 Token 寿命时间（External Memory Retention Clock, $\Delta t_{\text{token}}$）**：
   控制语境记忆的自发半衰期，对应全局记忆泄漏算子：
   $$\mathcal{D}_{\text{retention}} = \exp\left(-\gamma_0 \Delta t_{\text{token}}\right)$$
   这一物理过程每个 Token 仅应发生一次。
2. **内部计算演化时间（Internal Computation Clock, $\tau$）**：
   控制在单步观测内的物理场碰撞重组与特征沉思：
   $$\Phi_\tau = (\mathcal{D}_{\text{visc}} \circ \mathcal{C} \circ \mathcal{T})^K$$
   内部思考应保持净信息流，而不应将外部记忆泄漏也重复执行 $K$ 次。

在未缩放的 Baseline 中，执行 $K$ 步 microsteps 会导致全局衰减项被累乘 $K$ 次：
$$\prod_{k=1}^K e^{-\gamma_0 \Delta\tau} = e^{-K \gamma_0 \Delta\tau}$$
这导致大 $K$ 下流体场能量被迅速抽干（$E \to 0.0000$），陷入**慢性耗散冻死（Over-Dissipation Freeze）**。

而在**匹配保持预算（Matched Retention）**策略下，将内部每步的保持泄漏率缩放为：
$$\gamma_{0, K} = \gamma_{0, \text{ref}} \cdot \frac{3}{K}$$
保证一个 Token 内累积的保持衰减预算恒定：
$$\sum_{k=1}^K \gamma_{0, K} \Delta\tau = 3 \gamma_{0, \text{ref}} \Delta\tau = \text{Const}$$

## 三、 突破性物理结论

### 1. 彻底打破闭环大 $K$ 失效魔咒（NLL 暴降 -0.6051 nats）
- 在未缩放 Baseline 中，$K \ge 8$ 闭环推演全面恶化，并在 $K=32$ 飙升至 $9.5283\text{ nats}$，其场能量在 $K \ge 32$ 衰减至 $0.0011 \to 0.0000$，退化为零场底线。
- 在匹配保持预算下，场能量全程保持在充沛健康水准（$K=8$ 时 $E = 0.0131$，$K=32$ 时 $E = 0.0101$）。
- 伴随着健康能量底座的维持，**闭环深思考的威力全面释放**：
  - $K = 8$: NLL 从未缩放的 $9.2178$ 骤降至 **$8.7839\text{ nats}$**（净收益 **$-0.4339\text{ nats}$**，推理速度保持在 $15.5\text{ tok/s}$）；
  - $K = 16$: NLL 稳定在 **$8.7981\text{ nats}$**（净收益 **$-0.5036\text{ nats}$**）；
  - $K = 32$: NLL 从 $9.5283$ 暴降至 **$8.9231\text{ nats}$**（净收益高达 **$-0.6051\text{ nats}$**）；
  - $K = 64$: NLL 依然维持在 **$8.9507\text{ nats}$**（净收益 **$-0.3475\text{ nats}$**）。

### 2. 双钟架构的架构规范确立
实验无可辩驳地证明：
**大 $K$ 的闭环崩溃不是深思考有害，而是因为把全局记忆时间（Token Clock）与内部计算时间（Internal Clock）混为一谈！**
在后续统一架构中，必须在数学上实现解耦：
$$\mathcal{G}_{\text{step}} = \mathcal{D}_{\text{retention}}(\gamma_0) \circ \left[\prod_{k=1}^K \mathcal{D}_{\text{visc}}(\nu) \circ \mathcal{C} \circ \mathcal{T}\right]$$
外部衰减只做一次，内部纯粹由信息平流、非线性碰撞与物理自激黏性主导。
